## 🛠️ Efeitos Visuais

Este é o arquivo de **efeitos visuais anexados** do servidor **OpenTibiaBR/Canary**. Define auras, shaders, efeitos de partículas e asas aplicados aos avatares dos jogadores.

<Card title="Caminho Original" icon="document">
  `data/XML/attachedeffects.xml`
</Card>

<Aside type="tip">
  Efeitos visuais complementam as aparências (outfits). Podem ser obtidos via eventos, lojas ou quests, criando customização visual para os jogadores.
</Aside>

## 📄 Visão Geral

O arquivo organiza efeitos cosmética em **4 categorias**:

- **Auras**: Brilho/halo ao redor do avatar
- **Shaders**: Efeitos gráficos avançados (rainbow, ghost, jelly, fragmented, outline)
- **Efeitos**: Partículas visuais gerais
- **Asas**: Acessórios visuais anexados

## 🔧 Estrutura de Elementos

### Aura

```xml
<aura id="8" name="8 aura" />
```

<Card title="Propriedades" icon="parameters">
  - **id**: Identificador único
  - **name**: Descrição humanizada

Auras criam efeito de brilho ao redor do avatar.
</Card>

### Shader

```xml
<shader id="1" name="Outfit - Rainbow" />
```

<Card title="Shaders Disponíveis" icon="parameters">

| ID | Nome | Efeito |
|----|------|--------|
| 1 | Outfit - Rainbow | Arco-íris |
| 2 | Outfit - Ghost | Fantasmagórico |
| 3 | Outfit - Jelly | Gelatinoso |
| 4 | Outfit - Fragmented | Fragmentado |
| 5 | Outfit - Outline | Contorno |

Shaders modificam a aparência visual completa do outfit.
</Card>

### Effect

```xml
<effect id="7" name="7 effect" />
```

Efeitos são partículas visuais gerais, menos especializados que shaders.

### Wing

```xml
<wing id="2" name="2 wings" />
```

Asas são acessórios visuais anexados ao corpo.
