## 💡 Utilidade

Este arquivo define um sistema completo de encantamentos para equipamentos. Cada encantamento tem diferentes níveis (Basic/Intricate/Powerful), custos, duração e efeitos específicos. Inclui dano elemental, vamp/mana leech, crítico, proteção e skills boosts.

## 📄 Visão Geral do Código Resumo Executivo

O arquivo `imbuements.xml` implementa um sistema de encantamentos:

- **3 Níveis Base**: Basic, Intricate, Powerful (progressão)
- **19 Categorias**: Dano, proteção, leech, crítico, speed, skills
- **Múltiplos Efeitos**: Dano elemental (5 tipos), leech, crítico, etc
- **Sistema de Custos**: Price, protectionPrice, removecost
- **Duração**: Fixado em 72000 (algumas variações)
- **Premium/Storage**: Alguns requerem premium ou storage

## 🔧 Estrutura de Funcionalidades

### Estrutura Geral

```xml
<imbuements>
    <base id="..." name="..." price="..." protectionPrice="..." percent="..." removecost="..." duration="..." />
    <category id="..." name="..." agressive="..." />
    <imbuement name="..." base="..." category="..." ...>
        <attribute ... />
    </imbuement>
</imbuements>
```

### Elemento: Base

```xml
<base id="1" name="Basic" price="5000" protectionPrice="10000" percent="90" removecost="15000" duration="72000" />
```

**Atributos:**

| Atributo | Descrição | Exemplo |
|----------|-----------|---------|
| `id` | ID único da base | 1, 2, 3 |
| `name` | Nome (Basic/Intricate/Powerful) | Basic |
| `price` | Preço em moeda | 5000 |
| `protectionPrice` | Preço de proteção | 10000 |
| `percent` | Percentual de efetividade | 90 (80%), 70 (diminui) |
| `removecost` | Custo para remover | 15000 |
| `duration` | Duração em ms | 72000 (20 horas) |

**Bases Definidas:**

| ID | Nome | Price | Protection | Percent | Remove | Duration |
|----|------|-------|-----------|---------|--------|----------|
| 1 | Basic | 5000 | 10000 | 90 | 15000 | 72000 |
| 2 | Intricate | 30000 | 30000 | 70 | 15000 | 72000 |
| 3 | Powerful | 200000 | 50000 | 50 | 15000 | 72000 |

### Elemento: Category

```xml
<category id="0" name="Elemental Damage" agressive="1" />
```

**Atributos:**

| Atributo | Tipo | Descrição |
|----------|------|-----------|
| `id` | number | ID único da categoria |
| `name` | string | Nome humanizado |
| `agressive` | 0/1 | Se é ofensiva (1) ou defensiva (0) |

**19 Categorias Disponíveis:**

| ID | Nome | Tipo |
|----|------|------|
| 0 | Elemental Damage | Ofensivo |
| 1 | Life Leech | Ofensivo |
| 2 | Mana Leech | Ofensivo |
| 3 | Critical Hit | Ofensivo |
| 4-9 | Elemental Protection (Death/Earth/Fire/Ice/Energy/Holy) | Defensivo |
| 10 | Increase Speed | Defensivo |
| 11-16 | Skillboost (Axe/Sword/Club/Shielding/Distance/Magic) | Ofensivo |
| 17 | Increase Capacity | Defensivo |
| 18 | Skillboost (Fist) | Ofensivo |

### Elemento: Imbuement

```xml
<imbuement name="Scorch" base="1" subgroup=" (Fire)" category="0" iconid="13" premium="0" storage="0" sound="2002">
    <attribute key="description" value="Converts 10% of the physical damage to fire damage." />
    <attribute key="effect" type="damage" combat="fire" value="10" />
    <attribute key="item" value="9636" count="25" />
</imbuement>
```

**Atributos:**

| Atributo | Tipo | Descrição |
|----------|------|-----------|
| `name` | string | Nome do encantamento |
| `base` | 1/2/3 | Nível base (progression) |
| `subgroup` | string (opcional) | Subtipo visual |
| `category` | number | ID da categoria |
| `iconid` | number | Ícone UI |
| `premium` | 0/1 | Requer premium? |
| `storage` | number/0 | Storage key para tracking (0 = none) |
| `sound` | number (opcional) | Sound ID ao aplicar |

### Sub-Elemento: Attribute

**Description:**

```xml
<attribute key="description" value="Converts 10% of the physical damage to fire damage." />
```

**Effect (Damage):**

```xml
<attribute key="effect" type="damage" combat="fire" value="10" />
```

- `type="damage"`: Tipo de efeito
- `combat`: Tipo de dano (fire, earth, ice, energy, death)
- `value`: Percentual ou quantidade

**Effect (Skill):**

```xml
<attribute key="effect" type="skill" value="lifeleech" bonus="500" chance="100" />
```

- `type="skill"`: Skill boost/leech
- `value`: lifeleech, manaleech, critical
- `bonus`: Quantidade/percentual boost
- `chance`: Chance de ativar (0-10000)

**Item Requirement:**

```xml
<attribute key="item" value="9636" count="25" />
```

- `value`: Item ID necessário
- `count`: Quantidade necessária

## 📋 Resumo de Implementação

**Progressão de 3 Níveis:**

Cada encantamento tem 3 versões:
- **Base 1 (Basic)**: Menor efeito, barato, sem premium
- **Base 2 (Intricate)**: Efeito médio, custo médio, premium
- **Base 3 (Powerful)**: Máximo efeito, caro, premium + storage

**Exemplo - Encantamento Scorch:**

```xml
<!-- Basic Scorch -->
<imbuement name="Scorch" base="1" ... premium="0" storage="0">
    Converts 10% physical → fire
    Costs: 5000 (price) + 10000 (protection)
    Items: 25x Sulfurous item
</imbuement>

<!-- Intricate Scorch -->
<imbuement name="Scorch" base="2" ... premium="1" storage="0">
    Converts 25% physical → fire
    Costs: 30000 + 30000
    Items: 25x + 5x Phoenix item
</imbuement>

<!-- Powerful Scorch -->
<imbuement name="Scorch" base="3" ... premium="1" storage="50494">
    Converts 50% physical → fire
    Costs: 200000 + 50000
    Items: 25x + 5x + 5x Rare item
</imbuement>
```

**Custos de Encantamento:**

| Base | Price | Protection | Total | Remove |
|------|-------|-----------|-------|--------|
| Basic | 5000 | 10000 | 15000 | 15000 |
| Intricate | 30000 | 30000 | 60000 | 15000 |
| Powerful | 200000 | 50000 | 250000 | 15000 |

**Padrão de Efeito:**

Dano elemental: 10% (Basic) → 25% (Intricate) → 50% (Powerful)
Leech: 5% (Basic) → 10% (Intricate) → 25% (Powerful)
Crítico: +15% dmg/+10% chance → +25%/+10% → +50%/+10%
