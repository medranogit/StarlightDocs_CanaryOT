## 🛠️ Familiares

Sistema de **familiares (criaturas companheiras)** associados a vocações específicas.

  Cada vocação e sua versão avançada têm familares únicos, obtidos via quests ou lojas especiais.

## 📄 Visão Geral

Cataloga familiares com:

- **Organização**: 1 familiar por vocação base + 1 por avançada
- **Visual**: lookType (client ID do modelo)
- **Status**: Premium (sim/não), desbloqueado, habilitado
- **Aquisição**: Quest ou padrão

## 💡 Utilidade

Este arquivo define familiares (criaturas companheiras) disponíveis para diferentes vocações/profissões. Cada familiar tem aparência visual, requisitos (premium/quest), e está associado a uma vocação específica. Permite gerenciar quais familiares cada classe pode obter.

## 📄 Visão Geral do Código Resumo Executivo

O arquivo `familiars.xml` implementa um catálogo de familiares:

- **Associação por Vocação**: Cada familiar está linkedado a uma ou mais vocações
- **Identificação Visual**: lookType para cliente carregar modelo 3D
- **Status**: Premium sim/não, desbloqueado, habilitado
- **Tipo de Obtenção**: Quest (missão) ou Store (loja)
- **Organização**: Agrupado por classe (Sorcerer, Druid, Paladin, Knight, Monk)

```xml
<familiars>
```

## 📋 Resumo de Implementação

**Contagem de Familiares:**
- Total: 20 entradas (2 por vocação base/avançada + 4 Monk)
- Únicos: 10 familiares diferentes
- Premium: Vários (Thundergiant, Skullfrost, Master/Elder, etc)
- Quest: Alternativas especiais (Bladespark, Mossmasher, etc)

**Padrão de Configuração:**

```xml
<!-- Base familiar -->
<familiar vocation="X" lookType="YYY" name="Name" premium="yes/no" unlocked="no" enabled="yes" />

<!-- Quest variant -->
<familiar vocation="X" lookType="ZZZ" name="Name" premium="yes/no" unlocked="no" enabled="yes" type="quest" />
```

**Exemplo Completo (Sorcerer):**

```xml
<!-- Sorcerer base -->
<familiar vocation="1" lookType="994" name="Thundergiant" premium="yes" unlocked="no" enabled="yes" />
<!-- Master Sorcerer base -->
<familiar vocation="5" lookType="994" name="Thundergiant" premium="yes" unlocked="no" enabled="yes" />
<!-- Sorcerer quest -->
<familiar vocation="1" lookType="1367" name="Bladespark" premium="yes" unlocked="no" enabled="yes" type="quest" />
<!-- Master Sorcerer quest -->
<familiar vocation="5" lookType="1367" name="Bladespark" premium="yes" unlocked="no" enabled="yes" type="quest" />
```

**Integração:**

Familiares são geralmente:
- Obtidos via quest ou shop
- Visíveis como pet/companheiro
- Oferem bônus ou apenas cosméticos
- Específicos por vocação/progression
