## 🛠️ Vocações (Classes)

Sistema de **10 vocações** com progressão base→avançada, 7 tipos de skills, gems especiais e fórmulas.

<Card title="Caminho Original" icon="document">
  `data/XML/vocations.xml`
</Card>

<Aside type="tip">
  4 vocações base (Sorcerer, Druid, Paladin, Knight) + 4 avançadas + 2 Monks. Cada uma com stats progressivos, skill multipliers e gems únicos.
</Aside>

## 📄 Visão Geral

Define vocações com:

- **10 total**: 4 base, 4 avançadas, 2 Monks
- **Progression**: Base → Avançada (evolution)
- **Stats**: HP, Mana, Capacidade, Soul por level
- **Skills**: 7 tipos (Fist, Sword, Club, Axe, Distance, Shield, Magic)
- **Gems**: Para vocações avançadas (Lesser/Normal/Greater)

## 🔧 Estrutura

### Vocation

```xml
<vocation id="1" name="Sorcerer" magicshield="1" 
    gaincap="10" gainhp="5" gainmana="30" soulmax="100">
    <formula ... />
    <mitigation ... />
    <skill id="0" multiplier="1.5" />
    <gem quality="0" name="lesser sage gem" />

```

</Card>

## 💡 Utilidade

Este arquivo define todas as vocações do servidor com suas características, taxas de ganho de HP/Mana/Capacidade, multiplicadores de skills, fórmulas de dano, mitigação e gems especiais. Cada vocação tem versão base e avançada com stats progressivos.

## 📄 Visão Geral do Código Resumo Executivo

O arquivo `vocations.xml` implementa o sistema de classes:

- **10 Vocações**: 4 bases + 4 avançadas + 2 Monks
- **Stats Progressivos**: HP, Mana, Capacidade, Soul por vocação
- **Multiplicadores de Skill**: 7 tipos (0-6, melee/distance/magic/fist)
- **Fórmulas de Dano**: Melee, distância, defesa, armor
- **Mitigação**: Proteção com multiplicadores shield
- **Gems Especiais**: Para vocações avançadas
- **Avatar Visual**: LookType do avatar da vocação

## 🔧 Estrutura de Funcionalidades

### Estrutura Geral

```xml
<vocations>
    <vocation id="..." clientid="..." baseid="..." name="..." ...>
        <formula ... />
        <mitigation ... />
        <pvp ... />
        <skill id="..." multiplier="..." />
        <gem quality="..." name="..." />
    </vocation>
</vocations>
```

### Elemento: Vocation

```xml
<vocation id="1" clientid="3" baseid="1" name="Sorcerer" description="a sorcerer" magicshield="1" 
    gaincap="10" gainhp="5" gainmana="30" gainhpticks="12000" gainhpamount="1" 
    gainmanaticks="3000" gainmanaamount="2" manamultiplier="1.1" attackspeed="2000" 
    basespeed="110" soulmax="100" gainsoulticks="120000" fromvoc="1" avatarlooktype="1595">
```

**Atributos Principais:**

| Atributo | Tipo | Descrição |
|----------|------|-----------|
| `id` | number | ID único vocação (0-10) |
| `clientid` | number | Client ID para seleção |
| `baseid` | number | ID da vocação base (para avançadas) |
| `name` | string | Nome humanizado |
| `description` | string | Descrição curta |
| `magicshield` | 0/1 | Pode usar magic shield? |
| `avatarlooktype` | number | Visual do avatar |

**Atributos de Ganho (por nível):**

| Atributo | Descrição |
|----------|-----------|
| `gaincap` | Capacidade por nível |
| `gainhp` | HP por nível |
| `gainhpticks` | MS entre regen HP |
| `gainhpamount` | HP por tick |
| `gainmana` | Mana por nível |
| `gainmanaticks` | MS entre regen Mana |
| `gainmanaamount` | Mana por tick |
| `manamultiplier` | Multiplicador de mana |
| `soulmax` | Máximo de soul points |
| `gainsoulticks` | MS entre ganho soul |
| `attackspeed` | Velocidade de ataque (ms) |
| `basespeed` | Velocidade base movimento |
| `fromvoc` | Vocação de evolução |

### Sub-Elemento: Formula

```xml
<formula meleeDamage="1.0" distDamage="1.0" defense="1.0" armor="1.0" />
```

**Atributos:**

| Atributo | Descrição |
|----------|-----------|
| `meleeDamage` | Multiplicador de dano melee |
| `distDamage` | Multiplicador de dano distância |
| `defense` | Multiplicador de defesa |
| `armor` | Multiplicador de armor |

Todos os valores aparecem como `1.0` (uniforme), sugerindo que a progressão é baseada em skills/equipment.

### Sub-Elemento: Mitigation

```xml
<mitigation multiplier="1.3" primaryShield="2.05" secondaryShield="1.25" />
```

**Atributos:**

| Atributo | Descrição |
|----------|-----------|
| `multiplier` | Redução de dano geral |
| `primaryShield` | Multiplicador de shield primário |
| `secondaryShield` | Multiplicador de shield secundário |

Varia por vocação (Knight mais alto, Sorcerer mais baixo).

### Sub-Elemento: PVP

```xml
<pvp damageReceivedMultiplier="1.0" damageDealtMultiplier="1.0"/>
```

**Atributos:**

| Atributo | Descrição |
|----------|-----------|
| `damageReceivedMultiplier` | Dano recebido em PVP |
| `damageDealtMultiplier` | Dano causado em PVP |

Todos parecem `1.0` (uniforme).

## 📋 Resumo de Implementação

**Progressão de Vocação:**

```
Seleção no cliente → Base (1-4) → Avançada (5-8 ou 10)
                   ↓              ↓
                  Level 1        Level ≥ Requisito
                  Level 1-X      Level X+
```

**Exemplo - Sorcerer:**

```
Vocation 1: Sorcerer
├─ Level 1-X: Stats bases
├─ Magic Shield: YET
├─ Skills: Espada/Clava/Machado (2.0), Fist (1.5), Magic (1.1)
└─ Gem: Nenhuma

    ↓ Ao atingir evolução (talvez level 20)

Vocation 5: Master Sorcerer
├─ Base do 1 com melhorias
├─ Soul Max: 200 (vs 100)
├─ Gem: Sage gems (Lesser/Normal/Greater)
└─ Avatar: Mesmo (1595)
```

**Tabela Comparativa - Base vs Avançada:**

| Stat | Sorcerer | Master Sorcerer |
|------|----------|-----------------|
| Soul Max | 100 | 200 |
| Gain Soul Ticks | 120000 ms | 15000 ms |
| Gain Mana Ticks | 3000 ms | 2000 ms |
| Gems | Nenhuma | 3 níveis |

**Integração de Stats:**

- **HP**: Ganho lento (5 por level), regen a cada 12s
- **Mana**: Ganho rápido (30 por level), regen a cada 3s
- **Capacidade**: +10 por level
- **Soul**: Ganho lento (cada 120s), mas base vocação
