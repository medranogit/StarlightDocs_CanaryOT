## 💡 Utilidade

Este arquivo define todas as aparências (outfits) que jogadores podem usar. Cada outfit tem tipo (feminino/masculino), client ID visual, nome, status premium/unlocked, e forma de obtenção (quest/store). Permite gerenciar cosmética completa do jogo.

## 📄 Visão Geral do Código Resumo Executivo

O arquivo `outfits.xml` implementa um catálogo de aparências:

- **200+ Outfits**: Grande variedade de estilos
- **2 Tipos Base**: 0 (Female), 1 (Male - inferido)
- **Status Cosmético**: Premium, unlock status, enabled
- **Origem Diversa**: Quest, Store, Padrão
- **Progressão**: Desde básicos até temáticos avançados
- **Organização**: Por era/tema/expansão

## 🔧 Estrutura de Funcionalidades

### Estrutura Geral

```xml
<outfits>
    <outfit type="0" looktype="..." name="..." premium="..." unlocked="..." enabled="..." from="..." />
</outfits>
```

### Elemento: Outfit

```xml
<outfit type="0" looktype="136" name="Citizen" premium="no" unlocked="yes" enabled="yes" />
```

**Atributos:**

| Atributo | Tipo | Descrição |
|----------|------|-----------|
| `type` | number | Tipo de aparência (0=female, 1=unknown) |
| `looktype` | number | Client ID do modelo visual |
| `name` | string | Nome humanizado |
| `premium` | yes/no | Requer premium account? |
| `unlocked` | yes/no | Começa desbloqueado? |
| `enabled` | yes/yes | Está habilitado/ativo? |
| `from` | quest/store (opcional) | Fonte de obtenção |

**Descrição:**
Cada elemento define uma aparência disponível no jogo.

### Tipos de Aparências

| Type | Descrição | Exemplos |
|------|-----------|----------|
| 0 | Female/Feminino | Citizen, Hunter, Mage, Noblewoman |
| 1+ | Male/Masculino (inferido) | Correspondentes masculinos |

### Progressão de Outfits

**Eras Históricas:**

1. **Earlies** (LookType 136-150): Básicos clássicos
2. **Classérmicos** (LookType 155-324): Temáticos clássicos
3. **Medianos** (LookType 329-520): Expansões médias
4. **Avançados** (LookType 520-800): Temáticos avançados
5. **Modernos** (LookType 800+): Últimos lançamentos

**Examplos de Progressão:**

- Retro Citizen/Hunter/Mage/Knight (963-975): Reskins antigos
- Herbalist/Sun Priest (1020-1024): Religiosos
- Crystal Warlord/Soil Guardian (513-514): Elementais
- Void Master/Evoker/Seaweaver (1203, 724, 732): Especializados

### Desbloqueamento

**Unlocked = yes:**
- Disponível desde criação
- Bases (Citizen, Hunter, etc)
- Alguns especiais

**Unlocked = no:**
- Requer obtenção (quest/store)
- Maioria dos outfits de level alto
- Quest-only ou store-only

### Padrão de Nomenclatura

**Por Tema:**
- Classe-based: Citizen, Hunter, Mage, Knight
- Profissional: Entrepreneur, Ranger, Alchemist
- Temático: Pirate, Assassin, Shaman, Demon
- Elemental: Crystal Warlord, Soil Guardian, Evoker
- Ocupacional: Herbalist, Sun Priest, Baker
- Especial: Nightmare, Jester, Anniversary

## 📋 Resumo de Implementação

**Contagem Total:**
- Total de Outfits: 130+ (feminino)

- Quest-locked: ~50-60
- Store-only: ~50-70

- Premium no: 1 (Newly Wed)

Store:
- Premium yes: Vários
- Premium no: ~40+

**Padrão de Estrutura:**

```xml
<!-- Base outfit (sempre desbloqueado) -->
<outfit type="0" looktype="136" name="Citizen" premium="no" unlocked="yes" enabled="yes" />

<!-- Quest outfit (desbloqueável) -->
<outfit type="0" looktype="155" name="Pirate" premium="yes" unlocked="no" enabled="yes" from="quest" />

<!-- Store outfit (disponível) -->
<outfit type="0" looktype="471" name="Entrepreneur" premium="no" unlocked="no" enabled="yes" from="store" />
```

**Cronologia (por looktype):**

1. **136-150** (7): Outfits clássicos base
2. **155-288** (34): Temáticos clássicos
3. **324-520** (30): Mix expansão
4. **575-758** (50): Temáticos avançados
5. **800-1293** (60+): Modernos recentes

**Exemplo de Progressão de Personagem:**

```
Criação: Cidadão (136) + Hunter (137) + Mage (138) + Knight (139)
         ↓ Premium adquirido

        ↓ Quests completadas
```
