## 💡 Utilidade

Este arquivo define a hierarquia de grupos (player, tutor, senior tutor, gamemaster, community manager, god) e suas permissões através de flags booleanas. Controla acesso a comandos, poderes especiais, e restrições em combate/integrações.

## 📄 Visão Geral do Código Resumo Executivo

O arquivo `groups.xml` implementa um sistema hierárquico de permissões:

- **6 Grupos Principais**: De Player até God
- **Flags Granulares**: 40+ permissões específicas
- **Progressão**: Cada grupo tem mais poderes que anterior
- **Combate/Magic**: Flags de controle para restrições
- **Admin Powers**: God tem acesso total

## 🔧 Estrutura de Funcionalidades

### Estrutura Geral

```xml
<groups>
    <group id="1" name="player" access="0" maxdepotitems="0" maxvipentries="0">
        <!-- Flags específicas do grupo -->
    </group>
</groups>
```

### Elemento: Group

```xml
<group id="1" name="player" access="0" maxdepotitems="0" maxvipentries="0" />
```

**Atributos:**

| Atributo | Tipo | Descrição |
|----------|------|-----------|
| `id` | number | ID único do grupo |
| `name` | string | Nome do grupo (display) |
| `access` | number | Nível de acesso (0=normal, 1=admin) |
| `maxdepotitems` | number | Limite de items no banco depot |
| `maxvipentries` | number | Limite de VIP entries |

### Hierarquia de Grupos

| ID | Nome | Access | Descrição |
|----|------|--------|-----------|
| 1 | player | 0 | Jogador normal |

| 3 | senior tutor | 0 | Tutor sênior |
| 4 | gamemaster | 1 | Game Master (admin) |
| 5 | community manager | 1 | Gerente comunitário |
| 6 | god | 1 | God level (acesso total) |

### Sub-Elemento: Flags

Cada grupo pode ter múltiplas flags que definem permissões:

```xml
<flags>
    <flag talkorangehelpchannel="1" />
    <flag cannotbemuted="1" />
    <flag cannotusecombat="1" />
    <!-- ... mais 40+ flags ... -->
</flags>
```

### Flags Principais (40+)

**Combate:**
- `cannotusecombat`: Não pode usar combate
- `cannotattackplayer`: Não pode atacar jogadores
- `cannotattackmonster`: Não pode atacar monstros
- `cannotbeattacked`: Não pode ser atacado

**Habilidades:**
- `canconvinceall`: Pode convidar qualquer criatura
- `cansummonall`: Pode convocar qualquer criatura
- `canillusionall`: Pode iludir qualquer criatura
- `cansenseinvisibility`: Detecta invisibilidade
- `ignoredbymonsters`: Monstros ignoram
- `ignoredbynpcs`: NPCs ignoram

**Mana/Saúde:**
- `hasinfinitemana`: Mana infinita
- `hasinfinitesoul`: Soul infinita
- `hasnoexhaustion`: Sem cooldown
- `hasinfinitecapacity`: Capacidade infinita

**Abilities:**
- `cannotusespells`: Não pode usar spells
- `cannotpickupitem`: Não pode pegar itens
- `canalwayslogin`: Sempre pode logar
- `canbroadcast`: Pode fazer broadcast
- `canedithouses`: Pode editar casas
- `cannotbebanned`: Não pode ser banido
- `cannotbepushed`: Não pode ser empurrado

**Chat:**
- `cantalkredprivate`: Pode falar em red private
- `cantalkredchannel`: Pode falar em red channel
- `talkorangehelpchannel`: Pode falar em orange help
- `cantalkredchannelanonymous`: Pode falar red anonym
- `cannotbemuted`: Não pode ser mutado

**Experiência/Drops:**
- `notgainexperience`: Não ganha experiência
- `notgainmana`: Não ganha mana
- `notgainhealth`: Não ganha saúde
- `notgainskill`: Não ganha skill
- `notgenerateloot`: Não gera loot

**Velocidade/Especial:**
- `setmaxspeed`: Velocidade máxima
- `specialvip`: VIP especial
- `notgaininfight`: Não ganha em combate
- `isalwayspremium`: Sempre premium
- `ignoreprotectionzone`: Ignora PZ
- `ignorespellcheck`: Ignora check de spell
- `ignoreweaponcheck`: Ignora check de weapon
- `canmapclickteleport`: Teleporte por clique
- `canpushallcreatures`: Pode empurrar tudo

## 📋 Resumo de Implementação

**Estrutura Padrão:**

```xml
<group id="..." name="..." access="..." maxdepotitems="..." maxvipentries="...">
    <flags>
        <flag flagname="0/1" />
        <!-- Múltiplas flags -->
    </flags>
</group>
```

**Características por Nível:**

**Player (Normal):**
- Sem flags especiais
- Comportamento padrão
- Sujeito a todas as restrições

**Tutor (Helper):**
- `talkorangehelpchannel`: Ajudar em canal
- `cannotbemuted`: Não pode ser silenciado
- Não pode combater

**Senior Tutor:**
- Tudo do Tutor +
- `cantalkredprivate`: Comunicação vermelha privada
- `cantalkredchannel`: Comunicação vermelha em canal

**GameMaster (Admin):**
- Access = 1 (admin)
- Combat desabilitado
- Ignorado por criaturas
- Pode editar casas
- Broadcast permitido
- Não ganha experiência/mana/saúde/skill

**Community Manager (Admin):**
- Access = 1 (admin)
- Combat habilitado (contra monstros)
- Pode convidar/convocar criaturas
- Infinite mana/soul/capacity
- Pode editar casas
- Anonymous red talk

**God (Super Admin):**
- Access = 1 (admin)
- Acesso total a tudo
- Combat contra monstros permitido
- Pode atacar/convocar/iludir tudo
- Velocidade máxima sempre
- Teleporte por clique
- Map click teleport
