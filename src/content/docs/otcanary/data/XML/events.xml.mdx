## 🛠️ Eventos do Servidor

Sistema de **eventos temporários** com datas, taxas customizadas de experiência/loot/skill e configurações visuais.

<Card title="Caminho Original" icon="document">
  `data/XML/events.xml`
</Card>

<Aside type="tip">
  Permite criar eventos temáticos com boosts múltiplos. Útil para celebrações, dobradores de EXP/Loot e ciclos sazonais.
</Aside>

## 📄 Visão Geral

Define eventos com:

- **Período**: Data início/fim (formato MM/DD/YYYY)
- **Taxas**: EXP, Loot, Boss Loot, Spawn, Skill (100 = normal)
- **Descrição**: Texto para UI
- **Cores**: Tema visual (dark/light hex)
- **Prioridades**: Display, sazonal, especial

## 🔧 Estrutura

### Evento

```xml
<event name="Otservbr example 1" startdate="11/03/2020" enddate="12/30/2023" script="example.lua">
    <ingame exprate="100" lootrate="100" bosslootrate="100" spawnrate="100" skillrate="100" />
    <description description="Otserver br example 1 description..." />
    <colors colordark="#235c00" colorlight="#2d7400" />
    <details displaypriority="6" isseasonal="0" specialevent="0" />
</event>
```

<Card title="Atributos Principais" icon="parameters">

| Atributo | Tipo | Descrição |
|----------|------|-----------|
| `name` | string | Nome do evento |
| `startdate` | MM/DD/YYYY | Início |
| `enddate` | MM/DD/YYYY | Fim |
| `script` | string | Script Lua (opcional) |

**Ingame (sub-elemento):**
- `exprate`, `lootrate`, `bosslootrate`, `spawnrate`, `skillrate` (100 = 1x)

**Cores (sub-elemento):**
- `colordark`, `colorlight` (hex RGB)

**Details (sub-elemento):**
- `displaypriority` (maior = mais visível)
- `isseasonal` (0/1)
- `specialevent` (0/1)
</Card>
