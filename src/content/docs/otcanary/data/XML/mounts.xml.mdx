## 💡 Utilidade

Este arquivo define todas as montarias disponíveis no servidor. Cada montaria tem ID único, client ID visual, nome, velocidade, requisitos (premium/quest/store). Permite gerenciar quais criaturas podem ser montadas e como obtê-las.

## 📄 Visão Geral do Código Resumo Executivo

O arquivo `mounts.xml` implementa um catálogo de montarias:

- **99+ Montarias**: Desde animais clássicos até criaturas fantásticas
- **3 Categorias de Obtenção**: Quest, Store, Standard
- **Status Premium**: Varia por montaria
- **Velocidade Fixa**: Todas velocidade ~10
- **Visual System**: Client ID para modelo 3D
- **Organização**: Agrupadas por tipo/tema

## 🔧 Estrutura de Funcionalidades

### Estrutura Geral

```xml
<mounts>
    <mount id="..." clientid="..." name="..." speed="..." premium="..." type="..." />
</mounts>
```

### Elemento: Mount

```xml
<mount id="1" clientid="368" name="Widow Queen" speed="10" premium="yes" type="quest" />
```

**Atributos:**

| Atributo | Tipo | Descrição |
|----------|------|-----------|
| `id` | number | ID único interno |
| `clientid` | number | Client ID para modelo 3D |
| `name` | string | Nome da montaria |
| `speed` | number | Velocidade de movimento |
| `premium` | yes/no | Requer premium account? |
| `type` | string | Tipo de obtenção (quest/store) |

**Descrição:**
Cada elemento define uma montaria disponível no jogo.

### Tipos de Obtenção

| Tipo | Descrição | Exemplos |
|------|-----------|----------|
| quest | Obtida via missão/quest | Widow Queen, Racing Bird, War Bear |
| store | Obtida via loja em-jogo | Crimson Ray, Steelbeak, Shadow Hart |
| (vazio) | Padrão/permanente | Alguns clássicos |

## 📋 Resumo de Implementação

**Contagem Total:**
- Total de Mounts: 98 (conforme último ID visto)
- Quest mounts: ~50 (maioria)
- Store mounts: ~48

**Distribuição Premium:**

**Quest (Aprox 50):**
- Premium yes: ~45
- Premium no: ~5 (Rented Horse, Newly Wed, algumas adicionais)

**Store (Aprox 48):**
- Premium yes: ~5-10
- Premium no: ~38-43

**Padrão de Estrutura:**

```xml
<mount id="1" clientid="368" name="Animal Name" speed="10" premium="yes" type="quest" />
<mount id="23" clientid="426" name="Store Mount" speed="10" premium="no" type="store" />
```

**Cronologia (por range de clientid):**

1. **Era Clássica** (clientid 368-406): Animais e criaturas básicas
2. **Expansão 1** (clientid 421-548): Especiais e temáticas
3. **Expansão 2** (clientid 559-649): Mounts avançados
4. **Expansão 3** (clientid 669-763): Voadores e criaturas fantásticas
5. **Expansão Recente** (clientid 848+): Últimos lançamentos

**Exemplo de Progression:**

Novo jogador → Rented Horse (ID 22, non-premium)
Quester → War Bear/Draptor (ID 3,6 - quest)
Premium → Qualquer mount premium quest
Comprador → Store mounts (Crimson Ray, Magic Carpet, etc)
