## 📄 Visão Geral do Código

**Resumo Executivo**

O arquivo `events.json` é um repositório de eventos periódicos que modificam a experiência de gameplay durante períodos específicos do ano. Contém 10 eventos com ativação automática baseada em datas, cada um aplicando multiplicadores únicos para experiência, loot, spawn, forge, ou bestiário. O servidor verifica automaticamente datas na inicialização e aplica multiplicadores configurados para eventos ativos.

**Estrutura Fundamental**

```
{
  "events": [
    Event 1: Forge Time (20% forge bonus),
    Event 2: Double Bestiary,
    Event 3: Fast Exercise (2x speed),
    Event 4: 50% Loot Bonus,
    Event 5: 50% Exp Bonus,
    Event 6: Boss Cooldown Reduction,
    Event 7: Double Exp,
    Event 8: Double Loot,
    Event 9: Double Bosstiary,
    Event 10: Fast Respawn (2x spawn)
  ]
}
```

## Atributos Padrão

### Identificação

| Campo | Tipo | Obrigatório | Exemplo |
|-------|------|------------|---------|
| name | string | Sim | "Double Exp" |
| startdate | date | Sim | "11/12/2024" |
| enddate | date | Sim | "11/17/2024" |

### In-Game Multipliers

| Field | Type | Default | Valid Range |
|-------|------|---------|------------|
| exprate | int | 100 | 1-999 |
| lootrate | int | 100 | 1-999 |
| bosslootrate | int | 100 | 1-999 |
| spawnrate | int | 100 | 1-999 |
| skillrate | int | 100 | 1-999 |
| forgechance | int | 100 | 1-999 |
| bosscooldown | int | 100 | 1-999 |

### Boolean Multipliers

| Field | Default | Effect |
|-------|---------|--------|
| doublebestiary | false | 2x bestiary counter |
| doublebosstiary | false | 2x boss bestiary |
| fastexercise | false | 2x exercise speed |

### Visual Configuration

```json
"colors": {
  "colordark": "#002d00",
  "colorlight": "#004400"
}
```

- **colordark**: Hex color para exibição escura
- **colorlight**: Hex color para exibição clara

### Metadata Details

```json
"details": {
  "displaypriority": 6,
  "isseasonal": 1,
  "specialevent": 1
}
```

| Field | Type | Meaning |
|-------|------|---------|
| displaypriority | int | Ordem de exibição (1-10) |
| isseasonal | bool | Evento sazonal (anual) |
| specialevent | bool | Evento especial/temporário |

## Checkpoint de Aprendizagem

**Conceitos-chave:**
1. JSON array de 10+ eventos com datas ativação automática
2. Multiplicadores em percentual (100=normal, 200=dobro)
3. Boolean modifiers para features especiais (bestiary, forge)
4. Eventos sazonais vs especiais (displaypriority)
5. Cores Hex para visual customizado no cliente

**Responsabilidades:**
1. Manter eventos com datas corretas (mm/dd/yyyy)
2. Configurar multiplicadores apropriados (1-999 range)
3. Agrupar eventos relacionados em mesmas datas
4. Definir prioridade de exibição (1-10)
5. Sincronizar com scripts Lua opcionais (se aplicável)
