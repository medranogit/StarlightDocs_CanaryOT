## 📋 Todos os Handlers (8 total)

### 1. World Chat - Channel 3

[world_chat.lua](world_chat.lua)

**Tipo**: Public Channel  
**Acesso**: Open (level 1 blocked, except GMs)  
**Comandos**: Nenhum  
**Funções**: onSpeak (validação level + type conversion)

```lua
Bloqueado: Level 1 non-GMs
Permitido: Level 2+ or GMs
Orange: GMs apenas
```

## 🔐 Access Hierarchy

```
ACCOUNT_TYPE_GOD (99)
    ← Gamemaster channel orange
    
ACCOUNT_TYPE_GAMEMASTER (3)
    ← Gamemaster channel access
    ← Can use orange in world/help
    ← Can use red channel
    
GROUP_TYPE_GAMEMASTER
    ← Tutor promote to orange
    
GROUP_TYPE_SENIORTUTOR (2)
    ← Tutor orange access
    ← Staff in guild_leaders
    
GROUP_TYPE_TUTOR (1)
    ← Tutor channel access
    ← Help moderator (!mute)
    
Players (0)
    ← Level 20/Premium: english_chat
    ← !VOCATION_NONE L20: advertising
    ← VOCATION_NONE: advertising_rook
    ← Open: world_chat (level 2+)
    ← Open: help (level 2+)
```
