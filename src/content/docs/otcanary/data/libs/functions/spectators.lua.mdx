## 🛠️ Informações do Arquivo

Módulo que implementa **spectator detection system** para áreas.

Constructor Spectators() que cria instância com as seguintes configurações:
- only_player (true)
- multi_floor (false)
- blacklist_pos (posições excluídas)
- creature_detect (cache de criaturas detectadas)
- remove_destination (teleporte customizado)
- check_position (área a scannear com from e to)

Integra Game.getSpectators() para detecção, convertPosToRange/convertPos para processamento de posição, blacklist validation, e remoção automática de monstros/players.

**Caminho Original**: `data/libs/functions/spectators.lua`

<Aside type="caution">
**DEPRECATED**: Este módulo está marcado como deprecated. **Use Zone ao invés**. Spectators é legado mantido por compatibilidade mas Zone oferece API mais moderna. Use apenas para código legado.
</Aside>

<Aside type="tip">
O arquivo `spectators.lua` oferece **legacy spectator detection** para áreas retangulares. Permite filtrar por tipo de criatura (players/todos), piso único/múltiplo, excluir posições via blacklist, remover automaticamente monstros/players com teleportação. Útil para arenas, eventos, detecção dinâmica de criaturas em zona.
</Aside>

## 📄 Visão Geral do Código

### Resumo Executivo

Arquivo com **3 layers de funcionalidade**:

1. **Configuration**: only_player, multi_floor, blacklist_pos, remove_destination
2. **Position Management**: setCheckPosition (area `{from, to}`), convertPosToRange, convertPos (center)
3. **Detection & Removal**: check() para detectar criaturas via Game.getSpectators(), removeMonsters/removePlayers para cleanup

O design usa **Game.getSpectators() wrapper** que captura criaturas em área, **position-based filtering** com exclusões de blacklist, e **automatic creature removal** com fallback a temple.

## 🏗️ Constructor

### `Spectators()` → spectator instance

Cria nova Spectators instance via metatable __call.

**Tipo**: Constructor function (via metatable)  
**Retorna**: Spectators instance (metatable com __index = Spectators)

**Implementação**:
```lua
setmetatable(Spectators, {
	__call = function(self)
		local spectators_data = {
			only_player = true,
			multi_floor = false,
			blacklist_pos = {},
			creature_detect = {},
		}
		return setmetatable(spectators_data, { __index = Spectators })
	end,
})
```

**Estrutura Criada**:
- `only_player`: true (filtra para players apenas)
- `multi_floor`: false (scanneia piso único)
- `blacklist_pos`: {} (posições excluídas)
- `creature_detect`: {} (cache de criaturas detectadas)

**Uso**:
```lua
local spec = Spectators()
```

## 📐 Conversão de Posição

### `Spectators:convertPosToRange()` → table

Calcula range (metade da distância de cada axis).

**Tipo**: Method  
**Retorna**: `{x: number, y: number, z: number}`

**Implementação**:
```lua
function Spectators.convertPosToRange(self)
	local pos = self:getCheckPosition()
	return {
		x = (pos.to.x - pos.from.x) / 2,
		y = (pos.to.y - pos.from.y) / 2,
		z = pos.from.z,
	}
end
```

**Exemplo**:
Se area é `{from: (100,100,7), to: (150,150,7)}`:
- x = (150-100)/2 = 25
- y = (150-100)/2 = 25
- z = 7

---

### `Spectators:convertPos()` → Position

Calcula Position central da área.

**Tipo**: Method  
**Retorna**: Position (center de check_position)

**Implementação**:
```lua
function Spectators.convertPos(self)
	local pos = self:getCheckPosition()
	local range = self:convertPosToRange()
	return Position(pos.from.x + range.x, pos.from.y + range.y, range.z)
end
```

**Exemplo**:
If area é `{from: (100,100,7), to: (150,150,7)}`:
- center = Position(100+25, 100+25, 7) = Position(125, 125, 7)

### `Spectators:checkCreatureBlacklistPos(creature)` → boolean

Verifica se criatura está em posição bloqueada.

**Tipo**: Method  
**Parâmetros**: `creature` (Creature)  
**Retorna**: boolean (true se em blacklist)

**Implementação**:
```lua
function Spectators.checkCreatureBlacklistPos(self, creature)
	local creature_pos = creature:getPosition()
	for _, v in pairs(self:getBlacklistPos()) do
		if creature_pos.x >= v.from.x and creature_pos.x <= v.to.x then
			if creature_pos.y >= v.from.y and creature_pos.y <= v.to.y then
				return true
			end
		end
	end
	return false
end
```

**Fluxo**:
1. Obter posição da criatura
2. Loop cada blacklist range
3. Verificar se X está dentro range.x: [from.x, to.x]
4. Verificar se Y está dentro range.y: [from.y, to.y]
5. Se ambas: return true (em blacklist)

## 🔍 Detecção

### `Spectators:check(pos)` → creatures[]

Detecta criaturas em área via Game.getSpectators().

**Tipo**: Method  
**Parâmetros**: `pos` (table `{from, to}`|nil): Opcionalmente setá novo check_position  
**Retorna**: creatures[] (array de Creatures detectadas)

**Implementação**:
```lua
function Spectators.check(self, pos)
	if pos ~= nil then
		self:setCheckPosition(pos)
	end
	local range = self:convertPosToRange()
	pos = self:convertPos()
	local specs = Game.getSpectators(pos, self:getMultiFloor(), self:getOnlyPlayer(), range.x, range.x, range.y, range.y)
	self:setCreatureDetect(specs)
	return specs
end
```

**Fluxo**:
1. Setá check_position se fornecido
2. Calcula range via convertPosToRange()
3. Calcula center via convertPos()
4. Chama Game.getSpectators(center, multiFloor, onlyPlayers, rangeX, rangeX, rangeY, rangeY)
5. Seta creature_detect cache
6. Retorna spectators

**Assinatura Game.getSpectators**:
```
Game.getSpectators(pos, multiFloor, onlyPlayers, rangeX_min, rangeX_max, rangeY_min, rangeY_max)
```

**Exemplo**:
```lua
local spec = Spectators()
spec:setOnlyPlayer(true)
local creatures = spec:check({
	from = Position(100, 100, 7),
	to = Position(150, 150, 7)
})
print("Detected: " .. (#creatures or 0))
```

## 🗑️ Remoção de Criaturas

### `Spectators:removeMonsters()` → void

Remove todos monstros detectados.

**Tipo**: Method  
**Retorna**: Nenhum

**Implementação**:
```lua
function Spectators.removeMonsters(self)
	if self:getCreatureDetect() then
		for _, v in pairs(self:getCreatureDetect()) do
			if v:isMonster() then
				v:remove()
			end
		end
	end
end
```

**Fluxo**:
1. Loop creature_detect cache
2. Checar se :isMonster()
3. Se verdadeiro: chamar v:remove()

---

### `Spectators:removePlayer(player)` → void

Remove um player (teleporta para remove_destination ou temple).

**Tipo**: Method  
**Parâmetros**: `player` (Player)  
**Retorna**: Nenhum

**Implementação**:
```lua
function Spectators.removePlayer(self, player)
	if player then
		if player:isPlayer() then
			local destination = self:getRemoveDestination()
			if destination then
				player:teleportTo(destination)
			else
				player:teleportTo(player:getTown():getTemplePosition())
				player:remove()
			end
		end
	end
end
```

**Fluxo**:
1. Validar que é Player
2. Se remove_destination setado: teleportar para destination
3. Se não: teleportar para temple + remove()

**Comportamento**: Com destination = apenas teleportação. Sem destination = teleportação + remove (logout)

---

### `Spectators:removePlayers(players)` → void

Remove múltiplos players.

**Tipo**: Method  
**Parâmetros**: `players` (table de Players|nil): Se nil, usa creature_detect cache  
**Retorna**: Nenhum

**Implementação**:
```lua
function Spectators.removePlayers(self, players)
	local creature_remove = players or self:getCreatureDetect()
	for _, v in pairs(creature_remove) do
		self:removePlayer(v)
	end
end
```

**Fluxo**:
1. Usar players parameter ou creature_detect cache
2. Loop cada criatura
3. Chamar removePlayer(v)

## 📈 Utilities

### `Spectators:getPlayers()` → number

Conta quantos players foram detectados.

**Tipo**: Method  
**Retorna**: number (count de players)

**Implementação**:
```lua
function Spectators.getPlayers(self)
	local count = 0
	if not self:getCreatureDetect() then
		error("Not creature detect")
		return nil
	end
	for _, v in pairs(self:getCreatureDetect()) do
		if v:isPlayer() then
			count = count + 1
		end
	end
	return count
end
```

**Fluxo**:
1. Validar creature_detect não nil
2. Loop, contar se :isPlayer()
3. Retornar count

**Erro**: Se creature_detect nil → error (precisa chamar check() antes)
