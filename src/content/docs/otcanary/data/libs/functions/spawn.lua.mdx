## 🛠️ Informações do Arquivo

Módulo que implementa **complete spawn system para monstros**: constructor Spawn() que cria instância com storage-based respawn tracking, positions array (monster name + position + spawntime), monsters registry com UIDs, event callbacks (onSpawn para registro, onDeath para respawn), spawnMonsterTimer com contagem regressiva + efeitos visuais (3x CONST_ME_TELEPORT), removeSpawn para desabilitar spawn, checkMonstersUID para validar UIDs ativos vs inativo. Centraliza lógica de spawn em uma classe reutilizável.

**Caminho Original**: `data/libs/functions/spawn.lua`

<Aside type="tip">

## 📄 Visão Geral do Código

### Resumo Executivo

Arquivo com **4 layers de funcionalidade**:

1. **Spawn Instance Creation**: Constructor via __call que cria spawn_data com storage/monsters/positions
2. **Position Management**: Gerenciar lista de posições (monster name, posição, spawntime)
3. **Monster Registry**: Adicionar/remover/buscar monstros por UID
4. **Spawn Execution**: Despawnar monstros com timers, callbacks de evento, respawn automático

O design usa **storage-based respawn** (monstro guarda index de posição em storage), **event callback system** (onSpawn → registra monsterDeath, onDeath → respawn), **timer-based spawning** com visual effects, e **UID validation** para limpeza de referencias mortas.

## 🌍 Variáveis Globais

### `MonsterStorage`

Constantes de storage IDs para respawn tracking.

**Tipo**: Tabela global  
**Estrutura**:
```lua
MonsterStorage = {
	Spawn = {
		info = 550000,                    -- Storage para monstro index
		monster_spawn_object = 550001,    -- Storage para spawn object ref
	},
}
```

**Uso**:
- `info (550000)`: Monstro armazena seu spawn index aqui (para respawn)
- `monster_spawn_object (550001)`: Monstro armazena spawn object ref (para death callback)

## 🏗️ Constructor

### `Spawn()` → spawn instance

Cria novo Spawn instance via metatable __call.

**Tipo**: Constructor function (via metatable)  
**Retorna**: Spawn instance (metatable com __index = Spawn)

**Implementação**:
```lua
setmetatable(Spawn, {
	__call = function(self)
		local spawn_data = {
			storage = {
				info = MonsterStorage.Spawn.info,
				object = MonsterStorage.Spawn.monster_spawn_object,
			},
			monsters = {},
			positions = {},
			functions = {
				["onSpawn"] = {
					["MonsterDeath"] = function(s, monster)
						monster:setStorageValue(s.storage.object, s)
						monster:registerEvent("monsterDeath")
					end,
				},
				["onDeath"] = {
					["Respawn"] = function(s, monster)
						if monster:getStorageValue(s.storage.info) > 0 then
							s:spawnMonsterIndex(monster:getStorageValue(s.storage.info))
						end
					end,
				},
			},
		}
		local mt = setmetatable(spawn_data, { __index = Spawn })
		table.insert(SpawnMetatables, mt)
		return mt
	end,
})
```

**Estrutura Criada**:
- `storage.info`: 550000 (storage key para monstro armazenar index)
- `storage.object`: 550001 (storage key para spawn reference)
- `monsters`: Array vazio para UIDs de monstros
- `positions`: Array vazio para spawn configs
- `functions.onSpawn.MonsterDeath`: Callback registra monsterDeath event
- `functions.onDeath.Respawn`: Callback respawna monstro se index válido

**Fluxo**:
1. Cria spawn_data com estrutura completa
2. setmetatable com __index = Spawn (acesso aos métodos)
3. Insere em SpawnMetatables global
4. Retorna instância pronta

**Uso**:
```lua
local mySpawn = Spawn()
```

### `Spawn:getMonster(uid)` → index

Busca índice de monstro na lista.

**Tipo**: Method  
**Parâmetros**: `uid` (creature UID)  
**Retorna**: index (number) ou 0 (não encontrado)

**Implementação**:
```lua
function Spawn.getMonster(self, uid)
	for i, v in pairs(self:getMonsters()) do
		if v == uid then
			return i
		end
	end
	return 0
end
```

## 🎯 Motor de Spawn

### `Spawn:spawnMonsterTimer(config, func)` → void

Cria timer de spawn com contador visual e efeitos.

**Tipo**: Method  
**Parâmetros**:
- `config` (table): `{spawntime, monster, pos}`
- `func` (function|nil): Callback pós-spawn

**Retorna**: Nenhum (usa addEvent)

**Implementação**:
```lua
function Spawn.spawnMonsterTimer(self, config, func)
	local time_tp = 3  -- 3 segundos visual countdown
	config.spawntime = config.spawntime <= time_tp and (time_tp + 1) or (config.spawntime - time_tp)
	addEvent(function()
		-- 3 loops de efeito
		for i = 1, time_tp do
			addEvent(function()
				config.pos:sendMagicEffect(CONST_ME_TELEPORT)
			end, i * 1000)
		end
		-- Spawn monstro após efeitos
		addEvent(function()
			local monster = Game.createMonster(config.monster, config.pos, false, false)
			if not monster then
				logger.error("[Spawn] Error on spawn monster: {}", config.monster)
				return false
			end
			if func ~= nil and func ~= false then
				func(monster)
			end
			self:executeFunctionMonster("onSpawn", monster)
		end, time_tp * 1000)
	end, config.spawntime * 1000)
end
```

**Fluxo**:
1. Calcula tempo real: se menor ou igual a 3s, set 4s; senão subtract 3s (para efeitos)
2. Espera config.spawntime
3. Envia 3x CONST_ME_TELEPORT (1s apart)
4. Cria monstro Game.createMonster
5. Executa func(monster) se fornecido
6. Executa onSpawn callbacks

**Timing Example**:
- Config spawntime: 60s
- Efetivo wait: 57s (60-3)
- Visual effects: 3s antes do spawn (nos últimos 3s do timer)
- Total real: 60s (57 + 3 efeitos)

### `Spawn:spawnMonsterIndex(index)` → void

Spawna monstro em posição específica (via index no array).

**Tipo**: Method  
**Parâmetros**: `index` (number: índice em self.positions)  
**Retorna**: Nenhum

**Implementação**:
```lua
function Spawn.spawnMonsterIndex(self, index)
	local table = self:getPositions()
	table = table[index]
	if table ~= nil and table.status == true then
		local config = {
			spawntime = table.spawntime,
			monster = table.monster,
			pos = table.pos,
		}
		local func = function(s, monster)
			monster:setStorageValue(s.storage.info, index)
			s:addMonster(monster)
		end
		self:addFunctionMonster("onSpawn", func, "MonsterIndex")
		self:spawnMonsterTimer(config)
	else
		logger.error("[Spawn.spawnMonsterIndex] - Table is nil")
	end
end
```

**Fluxo**:
1. Lookup position by index
2. Validar status == true
3. Criar config `{spawntime, monster, pos}`
4. Criar callback que seta storage.info = index + addMonster
5. Adicionar callback a onSpawn
6. Chamar spawnMonsterTimer

**Storage Setting**: Monstro armazena index em storage.info para respawn tracking

### `Spawn:executeSpawn()` → boolean

Spawna todos os monstros (itera positions).

**Tipo**: Method  
**Retorna**: boolean (sucesso)

**Implementação**:
```lua
function Spawn.executeSpawn(self)
	local pos = self:getPositions()
	if not pos then
		error("Not set pos")
		return false
	end
	for i, v in pairs(pos) do
		self:spawnMonsterIndex(i)
	end
end
```

**Fluxo**:
1. Validar positions não nil
2. Loop cada posição
3. Chamar spawnMonsterIndex(i) para cada

## 🛑 Controle de Spawn

### `Spawn:removeSpawn()` → boolean

Desabilita spawn (set status = false).

**Tipo**: Method  
**Retorna**: boolean (sucesso)

**Implementação**:
```lua
function Spawn.removeSpawn(self)
	local pos = self:getPositions()
	if not pos then
		error("Not set pos")
		return false
	end
	for i, v in pairs(pos) do
		v.status = false
	end
end
```

**Efeito**: Novos spawns não ocorrem (status = false previne spawnMonsterIndex)

### `Spawn:checkMonstersUID()` → table

Valida UUIDs (limpa mortos, retorna estatísticas).

**Tipo**: Method  
**Retorna**: `{active: number, inactive: number}`

**Implementação**:
```lua
function Spawn.checkMonstersUID(self)
	local monsters = self:getMonsters()
	local statistics = {
		active = 0,
		inactive = 0,
	}
	for i, v in pairs(monsters) do
		if v ~= nil and v:isMonster() then
			statistics.active = statistics.active + 1
		else
			self:deleteMonster(v)
			statistics.inactive = statistics.inactive + 1
		end
	end
	return statistics
end
```

**Fluxo**:
1. Loop cada monstro em self.monsters
2. Validar v:isMonster() (vivo)
3. Se vivo: active++
4. Se morto: deleteMonster + inactive++
5. Retornar estatísticas

## ✅ Checkpoint de Aprendizagem

### Conceitos Principais

| Conceito | Descrição | Implementação |
|----------|-----------|---------------|
| **Storage-Based Respawn** | Monstro armazena spawn index em storage | monster:setStorageValue(storage.info, index) |
| **Event Callback Chain** | onSpawn → register death, onDeath → respawn | functions.onSpawn, .onDeath |
| **Timer-Based Spawn** | Countdown antes de spawn com efeitos | spawnMonsterTimer com addEvent |
| **Visual Feedback** | 3x CONST_ME_TELEPORT antes do spawn | Efeitos 1s apart |
| **UID Validation** | Limpa references mortas | checkMonstersUID |
| **Position Array** | Multi-spawn com independent timers | positions[] array |
| **Status Control** | Enable/disable spawn via flag | positions[i].status |
| **Metatable Constructor** | Spawn() via __call | __call em Spawn metatable |

### Padrões Identificados

1. **Position-Based Spawning**: Array de posições com timeout independente
2. **Event-Driven System**: onSpawn/onDeath callbacks para behavior customization
3. **Timer-Based Execution**: addEvent para spawn scheduling com visual effects
4. **Storage-Based State**: Monstro armazena index para respawn automation
5. **Array-Based Registry**: monsters[] para UID tracking
6. **Status-Based Control**: Flag enable/disable sem remover config
7. **Metatable Factory**: Constructor via __call para Spawn instances

### Responsabilidades by Category

- **Position Management**: Define/get spawn locations com spawntime
- **Monster Registry**: Track UIDs vivos, cleanup mortos
- **Event System**: onSpawn/onDeath callbacks para customization
- **Spawn Engine**: Timer logic, monster creation, effect timing
- **Spawn Control**: Start/stop spawning, validate health
