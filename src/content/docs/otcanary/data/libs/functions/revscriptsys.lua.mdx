## 🛠️ Informações do Arquivo

Módulo que implementa **revscript system infrastructure**: hooks de metatable em classes Tibian core para adicionar convenience methods, automatic getters/setters (createFunctions helper), __index customization para shortcuts (uid=getId, type=creatureType), e __newindex handlers que automaticamente registram callback functions em diversos event systems (CreatureEvent onLogin, MoveEvent onEquip, GlobalEvent onStartup, etc). Simplifica greatly a syntax de revscripts ao permitir assignment direto como `action.onUse = function(player, item, frompos, item, topos) end` ao invés de `action:onUse(function(...) end)`.

**Caminho Original**: `data/libs/functions/revscriptsys.lua`

<Aside type="tip">
O arquivo `revscriptsys.lua` é **foundation da revscript convenience API**. Permite que dados-driven scripts usem simples assignment syntax (`creatureEvent.onLogin = func`) ao invés de method calls (`creatureEvent:onLogin(func)`), automaticamente chamando type() e registerando evento. Suporta 10+ classes core (Action, TalkAction, EventCallback, CreatureEvent, MoveEvent, GlobalEvent, Weapon, Spell, MonsterType, NpcType).
</Aside>

## 📄 Visão Geral do Código

### Resumo Executivo

Arquivo com **5 layers de funcionalidade**:

1. **Dynamic Getters/Setters**: createFunctions gera automaticamente getter/setter pairs para qualquer method
2. **Creature Index Shortcuts**: Acesso simplificado a properties (uid, type, itemid, actionid)
3. **Item Index Shortcuts**: Alternative syntax para item data access
4. **Event Handler Hooks**: __newindex em metatables de event classes para auto-registration
5. **Event Type Mapping**: Automatic type() calls com nome de evento correto

O design usa **Lua metatable manipulation** via rawgetmetatable para interceptar assignments, **closure-based callbacks** que forwards to real methods, e **type-safe registration** com logging.

## 🔧 Função Global

### `createFunctions(class)` → void

Gera automaticamente getter/setter pairs para methods arbitrários.

**Tipo**: Função global  
**Parâmetros**: `class` (table, classe para augment)  
**Retorna**: Nenhum (modifica class in-place)

**Implementação**:
```lua
function createFunctions(class)
	local exclude = { [2] = { "is" }, [3] = { "get", "set", "add", "can" }, [4] = { "need" } }
	local temp = {}
	for name, func in pairs(class) do
		local add = true
		for strLen, strTable in pairs(exclude) do
			if table.contains(strTable, name:sub(1, strLen)) then
				add = false
			end
		end
		if add then
			local str = name:sub(1, 1):upper() .. name:sub(2)
			local getFunc = function(self)
				return func(self)
			end
			local setFunc = function(self, ...)
				return func(self, ...)
			end
			local get = "get" .. str
			local set = "set" .. str
			if not (rawget(class, get) and rawget(class, set)) then
				table.insert(temp, { set, setFunc, get, getFunc })
			end
		end
	end
	for _, func in ipairs(temp) do
		rawset(class, func[1], func[2])
		rawset(class, func[3], func[4])
	end
end
```

**Lógica**:
1. Itera sobre todos methods na class
2. Filtra excluded prefixes: is (2 chars), get/set/add/can (3 chars), need (4 chars)
3. Para cada method válido `method`, cria:
   - `getMethod()`: Chama `method(self)` (getter wrapper)
   - `setMethod(value)`: Chama `method(self, value)` (setter wrapper)
4. Insere em temp array para batch rawset (evita iteração conflicts)
5. rawset garante que não sobrescreve existing get*/set* methods

**Exemplo de Uso**:
```lua
-- Se class tem method "health(self)" que retorna HP
-- createFunctions cria:
--   getHealth(self) → health(self)
--   setHealth(self, value) → health(self, value)

-- Ou method "name(self)" que retorna nome:
--   getName(self) → name(self)
--   setName(self, value) → name(self, value)
```

## 🎭 Customização de Index - Creatures

### `CreatureIndex(self, key)` → value

Custom __index para Player, Monster, Npc metatables.

**Tipo**: Função local (metatable hook)  
**Parâmetros**: `self` (creature), `key` (acesso key)  
**Retorna**: value

**Shortcuts implementados**:
- `uid`: Maps to `getId()`
- `type`: Returns `THING_TYPE_PLAYER/MONSTER/NPC` (detecta via isPlayer/isMonster/isNpc)
- `itemid`: Returns 1
- `actionid`: Returns 0
- Tudo else: `methods[key]` (fallback aos métodos reais)

**Implementação**:
```lua
local function CreatureIndex(self, key)
	local methods = getmetatable(self)
	if key == "uid" then
		return methods.getId(self)
	elseif key == "type" then
		local creatureType = 0
		if methods.isPlayer(self) then
			creatureType = THING_TYPE_PLAYER
		elseif methods.isMonster(self) then
			creatureType = THING_TYPE_MONSTER
		elseif methods.isNpc(self) then
			creatureType = THING_TYPE_NPC
		end
		return creatureType
	elseif key == "itemid" then
		return 1
	elseif key == "actionid" then
		return 0
	end
	return methods[key]
end
```

**Aplicado a**: Player, Monster, Npc (via rawgetmetatable)

**Exemplo**:
```lua
local creature = Game.getCreatureByName("John")
print(creature.uid)       -- getId(creature)
print(creature.type)      -- THING_TYPE_PLAYER
print(creature.itemid)    -- 1
```

## 📦 Customização de Index - Items

### `ItemIndex(self, key)` → value

Custom __index para Item, Container, Teleport metatables.

**Tipo**: Função local (metatable hook)  
**Parâmetros**: `self` (item), `key` (acesso key)  
**Retorna**: value

**Shortcuts implementados**:
- `itemid`: Maps to `getId()`
- `actionid`: Maps to `getActionId()`
- `uid`: Maps to `getUniqueId()`
- `type`: Maps to `getSubType()`
- Tudo else: `methods[key]` (fallback)

**Implementação**:
```lua
local function ItemIndex(self, key)
	local methods = getmetatable(self)
	if key == "itemid" then
		return methods.getId(self)
	elseif key == "actionid" then
		return methods.getActionId(self)
	elseif key == "uid" then
		return methods.getUniqueId(self)
	elseif key == "type" then
		return methods.getSubType(self)
	end
	return methods[key]
end
```

**Aplicado a**: Item, Container, Teleport

**Exemplo**:
```lua
local item = player:getSlotItem(CONST_SLOT_HEAD)
print(item.itemid)   -- getId(item)
print(item.actionid) -- getActionId(item)
print(item.uid)      -- getUniqueId(item)
print(item.type)     -- getSubType(item)
```

## 🔗 Event Handler Hooks - Overview

Todos os handlers seguem padrão: intercept assignment → verificar se chave é evento conhecido → chamar type()/eventType() setup → chamar real method → retornar. Se key desconhecido → rawset normal.

### `ActionNewIndex(self, key, value)` → void

Action class onUse hook.

**Tipo**: Função local (__newindex hook)  
**Parâmetros**:
- `self` (Action)
- `key` (string)
- `value` (function)

**Implementação**:
```lua
local function ActionNewIndex(self, key, value)
	if key == "onUse" then
		self:onUse(value)
		return
	end
	rawset(self, key, value)
end
```

**Mapped Event**: `onUse` → `action:onUse(callback)`

**Exemplo**:
```lua
local action = Action()
action.onUse = function(player, item, frompos, item, topos)
	print("Action used!")
end
```

### `EventCallbackNewIndex(self, key, value)` → void

EventCallback class dynamic hook.

**Tipo**: Função local (__newindex hook)  
**Parâmetros**:
- `self` (EventCallback)
- `key` (string, nome de evento dinâmico)
- `value` (function, callback)

**Implementação**:
```lua
local eventCallbacks = Game.getEventCallbacks()
do
	local function EventCallbackNewIndex(self, key, value)
		local func = eventCallbacks[key]
		if func and type(func) == "function" then
			logger.trace("[Registering EventCallback: {}", key)
			func(self, value)
			self:type(key)
		else
			reportError("Invalid EventCallback with name: {}", tostring(key))
		end
	end
	rawgetmetatable("EventCallback").__newindex = EventCallbackNewIndex
end
```

**Fluxo**:
1. Lookup `key` em `eventCallbacks` (registry of known callbacks)
2. Se existe: chamar `eventCallbacks[key](self, value)`, depois `self:type(key)`, log sucesso
3. Se não existe: reportError

**Mapped Events**: Dinâmico por eventCallbacks registry

**Exemplo**:
```lua
local callback = EventCallback()
callback.playerLogin = function(player) ... end  -- Se playerLogin existe em eventCallbacks
```

## 🔄 Padrões de Uso

### Padrão 1: Criar Action com Convenience Syntax

```lua
local action = Action()
action:itemid(2175)  -- Item ID para wildcard
action.onUse = function(player, item, frompos, item, topos)
	player:say("You used item with ID " .. item.itemid)
	return true
end
action:register()
```

**Fluxo**:
1. Atribuir onUse dispara ActionNewIndex
2. Calls action:onUse(function)
3. Register retorna

**Benefício**: Declarativo, simples assignment ao invés de: `action:onUse(function(...) end)`

## 📚 Conclusão

O arquivo `revscriptsys.lua` é **convenience layer critical** para revscript system. Através de metatable hooks (__index/__newindex), permite que scripts usem simples assignment syntax (`creatureEvent.onLogin = func`) ao invés de method calls (`creatureEvent:onLogin(func)`), automaticamente registrando tipo de evento. Suporta 10+ classes core (Action, TalkAction, EventCallback, CreatureEvent, MoveEvent, GlobalEvent, Weapon, Spell, MonsterType, NpcType) com type-safe registration e automatic setup.

<Aside type="note">
**Nota de Manutenção**: Todos __newindex handlers usam rawgetmetatable para modificar metatables diretamente. EventCallback requer Game.getEventCallbacks() registry. createFunctions usa rawset para evitar __newindex loops. Excluded prefixes em createFunctions (is, get, set, add, can, need) garantem que properties não sejam duplicadas. MonsterType/NpcType usam eventType() constantes (MONSTERS_EVENT_*, NPCS_EVENT_*), não type strings. NpcType onCloseChannel calls onBuyItem (possível bug no original).
</Aside>
