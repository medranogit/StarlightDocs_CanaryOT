## 🛠️ Informações do Arquivo

Módulo que implementa sistema de loot de gemas para o Gem Atelier. Fornece geração probabilística de gemas baseada na classificação de forja do monstro (influenced, fiendish, ou archfoe), com três tiers de gemas (menor, regular, maior) e chances de drop diferenciadas por tier e classificação.

<Aside type="tip">
O sistema Gem Atelier integra-se à mecânica de **Dust Forge** do servidor, recompensando jogadores com gemas raras quando derotam monstros especiais. Cada tier tem drops específicos baseados na classificação do monstro e em rolls de chance.
</Aside>

## 📄 Visão Geral do Código

### Resumo Executivo

O arquivo `gematelier.lua` implementa um **gerador de loot probabilístico** que estende a classe `Monster` com método `generateGemAtelierLoot()`. O sistema funciona em 3 fases:

1. **Classificação**: Determina tipo de monstro (influenced, fiendish, archfoe)
2. **Tier Iteration**: Para cada tier de gema (lesser, regular, greater)
3. **Probabilistic Drop**: Roll chance para cada gem, dropando se passar no threshold

As gemas são organizadas em **3 tiers com curvas de chance diferentes**:
- **Lesser Gems**: 9000/100000 chance em influenced, 3000 em fiendish, 0 em archfoe
- **Regular Gems**: 0 em influenced, 3000 em fiendish, 9000 em archfoe
- **Greater Gems**: 0 em influenced, 9000 em fiendish, 3000 em archfoe

### Estrutura de Funcionalidades

```
Gem Atelier System
├── Local Config Table (3 tiers)
│   ├── lesser
│   │   ├── names (5 gemas)
│   │   ├── chance (por clasificação)
│   │   └── maxCount = 2
│   ├── regular
│   │   ├── names (5 gemas)
│   │   ├── chance (por clasificación)
│   │   └── maxCount = 2
│   └── greater
│       ├── names (5 gemas)
│       ├── chance (por clasificación)
│       └── maxCount = 1
└── Method Extension
    └── Monster:generateGemAtelierLoot() → table
        ├── Classifica monstro
        ├── Itera cada tier
        ├── Rolls chance para cada gem
        └── Retorna map de itemId → `{count}`
```

## 📋 Variáveis Locais

### `config` (Table)

Tabela local que centralize toda a configuração do sistema de gemas.

**Estrutura**:
```lua
local config = {
    [tier_name] = {
        names = {string, ...},           -- Array de nomes de gemas
        chance = {
            influenced = number,         -- Chance 1/100000 para monstro influenced
            fiendish = number,           -- Chance 1/100000 para monstro fiendish
            archfoe = number,            -- Chance 1/100000 para monstro archfoe
        },
        maxCount = number,               -- Máximo de gems a droplar deste tier
    },
    ...
}
```

**Tiers Definidos**:

#### Lesser Tier
```lua
lesser = {
    names = {
        "lesser guardian gem",
        "lesser marksman gem",
        "lesser sage gem",
        "lesser mystic gem",
        "lesser spiritualist gem",
    },
    chance = {
        influenced = 9000,   -- 9% em influenced
        fiendish = 3000,     -- 3% em fiendish
        archfoe = 0,         -- Não dropla em archfoe
    },
    maxCount = 2,            -- Máximo 2 gemas por monstro
}
```

**Padrão Observado**:
- 5 tipos de gemas por tier (um para cada classe/specialização)
- Chances variam por classificação
- `maxCount` controla limite de drops por tier

#### Regular Tier
```lua
regular = {
    names = {...},  -- 5 gemas regulares

        influenced = 0,      -- Não dropla

    },
```

#### Greater Tier

```lua
greater = {
```

## 🔧 Métodos de Extensão

### `Monster:generateGemAtelierLoot()`

Gera tabela de loot de gemas baseada na classificação de forja do monstro.

**Tipo**: Method Extension (Monster)  
**Parâmetros**: Nenhum  
**Retorna**: table (map de itemId → `{count}`)

**Assinatura**:
```lua
function Monster:generateGemAtelierLoot()
    -- Implementação
end
```

**Fluxo de Execução**:

1. **Obter Tipo de Monstro**:
```lua
local mType = self:getType()
if not mType then
    return {}
end
```

2. **Classificar Monstro**:
```lua
local category = "none"
local forgeClassification = self:getMonsterForgeClassification()
if forgeClassification == FORGE_INFLUENCED_MONSTER then
    category = "influenced"
elseif forgeClassification == FORGE_FIENDISH_MONSTER then
    category = "fiendish"
elseif (mType:bossRace() or ""):lower() == "archfoe" then
    category = "archfoe"
end
if category == "none" then
    return {}
end
```

3. **Iterate Tiers e Roll Chances**:
```lua
local loot = {}
for _, gemConfig in pairs(config) do
    local chance = gemConfig.chance[category] or 0
    local names = gemConfig.names
    local maxCount = gemConfig.maxCount
    if chance > 0 then
        for i = 1, maxCount do
            local roll = math.random(1, 100000)
            if roll > chance then
                goto continue
            end
            -- Drop logic
        end
    end
end
```

4. **Droplar Gem**:
```lua
local name = names[math.random(1, #names)]
local itemType = ItemType(name)
if not itemType then
    goto continue
end
if loot[itemType:getId()] then
    loot[itemType:getId()].count = loot[itemType:getId()].count + 1
else
    loot[itemType:getId()] = { count = 1 }
end
```

**Exemplo de Uso**:
```lua
-- Em creaturescripts/death event
local monster = Monster(cid)
if monster then
    local gemLoot = monster:generateGemAtelierLoot()
    for itemId, data in pairs(gemLoot) do
        for _ = 1, data.count do
            Game.createItem(itemId, 1, monster:getPosition())
        end
    end
end
```

**Retorno de Exemplo**:
```lua
-- Monstro influenced dropla 2 lesser gems
{
    [12345] = { count = 1 },  -- lesser guardian gem
    [12346] = { count = 1 },  -- lesser marksman gem
}

-- Monstro fiendish dropla 1 lesser + 1 regular + 2 greater
{
    [12345] = { count = 1 },  -- lesser gem
    [12347] = { count = 1 },  -- regular gem
    [12355] = { count = 2 },  -- greater gems
}
```

**Características**:
- **Idempotente**: Mesma classificação sempre retorna possibilidade de drops
- **Probabilística**: Cada gem tem chance independente de dropar
- **Cumulativa**: Mesma gem ID pode dropar múltiplas vezes com contador incrementado
- **Fail-Safe**: Retorna tabela vazia se monstro não tiver classificação ou tipo inválido

## 🎯 Sistema de Classificação

### Classificações Suportadas

| Classificação | Flag | Como Detectar | Gems |
|---------------|------|---------------|------|
| influenced | `FORGE_INFLUENCED_MONSTER` | `self:getMonsterForgeClassification()` | Lesser (9%) |
| fiendish | `FORGE_FIENDISH_MONSTER` | `self:getMonsterForgeClassification()` | Lesser (3%) + Greater (9%) |
| archfoe | (Boss Race) | `mType:bossRace() == "archfoe"` | Regular (9%) + Greater (3%) |
| normal | - | Nenhuma das acima | Nenhuma gem |

### Matriz de Chances

```
           | Lesser | Regular | Greater
-----------|--------|---------|--------
influenced | 9%     | 0%      | 0%
fiendish   | 3%     | 3%      | 9%
archfoe    | 0%     | 9%      | 3%
```

## 🔄 Padrões de Uso

### Padrão 1: Integração em Death Event

```lua
local function onMonsterDeath(creature)
    local monster = Monster(creature:getId())
    if not monster then
        return true
    end
    
    local gemLoot = monster:generateGemAtelierLoot()
    for itemId, lootData in pairs(gemLoot) do
        for _ = 1, lootData.count do
            local item = Game.createItem(itemId, 1, monster:getPosition())
            if item then
                item:setActionId(ACTIONID_GEM_ATELIER)
            end
        end
    end
    
    return true
end
```

### Padrão 2: Drop com Mensagem

```lua
local function dropGemsWithMessage(monster)
    local gemLoot = monster:generateGemAtelierLoot()
    if next(gemLoot) then
        local count = 0
        for _, data in pairs(gemLoot) do
            count = count + data.count
        end
        
        if count > 0 then
            doCreatureSayWithRadius(monster:getId(), 
                "The creature drops " .. count .. " gem(s)!", 
                TALKTYPE_MONSTER_SAY, 5, 5)
        end
        
        for itemId, data in pairs(gemLoot) do
            for _ = 1, data.count do
                Game.createItem(itemId, 1, monster:getPosition())
            end
        end
    end
end
```

### Padrão 3: Loot Direto em Backpack

```lua
local function giveGemsToKiller(creature, killer)
    local monster = Monster(creature:getId())
    if not killer:isPlayer() then return end
    
    local gemLoot = monster:generateGemAtelierLoot()
    for itemId, data in pairs(gemLoot) do
        for _ = 1, data.count do
            killer:addItem(itemId, 1)
        end
    end
end
```

## ✅ Checkpoint de Aprendizagem

### Conceitos Principais

1. **Tabelas de Configuração**: Centralizar dados em estrutura aninhada para fácil manutenção
2. **Classificação Dinâmica**: Determinar tipo em runtime vs hardcoded
3. **Iteração com Probabilidade**: Loop + math.random para drops randomizados
4. **Acumulação de Loot**: Map de itemId para evitar duplicatas de estrutura

### Padrões Identificados

- **Configuration Driven**: Tudo configurable via tabela local
- **Visitor Pattern**: Iterar cada tier e aplicar função drop
- **Guard Clauses**: Retornar {} para casos inválidos
- **Goto Labels**: `::continue::` para skip iterações

### Design Decisions

| Decisão | Motivo | Impacto |
|---------|--------|--------|
| Tabela local config | Encapsular dados, fácil modificar | Requer reload para mudanças |
| Method extension | Integração com Monster | Polimórfico para subclasses |
| Chance 1/100000 | Precisão de até 0.001% | Suporta chances muito pequenas |
| maxCount por tier | Limite drop razoável | Regular max 2, Greater max 1 |

## 📚 Conclusão

O arquivo `gematelier.lua` implementa um **sistema de loot probabilístico elegante** para recompensar jogadores que derrotam monstros especiais. Seu design centrado em **configuração** torna trivial ajustar chances ou adicionar novos gems, enquanto a **method extension** mantém código limpo sem poluir namespace global.

A matriz de chances (influenced → lesser, fiendish → greater, archfoe → regular) incentiva **estratégias diferentes** de farmar gemas raras baseadas na classe de monstro forjado. O sucesso é medido pelo **drop rate apropriado** que torna gemas valiosas sem serem farmáveis infinitamente.
