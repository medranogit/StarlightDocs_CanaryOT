## 🏗️ Constructor & Type System

### Constructor via Metatable `Set(initial, options)` → Set

Cria novo Set a partir de array, outro Set, ou vazio.

**Tipo**: Function (via __call metatable)  
**Parâmetros**:
- `initial` (table|Set|nil): Initial valores (array, Set, ou omitido)
- `options` (table|nil): Configuração `{insensitive: bool}`

**Retorna**: Set instance com metatable

**Implementação**:
```lua
setmetatable(Set, {
	__call = function(self, initial, options)
		local set = setmetatable({
			values = {},
			options = options or {},
		}, { __index = Set })
		if Set.isSet(initial) then
			for k in initial:iter() do
				set:insert(k)
			end
		elseif type(initial) == "table" then
			for _, k in ipairs(initial) do
				set:insert(k)
			end
		end
		return set
	end,
})
```

**Fluxo**:
1. Cria table com values={}, options={} ou provided options
2. setmetatable com __index=Set (acesso aos métodos)
3. Se initial é Set: copia elementos via iterator
4. Se initial é table: copia array elements via ipairs
5. Se nil: retorna Set vazio
6. Retorna Set pronto para uso

**Exemplos**:
```lua
local s1 = Set()                      -- Set vazio
local s2 = Set({1, 2, 3})            -- Set com array
local s3 = Set(s2)                    -- Set cópialocal s4 = Set({}, {insensitive = true})  -- Case-insensitive
```

## 💾 Core Membership Operations

### `Set:contains(key)` → boolean

Verifica se chave existe no set.

**Tipo**: Method  
**Parâmetros**: `key` (any)  
**Retorna**: boolean

**Implementação**:
```lua
function Set:contains(key)
	key = self:__key(key)
	return self.values[key] ~= nil
end
```

**Complexidade**: O(1) hash lookup

**Exemplo**:
```lua
local s = Set({1, 2, 3})
print(s:contains(1))  -- true
print(s:contains(4))  -- false
```

---

### `Set:insert(key)` → void

Adiciona chave ao set (ou ignora se existe).

**Tipo**: Method  
**Parâmetros**: `key` (any)  
**Retorna**: Nenhum

**Implementação**:
```lua
function Set:insert(key)
	key = self:__key(key)
	self.values[key] = true
end
```

**Comportamento**: Adiciona sempre (override se existe, sem harm)

**Exemplo**:
```lua
local s = Set()
s:insert(1)
s:insert(2)
s:insert(1)  -- Duplicata, mas Set mantém único
print(#s)    -- 2
```

---

### `Set:remove(key)` → void

Remove chave do set (silencioso se não existe).

**Tipo**: Method  
**Parâmetros**: `key` (any)  
**Retorna**: Nenhum

**Implementação**:
```lua
function Set:remove(key)
	if not self:contains(key) then
		return
	end
	key = self:__key(key)
	self.values[key] = nil
end
```

**Comportamento**: Check antes de remover (evita nil key issues)

**Exemplo**:
```lua
local s = Set({1, 2, 3})
s:remove(2)
print(s:contains(2))  -- false
s:remove(99)          -- Silencioso, sem erro
```

## 🔗 Set-Theoretic Operations

### `Set:union(other)` → Set

Retorna novo Set com todos elementos de self + other.

**Tipo**: Method  
**Parâmetros**: `other` (Set)  
**Retorna**: Set novo (cópia)

**Implementação**:
```lua
function Set:union(other)
	local set = Set(self, self.options)
	for k in Set(other, self.options):iter() do
		set:insert(k)
	end
	return set
end
```

**Fluxo**:
1. Criar novo Set com cópia de self
2. Iterar sobre other
3. Inserir cada elemento (deduplica automaticamente)
4. Retornar union

**Exemplo**:
```lua
local s1 = Set({1, 2, 3})
local s2 = Set({3, 4, 5})
local u = s1:union(s2)
print(u)  -- { 1, 2, 3, 4, 5 }
```

---

### `Set:intersection(other)` → Set

Retorna novo Set com apenas elementos em both self e other.

**Tipo**: Method  
**Parâmetros**: `other` (Set)  
**Retorna**: Set novo

**Implementação**:
```lua
function Set:intersection(other)
	local set = Set({}, self.options)
	for k in Set(other, self.options):iter() do
		if self:contains(k) then
			set:insert(k)
		end
	end
	return set
end
```

**Fluxo**:
1. Criar Set vazio
2. Iterar other
3. Se elemento em self: inserir no resultado
4. Retornar intersection

**Exemplo**:
```lua
local s1 = Set({1, 2, 3})
local s2 = Set({3, 4, 5})
local i = s1:intersection(s2)
print(i)  -- { 3 }
```

## 📊 Utilities & Utilities

### `Set:__key(k)` → any

Transforma chave (case-insensitive se habilitado).

**Tipo**: Utility method  
**Parâmetros**: `k` (any)  
**Retorna**: transformed key

**Implementação**:
```lua
function Set:__key(k)
	if self.options.insensitive then
		if type(k) ~= "string" then
			logger.error("key must be a string when insensitive option is enabled")
		end
		k = k:lower()
	end
	return k
end
```

**Comportamento**:
- Se insensitive=true: converte string para lowercase
- Se não string com insensitive: log erro
- Senão: retorna key unchanged

**Exemplo**:
```lua
local s = Set({}, {insensitive = true})
s:insert("Apple")
print(s:contains("APPLE"))  -- true (convertido para lowercase)
```

## 🎭 Metamethods

### `Set:__eq(other)` → boolean

Verifica igualdade de sets (tamanho + elemento check).

**Tipo**: Metamethod  
**Parâmetros**: `other` (Set)  
**Retorna**: boolean

**Implementação**:
```lua
function Set:__eq(other)
	if #self ~= #other then
		return false
	end
	for k in pairs(self.values) do
		if not other:contains(k) then
			return false
		end
	end
	return true
end
```

**Lógica**:
1. Se tamanho diferente: false
2. Se algum elemento em self não em other: false
3. Senão: true

**Exemplo**:
```lua
local s1 = Set({1, 2, 3})
local s2 = Set({1, 2, 3})
local s3 = Set({3, 2, 1})
print(s1 == s2)  -- true (mesmos elementos)
print(s1 == s3)  -- true (ordem não importa)
```

## 🔄 Padrões de Uso

### Padrão 1: Set Básico para Deduplicação

```lua
local items = {"apple", "banana", "apple", "orange", "banana"}
local uniqueItems = Set(items)
print(#uniqueItems)  -- 3 (deduplicated)
for item in uniqueItems:iter() do
	print(item)
end
```
