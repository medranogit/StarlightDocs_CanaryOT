## 📍 Position Finding: `Creature.getClosestFreePosition()`

**Assinatura**:
```lua
function Creature.getClosestFreePosition(self, position, maxRadius, mustBeReachable)
	maxRadius = maxRadius or 1
	if maxRadius == true then
		maxRadius = 2  -- Backward compatibility
	end
	-- Busca spiral de positions livres...
end
```

**Propósito**: Encontra **posição livre mais próxima** em raio especificado.

**Parâmetros**:
- `position` (`Position`): Position central para busca
- `maxRadius` (`number` | `boolean`): Raio máximo (default 1), true = 2
- `mustBeReachable` (`boolean`): Se true, valida caminho via pathfinding

**Retorno**:
- `Position`: Posição livre encontrada
- `Position()` vazia se nenhuma encontrada

**Algoritmo - Busca Spiral**:

```
Raio 0: (0,0) - center
Raio 1: 8 posições ao redor
Raio 2: 16 posições
...
Raio N: N*8 posições
```

**Validações por Tile**:
1. Tile existe
2. Sem creatures (`getCreatureCount() == 0`)
3. Sem impassable solid (`not CONST_PROP_IMMOVABLEBLOCKSOLID`)
4. Se `mustBeReachable`, pathfinding viável (`getPathTo()`)

**Retorna na Primeira Encontrada**: E continua buscando em raio++ para eventual encontrada mais próxima.

**Exemplo**:
```lua
-- Encontra posição livre para teleporte
local freePos = creature:getClosestFreePosition(targetPosition, 2, true)
if freePos.x ~= 0 then
	creature:teleportTo(freePos)
end
```

## 👗 Outfit Management (2 funções)

### `Creature:setMonsterOutfit(monster: string, time: number): boolean`

```lua
function Creature:setMonsterOutfit(monster, time)
	local monsterType = MonsterType(monster)
	if not monsterType then
		return false
	end

	local condition = Condition(CONDITION_OUTFIT)
	condition:setOutfit(monsterType:getOutfit())
	condition:setTicks(time)
	self:addCondition(condition)

	return true
end
```

**Propósito**: Aplicar outfit de monster com duration.

**Parâmetros**:
- `monster` (`string`): Nome do monster
- `time` (`number`): Duração em milliseconds

**Retorno**: `true` se sucesso, `false` se monster invalid

**Fluxo**:
1. Valida MonsterType(monster)
2. Cria Condition CONDITION_OUTFIT
3. Set outfit do monster
4. Set ticks (duration)
5. Aplica condition

**Exemplo**:
```lua
-- Disfarçar como dragon por 10 segundos
player:setMonsterOutfit("dragon", 10000)
```

### `Creature:setItemOutfit(item: string | number, time: number): boolean`

```lua
function Creature:setItemOutfit(item, time)
	local itemType = ItemType(item)
	if not itemType then
		return false
	end

	local condition = Condition(CONDITION_OUTFIT)
	condition:setOutfit({
		lookTypeEx = itemType:getId(),
	})
	condition:setTicks(time)
	self:addCondition(condition)

	return true
end
```

**Propósito**: Aplicar outfit de item com duration.

**Parâmetros**:
- `item` (`string | number`): Nome ou ID do item
- `time` (`number`): Duração em milliseconds

**Retorno**: `true` se sucesso, `false` se item invalid

**Diferença vs setMonsterOutfit**: Usa `lookTypeEx` para item visual.

**Exemplo**:
```lua
-- Parecer um backpack por 5 segundos
player:setItemOutfit(1988, 5000)
```

## 👹 Summon Management (2 funções)

### `Creature:setSummon(monster: string): boolean`

```lua
function Creature:setSummon(monster)
	local summon = Monster(monster)
	if not summon then
		return false
	end

	summon:setMaster(self, true)
	summon:setTarget(self.attackedCreature)
	return true
end
```

**Propósito**: Cria ou atribui summon a creature.

**Parâmetros**:
- `monster` (`string`): Monster ID/UID a setar como summon

**Retorno**: `true` se sucesso, `false` se invalid

**Efeitos**:
1. Set master/owner (self)
2. Set target para current attacked creature

**Exemplo**:
```lua
-- Criar summon de monster existente
player:setSummon(monsterId)
```

### `Creature:removeSummon(monster: string): boolean`

```lua
function Creature:removeSummon(monster)
	local summon = Monster(monster)
	if not summon or summon:getMaster() ~= self then
		return false
	end

	summon:setTarget(nil)
	summon:setFollowCreature(nil)
	summon:setDropLoot(true)
	summon:setSkillLoss(true)
	summon:setMaster(nil)

	return true
end
```

**Propósito**: Remove summon (desvincula de master).

**Parâmetros**:
- `monster` (`string`): Monster ID a remover

**Retorno**: `true` se sucesso, `false` se não é summon ou invalid

**Validações**:
- Monster válido
- Master é self (previne remover summon alheio)

**Efeitos de Cleanup**:
1. Clear target
2. Clear follow
3. Re-enable loot dropping
4. Re-enable skill loss
5. Clear master reference

**Assinatura**:
```lua
function Creature:addDamageCondition(target, type, list, damage, period, rounds)
	if damage <= 0 or not target or target:isImmune(type) then
		return false
	end

end
```

**Propósito**: Aplicar condition com **damage escalável** (DoT).

**Parâmetros**:
- `target` (`Creature`): Alvo do damage
- `type` (`CONDITION_*`): Tipo de condition (POISON, FIRE, etc)
- `list` (`DAMAGELIST_*`): Padrão de scaling
- `damage` (`number`): Damage base/máximo
- `period` (`number | array`): Período em segundos (ou array [min, max])
- `rounds` (`number`): Número de ticks/iterations

**Validações**:
- Damage > 0
- Target existe
- Target não é immune to type

**Retorno**: `true` se aplicado, `false` se validação falhou

### Tipo 1: `DAMAGELIST_EXPONENTIAL_DAMAGE`

```lua
if list == DAMAGELIST_EXPONENTIAL_DAMAGE then
	local exponent, value = -10, 0
	while value < damage do
		value = math.floor(10 * math.pow(1.2, exponent) + 0.5)
		condition:addDamage(1, period or 4000, -value)
		if value >= damage then
			local permille = math.random(10, 1200) / 1000
			condition:addDamage(1, period or 4000, -math.max(1, math.floor(value * permille + 0.5)))
		else
			exponent = exponent + 1
		end
	end
end
```

**Escala**: Exponencial crescente (1.2^x)

**Uso**: Veneno que aumenta em severidade

**Padrão**:
```
Tick 1: valor baixo
Tick 2: valor médio
Tick N: valor alto (até damage limit)
```

### Tipo 2: `DAMAGELIST_LOGARITHMIC_DAMAGE`

```lua
elseif list == DAMAGELIST_LOGARITHMIC_DAMAGE then
	local n, value = 0, damage
	while value > 0 do
		value = math.floor(damage * math.pow(2.718281828459, -0.05 * n) + 0.5)
		if value ~= 0 then
			condition:addDamage(1, period or 4000, -value)
			n = n + 1
		end
	end
end
```

**Escala**: Logarítmica decrescente (e^-x)

**Uso**: Dano que diminui com o tempo

**Padrão**:
```
Tick 1: damage alto
Tick 2: damage médio (reduzido ~95%)
Tick N: damage baixo (trailing off)
```

### Tipo 3: `DAMAGELIST_VARYING_PERIOD`

**Período**: Aleatório entre periodMin/Max

**Uso**: Dano com timing variável

**Parâmetros**:

### Tipo 4: `DAMAGELIST_CONSTANT_PERIOD`

```lua

**Período**: Fixo

**Uso**: Dano DoT regular

**Padrão**: 
```

**Parâmetros**:
- `player` (`Player`): Player usando door
- `toPosition` (`Position`): Posição alvo

**Algoritmo de Retry**:

1. Tenta posição original (right +1)
2. Se falhar, tenta (up +1)
3. Se falhar, tenta (down -2)
4. Se falhar, tenta (left-down -1, up +1)
5. Se todas falham, cancela

- Tile existe
- queryAdd returns RETURNVALUE_NOERROR
- Flags: FLAG_IGNOREBLOCKCREATURE | FLAG_PATHFINDING

## 🗡️ Killer Tracking: `Creature.getKillers()`

**Assinatura**:
```lua
function Creature.getKillers(self, onlyPlayers)
	local killers = {}
	local inFightTicks = configManager.getNumber(configKeys.PZ_LOCKED)
	local timeNow = systemTime()
	local getCreature = onlyPlayers and Player or Creature
	for cid, cb in pairs(self:getDamageMap()) do
		local creature = getCreature(cid)
		if creature and creature ~= self and (timeNow - cb.ticks) <= inFightTicks then
			killers[#killers + 1] = {
				creature = creature,
				damage = cb.total,
			}
		end
	end
	table.sort(killers, function(a, b)
		return a.damage > b.damage
	end)
	for i, killer in pairs(killers) do
		killers[i] = killer.creature
	end
	return killers
end
```

**Propósito**: Obtém **killers ordenados por damage**.

**Parâmetros**:
- `onlyPlayers` (`boolean`): Se true, retorna só Players; se false, todas Creatures

**Filtros**:
- Creature != self
- Damage recente (dentro inFightTicks)

**Retorno**: Array de Creatures, ordenado por damage decrescente

**Exemplo**:
```lua
local killers = player:getKillers(true)  -- Só players
for _, killer in ipairs(killers) do
	print(killer:getName() .. " damage: " .. killer:getDamage())
end
```

## ⭐ Stamina Bonus Integration: `Creature:addEventStamina()`

```lua
function Creature:addEventStamina(target)
	local player = self:getPlayer()
	local monster = target:getMonster()
	if player and monster and monster:getName() == staminaBonus.target then
		local playerId = player:getId()
		if not staminaBonus.eventsTrainer[playerId] then
			staminaBonus.eventsTrainer[playerId] = addEvent(addStamina, staminaBonus.period, playerId)
		end
	end
end
```

**Propósito**: Hook para stamina bonus system (training events).

**Parâmetros**:
- `target` (`Creature`): Target da ação

**Lógica**:
1. Valida self é Player
2. Valida target é Monster
3. Valida monster é alvo de training (staminaBonus.target)
4. Cria event único por player se não existe
5. Adiciona stamina periodicamente
