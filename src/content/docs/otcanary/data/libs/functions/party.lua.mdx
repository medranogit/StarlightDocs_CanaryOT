## 🛠️ Informações do Arquivo

Módulo que estende a classe `Party` nativa com funcionalidades de gerenciamento de grupo: broadcast sincronizado de mensagens para todos membros, cálculo de hazard level baseado na zona mais perigosa onde algum membro está, e métodos para consultar vocações presentes na party (Knights, Paladins, Sorcerers, Druids, Mages). Também adiciona utilitário global para obter lista de participantes com shared experience.

**Caminho Original**: `data/libs/functions/party.lua`

<Aside type="tip">
O arquivo `party.lua` é fundamental para **group mechanics**. Permite criar sistemas escaláveis como broadcast de loot, sincronização de hazard zones (perigo coletivo), e composição balanceada de grupos (raid requirements).
</Aside>

## 📄 Visão Geral do Código

### Resumo Executivo

Arquivo com **3 layers de funcionalidade**:

1. **Broadcast Layer**: Enviar mensagens sincronizadas para leader e todos membros
2. **Hazard Layer**: Calcular nível de perigo baseado em zonas de todos membros
3. **Composition Layer**: Consultar profissões presentes (vocation filtering)

O design usa **métodos de filtragem** para extrair subgrupos por vocação, suportando tanto verificações booleanas (hasKnight) quanto retorno de arrays (getKnights).

## 📡 Métodos de Broadcast

### `Party.broadcastPartyLoot(self, text)` → void

Envia mensagem de loot sincronizada para leader e todos membros.

**Tipo**: Method  
**Parâmetros**:
- `self` (Party): Instância da party
- `text` (string): Mensagem para broadcast

**Retorna**: Nenhum (void)

**Implementação**:
```lua
function Party.broadcastPartyLoot(self, text)
    self:getLeader():sendTextMessage(MESSAGE_LOOT, text)
    local membersList = self:getMembers()
    for i = 1, #membersList do
        local player = membersList[i]
        if player then
            player:sendTextMessage(MESSAGE_LOOT, text)
        end
    end
end
```

**Fluxo**:
1. Enviar para leader
2. Iterar todos membros
3. Validar jogador existe
4. Enviar via `MESSAGE_LOOT` (tipo de chat)

**Exemplo**:
```lua
local party = player:getParty()
if party then
    party:broadcastPartyLoot("Boss dropped a legendary sword!")
    -- Leader + todos 3 membros veem a mensagem
end
```

## ⚠️ Métodos de Hazard

### `Party:refreshHazard()` → void

Recalcula nível de hazard para party baseado em zonas de todos membros.

**Tipo**: Method  
**Retorna**: Nenhum (void)

**Implementação Core**:
```lua
function Party:refreshHazard()
    local members = self:getMembers()
    table.insert(members, self:getLeader())
    local hazard = nil
    local level = -1

    for _, member in ipairs(members) do
        local zones = member:getZones()
        if zones then
            for _, zone in ipairs(zones) do
                local memberHazard = Hazard.getByName(zone:getName())
                if memberHazard then
                    if not hazard then
                        hazard = memberHazard
                    elseif hazard.name ~= memberHazard.name then
                        -- Party members are in different hazard areas
                        level = 0
                        break
                    end
                end
            end
        end

        if hazard then
            local memberLevel = hazard:getPlayerCurrentLevel(member)
            if memberLevel < level or level == -1 then
                level = memberLevel
            end
        end
    end
    
    for _, member in ipairs(members) do
        member:setHazardSystemPoints(level)
    end
end
```

**Fluxo**:
1. Coletar leader + todos membros
2. Iterar cada jogador, extrair suas zonas (multiple zones per player)
3. Mapear zona → Hazard via nome
4. Se todos em MESMA hazard: calcular level mínimo (mais letal para grupo)
5. Se em DIFERENTES hazards: level = 0 (sem sincronização)
6. Aplicar level a todos membros via `setHazardSystemPoints()`

**Validação**:
- `zone:getName()` deve existir em Hazard registry
- Se member é nil: skip (não crashear)
- Level padrão = -1 (sem hazard)

**Exemplo**:
```lua
-- Party em zona "Dragon Lair" (hazard level 5)
party:refreshHazard()
-- Todos membros agora têm hazard level 5

-- 1 membro sai da zona
party:refreshHazard()
-- Level = 0 (membros em hazards diferentes, sem sincronização)
```

## 👥 Métodos de Vocação

### `Party.hasVocation(self, vocationId)` → boolean

Verifica se party tem jogador com vocação específica (leader + membros).

**Tipo**: Method  
**Parâmetros**:
- `vocationId` (number): ID da vocação base (VOCATION.BASE_ID.KNIGHT, etc)

**Retorna**: boolean (true se encontra, false senão)

**Implementação**:
```lua
function Party.hasVocation(self, vocationId)
    if self:getLeader():getVocation():getBaseId() == vocationId then
        return true
    end
    local membersList = self:getMembers()
    for i = 1, #membersList do
        local player = membersList[i]
        if player and player:getVocation():getBaseId() == vocationId then
            return true
        end
    end
    return false
end
```

**Busca**: Leader primeiro, depois todos membros (early-out em match).

### `Party:getPlayersWithVocation(vocation)` → Player[]

Retorna array de todos jogadores (leader + membros) com vocação específica.

**Tipo**: Method  
**Parâmetros**: `vocation` (number, vocação base ID)  
**Retorna**: table com Player objects

**Implementação**:
```lua
function Party:getPlayersWithVocation(vocation)
    local players = {}
    if self:getLeader():getVocation():getBaseId() == vocation then
        table.insert(players, self:getLeader())
    end
    local membersList = self:getMembers()
    for i = 1, #membersList do
        local player = membersList[i]
        if player and player:getVocation():getBaseId() == vocation then
            table.insert(players, player)
        end
    end
    return players
end
```

**Validação**: Valida que player existe antes de inserir.

**Exemplo**:
```lua
local knights = party:getPlayersWithVocation(VOCATION.BASE_ID.KNIGHT)
for _, knight in ipairs(knights) do
    knight:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Tanking turn!")
end
```

### `Party:getMages()` → Player[]

Retorna array combinado de Sorcerers + Druids.

**Tipo**: Method  
**Retorna**: Player[] (sorcerers + druids mesclados)

**Implementação**:
```lua
function Party:getMages()
    local sorcerers = self:getSorcerers()
    local druids = self:getDruids()
    local mages = {}
    for i = 1, #sorcerers do
        table.insert(mages, sorcerers[i])
    end
    for i = 1, #druids do
        table.insert(mages, druids[i])
    end
    return mages
end
```

**Exemplo**:
```lua
local mages = party:getMages()
-- Contém Sorcerers + Druids
```

## 🌍 Função Global: Participants

### `Participants(player, requireSharedExperience)` → Player[]

Retorna lista de jogadores participantes de experiência compartilhada (se em party com shared exp) ou solo player.

**Tipo**: Função Global  
**Parâmetros**:
- `player` (Player): Jogador base
- `requireSharedExperience` (boolean): Se true, retorna [] se shared exp desativado

**Retorna**: Player[] (player solo ou party members)

**Implementação**:
```lua
function Participants(player, requireSharedExperience)
    local party = player:getParty()
    if not party then
        return { player }  -- Solo
    end
    if requireSharedExperience and not party:isSharedExperienceActive() then
        return { player }  -- Party existe mas shared exp off
    end
    local members = party:getMembers()
    table.insert(members, party:getLeader())
    return members
end
```

**BUG OBSERVADO**: Parâmetro é `requireSharedExperience` mas código usa `requiredSharedExperience` (typo).

**Fluxo**:
1. Se sem party: retorna [player]
2. Se party mas shared exp desativado + flag true: retorna [player]
3. Senão: retorna members + leader

**Exemplo**:
```lua
-- Player solo
local participants = Participants(player, true)
-- Retorna: { player }

-- Player em party com shared exp
local participants = Participants(player, true)
-- Retorna: { leader, member1, member2, member3 }
```

## 👤 Método Player: isPartyLeaderOrSolo

### `Player:isPartyLeaderOrSolo(sharedExperience)` → boolean

Verifica se jogador é leader da party OU está solo (sem party).

**Tipo**: Method  
**Parâmetros**:
- `sharedExperience` (boolean): Se true, only true se leader + shared exp ativo

**Retorna**: boolean (true se leader ou solo, false se membro)

**Implementação**:
```lua
function Player:isPartyLeaderOrSolo(sharedExperience)
    local party = self:getParty()
    if not party then
        return true  -- Solo
    end
    if sharedExperience and not party:isSharedExperienceActive() then
        return true  -- Tem party mas shared exp off (treated as solo)
    end
    return party:getLeader() == self  -- Check se é leader
end
```

**Exemplo**:
```lua
if player:isPartyLeaderOrSolo(true) then
    print("Você é líder ou está solo!")
else
    print("Você é membro da party")
end
```

## 🔄 Padrões de Uso

### Padrão 1: Broadcast de Evento de Party

```lua
local party = player:getParty()
if party then
    party:broadcastPartyLoot("Boss defeated! Loot incoming...")
    
    local loot = {
        { itemId = 10000, amount = 1 },
    }
    
    for _, participant in ipairs(Participants(player, true)) do
        for _, item in ipairs(loot) do
            participant:addItem(item.itemId, item.amount)
        end
    end
end
```

### Padrão 2: Requerer Composição de Party

```lua
local function canFormRaid(player)
    local party = player:getParty()
    if not party then
        return false, "Você precisa de uma party"
    end
    
    if not party:hasKnight() then
        return false, "Party precisa de um Knight (tank)"
    end
    
    if #party:getMages() < 1 then
        return false, "Party precisa de pelo menos 1 Mago"
    end
    
    return true, "Composição válida!"
end
```

### Padrão 3: Sincronizar Hazard ao Entrar em Zona Perigosa

```lua
-- Em creaturescript onZoneEnter
function onZoneEnter(player, zone)
    local party = player:getParty()
    if party then
        party:refreshHazard()  -- Recalcula para toda party
    end
    return true
end
```

### Padrão 4: Distribuir Loot para Subgrupo de Vocação

```lua
local function rewardKnights(party, itemId, amount)
    local knights = party:getKnights()
    for _, knight in ipairs(knights) do
        knight:addItem(itemId, amount)
        knight:sendTextMessage(MESSAGE_LOOT, "Tank bonus!")
    end
    
    if #knights == 0 then
        print("Party não tem Knights")
    end
end
```

## ✅ Checkpoint de Aprendizagem

### Conceitos Principais

| Conceito | Descrição | Método |
|----------|-----------|--------|
| **Broadcast Sincronizado** | Mensagem para leader + todos membros | broadcastPartyLoot |
| **Composição de Party** | Verificar vocações presentes | hasKnight, getKnights |
| **Hazard Sincronizado** | Nível de perigo baseado em zonas | refreshHazard |
| **Participantes Dinâmicos** | Lista com/sem shared experience | Participants() |
| **Filtro por Vocação** | Extrair subgrupos profissionais | getPlayersWithVocation |

### Padrões Identificados

1. **Dual-Check Pattern**: Verificar leader primeiro, depois membros
2. **Early-Out Filtering**: Retornar true/false na primeira match
3. **Array Accumulation**: Acumular resultados em table antes de retornar
4. **Nil Safety**: Validar `if player then` antes de usar
5. **Shared Experience Guard**: Checar `isSharedExperienceActive()` se necessário

### Responsabilidades por Método

- **broadcastPartyLoot**: Sincronização de mensagens
- **refreshHazard**: Cálculo de zona mais perigosa
- **hasVocation**: Verificação booleana rápida
- **getPlayersWithVocation**: Extração de subgrupo
- **Participants**: Adaptar para shared experience
