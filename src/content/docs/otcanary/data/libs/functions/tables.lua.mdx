## 🔧 Utilitários Básicos

### `table.append`

Alias para `table.insert()`.

**Tipo**: Alias (adicionado a table library)  
**Equivalente a**: `table.insert()`

**Uso**:
```lua
table.append(myTable, value)  -- Mesmo que table.insert(myTable, value)
```

### `table.empty(t)` → boolean

Verifica se tabela está vazia.

**Tipo**: Função estendida  
**Parâmetros**: t (table)  
**Retorna**: boolean (true se vazio)

**Implementação**:
```lua
table.empty = function(t)
	return next(t) == nil
end
```

**Lógica**: Usa `next(t)` para check (mais eficiente que contar)

**Exemplo**:
```lua
print(table.empty({}))           -- true
print(table.empty({1, 2, 3}))    -- false
print(table.empty({a = 1}))      -- false
```

## 🔍 Busca

### `table.find(table, value)` → index | nil

Encontra primeiro índice de valor.

**Tipo**: Função estendida  
**Parâmetros**:
- table (table): Tabela a buscar
- value (any): Valor a encontrar

**Retorna**: index (key) ou nil

**Implementação**:
```lua
table.find = function(table, value)
	for i, v in pairs(table) do
		if v == value then
			return i
		end
	end
	return nil
end
```

**Fluxo**:
1. Loop cada elemento (pairs)
2. Se v == value: return i (a chave)
3. Se nenhum encontrado: return nil

**Exemplo**:
```lua
local idx = table.find({10, 20, 30}, 20)
-- idx = 2

local notFound = table.find({"a", "b", "c"}, "z")
-- notFound = nil

local keyFind = table.find({x = 10, y = 20}, 10)
-- keyFind = "x"
```

---

### `table.contains(array, value)` → boolean

Verifica se valor existe (returns boolean, não index).

**Tipo**: Função estendida  
**Parâmetros**:
- array (table): Tabela a buscar
- value (any): Valor a encontrar

**Retorna**: boolean

**Implementação**:
```lua
table.contains = function(array, value)
	for _, targetColumn in pairs(array) do
		if targetColumn == value then
			return true
		end
	end
	return false
end
```

**Diferença vs find**: contains retorna boolean; find retorna index

**Exemplo**:
```lua
print(table.contains({1, 2, 3}, 2))        -- true
print(table.contains({"a", "b"}, "c"))     -- false
print(table.contains({x = 10, y = 20}, 20))-- true
```

## 📊 Contagem

### `table.count(table, item)` → number

Conta quantas vezes item aparece na tabela.

**Tipo**: Função estendida  
**Parâmetros**:
- table (table): Tabela a contar
- item (any): Item a contar

**Retorna**: number (count)

**Implementação**:
```lua
table.count = function(table, item)
	local count = 0
	for i, n in pairs(table) do
		if item == n then
			count = count + 1
		end
	end
	return count
end
```

**Exemplo**:
```lua
print(table.count({1, 2, 2, 3, 2}, 2))           -- 3
print(table.count({a = 1, b = 1, c = 2}, 1))    -- 2
print(table.count({10, 20, 30}, 40))            -- 0
```

## 🎲 Combinatorics

### `table.getCombinations(table, num)` → combinations[]

Gera todas combinações de num elementos.

**Tipo**: Função estendida  
**Parâmetros**:
- table (table): Elementos para combinar
- num (number): Tamanho de cada combinação

**Retorna**: table de combinações (cada é array)

**Implementação** (algoritmo):
```lua
table.getCombinations = function(table, num)
	local a, number, select, newlist = {}, #table, num, {}
	for i = 1, select do
		a[#a + 1] = i
	end

	local newthing = {}
	while true do
		local newrow = {}
		for i = 1, select do
			newrow[#newrow + 1] = table[a[i]]
		end

		newlist[#newlist + 1] = newrow
		i = select
		while a[i] == (number - select + i) do
			i = i - 1
		end

		if i < 1 then
			break
		end

		a[i] = a[i] + 1
		for j = i, select do
			a[j] = a[i] + j - i
		end
	end

	return newlist
end
```

**Algoritmo**: Combinatorial generation (lexicographic order)

**Exemplo**:
```lua
local combos = table.getCombinations({1, 2, 3}, 2)
-- combos = {
--   {1, 2},
--   {1, 3},
--   {2, 3}
-- }

local names = table.getCombinations({"A", "B", "C"}, 2)
-- names = {
--   {"A", "B"},
--   {"A", "C"},
--   {"B", "C"}
-- }
```

## 💾 Serialização

### `table.serialize(x, recur)` → string

Converte table (ou valor) em string Lua-válida.

**Tipo**: Função estendida  
**Parâmetros**:
- x (any): Valor a serializar
- recur (table|nil): Recursion tracker (interno)

**Retorna**: string representação

**Implementação**:
```lua
function table.serialize(x, recur)
	local t = type(x)
	recur = recur or {}

	if t == nil then
		return "nil"
	elseif t == "string" then
		return string.format("%q", x)
	elseif t == "number" then
		return tostring(x)
	elseif t == "boolean" then
		return t and "true" or "false"
	elseif getmetatable(x) then
		error("Can not serialize a table that has a metatable associated with it.")
	elseif t == "table" then
		if table.find(recur, x) then
			error("Can not serialize recursive tables.")
		end
		table.append(recur, x)

		local s = "{"
		for k, v in pairs(x) do
			s = s .. "[" .. table.serialize(k, recur) .. "]"
			s = s .. " = " .. table.serialize(v, recur) .. ","
		end
		s = s .. "}"
		return s
	else
		error("Can not serialize value of type '" .. t .. "'.")
	end
end
```

**Suporte**:
- nil → "nil"
- string → quoted com %q
- number → tostring
- boolean → "true" ou "false"
- table → `{[k] = v, ...}` format

**Validações**:
- Error se metatable exists
- Error se tabela recursiva (detecção via recur array)

**Exemplo**:
```lua
print(table.serialize({a = 1, b = 2}))
-- {["a"] = 1,["b"] = 2,}

print(table.serialize({{1, 2}, {3, 4}}))
-- {[1] = {[1] = 1,[2] = 2,},[2] = {[1] = 3,[2] = 4,},}

table.serialize({a = {}})
-- {["a"] = {},}
```

### `table.unserialize(str)` → table

Converte string (do serialize) em table.

**Tipo**: Função estendida  
**Parâmetros**: str (string): Serialized string  
**Retorna**: table (or value)

**Implementação**:
```lua
function table.unserialize(str)
	return loadstring("return " .. str)()
end
```

**Fluxo**:
1. Prepend "return " ao string
2. Executar com loadstring (cria chunk)
3. Call chunk () para retornar valor

**Segurança**: ⚠️ loadstring executa código arbitrário (usar cuidado com input não-confiável)

**Exemplo**:
```lua
local serialized = table.serialize({a = 1, b = 2})
local restored = table.unserialize(serialized)
-- restored = {a = 1, b = 2}

local data = table.unserialize("{[1] = 10, [2] = 20}")
-- data = {10, 20}
```

## 🔄 Clonagem

### `table.shallowCopy(oldTable)` → newTable

Cria cópia rasa (shallow copy).

**Tipo**: Função estendida  
**Parâmetros**: oldTable (table)  
**Retorna**: newTable (cópia rasa)

**Implementação**:
```lua
function table.shallowCopy(oldTable)
	local newTable = {}
	for k, v in pairs(oldTable) do
		newTable[k] = v
	end
	return newTable
end
```

**Nota**: Shallow = copiam referências (não deepCopy)

**Exemplo**:
```lua
local original = {a = 1, b = {x = 10}}
local copy = table.shallowCopy(original)

copy.a = 2
copy.b.x = 20

print(original.a)    -- 1 (não afetado)
print(original.b.x)  -- 20 (referência compartilhada!)
```

## 🔁 Iteração Ordenada

### `pairsByKeys(t, f)` → iterator

Retorna iterator que ordena por chaves.

**Tipo**: Função global  
**Parâmetros**:
- t (table): Tabela a iterar
- f (function|nil): Funcão de comparação (opcional)

**Retorna**: iterator function

**Implementação**:
```lua
function pairsByKeys(t, f)
	local a = {}
	for n in pairs(t) do
		table.insert(a, n)
	end
	table.sort(a, f)
	local i = 0 -- iterator variable
	local iter = function() -- iterator function
		i = i + 1
		if a[i] == nil then
			return nil
		else
			return a[i], t[a[i]]
		end
	end
	return iter
end
```

**Fluxo**:
1. Extrair todas chaves em array a
2. Sort a com função f (se fornecida)
3. Retornar função iterator que:
   - Incrementa i
   - Retorna (key, value) ou nil

**Uso em Loop**:
```lua
for key, value in pairsByKeys(table) do
	print(key, value)
end

-- Com comparator customizado
for key, value in pairsByKeys(table, function(a, b) return a > b end) do
	print(key, value)
end
```

**Exemplo**:
```lua
local data = {z = 1, a = 2, m = 3}

-- Iteração normal (ordem indefinida)
for k, v in pairs(data) do
	print(k, v)
end

-- Iteração ordenada (a, m, z)
for k, v in pairsByKeys(data) do
	print(k, v)
end
```
