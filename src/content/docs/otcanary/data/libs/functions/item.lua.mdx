## 🛠️ Informações do Arquivo

Módulo que implementa extensões de métodos auxiliares para a classe Item do engine Canary. Fornece acesso facilitado ao ItemType, validações de tipo (isContainer, isCreature, etc), gerenciamento de atributos customizáveis (descrição, texto, nome, ID único, duração, estado de decay).

<Aside type="tip">
O arquivo `item.lua` estende a classe Item nativa do engine com 15 métodos reutilizáveis que abstraem operações comuns, eliminando a necessidade de chamar APIs de baixo nível diretamente no código de scripts.
</Aside>

## 📄 Visão Geral do Código

### Resumo Executivo

O arquivo `item.lua` implementa um **módulo de extensão** que adiciona métodos à classe `Item` do engine Canary. Todos os 15 métodos seguem o padrão de **method extension** do Lua via assignment direto na tabela de classe.

As funcionalidades podem ser categorizadas em **3 padrões**:

1. **Acesso e Tipagem**: `getType()`, 7 métodos `is*()` que retornam false
2. **Gerenciamento de Atributos**: `setDescription()`, `setText()`, `setName()`, `setUniqueId()`
3. **Estado Temporal**: `getDuration()`, `setDurationAttr()`, `stopDecay()`

### Estrutura de Funcionalidades

```
Item Module Extensions
├── Acesso ao Tipo
│   └── Item.getType() → ItemType
├── Validações de Tipo (sempre false)

│   ├── Item.isCreature() → false
│   ├── Item.isMonster() → false
│   ├── Item.isNpc() → false
│   ├── Item.isPlayer() → false
│   ├── Item.isTeleport() → false
│   └── Item.isTile() → false
├── Gerenciamento de Atributos
│   ├── Item.setDescription(description)
│   ├── Item.setText(text)

│   └── Item.setUniqueId(uniqueId) → boolean
└── Gerenciamento de Estado
    ├── Item.getDuration() → number
    ├── Item.setDurationAttr(duration) → boolean
    └── Item.stopDecay() → boolean
```

## 📋 Métodos de Extensão da Classe Item

### Acesso ao Tipo

#### `Item.getType(self)`

Retorna o objeto ItemType associado a este item.

**Tipo**: Method Extension  
**Parâmetros**:
- `self` (Item): Item atual (automaticamente passado com `:`)

**Retorna**: ItemType object

**Implementação**:
```lua
function Item.getType(self)
    return ItemType(self:getId())
end
```

**Exemplo**:
```lua
local item = Item(uid)
local itemType = item:getType()
print("Peso: " .. itemType:getWeight() .. " oz")
print("Descrição: " .. itemType:getDescription())
```

**Observações**:
- Wrapper conveniente para `ItemType(item:getId())`
- Retorna nil se itemId não existe
- Útil para acessar propriedades do ItemType sem chamar constructor manualmente

---

### Validações de Tipo (Type Checking)

Os 7 métodos seguintes sempre retornam `false` para items (diferente de Creatures):

#### `Item.isContainer(self)`
#### `Item.isCreature(self)`
#### `Item.isMonster(self)`
#### `Item.isNpc(self)`
#### `Item.isPlayer(self)`
#### `Item.isTeleport(self)`
#### `Item.isTile(self)`

**Tipo**: Method Extension  
**Parâmetros**: `self` (Item)  
**Retorna**: boolean (sempre false)

**Propósito**: Permitir código genérico que funciona com qualquer objeto (Item, Creature, Monster, etc).

**Exemplo de Uso Polimórfico**:
```lua
local function identify(obj)
    if obj:isPlayer() then
        print("É um jogador")
    elseif obj:isMonster() then
        print("É um monstro")
    elseif obj:isItem() then
        print("É um item")
    end
end

identify(Game.getPlayerByName("Player"))  -- Jogador
identify(Game.getCreatureById(123))       -- Monstro
identify(Item(456))                       -- Item
```

**Observação**:
- Complementam método nativo `item:isItem()` que retorna true
- Padrão duck-typing: toda classe suporta estes métodos
- Usados em código que precisa processar objetos de tipo desconhecido

## 🏷️ Gerenciamento de Atributos

### `Item.setDescription(self, description)`

Define ou remove descrição customizada do item.

**Tipo**: Method Extension  
**Parâmetros**:
- `self` (Item): Item
- `description` (string): Nova descrição

**Retorna**: void (modifica in-place)

**Implementação**:
```lua
function Item.setDescription(self, description)
    if description ~= "" then
        self:setAttribute(ITEM_ATTRIBUTE_DESCRIPTION, description)
    else
        self:removeAttribute(ITEM_ATTRIBUTE_DESCRIPTION)
    end
end
```

**Exemplos**:
```lua
local item = Item(uid)

-- Definir descrição
item:setDescription("An ancient sword with mysterious runes")

-- Remover descrição (string vazia)
item:setDescription("")
```

**Comportamento**:
- Se `description` é string vazia: remove atributo
- Se `description` tem conteúdo: define via setAttribute
- Permite descrições customizadas diferentes do ItemType padrão

### `Item.setUniqueId(self, uniqueId)`

Define unique ID do item com validação de range (0-65535).

**Tipo**: Method Extension  
**Parâmetros**:
- `self` (Item): Item
- `uniqueId` (number): Novo unique ID (0-65535)

**Retorna**: boolean (true se sucesso, false se valor inválido)

**Implementação**:
```lua
function Item.setUniqueId(self, uniqueId)
    if type(uniqueId) ~= "number" or uniqueId < 0 or uniqueId > 65535 then
        return false
    end
    self:setAttribute(ITEM_ATTRIBUTE_UNIQUEID, uniqueId)
end
```

**Exemplos**:
```lua
local item = Item(uid)

-- Definir unique ID válido
if item:setUniqueId(1234) then
    print("Unique ID definido com sucesso")
end

-- Tentar valor inválido
if not item:setUniqueId(100000) then
    print("Unique ID fora do range (0-65535)")
end
```

**Validações**:
- Tipo deve ser `number`
- Mínimo: 0
- Máximo: 65535 (0xFFFF)
- Retorna false para qualquer valor invalid

**Observação**: Unique IDs são usados para items que precisa de identificação única (chaves de quests, etc).

## ⏱️ Gerenciamento de Duração e Decay

### `Item.getDuration(self)`

Retorna a duração remanescente de um item (em segundos).

**Tipo**: Method Extension  
**Parâmetros**: `self` (Item)  
**Retorna**: number (segundos) ou nil

**Implementação**:
```lua
function Item.getDuration(self)
    return self:getAttribute(ITEM_ATTRIBUTE_DURATION)
end
```

**Exemplos**:
```lua
local item = Item(uid)
local remaining = item:getDuration()

if remaining then
    print("Item vai expirar em " .. remaining .. " segundos")
else
    print("Item não tem duração definida")
end
```

**Uso**: Items temporizados (buff items, food, poções com expire time).

---

### `Item.setDurationAttr(self, duration)`

Define a duração do item em segundos.

**Tipo**: Method Extension  
**Parâmetros**:
- `self` (Item): Item
- `duration` (number): Duração em segundos

**Retorna**: boolean (resultado do setAttribute)

**Implementação**:
```lua
function Item.setDurationAttr(self, duration)
    return self:setAttribute(ITEM_ATTRIBUTE_DURATION, duration)
end
```

**Exemplos**:
```lua
local food = Item(uid)

-- Food que expira em 2 horas
food:setDurationAttr(2 * 60 * 60)

-- Poção que expira em 5 minutos
local potion = Item(potionUid)
potion:setDurationAttr(5 * 60)
```

---

### `Item.stopDecay(self)`

Para o decay (deterioração) do item permanentemente.

**Tipo**: Method Extension  
**Parâmetros**: `self` (Item)  
**Retorna**: boolean (resultado do setAttribute)

**Implementação**:
```lua
function Item.stopDecay(self)
    return self:setAttribute(ITEM_ATTRIBUTE_DECAYSTATE, DECAYING_FALSE)
end
```

**Exemplos**:
```lua
local rare_item = Item(uid)

-- Parar decay de item raro
if rare_item:stopDecay() then
    print("Item será preservado permanentemente")
end
```

**Constante Usada**: `DECAYING_FALSE` (não deteriorar)

**Observação**:
- Items normalmente decaem se tiverem duração
- `stopDecay()` marca com estado de não-deterioração
- Útil para items de quest, decoração, ou itens únicos

## 🔄 Padrões de Uso

### Padrão 1: Criar Item Customizado

```lua
local function createCustomItem(itemId, position, name, description)
    local item = Game.createItem(itemId, 1, position)
    if not item then
        return false
    end
    
    if name and name ~= "" then
        item:setName(name)
    end
    
    if description and description ~= "" then
        item:setDescription(description)
    end
    
    return item
end

-- Uso
local sword = createCustomItem(
    2400,  -- Iron Sword ID
    Position(100, 100, 7),
    "Blade of the Ancient King",
    "A legendary sword passed down through generations"
)
```

### Padrão 2: Item Temporizado com Cleanup

```lua
local function createTemporaryReward(itemId, position, duration_seconds)
    local item = Game.createItem(itemId, 1, position)
    if not item then
        return false
    end
    
    item:setDurationAttr(duration_seconds)
    item:setDescription("This reward expires in " .. duration_seconds .. " seconds")
    
    -- Schedule removal
    addEvent(function()
        if item:isItem() then
            item:remove()
        end
    end, duration_seconds * 1000)
    
    return item
end

-- Uso: Recompensa que some em 1 hora
createTemporaryReward(2160, Position(100, 100, 7), 60 * 60)
```

### Padrão 3: Validação de Atributos

```lua
local function isValidQuestItem(item)
    if not item:isItem() then
        return false
    end
    
    local itemType = item:getType()
    if not itemType then
        return false
    end
    
    -- Validar unique ID
    if item:getAttribute(ITEM_ATTRIBUTE_UNIQUEID) == nil then
        return false
    end
    
    return true
end
```

## ✅ Checkpoint de Aprendizagem

### Conceitos Principais

1. **Method Extensions**: Adicionar métodos a classes nativas via assignment de função
2. **Atributos Customizáveis**: Items suportam descrição, texto, nome customizados
3. **Type Checking Polimórfico**: Código genérico que trabalha com qualquer tipo via `is*()` methods
4. **Guard Clauses com Remoção**: Remover atributo se valor vazio (vs manter null)

### Padrões Identificados

- **Wrapper Pattern**: `getType()` simplifica acesso a ItemType
- **Conditional Attribute Management**: Remover se vazio, definir se preenchido
- **Validation Pattern**: `setUniqueId()` valida range antes de definir
- **Polymorphic Interface**: Mesmo método em Item, Creature, Monster, etc

### Responsabilidades por Categoria

| Categoria | Método | Responsabilidade |
|-----------|--------|------------------|
| Acesso | getType() | Converter ID para ItemType |
| Tipagem | is*() methods | Permitir code polimórfico |
| Atributos | setDescription/Text/Name | Customizar propriedades do item |
| Validação | setUniqueId() | Validar range antes de definir |
| Temporal | Duration, Decay | Gerenciar items temporizados |

## 📚 Conclusão

O arquivo `item.lua` é um **módulo de conveniences** que encapsula operações comuns em Items, eliminando a necessidade de chamar `setAttribute()` e `removeAttribute()` diretamente no código. Seus 15 métodos cobrem 95% dos casos de uso reais.

O design com **conditional removal** (remover se vazio) permite que code seja declarativo: "quero descrição X" sem se preocupar com cleanup. O padrão de **method extension** torna a API natural: `item:setName()` ao invés de `setItemName(item)`.
