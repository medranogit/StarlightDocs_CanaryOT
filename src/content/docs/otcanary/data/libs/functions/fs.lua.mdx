## 🛠️ Informações do Arquivo

Módulo que implementa operações de sistema de arquivos de forma cross-platform. Fornece funções para verificar existência de arquivos, criar diretórios simples e criar estruturas de diretórios recursivamente com suporte a caminhos com separadores misto (/ e \).

<Aside type="tip">
O módulo `FS` (File System) encapsula operações de I/O de forma segura e testável, permitindo que o código Lua não dependa de chamadas diretas a `os.execute()`. Útil para inicialização de estruturas de diretórios e validação de arquivos de configuração.
</Aside>

## 📄 Visão Geral do Código

### Resumo Executivo

O arquivo `fs.lua` implementa um **módulo namespace** que centraliza operações comuns de sistema de arquivos. Ao contrário de usar `os.execute()` diretamente em todo o código, o módulo `FS` fornece abstrações que retornam resultados padronizados com tratamento de erro.

As funções implementam o **padrão de API consistente**:
- Retornam `boolean` para sucesso/falha
- Retornam `(boolean, string)` para operações com mensagem de erro
- Usam caminho como primeiro parâmetro

### Estrutura de Funcionalidades

```
FS Module (Namespace para Operações de Arquivo)
├── FS.exists(path) → boolean
│   └── Verifica existência de arquivo/diretório
├── FS.mkdir(path) → boolean | (boolean, string)
│   └── Cria diretório único
└── FS.mkdir_p(path) → boolean | (boolean, string)
    └── Cria estrutura de diretórios recursivamente
```

## 📋 Funções Globais do Módulo FS

### `FS.exists(path)`

Verifica se um arquivo ou diretório existe no sistema de arquivos.

**Tipo**: Função Global do Módulo  
**Parâmetros**:
- `path` (string): Caminho do arquivo/diretório a verificar

**Retorna**: boolean (true se existe, false caso contrário)

**Implementação**:
```lua
function FS.exists(path)
    local file = io.open(path, "r")
    if file then
        file:close()
        return true
    end
    return false
end
```

**Exemplos**:
```lua
-- Verificar arquivo de configuração
if FS.exists("config.lua") then
    print("Arquivo de config encontrado")
end

-- Verificar diretório de logs
if FS.exists("logs/") then
    print("Diretório de logs existe")
end
```

**Observações**:
- Tenta abrir em modo leitura ("r")
- Fecha o arquivo imediatamente se abrir com sucesso
- Não distingue entre arquivo e diretório
- Safe: usa `io.open` ao invés de `os.execute`

---

### `FS.mkdir(path)`

Cria um único diretório no caminho especificado.

**Tipo**: Função Global do Módulo  
**Parâmetros**:
- `path` (string): Caminho do diretório a criar

**Retorna**: 
- `boolean`: true se sucesso, false se falha
- `(boolean, string)`: Retorna (false, erro) se `os.execute` falhar

**Implementação**:
```lua
function FS.mkdir(path)
    if FS.exists(path) then
        return true
    end
    local success, err = os.execute('mkdir "' .. path .. '"')
    if not success then
        return false, err
    end
    return true
end
```

**Exemplo**:
```lua
-- Criar diretório simples
if FS.mkdir("logs") then
    print("Diretório 'logs' criado com sucesso")
else
    print("Falha ao criar diretório")
end

-- Usar como estrutura
local success, err = FS.mkdir("temp")
if not success then
    print("Erro: " .. tostring(err))
end
```

**Comportamento**:
- Retorna true imediatamente se diretório já existe
- Usa `os.execute('mkdir ...')` para criação real
- Citações duplas no caminho previnem problemas com espaços
- **Limitação**: Não cria diretórios pai (use `mkdir_p` para isso)

### `FS.mkdir_p(path)`

Cria uma estrutura de diretórios completa, similar a `mkdir -p` em Unix/Linux.

**Tipo**: Função Global do Módulo  
**Parâmetros**:
- `path` (string): Caminho completo da estrutura a criar (pode incluir múltiplos níveis)

**Retorna**: 
- `boolean`: true se sucesso
- `(boolean, string)`: (false, erro) se algum `mkdir` falhar

**Implementação**:
```lua
function FS.mkdir_p(path)
    if path == "" then
        return true
    end

    local components = {}
    for component in path:gmatch("[^/\\]+") do
        table.insert(components, component)
    end

    local currentPath = ""
    for i, component in ipairs(components) do
        currentPath = currentPath .. component

        if not FS.exists(currentPath) then
            local success, err = FS.mkdir(currentPath)
            if not success then
                return false, err
            end
        end

        if i < #components then
            currentPath = currentPath .. "/"
        end
    end

    return true
end
```

**Exemplos**:
```lua
-- Criar estrutura completa
if FS.mkdir_p("logs/2024/february") then
    print("Estrutura de diretórios criada")
end

-- Com caminho misto separadores
FS.mkdir_p("data\\world\\quests\\tibia_tales")

-- Tratar erros
local success, err = FS.mkdir_p("reports/failed/analysis")
if not success then
    print("Erro ao criar estrutura: " .. tostring(err))
else
    print("Structure created: reports/failed/analysis")
end
```

**Algoritmo**:
1. Retorna true se caminho vazio
2. Parse componentes usando regex `[^/\\]+` (qualquer coisa que não seja `/` ou `\`)
3. Iterar cada componente, acumulando caminho
4. Para cada componente, verificar se existe com `FS.exists()`
5. Se não existe, chamar `FS.mkdir()` para criar
6. Se `mkdir` falhar, retornar erro imediatamente
7. Acumular separador `/` entre componentes

**Características**:
- Suporta separadores misto: `data/world\quests/tibia` funciona
- Idempotente: chamar multiple times é seguro (detecta existência)
- Falha rápida: retorna false no primeiro erro
- Usa apenas forward slashes `/` internamente (normalizar)

## 🔧 Padrões de Uso

### Padrão 1: Validação Pré-Operação

```lua
-- Antes de escrever arquivo
if not FS.mkdir_p("logs") then
    logger.error("Falha ao criar diretório de logs")
    return false
end

local file = io.open("logs/game.log", "a")
io.output(file)
io.write("Game started at " .. os.date() .. "\n")
io.close()
```

### Padrão 2: Inicialização de Estrutura

```lua
local requiredDirs = {
    "logs",
    "reports/bugs",
    "reports/suggestions",
    "data/worlds",
    "data/quests/my_quest"
}

for _, dir in ipairs(requiredDirs) do
    if not FS.mkdir_p(dir) then
        print("Failed to initialize: " .. dir)
        return false
    end
end

print("All directories initialized")
```

### Padrão 3: Configuração Condicional

```lua
local configPath = "config/game.lua"
if FS.exists(configPath) then
    dofile(configPath)
else
    -- Criar estrutura e usar padrões
    FS.mkdir_p("config")
    -- Gerar config padrão
end
```

## ✅ Checkpoint de Aprendizagem

### Conceitos Principais

1. **Encapsulamento de I/O**: Abstrair `os.execute()` em funções reutilizáveis
2. **Idempotência**: Operações seguras para executar múltiplas vezes
3. **Tratamento de Erro Consistente**: Sempre retornar (success, error) para falhas
4. **Parsing de Caminho**: Usar regex para separadores misto (/ e \)

### Padrões Identificados

- **Wrapper Pattern**: Encapsula `io.open` e `os.execute` para interface unificada
- **Guard Clause**: Retorna early se caminho já existe
- **Recursive Build**: Constrói caminhos incrementalmente

### Casos de Uso

| Caso | Função | Exemplo |
|------|--------|---------|
| Verificar configuração | `FS.exists` | Detectar arquivo config.lua |
| Criar único diretório | `FS.mkdir` | Criar pasta "logs" |
| Criar hierarquia | `FS.mkdir_p` | Criar "logs/2024/february" |
| Inicializar app | `mkdir_p` | Setup estrutura no boot |

## 📚 Conclusão

O módulo `fs.lua` é uma **camada abstraída de segurança** para operações de sistema de arquivos, eliminando a necessidade de chamar `os.execute()` diretamente no código. Suas 3 funções cobrem 95% dos casos de uso reais: existência, criação simples e criação recursiva.
