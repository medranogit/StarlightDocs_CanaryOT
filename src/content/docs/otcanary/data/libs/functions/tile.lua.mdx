## 🚚 Relocation

### `Tile.relocateTo(toPosition)` → boolean

Move todos items/creatures do tile para nova posição.

**Tipo**: Função estendida  
**Parâmetros**: toPosition (Position): Posição destino  
**Retorna**: boolean (true se bem-sucedido)

**Validações**:
- Se position == toPosition: return false
- Se destination tile não existe: return false

**Lógica de Relocation**:
```lua
for i = self:getThingCount() - 1, 0, -1 do
	local thing = self:getThing(i)
	if thing then
		if thing:isItem() then
			if thing:getFluidType() ~= 0 then
				thing:remove()  -- Fluids removidos
			elseif ItemType(thing:getId()):isMovable() then
				thing:moveTo(toPosition)  -- Items móveis movem
			end
		elseif thing:isCreature() then
			thing:teleportTo(toPosition)  -- Criaturas teleportam
		end
	end
end
```

**Fluxo**:
1. Loop backward (getThingCount - 1 para 0)
2. Se item e fluid: remove
3. Se item e movable: move
4. Se creature: teleport

**Exemplo**:
```lua
local fromPos = Position(100, 100, 7)
local toPos = Position(150, 150, 7)

local fromTile = Tile(fromPos)
if fromTile:relocateTo(toPos) then
	print("Tile relocado com sucesso!")
else
	print("Falha na relocation")
end
```

## 🚶 Walkability Validation

### `Tile.isWalkable(pz, creature, floorchange, block, proj)` → boolean

Validação complexa se tile é walkable.

**Tipo**: Função estendida  
**Parâmetros**:
- pz (boolean|nil): Check protection zone?
- creature (boolean|nil): Check creatures?
- floorchange (boolean|nil): Check floor changes?
- block (boolean|nil): Check path blocking?
- proj (boolean|nil): Check projectile blocking?

**Retorna**: boolean

**Validações Sequenciais**:

```lua
-- 1. Null check
if not self then return false end

-- 2. Ground existence
if not self:getGround() then return false end

-- 3. Solid properties
if self:hasProperty(CONST_PROP_BLOCKSOLID) or 
   self:hasProperty(CONST_PROP_BLOCKPROJECTILE) then
	return false
end

-- 4. Immovable solid
if self:hasProperty(CONST_PROP_IMMOVABLEBLOCKSOLID) then
	return false
end

-- 5. PZ/House check
if pz and (self:hasFlag(TILESTATE_HOUSE) or 
           self:hasFlag(TILESTATE_PROTECTIONZONE)) then
	return false
end

-- 6. Creature collision
if creature and self:getTopCreature() ~= nil then
	return false
end

-- 7. Floor change check
if floorchange and self:hasFlag(TILESTATE_FLOORCHANGE) then
	return false
end

-- 8. Path blocking
if block then
	if self:hasProperty(CONST_PROP_BLOCKPATH) or 
	   self:hasProperty(CONST_PROP_IMMOVABLEBLOCKPATH) or
	   self:hasProperty(CONST_PROP_IMMOVABLENOFIELDBLOCKPATH) or
	   self:hasProperty(CONST_PROP_NOFIELDBLOCKPATH) then
		return false
	end
	local topStackItem = self:getTopTopItem()
	if topStackItem and topStackItem:hasProperty(CONST_PROP_BLOCKPATH) then
		return false
	end
end

-- 9. Projectile blocking
if proj then
	local items = self:getItems()
	if #items > 0 then
		for i = 1, #items do
			local itemType = ItemType(items[i])
			local blockSolid = items[i]:hasProperty(CONST_PROP_BLOCKSOLID)
			local blockProjectile = items[i]:hasProperty(CONST_PROP_BLOCKPROJECTILE)
			if itemType:getType() ~= ITEM_TYPE_MAGICFIELD and 
			   not itemType:isMovable() and 
			   (blockSolid or blockProjectile) then
				return false
			end
		end
	end
end

return true
```

**Exemplo**:
```lua
local tile = Tile(position)

-- Check full walkability (all flags)
if tile:isWalkable(true, true, true, true, true) then
	print("Tile completamente walkable")
end

-- Check basic walkability (sem PZ check)
if tile:isWalkable(false, true, false, true, true) then
	print("Tile walkable (fora de PZ)")
end

-- Check se pode lançar spell (projectile blocking)
if tile:isWalkable(false, false, false, false, true) then
	print("Projectile passível")
end
```

## 🪢 Rope Spots

### `Tile.isRopeSpot()` → boolean

Verifica se tile é um rope spot (pode fazer rope climb).

**Tipo**: Função estendida  
**Retorna**: boolean

**Implementação**:
```lua
function Tile:isRopeSpot()
	if not self then
		return false
	end

	if not self:getGround() then
		return false
	end

	-- Check ground item IDs
	if table.contains(ropeSpots, self:getGround():getId()) then
		return true
	end

	-- Check stacked items
	for i = 1, self:getTopItemCount() do
		local thing = self:getThing(i)
		if thing and table.contains(specialRopeSpots, thing:getId()) then
			return true
		end
	end

	return false
end
```

**Validações**:
1. Null check
2. Ground existence check
3. Ground ID in ropeSpots table
4. Loop stacked items para specialRopeSpots

**Variáveis Globais Esperadas**:
- ropeSpots (table): IDs de ground items
- specialRopeSpots (table): IDs de special rope items

**Exemplo**:
```lua
local tile = Tile(position)
if tile:isRopeSpot() then
	player:say("Você pode fazer rope climb aqui!")
end
```

### Padrão 5: Movement with Validation

function moveCreatureSafe(creature, toPos)

	if not toTile then
		creature:say("Posição inválida!")

		return false

	return true

### Padrão 6: Rope Spot Detection with Climbing

```lua
function tryRopeClimb(creature, direction)
	local currentPos = creature:getPosition()
	local ropePos = Position(currentPos.x + direction.x, currentPos.y + direction.y, currentPos.z + direction.z)
	
	local ropeTile = Tile(ropePos)
	if ropeTile:isRopeSpot() then
		-- Climb up or down
		local newZ = currentPos.z - 1  -- Climbing up (Z diminui)
		creature:moveTo(Position(ropePos.x, ropePos.y, newZ))
		return true
	else
		creature:say("Sem rope spot para escalar!")
		return false
	end
end
```
