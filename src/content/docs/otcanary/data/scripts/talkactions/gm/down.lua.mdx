## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `down.lua` implementa um comando TalkAction (`/down`) que permite gamemasters mover-se um andar abaixo mantendo as coordenadas X e Y. O sistema obtém a posição atual do jogador, incrementa sua coordenada Z em 1 (representando movimento vertical para nível inferior), e teleporta instantaneamente. Comando utilitário simples sem parâmetros adicionais, efeitos visuais ou validações de destino.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Instanciação do TalkAction
local down = TalkAction("/down")

-- 2. Função Principal (onSay)
function down.onSay(player, words, param)
    -- Log automático do comando
    logCommand(player, words, param)
    
    -- Obter posição atual
    local position = player:getPosition()
    
    -- Incrementar Z (mover andar abaixo)
    -- Em Tibia: Z maior = nível mais baixo
    position.z = position.z + 1
    
    -- Teleportar para nova posição
    player:teleportTo(position)
    
    return true
end

-- 3. Configuração de Registro
down:separator(" ")
down:groupType("gamemaster")
down:register()
```

## 🤖 Documentação das Funções

### **down.onSay(player, words, param)**

**Descrição:** Função callback executada quando o comando `/down` é utilizado. Teleporta o jogador um andar abaixo mantendo coordenadas horizontais.

**Parâmetros:**
- `player` (Player): Jogador que executou o comando
- `words` (string): Palavras do comando (`/down`)
- `param` (string): Parâmetros adicionais (não utilizado)

**Fluxo de Execução:**
1. Registra comando em log via `logCommand(player, words, param)`
2. Obém posição atual: `position = player:getPosition()`
3. Incrementa coordenada Z: `position.z = position.z + 1`
4. Teleporta: `player:teleportTo(position)`
5. Retorna sucesso

**Modificação de Coordenadas:**
```
Antes: Position(X=100, Y=200, Z=6)
Depois: Position(X=100, Y=200, Z=7)
```

**Comportamento Especial:**
- Mantém coordenadas X e Y inalteradas
- Incrementa apenas Z (altura/andar)
- Teleportação é instantânea
- Sem efeitos visuais ou validações

**Retorno:** `true` (comando executado com sucesso)
