## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `mc_check.lua` implementa um comando TalkAction (`/mc`) que detecta e lista suspeitas de multiclient no servidor. O sistema itera todos os jogadores, agrupa por IP em hash map, filtra IPs com múltiplas contas (> 1), formata lista legível com nome e level de cada jogador, e envia resultado via MESSAGE_ADMINISTRATOR. Ferramenta de auditoria essencial para identificar abuso de multiclient.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Instanciação do TalkAction
local mcCheck = TalkAction("/mc")

-- 2. Função Principal (onSay)
function mcCheck.onSay(player, words, param)
    -- Log automático do comando
    logCommand(player, words, param)
    
    -- Enviar header
    player:sendTextMessage(MESSAGE_ADMINISTRATOR, "Multiclient Check List:")
    
    -- Hash map de IPs -> lista de jogadores
    local ipList = {}
    
    -- Obter todos os jogadores online
    local players = Game.getPlayers()
    
    -- Iterar cada jogador
    for i = 1, #players do
        local tmpPlayer = players[i]
        local ip = tmpPlayer:getIp()
        
        -- Filtrar IPs válidos (não zero)
        if ip ~= 0 then
            -- Inicializar lista para IP se não existe
            local list = ipList[ip]
            if not list then
                ipList[ip] = {}
                list = ipList[ip]
            end
            
            -- Adicionar jogador à lista do IP
            list[#list + 1] = tmpPlayer
        end
    end
    
    -- Iterar cada IP e seus jogadores
    for ip, list in pairs(ipList) do
        local listLength = #list
        
        -- Filtrar: apenas IPs com mais de 1 jogador (multiclient)
        if listLength > 1 then
            -- Primeiro jogador (base da mensagem)
            local tmpPlayer = list[1]
            local message = ("%s: %s [%d]"):format(
                Game.convertIpToString(ip),     -- Converter IP para string
                tmpPlayer:getName(),             -- Nome
                tmpPlayer:getLevel()             -- Level
            )
            
            -- Adicionar todos os jogadores adicionais
            for i = 2, listLength do
                tmpPlayer = list[i]
                message = ("%s, %s [%d]"):format(
                    message,
                    tmpPlayer:getName(),
                    tmpPlayer:getLevel()
                )
            end
            
            -- Enviar mensagem formatada
            player:sendTextMessage(MESSAGE_ADMINISTRATOR, message .. ".")
        end
    end
    
    return true
end

-- 3. Configuração de Registro
mcCheck:separator(" ")
mcCheck:groupType("gamemaster")
mcCheck:register()
```
