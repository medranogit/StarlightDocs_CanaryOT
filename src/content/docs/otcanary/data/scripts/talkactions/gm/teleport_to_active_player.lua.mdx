## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `teleport_to_active_player.lua` implementa um comando TalkAction (`/active`) que teleporta gamemasters para um jogador ativo aleatório. O sistema itera todos os jogadores online, filtra por 3 critérios (não-ghost, não-training, não-AFK), agrupa em lista de ativos, seleciona aleatoriamente um deles, e teleporta. Ferramenta de navegação rápida para localar jogadores ativos.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Instanciação do TalkAction
local teleportToCreature = TalkAction("/active")

-- 2. Função Principal (onSay)
function teleportToCreature.onSay(player, words, param)
    -- Log automático do comando
    logCommand(player, words, param)
    
    -- Obter todos os jogadores
    local players = Game.getPlayers()
    local activePlayers = {}
    
    -- Iterar e filtrar ativos
    for _, targetPlayer in ipairs(players) do
        -- Critério 1: Não em ghost mode
        local isGhost = targetPlayer:isInGhostMode()
        
        -- Critério 2: Não em training
        local isTraining = _G.OnExerciseTraining[targetPlayer:getId()]
        
        -- Critério 3: Não AFK (idle >= 5 minutos)
        local isIdle = targetPlayer:getIdleTime() >= 5 * 60 * 1000  -- 5 min em ms
        
        -- Determinar se ativo
        local isActive = not isGhost and not isTraining and not isIdle
        
        -- Adicionar à lista se ativo
        if isActive then
            table.insert(activePlayers, targetPlayer)
        end
    end
    
    -- Validação: se há jogadores ativos
    if #activePlayers == 0 then
        player:sendCancelMessage("There are no active players.")
        return true
    end
    
    -- Selecionar aleatório
    local targetPlayer = activePlayers[math.random(#activePlayers)]
    
    -- Teleportar
    player:teleportTo(targetPlayer:getPosition())
    
    return true
end

-- 3. Configuração de Registro
teleportToCreature:separator(" ")
teleportToCreature:groupType("gamemaster")
teleportToCreature:register()
```

## 🤖 Documentação das Funções

### **teleportToCreature.onSay(player, words, param)**

**Descrição:** Função callback executada quando o comando `/active` é utilizado. Teleporta para jogador ativo aleatório.

**Parâmetros:**
- `player` (Player): Jogador que executará o comando (GM)
- `words` (string): Palavras do comando (`/active`)
- `param` (string): Parâmetros adicionais (não utilizado)

**Fluxo de Execução:**

1. **Log do Comando:**
   - `logCommand(player, words, param)` registra uso

2. **Obtenção de Jogadores:**
   ```lua
   local players = Game.getPlayers()
   ```
   - Array de todos jogadores online

3. **Filtragem de Jogadores Ativos:**
   ```lua
   for _, targetPlayer in ipairs(players) do
       local isGhost = targetPlayer:isInGhostMode()
       local isTraining = _G.OnExerciseTraining[targetPlayer:getId()]
       local isIdle = targetPlayer:getIdleTime() >= 5 * 60 * 1000
       local isActive = not isGhost and not isTraining and not isIdle
   ```

4. **Critérios de Atividade:**

   | Critério | Tipo | Descrição |
   |---|---|---|
   | **Ghost Mode** | boolean | Se verdadeiro: invisível (exclui) |
   | **Training** | table lookup | Se em `_G.OnExerciseTraining`: excluir |
   | **Idle Time** | number (ms) | Se >= 300.000ms (5 min): AFK (exclui) |

5. **Agregação de Ativos:**
   ```lua
   if isActive then
       table.insert(activePlayers, targetPlayer)
   end
   ```

6. **Validação de Lista Vazia:**
   ```lua
   if #activePlayers == 0 then
       player:sendCancelMessage("There are no active players.")
       return true
   end
   ```

7. **Seleção Aleatória:**
   ```lua
   local targetPlayer = activePlayers[math.random(#activePlayers)]
   ```
   - `math.random(n)` retorna inteiro entre 1 e n
   - Acessa jogador aleatório da lista

8. **Teleportação:**
   ```lua
   player:teleportTo(targetPlayer:getPosition())
   ```

**Exemplo de Cenário:**

```
Online:
- Player1 (ativo, olhando mapa)
- Player2 (ghost mode) <- Excluído
- Player3 (training) <- Excluído
- Player4 (AFK 10 min) <- Excluído
- Player5 (ativo, matando monstros)

Ativos: [Player1, Player5]
Resultado: Teleporta para Player1 ou Player5 aleatoriamente
```

**Funções Globais Utilizadas:**

| Função | Descrição |
|---|---|
| `Game.getPlayers()` | Retorna array todos jogadores |
| `targetPlayer:isInGhostMode()` | Verifica ghost mode |
| `_G.OnExerciseTraining[]` | Lookup de jogadores em training |
| `targetPlayer:getId()` | Obtém ID do jogador |
| `targetPlayer:getIdleTime()` | Tempo em ms desde última ação |
| `math.random(max)` | Inteiro aleatório 1..max |
| `player:teleportTo()` | Teleporta |

**Retorno:** `true` (comando executado com sucesso)

### **Variáveis Globais Utilizadas**

**`_G.OnExerciseTraining`**

- Tabela global de controle
- `_G.OnExerciseTraining[playerId]` = true se em training
- Gerenciado por sistema de training do servidor
