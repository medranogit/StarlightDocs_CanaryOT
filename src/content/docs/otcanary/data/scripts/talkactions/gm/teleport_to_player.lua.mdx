## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `teleport_to_player.lua` implementa um comando TalkAction (`/listplayers`) que oferece seleção interativa de jogadores via modal window. O sistema itera jogadores, filtra por 4 critérios (ghost, training, AFK, training room) ou mostra todos se `param == "all"`, cria interface modal com callbacks que teleportam ao selecionado. Ferramenta de navegação visual intuitiva.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Instanciação do TalkAction
local teleportToCreature = TalkAction("/listplayers")

-- 2. Função Principal (onSay)
function teleportToCreature.onSay(player, words, param)
    -- Log automático do comando
    logCommand(player, words, param)
    
    -- Modo: "all" mostra todos, senão apenas ativos
    local showAll = param == "all" and true or false
    
    -- Obter jogadores online
    local players = Game.getPlayers()
    local playerList = {}
    
    -- Iterar e filtrar
    for _, targetPlayer in ipairs(players) do
        -- Excluir o próprio jogador
        if targetPlayer:getName() == player:getName() then
            goto continue
        end
        
        -- Decidir se adiciona à lista
        if showAll then
            -- Modo "all": inclui todos
            table.insert(playerList, targetPlayer)
        else
            -- Modo filtrado: apenas ativos
            local isGhost = targetPlayer:isInGhostMode()
            local isTraining = _G.OnExerciseTraining[targetPlayer:getId()]
            local isIdle = targetPlayer:getIdleTime() >= 5 * 60 * 1000
            local isInTrainingRoom = targetPlayer:getPosition():isInRange(
                Position(1015, 1109, 7), 
                Position(1094, 1738, 7)
            )
            local isActive = not isGhost and not isTraining and 
                             not isIdle and not isInTrainingRoom
            if isActive then
                table.insert(playerList, targetPlayer)
            end
        end
        
        ::continue::
    end
    
    -- Validação: lista vazia
    if #playerList == 0 then
        player:sendCancelMessage("There are no active players.")
        return true
    end
    
    -- Criar modal window
    local window = ModalWindow({
        title = "Teleport to Player",
        message = "select player to teleport",
    })
    
    -- Adicionar cada jogador como choice
    for _, targetPlayer in pairs(playerList) do
        if targetPlayer then
            window:addChoice(targetPlayer:getName(), function(player, button, choice)
                -- Callback executado quando jogador seleciona este jogador
                if button.name ~= "Select" then
                    return true  -- Ignorar se clicou em outro botão
                end
                -- Teleportar para o jogador selecionado
                player:teleportTo(targetPlayer:getPosition())
            end)
        end
    end
    
    -- Adicionar botões de ação
    window:addButton("Select")
    window:addButton("Close")
    
    -- Configurar default buttons
    window:setDefaultEnterButton(0)  -- Enter = Select (index 0)
    window:setDefaultEscapeButton(1) -- Escape = Close (index 1)
    
    -- Exibir modal para o jogador
    window:sendToPlayer(player)
    
    return true
end

-- 3. Configuração de Registro
teleportToCreature:separator(" ")
teleportToCreature:groupType("gamemaster")
teleportToCreature:register()
```

## 🤖 Documentação das Funções

### **teleportToCreature.onSay(player, words, param)**

**Descrição:** Função callback executada quando o comando `/listplayers` é utilizado. Exibe modal window de seleção de jogadores.

**Parâmetros:**
- `player` (Player): Jogador que executará o comando
- `words` (string): Palavras do comando (`/listplayers`)
- `param` (string): Modo (vazio = filtrado, "all" = todos)

**Formato de Comando:**
```
/listplayers              -- Mostra apenas jogadores ativos
/listplayers all          -- Mostra todos os jogadores online
```

**Fluxo de Execução:**

1. **Log do Comando:**
   - `logCommand(player, words, param)` registra uso

2. **Determinar Modo:**
   ```lua
   local showAll = param == "all" and true or false
   ```

3. **Obter Jogadores:**
   ```lua
   local players = Game.getPlayers()
   ```

4. **Filtração:**
   ```lua
   if targetPlayer:getName() == player:getName() then
       goto continue  -- Pula o próprio jogador
   end
   ```

5. **Modo "all" - Incluir Todos:**
   ```lua
   if showAll then
       table.insert(playerList, targetPlayer)
   else
       -- Modo filtrado (ver abaixo)
   end
   ```

6. **Modo Filtrado - 4 Critérios:**

   |---|---|---|
   | Ghost Mode | boolean | Invisível (exclui) |

   ```lua
               if button.name ~= "Select" then
   ```


### **ModalWindow - Estrutura de Callbacks**

**Closure em Callbacks:**

```lua
window:addChoice(targetPlayer:getName(), function(player, button, choice)
    -- Captura 'targetPlayer' do escopo externo (closure)
    player:teleportTo(targetPlayer:getPosition())
end)
```

- Cada choice recebe seu próprio callback
- Closure permite manter referência do jogador específico
- Callback recebe: player (GM), button (objeto do botão), choice (índice da choice)
