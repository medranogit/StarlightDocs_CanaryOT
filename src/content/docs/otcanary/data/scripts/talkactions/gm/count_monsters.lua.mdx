## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `count_monsters.lua` implementa um comando TalkAction (`/countmonsters`) que analisa o arquivo de definição de monstros XML do servidor e gera um relatório detalhado. O sistema abre o arquivo XML, parsa todas as ocorrências de `<monster name="...">` usando regex global, agrupa nomes duplicados e conta frequências, ordena alfabeticamente com `pairsByKeys()`, e escreve relatório em arquivo de texto local com contagem individual e total de monstros.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Constantes de Caminho
local xml_monster_dir = DATA_DIRECTORY .. "/world/otservbr-monster.xml"
local new_file_name = "monster_count.txt"

-- 2. Instanciação do TalkAction
local count_monsters = TalkAction("/countmonsters")

-- 3. Função Principal (onSay)
function count_monsters.onSay(player, words, param)
    -- Log automático do comando
    logCommand(player, words, param)
    
    -- Abertura de arquivos
    local open_file = io.open(xml_monster_dir, "r")          -- Leitura
    local writing_file = io.open(new_file_name, "w+")        -- Escrita (criar/limpar)
    local file_read = open_file:read("*all")                 -- Ler todo conteúdo
    open_file:close()                                         -- Fechar leitura
    
    -- Tabela de contagem
    local monsters = {}
    
    -- Parse de XML usando gmatch (regex global)
    -- Padrão: '<monster name="(.-)"'
    -- Captura: qualquer texto entre name=" e "
    for str_match in file_read:gmatch('<monster name="(.-)"') do
        local ret_table = monsters[str_match]
        if ret_table then
            -- Já existe, incrementar contador
            monsters[str_match] = ret_table + 1
        else
            -- Primeira ocorrência, inicializar
            monsters[str_match] = 1
        end
    end
    
    -- Inicializar arquivo com header
    writing_file:write("--- Monsters on Server ---\n")
    
    -- Variável de total
    local total = 0
    
    -- Iterar com pairsByKeys para ordenação alfabética
    for monster, count in pairsByKeys(monsters) do
        -- Escrever cada monstro com sua contagem
        writing_file:write(monster .. " - " .. count .. "\n")
        -- Acumular total
        total = total + count
    end
    
    -- Mensagem de resultado
    local outputMsg = "Total of monsters on server: " .. total
    
    -- Escrever footer com total
    writing_file:write("\n" .. outputMsg .. "\n------------------------")
    writing_file:close()
    
    -- Log no console do servidor
    logger.info(outputMsg)
    
    return true
end

-- 4. Configuração de Registro
count_monsters:separator(" ")
count_monsters:groupType("gamemaster")
count_monsters:register()
```

   end

4. **Contagem de Frequência:**

   if monsters[str_match] then
