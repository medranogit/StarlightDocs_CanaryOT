## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `up.lua` implementa um comando TalkAction (`/up`) que move gamemasters um andar acima mantendo coordenadas horizontais. O sistema obtém posição atual, decrementa Z em 1 (representando nível superior), e teleporta. Comando complementar ao `/down` para navegação vertical simples.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Instanciação do TalkAction
local up = TalkAction("/up")

-- 2. Função Principal (onSay)
function up.onSay(player, words, param)
    -- Log automático do comando
    logCommand(player, words, param)
    
    -- Obter posição atual
    local position = player:getPosition()
    
    -- Decrementar Z (subir um andar)
    position.z = position.z - 1
    
    -- Teleportar para nova posição
    player:teleportTo(position)
    
    return true
end

-- 3. Configuração de Registro
up:separator(" ")
up:groupType("gamemaster")
up:register()
```

## 🤖 Documentação das Funções

### **up.onSay(player, words, param)**

**Descrição:** Função callback executada quando o comando `/up` é utilizado. Teleporta o jogador um andar acima mantendo coordenadas horizontais.

**Parâmetros:**
- `player` (Player): Jogador que executará o comando
- `words` (string): Palavras do comando (`/up`)
- `param` (string): Parâmetros adicionais (não utilizado)

**Fluxo de Execução:**

1. **Log do Comando:**
   - `logCommand(player, words, param)` registra uso

2. **Obtenção de Posição:**
   ```lua
   local position = player:getPosition()
   ```

3. **Decremento de Z:**
   ```lua
   position.z = position.z - 1
   ```
   - Em Tibia: Z menor = nível mais alto
   - Z maior = nível mais baixo

4. **Teleportação:**
   ```lua
   player:teleportTo(position)
   ```

**Modificação de Coordenadas:**
```
Antes: Position(X=100, Y=200, Z=7)
Depois: Position(X=100, Y=200, Z=6)
```

**Comportamento Especial:**
- Mantém coordenadas X e Y inalteradas
- Decrementa apenas Z (altura/andar)
- Teleportação é instantânea
- Sem efeitos visuais ou validações

**Comparação com /down:**

| Comando | Efeito | Z Anterior | Z Novo |
|---|---|---|---|
| `/up` | Sobe andar | 7 | 6 |
| `/down` | Desce andar | 7 | 8 |

**Retorno:** `true` (comando executado com sucesso)

## 📌 Resumo

O arquivo `up.lua` é comando GM minimalista para navegação vertical superior. Implementação inversa de `/down` que decrementa Z em vez de incrementar. Essencial para GMs navegarem entre andares bidirecionalmente sem sair da posição horizontal. Sem validações ou efeitos, ideal para eficiência e rapidez.
