## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `magic_effect.lua` implementa um comando TalkAction (`/effect`) que permite gamemasters enviar qualquer efeito mágico na posição atual. O sistema valida parâmetro com conversão numérica, verifica se ID positivo, obtém posição do jogador, e envia efeito via `sendMagicEffect()`. Implementação minimalista focada em testes rápidos sem validações granulares ou restrições de ID.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Instanciação do TalkAction
local magicEffect = TalkAction("/effect")

-- 2. Função Principal (onSay)
function magicEffect.onSay(player, words, param)
    -- Log automático do comando
    logCommand(player, words, param)
    
    -- Validação de parâmetro vazio
    if param == "" then
        player:sendCancelMessage("Command param required.")
        return true
    end
    
    -- Converter parâmetro para número
    local effect = tonumber(param)
    
    -- Validação: numérico e positivo
    if effect ~= nil and effect > 0 then
        -- Obter posição e enviar efeito
        player:getPosition():sendMagicEffect(effect)
    end
    
    return true
end

-- 3. Configuração de Registro
magicEffect:separator(" ")
magicEffect:groupType("gamemaster")
magicEffect:register()
```

## 🤖 Documentação das Funções

### **magicEffect.onSay(player, words, param)**

**Descrição:** Função callback executada quando o comando `/effect` é utilizado. Envia efeito mágico na posição do jogador.

**Parâmetros:**
- `player` (Player): Jogador que executará o comando
- `words` (string): Palavras do comando (`/effect`)
- `param` (string): **[OBRIGATÓRIO]** ID numérico do efeito (> 0)

**Fluxo de Execução:**

1. **Log do Comando:**
   - `logCommand(player, words, param)` registra uso

2. **Validação de Parâmetro Vazio:**
   - Se param == "", retorna "Command param required."

3. **Conversão para Número:**
   ```lua
   local effect = tonumber(param)
   ```
   - Se conversão falhar: `effect = nil`
   - Se conversão suceder: `effect` contém número

4. **Validação de Validez:**
   ```lua
   if effect ~= nil and effect > 0 then
       -- Válido: enviar efeito
   else
       -- Inválido: silencioso (sem feedback)
   end
   ```
   - Condições:
     - `effect ~= nil` - Parâmetro é numérico
     - `effect > 0` - ID positivo (> 0)

5. **Envio de Efeito:**
   ```lua
   player:getPosition():sendMagicEffect(effect)
   ```
   - Obtém posição: `player:getPosition()`
   - Envia efeito naquela posição
   - Visível para todos os spectadores próximos

**Comportamento:**

| Entrada | Ação | Resultado |
|---|---|---|
| `/effect` | Vazio | "Command param required." |
| `/effect abc` | Não numérico | Silencioso (sem ação) |
| `/effect -5` | Negativo | Silencioso (sem ação) |
| `/effect 0` | Zero | Silencioso (sem ação) |
| `/effect 28` | Válido | Efeito 28 na posição |
| `/effect 9999` | ID alto | Efeito 9999 (se válido) |

**Notas:**
- Sem validação de ID real (IDs altos ou inválidos são silenciosamente ignorados)
- Sem feedback visual após sucesso
- Efeito é visível para todos próximos

**Retorno:** `true` (comando executado com sucesso)
