## 📄 Visão Geral do Código - Resumo Executivo

O arquivo bless.lua implementa comando simples de compra de bênçãos. Dispõe de wrapper ao sistema Blessings, bulk purchase via BuyAllBlesses. Ferramenta essencial de blessing purchase.

## 🔧 Estrutura de Funcionalidades

### **TalkAction !bless**

```lua
local bless = TalkAction("!bless")

function bless.onSay(player, words, param)
	Blessings.BuyAllBlesses(player)
	return true
end

bless:groupType("normal")
bless:register()
```

**Comando:** `!bless`

**Fluxo:**
1. Chama Blessings.BuyAllBlesses(player)
2. Sistema compra todas bênçãos
3. Retorna true

---

## **Blessings API**

```lua
Blessings.BuyAllBlesses(player)
```

Função que:
- Obtém lista de bênçãos disponíveis
- Verifica custo total
- Valida dinheiro do player
- Compra todas de uma vez
- Fornece feedback (via sistema)

---

**Exemplos de Uso:**

```
Player: !bless

Fluxo:
1. Blessings.BuyAllBlesses(player)
2. Sistema:
   - Calcula custo total
   - Remove dinheiro
   - Adiciona bênçãos
   - Feedback ao player

Resultado:
- Todas as bênçãos compradas
- Dinheiro debitado
- Feedback automático do sistema
```
