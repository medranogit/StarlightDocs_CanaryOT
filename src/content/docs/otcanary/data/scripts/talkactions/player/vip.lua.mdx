## 💡 Utilidade

Este comando permite que jogadores verifiquem se possuem VIP ativo em sua conta e visualizem informações détalhadas sobre o status VIP, incluindo tempo de expiração. Suporta dois alias de comando: `!checkvip` e `!vip`.

## 📄 Visão Geral do Código Resumo Executivo

O script `vip.lua` implementa um sistema de check de status VIP:

- **Múltiplos Aliases**: Suporta `!checkvip` ou `!vip` (ambos executam mesma função)
- **Verificação de VIP**: Valida se jogador tem VIP ativo
- **Display de Status**: Se ativo, exibe painel de VIP com detalhes
- **Mensagem de Fallback**: Se inativo, exibe notificação clara
- **Integração de API**: Usa método nativo `sendVipStatus()`

### Fluxo Lógico Resumido

1. Verifica se jogador possui VIP ativo
2. Se SIM: chama método nativo para exibir status VIP
3. Se NÃO: exibe mensagem informando que não tem VIP

## 🔧 Estrutura de Funcionalidades

### Variáveis Locais Globais

```lua
local vip = TalkAction("!checkvip", "!vip")
```

**Descrição:**

- Cria TalkAction com 2 aliases:
  - `!checkvip`: Alias formal
  - `!vip`: Alias simplificado

Ambos comandos trigam a mesma função `onSay()`.

### Função Principal: `vip.onSay()`

```lua
function vip.onSay(player, words, param)
    if player:isVip() then
        player:sendVipStatus()
    else
        player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You do not have VIP on your account.")
    end
    return true
end
```

**Parâmetros:**
- `player` (Player): Jogador que executou o comando
- `words` (string): Palavra-chave do comando (`!checkvip` ou `!vip`)
- `param` (string): Parâmetro vazio (sem uso)

**Retorno:**
- `true`: Comando processado com sucesso

#### Lógica Detalhada

1. **Verificação de VIP**:
   - `player:isVip()`: Retorna `true` se VIP é ativo, `false` caso contrário
   - Verifica se tempo de VIP ainda não expirou

2. **Caminho de VIP Ativo**:
   - `player:sendVipStatus()`: Exibe painel/janela de status VIP
   - Painel contém:
     - Informações VIP (dias, horas restantes, etc)
     - Benefícios ativos
     - Data de expiração
   - Interface nativa do jogo

3. **Caminho de VIP Inativo**:
   - `player:sendTextMessage(MESSAGE_EVENT_ADVANCE, ...)`:
     - Tipo: MESSAGE_EVENT_ADVANCE (cor de alerta/evento)
     - Mensagem: "You do not have VIP on your account."

### Variáveis Globais Utilizadas

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `MESSAGE_EVENT_ADVANCE` | number | Tipo de mensagem (cor de alerta/evento) |

### Funções Globais Utilizadas

| Função | Origem | Descrição |
|--------|--------|-----------|
| `player:isVip()` | Object Player | Verifica se jogador tem VIP ativo |
| `player:sendVipStatus()` | Object Player | Exibe janela de status VIP com detalhes |
| `player:sendTextMessage(type, text)` | Object Player | Envia mensagem de texto |
