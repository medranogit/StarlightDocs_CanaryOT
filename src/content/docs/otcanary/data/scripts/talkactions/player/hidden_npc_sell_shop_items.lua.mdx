## 💡 Utilidade

Este comando permite que jogadores controlem se desejam visualizar itens ocultos ao vender para NPCs. A preferência é armazenada no sistema Key-Value (KV) do jogador e persiste através de sessões.

## 📄 Visão Geral do Código Resumo Executivo

O script `hidden_npc_sell_shop_items.lua` implementa um sistema de visibilidade de itens ocultos:

- **Validação de Parâmetro**: Verifica se parâmetro "on" ou "off" foi fornecido
- **Armazenamento em KV**: Utiliza sistema Key-Value para persistir preferência
- **Ativação de Modo**: Pode ativar visualização de itens ocultos ou não
- **Feedback Visual**: Envia mensagem de confirmação ao jogador

### Fluxo Lógico Resumido

1. Valida se parâmetro foi fornecido
2. Se "on": ativa visualização de itens ocultos (KV = true)
3. Se "off": desativa visualização de itens ocultos (KV = false)
4. Envia mensagem de confirmação

## 🔧 Estrutura de Funcionalidades

### Função Principal: `talkaction.onSay()`

```lua
function talkaction.onSay(player, words, param)
    if param == "" then
        player:sendCancelMessage("You need to specify on/off param.")
        return true
    end
    
    if param == "on" then
        player:kv():set("npc-shop-hidden-sell-item", true)
        player:sendTextMessage(MESSAGE_LOOK, "You activated hidden sell shop items.")
    elseif param == "off" then
        player:kv():set("npc-shop-hidden-sell-item", false)
        player:sendTextMessage(MESSAGE_LOOK, "You deactivated hidden sell shop items")
    end
    return true
end
```

**Parâmetros:**
- `player` (Player): Jogador que executou o comando
- `words` (string): Palavra-chave do comando
- `param` (string): Parâmetro "on" ou "off"

**Retorno:**
- `true`: Comando processado com sucesso

#### Lógica Detalhada

1. **Validação de Parâmetro**:
   - Verifica se `param == ""` (vazio)
   - Se vazio: envia mensagem de cancelamento pedindo "on" ou "off"

2. **Processamento de "on"** (Ativar Visualização):
   - `player:kv():set("npc-shop-hidden-sell-item", true)`: Armazena chave KV como `true`
   - Envia mensagem em `MESSAGE_LOOK`: "You activated hidden sell shop items."

3. **Processamento de "off"** (Desativar Visualização):
   - `player:kv():set("npc-shop-hidden-sell-item", false)`: Armazena chave KV como `false`
   - Envia mensagem em `MESSAGE_LOOK`: "You deactivated hidden sell shop items"

### Variáveis Globais Utilizadas

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `MESSAGE_LOOK` | number | Tipo de mensagem (comunicação visual/narração) |

### Funções Globais Utilizadas

**Uso Prático:**

Quando um jogador digita `!hiddenshop on` ou `!hiddenshop off`:

1. Valida parâmetro fornecido
2. Ativa/desativa visualização de itens ocultos no sistema KV
3. Envia feedback visual ao jogador

**Exemplos de Execução:**

```
Jogador: !hiddenshop on
Sistema: "You activated hidden sell shop items."
KV: npc-shop-hidden-sell-item = true
Resultado: Pode visualizar itens ocultos em lojas NPC

---

Jogador: !hiddenshop off
Sistema: "You deactivated hidden sell shop items"
KV: npc-shop-hidden-sell-item = false
Resultado: Não visualiza itens ocultos em lojas NPC

---

Jogador: !hiddenshop
Sistema: "You need to specify on/off param."
Resultado: Comando cancelado
```

**Contexto de Uso:**

Este comando é útil para:
- Jogadores que querem ocultar itens específicos ao vender para NPCs
- Gerenciamento de inventário durante transações
- Controle de quais itens aparecem nas interfaces de venda
- NPCs avançados com sistemas de seleção de itens
