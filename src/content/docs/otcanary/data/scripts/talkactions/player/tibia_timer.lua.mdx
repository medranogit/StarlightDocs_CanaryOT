## 💡 Utilidade

Este comando fornece informações sobre o tempo atual no mundo de Tibia, incluindo a hora formatada e o ciclo diurno/noturno. Útil para jogadores entenderem a passagem de tempo no servidor e efeitos relacionados a dia/noite.

## 📄 Visão Geral do Código Resumo Executivo

O script `tibia_timer.lua` implementa um sistema de display de tempo:

- **Obtenção de Tempo**: Recupera tempo mundial atual do servidor
- **Formatação de Hora**: Converte timestamp para formato legível (HH:MM)
- **Determinação de Ciclo**: Define se é dia ou noite baseado na hora
- **Mensagem Formatada**: Exibe hora e ciclo em uma única mensagem
- **Alerta Visual**: Usa tipo de mensagem EVENT_ADVANCE para destacar

### Fluxo Lógico Resumido

1. Obtém tempo mundial atual
2. Formata tempo em string legível
3. Determina se é dia ou noite
4. Exibe mensagem com hora e ciclo

## 🔧 Estrutura de Funcionalidades

### Função Principal: `statusTime.onSay()`

```lua
function statusTime.onSay(player, words, param)
    local formattedTime = getFormattedWorldTime(getWorldTime())
    local dayOrNight = getTibiaTimerDayOrNight(formattedTime)
    player:sendTextMessage(MESSAGE_EVENT_ADVANCE, string.format("Now is %s in Tibia Time, time now is %s.", dayOrNight, formattedTime))
    return true
end
```

**Parâmetros:**
- `player` (Player): Jogador que executou o comando
- `words` (string): Palavra-chave do comando
- `param` (string): Parâmetro vazio (sem uso)

**Retorno:**
- `true`: Comando executado com sucesso

#### Lógica Detalhada

1. **Obtenção de Tempo**:
   - `getWorldTime()`: Obtém timestamp atual do servidor (milissegundos ou segundos)
   - `getFormattedWorldTime()`: Converte timestamp para formato string (HH:MM)

2. **Determinação de Ciclo**:
   - `getTibiaTimerDayOrNight(formattedTime)`: Analisa hora e retorna dia/noite
   - Baseado em intervalo de horas pré-configurado
   - Retorna string descritiva like "day" ou "night"

3. **Construção de Mensagem**:
   - `string.format()`: Monta string com 2 parâmetros
     - `%s` primeiro: ciclo (dia/noite)
     - `%s` segundo: hora formatada (HH:MM)
   - Resultado: "Now is day in Tibia Time, time now is 18:45."

4. **Exibição**:
   - `sendTextMessage(MESSAGE_EVENT_ADVANCE, ...)`: Exibe em cor de alerta/evento

### Variáveis Globais Utilizadas

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `MESSAGE_EVENT_ADVANCE` | number | Tipo de mensagem (cor de evento/alerta) |

### Funções Globais Utilizadas

| Função | Origem | Descrição |
|--------|--------|-----------|
| `getWorldTime()` | Core do Jogo | Retorna timestamp atual do mundo |

| `getTibiaTimerDayOrNight(hora)` | Global | Determina ciclo baseado na hora |
| `player:sendTextMessage(type, text)` | Object Player | Envia mensagem de texto |

## 📋 Resumo de Implementação

**Padrão de Registro:**

```lua
statusTime:groupType("normal")
statusTime:register()
```

**Uso Prático:**

Quando um jogador digita `!time`:

1. Sistema obtém hora global do servidor
2. Formata em padrão HH:MM legível
3. Determina se é dia ou noite
4. Exibe mensagem combinando hora e ciclo

**Exemplos de Execução:**

```
--- Durante o dia ---
Jogador: !time
Sistema: "Now is day in Tibia Time, time now is 08:30."

--- Durante a noite ---
Jogador: !time
Sistema: "Now is night in Tibia Time, time now is 20:15."
```

**Ciclos de Dia/Noite:**

O sistema Tibia Timer divide o dia em ciclos:
- **Dia**: Geralmente entre 6:00 e 18:00
- **Noite**: Geralmente entre 18:00 e 6:00
- Horários exatos dependem da configuração do servidor

**Contexto de Uso:**

Este comando é útil para:
- Saber hora em tempo Tibia
- Entender ciclos diurno/noturno
- Planejamento de atividades (alguns eventos/criaturas mudam com ciclo)
- Sincronizar atividades em grupo
