## 💡 Utilidade

Este comando é exclusivo para Senior Tutores e permite que eles visualizem suas coordenadas 3D exatas no mundo. Útil para navegação, teleporte remoto coordenado e referência de localização em conversas com outros tutores.

## 📄 Visão Geral do Código Resumo Executivo

O script `tutor_position.lua` implementa um sistema de display de coordenadas:

- **Restrição de Acesso**: Apenas Senior Tutores podem utilizar
- **Obtenção de Posição**: Recupera coordenadas X, Y, Z do jogador
- **Formatação**: Exibe em padrão legível "X, Y, Z."
- **Mensagem Alerta**: Usa tipo MESSAGE_EVENT_ADVANCE para destaque visual
- **String Multilinha**: Usa sintaxe `\z` para quebra de linha

### Fluxo Lógico Resumido

1. Obtém posição do jogador (X, Y, Z)
2. Formata mensagem com as 3 coordenadas
3. Envia mensagem ao jogador

## 🔧 Estrutura de Funcionalidades

### Função Principal: `tutorPosition.onSay()`

```lua
function tutorPosition.onSay(player, words, param)
    local position = player:getPosition()
    player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Your current position is: \z
        " .. position.x .. ", " .. position.y .. ", " .. position.z .. ".")
    return true
end
```

**Parâmetros:**
- `player` (Player): Jogador que executou o comando (senior tutor)
- `words` (string): Palavra-chave do comando
- `param` (string): Parâmetro vazio (sem uso)

**Retorno:**
- `true`: Comando executado com sucesso

#### Lógica Detalhada

1. **Obtenção de Posição**:
   - `player:getPosition()`: Obtém object Position com coordenadas 3D
   - Retorna posição atual do jogador no mundo

2. **Acesso a Coordenadas**:
   - `position.x`: Coordenada horizontal (leste/oeste)
   - `position.y`: Coordenada horizontal (norte/sul)
   - `position.z`: Coordenada vertical (profundidade/andar)

3. **Construção de Mensagem**:
   - `\z` (continuação de linha): Quebra de linha sem espaço no string
   - Concatena strings com `..` operador
   - Formato: "Your current position is: X, Y, Z."

4. **Exibição**:
   - `sendTextMessage(MESSAGE_EVENT_ADVANCE, ...)`: Envia com cor de alerta

### Variáveis e Propriedades Utilizadas

| Item | Tipo | Descrição |

## 📋 Resumo de Implementação

**Padrão de Registro:**

```lua
tutorPosition:groupType("senior tutor")
tutorPosition:register()
```

**Acesso Restrito:**

Este comando APENAS funciona para jogadores com grupo "senior tutor". Outros jogadores recebem mensagem de acesso negado do sistema TalkAction.

**Uso Prático:**

Quando um Senior Tutor digita `!position`:

1. Sistema obtém posição 3D atual do tutor
2. Formata coordenadas em string legível
3. Exibe mensagem com X, Y, Z

**Exemplos de Execução:**

```
--- Posição normal ---
Tutor: !position (em localização normal)
Sistema: "Your current position is: 1001, 1001, 7."

--- Posição em subsoil ---
Tutor: !position (em caverna/andar baixo)
Sistema: "Your current position is: 500, 500, 15."

--- Posição em andar elevado ---
Tutor: !position (em torre/andar alto)
Sistema: "Your current position is: 1500, 1500, 3."
```

**Significado das Coordenadas:**

- **X**: Posição horizontal (leste é maior, oeste é menor)
- **Y**: Posição horizontal (norte é menor, sul é maior)
- **Z**: Andar/profundidade (menor = mais alto, maior = mais profundo)

**Contexto de Uso:**

Este comando é útil para Senior Tutores:
- Coordenar encontros com outros tutores
- Registrar localizações importantes
- Debugar posições problemáticas
- Navegar com precisão pelo mapa
- Sincronizar ações em localização específica
