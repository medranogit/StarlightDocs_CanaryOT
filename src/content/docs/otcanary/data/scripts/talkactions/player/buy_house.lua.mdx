## 📄 Visão Geral do Código - Resumo Executivo

O arquivo buy_house.lua implementa sistema completo de house purchasing. Dispõe de validações múltiplas (premium/level/position/existência), directional navigation, metrics tracking, conditional registration via config gate. Ferramenta essencial de house system.

## 🔧 Estrutura de Funcionalidades

### **TalkAction !buyhouse**

```lua
local buyHouse = TalkAction("!buyhouse")

function buyHouse.onSay(player, words, param)
	-- Gate 1: Preço configurado
	local housePrice = configManager.getNumber(configKeys.HOUSE_PRICE_PER_SQM)
	if housePrice == -1 then
		return true  -- Desabilitado
	end

	-- Gate 2: Premium
	if not player:isPremium() then
		player:sendCancelMessage("You need a premium account.")
		return true
	end

	-- Gate 3: Level mínimo
	local houseBuyLevel = configManager.getNumber(configKeys.HOUSE_BUY_LEVEL)
	if player:getLevel() < houseBuyLevel then
		player:sendCancelMessage("You need to be level " .. houseBuyLevel .. " to buy a house.")
		return true
	end

	-- Navegação: próxima posição na direção
	local position = player:getPosition()
	position:getNextPosition(player:getDirection())

	-- Gate 4: Casa existe
	local tile = Tile(position)
	local house = tile and tile:getHouse()
	local playerPos = player:getPosition()
	local houseEntry = house and house:getExitPosition()

	if not house or playerPos ~= houseEntry then
		player:sendCancelMessage("You have to be looking at the door of the house you would like to buy.")
		return true
	end

	-- Gate 5: Casa sem dono
	if house:getOwnerGuid() > 0 then
		player:sendCancelMessage("This house already has an owner.")
		return true
	end

	-- Gate 6: Player sem casa
	if player:getHouse() then
		player:sendCancelMessage("You are already the owner of a house.")
		return true
	end

	-- Gate 7: Casa vazia
	if house:hasItemOnTile() then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You cannot buy this house, as there are items inside it. Please, contact an administrator.")
		return true
	end

	-- Comprar
	local price = house:getPrice()
	if not player:removeMoneyBank(price) then
		player:sendCancelMessage("You do not have enough money.")
		return true
	end
	
	-- Metrics tracking
	metrics.addCounter("balance_decrease", remainsPrice, {
		player = player:getName(),
		context = "house_purchase",
	})

	-- Finalizar
	house:setHouseOwner(player:getGuid())
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You have successfully bought this house, be sure to have the money for the rent in the bank.")
	return true
end

-- Conditional registration
if not configManager.getBoolean(configKeys.CYCLOPEDIA_HOUSE_AUCTION) then
	buyHouse:separator(" ")
	buyHouse:groupType("normal")
	buyHouse:register()
end
```

**Comando:** `!buyhouse`

**Fluxo:**
1. Valida preço configurado
2. Valida premium + level
3. Valida posição (direção)
4. Valida casa existe
5. Valida posições (player at exit)
6. Valida sem dono
7. Valida player sem casa
8. Valida vazia (sem items)
9. Compra + metrics + set owner

## **Gates de Validação**

### **Gate 1: Preço Configurado**

```lua
HOUSE_PRICE_PER_SQM != -1
```

Se -1: comando desabilitado

---

### **Gate 2: Premium Account**

```lua
player:isPremium() == true
```

Se falso: "You need a premium account."

---

### **Gate 3: Level Mínimo**

```lua
player:getLevel() >= HOUSE_BUY_LEVEL
```

Configurável via `HOUSE_BUY_LEVEL`

---

### **Gate 4-7: House Validation**

| Gate | Check | Condição |
|---|---|---|
| 4 | Casa existe | house != nil |
| 5 | Posição correta | playerPos == houseEntry |
| 6 | Sem dono | ownerGuid == 0 |
| 7 | Player sem casa | player:getHouse() == nil |
| 8 | Casa vazia | hasItemOnTile() == false |

---

## **Configuração Necessária**

```lua
-- config.lua
HOUSE_PRICE_PER_SQM = 1000    -- Preço por SQM (-1 = desabilitado)
HOUSE_BUY_LEVEL = 20           -- Level mínimo
CYCLOPEDIA_HOUSE_AUCTION = false  -- Usar leilão em vez de comando
```
