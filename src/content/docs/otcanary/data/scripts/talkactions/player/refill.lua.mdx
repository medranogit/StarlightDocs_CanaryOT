## 💡 Utilidade

Este comando permite que jogadores recarreguem amuletos e anéis descarregados usando Silver Tokens. O sistema verifica automaticamente o inventário do jogador, localiza itens elegíveis e realiza a troca mantendo logs de debug.

## 📄 Visão Geral do Código Resumo Executivo

O script `refill.lua` implementa um sistema de recarga de equipamentos:

- **Tabela de Configuração**: Define pares de itens (descarregado/carregado) e custos
- **Iteração Automática**: Processa todos os itens elegíveis de uma vez
- **Validação de Custo**: Verifica disponibilidade de Silver Tokens antes de processar
- **Feedback Detalhado**: Lista itens recarregados e custo total
- **Logging de Debug**: Registra execução do comando

### Fluxo Lógico Resumido

1. Define tabela com todos os itens recarregáveis
2. Itera sobre cada tipo de item
3. Verifica se jogador possui item descarregado e Silver Tokens suficientes
4. Remove item descarregado e Silver Tokens
5. Adiciona item carregado
6. Envia feedback com lista de itens recarregados

### Função Principal: `refill.onSay()`

```lua
function refill.onSay(player, words, param)
    logger.debug("!refill executed")
    local refilledItems = {}
    local totalCost = 0
    
    for itemName, itemData in pairs(chargeItem) do
        local chargeableCount = player:getItemCount(itemData.noChargeID)
        local silverTokensCount = player:getItemCount(silverTokenID)
        
        if chargeableCount >= 1 and silverTokensCount >= itemData.cost then
            totalCost = totalCost + itemData.cost
            table.insert(refilledItems, itemName)
            player:removeItem(silverTokenID, itemData.cost)
            player:removeItem(itemData.noChargeID, 1)
            player:addItem(itemData.ChargeID, 1)
        end
    end
    
    if #refilledItems == 0 then
        player:sendTextMessage(MESSAGE_LOOK, "You do not have any items to refill or lack silver tokens.")
    else
        local itemList = table.concat(refilledItems, ", ")
        player:sendTextMessage(MESSAGE_LOOK, "Refilled " .. itemList .. " for a total of " .. totalCost .. " silver tokens.")
    end
    return true
end
```

**Parâmetros:**
- `player` (Player): Jogador que executou o comando
- `words` (string): Palavra-chave do comando
- `param` (string): Parâmetro vazio (sem uso)

**Retorno:**
- `true`: Comando processado com sucesso

#### Lógica Detalhada

1. **Logging de Debug**:
   - `logger.debug("!refill executed")`: Registra execução

2. **Inicialização**:
   - `refilledItems = {}`: Tabela para rastrear itens processados
   - `totalCost = 0`: Acumula custo total

3. **Loop de Processamento**:
   - Itera cada tipo de item na tabela `chargeItem`
   - Obtém contagem de itens descarregados: `getItemCount(noChargeID)`
   - Obtém contagem de Silver Tokens: `getItemCount(silverTokenID)`
   
4. **Validação e Processamento**:
   - Valida: pelo menos 1 item descarregado E Silver Tokens suficientes
   - Se válido:
     - Adiciona nome à lista de recarregados
     - Incrementa custo total
     - Remove Silver Tokens
     - Remove item descarregado
     - Adiciona item carregado

5. **Feedback**:
   - Se `refilledItems` vazio: envia mensagem de erro
   - Se itens recarregados: lista itens e custo total

**Uso Prático:**

Quando um jogador digita `!refill`:

1. Sistema itera todos os 10 tipos de itens recarregáveis
2. Para cada item, verifica se jogador possui versão descarregada

5. Acumula custo total
6. Envia mensagem com lista e custo

Sistema: "You do not have any items to refill or lack silver tokens."
