## 📄 Visão Geral do Código - Resumo Executivo

O arquivo hireling_clear_stats.lua implementa comando TalkAction (/clearhirelingstas) que reseta todas as estatísticas de hireling de um jogador. O sistema oferece parâmetro alvo opcional (default self), valida player, aplica clearAllHirelingStats(), magic effect GREEN confirmação. Ferramenta de hireling testing.

## 🔧 Estrutura de Funcionalidades

```lua
-- Very useful for testing environments
local talk = TalkAction("/clearhirelingstas")

function talk.onSay(player, words, param)
	-- create log
	logCommand(player, words, param)
	
	-- Parse: optional player name
	local split = param:split(",")
	local name = split[1] ~= "" and split[1]
	
	-- Buscar jogador ou usar self
	local target = Player(name)
	if target then
		target:clearAllHirelingStats()
	else
		player:clearAllHirelingStats()
	end
	
	-- Magic effect visual
	player:getPosition():sendMagicEffect(CONST_ME_MAGIC_GREEN)
	return true
end

talk:separator(" ")
talk:groupType("god")
talk:register()
```

## 🤖 Documentação das Funções

### **talk.onSay(player, words, param)**

**Descrição:** Função callback que reseta hireling stats de um jogador.

**Parâmetros:**
- `param` (string): Nome do jogador (opcional, padrão: self)

**Formato de Comando:**
```
/clearhirelingstas                  -- Reseta stats do próprio GM
/clearhirelingstas PlayerName      -- Reseta stats de outro jogador
```

**Fluxo de Execução:**

1. **Log do Comando:**
   ```lua
   logCommand(player, words, param)
   ```

2. **Parse de Parâmetro:**
   ```lua
   local split = param:split(",")
   local name = split[1] ~= "" and split[1]
   ```
   - Se split[1] vazio: name = nil
   - Se split[1] não vazio: name = split[1]

   **Exemplos:**
   ```lua
   param = ""
   split[1] = ""
   name = nil  -- Usará self

   ---

   param = "TestPlayer"
   split[1] = "TestPlayer"
   name = "TestPlayer"  -- Buscará player
   ```

3. **Buscar Jogador:**
   ```lua
   local target = Player(name)
   if target then
       target:clearAllHirelingStats()
   else
       player:clearAllHirelingStats()
   end
   ```

   **Modo 1: Parâmetro Fornecido**
   - Busca player por nome
   - Se encontrado: reseta stats do target
   - Se não encontrado: reseta stats do executor (self-fallback)

   **Modo 2: Parâmetro Vazio**
   - name = nil
   - Player(nil) retorna nil
   - Reseta stats do executor

4. **Magic Effect:**
   ```lua
   player:getPosition():sendMagicEffect(CONST_ME_MAGIC_GREEN)
   ```
   - GREEN effect na posição do GM
   - Confirmação visual

---

**Exemplos de Uso:**

```
GM: /clearhirelingstas

Fluxo:
1. Parse: split[1]="", name=nil
2. Player(nil) -> nil
3. player:clearAllHirelingStats()
4. GREEN effect

Resultado:
- Stats do hireling do GM são resetadas

---

GM: /clearhirelingstas TestPlayer

Fluxo:
1. Parse: split[1]="TestPlayer", name="TestPlayer"
2. Player("TestPlayer") -> target (se online)
3. target:clearAllHirelingStats()
4. GREEN effect

Resultado:
- Stats do hireling do TestPlayer são resetadas
- Se TestPlayer offline: reseta stats do GM

---

GM (offline): /clearhirelingstas OfflinePlayer

Resultado:
- Player("OfflinePlayer") -> nil
- player:clearAllHirelingStats() (self-fallback)
```
