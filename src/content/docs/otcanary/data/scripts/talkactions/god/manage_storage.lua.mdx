## 📄 Visão Geral do Código - Resumo Executivo

O arquivo manage_storage.lua implementa 2 comandos de storage management. Dispõe de getter com Player extension, setter com default value, suporte a storage key (número) e name (string), validações de parâmetros, logging automático. Ferramenta essencial de player data debugging.

## 🔧 Estrutura de Funcionalidades

### **Player Extension getStorageValueTalkaction**

```lua
function Player.getStorageValueTalkaction(self, param)
	-- Validação de parâmetros
	if not HasValidTalkActionParams(self, param, "Usage: /getstorage <playername>, <storage key or name>") then
		return true
	end
	
	local split = param:split(",")
	if not split[2] then
		self:sendCancelMessage("Insufficient parameters.")
		return true
	end
	
	-- Buscar player
	local target = Player(split[1]:trim())
	if not target then
		self:sendCancelMessage("A player with that name is not online.")
		return true
	end
	
	-- Storage key: número ou string
	local storageKey = tonumber(split[2]) or split[2]:trim()
	if not storageKey then
		self:sendCancelMessage("Invalid storage key or name.")
		return true
	end
	
	-- Obter valor
	local storageValue = target:getStorageValue(storageKey)
	if storageValue == nil then
		self:sendTextMessage(MESSAGE_EVENT_ADVANCE, "The storage with id: " .. split[2] .. " does not exist or is not set for player " .. target:getName() .. ".")
	else
		self:sendTextMessage(MESSAGE_EVENT_ADVANCE, "The storage with id: " .. split[2] .. " from player " .. target:getName() .. " is: " .. storageValue .. ".")
	end
	
	return true
end
```

### **Player Extension setStorageValueTalkaction**

```lua
function Player.setStorageValueTalkaction(self, param)
	-- Validação
	if not HasValidTalkActionParams(self, param, "Usage: /setstorage <storagekey or name>, <value>, <player name>=default self") then
		return true
	end
	
	local split = param:split(",")
	local value = 1
	if split[2] then
		value = split[2]
	end
	
	-- Storage key: só número
	local storageKey = tonumber(split[1])
	if storageKey == nil then
		logger.warn("The storage key is not a number.")
		self:sendCancelMessage("The storage key is not a number.")
	else
		-- Alvo: param[3] ou self
		if split[3] then
			local targetPlayer = Player(string.trim(split[3]))
			if not targetPlayer then
				self:sendCancelMessage("Player not found.")
				return true
			else
				local message = "Set storage: " .. storageKey .. " to player " .. split[3] .. " newValue: " .. value .. "."
				self:sendTextMessage(MESSAGE_EVENT_ADVANCE, message)
				targetPlayer:setStorageValue(storageKey, value)
				targetPlayer:save()
				return true
			end
		else
			local message = "Set storage: " .. storageKey .. " to player " .. self:getName() .. ", newValue: " .. value .. "."
			self:sendTextMessage(MESSAGE_EVENT_ADVANCE, message)
			self:setStorageValue(storageKey, value)
			self:save()
		end
	end
	return true
end
```

### **TalkAction /setstorage**

```lua
local talkaction = TalkAction("/setstorage")

function talkaction.onSay(player, words, param)
	return player:setStorageValueTalkaction(param)
end

talkaction:separator(" ")
talkaction:groupType("god")
talkaction:register()
```

**Comando:**
```
/setstorage 10001, 1                  -- Set self, value=1
/setstorage 10001, 100                -- Set self, value=100
/setstorage 10001, 1, PlayerName      -- Set outro player
```

**Fluxo:**
1. Valida parâmetros
2. Parse key, value, playerName (opt)
3. Value default = 1
4. Key deve ser número
5. setStorageValue(key, value)
6. player:save() - persiste

**Validações:**
- Key deve ser número
- Player deve estar online (se especificado)
- Value defaults para 1

---

**Exemplos de Uso:**

```
GM: /getstorage TestPlayer, 10000

Resultado:
"The storage with id: 10000 from player TestPlayer is: 100."

---

GM: /setstorage 10000, 50, TestPlayer

Resultado:
"Set storage: 10000 to player TestPlayer newValue: 50."
- Storage de TestPlayer alterado
- Dados salvos no banco

---

GM: /setstorage 10001, 1

Resultado:
"Set storage: 10001 to player AdminName, newValue: 1."
- Storage do próprio GM alterado
```
