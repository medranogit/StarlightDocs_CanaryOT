## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `add_mount.lua` implementa um comando TalkAction (`/addmount`) que adiciona montarias a jogadores. O sistema valida parâmetros, oferece modo "all" para adicionar 231 mounts disponíveis, ou modo single para mount específico por ID, aplica via `addMount()`, e fornece feedback diferenciado. Ferramenta de concessão de mobilidade.

## 🔧 Estrutura de Funcionalidades

```lua
local addmount = TalkAction("/addmount")

function addmount.onSay(player, words, param)
    -- Create log
    logCommand(player, words, param)
    
    -- Validação: parâmetro vazio
    if param == "" then
        player:sendCancelMessage("Command param required.")
        return true
    end
    
    -- Parse: playerName, mountParam
    local split = param:split(",")
    if #split < 2 then
        player:sendCancelMessage("Usage: /addmount <playername>, <mount id or 'all'>")
        return true
    end
    
    -- Buscar jogador
    local playerName = split[1]
    local target = Player(playerName)
    
    if not target then
        player:sendCancelMessage("Player not found.")
        return true
    end
    
    -- Extrair mount parameter
    local mountParam = string.trim(split[2])
    
    -- Modo "all": adicionar todos mounts (1-231)
    if mountParam == "all" then
        for mountId = 1, 231 do
            target:addMount(mountId)
        end
        
        target:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
            string.format("%s has added all mounts to you.", player:getName()))
        player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
            string.format("You have successfully added all mounts to player %s.", target:getName()))
    else
        -- Modo single: mount específico
        local mountId = tonumber(mountParam)
        if not mountId then
            player:sendCancelMessage("Invalid mount ID.")
            return true
        end
        
        target:addMount(mountId)
        target:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
            string.format("%s has added a new mount for you.", player:getName()))
        player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
            string.format("You have successfully added mount %d to player %s.", mountId, target:getName()))
    end
    
    return true
end

addmount:separator(" ")
addmount:groupType("god")
addmount:register()
```

## 🤖 Documentação das Funções

### **addmount.onSay(player, words, param)**

**Descrição:** Função callback que adiciona mounts a um jogador online.

**Parâmetros:**
- `param` (string): `<playername>, <mount_id|all>`

**Formato de Comando:**
```
/addmount Player1, 5               -- Adiciona mount ID 5
/addmount Player1, all             -- Adiciona todos 231 mounts
```

**Fluxo de Execução:**

1. **Log do Comando:**
   - `logCommand(player, words, param)` registra uso

2. **Validação de Parâmetro Vazio:**
   - Se param == "", retorna "Command param required."

3. **Parse de Parâmetros:**
   ```lua
   local split = param:split(",")
   if #split < 2 then
       player:sendCancelMessage("Usage: /addmount <playername>, <mount id or 'all'>")
   ```
   - Valida presença de 2 parâmetros

4. **Busca de Jogador:**
   ```lua
   local target = Player(playerName)
   if not target then
       player:sendCancelMessage("Player not found.")
   ```
   - Deve estar online

5. **Extrair Mount Parameter:**
   ```lua
   local mountParam = string.trim(split[2])
   ```

6. **Modo "all" - Adicionar Todos Mounts:**
   ```lua
   if mountParam == "all" then
       for mountId = 1, 231 do
           target:addMount(mountId)
       end
   ```
   - Itera IDs 1 até 231
   - Cada um via `addMount(id)`
   - Feedback: "has added all mounts to you"

7. **Modo Single - Mount Específico:**
   ```lua
   else
       local mountId = tonumber(mountParam)
       if not mountId then
           player:sendCancelMessage("Invalid mount ID.")
       end
       target:addMount(mountId)
   ```
   - Converte string para número
   - Valida conversão
   - Aplica single mount

**Exemplo de Execução:**

```
GM: /addmount TestPlayer, 5

Parse:
- playerName = "TestPlayer"
- mountParam = "5"

Busca:
- TestPlayer encontrado ✓

Modo Single:
- mountId = 5
- Válido ✓
- addMount(5) aplicado

Feedback:
- TestPlayer vê: "[GM] has added a new mount for you."
- GM vê: "You have successfully added mount 5 to player TestPlayer."
```

---

```
GM: /addmount TestPlayer, all

Parse:
- playerName = "TestPlayer"
- mountParam = "all"

Modo All:
- Para mountId = 1, 2, 3, ..., 231:
  - addMount(mountId)

Feedback:
- TestPlayer vê: "[GM] has added all mounts to you."
- GM vê: "You have successfully added all mounts to player TestPlayer."
```

**Range de IDs:**
- Mounts disponíveis: 1 a 231 (aproximadamente)
- "all" itera este range completo

**Funções Globais Utilizadas:**

| Função | Descrição |
|---|---|
| `param:split(sep)` | Divide por separador |
| `string.trim(str)` | Remove espaços |
| `tonumber(str)` | Converte para número |
| `Player(name)` | Busca jogador |
| `target:addMount(id)` | Adiciona mount |
| `string.format(fmt, ...)` | Formata string |

**Retorno:** `true` (comando executado com sucesso)
