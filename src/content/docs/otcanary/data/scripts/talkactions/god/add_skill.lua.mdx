## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `add_skill.lua` implementa um comando TalkAction (`/addskill`) que aumenta skills de jogadores (level, magic, ou combat skills). O sistema com skillMap (6 tipos), detecta tipo por prefix de string, calcula experiência/mana/tries necessárias, aplica via `addExperience()`/`addManaSpent()`/`addSkillTries()`, e fornece feedback singular/plural. Ferramenta de progressão.

## 🔧 Estrutura de Funcionalidades

```lua
-- Mapa de skills combat
local skillMap = {
    club = SKILL_CLUB,
    sword = SKILL_SWORD,
    axe = SKILL_AXE,
    dist = SKILL_DISTANCE,
    shield = SKILL_SHIELD,
    fish = SKILL_FISHING,
}

-- Função auxiliar: extrair skill ID do nome
local function getSkillId(skillName)
    return skillMap[skillName:match("^%a+")] or SKILL_FIST
end

local addSkill = TalkAction("/addskill")

function addSkill.onSay(player, words, param)
    -- Create log
    logCommand(player, words, param)
    
    -- Validação: parâmetro vazio
    if param == "" then
        player:sendCancelMessage("Command param required.")
        return true
    end
    
    -- Parse: playerName, skillType, amount (opcional)
    local split = param:split(",")
    if #split < 2 then
        player:sendCancelMessage("Usage: /addskill <playername>, <skill or 'level'/'magic'>, [amount]")
        return true
    end
    
    -- Extrair parâmetros
    local targetPlayerName = split[1]:trim()
    local targetPlayer = Player(targetPlayerName)
    
    if not targetPlayer then
        player:sendCancelMessage("Player not found.")
        return true
    end
    
    -- Tipo de skill e quantidade
    local skillParam = split[2]:trim()
    local skillIncreaseAmount = tonumber(split[3]) or 1
    local skillPrefix = skillParam:sub(1, 1)  -- Primeira letra
    
    -- MODO 1: Level (prefix "l")
    if skillPrefix == "l" then
        local targetNewLevel = targetPlayer:getLevel() + skillIncreaseAmount
        local targetNewExp = Game.getExperienceForLevel(targetNewLevel)
        local experienceToAdd = targetNewExp - targetPlayer:getExperience()
        local levelText = (skillIncreaseAmount > 1) and "levels" or "level"
        
        targetPlayer:addExperience(experienceToAdd, false)
        targetPlayer:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
            string.format("%s has added %d %s to you.", player:getName(), skillIncreaseAmount, levelText))
        player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
            string.format("You have successfully added %d %s to player %s.", skillIncreaseAmount, levelText, targetPlayer:getName()))
    
    -- MODO 2: Magic Level (prefix "m")
    elseif skillPrefix == "m" then
        for _ = 1, skillIncreaseAmount do
            local requiredManaSpent = targetPlayer:getVocation():getRequiredManaSpent(targetPlayer:getBaseMagicLevel() + 1)
            targetPlayer:addManaSpent(requiredManaSpent - targetPlayer:getManaSpent(), true)
        end
        
        local magicText = (skillIncreaseAmount > 1) and "magic levels" or "magic level"
        targetPlayer:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
            string.format("%s has added %d %s to you.", player:getName(), skillIncreaseAmount, magicText))
        player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
            string.format("You have successfully added %d %s to player %s.", skillIncreaseAmount, magicText, targetPlayer:getName()))
    
    -- MODO 3: Combat Skill (club, sword, axe, dist, shield, fish)
    else
        local skillId = getSkillId(skillParam)
        for _ = 1, skillIncreaseAmount do
            local requiredSkillTries = targetPlayer:getVocation():getRequiredSkillTries(skillId, targetPlayer:getSkillLevel(skillId) + 1)
            targetPlayer:addSkillTries(skillId, requiredSkillTries - targetPlayer:getSkillTries(skillId), true)
        end
        
        local skillText = (skillIncreaseAmount > 1) and "skill levels" or "skill level"
        targetPlayer:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
            string.format("%s has added %d %s %s to you.", player:getName(), skillIncreaseAmount, skillParam, skillText))
        player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
            string.format("You have successfully added %d %s %s to player %s.", skillIncreaseAmount, skillParam, skillText, targetPlayer:getName()))
    end
    
    return true
end

addSkill:separator(" ")
addSkill:groupType("god")
addSkill:register()
```

## 🤖 Documentação das Funções

### **addSkill.onSay(player, words, param)**

**Descrição:** Função callback que aumenta skills de um jogador (level, magic, ou combat).

**Parâmetros:**
- `param` (string): `<playername>, <skill|level|magic>, [amount]`

**Formato de Comando:**
```
/addskill Player1, level, 5        -- +5 levels
/addskill Player1, magic, 3        -- +3 magic levels
/addskill Player1, sword, 2        -- +2 sword skill levels
/addskill Player1, club            -- +1 club skill level (padrão)
```

**Fluxo de Execução:**

1. **Log do Comando:**
   - `logCommand(player, words, param)` registra uso

2. **Validação:**
   - Parâmetro vazio: "Command param required."
   - Menos de 2 parâmetros: "Usage: /addskill ..."

3. **Busca de Jogador:**
   - Se não encontrado: "Player not found."

4. **Extração de Parâmetros:**
   ```lua
   local skillParam = split[2]:trim()
   local skillIncreaseAmount = tonumber(split[3]) or 1
   local skillPrefix = skillParam:sub(1, 1)  -- Primeira letra
   ```
   - Exemplo: "sword" -> skillPrefix = "s"
   - Exemplo: "level" -> skillPrefix = "l"
   - Exemplo: "magic" -> skillPrefix = "m"

5. **MODO 1: Level (prefix "l")**
   ```lua
   if skillPrefix == "l" then
       local targetNewLevel = targetPlayer:getLevel() + skillIncreaseAmount
       local targetNewExp = Game.getExperienceForLevel(targetNewLevel)
       local experienceToAdd = targetNewExp - targetPlayer:getExperience()
       targetPlayer:addExperience(experienceToAdd, false)
   ```
   - Calcula novo nível
   - Obtém experiência necessária
   - Diferença = experiência a adicionar
   - Aplica via `addExperience()`

6. **MODO 2: Magic (prefix "m")**
   ```lua
   elseif skillPrefix == "m" then
       for _ = 1, skillIncreaseAmount do
           local requiredManaSpent = targetPlayer:getVocation():getRequiredManaSpent(targetPlayer:getBaseMagicLevel() + 1)
           targetPlayer:addManaSpent(requiredManaSpent - targetPlayer:getManaSpent(), true)
       end
   ```
   - Loop skillIncreaseAmount vezes
   - Calcula mana necessária para próximo level
   - Diferença = mana a adicionar
   - Aplica via `addManaSpent()`

7. **MODO 3: Combat Skill (club, sword, axe, dist, shield, fish)**
   ```lua
   else
       local skillId = getSkillId(skillParam)
       for _ = 1, skillIncreaseAmount do
           local requiredSkillTries = targetPlayer:getVocation():getRequiredSkillTries(skillId, targetPlayer:getSkillLevel(skillId) + 1)
           targetPlayer:addSkillTries(skillId, requiredSkillTries - targetPlayer:getSkillTries(skillId), true)
       end
   ```
   - Busca skillId em skillMap ou padrão SKILL_FIST
   - Loop skillIncreaseAmount vezes
   - Calcula tries necessárias
   - Diferença = tries a adicionar
   - Aplica via `addSkillTries()`

8. **Feedback Singular/Plural:**
   ```lua
   local levelText = (skillIncreaseAmount > 1) and "levels" or "level"
   ```
   - Se amount > 1: plural ("levels")
   - Senão: singular ("level")

**Exemplo de Execução:**

```

- playerName = "TestPlayer"
- skillParam = "level"
- skillIncreaseAmount = 5

```
