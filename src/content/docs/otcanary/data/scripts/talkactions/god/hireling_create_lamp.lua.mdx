## 📄 Visão Geral do Código - Resumo Executivo

O arquivo hireling_create_lamp.lua implementa comando TalkAction (/hireling) que cria novos hireling NPCs (companheiros). O sistema oferece parâmetros opcionais para nome e sexo, defaults sensatos, validação de sucesso, magic effect GREEN. Ferramenta de hireling creation.

## 🔧 Estrutura de Funcionalidades

```lua
local talk = TalkAction("/hireling")

function talk.onSay(player, words, param)
	-- create log
	logCommand(player, words, param)
	
	-- Parse: optional name and sex
	local split = param:split(",")
	local name = split[1] ~= "" and split[1] or "Hireling " .. player:getName()
	local sex = split[2] and tonumber(split[2]) or 1
	
	-- Criar hireling
	local result = player:addNewHireling(name, sex)
	if result then
		player:getPosition():sendMagicEffect(CONST_ME_MAGIC_GREEN)
	end
	return true
end

talk:separator(" ")
talk:groupType("god")
talk:register()
```

## 🤖 Documentação das Funções

### **talk.onSay(player, words, param)**

**Descrição:** Função callback que cria novo hireling.

**Parâmetros:**
- `param` (string): `[name], [sex]` (ambos opcionais)

**Formato de Comando:**
```
/hireling                              -- Nome default, sex=1
/hireling TestHireling                -- Nome custom, sex=1
/hireling TestHireling, 2             -- Nome e sex custom
```

**Fluxo de Execução:**

1. **Log do Comando:**
   ```lua
   logCommand(player, words, param)
   ```

2. **Parse de Parâmetros:**
   ```lua
   local split = param:split(",")
   local name = split[1] ~= "" and split[1] or "Hireling " .. player:getName()
   local sex = split[2] and tonumber(split[2]) or 1
   ```

   **Lógica Name:**
   - Se split[1] não vazio: usa split[1]
   - Se split[1] vazio ou param vazio: usa "Hireling " + nome do jogador

   **Lógica Sex:**
   - Se split[2] existe: converte tonumber(split[2])
   - Se split[2] não existe: usa 1 (default)

   **Exemplos:**
   ```lua
   -- Caso 1: sem parâmetro
   param = ""
   split[1] = ""
   split[2] = nil
   name = "Hireling PlayerName"
   sex = 1

   ---

   -- Caso 2: só nome
   param = "Guardian"
   split[1] = "Guardian"
   split[2] = nil
   name = "Guardian"
   sex = 1

   ---

   -- Caso 3: nome e sex
   param = "Guardian, 2"
   split[1] = "Guardian"
   split[2] = " 2"
   name = "Guardian"
   sex = 2
   ```

3. **Criar Hireling:**
   ```lua
   local result = player:addNewHireling(name, sex)
   ```
   - Chama player:addNewHireling() com nome e sexo
   - Retorna true/false

4. **Magic Effect (Sucesso):**
   ```lua
   if result then
       player:getPosition():sendMagicEffect(CONST_ME_MAGIC_GREEN)
   end
   ```
   - Se criado com sucesso: GREEN effect
   - Se falha: silencioso
