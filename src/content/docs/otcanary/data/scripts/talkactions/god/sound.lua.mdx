O arquivo sound.lua implementa 5 comandos de sound effects. Dispõe de area/internal/global sounds com single/double effects, ambient e music, validações de parâmetro, feedback personalizado. Ferramenta versátil de audio management.

## 🔧 Estrutura de Funcionalidades

### **TalkAction /areasound**

```lua
local areasound = TalkAction("/areasound")

function areasound.onSay(player, words, param)
	-- create log
	logCommand(player, words, param)

	if param == "" then
		player:sendCancelMessage("Command param required.")
		return true
	end

	local split = param:split(",")
	if not split[2] then
		-- Single effect
		local primaryEffect = tonumber(param)
		if primaryEffect == nil or primaryEffect == 0 then
			player:sendCancelMessage("Invalid command param.")
			return true
		end

		player:sendCancelMessage("Playing sound number " .. primaryEffect .. " on the area.")
		player:getPosition():sendSingleSoundEffect(primaryEffect, player:isInGhostMode() and nil or player)
		return true
	end

	-- Double effects
	local primaryEffect = tonumber(split[1])
	local secondaryEffect = tonumber(split[2])
	if primaryEffect == nil or secondaryEffect == nil then
		player:sendCancelMessage("Invalid command params.")
		return true
	end

	player:sendCancelMessage("Playing sound number " .. primaryEffect .. " and " .. secondaryEffect .. " on the area.")
	player:getPosition():sendDoubleSoundEffect(primaryEffect, secondaryEffect, player:isInGhostMode() and nil or player)
	return true
end

areasound:separator(" ")
areasound:groupType("god")
areasound:register()
```

**Comando:**
```
/areasound 100                  -- Single effect no local
/areasound 100, 200             -- Double effect no local
```

**Fluxo:**
1. Valida param não vazio
2. Se 1 param: Single effect
3. Se 2 params: Double effects
4. Considera ghost mode (não ouve se ghost)
5. Feedback ao executor

### **TalkAction /globalsound**

```lua
local globalsound = TalkAction("/globalsound")

function globalsound.onSay(player, words, param)
	-- create log
	logCommand(player, words, param)

	if param == "" then
		player:sendCancelMessage("Command param required.")
		return true
	end

	local split = param:split(",")
	if not split[2] then
		-- Single effect
		local primaryEffect = tonumber(param)
		if primaryEffect == nil or primaryEffect == 0 then
			player:sendCancelMessage("Invalid command param.")
			return true
		end

		player:sendCancelMessage("Playing sound number " .. primaryEffect .. " globally.")
		for _, pid in ipairs(Game.getPlayers()) do
			pid:sendSingleSoundEffect(primaryEffect, false)
		end
		return true
	end

	-- Double effects
	local primaryEffect = tonumber(split[1])
	local secondaryEffect = tonumber(split[2])
	if primaryEffect == nil or secondaryEffect == nil then
		player:sendCancelMessage("Invalid command params.")
		return true
	end

	player:sendCancelMessage("Playing sound number " .. primaryEffect .. " and " .. secondaryEffect .. " globally.")
	for _, pid in ipairs(Game.getPlayers()) do
		pid:sendDoubleSoundEffect(primaryEffect, secondaryEffect)
	end
	return true
end

globalsound:separator(" ")
globalsound:groupType("god")
globalsound:register()
```

**Comando:**
```
/globalsound 100                -- Single effect para todos
/globalsound 100, 200           -- Double effect para todos
```

**Fluxo:** Game.getPlayers() itera todos players online.

### **TalkAction /ambientsound**

```lua
local ambientSoundCommand = TalkAction("/ambientsound")

function ambientSoundCommand.onSay(player, words, param)
	logCommand(player, words, param)

	local soundId = tonumber(param)
	if not soundId then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Uso correto: /ambientsound <id> ou /ambientsound disable")
		return false
	end

	player:sendAmbientSoundEffect(soundId)
	return true
end

ambientSoundCommand:separator(" ")
ambientSoundCommand:groupType("gamemaster")
ambientSoundCommand:register()
```

**Comando:** `/ambientsound 50`

**Requisito:** GameMaster (nivel menor)

GM: /areasound 25

- Feedback: "Playing sound number 25 internally."

**Funções Globais Utilizadas**

| Função | Descrição |
|---|---|
| `logCommand(player, words, param)` | Log do comando |
| `param:split(sep)` | Divide string |
| `tonumber(str)` | Converte número |
| `player:getPosition()` | Posição do GM |
| `position:sendSingleSoundEffect(id, observer)` | 1 effect com observer opt |
| `position:sendDoubleSoundEffect(id1, id2, observer)` | 2 effects |
| `player:sendSingleSoundEffect(id)` | Internal single |
| `player:sendDoubleSoundEffect(id1, id2)` | Internal double |
| `player:sendAmbientSoundEffect(id)` | Ambient sound |
| `player:sendMusicSoundEffect(id)` | Music sound |
| `player:isInGhostMode()` | Valida ghost |
| `Game.getPlayers()` | Lista all online |
| `player:sendTextMessage(type, msg)` | Envia mensagem |

- `MESSAGE_EVENT_ADVANCE`
