## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `add_condition.lua` implementa um comando TalkAction (`/testtaintconditions`) que aplica ícone de taint ao jogador executor. O sistema é minimalista, executa `setTaintIcon()` diretamente, e retorna silenciosamente. Ferramenta de debug para testar sistema de taint.

## 🔧 Estrutura de Funcionalidades

```lua
local talkaction = TalkAction("/testtaintconditions")

function talkaction.onSay(player, words, param)
    -- Aplicar taint icon ao player
    player:setTaintIcon()
    
    -- Retornar false: executa comando mas sem mensagem
    return false
end

talkaction:separator(" ")
talkaction:groupType("god")
talkaction:register()
```
