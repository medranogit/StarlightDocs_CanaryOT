## 📄 Visão Geral do Código - Resumo Executivo

O arquivo flags.lua implementa sistema completo de gerenciamento de 40+ flags de permissão. Dispõe de tabela centralizada (PlayerFlags_t), helper functions para conversão e busca, extensions Player para validar/set/remove flags, 3 TalkActions (/hasflag, /setflag, /removeflag), logging automático, validações rigorosas, e interface visual (showTextDialog). Ferramenta essencial de permission management.

## 🤖 Documentação das Funções

### **Funções Locais**

#### **sendValidKeys(player)**

**Descrição:** Envia diálogo com lista de flags válidas ao jogador.

```lua
local function sendValidKeys(player)
	local flagsList = {}
	for flagName, _ in pairs(PlayerFlags_t) do
		table.insert(flagsList, flagName)
	end
	local text = "Invalid flag. Valid flags are: " .. table.concat(flagsList, "\n")
	player:showTextDialog(2019, text)
end
```

**Parâmetros:**
- `player` (Player): Jogador que recebe a mensagem

**Funcionamento:**
- Extrai todos os nomes de flags da tabela
- Concatena em string com quebras de linha
- Mostra em dialog com ID 2019

---

#### **getFlagNumberOrName(flagType)**

**Descrição:** Converte flag por nome ou número para valor enum.

```lua
local function getFlagNumberOrName(flagType)
	for flagName, flagEnum in pairs(PlayerFlags_t) do
		if tonumber(flagEnum) == tonumber(flagType) then
			return flagEnum
		end
		if type(flagType) == "string" and string.lower(flagType) == string.lower(flagName) then
			return flagEnum
		end
	end
	return nil
end
```

**Parâmetros:**
- `flagType` (number|string): Flag ID ou nome

**Retorno:**
- Enum value se encontrado
- nil se não encontrado

**Exemplos:**
```lua
getFlagNumberOrName("CannotUseCombat")  -- retorna enum
getFlagNumberOrName(1)                  -- retorna enum
getFlagNumberOrName("invalid")          -- retorna nil
```

---

#### **getFlagNameByType(flagType)**

**Descrição:** Obtém nome textual da flag pelo número.

```lua
local function getFlagNameByType(flagType)
	for flagName, flagEnum in pairs(PlayerFlags_t) do
		if tonumber(flagEnum) == tonumber(flagType) then
			return flagName
		end
	end
	return nil
end
```

**Parâmetros:**
- `flagType` (number): Flag ID

**Retorno:**
- Nome string se encontrado
- nil se não encontrado

### **Extensões Player**

#### **Player.talkactionHasFlag(self, param, flagType)**

**Descrição:** Verifica se jogador tem determinada flag.

**Parâmetros:**
- `param` (string): "PlayerName, flagname|number"
- `flagType` (number): Flag enum

**Validações:**
```lua
if not HasValidTalkActionParams(self, param, "Usage: /hasflag <playerName>, <flagnumber or name>") then
	return true
end
```

**Fluxo:**
1. Valida parâmetros
2. Parse "PlayerName, flag"
3. Busca jogador
4. Busca flag
5. Verifica `targetPlayer:hasGroupFlag(flagValue)`
6. Mensagem de resultado

**Mensagens:**
```
"Player <name> have flag type: <flagname>."       (tem)
"Player <name> not have flag type: <flagname>."   (não tem)
```

---

#### **Player.talkactionSetFlag(self, param, flagType)**

**Descrição:** Adiciona flag ao jogador.

**Validações:**
- Parâmetros válidos
- Jogador existe
- Flag válida
- Jogador não tem flag já

**Fluxo:**
```lua
if targetPlayer:hasFlag(flagValue) then
	self:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Player " .. playerName .. " already has flag " .. getFlagNameByType(flagValue) .. ".")
	return true
end

targetPlayer:setGroupFlag(flagValue)
```

**Logging:**
```lua
logger.info("[Player.talkactionSetFlag] Added flag {} to {} character by {}.", getFlagNameByType(flagValue), targetPlayer:getName(), self:getName())
```

---

#### **Player.talkactionRemoveFlag(self, param, flagType)**

**Descrição:** Remove flag de jogador.

**Validações:**
- Jogador existe
- Flag é válida
- Jogador tem flag

**Fluxo:**
```lua
if not targetPlayer:hasFlag(flagValue) then
	self:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Player " .. playerName .. " not have flag " .. getFlagNameByType(flagValue) .. ".")
	return true
end

targetPlayer:removeGroupFlag(flagValue)
```

O arquivo flags.lua é sistema completo de permission management. Essencial para GMs controlar permissões, criar ranks customizados, testar restrições. Design flexível suporta busca por nome ou ID.
