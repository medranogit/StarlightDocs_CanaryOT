### **TalkAction /reload**

```lua
local reloadTalk = TalkAction("/reload")

function reloadTalk.onSay(player, words, param)
	logCommand(player, words, param)
	
	-- Gate: ALLOW_RELOAD
	if not configManager.getBoolean(configKeys.ALLOW_RELOAD) then
		player:sendCancelMessage("Reload is not allowed!")
		return true
	end
	
	-- Parâmetro vazio
	if param == "" then
		player:sendCancelMessage(string.format("Usage: /reload <type>"))
		return true
	end
	
	-- Parse tipo
	param = param:trim():lower()
	local reloadType = reloadTypes[param]
	
	-- Validação: tipo existe?
	if not reloadType then
		player:sendCancelMessage(string.format("Unknown reload type: '%s'", param))
		return true
	end
	
	-- Fazer reload
	local errorCode = Game.reload(reloadType)
	
	-- Save after reload
	if reloadType == RELOAD_TYPE_CONFIG then
		saveServer()
	end
	
	if reloadType == RELOAD_TYPE_ALL then
		SaveHirelings()
	end
	
	-- Feedback
	if errorCode == RELOAD_STATUS_OK then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, string.format("Type '%s' reloaded successfully.", param))
	elseif errorCode == RELOAD_STATUS_WARNING then
		player:sendTextMessage(MESSAGE_LOOK, string.format("Type '%s' reloaded with warning. Check logs.", param))
	else
		player:sendTextMessage(MESSAGE_ADMINISTRATOR, string.format("Error reloading '%s'. Check logs for details.", param))
	end
	
	return true
end

reloadTalk:separator(" ")
reloadTalk:groupType("god")
reloadTalk:register()
```

**Comando:** `/reload <type>`

**Parâmetros:**
| Param | Nome | Tipo |
|---|---|---|
| 1 | type | string (lowercase) |

**Exemplos de Uso:**

```
GM: /reload config

Fluxo:
1. Valida ALLOW_RELOAD habilitado
2. Game.reload(RELOAD_TYPE_CONFIG)
3. saveServer() - salva config
4. Feedback: "Type 'config' reloaded successfully."

Resultado:
- Configurações recarregadas
- Nova config em memória
- Banco de dados de configs atualizado

---

GM: /reload all

Fluxo:
1. Game.reload(RELOAD_TYPE_ALL)
2. SaveHirelings() - salva hireling data
3. Recarrega TUDO
4. Feedback: "Type 'all' reloaded successfully."

Resultado:
- Servidor recarregado completamente
- Sem restart necessário
- Todas as mudanças em arquivo aplicadas

---

GM: /reload script

Fluxo:
1. Game.reload(RELOAD_TYPE_SCRIPTS)
2. Scripts Lua recompilados
3. Feedback: "Type 'script' reloaded successfully."

Resultado:
- Novos scripts carregados
- Mudanças em Lua aplicadas

---

GM: /reload mounts

Fluxo:
1. Game.reload(RELOAD_TYPE_MOUNTS)
2. Mount database recarregado
3. Feedback: "Type 'mounts' reloaded successfully."

Resultado:
- Novos mounts disponíveis
```
