O arquivo raids.lua implementa sistema completo de raid management com 3 comandos. Dispõe de raid starter com delay configurável, simulador com chance rolls, lister, validações de raid existe, integration com Raid registry. Ferramenta essencial de raid control.

## 🔧 Estrutura de Funcionalidades

### **TalkAction /raid**

```lua
local raidTalk = TalkAction("/raid")

function raidTalk.onSay(player, words, param)
	logCommand(player, words, param)
	
	if param == "" then
		player:sendCancelMessage("Usage: /raid <boss> [delay]")
		return true
	end
	
	local split = param:split(",")
	local boss = split[1]:trim()
	local delay = split[2] and ParseDuration(split[2]:trim()) or 0
	
	local raid = Raid.registry:getRaid(boss)
	if not raid then
		player:sendCancelMessage("Raid '" .. boss .. "' does not exist.")
		return true
	end
	
	-- Iniciar raid
	if raid:tryStart() then
		local delaySec = math.floor(delay / 1000)
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Raid '" .. boss .. "' will start in " .. delaySec .. " second(s).")
	else
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Failed to start raid " .. boss .. ".")
	end
	
	return true
end

raidTalk:separator(" ")
raidTalk:groupType("god")
raidTalk:register()
```

**Comando:** `/raid BossName`

**Parâmetros:**
| Param | Nome | Default | Tipo |
|---|---|---|---|
| 1 | boss | (obrigatório) | string |
| 2 | delay | 0 | duration |

**Durações Suportadas:**
```
5s, 1m, 1m30s, 2h, 1d, etc.
ParseDuration converte para milissegundos
```

**Fluxo:**
1. Parse boss name e delay (opt)
2. Busca na Raid.registry
3. tryStart() inicia raid
4. Feedback ou erro

### **TalkAction /simraid**

```lua
local simRaid = TalkAction("/simraid")

function simRaid.onSay(player, words, param)
	logCommand(player, words, param)
	
	if param == "" then
		player:sendCancelMessage("Usage: /simraid <raidname> [amount]")
		return true
	end
	
	local split = param:split(",")
	local raidName = split[1]:trim()
	local amount = tonumber(split[2]) or 1
	
	local raid = Raid.registry:getRaid(raidName)
	if not raid then
		player:sendCancelMessage("Raid '" .. raidName .. "' does not exist.")
		return true
	end
	
	-- Simulação
	local zone = Zone("raid.simzone")
	if zone:isPossible() then
		local triggerCount = 0
		local rolls = 0
		
		-- Rolar simulação
		for _ = 1, amount do
			if math.random(100) < 50 then  -- 50% chance exemplo
				triggerCount = triggerCount + 1
			end
			rolls = rolls + 1
		end
		
		local message = "Simulation finished. Rolled: " .. rolls .. ", Triggered: " .. triggerCount
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, message)
	else
		player:sendCancelMessage("Failed to load simulation zone.")
	end
	
	return true
end

simRaid:separator(" ")
simRaid:groupType("god")
simRaid:register()
```

**Comando:** `/simraid RaidName [Amount]`

**Parâmetros:**
| Param | Nome | Default | Tipo |
|---|---|---|---|
| 1 | raidName | (obrigatório) | string |
| 2 | amount | 1 | number |

**Fluxo:**
1. Parse raid name e amount
2. Busca raid na registry
3. Carrega simulation zone
4. Rola X vezes com random
5. Conta triggers vs rolls

### **TalkAction /listraid**

```lua
local listRaid = TalkAction("/listraid")

function listRaid.onSay(player, words, param)
	logCommand(player, words, param)
	
	local raids = Raid.registry:getRaids()
	if not raids or #raids == 0 then
		player:sendCancelMessage("No raids registered.")
		return true
	end
	
	-- Listar todas
	local message = "Registered Raids:\n"
	for _, raid in ipairs(raids) do
		message = message .. "- " .. raid:getName() .. "\n"
	end
	
	player:sendTextMessage(MESSAGE_LOOK, message)
	return true
end

listRaid:separator(" ")
listRaid:groupType("god")
listRaid:register()
```

**Comando:** `/listraid`

**Fluxo:**
1. Obtém todas raids
2. Itera e mostra nomes
3. Feedback com lista
