## 📄 Visão Geral do Código - Resumo Executivo

O arquivo goto_house.lua implementa comando de teleportação para casas. Dispõe de 2 modos (casa própria/outra), validações de existência, exit position lookup. Ferramenta essencial de house management travel.

## 🔧 Estrutura de Funcionalidades

### **TalkAction /gotohouse**

```lua
local sellHouse = TalkAction("/gotohouse")

function sellHouse.onSay(player, words, param)
	-- Modo 1: Teleportar para casa de outro player
	local targetPlayer = Player(param)
	if targetPlayer then
		local targetHouse = targetPlayer:getHouse()
		if not targetHouse then
			targetPlayer:sendCancelMessage(string.format("The player %s not have house.", player:getName()))
			return
		end

		targetPlayer:teleportTo(targetHouse:getExitPosition())
	else
		-- Modo 2: Teleportar para casa própria
		local house = player:getHouse()
		if not house then
			player:sendCancelMessage("You not have house. For goto house of one player use the player name param, usage: /gotohouse playername")
			return
		end

		player:teleportTo(house:getExitPosition())
	end

	return true
end

sellHouse:separator(" ")
sellHouse:groupType("god")
sellHouse:register()
```

**Comando:**
```
/gotohouse                          -- Teleporta para casa própria
/gotohouse PlayerName               -- Teleporta para casa do player
```

## **Modos de Operação**

### **Modo 1: Casa Própria**

```
/gotohouse

Fluxo:
1. param vazio
2. targetPlayer = Player("") = nil
3. Vai para else
4. player:getHouse() busca casa própria
5. Valida se house existe
6. getExitPosition() obtém saída
7. player:teleportTo(exitPos)

Resultado:
- GM teleportado para saída da casa
- Feedback silencioso
```

---

### **Modo 2: Casa de Outro Player**

```
/gotohouse TestPlayer

Fluxo:
1. param = "TestPlayer"
2. targetPlayer = Player("TestPlayer")
3. Valida targetPlayer existe
4. targetHouse = targetPlayer:getHouse()
5. Valida house existe
6. getExitPosition() obtém saída
7. teleportTo(exitPos) teleporta

Resultado:
- GM teleportado para saída da casa de TestPlayer
- Feedback de erro se TestPlayer sem casa
```

1. Player("OfflinePlayer") = nil

"You not have house..."
