## 📄 Visão Geral do Código - Resumo Executivo

O arquivo open_server.lua implementa comando simples de server control. Altera game state para NORMAL (abre servidor). Notifica via webhook para announcements channel. Ferramenta essencial de server state management.

## 🔧 Estrutura de Funcionalidades

### **TalkAction /openserver**

```lua
local openServer = TalkAction("/openserver")

function openServer.onSay(player, words, param)
	logCommand(player, words, param)
	
	-- Abrir servidor
	Game.setGameState(GAME_STATE_NORMAL)
	
	-- Notificar via webhook
	webhook:sendMessage("Server is back online!", announcementChannels["serverAnnouncements"])
	
	return true
end

openServer:separator(" ")
openServer:groupType("god")
openServer:register()
```

**Comando:** `/openserver`

**Fluxo:**
1. Altera game state
2. GAME_STATE_NORMAL = servidor aberto
3. Notificação webhook

---

## **Game States**

```lua
GAME_STATE_NORMAL = 0          -- Servidor aberto (padrão)
GAME_STATE_STARTUP = 1         -- Startup (loading)
GAME_STATE_CLOSED = 2          -- Fechado
GAME_STATE_CLOSING = 3         -- Fechando
GAME_STATE_SHUTDOWN = 4        -- Shutdown
```

Comando `Game.setGameState(state)` altera o estado atual.

---

**Exemplos de Uso:**

```
GM: /openserver

Fluxo:
1. Game.setGameState(GAME_STATE_NORMAL)
2. Servidor agora aceita novos players
3. Webhook envia: "Server is back online!"
4. Anúncio do Discord/Webhook

Resultado:
- Servidor aberto para conexões
- Webhook notificação enviada
- Log do comando registrado
```
