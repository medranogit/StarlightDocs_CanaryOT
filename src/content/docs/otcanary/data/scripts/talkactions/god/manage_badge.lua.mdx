## 📄 Visão Geral do Código - Resumo Executivo

O arquivo manage_badge.lua implementa comando TalkAction (/addbadge) que adiciona badges (emblemas visuais) a jogadores. O sistema valida parâmetros, busca jogador online, adiciona badge via API, feedback personalizado para executor e alvo. Ferramenta de badge cosmética management.

## 🔧 Estrutura de Funcionalidades

```lua
local addBadge = TalkAction("/addbadge")

function addBadge.onSay(player, words, param)
	-- create log
	logCommand(player, words, param)
	
	-- Validação: parâmetro vazio
	if param == "" then
		player:sendCancelMessage("Command param required.")
		return true
	end
	
	-- Parse: playerName, badgeID
	local split = param:split(",")
	if not split[2] then
		player:sendCancelMessage("Insufficient parameters. Usage: /addbadge playerName, badgeID")
		return true
	end
	
	-- Buscar jogador
	local target = Player(split[1])
	if not target then
		player:sendCancelMessage("A player with that name is not online.")
		return true
	end
	
	-- Adicionar badge
	split[2] = split[2]:trimSpace()
	local id = tonumber(split[2])
	if target:addBadge(id) then
		-- Feedback: executor
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, string.format('You added a badge with ID "%i" to player "%s".', id, target:getName()))
		-- Feedback: alvo
		target:sendTextMessage(MESSAGE_EVENT_ADVANCE, string.format("%s added a badge to you.", player:getName()))
	end
	return true
end

addBadge:separator(" ")
addBadge:groupType("god")
addBadge:register()
```
