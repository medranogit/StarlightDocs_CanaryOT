## 📄 Visão Geral do Código - Resumo Executivo

O arquivo test_send_message.lua implementa comando de teste de tipos de mensagem. Dispõe de 2 parâmetros (tipo obrigatório, cor opcional), default color (WHITE_EXP), feedback de teste. Ferramenta debug para message system.

## 🔧 Estrutura de Funcionalidades

### **TalkAction /testmessage**

```lua
local sendMessage = TalkAction("/testmessage")

function sendMessage.onSay(player, words, param)
	-- create log
	logCommand(player, words, param)

	if param == "" or param == nil then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Message type is missing, please enter a message type.")
		return
	end

	-- Parse parâmetros
	local split = param:split(",")
	local messageType = tonumber(split[1])
	local textCollor = TEXTCOLOR_WHITE_EXP
	if split[2] then
		textCollor = tonumber(split[2])
	end

	-- Enviar mensagem de teste
	player:sendTextMessage(messageType, "Testing message type.", player:getPosition(), 500, textCollor)
	return true
end

sendMessage:separator(" ")
sendMessage:groupType("god")
sendMessage:register()
```

**Comando:**
```
/testmessage 23                     -- Teste tipo 23 (color default WHITE_EXP)
/testmessage 23, 215                -- Teste tipo 23 com color 215
```

## **Fluxo de Execução**

```
/testmessage 23, 215

Fluxo:
1. Valida param não vazio
2. Parse split(","):
   - messageType = 23
   - textColor = 215
3. Fallback color se não informado:
   - textColor = TEXTCOLOR_WHITE_EXP (215)
4. player:sendTextMessage(
     messageType = 23,
     message = "Testing message type.",
     position = player:getPosition(),
     distance = 500,
     textColor = 215
   )
5. Feedback: "Testing message type." na cor 215

Resultado:
- Mensagem de teste enviada
- Tipo 23 testado
- Cor 215 aplicada
```

**Erros Comuns:**

```
Error: "Message type is missing, please enter a message type."
- Param vazio ou nil
- Solução: /testmessage <type>

Erro: Mensagem não aparece
- MessageType inválido (negativo ou > MAX_MESSAGE_TYPE)
- Solução: Use tipos conhecidos (16-47)

Erro: Cor não aplicada
- TEXTCOLOR inválido
- Solução: Use cores conhecidas
```
