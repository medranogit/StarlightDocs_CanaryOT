```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 7.3) + 42
```

### Função Global: rune.onCastSpell (VALIDAÇÕES)

```lua
function rune.onCastSpell(creature, var, isHotkey)
	local player = Player(creature)
	if not player then
		return false
	end

	local vocation = player:getVocation():getName():lower()
	if vocation == "exalted monk" then
		player:sendCancelMessage("Your vocation cannot use this rune.")
		player:getPosition():sendMagicEffect(CONST_ME_POFF)
		return false
	end

	if Monster(var:getNumber(1073762188)) then
		player:sendCancelMessage("Sorry, not possible.")
		player:getPosition():sendMagicEffect(CONST_ME_POFF)
		return false
	end

	return combat:execute(player, var)
end
```

**Propósito:** Handler com validações duplas.

**Fluxo:**

| Step | Ação | Resultado |
|---|---|---|
| 1 | Cast rune | Handler called |
| 2 | Player check | Se não player: false |
| 3 | Vocation check | Se "exalted monk": reject |
| 4 | Monster check | Se monster: reject |
| 5 | Execute | combat:execute() |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Cura realizada |
| `false` | Validação falhou |

**Descrição:** Cura com validações múltiplas.

|---|---|---|

**Retorno:**

| Valor | Descrição |
|---|---|

| `false` | Validação falhou ou target inválido |

**Validações:**

| Validação | Rejeita | Mensagem |
|---|---|---|
| Player check | Não-players | (falhou silencioso) |
| Vocation | "exalted monk" | "Your vocation cannot use this rune." |
| Monster | Monstros | "Sorry, not possible." |

**Efeito:**
- Efeito cura azul
- Cura sin negativo (apenas recuperação)
- Dispel paralyze automático
- Cooldown 1s

**Exemplo:**

```lua

rune.onCastSpell(cleric, targetVariant, false)
// ✓ Validação player OK
// ✓ Validação vocation OK (não é monk)
// ✓ Validação monster OK (é player)
// Executa: combat:execute()
// Cura: +161 a +286 HP
// Dispel: remove paralyze
// Sons: ULTIMATE_HEALING
// Resultado: 1 carga consumida!
```
