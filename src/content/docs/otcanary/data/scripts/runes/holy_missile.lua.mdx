## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `holy_missile` oferece dano sagrado classe-restrita:

- **Dano:** COMBAT_HOLYDAMAGE escalável agressivo
- **Fórmula:** (level/5) + (maglevel*1.79/3.75) + bônus
- **Vocação:** Paladin/Royal Paladin only
- **Distancia:** Permitida
- **Cargas:** 5 (moderadas)

### Arquitetura

Combat com fórmula callback agressiva:

```
local combat = Combat()
├─ Type: COMBAT_HOLYDAMAGE
├─ Effect: HOLYDAMAGE
├─ Effect: HOLYAREA
├─ Distance: HOLY
└─ Callback: onGetFormulaValues

onGetFormulaValues()
└─ min/max escalável agressivo

rune.onCastSpell()
└─ combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_HOLYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HOLYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HOLYAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_HOLY)
```

**Propósito:** Instância de Combat para míssil sagrado.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_HOLYDAMAGE | Dano sagrado |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HOLYDAMAGE | Efeito impacto |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HOLYAREA | Efeito área |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_HOLY | Projétil sagrado |

**Características:**
- Sem `combat:setArea()` = single target
- Múltiplos efeitos visuais
- Callback para fórmula agressiva
- Vocação restrita (Paladin)

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.79) + 11
	local max = (level / 5) + (maglevel * 3.75) + 24
	return -min, -max
end
```

**Propósito:** Calcula dano sagrado escalável agressivo.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level total |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 1.79) + 11
max = (level / 5) + (maglevel * 3.75) + 24
```

**Pesos:**
- Level: 0.2 por ponto (padrão)
- Maglevel min: 1.79 (ALTO)
- Maglevel max: 3.75 (MUITO ALTO!)
- Bônus: 11/24 (suporta escalabilidade)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 27 | 4 | 24 | 44 |
| 50 | 10 | 40 | 75 |
| 80 | 20 | 56 | 129 |
| 100 | 30 | 66 | 175 |

## 🤖 Documentação das Funções

### onGetFormulaValues(player, level, maglevel)

**Descrição:** Calcula dano sagrado de holy missile (agressivo).

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|

| `-max` | number | Dano máximo |

**Exemplo:**

```lua

// max = 10 + 37.5 + 24 = 71.5
// Retorna: -38.9, -71.5
```

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Lança míssil sagrado com dano escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador (Paladin) |
| `var` | Variant | Target (obrigatório) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Míssil sagrado lançado |
| `false` | Vocação inválida ou target falhou |

**Efeito:**
- Validação vocacional (Paladin only)
- Projétil sagrado viaja (distancia)
- Impacto HOLYDAMAGE + HOLYAREA
- Dano escalável agressivo

**Exemplo:**

```lua
-- Paladino nível 50, MLvl 10
rune.onCastSpell(paladin, targetVariant, false)
// Valida vocação = OK (Paladin)
// Projétil sagrado viaja
// Efeitos visuais duplos (Holy x2)
// Resultado: -38 a -71 dano sagrado
```
