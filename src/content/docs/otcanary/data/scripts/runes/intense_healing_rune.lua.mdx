## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `intense_healing_rune` oferece cura early game com validação:

- **Cura:** COMBAT_HEALING (não dano!)
- **Fórmula:** (level/5) + (maglevel*3.2/5.4) + bônus
- **Validação:** Monster check
- **Acesso:** Level 15 (MUITO CEDO!)
- **Cargas:** 1 (custosa!)

### Arquitetura

Combat com fórmula callback + validação especial:

```
local combat = Combat()
├─ Type: COMBAT_HEALING
├─ Effect: MAGIC_BLUE
├─ Aggressive: 0 (healing)
├─ Callback: onGetFormulaValues
└─ Dispel: CONDITION_PARALYZE

rune.onCastSpell()
├─ Monster check (validação)
├─ Se monstro: cancela
└─ Else: combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_HEALING)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_MAGIC_BLUE)
combat:setParameter(COMBAT_PARAM_AGGRESSIVE, 0)
combat:setParameter(COMBAT_PARAM_TARGETCASTERORTOPMOST, 1)
combat:setParameter(COMBAT_PARAM_DISPEL, CONDITION_PARALYZE)
```

**Propósito:** Instância de Combat para cura intensa.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_HEALING | Tipo cura |
| `COMBAT_PARAM_EFFECT` | CONST_ME_MAGIC_BLUE | Efeito magia azul |
| `COMBAT_PARAM_AGGRESSIVE` | 0 | Não agressivo |
| `COMBAT_PARAM_TARGETCASTERORTOPMOST` | 1 | Alvo ou self |
| `COMBAT_PARAM_DISPEL` | CONDITION_PARALYZE | Remove paralyze |

**Características:**
- Sem `combat:setArea()` = single target
- Callback para fórmula escalável cura
- Dispel automático de paralyze
- Não agressivo (proteção PG)

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 3.2) + 20
	local max = (level / 5) + (maglevel * 5.4) + 40
	return min, max
end
```

**Propósito:** Calcula cura escalável (POSITIVO, não negativo!).

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level total |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `min` | number | Cura mínima (POSITIVO!) |
| `max` | number | Cura máxima (POSITIVO!) |

**Fórmula:**
```
min = (level / 5) + (maglevel * 3.2) + 20
max = (level / 5) + (maglevel * 5.4) + 40
```

**Diferença Chave:** Retorna `min, max` (não negativo!)

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 3.2 (ALTO)
- Maglevel max: 5.4 (MUITO ALTO!)
- Bônus: 20/40 (suporta early)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 15 | 1 | 26 | 48 |
| 40 | 8 | 51 | 91 |
| 80 | 20 | 80 | 148 |
| 100 | 30 | 98 | 204 |

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var, isHotkey)
	if Monster(var:getNumber(1073762188)) then
		creature:sendCancelMessage("Sorry, not possible.")
		creature:getPosition():sendMagicEffect(CONST_ME_POFF)
		return false
	else
		return combat:execute(creature, var)
	end
end
```

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Cura com validação contra monstros e dispel.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Target (alvo ou self) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Cura aplicada |
| `false` | Alvo é monstro (blocked) |

**Validação:**
- Monster check: `var:getNumber(1073762188)`
- Se monstro: cancela com send message + effect
- Se player/self: aplica cura

**Efeito:**
- Cura escalável
- Dispel automático paralyze
- Efeito visual MAGIC_BLUE
- No PZ lock (funciona town)

**Exemplo:**

```lua
-- Mago nível 40, MLvl 8 cura aliado
rune.onCastSpell(mago, aliadoVariant, false)
// Monster check: é player? SIM
// Calcula: -53 a -91 cura
// Dispel paralyze se houver
// Efeito azul
// Resultado: Aliado curado!

-- Mago tenta curar um monstro
rune.onCastSpell(mago, monstroVariant, false)
// Monster check: é monstro? SIM
// Cancela com: "Sorry, not possible."
// Efeito poff (erro)
// Resultado: Bloqueado!
```
