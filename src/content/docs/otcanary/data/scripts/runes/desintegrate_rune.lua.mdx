## 💡 Tip

<Aside type="tip">
**Remoção de Itens com Proteção e Limite**

Esta runa implementa um **sistema de limpeza com salvaguardas**:

1. **Validações:**
   - Item deve ser movable
   - Unique ID > 65535 (itens gerados, não hardcoded)
   - Action ID = 0 (sem associação de quest)
   - Corpses excluídos por lista (7 IDs protegidos)

2. **Limite de 500:** Previne lag ao remover muitos itens
3. **Sem Feedback Visual:** Sempre retorna true (mesmo sem remove)
4. **Range 1:** Apenas adjacente, não far use

**Fluxo:**
```
Aponta runa em tile
├─ Pega todos itens na tile
├─ Loop com limite 500
│  ├─ Valida movable?
│  ├─ Valida unique ID > 65535?
│  ├─ Valida actionid = 0?
│  ├─ Valida não é corpse?
│  └─ Remove se passa
└─ Sempre retorna true
```

**Diferencial:** Protege corpses e itens "especiais" (quest, hardcoded).
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `desintegrate_rune` oferece limpeza controlada:

- **Alvo:** Itens em tile (range 1)
- **Critérios:** Movable + unique ID + sem actionid
- **Exclusões:** Corpses (7 IDs) + hardcoded items
- **Limite:** 500 itens por conjuração

### Arquitetura

Iteração com 4 validações em cascata + limite:

```
onCastSpell(creature, variant, isHotkey)
├─ Pega position (variant)
├─ Pega tile (position)
├─ Pega items array
├─ Loop com limite 500:
│  ├─ Valida movable
│  ├─ Valida unique ID > 65535
│  ├─ Valida actionid = 0
│  ├─ Valida não é corpse
│  └─ Remove se passar
└─ Sempre retorna true
```

### Fluxo Lógico Resumido

| Etapa | Descrição |
|---|---|
| **Pega Position** | Tile alvo |
| **Pega Items** | Array de todos itens |
| **Loop com Limite** | Até 500 itens |
| **Validação** | 4 critérios |
| **Remove** | Se passar validação |

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, variant, isHotkey)
	local position = variant:getPosition()
	local tile = Tile(position)
	if tile then
		local items = tile:getItems()
		if items then
			for i, item in ipairs(items) do
				if item:getType():isMovable() and item:getUniqueId() > 65535 and item:getActionId() == 0 and not table.contains(corpseIds, item:getId()) then
					item:remove()
				end

				if i == removalLimit then
					break
				end
			end
		end
	end

	creature:sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
	position:sendMagicEffect(CONST_ME_POFF)
	return true
end
```

**Propósito:** Handler principal da runa ao conjuração.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Jogador conjurando |
| `variant` | Variant | Position alvo |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Sempre (remoção feita ou não) |

**Fluxo Detalhado:**

1. **Extrai Position:** `variant:getPosition()`
2. **Pega Tile:** `Tile(position)`
3. **Validação Tile Existente:**
   ```lua
   if tile then
       -- Continua
   end
   ```

4. **Pega Items Array:** `tile:getItems()`
5. **Validação Items Existem:**
   ```lua
   if items then
       -- Loop
   end
   ```

6. **Loop com Índice:**
   ```lua
   for i, item in ipairs(items) do
   ```
   - `i`: Índice (1, 2, 3, ...)
   - `item`: Item atual

7. **Validação em Cascata:**
   ```lua
   if item:getType():isMovable() and 
      item:getUniqueId() > 65535 and 
      item:getActionId() == 0 and 
      not table.contains(corpseIds, item:getId()) then
       item:remove()
   end
   ```

   **Sub-validações:**
   - `isMovable()`: Item não é wall/static
   - `getUniqueId() > 65535`: Item é gerado (não hardcoded)
     - Unique IDs 0-65535: items fixos do mapa
     - Unique IDs > 65535: items criados em runtime
   - `getActionId() == 0`: Item não tem quest association
   - `not table.contains(corpseIds, id)`: Não é corpse protegido

8. **Remove se Passa:**
   ```lua
   item:remove()
   ```

9. **Verifica Limite:**
   ```lua
   if i == removalLimit then
       break
   end
   ```
   - Para loop após 500 itens

10. **Feedback (sempre executado):**
    ```lua
    creature:sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
    position:sendMagicEffect(CONST_ME_POFF)
    return true
    ```
    - Mensagem: "não foi possível"
    - Efeito: POFF
    - Nota: Mensagem é genérica mesmo com sucesso

| Nome | Tipo | Descrição |
|---|---|---|

- POFF na tile
- Mensagem genérica "não foi possível"

```lua
rune.onCastSpell(player, tileVariant, false)

// 3 são corpse ou não-movable -> mantidos
// POFF effect na tile
// Resultado: 7 itens desintegrados
```
