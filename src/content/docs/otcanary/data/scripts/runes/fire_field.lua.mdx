### Propósito Principal

A runa `fire_field` oferece primeira experiência com campos:

- **Dano:** COMBAT_FIREDAMAGE (fixo)
- **Field:** ITEM_FIREFIELD_PVP_FULL
- **Área:** Single tile
- **Early Access:** Level 15 (muito cedo!)

```
local combat = Combat()

├─ Effect: HITBYFIRE

rune.onCastSpell()
└─ combat:execute(creature, var)
```

### Fluxo Lógico Resumido

| Etapa | Descrição |
|---|---|

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_FIREDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITBYFIRE)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_FIRE)
combat:setParameter(COMBAT_PARAM_CREATEITEM, ITEM_FIREFIELD_PVP_FULL)
```

**Propósito:** Instância de Combat para field de fogo.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_FIREDAMAGE | Dano fogo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HITBYFIRE | Efeito queimadura |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_FIRE | Projétil fogo |
| `COMBAT_PARAM_CREATEITEM` | ITEM_FIREFIELD_PVP_FULL | Field completo |

**Características:**
- Sem `combat:setArea()` = padrão single
- Sem callback = dano fixo
- Field FULL = durável

---

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var, isHotkey)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler principal da runa ao conjuração.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Alvo (position) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Field criado |
| `false` | PZ lock bloqueado |
