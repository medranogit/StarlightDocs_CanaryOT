## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `lightest_magic_missile` oferece prática educacional:

- **Dano:** COMBAT_ENERGYDAMAGE fixo 3-5
- **Fórmula:** Constante (sem callback!)
- **Área:** Single target
- **Vocação:** Todas (8 types)
- **Cargas:** 10 (sessão longa)

### Arquitetura

Combat sem fórmula callback:

```
local combat = Combat()
├─ Type: COMBAT_ENERGYDAMAGE
├─ Effect: ENERGYAREA
├─ Distance: ENERGY
└─ Callback: onGetFormulaValues (fixo!)

onGetFormulaValues()
└─ return -3, -5 (constante!)

rune.onCastSpell()
└─ combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGY)
```

**Propósito:** Instância de Combat para míssil de prática.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ENERGYDAMAGE | Dano energia |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ENERGYAREA | Efeito explosão |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ENERGY | Projétil energia |

**Características:**
- Sem `combat:setArea()` = single target
- Callback retorna constante
- Sem armor bypass
- Sem escalabilidade (feature!)

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	return -3, -5
end
```

**Propósito:** Retorna dano fixo (ignora player stats!).

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador (ignorado!) |
| `level` | number | Level (ignorado!) |
| `maglevel` | number | Magic level (ignorado!) |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-3` | number | Dano mínimo fixo |
| `-5` | number | Dano máximo fixo |

**Fórmula:**
```
Sempre: min = 3, max = 5
Não escalável
Não configurável
```

**Constância:**
- Level 1: 3-5 dano
- Level 100: 3-5 dano (mesma!)
- MLvl 0: 3-5 dano
- MLvl 50: 3-5 dano (mesma!)

---

### Registração do Callback

```lua
combat:setCallback(CALLBACK_PARAM_LEVELMAGICVALUE, "onGetFormulaValues")
```

function rune.onCastSpell(creature, var, isHotkey)

end

**Propósito:** Handler da runa educacional.

**Retorno:**

|---|---|
| `true` | Míssil prática lançado |

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Lança míssil de prática com dano fixo.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Target (obrigatório) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Prática ativada |
| `false` | Target falhou |

**Efeito:**
- Projétil energia viaja
- Som PRACTISE (educacional)
- Impacto ENERGYAREA
- Dano fixo 3-5 sempre
- Single target

**Exemplo:**

```lua
-- Newbie sorcerer nível 1, MLvl 0
rune.onCastSpell(sorcerer, targetVariant, false)
// Primeira execução
// Aprende: targeting, distancia, cooldown
// Dano: 3-5 (não importa!)
// Resultado: Fundamentos aprendidos!

-- Veteran sorcerer nível 100, MLvl 50
rune.onCastSpell(sorcerer, targetVariant, false)
// Mesma runa = dano 3-5 (não escalou!)
// Já não usa (runa obsoleta)
// Resultado: Educação concluída!
```
