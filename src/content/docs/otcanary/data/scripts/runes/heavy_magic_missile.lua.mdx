## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `heavy_magic_missile` oferece míssil econômico com distancia:

- **Dano:** COMBAT_ENERGYDAMAGE escalável
- **Fórmula:** (level/5) + (maglevel*0.4/1.59) + bônus
- **Área:** Single target
- **Distancia:** Permitida (allowFarUse)
- **Cargas:** 10 (muitas!)

### Arquitetura

Combat com fórmula callback simplificada:

```
local combat = Combat()
├─ Type: COMBAT_ENERGYDAMAGE
├─ Effect: ENERGYAREA
├─ Distance: ENERGY
└─ Callback: onGetFormulaValues

onGetFormulaValues()
└─ min/max escalável baixo

rune.onCastSpell()
└─ combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGY)
```

**Propósito:** Instância de Combat para míssil energético.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ENERGYDAMAGE | Dano energia |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ENERGYAREA | Efeito explosão energia |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ENERGY | Projétil energia |

**Características:**
- Sem `combat:setArea()` = single target
- Callback para fórmula escalável (baixa)
- Sem armor bypass

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 0.4) + 2
	local max = (level / 5) + (maglevel * 1.59) + 10
	return -min, -max
end
```

**Propósito:** Calcula dano escalável econômico.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level total |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 0.4) + 2
max = (level / 5) + (maglevel * 1.59) + 10
```

**Pesos:**
- Level: 0.2 por ponto (baixo)
- Maglevel min: 0.4 (muito baixo!)
- Maglevel max: 1.59 (baixo)
- Bônus: 2/10 (suporta treino)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 25 | 3 | 8 | 20 |
| 45 | 7 | 16 | 31 |
| 75 | 20 | 30 | 42 |
| 100 | 30 | 40 | 57 |

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Lança míssil energético pesado a distancia.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Target (obrigatório) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Míssil lançado |
| `false` | Target inválido |

**Efeito:**
- Projétil energia viaja (distancia longa)
- Som customizado de cast + impacto
- Impacto ENERGYAREA
- Dano escalável econômico

**Exemplo:**

```lua

rune.onCastSpell(mago, targetVariant, false)
// allowFarUse = pode atacar longe
// Projétil energia viaja
// Impacto com efeito
// Resultado: -13 a -30 dano
```
