## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `light_magic_missile` oferece míssil econômico early game:

- **Dano:** COMBAT_ENERGYDAMAGE escalável muito baixo
- **Fórmula:** (level/5) + (maglevel*0.4/0.81) + bônus
- **Área:** Single target
- **Distancia:** Permitida
- **Cargas:** 10 (treino profundo)

### Arquitetura

Combat com fórmula callback minimalista:

```
local combat = Combat()
├─ Type: COMBAT_ENERGYDAMAGE
├─ Effect: ENERGYAREA
├─ Distance: ENERGY
└─ Callback: onGetFormulaValues

onGetFormulaValues()
└─ min/max muito baixo

rune.onCastSpell()
└─ combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGY)
```

**Propósito:** Instância de Combat para míssil leve.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ENERGYDAMAGE | Dano energia |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ENERGYAREA | Efeito explosão |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ENERGY | Projétil energia |

**Características:**
- Sem `combat:setArea()` = single target
- Callback para fórmula muito escalável
- Sem armor bypass

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 0.4) + 2
	local max = (level / 5) + (maglevel * 0.81) + 4
	return -min, -max
end
```

**Propósito:** Calcula dano muito baixo para treino.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level total |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 0.4) + 2
max = (level / 5) + (maglevel * 0.81) + 4
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 0.4
- Maglevel max: 0.81

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 15 | 0 | 5 | 7 |
| 30 | 5 | 10 | 13 |
| 50 | 15 | 18 | 28 |
| 80 | 30 | 30 | 47 |

---

### Registração do Callback

```lua
combat:setCallback(CALLBACK_PARAM_LEVELMAGICVALUE, "onGetFormulaValues")
```

**Descrição:** Calcula dano muito baixo de light magic missile.

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Lança míssil leve a distancia.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Target (obrigatório) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Míssil lançado |
| `false` | Target falhou |

**Efeito:**
- Projétil energia viaja
- Som customizado de cast + impacto
- Impacto ENERGYAREA
- Dano muito baixo
- Single target

**Exemplo:**

```lua
-- Mago nível 30, MLvl 5
rune.onCastSpell(mago, targetVariant, false)
// Projétil energia viaja
// Impacto: -10 a -14 dano
// Resultado: Training eficiente
```
