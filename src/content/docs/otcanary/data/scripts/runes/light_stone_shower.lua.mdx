## 💡 Tip

<Aside type="tip">
**Chuva de Pedras com Cap de Escalabilidade**

Esta runa implementa um **sistema de dano terra com validação de cap**:

1. **Level/MLvl Cappado:**
   - `level = math.min(level, 20)` = máx 20!
   - `maglevel = math.min(maglevel, 20)` = máx 20!
   - Evita escalabilidade infinita

2. **Acesso Extremo:**
   - Level 1 (primeira runa!)
   - MLvl 0 (nada!)

3. **Fórmula Muito Baixa:**
   - min = (level/5) + (maglevel*0.3) + 2
   - max = (level/5) + (maglevel*0.45) + 3
   - Earth damage (tipo raro!)

4. **Sem Target:** Pode auto-cast

**Fórmula Visual (com cap):**
```
level 1, mlvl 0:
  level capped = 1, mlvl capped = 0
  min = 0.2 + 0 + 2 = 2.2
  max = 0.2 + 0 + 3 = 3.2

level 50, mlvl 30:
  level capped = 20, mlvl capped = 20
  min = 4 + 6 + 2 = 12 (CAPPED!)
  max = 4 + 9 + 3 = 16 (CAPPED!)
```

**Diferencial:** Primeira runa pure + cap protection!
</Aside>

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_EARTHDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_STONES)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_EARTH)
combat:setArea(createCombatArea(AREA_CIRCLE1X1))
```

**Propósito:** Instância de Combat para chuva de pedras.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_EARTHDAMAGE | Dano terra |
| `COMBAT_PARAM_EFFECT` | CONST_ME_STONES | Efeito pedras |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_EARTH | Projétil terra |
| `Area` | AREA_CIRCLE1X1 | 1x1 (single) |

**Características:**
- Área 1x1 = single tile
- Callback para fórmula cappada
- Sem armor bypass
- Sem needTarget (auto-cast ok)

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	level = math.min(level, 20)
	maglevel = math.min(maglevel, 20)
	local min = (level / 5) + (maglevel * 0.3) + 2
	local max = (level / 5) + (maglevel * 0.45) + 3
	return -min, -max
end
```

**Propósito:** Calcula dano com cap de escalabilidade.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level (será cappado!) |
| `maglevel` | number | Magic level (será cappado!) |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula com Cap:**
```
level = math.min(level, 20)        -- Máximo 20 levels!
maglevel = math.min(maglevel, 20)  -- Máximo 20 MLvl!
min = (level / 5) + (maglevel * 0.3) + 2
max = (level / 5) + (maglevel * 0.45) + 3
```

**Pesos (após cap):**
- Level: 0.2 por ponto (max 4 dos 20)
- Maglevel min: 0.3 (max 6 dos 20)
- Maglevel max: 0.45 (max 9 dos 20)

**Exemplos:**

| Level | MLvl | Level Capped | MLvl Capped | Min | Max |
|---|---|---|---|---|---|
| 1 | 0 | 1 | 0 | 2 | 3 |
| 20 | 10 | 20 | 10 | 7 | 10 |
| 100 | 50 | 20 | 20 | 12 | 16 |
