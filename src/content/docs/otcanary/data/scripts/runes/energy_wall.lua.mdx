## 💡 Tip

<Aside type="tip">
**Parede de Energia com Cobertura Diagonal**

Esta runa implementa um **sistema de controle territorial em linha**:

1. **Área Wall:** AREA_WALLFIELD_ENERGY
   - Cria linha horizontal ou vertical
   - Múltiplos fields em sequência

2. **Área Diagonal:** AREADIAGONAL_WALLFIELD_ENERGY
   - Cobre cantos diagonais
   - Bloqueia fuga por diagonal

3. **Cargas:** 4 (cara, mas extensa)
4. **PZ Locked:** Força combate fora town

**Fluxo:**
```
Aponta runa em linha
├─ Area wallfield (linha)
├─ Area diagonal (cantos)
├─ Múltiplos fields criados
└─ Parede completa bloqueia
```

**Diferencial:** Wall patterns = controle territorial max!
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `energy_wall` oferece criação de parede:

- **Dano:** COMBAT_ENERGYDAMAGE
- **Áreas:** Wall + diagonal (cobertura linha)
- **Fields:** Múltiplos em parede
- **Controle:** Territorial completo

### Arquitetura

Combat com áreas especializadas:

```
local combat = Combat()
├─ Type: COMBAT_ENERGYDAMAGE
├─ Effect: ENERGYHIT
├─ Distance: ENERGYBALL
├─ CreateItem: ENERGYFIELD_PVP
├─ Area: WALLFIELD_ENERGY
└─ Area: AREADIAGONAL_WALLFIELD_ENERGY

rune.onCastSpell()
└─ combat:execute(creature, var)
```

### Fluxo Lógico Resumido

| Etapa | Descrição |
|---|---|
| **Conjura** | onCastSpell() |
| **PZ Lock** | Valida fora PZ |
| **Combat Execute** | Wall fields criados |

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYHIT)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGYBALL)
combat:setParameter(COMBAT_PARAM_CREATEITEM, ITEM_ENERGYFIELD_PVP)
combat:setArea(createCombatArea(AREA_WALLFIELD_ENERGY, AREADIAGONAL_WALLFIELD_ENERGY))
```

**Propósito:** Instância de Combat para parede de energia.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ENERGYDAMAGE | Dano energia |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ENERGYHIT | Impacto |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ENERGYBALL | Projétil |
| `COMBAT_PARAM_CREATEITEM` | ITEM_ENERGYFIELD_PVP | Field criado |
| `Area 1` | AREA_WALLFIELD_ENERGY | Linha principal |
| `Area 2` | AREADIAGONAL_WALLFIELD_ENERGY | Diagonais |

**Características:**
- 2 áreas combinadas = cobertura completa
- Sem fórmula = dano fixo
- Wall patterns = linha/parede

---

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var, isHotkey)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler principal da runa ao conjuração.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Alvo (position) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Wall criada, fields múltiplos |
| `false` | PZ lock bloqueado |
