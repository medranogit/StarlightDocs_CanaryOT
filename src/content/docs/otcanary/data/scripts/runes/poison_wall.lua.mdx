## 💡 Tip

<Aside type="tip">
**Parede de Veneno com Cobertura Total**

Esta runa implementa um **sistema de wall pattern em terra**:

1. **Áreas Múltiplas:**
   - WALLFIELD: linha principal
   - AREADIAGONAL_WALLFIELD: cobertura diagonal
   - Padrão 2-area wall

2. **Field Automático:**
   - POISONFIELD_PVP auto-deploy
   - Controle territorial
   - Tipo terra (raro!)

3. **Sem Bloqueio:**
   - isBlocking: false
   - Creatures passam
   - Movimento fluido

4. **Sem Target:**
   - Auto-cast permitido
   - Apenas posição

**Fluxo:**
```
Conjura parede
├─ Area wallfield (linha)
├─ Area diagonal (cantos)
├─ Fields criam parede
└─ Creatures passam (livres)
```

**Diferencial:** Wall veneno terra = tipo raro + padrão familiar!
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `poison_wall` oferece parede tática:

- **Dano:** COMBAT_EARTHDAMAGE (fixo)
- **Áreas:** Wall + diagonal (2)
- **Field:** POISONFIELD_PVP automático
- **Bloqueio:** Não (passagem)
- **Cargas:** 4

### Arquitetura

Combat com múltiplas áreas:

```
local combat = Combat()
├─ Type: EARTHDAMAGE
├─ Effect: GREEN_RINGS
├─ Distance: POISON
├─ CreateItem: POISONFIELD_PVP
├─ Area: WALLFIELD
└─ Area: AREADIAGONAL_WALLFIELD

rune.onCastSpell()
└─ combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_EARTHDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_GREEN_RINGS)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_POISON)
combat:setParameter(COMBAT_PARAM_CREATEITEM, ITEM_POISONFIELD_PVP)
combat:setArea(createCombatArea(AREA_WALLFIELD, AREADIAGONAL_WALLFIELD))
```

**Propósito:** Combat com múltiplas áreas wall.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_EARTHDAMAGE | Dano terra |
| `COMBAT_PARAM_EFFECT` | CONST_ME_GREEN_RINGS | Efeito anéis |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_POISON | Projétil veneno |
| `COMBAT_PARAM_CREATEITEM` | ITEM_POISONFIELD_PVP | Field automático |
| `Area 1` | AREA_WALLFIELD | Linha principal |
| `Area 2` | AREADIAGONAL_WALLFIELD | Diagonais |

## 🤖 Documentação das Funções

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Cria parede de veneno com cobertura completa.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Position central |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Parede criada |
| `false` | Position falhou |

**Efeito:**
- Projétil veneno viaja
- Impacto GREEN_RINGS
- Fields em pattern wall + diagonal
- Dano earth fixo
- Creatures passam

**Exemplo:**

```lua

// Wallfield: linha horizontal/vertical
// Diagonal: cantos cobertos
// Fields automáticos: bloqueio tático
// Creatures: passam (livres)
// Resultado: Parede completa!
```
