## 💡 Tip

<Aside type="tip">
**Invocação de Esqueletos via Cadáveres**

Esta runa implementa um **sistema de animação temporária de cadáveres**:

1. **Detecção de Corpse:** Busca item corpse na posição
2. **Validação:** Verifica se player pode ter mais summons (máx 2)
3. **Criação:** Spawna Skeleton no ponto do corpse
4. **Limpeza:** Remove corpse original

**Fluxo Visual:**
```
Jogador aponta runa no cadáver
├─ Valida corpse (movable + tipo correto)
├─ Valida limite summons (< 2)
├─ Valida skull (≠ BLACK)
├─ Cria Skeleton
├─ Remove corpse
└─ Efeito MAGIC_BLUE
```

**Caso Especial:** Skull Black bloqueia invocação (PvP hardcore).
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `animate_dead_rune` oferece invocação controlada:

- **Alvo:** Cadáveres (corpse) num raio
- **Efeito:** Cria esqueleto permanente até morte
- **Límite:** Máximo 2 summons por jogador
- **Restrições:** Proíbe Skull Black, requer corpse movable

### Arquitetura

Fluxo com 4 validações → conversão corpse em summon:

```
onCastSpell(player, variant)
├─ Pega posição (variant)
├─ Busca tile + corpse (top-down)
├─ Validação 1: corpse existe + é corpse + movable
├─ Validação 2: < 2 summons + ≠ SKULL_BLACK
├─ Cria summon Skeleton
├─ Remove corpse
├─ Efeito MAGIC_BLUE
└─ Retorna true/false
```

### Fluxo Lógico Resumido

| Etapa | Tipo | Resultado |
|---|---|---|
| **Pega Posição** | Validação | Position do corpse |
| **Busca Corpse** | Validação | Item corpse ou nil |
| **Valida Corpse** | Validação | É movable e tipo corpse |
| **Valida Limit** | Validação | < 2 summons |
| **Valida Skull** | Validação | ≠ SKULL_BLACK |
| **Cria Skeleton** | Ação | Game.createMonster retorna summon |
| **Remove Corpse** | Ação | corpse:remove() |
| **Efeito** | Feedback | MAGIC_BLUE sucesso ou POFF falha |

## 🔧 Estrutura de Funcionalidades

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(player, variant)
	local position = variant:getPosition()
	local tile = Tile(position)
	if tile then
		local corpse = tile:getTopDownItem()
		if corpse then
			local itemType = corpse:getType()
			if itemType:isCorpse() and itemType:isMovable() then
				if #player:getSummons() < 2 and player:getSkull() ~= SKULL_BLACK then
					local summon = Game.createMonster("Skeleton", position, true, true)
					if summon then
						corpse:remove()
						player:setSummon(summon)
						position:sendMagicEffect(CONST_ME_MAGIC_BLUE)
						return true
					end
				else
					player:sendCancelMessage("You cannot control more creatures.")
					player:getPosition():sendMagicEffect(CONST_ME_POFF)
					return false
				end
			end
		end
	end

	player:getPosition():sendMagicEffect(CONST_ME_POFF)
	player:sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
	return false
end
```

**Propósito:** Handler principal da runa ao conjuração.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Jogador conjurando a runa |
| `variant` | Variant | Posição do alvo (position) |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Summon criado com sucesso |
| `false` | Falha na invocação (corpse inválido, limite, skull) |

**Fluxo Detalhado:**

1. **Extrai Posição:** `variant:getPosition()`
2. **Pega Tile:** `Tile(position)` - valida existência
3. **Busca Corpse:** `tile:getTopDownItem()` - top-down (item mais visível)
4. **Valida Tipo:**
   - `itemType:isCorpse()` - é cadáver
   - `itemType:isMovable()` - pode ser movido/removido
5. **Valida Summons:** `#player:getSummons() < 2`
   - Usa operador `#` (tamanho da array)
   - Máximo 2 summons
6. **Valida Skull:** `player:getSkull() ~= SKULL_BLACK`
   - Skull Black bloqueia invocação
7. **Cria Summon:**
   - `Game.createMonster("Skeleton", position, true, true)`
   - 3º param: `true` (summon)
   - 4º param: `true` (hideHealth?)
8. **Remove Corpse:** `corpse:remove()`
9. **Associa ao Player:** `player:setSummon(summon)`
10. **Efeito Sucesso:** `CONST_ME_MAGIC_BLUE` na posição
11. **Fallback:** Se criar monster falha, retorna false

**Tratamento de Erros:**

- **Tile inválida:** Ignora, segue para POFF
- **Corpse não encontrado:** POFF + mensagem NOTPOSSIBLE
- **Limit atingido:** Mensagem "cannot control more creatures" + POFF
- **Skull Black:** Mensagem limit (mesmo que limit real) + POFF

## 🎯 Padrões Identificados

### Padrão 1: Validação em Cascata

```lua
if tile then
	if corpse then
		if itemType:isCorpse() and itemType:isMovable() then
			if #player:getSummons() < 2 and player:getSkull() ~= SKULL_BLACK then
				-- Lógica
			end
		end
	end
end
```

**Benefício:** Early return não necessário, validações claras aninhadas.

### Padrão 2: Try-Create com Validação

```lua
local summon = Game.createMonster("Skeleton", position, true, true)
if summon then
	corpse:remove()
	player:setSummon(summon)
	-- Sucesso
end
```

**Benefício:** Verifica sucesso de criação antes de modificar estado.

### Padrão 3: Efeitos Condicionais

```lua
-- Sucesso
position:sendMagicEffect(CONST_ME_MAGIC_BLUE)

-- Falha
player:getPosition():sendMagicEffect(CONST_ME_POFF)
```

**Benefício:** Feedback visual diferente para sucesso/falha.

### Padrão 4: Limite de Summons

```lua
if #player:getSummons() < 2 and player:getSkull() ~= SKULL_BLACK then
	-- Permite
end
```

**Benefício:** Array length check para conto dinâmico.
