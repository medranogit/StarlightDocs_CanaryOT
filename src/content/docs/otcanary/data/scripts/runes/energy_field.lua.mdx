## 💡 Tip

<Aside type="tip">
**Criação de Campo de Energia com Proteção de PZ**

Esta runa implementa um **sistema simples de deployment de field**:

1. **Sem Área:** Afeta apenas tile alvo (1x1 implícito)
2. **Damage + Field:** Aplica dano + cria ITEM_ENERGYFIELD_PVP
3. **Sem Fórmula:** Dano fixo do engine (sem callback)
4. **PZ Locked:** Bloqueia em protection zones

**Diferencial:**
- Mais barata que energy_bomb (3 cargas vs 2)
- Nível menor (18 vs 37)
- Magic level menor (3 vs 10)
- Sem área = apenas 1 tile

**Comparação com energy_bomb:**
```
energy_field:  3 cargas, lvl 18, mlvl 3, sem area
energy_bomb:   2 cargas, lvl 37, mlvl 10, area 1x1
```

**Fluxo:**
```
Aponta runa em tile
├─ PZ lock valida
├─ Dano fixo aplicado
├─ Field criado
└─ Inimigo cercado por energy
```
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `energy_field` oferece criação de field básico:

- **Dano:** COMBAT_ENERGYDAMAGE (fixo)
- **Field:** ITEM_ENERGYFIELD_PVP
- **Área:** Single tile (padrão)
- **Early Game:** Level 18 (acesso anterior a energy_bomb)

### Arquitetura

Combat minimalista com field item:

```
local combat = Combat()
├─ Type: COMBAT_ENERGYDAMAGE
├─ Effect: ENERGYHIT
├─ Distance: ENERGYBALL
├─ CreateItem: ENERGYFIELD_PVP
└─ Sem area() (padrão single)

rune.onCastSpell()
└─ combat:execute(creature, var)
```

### Fluxo Lógico Resumido

| Etapa | Descrição |
|---|---|
| **Conjura** | onCastSpell() |
| **PZ Lock** | Valida fora protection zone |
| **Combat Execute** | Dano + field criado |

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYHIT)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGYBALL)
combat:setParameter(COMBAT_PARAM_CREATEITEM, ITEM_ENERGYFIELD_PVP)
```

**Propósito:** Instância de Combat para dano energia com field.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ENERGYDAMAGE | Dano tipo energia |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ENERGYHIT | Efeito impacto |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ENERGYBALL | Projétil viajante |
| `COMBAT_PARAM_CREATEITEM` | ITEM_ENERGYFIELD_PVP | Field criado |

**Características:**
- Sem `combat:setArea()` = padrão single tile
- Sem `combat:setCallback()` = dano fixo
- Sem fórmula escalável

---

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var, isHotkey)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler principal da runa ao conjuração.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Alvo (position) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Combat executado, field criado |
| `false` | PZ lock bloqueado ou falha |

**Lógica:**
- Passa direto para `combat:execute()`
- SEM validações adicionais
- Engine faz PZ lock check
