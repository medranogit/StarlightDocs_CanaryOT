## 💡 Tip

<Aside type="tip">
**Destruição de Campos com Proteção e Validação**

Esta runa implementa um **sistema seguro de limpeza de campos**:

1. **Validação de PZ (Protection Zone):**
   - Bloqueia se conjurador em PZ
   - Protege contra abuso preventivo

2. **Lista de Campos Deströáveis:**
   - 15 IDs de campos permitidos
   - Fire, poison, spike, etc
   - Campos que NÃO estão = rejeitados

3. **Type Check:** ITEM_TYPE_MAGICFIELD
   - Garante que é campo, não outro item
   - top-down para pegar visível

**Fluxo:**
```
Aponta runa em campo
├─ Valida PZ (conjurador)
├─ Pega tile
├─ Busca magic field (top-down)
├─ Valida se está em lista deströável
├─ Remove se válido
└─ Feedback sucesso/falha
```

**Diferencial:** PZ protection + lista branca de campos.
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `destroy_field_rune` oferece destruição controlada de campos:

- **Alvo:** Magic fields em range 5
- **Critérios:** Deve estar em lista de deströáveis (15 IDs)
- **Restrições:** Bloqueada em PZ para evitar farma
- **Range:** 5 tiles (distância)

### Arquitetura

Validações em cascata → busca campos → remoção:

```
onCastSpell(creature, variant, isHotkey)
├─ Valida PZ (conjurador)
├─ Pega position (variant)
├─ Pega tile
├─ Busca magic field tipo (top-down)
├─ Valida se em lista deströável
├─ Remove se valid
└─ Efeito sucesso/falha
```

### Fluxo Lógico Resumido

| Etapa | tipo | Resultado |
|---|---|---|
| **Valida PZ** | Validação | Se true, rejeita |
| **Pega Position** | Extração | Position alvo |
| **Pega Tile** | Busca | Tile object |
| **Busca Field** | Busca | Magic field ou nil |
| **Valida ID** | Validação | Em lista deströável? |
| **Remove** | Ação | field:remove() |
| **Efeito** | Feedback | POFF sucesso/falha |

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, variant, isHotkey)
	local inPz = creature:getTile():hasFlag(TILESTATE_PROTECTIONZONE)
	if inPz then
		creature:sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
		creature:getPosition():sendMagicEffect(CONST_ME_POFF)
		return false
	end

	local position = Variant.getPosition(variant)
	local tile = Tile(position)
	local field = tile and tile:getItemByType(ITEM_TYPE_MAGICFIELD)
	if field and table.contains(fields, field:getId()) then
		field:remove()
		position:sendMagicEffect(CONST_ME_POFF)
		return true
	end

	creature:sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
	creature:getPosition():sendMagicEffect(CONST_ME_POFF)
	return false
end
```

**Propósito:** Handler principal da runa ao conjuração.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Jogador conjurando |
| `variant` | Variant | Position or field alvo |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Campo deストóído com sucesso |
| `false` | PZ, sem field, ou ID não permitido |

**Fluxo Detalhado:**

1. **Valida PZ (Conjurador):**
   ```lua
   local inPz = creature:getTile():hasFlag(TILESTATE_PROTECTIONZONE)
   if inPz then
       -- Rejeita em PZ
       return false
   end
   ```
   - Impede uso em protection zones
   - Proteção contra farming de loot

2. **Extrai Position:**
   ```lua
   local position = Variant.getPosition(variant)
   ```
   - Position é parametrizado (range 5 permite distância)

3. **Pega Tile:**
   ```lua
   local tile = Tile(position)
   ```

4. **Busca Magic Field:**
   ```lua
   local field = tile and tile:getItemByType(ITEM_TYPE_MAGICFIELD)
   ```
   - `getItemByType()`: Busca item por tipo (magic field type)
   - Short-circuit: se ~tile, field = nil

5. **Validação de Campo:**
   ```lua
   if field and table.contains(fields, field:getId()) then
       -- Destruir
   end
   ```
   - Field deve existir
   - ID deve estar em lista branca

6. **Remove Campo:**
   ```lua
   field:remove()
   position:sendMagicEffect(CONST_ME_POFF)
   return true
   ```
   - Efeito POFF na position
   - Retorna true (sucesso)

7. **Fallback:**
   ```lua
   creature:sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
   creature:getPosition():sendMagicEffect(CONST_ME_POFF)
   return false
   ```
   - Se PZ ou sem field válido
   - Efeito em posição do conjurador
   - Mensagem de cancelamento

## 🎯 Padrões Identificados

### Padrão 1: PZ Early Validation

```lua
local inPz = creature:getTile():hasFlag(TILESTATE_PROTECTIONZONE)
if inPz then
	-- Rejeita
	return false
end
```

**Benefício:** Proteção contra abuso antes de outras validações.

### Padrão 2: Short-Circuit com AND

```lua
local field = tile and tile:getItemByType(ITEM_TYPE_MAGICFIELD)
if field and table.contains(fields, field:getId()) then
	-- Destruir
end
```

**Benefício:** Se ~tile, field = nil e segunda validação falha também.

### Padrão 3: Lista Branca

```lua
local fields = { 105, 2118, ... }
-- Depois
if field and table.contains(fields, field:getId()) then
```

**Benefício:** Apenas campos permitidos podem ser destruídos.

### Padrão 4: Efeitos Condicionais

```lua
-- Sucesso
position:sendMagicEffect(CONST_ME_POFF)

-- Falha
creature:getPosition():sendMagicEffect(CONST_ME_POFF)
```

**Benefício:** Feedback visual em posição diferente para sucesso/falha.

**Descrição:** Destrói campo mágico permitido.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |

**Retorno:**

| Valor | Descrição |
|---|---|

**Validações:**
- **PZ:** Bloqueia se conjurador em protection zone
- **Type:** Deve ser ITEM_TYPE_MAGICFIELD
- **ID:** Deve estar em lista branca (15 IDs)

**Efeito:**
- **Sucesso:** POFF na tile field
- **Falha:** POFF em posição conjurador + mensagem

**Exemplo:**

```lua
-- Fire field ID 105 na posição X
rune.onCastSpell(player, positionVariant, false)
// Conjurador não em PZ
// Pega tile, busca field
// field.getId() = 105
// table.contains(fields, 105) = true
// field:remove()
// POFF effect em position
// Resultado: Fire field destruído
```
