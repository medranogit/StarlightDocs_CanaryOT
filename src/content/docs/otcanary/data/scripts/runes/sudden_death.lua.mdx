## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `sudden_death` oferece dano morte devastador:

- **Dano:** COMBAT_DEATHDAMAGE escalável agressivo
- **Fórmula:** (level/5) + (maglevel*4.605/7.395) + bônus (EXTREMA!)
- **Target:** Requerido
- **Cargas:** 3

### Arquitetura

Combat com fórmula callback agressiva:

```
local combat = Combat()
├─ Type: DEATHDAMAGE
├─ Effect: MORTAREA
├─ Distance: SUDDENDEATH
└─ Callback: onGetFormulaValues

onGetFormulaValues()
└─ min/max agressivo

rune.onCastSpell()
└─ combat:execute()
```

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 4.605) + 28
	local max = (level / 5) + (maglevel * 7.395) + 46
	return -min, -max
end
```

**Propósito:** Calcula dano morte agressivo.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 4.605) + 28
max = (level / 5) + (maglevel * 7.395) + 46
```

**Pesos:**
- Level: 0.2 por ponto (baixo)
- Maglevel min: 4.605 (EXTREMO!)
- Maglevel max: 7.395 (EXTREMO!)
- Bônus: 28/46 (significativo)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 45 | 15 | 106 | 166 |
| 60 | 20 | 138 | 224 |
| 80 | 30 | 182 | 284 |
| 100 | 40 | 222 | 352 |
