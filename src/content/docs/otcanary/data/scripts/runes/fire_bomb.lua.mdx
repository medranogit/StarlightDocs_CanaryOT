## 💡 Tip

<Aside type="tip">
**Bomba de Fogo com Field Territorial**

Esta runa implementa um **sistema de ataque com deploy de field**:

1. **Dano de Fogo:** COMBAT_FIREDAMAGE (vs energia)
2. **Field Completo:** ITEM_FIREFIELD_PVP_FULL
   - "FULL" = campo durável/potente
3. **Cargas:** 2 (cara, como energy_bomb)
4. **PZ Locked:** Força combate em dungeons

**Comparação com energy_bomb:**
```
energy_bomb:  COMBAT_ENERGYDAMAGE, ENERGYFIELD_PVP
fire_bomb:    COMBAT_FIREDAMAGE, FIREFIELD_PVP_FULL
```

**Diferencial:** Field "FULL" = mais poderoso que simples!

**Fluxo:**
```
Aponta runa em inimigo
├─ PZ lock valida
├─ Projétil fogo viaja
├─ Chega no alvo
├─ Dano fogo aplicado
├─ Field fogo completo criado
└─ Inimigo queimando + preso
```
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `fire_bomb` oferece ataque incendiário:

- **Dano:** COMBAT_FIREDAMAGE (fixo)
- **Field:** ITEM_FIREFIELD_PVP_FULL (complete/potent)
- **Área:** Single tile (1x1)
- **Mid-Game:** Level 27 (acesso rápido)

### Arquitetura

Combat simples com field de fogo:

```
local combat = Combat()
├─ Type: COMBAT_FIREDAMAGE
├─ Effect: HITBYFIRE
├─ Distance: FIRE (projétil)
├─ CreateItem: FIREFIELD_PVP_FULL
└─ Area: 1x1 (padrão)

rune.onCastSpell()
└─ combat:execute(creature, var)
```

### Fluxo Lógico Resumido

| Etapa | Descrição |
|---|---|
| **Conjura** | onCastSpell() |
| **PZ Lock** | Valida fora PZ |
| **Combat Execute** | Dano + field criado |

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_FIREDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITBYFIRE)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_FIRE)
combat:setParameter(COMBAT_PARAM_CREATEITEM, ITEM_FIREFIELD_PVP_FULL)
combat:setArea(createCombatArea(AREA_SQUARE1X1))
```

**Propósito:** Instância de Combat para fogo explosivo.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_FIREDAMAGE | Tipo fogo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HITBYFIRE | Efeito queimadura |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_FIRE | Projétil fogo |
| `COMBAT_PARAM_CREATEITEM` | ITEM_FIREFIELD_PVP_FULL | Field fogo completo |
| `Area` | AREA_SQUARE1X1 | 1x1 single tile |

**Características:**
- Sem fórmula = dano fixo
- Field FULL = durável
- Single tile = focused damage

---

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var, isHotkey)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler principal da runa ao conjuração.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Alvo (position) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Fire bomb detonada, field criado |
| `false` | PZ lock bloqueado |

**Lógica:**
- Passa direto para `combat:execute()`
- Engine valida PZ lock
- Sem validações adicionais

## 🤖 Documentação das Funções

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Detona bomba de fogo com field.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Alvo (position) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Bomba detonada, field criado |
| `false` | PZ lock bloqueado |

**Validações:**
- **PZ Lock:** Engine valida

**Efeito:**
- Projétil fogo viaja (CONST_ANI_FIRE)
- Impacto HITBYFIRE
- Field FIREFIELD_PVP_FULL criado
- Dano fixo + efeito contínuo field

**Exemplo:**

```lua
-- Knight aponta runa em inimigo
rune.onCastSpell(knight, enemyVariant, false)
// Fora PZ: ok
// Projétil fogo viaja
// Inimigo sofre dano fogo
// Field fogo criado, enemigo cercado
// Resultado: Incêndio + campo territorial
```
