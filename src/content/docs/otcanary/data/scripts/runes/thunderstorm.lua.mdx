## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYHIT)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGYBALL)
combat:setArea(createCombatArea(AREA_CIRCLE3X3))
```

**Propósito:** Combat com área 3x3.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ENERGYDAMAGE | Dano energia |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ENERGYHIT | Efeito hit |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ENERGYBALL | Projétil energia |
| `Area` | AREA_CIRCLE3X3 | 3x3 círculo (9 tiles) |

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, magicLevel)
	local min = (level / 5) + (magicLevel * 1) + 6
	local max = (level / 5) + (magicLevel * 2.6) + 16
	return -min, -max
end
```

**Propósito:** Calcula dano energia escalável área.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `magicLevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (magicLevel * 1) + 6
max = (level / 5) + (magicLevel * 2.6) + 16
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 1.0 (moderado)
- Maglevel max: 2.6 (crescimento)
- Bônus: 6/16 (suporta escalabilidade)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 28 | 4 | 16 | 32 |
| 50 | 10 | 28 | 52 |
| 80 | 20 | 48 | 88 |
| 100 | 30 | 60 | 114 |

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Lança tempestade energia em 3x3.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Position central |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Tempestade lançada |
| `false` | Position falhou |

**Efeito:**
- Projétil energia viaja
- Impacto ENERGYHIT
- Dano área 3x3 (9 tiles)
- Até 9 targets simultâneos
- Creatures passam (livres)

**Exemplo:**

```lua
-- Mago nível 50, MLvl 10
rune.onCastSpell(mago, centerVariant, false)
// Auto-cast (sem needTarget)
// Projétil energia (bola)
// Chega no centro
// Explode em 3x3
// Cada criatura: -26 a -52 dano
// Creatures passam livremente
// Resultado: Área completa!
```
