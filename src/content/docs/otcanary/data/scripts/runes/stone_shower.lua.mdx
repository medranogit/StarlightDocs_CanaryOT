## 💡 Tip

<Aside type="tip">
**Chuva de Pedras em Área 3x3**

Esta runa implementa um **sistema de AoE terra com escalabilidade**:

1. **Primeira AoE Terra:**
   - Área 3x3 = 9 tiles
   - Até 9 targets simultâneos
   - Dano terra spread

2. **Fórmula Escalável (Moderado):**
   - min = (level/5) + (maglevel*1) + 6
   - max = (level/5) + (maglevel*2.6) + 16
   - Crescimento suave + bônus fixo

3. **Sem Target Requerido:**
   - Auto-cast permitido
   - Apenas posição
   - Controle fácil

4. **Sem Bloqueio:**
   - isBlocking: false
   - Creatures passam
   - Movimento fluido

**Fórmula Visual:**
```
level 28, mlvl 4:
  min = 5.6 + 4 + 6 = 15.6
  max = 5.6 + 10.4 + 16 = 32

level 60, mlvl 15:
  min = 12 + 15 + 6 = 33
  max = 12 + 39 + 16 = 67
```

**Diferencial:** Primeira AoE terra + escalável = área tática!
</Aside>

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_EARTHDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_STONES)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_EARTH)
combat:setArea(createCombatArea(AREA_CIRCLE3X3))
```

**Propósito:** Combat com área 3x3.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_EARTHDAMAGE | Dano terra |
| `COMBAT_PARAM_EFFECT` | CONST_ME_STONES | Efeito pedras |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_EARTH | Projétil terra |
| `Area` | AREA_CIRCLE3X3 | 3x3 círculo (9 tiles) |

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, magicLevel)
	local min = (level / 5) + (magicLevel * 1) + 6
	local max = (level / 5) + (magicLevel * 2.6) + 16
	return -min, -max
end
```

**Propósito:** Calcula dano escalável área.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `magicLevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (magicLevel * 1) + 6
max = (level / 5) + (magicLevel * 2.6) + 16
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 1.0 (moderado)
- Maglevel max: 2.6 (crescimento)
- Bônus: 6/16 (suporta escalabilidade)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 28 | 4 | 16 | 32 |
| 50 | 10 | 28 | 52 |
| 80 | 20 | 48 | 88 |
| 100 | 30 | 60 | 114 |

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Lança chuva de pedras em 3x3.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Position central |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Chuva lançada |
| `false` | Position falhou |

**Efeito:**
- Projétil terra viaja
- Impacto STONES
- Dano area 3x3 (9 tiles)
- Até 9 targets simultâneos
- Creatures passam (livres)

**Exemplo:**

```lua
-- Mago nível 50, MLvl 10
rune.onCastSpell(mago, centerVariant, false)
// Auto-cast (sem needTarget)
// Projétil terra
// Chega no centro
// Explode em 3x3
// Cada criatura: -26 a -52 dano
// Creatures passam livremente
// Resultado: Área completa!
```
