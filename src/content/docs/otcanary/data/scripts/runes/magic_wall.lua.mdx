## 💡 Tip

<Aside type="tip">
**Campo Mágico com Validações Avançadas**

Esta runa implementa um **sistema de bloqueio posicional com callbacks**:

1. **Callback TARGETTILE:**
   - Executa função em tile específica
   - Não usa Combat dano padrão
   - Lógica custom completa

2. **Validações:**
   - Floorchange: não cria se descida
   - Creatures: falha se monstro presente
   - Tile nula: fallback seguro

3. **Diferenciação PvP/Safe:**
   - ITEM_MAGICWALL (PvP)
   - ITEM_MAGICWALL_SAFE (Safe)
   - Auto-detecção WorldType!

4. **Item com Duração:**
   - 16-24 segundos
   - Descrição: "Casted by: [Nome]"
   - Rastreabilidade!

**Fluxo:**
```
Conjura em tile
├─ Valida tile (existe?)
├─ Valida floor (não desce?)
├─ Valida creatures (monstro?)
├─ Detecta mundo (PvP? Safe?)
├─ Cria MAGICWALL item
├─ Duração 16-24s
└─ Com assinatura do caster!
```

**Diferencial:** Lógica posicional + validações = campo tático!
</Aside>

## 🔧 Estrutura de Funcionalidades

### Função Global: onCreateMagicWall

```lua
function onCreateMagicWall(creature, position)
	local tile = Tile(position)
	if not tile then
		return false
	end

	if tile:hasFlag(TILESTATE_FLOORCHANGE) then
		return false
	end

	if tile:getTopCreature() and not tile:getTopCreature():isPlayer() then
		return false
	end

	local magicWall
	if Game.getWorldType() == WORLD_TYPE_NO_PVP then
		magicWall = ITEM_MAGICWALL_SAFE
	else
		magicWall = ITEM_MAGICWALL
	end

	local item = Game.createItem(magicWall, 1, position)
	if item then
		item:setDuration(16, 24)
		item:setAttribute(ITEM_ATTRIBUTE_DESCRIPTION, string.format("Casted by: %s", creature:getName()))
	end
end
```

**Propósito:** Cria campo mágico com validações e atributos.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `position` | Position | Tile alvo |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Campo criado |
| `false` | Validação falhou |

**Validações:**

| Check | Lógica | Efeito |
|---|---|---|
| `Tile(position)` | Tile existe? | Se nulo: false |
| `TILESTATE_FLOORCHANGE` | É descida? | Se true: false |
| `getTopCreature()` | Top = player? | Se monstro: false |

**Diferenciação Mundo:**

```lua
if Game.getWorldType() == WORLD_TYPE_NO_PVP then
    magicWall = ITEM_MAGICWALL_SAFE
else
    magicWall = ITEM_MAGICWALL
end
```

**Atributos Item:**

| Atributo | Valor |
|---|---|
| Duration | 16-24 segundos (aleatório) |
| Description | "Casted by: [Nome Caster]" |

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGY)
combat:setCallback(CALLBACK_PARAM_TARGETTILE, "onCreateMagicWall")
```

**Propósito:** Combat sem dano, apenas callback.

**Parâmetro:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ENERGY | Projétil energia |
| `Callback` | TARGETTILE | Executa função em tile |

## 🤖 Documentação das Funções

### onCreateMagicWall(creature, position)

**Descrição:** Cria campo mágico com validações e atributos.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `position` | Position | Tile alvo |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Campo criado |
| `false` | Falhou em validação |

**Validações (em ordem):**

1. `Tile(position)` - Tile existe?
2. `TILESTATE_FLOORCHANGE` - É descida/piso diferente?
3. `getTopCreature()` - Tem criatura? É monstro?

**Mundo:**

| Tipo | Item | Efeito |
|---|---|---|
| NO_PVP (Safe) | ITEM_MAGICWALL_SAFE | Versão segura |
| PVP | ITEM_MAGICWALL | Versão normal |

**Duração:** 16-24 segundos (aleadamente)

**Descrição:** "Casted by: [Nome do Caster]"

**Exemplo:**

```lua
onCreateMagicWall(mago, targetPosition)
// Tile existe? SIM
// Floor change? NÃO
// Top creature = player? SIM (player ou vazio)
// Mundo = PvP? SIM -> ITEM_MAGICWALL
// Item criado com duração 16-24s
// Description: "Casted by: MagoNome"
// Retorna: true (criado!)
```

### rune.onCastSpell(creature, variant, isHotkey)

**Descrição:** Executa callback TARGETTILE para criar campo.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `variant` | Variant | Tile destino |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Campo criado |
| `false` | Validação falhou |

**Efeito:**
- Projétil energia viaja até tile
- Callback onCreateMagicWall executado
- Item mágico criado com duração
- Campo bloqueia movimento (blocking=true)

**Exemplo:**

```lua
-- Mago nível 32, MLvl 9
rune.onCastSpell(mago, tileVariant, false)
// Callback TARGETTILE
// Valida tile em tileVariant
// Se OK: cria MAGICWALL item
// Duração: 16-24s
// Descrição: "Casted by: MagoNome"
// Resultado: Campo tático criado!
```
