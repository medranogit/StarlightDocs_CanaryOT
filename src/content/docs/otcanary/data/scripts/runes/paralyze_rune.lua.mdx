## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `paralyze_rune` oferece controle tático:

- **Efeito:** CONDITION_PARALYZE 6s
- **Tipo:** Suporte (não dano)
- **Vocação:** Druids (restrita)
- **Custo:** 1 carga + 1400 mana
- **Cooldown:** Assimétrico (6s/2s)

### Arquitetura

Combat com condition (sem dano):

```
local combat = Combat()
├─ Type: UNDEFINEDDAMAGE (sem dano)
├─ Effect: MAGIC_RED (target)
├─ Condition: PARALYZE
│  └─ Ticks: 6000 ms
├─ Formula: -1, 0, -1, 0 (puro paralise)
└─ Resultado: Paralisia!

rune.onCastSpell()
├─ combat:execute()
├─ Se sucesso:
│  └─ Efeito GREEN caster
└─ Paralisia aplicada!
```

**Propósito:** Combat de suporte sem dano.

**Parâmetros:**

**Características:**
- Sem dano direto
- Apenas paralisia
- Efeito visual RED

### Variável Global: condition

```lua
local condition = Condition(CONDITION_PARALYZE)
condition:setParameter(CONDITION_PARAM_TICKS, 6000)
condition:setFormula(-1, 0, -1, 0)
combat:addCondition(condition)
```

**Propósito:** Condition de paralisia customizada.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `Type` | CONDITION_PARALYZE | Tipo: paralisia |
| `TICKS` | 6000 | Duração: 6 segundos |
| `Formula` | -1, 0, -1, 0 | Puro imobilizar |

**Fórmula Condition:**
```
-1, 0, -1, 0 = paralisa completamente
```

---

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var)
	if not combat:execute(creature, var) then
		return false
	end

	creature:getPosition():sendMagicEffect(CONST_ME_MAGIC_GREEN)
	return true
end
```

**Propósito:** Handler com efeito visual duplo.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Target |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Paralisia aplicada |
| `false` | Combat falhou |

**Lógica:**

```lua
if not combat:execute(creature, var) then
    return false  -- Combat falhou
end

creature:getPosition():sendMagicEffect(CONST_ME_MAGIC_GREEN)
return true  -- Sucesso + efeito caster
```

**Efeitos:**
- Target: RED (paralizado)
- Caster: GREEN (sucesso)

## 🤖 Documentação das Funções

### rune.onCastSpell(creature, var)

**Descrição:** Paralisa alvo com condition e efeitos duplos.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador (Druid) |
| `var` | Variant | Target (obrigatório) |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Paralisia aplicada |
| `false` | Combat falhou |

**Condições:**
- Level 54+ requerido
- MLvl 18+ requerido
- Druid ou Elder Druid
- 1400 mana disponível
- 1 carga disponível
- PZ lock válido

**Efeitos:**

| Efeito | Tipo | Duração |
|---|---|---|
| RED | Target | Visível |
| GREEN | Caster | Visível |
| PARALYZE | Condition | 6000ms |

**Exemplo:**

```lua
-- Druid nível 54, MLvl 18
rune.onCastSpell(druid, targetVariant)
// Combat com condition PARALYZE
// Target paralizado por 6s
// Efeito RED em alvo
// Efeito GREEN em druid
// Mana: -1400
// Cargas: -1
// Resultado: Alvo preso 6 segundos!
```
