Esta runa implementa um **sistema escalável econômico para treino**:

1. **Fórmula Econômica:**
   - min = (level/5) + (maglevel*0.4) + 2
   - max = (level/5) + (maglevel*1.59) + 10
   - Very baixa escalabilidade (treino!)

2. **Muitas Cargas:**
   - 10 uses (sessão longa!)
   - Ideal para farming/treino
   - Múltiplos targets

3. **Acesso Early:**
   - Level 24 (cedo)
   - MLvl 3 (baixo)
   - Sem PZ lock (town safe)

4. **Efeito Earth:**
   - CONST_ME_STONES
   - Visual estalagmites
   - Som customizado


## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `stalagmite` oferece treino econômico early:

- **Dano:** COMBAT_EARTHDAMAGE escalável baixo
- **Fórmula:** (level/5) + (maglevel*0.4/1.59) + bônus
- **Cargas:** 10
- **Target:** Requerido
- **Sem PZ Lock:** Town safe

### Arquitetura

Combat com fórmula callback leve:

```
local combat = Combat()
├─ Type: EARTHDAMAGE
├─ Effect: STONES
├─ Distance: EARTH
└─ Callback: onGetFormulaValues

onGetFormulaValues()
└─ min/max econômico

rune.onCastSpell()
└─ combat:execute()
```

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 0.4) + 2
	local max = (level / 5) + (maglevel * 1.59) + 10
	return -min, -max
end
```

**Propósito:** Calcula dano econômico.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 0.4) + 2
max = (level / 5) + (maglevel * 1.59) + 10
```

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 24 | 3 | 8 | 20 |
| 40 | 8 | 14 | 33 |
| 60 | 15 | 24 | 54 |

## 🤖 Documentação das Funções

### onGetFormulaValues(player, level, maglevel)

**Descrição:** Calcula dano terra econômico.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|

| `-max` | number | Dano máximo |

**Exemplo:**

