## 💡 Tip

<Aside type="tip">
**Dano de Energia com Field Deployment**

Esta runa implementa um **sistema de ataque territorial**:

1. **Dano de Energia:**
   - COMBAT_ENERGYDAMAGE
   - Projétil visível (CONST_ANI_ENERGYBALL)
   - Efeito no impacto (CONST_ME_ENERGYHIT)

2. **Field Criado:**
   - Item ITEM_ENERGYFIELD_PVP
   - Criado no impacto
   - Controle territorial

3. **PZ Locked:**
   - Só funciona fora de protection zones
   - Protege players em town
   - Força combate em dungeons/arenas

**Fluxo:**
```
Aponta runa em inimigo
├─ PZ Lock: valida se fora PZ
├─ Projétil viaja (ENERGYBALL)
├─ Chega no alvo
├─ Dano aplicado
├─ Field criado no impacto
└─ Inimigo cercado, territorialidade
```

**Diferencial:** Field criado oferece controle + bloco de movimento.
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `energy_bomb` oferece dano ofensivo territorial:

- **Dano:** COMBAT_ENERGYDAMAGE
- **Efeito:** Projétil + impacto explosivo
- **Field:** Energia PvP criado no impacto
- **Controle:** PZ lock-out força combate fora de town

### Arquitetura

Combat simples com item criado:

```
local combat = Combat()
├─ Type: COMBAT_ENERGYDAMAGE
├─ Effect: ENERGYHIT
├─ Distance: ENERGYBALL (projétil)
├─ Area: 1x1 (single tile)
└─ CreateItem: ENERGYFIELD_PVP

rune.onCastSpell()
└─ combat:execute(creature, var)
```

### Fluxo Lógico Resumido

| Etapa | Descrição |
|---|---|
| **Conjura** | onCastSpell() chamado |
| **PZ Lock** | Valida se fora PZ |
| **Combat Execute** | Projétil + dano |
| **Field Criado** | ENERGYFIELD_PVP no impacto |

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYHIT)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGYBALL)
combat:setParameter(COMBAT_PARAM_CREATEITEM, ITEM_ENERGYFIELD_PVP)
combat:setArea(createCombatArea(AREA_SQUARE1X1))
```

**Propósito:** Instância de Combat configurada para dano de energia com field.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ENERGYDAMAGE | Tipo de dano energia |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ENERGYHIT | Efeito visual no impacto |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ENERGYBALL | Projétil viajando |
| `COMBAT_PARAM_CREATEITEM` | ITEM_ENERGYFIELD_PVP | Field PvP criado |
| `Area` | AREA_SQUARE1X1 | 1x1 (apenas tile alvo) |

**Características:**
- Sem fórmula (dano fixo - necessário adicionar se escalável)
- Sem callback (dano é padrão do engine)
- Field criado automaticamente no impacto

---

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var, isHotkey)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler principal da runa ao conjuração.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Alvo (position) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Combat executado, dano/field aplicado |
| `false` | PZ lock, LOS bloqueado, ou falha |

**Lógica:**
- Retorna resultado direto de `combat:execute()`
- PZ lock é validado pelo engine (setPzLocked)
- Sem lógica adicional (combat faz tudo)

## 🤖 Documentação das Funções

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Causa dano de energia e cria field no impacto.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Alvo (position) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Combat executado, dano + field |
| `false` | PZ lock bloqueado, LOS falhou |

**Validações:**
- **PZ Lock:** Engine valida automaticamente
- **LOS:** Line of sight (se necessário)
- **Target válido:** Position devem ser valid

**Efeito:**
- Projétil ENERGYBALL viaja até alvo
- Impacto ENERGYHIT no alvo
- Field ENERGYFIELD_PVP criado na tile
- Dano aplicado ao alvo

**Exemplo:**

```lua
-- Knight aponta runa em inimigo fora de town
rune.onCastSpell(knight, enemyVariant, false)
// PZ lock valida: não em PZ, ok
// Projétil viaja visualmente
// Chega no inimigo
// Dano energético aplicado
// Field criado na tile
// Resultado: Inimigo preso, cercado por energy
```
