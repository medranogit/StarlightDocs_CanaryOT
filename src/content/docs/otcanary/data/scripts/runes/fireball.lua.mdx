## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `fireball` oferece dano escalável inicial:

- **Dano:** COMBAT_FIREDAMAGE escalável
- **Fórmula:** (level/5) + (maglevel*1.81/3) + bônus
- **Área:** Single target
- **Acesso:** Level 27, sem PZ lock

### Arquitetura

Combat com fórmula callback:

```
local combat = Combat()
├─ Type: COMBAT_FIREDAMAGE
├─ Effect: FIREATTACK
├─ Distance: FIRE
└─ Callback: onGetFormulaValues

onGetFormulaValues()
└─ min/max escalável

rune.onCastSpell()
└─ combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_FIREDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_FIREATTACK)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_FIRE)
```

**Propósito:** Instância de Combat para bola de fogo.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_FIREDAMAGE | Dano fogo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_FIREATTACK | Efeito ataque |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_FIRE | Projétil fogo |

**Características:**
- Sem `combat:setArea()` = single target
- Callback para fórmula escalável
- Sem armor bypass

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.81) + 10
	local max = (level / 5) + (maglevel * 3) + 18
	return -min, -max
end
```

**Propósito:** Calcula dano escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level total |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 1.81) + 10
max = (level / 5) + (maglevel * 3) + 18
```

**Pesos:**
- Level: 0.2 por nível
- Maglevel min: 1.81
- Maglevel max: 3.0

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 27 | 4 | 23 | 35 |
| 40 | 8 | 37 | 57 |
| 60 | 15 | 54 | 81 |
| 100 | 25 | 85 | 123 |

### Registração do Callback

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var, isHotkey)

end
```

```lua
local min = (level / 5) + (maglevel * 1.81) + 10
local max = (level / 5) + (maglevel * 3) + 18
```

**Benefício:** Maglevel tem impacto maior que level (~2x).

### Padrão 2: Bônus Fixo

```lua
-- + 10 (min), + 18 (max)
```

**Benefício:** Garante dano base mesmo com level baixo.

## 🤖 Documentação das Funções

### onGetFormulaValues(player, level, maglevel)

**Descrição:** Calcula dano de fireball.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Lança bola de fogo escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Target (obrigatório) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Dano aplicado |
| `false` | Target inválido |

**Efeito:**
- Projétil fogo viaja
- Impacto FIREATTACK
- Dano escalável aplicado
- Single target (sem área)

**Exemplo:**

```lua
-- Mago nível 40, MLvl 8 aponta em inimigo
rune.onCastSpell(mago, targetVariant, false)
// Precisa target selecionado (needTarget)
// Calcula dano: -32 a -50
// Projétil viaja e impacta
// Resultado: Inimigo queimado
```
