## 💡 Tip

<Aside type="tip">
**Bola de Fogo Grande com Área**

Esta runa implementa um **sistema de dano em área com escalabilidade**:

1. **Área 3x3:** Até 9 targets simultâneos
2. **Fórmula Escalável:**
   - min = (level/5) + (maglevel*1.2) + 7
   - max = (level/5) + (maglevel*2.8) + 17
   - Mesmo da avalanche (mas fogo vs físico)

3. **Sem PZ Lock:** Funciona em town!
4. **Efeito:** FIREAREA (explosão fogo)

**Comparação com fireball:**
```
fireball:       single target, mlvl*1.81/3
great_fireball: 3x3 área, mlvl*1.2/2.8
```

**Fluxo:**
```
Aponta em grupo
├─ Projétil fogo viaja
├─ Chega no centro
├─ Explode em 3x3 (FIREAREA)
└─ Todos em área sofrem dano
```

**Diferencial:** Primeira AoE de fogo disponível!
</Aside>

### Propósito Principal

A runa `great_fireball` oferece dano em área:

- **Dano:** COMBAT_FIREDAMAGE escalável
- **Fórmula:** (level/5) + (maglevel*1.2/2.8) + bônus
- **Área:** 3x3 Circle (até 9 targets)
- **Acesso:** Level 30, sem PZ lock

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_FIREDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_FIREAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_FIRE)
combat:setArea(createCombatArea(AREA_CIRCLE3X3))
```

**Propósito:** Instância de Combat para grande bola de fogo.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_FIREDAMAGE | Dano fogo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_FIREAREA | Explosão área |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_FIRE | Projétil fogo |
| `Area` | AREA_CIRCLE3X3 | 3x3 círculo (9 tiles) |

**Características:**
- Área 3x3 = splash damage
- Callback para fórmula escalável
- Efeito explosivo visual

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.2) + 7
	local max = (level / 5) + (maglevel * 2.8) + 17
	return -min, -max
end
```

**Propósito:** Calcula dano escalável em área.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level total |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 1.2) + 7
max = (level / 5) + (maglevel * 2.8) + 17
```

**Pesos:**
- Level: 0.2 igual
- Maglevel min: 1.2
- Maglevel max: 2.8 (quase 3x min)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 30 | 4 | 13.8 | 26.2 |
| 50 | 10 | 23 | 45 |
| 75 | 20 | 40 | 73 |
| 100 | 30 | 54 | 101 |
