## 💡 Tip

<Aside type="tip">
**Icípide de Gelo com Passagem Livre**

Esta runa implementa um **sistema de dano de gelo escalável sem bloqueio**:

1. **Fórmula Escalável (Padrão):**
   - min = (level/5) + (maglevel*1.81) + 10
   - max = (level/5) + (maglevel*3) + 18
   - Mesmo padrão do fireball (mas gelo)

2. **Sem Bloqueio:** isBlocking = false
   - Creatures passam através
   - Não bloqueia movimento

3. **Distância:** allowFarUse = true (funciona longe!)
4. **Efeito:** ICEAREA (visual gelo)

**Fórmula Visual:**
```
level 28, mlvl 4:
  min = 5.6 + 7.24 + 10 = 22.84
  max = 5.6 + 12 + 18 = 35.6

level 60, mlvl 15:
  min = 12 + 27.15 + 10 = 49.15
  max = 12 + 45 + 18 = 75
```

**Diferencial:** Sem bloqueio = passagem livre, gelo vs fogo!
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `icicle` oferece dano de gelo escalável com passagem:

- **Dano:** COMBAT_ICEDAMAGE escalável
- **Fórmula:** (level/5) + (maglevel*1.81/3) + bônus
- **Área:** Single target
- **Distancia:** Permitida
- **Bloqueio:** Não (creatures passam)

### Arquitetura

Combat com fórmula callback padrão:

```
local combat = Combat()
├─ Type: COMBAT_ICEDAMAGE
├─ Effect: ICEAREA
├─ Distance: ICE
└─ Callback: onGetFormulaValues

onGetFormulaValues()
└─ min/max escalável

rune.onCastSpell()
└─ combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ICEDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ICEAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ICE)
```

**Propósito:** Instância de Combat para icípide de gelo.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ICEDAMAGE | Dano gelo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ICEAREA | Efeito área gelo |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ICE | Projétil gelo |

**Características:**
- Sem `combat:setArea()` = single target
- Callback para fórmula escalável (padrão)
- Sem armor bypass
- Sem bloqueio (creatures passam)

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.81) + 10
	local max = (level / 5) + (maglevel * 3) + 18
	return -min, -max
end
```

**Propósito:** Calcula dano de gelo escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level total |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 1.81) + 10
max = (level / 5) + (maglevel * 3) + 18
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 1.81
- Maglevel max: 3.0

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 28 | 4 | 23 | 35 |
| 50 | 10 | 38 | 58 |
| 80 | 20 | 62 | 101 |
| 100 | 30 | 80 | 135 |

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Lança icípide de gelo escalável a distancia.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Target (obrigatório) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Icípide lançada |
| `false` | Target inválido |

**Efeito:**
- Projétil gelo viaja (distancia)
- Som customizado de cast + impacto
- Impacto ICEAREA
- Dano escalável
- Sem bloqueio real

**Exemplo:**

```lua
-- Mago nível 50, MLvl 10
rune.onCastSpell(mago, targetVariant, false)
// allowFarUse = ataque longe
// Projétil gelo viaja
// Impacto visual gelo
// isBlocking=false: creatures passam
// Resultado: -38 a -58 dano gelo
```
