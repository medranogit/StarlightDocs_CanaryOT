## 💡 Tip

<Aside type="tip">
**Fogo da Alma com Queimadura Prolongada**

Esta runa implementa um **sistema de dano inicial + DoT (damage over time)**:

1. **Impacto Imediato:**
   - COMBAT_FIREDAMAGE direto
   - Efeito HITBYFIRE
   - Dano instantâneo

2. **DoT Condition:**
   - CONDITION_FIRE customizada
   - 10 dano a cada 2000ms (cada 2 segundos)
   - Delayed: 1 (inicia após delay)

3. **Sem Rune ID:**
   - rune:id() não definido
   - Usa ID padrão auto-assigned
   - Comportamento atípico!

4. **Requer Target:**
   - needTarget: true
   - Seleção explícita

**Fluxo:**
```
Alvo atingido
├─ Impacto FIREDAMAGE (instantâneo)
├─ Efeito HITBYFIRE (visual)
├─ Condition FIRE aplicada
├─ Delay inicial (CONDITION_PARAM_DELAYED: 1)
└─ 10 dano a cada 2s (persistente)
```

**Diferencial:** DoT clássico + soul identity!
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `soul_fire` oferece dano com queimadura:

- **Dano:** COMBAT_FIREDAMAGE + DoT
- **Condition:** FIRE com 10 dano/2s
- **Target:** Requerido
- **Cargas:** 3

### Arquitetura

Combat com condition DoT:

```
local combat = Combat()
├─ Type: FIREDAMAGE
├─ Effect: HITBYFIRE
├─ Distance: FIRE
└─ Condition: FIRE
   └─ DoT: 10 dano @ 2000ms

rune.onCastSpell()
└─ combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_FIREDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITBYFIRE)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_FIRE)
```

**Propósito:** Combat com dano fogo.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_FIREDAMAGE | Dano fogo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HITBYFIRE | Efeito queimadura |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_FIRE | Projétil fogo |

---

### Variável Global: condition

```lua
local condition = Condition(CONDITION_FIRE)
condition:setParameter(CONDITION_PARAM_DELAYED, 1)
condition:addDamage(10, 2000, -10)
combat:addCondition(condition)
```

**Propósito:** Condition de queimadura com DoT.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `Type` | CONDITION_FIRE | Tipo: fogo |
| `DELAYED` | 1 | Inicia com delay |
| `addDamage(10, 2000, -10)` | 10 dano @ 2000ms | DoT persistente |

**Fórmula DoT:**
```
10 dano a cada 2000ms (2 segundos)
-10 = tick duration
```

---

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var, isHotkey)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler simples.

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Soul fire ativado |
| `false` | Target falhou |

## 🤖 Documentação das Funções

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Aplica soul fire com DoT permanente.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Target (obrigatório) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Soul fire aplicado |
| `false` | Target falhou |

**Efeitos:**

| Efeito | Tipo | Duração |
|---|---|---|
| FIREDAMAGE | Instantâneo | Imediato |
| HITBYFIRE | Visual | Visível |
| CONDITION_FIRE | DoT | Persistente |
| Tick | 10 dano @ 2000ms | Enquanto ativo |

**Exemplo:**

```lua
-- Mago nível 27, MLvl 7
rune.onCastSpell(mago, targetVariant, false)
// Combat executa
// Impacto FIREDAMAGE
// Efeito HITBYFIRE (visual)
// Condition FIRE aplicada
// Alvo sofre:
//   - Impacto inicial
//   - 10 dano a cada 2s
// Resultado: Queimadura prolongada!
```
