## 💡 Tip

<Aside type="tip">
**Bomba de Veneno com Campo Auto-Deploy**

Esta runa implementa um **sistema de área com campo automático**:

1. **Dano + Field:**
   - COMBAT_EARTHDAMAGE + efeito GREEN_RINGS
   - ITEM_POISONFIELD_PVP auto-criado
   - Efeito duplo: dano + controle

2. **Área SQUARE 1x1:**
   - Single tile precision
   - Não área grande (controlado)

3. **Sem Bloqueio:**
   - isBlocking: false
   - Creatures passam através
   - Uso livre, movimento fluido

4. **Cargas Poucas:**
   - 2 apenas
   - Poder balanceado
   - Uso tático

**Fluxo:**
```
Lança bomba
├─ Projétil viaja
├─ Chega em tile
├─ Dano earth aplicado
├─ GREEN_RINGS efeito
├─ POISONFIELD criado
└─ Área efeito = controle!
```

**Diferencial:** Bomba com field = agressão + controle!
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `poison_bomb` oferece dano + controle:

- **Dano:** COMBAT_EARTHDAMAGE
- **Field:** POISONFIELD_PVP automático
- **Área:** SQUARE 1x1
- **Bloqueio:** Não (passagem livre)
- **Cargas:** 2

### Arquitetura

Combat com campo automático:

```
local combat = Combat()
├─ Type: EARTHDAMAGE
├─ Effect: GREEN_RINGS
├─ Distance: POISON
├─ CreateItem: POISONFIELD_PVP
└─ Area: SQUARE 1x1

rune.onCastSpell()
└─ combat:execute() (auto-cria field)
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_EARTHDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_GREEN_RINGS)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_POISON)
combat:setParameter(COMBAT_PARAM_CREATEITEM, ITEM_POISONFIELD_PVP)
combat:setArea(createCombatArea(AREA_SQUARE1X1))
```

**Propósito:** Combat de dano + field automático.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_EARTHDAMAGE | Dano terra |
| `COMBAT_PARAM_EFFECT` | CONST_ME_GREEN_RINGS | Efeito anéis verdes |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_POISON | Projétil veneno |
| `COMBAT_PARAM_CREATEITEM` | ITEM_POISONFIELD_PVP | Field automático |
| `Area` | AREA_SQUARE1X1 | Área single tile |

**Características:**
- SQUARE 1x1 = single
- Field auto-deploy
- Sem armor bypass

---

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var, isHotkey)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler simples, tudo no combat.

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Bomba lançada + field criado |
| `false` | Target falhou |

## 🤖 Documentação das Funções

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Lança bomba de veneno com field automático.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Position alvo |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Bomba ativa + field criado |
| `false` | Position falhou |

**Efeito:**
- Projétil veneno viaja
- Impacto com anéis verdes
- Dano earth aplicado (1x1)
- POISONFIELD_PVP criado (campo tóxico)
- Creatures passam (não bloqueio)

**Exemplo:**

```lua
-- Mago nível 25, MLvl 4
rune.onCastSpell(mago, positionVariant, false)
// PZ locked: fora proteção
// Projétil viaja
// Impacto GREEN_RINGS
// Dano earth em 1x1
// Field POISONFIELD criado
// Creatures passam (livres)
// Resultado: Bomba + field!
```
