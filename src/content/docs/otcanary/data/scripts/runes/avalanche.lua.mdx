## 💡 Tip

<Aside type="tip">
**Dano de Gelo em Área com Fórmula Escalável**

Esta runa implementa um **sistema de dano ofensivo com escalabilidade**:

1. **Fórmula de Dano:**
   - Mínimo: (level / 5) + (maglevel * 1.2) + 7
   - Máximo: (level / 5) + (maglevel * 2.8) + 17
   - Cresce com ambos level E maglevel

2. **Área 3x3:** Afeta múltiplos inimigos
3. **Efeito Gelo:** ICEAREA + distância ICE
4. **Custo:** 4 cargas (mais caro que outras)

**Fórmula Visual:**
```
Dano Mín = (lvl / 5) + (mlvl * 1.2) + 7
Dano Máx = (lvl / 5) + (mlvl * 2.8) + 17

Exemplos:
- Lvl 30, MLvl 4: dano -20.4 a -45.2
- Lvl 50, MLvl 10: dano -39.0 a -85.0
```

**Diferencial:** Escalável + área = crowd control efetivo.
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `avalanche` oferece dano de gelo escalável:

- **Tipo de Dano:** COMBAT_ICEDAMAGE (gelo)
- **Escala:** Baseada em level + maglevel
- **Área:** 3x3 (até 9 tiles)
- **Custo:** 4 cargas (significativo)

### Arquitetura

Combat com fórmula callback + área:

```
local combat = Combat()
├─ Type: COMBAT_ICEDAMAGE
├─ Effect: ICEAREA
├─ Distance: ICE
├─ Area: 3x3 Circle
├─ Callback: onGetFormulaValues

function onGetFormulaValues(player, level, maglevel)
  ├─ min = (level/5) + (maglevel*1.2) + 7
  └─ max = (level/5) + (maglevel*2.8) + 17
```

### Fluxo Lógico Resumido

| Etapa | Descrição |
|---|---|
| **Conjura Runa** | onCastSpell() chamado |
| **Combat Execute** | Pega player level/maglevel |
| **Calcula Dano** | onGetFormulaValues() retorna min/max |
| **Aplica Área** | 3x3 afeta todos em range |
| **Dano Aplicado** | Cada criatura sofre dano gelo |

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ICEDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ICEAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ICE)
combat:setArea(createCombatArea(AREA_CIRCLE3X3))
```

**Propósito:** Instância de Combat configurada para dano de gelo em área.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ICEDAMAGE | Tipo de dano gelo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ICEAREA | Efeito visual gelo em área |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ICE | Projétil gelo viajando |
| `Area` | AREA_CIRCLE3X3 | 3x3 círculo (9 tiles) |

**Características:**
- Sem target requerido (area-based)
- Fórmula anexada via callback
- Distância com projétil visual

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.2) + 7
	local max = (level / 5) + (maglevel * 2.8) + 17
	return -min, -max
end
```

**Propósito:** Calcula dano mínimo e máximo escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador (oferecido pelo combat) |
| `level` | number | Level do jogador |
| `maglevel` | number | Magic level do jogador |

**Retorno:**

| Valor | Descrição |
|---|---|
| `-min` | Dano mínimo (negativo) |
| `-max` | Dano máximo (negativo) |

**Fórmula Detalhada:**

```
Componentes:
  - (level / 5):       Escala base de level (0.2 por level)
  - (maglevel * 1.2):  Escala mínima de maglevel
  - (maglevel * 2.8):  Escala máxima de maglevel
  - +7, +17:           Bônus fixo (min e max)

Exemplos:
  Level 30, MLvl 4:
    min = (30/5) + (4*1.2) + 7 = 6 + 4.8 + 7 = 17.8
    max = (30/5) + (4*2.8) + 17 = 6 + 11.2 + 17 = 34.2
    Dano: -17.8 a -34.2

  Level 50, MLvl 10:
    min = (50/5) + (10*1.2) + 7 = 10 + 12 + 7 = 29
    max = (50/5) + (10*2.8) + 17 = 10 + 28 + 17 = 55
    Dano: -29 a -55

  Level 100, MLvl 20:
    min = (100/5) + (20*1.2) + 7 = 20 + 24 + 7 = 51
    max = (100/5) + (20*2.8) + 17 = 20 + 56 + 17 = 93
    Dano: -51 a -93
```

**Registração:**

```lua
combat:setCallback(CALLBACK_PARAM_LEVELMAGICVALUE, "onGetFormulaValues")
```

## 🤖 Documentação das Funções

### onGetFormulaValues(player, level, maglevel)

**Descrição:** Calcula dano escalável para avalanche.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador (oferecido por combat) |
| `level` | number | Level total do jogador |
| `maglevel` | number | Magic level do jogador |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo (negativo) |
| `-max` | number | Dano máximo (negativo) |

**Cálculo:**
- min = (level / 5) + (maglevel * 1.2) + 7
- max = (level / 5) + (maglevel * 2.8) + 17

**Exemplo:**

```lua
onGetFormulaValues(player, 40, 6)
// min = 8 + 7.2 + 7 = 22.2
// max = 8 + 16.8 + 17 = 41.8
// Retorna: -22.2, -41.8
```

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Executa dano de gelo em área 3x3.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `var` | Variant | Posição alvo |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|

| `false` | Alvo inválido, sem LOS |

**Efeito:**
- Projétil gelo viaja até alvo
- Explosão ICEAREA em 3x3
- Todos em área recebem dano gelo escalável

**Exemplo:**

```lua
rune.onCastSpell(mage, enemyGroupVariant, false)
// Projétil ICE viaja
// Chega na posição
// Explode em 3x3 (até 9 inimigos)
// Cada recebe dano -22 a -42 (exemplo lvl 40, mlvl 6)
```
