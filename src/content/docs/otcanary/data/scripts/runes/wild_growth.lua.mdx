## 💡 Tip

<Aside type="tip">
**Barragem Vegetação Selvagem com Callback Tile**

Esta runa implementa um **sistema de item creation via callback tile**:

1. **Não é Combat Direto:**
   - Sem COMBAT_PARAM_TYPE
   - Sem dano instantâneo
   - Cria item em tile

2. **Callback TARGETTILE:**
   - onCreateWildGrowth handler
   - Position-based (tile)
   - Item generation

3. **World Type Detection:**
   - WORLD_TYPE_NO_PVP → ITEM_WILDGROWTH_SAFE
   - Outro → ITEM_WILDGROWTH
   - Adaptativo

4. **Validações Complexas:**
   - Tile existence: must exist
   - FloorChange: reject se TILESTATE_FLOORCHANGE
   - Creature: reject se non-player creature
   - Position: sem items já lá

5. **Item Metadata:**
   - Duration: 30 segundos
   - Description: caster name
   - Blocking: bloqueio total

**Fluxo:**
```
Runa conjurada
├─ Tile callback trigger
├─ Validações múltiplas
│  ├─ Tile exists?
│  ├─ No floorchange?
│  ├─ No non-player creatures?
│  └─ Safe zone?
└─ Item criado
   ├─ Duration 30s
   ├─ Blocking visual
   └─ Caster stored
```

**Diferencial:** Não-combat callback + item creation + world detection!
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

A runa `wild_growth` oferece bloqueio tático via items:

- **Tipo:** Item creation (não combat)
- **Callback:** TARGETTILE (onCreateWildGrowth)
- **Item:** WILDGROWTH ou WILDGROWTH_SAFE (world dependent)
- **Duração:** 30s
- **Cargas:** 2

### Arquitetura

Callback tile com validações:

```
combat:setCallback(CALLBACK_PARAM_TARGETTILE, "onCreateWildGrowth")

onCreateWildGrowth(creature, position)
├─ Tile(position) check
├─ FloorChange check: reject
├─ TopCreature check: reject se non-player
├─ WorldType detect:
│  ├─ NO_PVP → ITEM_WILDGROWTH_SAFE
│  └─ else → ITEM_WILDGROWTH
└─ Game.createItem(item, 1, position)
   ├─ setDuration(30)
   └─ setAttribute(description, caster_name)

rune.onCastSpell()
└─ combat:execute()
```

**Nota:** Sem COMBAT_PARAM_TYPE (não é dano!).

---

### Função Global: onCreateWildGrowth

```lua
function onCreateWildGrowth(creature, position)
	local tile = Tile(position)
	if not tile then
		return false
	end

	if tile:hasFlag(TILESTATE_FLOORCHANGE) then
		return false
	end

	if tile:getTopCreature() and not tile:getTopCreature():isPlayer() then
		return false
	end

	local wildGrowth
	if Game.getWorldType() == WORLD_TYPE_NO_PVP then
		wildGrowth = ITEM_WILDGROWTH_SAFE
	else
		wildGrowth = ITEM_WILDGROWTH
	end

	local item = Game.createItem(wildGrowth, 1, position)
	if item then
		item:setDuration(30)
		item:setAttribute(ITEM_ATTRIBUTE_DESCRIPTION, string.format("Casted by: %s", creature:getName()))
	end
end
```

**Propósito:** Cria vegetação selvagem com validações.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `position` | Position | Tile destination |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Item criado sucesso |
| `false` | Validação falhou |

**Validações:**

| Validação | Descrição | Rejeita |
|---|---|---|
| `Tile(position)` | Tile existence | Não existe |
| `hasFlag(TILESTATE_FLOORCHANGE)` | Floor change check | É floorchange |
| `getTopCreature()` | Creature presence | Non-player creature |

**World Type Selection:**

| WorldType | Item Selecionado |
|---|---|
| WORLD_TYPE_NO_PVP | ITEM_WILDGROWTH_SAFE |
| Outro | ITEM_WILDGROWTH |

**Item Attributes:**

| Atributo | Valor | Descrição |
|---|---|---|
| `Duration` | 30 | Segundos |
| `Description` | "Casted by: [name]" | Caster metadata |
