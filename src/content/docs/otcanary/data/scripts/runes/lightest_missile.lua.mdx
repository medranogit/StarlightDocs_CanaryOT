<Aside type="tip">
**Prática Escalável para Casters**

Esta runa implementa um **sistema educacional com escalabilidade mínima**:

1. **Vocação Restrita:**
   - Sorcerer/Master Sorcerer
   - Druid/Elder Druid
   - Paladin/Royal Paladin
   - Sem Knights (melee)

2. **Fórmula Escalável (Mínimamente):**
   - min = (level/5) + (maglevel*0.4) + 3
   - max = (level/5) + (maglevel*0.8) + 5
   - Um passo acima de prática pura

3. **Acesso Level 1:**
   - MLvl 0 (nenhum!)
   - Vocação-específica

4. **Aprendizado Progressivo:**
   - Começa como prática: 3-5 dano
   - Escalona levemente com MLvl
   - Introduz conceito de stats

**Comparação:**
```
lightest_magic_missile: 3-5 fixo (pura prática, todas vocações)
lightest_missile:       3-5 base + escalável (aprendizado, casters)
light_magic_missile:    2-4 base + maior escalável (próximo passo)
```

**Diferencial:** Prática com escalabilidade para casters!
</Aside>

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGY)
```

**Propósito:** Instância de Combat para míssil educacional.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ENERGYDAMAGE | Dano energia |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ENERGYAREA | Efeito explosão |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ENERGY | Projétil energia |

**Características:**
- Sem `combat:setArea()` = single target
- Callback para fórmula escalável baixa
- Sem armor bypass
- Sem needTarget (não requerido!)

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 0.4) + 3
	local max = (level / 5) + (maglevel * 0.8) + 5
	return -min, -max
end
```

**Propósito:** Calcula dano escalável educacional.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level total |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 0.4) + 3
max = (level / 5) + (maglevel * 0.8) + 5
```

**Pesos:**
- Level: 0.2 por ponto (padrão)
- Maglevel min: 0.4 (muito baixo)
- Maglevel max: 0.8 (baixo)
- Bônus: 3/5 (educacional)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 1 | 0 | 3 | 5 |
| 20 | 5 | 7 | 9 |
| 50 | 15 | 21 | 27 |
| 100 | 30 | 41 | 53 |

### Registração do Callback

**Descrição:** Calcula dano escalável educacional muito baixo.

### rune.onCastSpell(creature, var, isHotkey)

**Descrição:** Lança míssil educacional com escalabilidade suave.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador (Caster/Paladin) |
| `var` | Variant | Target (obrigatório) |
| `isHotkey` | boolean | Via hotkey |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Míssil lançado |
| `false` | Vocação/target falhou |

**Efeito:**
- Validação vocacional (casters only)
- Projétil energia viaja
- Impacto ENERGYAREA
- Dano escalável educacional
- Single target

**Exemplo:**

```lua
-- Druid nível 50, MLvl 15
rune.onCastSpell(druid, targetVariant, false)
// Vocação: Druid (OK)
// Projétil energia viaja
// Dano: -19 a -27
// Resultado: Aprendizado progressivo!

-- Knight nível 50, MLvl 15
rune.onCastSpell(knight, targetVariant, false)
// Vocação: Knight (BLOQUEADO!)
// Não é caster
// Resultado: Uso educacional restrito!
```
