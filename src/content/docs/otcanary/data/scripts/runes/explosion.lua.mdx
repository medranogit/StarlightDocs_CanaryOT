## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_EXPLOSIONAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_EXPLOSION)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, 1)
combat:setArea(createCombatArea(AREA_CIRCLE1X1))
```

**Propósito:** Instância de Combat para explosão física.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_PHYSICALDAMAGE | Dano físico |
| `COMBAT_PARAM_EFFECT` | CONST_ME_EXPLOSIONAREA | Explosão visual |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_EXPLOSION | Projétil explosão |
| `COMBAT_PARAM_BLOCKARMOR` | 1 | Ignora armadura (penetra) |
| `Area` | AREA_CIRCLE1X1 | 1x1 single target |

**Características:**
- BLOCKARMOR penetra defesa
- Sem área espalha = single tile
- Callback para fórmula escalável

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = 0
	local max = (level / 5) + (maglevel * 4.8)
	return -min, -max
end
```

**Propósito:** Calcula dano escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level total |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo (0) |
| `-max` | number | Dano máximo escalável |

**Fórmula:**
```
min = 0
max = (level / 5) + (maglevel * 4.8)
```

**Peso:**
- Level: 0.2 por nível (leve)
- Maglevel: 4.8 por magic level (pesado)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 31 | 6 | 0 | 35 |
| 50 | 10 | 0 | 58 |
| 75 | 20 | 0 | 111 |
| 100 | 30 | 0 | 164 |

---

### Registração do Callback

```lua
combat:setCallback(CALLBACK_PARAM_LEVELMAGICVALUE, "onGetFormulaValues")
```

**Propósito:** Anexa função ao callback.

### Função Global: rune.onCastSpell

```lua
function rune.onCastSpell(creature, var, isHotkey)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler principal.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Explosão executada, dano aplicado |
| `false` | Falha (LOS, etc) |
