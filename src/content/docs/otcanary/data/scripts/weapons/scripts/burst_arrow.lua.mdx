## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `burst_arrow.lua` implementa weapon de projétil tipo flecha burst com dano físico explosivo em área 3x3. Script define Combat com formula skill-based, área custom em padrão cruz (9 tiles), efeito explosão com animação burst arrow e som de impacto próprio. Weapon registra como WEAPON_AMMO com ID 3449, ataque 27, 100% hit chance, ação removecount (consome munição). Implementação inclui validação explícita que rejeita players com skull black (proteção contra PKs). Padrão straightforward de weapon ranged com AoE e validação de estado.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Área de Efeito (3x3)
local area = createCombatArea({
	{ 1, 1, 1 },
	{ 1, 3, 1 },  -- 3 = centro
	{ 1, 1, 1 },
})

-- 2. Configuração de Combat
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_EXPLOSIONAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_BURSTARROW)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, true)  -- Bloqueia armor
combat:setFormula(COMBAT_FORMULA_SKILL, 0, 0, 1, 0)  -- Skill-based
combat:setParameter(COMBAT_PARAM_IMPACTSOUND, SOUND_EFFECT_TYPE_BURST_ARROW_EFFECT)
combat:setParameter(COMBAT_PARAM_CASTSOUND, SOUND_EFFECT_TYPE_DIST_ATK_BOW)
combat:setArea(area)

-- 3. Instância de Weapon
local burstArrow = Weapon(WEAPON_AMMO)

-- 4. Handler de Uso
burstArrow.onUseWeapon = function(player, variant)
	-- Validação skull black
	if player:getSkull() == SKULL_BLACK then
		return false
	end
	-- Executa combat
	return combat:execute(player, variant)
end

-- 5. Configuração do Item
burstArrow:id(3449)
burstArrow:attack(27)
burstArrow:action("removecount")
burstArrow:ammoType("arrow")
burstArrow:shootType(CONST_ANI_BURSTARROW)
burstArrow:maxHitChance(100)
burstArrow:register()
```

| COMBAT_PARAM_DISTANCEEFFECT | CONST_ANI_BURSTARROW | Animação da flecha em voo |
| COMBAT_PARAM_BLOCKARMOR | true | Armor reduz dano |

| COMBAT_PARAM_CASTSOUND | SOUND_EFFECT_TYPE_DIST_ATK_BOW | Som ao disparar |

## 🤖 Documentação de Funções

### **burstarrow.onUseWeapon(player, variant)**

**Descrição:** Handler chamado quando player usa burst arrow.

**Parâmetros:**
- `player` (Player): Player disparando a flecha
- `variant` (Variant): Target/tile onde atirar

**Lógica:**
1. Verifica se player tem skull black
2. Se skull black: retorna false (rejeita ação)
3. Senão: executa combat:execute(player, variant)

**Retorno:**
- `boolean`: true (sucesso) ou false (skull black)

**Exemplo de Uso:**
```lua
-- Player sem skull dispara burst arrow
-- burstarrow.onUseWeapon(player, variant)
-- Combat executa com 3x3 AoE, 27 ataque
```
