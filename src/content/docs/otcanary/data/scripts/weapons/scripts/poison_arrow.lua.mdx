## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `poison_arrow.lua` implementa weapon ammo single-target com dano físico imediato + condição poison delayed em 3 ticks. Script define Combat físico com fórmula skill-based puro, adiciona Condition poison com delayed flag e 3 escalas de damage (4s/-3, 9s/-2, 20s/-1). Weapon registra como WEAPON_AMMO com ID 3448, ataque 21, chance acerto 91%, ação removecount. Implementação straightforward de poison ammo early-game que combina dano imediato + dot (damage over time) escalante progressivamente. Padrão útil para early progression com efeito visual poison arrow.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Configuração de Combat Físico
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_POISONARROW)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, true)  -- Armor reduz dano
combat:setFormula(COMBAT_FORMULA_SKILL, 0, 0, 1, 0)  -- Skill-based puro

-- 2. Configuração de Condição Poison
local condition = Condition(CONDITION_POISON)
condition:setParameter(CONDITION_PARAM_DELAYED, true)  -- Dano delayed
condition:addDamage(4, 4000, -3)   -- Tick 1: 4s interval, 4000ms duration, -3 dano
condition:addDamage(9, 4000, -2)   -- Tick 2: 9s interval, 4000ms duration, -2 dano
condition:addDamage(20, 4000, -1)  -- Tick 3: 20s interval, 4000ms duration, -1 dano

-- 3. Adição de Condição ao Combat
combat:addCondition(condition)

-- 4. Instância de Weapon
local poisonArrow = Weapon(WEAPON_AMMO)

-- 5. Handler de Uso
function poisonArrow.onUseWeapon(player, variant)
	return combat:execute(player, variant)
end

-- 6. Configuração do Item
poisonArrow:id(3448)
poisonArrow:attack(21)
poisonArrow:action("removecount")
poisonArrow:ammoType("arrow")
poisonArrow:shootType(CONST_ANI_POISONARROW)
poisonArrow:maxHitChance(91)
poisonArrow:register()
```

## 🤖 Documentação de Funções

### **poisonArrow.onUseWeapon(player, variant)**

**Descrição:** Handler chamado quando player usa poison arrow.

**Parâmetros:**
- `player` (Player): Player disparando
- `variant` (Variant): Target/tile alvo

**Lógica:**
1. Executa combat:execute(player, variant)
2. Combat causa dano físico imediato
3. Aplica condition poison (delayed)

**Retorno:**
- `boolean`: true (sucesso)

**Exemplo de Uso:**
```lua
-- Player dispara poison arrow em inimigo
-- 1. Dano físico imediato (skill-based)
-- 2. Condition poison aplicada (delayed)
-- 3. 3 ticks: -3 (4s), -2 (9s), -1 (20s) dano
```

---

### **Condition:setParameter(CONDITION_PARAM_DELAYED, boolean)**

**Descrição:** Define se condição causa dano delayed (não imediato).

**Valor:** `true`
- Dano ocorre em ticks schedulados (4s, 9s, 20s)
- Não imediato ao hit

---

### **Condition:addDamage(interval, duration, damage)**

**Descrição:** Adiciona tick de damage à condição.

**Parâmetros:**
- `interval` (number): Segundos até este tick
- `duration` (number): Duração em ms (4000 = 4s)
- `damage` (number): Dano (negativo)

**Poison Arrow:**
- Tick 1: interval=4, duration=4000, damage=-3
- Tick 2: interval=9, duration=4000, damage=-2
- Tick 3: interval=20, duration=4000, damage=-1

---

### **Combat:addCondition(condition)**

**Descrição:** Adiciona condição ao combat (aplicada ao hit).

**Poison Arrow:** Adiciona poison condition ao físico combat

---

### **Weapon:maxHitChance(percentage)**

**Descrição:** Define chance máxima de acerto da arma.

**Valor Poison Arrow:** `91`
- 91% chance hit
- 9% chance esquiva
- Rara para early game ammo

## 📌 Resumo

**Poison Arrow** é weapon ammo single-target com dano físico imediato + condição poison delayed em 3 ticks escalonados. Implementação combina Combat skill-based (dano físico) com Condition poison (dano over time: -3/-2/-1 em 4s/9s/20s). Weapon ammo básico (ataque 21) com chance acerto 91% para early game progression. Padrão útil de debuff combo que primeiro causa dano imediato+aplicar poison, depois dano progressivo em ticks. Formula skill-based permite escalamento com distance skill. Straightforward implementação single-target poison weapon.

Diferencia-se por: (1) condition poison delayed, (2) 3 ticks escalantes, (3) single target (sem AoE), (4) skill-based formula, (5) chance acerto 91%, (6) dano progressivo -3/-2/-1.
