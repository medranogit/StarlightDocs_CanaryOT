## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `viper_star.lua` implementa weapon missile com dual combat sequencial: primário (físico skill-based) + secundário (terra + poison delayed). Script define dois Combat objects: combat físico puro e secondCombat earth damage com condition poison. Handler onUseWeapon executa combat primário, valida hit (variant:getNumber()), se hit executa secondCombat com poison. Condition poison delayed tem 2 ticks (-2/-1 em 10s/20s). Weapon registra como WEAPON_MISSILE ID 7366, ataque 28, 76% hit chance, break chance 9%. Implementação avançada de missile com dual damage + condition application condicionada ao sucesso do hit primário. Padrão de sequential execution com validation de hit.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Configuração de Combat Primário (Físico)
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_GREENSTAR)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, true)
combat:setFormula(COMBAT_FORMULA_SKILL, 0, 0, 1, 0)  -- Skill-based puro

-- 2. Configuração de Condição Poison
local condition = Condition(CONDITION_POISON)
condition:setParameter(CONDITION_PARAM_DELAYED, true)
condition:addDamage(10, 4000, -2)  -- Tick 1: 10s interval, -2 dano
condition:addDamage(20, 4000, -1)  -- Tick 2: 20s interval, -1 dano

-- 3. Configuração de Combat Secundário (Terra + Poison)
local secondCombat = Combat()
secondCombat:setParameter(COMBAT_PARAM_TYPE, COMBAT_EARTHDAMAGE)
secondCombat:addCondition(condition)

-- 4. Instância de Weapon
local viperStar = Weapon(WEAPON_MISSILE)

-- 5. Handler de Uso - Dual Execute
function viperStar.onUseWeapon(player, variant)
	-- Executa combat primário
	local boolean = combat:execute(player, variant)
	if not boolean then
		return false
	end
	
	-- Valida se target foi atingido
	local target = variant:getNumber()
	if target ~= 0 then
		-- Executa combat secundário com poison
		boolean = secondCombat:execute(player, variant)
	end
	return boolean
end

-- 6. Configuração do Item
viperStar:id(7366)
viperStar:attack(28)
viperStar:breakChance(9)
viperStar:shootType(CONST_ANI_GREENSTAR)
viperStar:maxHitChance(76)
viperStar:register()
```

## 🤖 Documentação de Funções

### **viperStar.onUseWeapon(player, variant)**

**Descrição:** Handler que executa dual combat sequencial com validation de hit.

**Parâmetros:**
- `player` (Player): Player disparando missile
- `variant` (Variant): Target/tile alvo

**Fluxo:**
1. Executa `combat:execute(player, variant)` (dano físico)
2. Se retorna false: return false (falhou)
3. Pega target via `variant:getNumber()`
4. Se target != 0 (hit válido):
   - Executa `secondCombat:execute(player, variant)` (terra + poison)
5. Retorna boolean final

**Retorno:**
- `boolean`: true (ambos combats executaram), false (primary falhou)

**Exemplo de Uso:**
```lua
-- Player dispara viper star em inimigo
-- 1. Executa combat físico
-- 2. Se atingiu: executa secondCombat terra + poison
-- 3. Resultados: dano físico + dano terra + poison delayed (-2/-1 em 10s/20s)
```

### **Combat:execute(player, variant)**

**Descrição:** Executa combat contra variant (target ou tile).

**Retorno:**

**Viper Star:**

- Secondary combat executa se primary retorna true
