## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `diamond_arrow.lua` implementa weapon ammo premium com dano físico em AoE 5x5 padrão diamante, requerendo level 150. Script define Combat com callback custom onGetFormulaValues que calcula dano baseado em distance skill e attack stats. Fórmula: min = level/5, max = 0.09 * factor * distanceSkill * attack + level/5, permitindo escalamento progressivo com skill. Weapon registra com dual IDs (25757, 35901) para variações de raridade, ataque 37, 100% hit chance, ação removecount. Implementação inclui wieldUnproperly flag para permitir uso abaixo level com penalties. Padrão avançado de ranged weapon com fórmula skill scaling.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Área de Efeito (5x5 Diamante)
local area = createCombatArea({
	{ 0, 1, 1, 1, 0 },
	{ 1, 1, 1, 1, 1 },
	{ 1, 1, 3, 1, 1 },  -- 3 = centro
	{ 1, 1, 1, 1, 1 },
	{ 0, 1, 1, 1, 0 },
})

-- 2. Configuração de Combat
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYHIT)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_DIAMONDARROW)
combat:setParameter(COMBAT_PARAM_IMPACTSOUND, SOUND_EFFECT_TYPE_DIAMOND_ARROW_EFFECT)
combat:setParameter(COMBAT_PARAM_CASTSOUND, SOUND_EFFECT_TYPE_DIST_ATK_BOW)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, true)

-- 3. Fórmula de Dano com Callback
function onGetFormulaValues(player, skill, attack, factor)
	local distanceSkill = player:getEffectiveSkillLevel(SKILL_DISTANCE)
	local min = (player:getLevel() / 5)
	local max = (0.09 * factor) * distanceSkill * attack + (player:getLevel() / 5)
	return -min, -max
end

combat:setCallback(CALLBACK_PARAM_SKILLVALUE, "onGetFormulaValues")
combat:setArea(area)

-- 4. Instância de Weapon
local diamondArrow = Weapon(WEAPON_AMMO)

-- 5. Handler de Uso
function diamondArrow.onUseWeapon(player, variant)
	return combat:execute(player, variant)
end

-- 6. Configuração do Item
diamondArrow:id(25757)
diamondArrow:id(35901)  -- Dual ID
diamondArrow:level(150)
diamondArrow:attack(37)
diamondArrow:action("removecount")
diamondArrow:ammoType("arrow")
diamondArrow:shootType(CONST_ANI_DIAMONDARROW)
diamondArrow:maxHitChance(100)
diamondArrow:wieldUnproperly(true)
diamondArrow:register()
```

## 📊 Fórmula de Dano

**Função:** `onGetFormulaValues(player, skill, attack, factor)`

**Cálculo:**

```
min = level / 5
max = (0.09 * factor) * distanceSkill * attack + (level / 5)
return -min, -max  (valores negativos = dano)
```

**Exemplo (Player Level 200, Distance Skill 100, Attack 37, Factor 1.0):**

```
min = 200 / 5 = 40 dano
max = (0.09 * 1.0) * 100 * 37 + 40 = 0.09 * 3700 + 40 = 333 + 40 = 373 dano
Resultado: 40-373 dano
```

**Escalamento:**
- Aumenta linear com level (min)
- Aumenta por distance skill e attack (max)
- Factor multiplica a base (1.0 aqui)

## 🤖 Documentação de Funções

### **onGetFormulaValues(player, skill, attack, factor)**

**Descrição:** Callback custom que calcula dano baseado em stats do player.

**Parâmetros:**
- `player` (Player): Player disparo
- `skill` (number): Distance skill level
- `attack` (number): Attack stat do item
- `factor` (number): Multiplicador base (1.0)

**Lógica:**
1. Pega distance skill efetiva do player
2. Min = level / 5 (base de dano)
3. Max = 0.09 * factor * distanceSkill * attack + level / 5
4. Retorna -min, -max (negativos indicam dano)

**Retorno:**
- `min` (number): Dano mínimo (negativo)
- `max` (number): Dano máximo (negativo)

**Exemplo:**
```lua
-- Player 200/100 skill dispara diamond arrow
-- min = 40, max = 373
-- Dano: 40-373 físico
```

---

### **Combat:setCallback(type, functionName)**

**Descrição:** Define callback para cálculo dinâmico de dano.

**Parâmetro:**
- `CALLBACK_PARAM_SKILLVALUE` = usa distance skill

**Diamond Arrow:**
- Callback = onGetFormulaValues
- Permite dano escalável por skill do player

---

### **Weapon:wieldUnproperly(boolean)**

**Descrição:** Permite usar item abaixo level requirement.

**Valor:** `true`
- Permite uso level < 150
- Provavelmente com penalidade de dano interna
