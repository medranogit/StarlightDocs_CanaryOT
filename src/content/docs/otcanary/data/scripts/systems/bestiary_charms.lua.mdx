## 📄 Visão Geral do Código - Resumo Executivo

O arquivo `bestiary_charms.lua` implementa sistema configurável de 17 charms do bestiary com efeitos ofensivos, defensivos e passivos aplicáveis em combate via probabilidade. É repositório de definições puro - não contém lógica de aplicação, apenas dados estruturados. Os charms variam desde ofensivos (Wound, Enflame, Poison, Freeze, Zap, Curse, Divine Wrath com dano 5% HP) passivos (Low Blow +8% crit, Bless -10% XP loss) e defensivos (Parry reflect, Dodge full dodge, Adrenaline Burst +speed, Numb paralyze, Cleanse immunity, Cripple paralyze enemy). A implementação utiliza tabela simples com campos padrão: name, description, category, type, chance (tripla por nível), points (tripla por nível), efeitos visuais. Padrão de 3 níveis de ativação com custo/benefício escalado.

## 🔧 Estrutura de Funcionalidades

```lua
-- 1. Tabela Global de Charms
local charms = {
    -- Formato por entrada:
    [ID] = {
        name = "Nome do Charm",
        description = "Descrição detalhada do efeito",
        
        -- Categorização
        category = CHARM_MAJOR | CHARM_MINOR,
        type = CHARM_OFFENSIVE | CHARM_DEFENSIVE | CHARM_PASSIVE,
        
        -- Campos ofensivos (se aplicável)
        damageType = COMBAT_PHYSICALDAMAGE | COMBAT_FIREDAMAGE | ...,
        percent = 5, -- % do HP inicial como dano
        messageServerLog = true,
        effect = CONST_ME_HITAREA, -- efeito visual
        
        -- Campos defensivos (se aplicável)
        messageCancel = "Mensagem ao trigger",
        effect = CONST_ME_EXPLOSIONAREA,
        
        -- Campos comuns
        chance = { level1%, level2%, level3% },
        points = { level1_cost, level2_cost, level3_cost },
    },
}

-- 2. Definições de 17 Charms
-- 2.1 Ofensivos: Wound, Enflame, Poison, Freeze, Zap, Curse, Divine Wrath
-- 2.2 Defensivos: Cripple, Parry, Dodge, Adrenaline Burst, Numb, Cleanse
-- 2.3 Passivos: Bless, Scavenge, Gut, Low Blow
```

## 📊 Estrutura de Campos

| Campo | Tipo | Descrição | Exemplos |
|---|---|---|---|
| `name` | string | Nome do charm | "Wound", "Dodge" |
| `description` | string | Descrição longa do efeito | "Triggers on a creature..." |
| `category` | constant | CHARM_MAJOR ou CHARM_MINOR | CHARM_MAJOR (mais caro) |
| `type` | constant | Tipo de charm (role) | CHARM_OFFENSIVE, CHARM_DEFENSIVE, CHARM_PASSIVE |
| `damageType` | constant | Tipo de dano (ofensivos) | COMBAT_PHYSICALDAMAGE, COMBAT_FIREDAMAGE, etc |
| `percent` | number | % do HP inicial como dano | 5 |
| `chance` | table(3) | Chance por nível (%) | `{ 5, 10, 11 }` |
| `points` | table(3) | Custo bestiary por nível | `{ 240, 360, 1200 }` |
| `messageServerLog` | boolean | Log no servidor | true |
| `messageCancel` | string | Mensagem ao trigger | "You parried an attack..." |
| `effect` | constant | Efeito visual | CONST_ME_HITAREA, CONST_ME_POFF |

## 📌 Resumo

**Bestiary Charms** é sistema de configuração puro com 17 charms distintos divididos em 3 tipos: (1) Ofensivos (8 charms causando 5% HP dano + efeito visual), (2) Defensivos (5 charms protegendo/contrapesando ataques com paralyze/dodge/reflect), (3) Passivos (4 charms oferecendo bônus permanentes como +crit, +loot, -XP loss). Cada charm tem 3 níveis de ativação (L1/L2/L3) com custo de bestiary points e chance de trigger escalada. Category CHARM_MAJOR é mais caro que CHARM_MINOR. Charms ofensivos têm danos variados (Physical, Fire, Earth, Ice, Energy, Death, Holy) todos a 5% HP inicial. Defensivos oferecem proteção variada com duração de 10 segundos em combate. Passivos aplicam continuamente sem trigger.

A implementação segue padrão de tabela de configuração puro, diferenciando-se por: (1) 17 charms distintos, (2) tripla de níveis com escalagem de custo/benefício, (3) 8 tipos de dano ofensivo, (4) 6 defensivos únicos, (5) 4 passivos escalados.
