**Descrição:**
Biblioteca que estende construtores de classes nativas do engine com suporte a definição tabular. Permite criar eventos/ações de forma declarativa, passando um table com propriedades e callbacks. Implementa metatable hooks que interceptam chamadas de construtor, processam a definição, aplicam métodos, e opcionalmente registram a entidade. Oferece backwards compatibility com sintaxe de construtor clássico.

## 💡 Tip

<Aside type="tip">
**Propósito de Helper Constructors (Declarative Pattern)**

Sem helper constructors, criar eventos é verboso:

**Sintaxe Clássica (Sem Helpers):**
```lua
local myAction = Action("1000")
function myAction.onUse(player, item, frompos, target, topos)
	player:say("Hello!")
	return true
end
myAction:register()
```

**Sintaxe Declarativa (Com Helpers):**
```lua
Action({
	itemid = 1000,
	onUse = function(player, item, frompos, target, topos)
		player:say("Hello!")
		return true
	end,
	register = true  -- Auto-register
})
```

**Benefícios:**
- Menos linhas de código
- Mais legível
- Menos chance de esquecer :register()
- Validação automática

**Quando Disparado:**
```
Action({ definition })
  ├─ Construtor hook dispara
  ├─ Processa table de definição
  ├─ Aplica cada propriedade/callback
  ├─ Valida se tem callback
  └─ Auto-registra se register=true
```
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `helper_constructors.lua` implementa um **metatable hook system** que:

- **Intercepta construtores** de classes nativas
- **Processa definições tabulares** (table-based definitions)
- **Aplica métodos automaticamente** iterando propriedades
- **Valida callbacks** antes de registrar
- **Mantém compatibilidade** com sintaxe clássica

### Arquitetura

Script usa padrão de **constructor wrapping com metatable enhancement**:

```lua
for _, class in ipairs(classes) do
	local MT = getmetatable(class)
	local DefaultConstructor = MT.__call
	
	MT.__call = function(self, def, ...)
		-- Processa def (pode ser table ou string)
		-- Aplica métodos
		-- Valida callbacks
		-- Registra se necessário
		return obj
	end
end
```

A wrapper de construtor intercepta TODA chamada `Class(...)` e decide entre sintaxe clássica ou declarativa.

### Fluxo Lógico Resumido

| Entrada | Processamento | Saída |
|---------|---------------|-------|
| `Class("id")` | Sintaxe clássica | Objeto criado (sem callback checks) |
| `Class({...})` | Sintaxe declarativa | Objeto com métodos aplicados e registro |

### Função Principal: MT.__call Hook

```lua
MT.__call = function(self, def, ...)
	-- Backwards compatibility for default obj() constructor
	if type(def) ~= "table" then
		return DefaultConstructor(self, def, ...)
	end

	local obj = nil
	if def.init then
		obj = DefaultConstructor(self, unpack(def.init))
	else
		obj = DefaultConstructor(self)
	end

	-- Call each method from definition table with the value as params
	local hasCallback = false

	for methodName, value in pairs(def) do
		-- Strictly check if a correct callback is passed
		if methodName:sub(1, 2) == "on" and type(value) == "function" and rawget(class, methodName) then
			hasCallback = true
		end

		if methodName ~= "register" then
			local method = rawget(self, methodName)
			if method then
				if type(value) == "table" then
					method(obj, unpack(value))
				else
					method(obj, value)
				end
			end
		end
	end

	-- Only register if callback has already been defined, otherwise defining afterwards will not work
	if def.register then
		if not hasCallback then
			logger.warn("[HelperConstructors] - Event not registered due to there being no callback")
		else
			obj:register()
		end
	end

	return obj
end
```

**Propósito:** Wrapper de construtor que processa definições tabulares.

**Fluxo de Execução:**

#### 1. **Validação de Type** (Backwards Compatibility)

```lua
if type(def) ~= "table" then
	return DefaultConstructor(self, def, ...)
end
```

- Se `def` não é table → uso clássico `Action("1000")`
- Delega para construtor original
- Permite código legado sem modificação

#### 2. **Inicialização do Objeto**

```lua
local obj = nil
if def.init then
	obj = DefaultConstructor(self, unpack(def.init))
else
	obj = DefaultConstructor(self)
end
```

- Se table tem propriedade `init` → unpacks array como args para construtor
- Senão → construtor sem argumentos

**Exemplo:**
```lua
Action({
	init = {"1000"},  -- ID do action
	onUse = function(...) end
})
-- Equivalente: Action("1000")

Spell({
	init = {"fireball", "1000"},  -- Name, ID
	getManaCost = 50
})
-- Equivalente: Spell("fireball", "1000")
```

#### 3. **Iteração de Definição**

```lua
for methodName, value in pairs(def) do
	-- Processa cada propriedade/callback
end
```

Para cada key-value na table de definição:

#### 4. **Detecção de Callback**

```lua
if methodName:sub(1, 2) == "on" and type(value) == "function" and rawget(class, methodName) then
	hasCallback = true
end
```

- Verifica se nome começa com `"on"` (padrão de callback)
- Verifica se valor é function
- Verifica se classe tem esse método (`rawget`)
- Se tudo true → marca `hasCallback = true`

**Exemplo:**
```lua
Action({
	onUse = function(...) end,     -- ✓ Detectado como callback
	getName = "Test",              -- ✗ Não é callback (não começa com "on")
	someOtherProperty = 123        -- ✗ Não é callback
})
```

#### 5. **Aplicação de Métodos**

```lua
if methodName ~= "register" then
	local method = rawget(self, methodName)
	if method then
		if type(value) == "table" then
			method(obj, unpack(value))
		else
			method(obj, value)
		end
	end
end
```

Para cada propriedade NÃO-"register":
- Busca método no objeto
- Se método existe:
  - Se value é table → desempacota como args
  - Senão → passa valor direto

**Exemplo:**
```lua
Action({
	itemid = 1000,              -- obj:setItemId(1000)
	actionid = "action_test",   -- obj:setActionId("action_test")
	onUse = function(...) end,  -- obj:setCallback(onUse, ...)
	cooldown = {5, 100}         -- obj:setCooldown(5, 100) [unpacked]
})
```

#### 6. **Registro Condicional**

```lua
if def.register then
	if not hasCallback then
		logger.warn("[HelperConstructors] - Event not registered due to there being no callback")
	else
		obj:register()
	end
end
```

Se `register = true` na definição:
- Se não há callback → Aviso (risk: evento vazio)
- Se há callback → Auto-registra `obj:register()`

**Por quê validar callback?**
- Evento sem callback = inútil
- Provavelmente é erro de digitação
- Melhor avisar que registrar event vazio

## 🎯 Padrões & Boas Práticas

### Padrão 1: Metatable Interception

**Técnica:** Substituir `__call` metatable para interceptar construtores.

```lua
local MT = getmetatable(class)
local DefaultConstructor = MT.__call

MT.__call = function(self, def, ...)
	-- Lógica customizada
	return DefaultConstructor(self, def, ...)  -- Fallback
end
```

**Vantagem:**
- Não modifica classe original
- Backwards compatible (fallback)
- Aplica a múltiplas classes em loop

**Aplicação:** Wrapping de construtores, DSLs.

---

### Padrón 2: Table-Based Declaration

**Técnica:** Aceitar table com propriedades ao invés de chamadas encadeadas.

```lua
-- Antes:
local spell = Spell("fireball")
spell:manaCost(50)
spell:level(30)
spell:register()

-- Depois:
Spell({
	init = {"fireball"},
	manaCost = 50,
	level = 30,
	register = true
})
```

**Vantagem:**
- Menos linhas de código
- Mais legível (DSL style)
- Reduz chance de esquecer :register()

**Aplicação:** DSLs, declarative configs.

---

### Padrón 3: Callback Validation

**Técnica:** Validar que eventos têm callback antes de registrar.

```lua
if methodName:sub(1, 2) == "on" and type(value) == "function" then
	hasCallback = true
end

if def.register and not hasCallback then
	logger.warn("Event has no callback")
	-- Não registra
end
```

**Vantagem:**
- Previne bugs (events vazios)
- Mensagem clara (ajuda debug)
- Evita comportamento surpresa

**Aplicação:** Validação de entidades antes de usar.

---

### Padrön 4: Automatic Method Application

**Técnica:** Iterar definição e aplicar métodos automaticamente.

```lua
for methodName, value in pairs(def) do
	local method = rawget(self, methodName)
	if method then
		if type(value) == "table" then
			method(obj, unpack(value))
		else
			method(obj, value)
		end
	end
end
```

**Vantagem:**
- Genérico: funciona com qualquer propriedade
- Flexível: unpacking de tables when needed
- Limpo: loop centralizado

**Aplicação:** Aplicação bulk de propriedades.
