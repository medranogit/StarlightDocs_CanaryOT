## 💡 Tip

<Aside type="tip">
**Fluxo de Visualização em Shop (Look in Shop)**

Quando um jogador inspeciona um item enquanto abre shop de NPC:

1. **Trigger:** playerOnLookInShop é disparado com itemType e count
2. **Validação:** Callback retorna booleano (true = permitir, false = bloquear)
3. **Ação:** Se true, descrição do item é mostrada; se false, visualização é recusada

**Exemplo Teórico - Implementação Completa:**
```lua
function callback.playerOnLookInShop(player, itemType, count)
    local itemName = itemType:getName()
    
    -- Exemplo: bloquear visualização de itens restritos
    if itemType:hasProperty(ITEM_TYPE_RESTRICTED) then
        if not player:getGroup():getAccess() then
            return false
        end
    end
    
    -- Log visualização (audit trail)
    logger.debug("[Shop] Player " .. player:getName() .. " looked at " .. itemName)
    
    return true  -- Permitir visualização
end
```

**Nota:** Atualmente stub. Usar para auditing ou restrições de itens por grupo.
</Aside>
