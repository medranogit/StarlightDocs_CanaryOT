## 💡 Tip

<Aside type="tip">
**Fluxo de Visualização em Trade (Look in Trade)**

Quando um jogador inspeciona item de outro jogador durante transação:

1. **Trigger:** playerOnLookInTrade é disparado
2. **Processamento:** Obtém descrição do item
3. **Ação:** Envia mensagem de "look" ao jogador

**Exemplo de Flow - Trade entre Jogadores:**
```
Player A abrindo trade com Player B
Player A clica em item de Player B
  ├─ playerOnLookInTrade(Player A, Player B, item, distance)
  ├─ description = item:getDescription(distance)
  └─ Player A recebe: "You see [item description]"
```

**Diferença vs on_look.lua:**
- `on_look.lua` → visualização de itens NO CHÃO ou em criaturas
- `on_look_in_trade.lua` → visualização de itens DURANTE TRADE apenas
</Aside>

### Propósito Principal

O script `on_look_in_trade.lua` implementa o callback de visualização durante transação. Quando um jogador observa um item oferecido por outro jogador:


## 🔧 Estrutura de Funcionalidades

### Função Principal (Callback)

#### **playerOnLookInTrade(player, partner, item, distance)**

```lua
function callback.playerOnLookInTrade(player, partner, item, distance)
	player:sendTextMessage(MESSAGE_LOOK, "You see " .. item:getDescription(distance))
end
```

**Propósito:** Entry point do callback. Envia descrição de item durante transação para jogador.

**Fluxo de Execução:**

1. **Entrada:** Recebe player observador, partner (outro jogador), item e distância
2. **Processamento:** 
   - Obtém descrição base do item via `item:getDescription(distance)`
   - Prependa "You see "
3. **Envio:** Transmite mensagem via MESSAGE_LOOK channel

**Parâmetros:**
- `player` - Player que está visualizando o item
- `partner` - Player oferecendo o item
- `item` - Item object sendo visualizado
- `distance` - Distância da visualização (afeta descrição)

**Sem retorno** - Callback é void (apenas envia mensagem)

## 🎯 Padrões & Boas Práticas

### Padrão 1: Message Dispatch via sendTextMessage

**Técnica:** Usar sendTextMessage com channel específico para comunicação estruturada.

```lua
player:sendTextMessage(MESSAGE_LOOK, "You see " .. item:getDescription(distance))
```

**Vantagem:** Sistema de canais permite filtragem/roteamento client-side. Estruturado.

**Aplicação:** Qualquer comunicação player que necessite categorização.

---

### Padrão 2: Distance-Aware Descriptions

**Técnica:** Passar distância para getDescription(), permitindo variação de detalhe.

```lua
item:getDescription(distance)  -- Descrição pode variar conforme distância
```

**Vantagem:** Realismo. Itens distantes mostram menos detalhe. Suporta lore.

**Aplicação:** Qualquer visualização de objeto que necessite contexto de proximidade.

---

### Padrão 3: Simple Message Concatenation

**Técnica:** Usar concatenação simples para construir mensagem final.

```lua
"You see " .. item:getDescription(distance)  -- Simples, direto, legível
```

**Vantagem:** Direto, sem complexidade desnecessária. Performance ótima.

**Aplicação:** Mensagens simples e estáticas sem condicional.

## ⚙️ Fluxo de Operação

### Cenário 1: Player A visualiza item de Player B durante trade

```

  playerA,
  playerB,
  manaPotion,
  distance=1
```

```
[Look channel] You see a mana potion
```
