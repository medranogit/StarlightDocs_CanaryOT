## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `on_look.lua` implementa o sistema completo de visualização de objetos e criaturas no servidor. Quando um jogador observa algo ("look"), este script:

- **Gera descrições apropriadas** baseadas no tipo (item/criatura)
- **Detecta itens especiais** (barris de poção, kegs) e mostra refillings/charges
- **Integra sistema de familiares** exibindo tempo restante de summon
- **Oculta informações sensíveis** como magic walls para non-admins
- **Injeta dados administrativos** para staff (IDs, atributos, transformações, IP)

### Arquitetura

O script usa **decomposição em funções especializadas**:

```
playerOnLook (entrada)
  ├─ handleItemDescription (para items)
  │  ├─ isSpecialItem (verifica ranges)
  │  └─ getPositionDescription (formata posição)
  ├─ handleCreatureDescription (para criaturas)
  │  └─ getMaster check (familiares)
  └─ appendAdminDetails (se acesso admin)
     ├─ Item details (IDs, atributos, transformações)
     └─ Creature details (Health, Mana, Speed, IP)
```

### Fluxo Lógico Resumido

| Entrada | Processamento | Saída |
|---------|---------------|-------|
| Item especial (cask/keg) | Detecta via range, retorna charges | "You see [desc]\nIt has X refillings left." |
| Criatura normal | getDescription() + name | "You see [desc]" |
| Familiar | Busca master, calcula tempo restante | "You see [name] (Master: X). It will disappear in [tempo]" |
| Não-admin vê magic wall | Substitui descrição | "You see a magic wall." |
| Admin vê item | Injeta Client ID, Action ID, Unique ID, Door ID, Transforms, Decay | "[desc]\nClient ID: 123, Action ID: 456..." |

## 🔧 Estrutura de Funcionalidades

### Funções Locais

#### 1. **isSpecialItem(itemId)**

```lua
local function isSpecialItem(itemId)
	for _, range in ipairs(specialItemRanges) do
		if itemId >= range.rangeStart and itemId <= range.rangeEnd then
			return true
		end
	end
	return false
end
```

**Propósito:** Verifica se um item ID pertence à tabela de ranges especiais (casks e kegs).

**Algoritmo:**
- Itera sobre `specialItemRanges` (health cask, mana cask, spirit cask, keg)
- Se itemId está dentro de qualquer range [start, end], retorna `true`
- Senão retorna `false`

**Complexidade:** O(n) onde n = número de ranges (tipicamente 4)

**Uso:** `if isSpecialItem(inspectedThing.itemid) then`

#### 2. **getPositionDescription(position)**

```lua
local function getPositionDescription(position)
	if position.x == 65535 then
		return "Position: In your inventory."
	else
		return string.format("Position: (%d, %d, %d)", position.x, position.y, position.z)
	end
end
```

**Propósito:** Formata descrição de posição, detectando items em inventário vs coordenadas.

**Lógica:**
- Se `position.x == 65535`, é item em inventário (retorna texto especial)
- Senão, retorna coordenadas (x, y, z)

**Uso:** Chamado em `appendAdminDetails()` para mostrar informações de admin

---

#### 3. **handleItemDescription(inspectedThing, lookDistance, player)**

```lua
local function handleItemDescription(inspectedThing, lookDistance, player)
	local descriptionText = inspectedThing:getDescription(lookDistance)

	if not player:getGroup():getAccess() then
		if inspectedThing:getId() == ITEM_MAGICWALL or inspectedThing:getId() == ITEM_MAGICWALL_SAFE then
			return "You see a magic wall."
		elseif inspectedThing:getId() == ITEM_WILDGROWTH or inspectedThing:getId() == ITEM_WILDGROWTH_SAFE then
			return "You see rush wood."
		end
	end
	if isSpecialItem(inspectedThing.itemid) then
		local itemCharges = inspectedThing:getCharges()
		if itemCharges > 0 then
			return string.format("You see %s\nIt has %d refillings left.", descriptionText, itemCharges)
		end
	else
		return "You see " .. descriptionText
	end

	return descriptionText
end
```

**Propósito:** Gera descrição para items com tratamento de casos especiais.

**Fluxo:**
1. Obtém base description via `getDescription(lookDistance)`
2. **Filtragem de acesso:** Se jogador é não-admin:
   - Magic wall/safe → oculta e retorna "You see a magic wall."
   - Wild growth/safe → oculta e retorna "You see rush wood."
3. **Items especiais:** Se é cask/keg:
   - Se tem charges > 0 → "You see [desc]\nIt has X refillings left."
4. **Items normais:** Senão → "You see [desc]"

**Pattern:** Early return para não-admins, after-text injection para items especiais

---

#### 4. **handleCreatureDescription(inspectedThing, lookDistance)**

```lua
local function handleCreatureDescription(inspectedThing, lookDistance)
	local descriptionText = inspectedThing:getDescription(lookDistance)

	if inspectedThing:isMonster() then
		local monsterMaster = inspectedThing:getMaster()
		if monsterMaster and table.contains(FAMILIARSNAME, inspectedThing:getName():lower()) then
			local summonTimeRemaining = monsterMaster:kv():get("familiar-summon-time") or 0
			descriptionText = string.format("%s (Master: %s). It will disappear in %s", descriptionText, monsterMaster:getName(), Game.getTimeInWords(summonTimeRemaining - os.time()))
		end
	end

	return "You see " .. descriptionText
end
```

**Propósito:** Gera descrição para criaturas com detecção de familiares.

**Fluxo:**
1. Obtém base description
2. Se é monstro E tem master E nome está em FAMILIARSNAME:
   - Recupera `familiar-summon-time` de kv (key-value)
   - Calcula tempo restante: `summonTime - currentTime`
   - Formata: "[desc] (Master: PlayerName). It will disappear in [time]"
3. Prependa "You see " e retorna

**Pattern:** Sistema de familiares com armazenamento assíncrono via kv(), formatação de tempo via `Game.getTimeInWords()`

#### 5. **appendAdminDetails(descriptionText, inspectedThing, inspectedPosition)**

```lua
local function appendAdminDetails(descriptionText, inspectedThing, inspectedPosition)
	if inspectedThing:isItem() then
		descriptionText = string.format("%s\nClient ID: %d", descriptionText, inspectedThing:getId())

		local itemActionId = inspectedThing:getActionId()
		if itemActionId ~= 0 then
			descriptionText = string.format("%s, Action ID: %d", descriptionText, itemActionId)
		end

		local itemUniqueId = inspectedThing:getUniqueId()
		if itemUniqueId > 0 and itemUniqueId < 65536 then
			descriptionText = string.format("%s, Unique ID: %d", descriptionText, itemUniqueId)
		end

		local doorIdAttribute = inspectedThing:getAttribute(ITEM_ATTRIBUTE_DOORID)
		if doorIdAttribute and doorIdAttribute > 0 then
			descriptionText = string.format("%s, Door ID: %d", descriptionText, doorIdAttribute)
		end

		local itemType = inspectedThing:getType()
		local transformOnEquipId = itemType:getTransformEquipId()
		local transformOnDeEquipId = itemType:getTransformDeEquipId()

		if transformOnEquipId ~= 0 then
			descriptionText = string.format("%s\nTransforms to: %d (onEquip)", descriptionText, transformOnEquipId)
		elseif transformOnDeEquipId ~= 0 then
			descriptionText = string.format("%s\nTransforms to: %d (onDeEquip)", descriptionText, transformOnDeEquipId)
		end

		local itemDecayId = itemType:getDecayId()
		if itemDecayId ~= -1 then
			descriptionText = string.format("%s\nDecays to: %d", descriptionText, itemDecayId)
		end
	elseif inspectedThing:isCreature() then
		local healthDescription, creatureId = "%s\n%s\nHealth: %d / %d"
		if inspectedThing:isPlayer() and inspectedThing:getMaxMana() > 0 then
			creatureId = string.format("Player ID: %i", inspectedThing:getGuid())
			healthDescription = string.format("%s, Mana: %d / %d", healthDescription, inspectedThing:getMana(), inspectedThing:getMaxMana())
		elseif inspectedThing:isMonster() then
			creatureId = string.format("Monster ID: %i", inspectedThing:getId())
		elseif inspectedThing:isNpc() then
			creatureId = string.format("NPC ID: %i", inspectedThing:getId())
		end

		descriptionText = string.format(healthDescription, descriptionText, creatureId, inspectedThing:getHealth(), inspectedThing:getMaxHealth())
	end

	descriptionText = string.format("%s\n%s", descriptionText, getPositionDescription(inspectedPosition))

	if inspectedThing:isCreature() then
		local creatureBaseSpeed = inspectedThing:getBaseSpeed()
		local creatureCurrentSpeed = inspectedThing:getSpeed()
		descriptionText = string.format("%s\nSpeed Base: %d\nSpeed: %d", descriptionText, creatureBaseSpeed, creatureCurrentSpeed)

		if inspectedThing:isPlayer() then
			descriptionText = string.format("%s\nIP: %s", descriptionText, Game.convertIpToString(inspectedThing:getIp()))
		end
	end

	return descriptionText
end
```

**Propósito:** Injeta detalhes administrativos na descrição para staff/moderadores.

**Seções:**

**a) Item Details:**
- Client ID (sempre injetado)
- Action ID (se != 0)
- Unique ID (se 0 < uniqueId < 65536)
- Door ID (se atributo != 0)
- Transform onEquip (se != 0)
- Transform onDeEquip (elsif != 0)
- Decay ID (se != -1)

**b) Creature Details:**
- Health XXX / XXX (sempre)
- Creature ID (formato varia por tipo):
  - Player: GUID
  - Monster: ID
  - NPC: ID
- Mana (only para players com maxMana > 0)

**c) Position Info:**
- Chama `getPositionDescription()` para inventory vs coords

**d) Speed Info (criatures only):**
- Base speed
- Current speed

**e) IP Info (players only):**
- IP formatado via `Game.convertIpToString()`

**Pattern:** Conditional building incremental via string.format(), tipo-specific metadata injection

### Função Principal (Callback)

#### **playerOnLook(player, inspectedThing, inspectedPosition, lookDistance)**

```lua
function callback.playerOnLook(player, inspectedThing, inspectedPosition, lookDistance)
	local descriptionText

	if inspectedThing:isItem() then
		descriptionText = handleItemDescription(inspectedThing, lookDistance, player)
	elseif inspectedThing:isCreature() then
		descriptionText = handleCreatureDescription(inspectedThing, lookDistance)
	end

	if player:getGroup():getAccess() then
		descriptionText = appendAdminDetails(descriptionText, inspectedThing, inspectedPosition)
	end

	player:sendTextMessage(MESSAGE_LOOK, descriptionText)
end
```

**Propósito:** Entry point do callback. Orquestra geração de descrição e envio ao cliente.

**Fluxo de Execução:**

1. **Classificação:** Determina tipo (item vs criatura)
   - Se `inspectedThing:isItem()` → `handleItemDescription()`
   - Senão se `inspectedThing:isCreature()` → `handleCreatureDescription()`

2. **Filtragem de Acesso Admin:**
   - Se `player:getGroup():getAccess()` é verdadeiro:
     - Chama `appendAdminDetails()` para injetar metadata

3. **Envio:** Transmite mensagem ao cliente via MESSAGE_LOOK channel

**Parâmetros:**
- `player` - Player object executando a ação
- `inspectedThing` - Item ou Creature objeto sendo observado
- `inspectedPosition` - Position table `{x, y, z}` do objeto
- `lookDistance` - Distância da observação (affects description)

## 🎯 Padrões & Boas Práticas

### Padrão 1: Range-Based Classification (Item Detection)

**Técnica:** Usar table de ranges para classificação baseada em ID ranges.

```lua
local specialItemRanges = {
	{ rangeStart = ITEM_HEALTH_CASK_START, rangeEnd = ITEM_HEALTH_CASK_END },
	-- ...
}

local function isSpecialItem(itemId)
	for _, range in ipairs(specialItemRanges) do
		if itemId >= range.rangeStart and itemId <= range.rangeEnd then
			return true
		end
	end
end
```

**Vantagem:** Fácil adicionar novos ranges sem editar lógica de comparação. Centralizado.

**Aplicação:** Detectar casks, kegs, herbs, runes - qualquer item que usa ranges contíguas de IDs.
