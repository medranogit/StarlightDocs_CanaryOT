# Event Callback Usage Guide

O sistema `EventCallback` é uma forma de vincular dinamicamente funções C++ para serem acionadas por eventos específicos dentro do jogo. É uma forma elegante e flexível de adicionar comportamento customizado em várias partes da aplicação.

---

## 📋 Tipos de Event Callback

Event callbacks estão disponíveis para várias categorias de entidades do jogo, como `Creature`, `Player`, `Party` e `Monster`.

### Anotações de Tipo de Retorno

Cada função é prefixada com `(bool)`, `(void)` ou `(ReturnValue)`. Esta anotação indica o tipo de retorno esperado da função:

- **`(bool)`**: A função deve retornar um valor booleano (`true` ou `false`). O valor de retorno pode afetar o fluxo do programa no lado C++. Por exemplo, se a função retorna `false`, a execução da função associada no lado C++ é imediatamente interrompida.

- **`(void)`**: A função não retorna nenhum valor. Apenas realiza uma ação e depois termina.

- **`(ReturnValue)`**: A função deve retornar um valor enum `ReturnValue`. Qualquer valor diferente de `RETURNVALUE_NOERROR` interrompe a execução de callbacks posteriores.

## 💡 Uso de Event Callbacks

Para usar o sistema `EventCallback`, você primeiro precisa criar uma instância de `EventCallback`, depois definir as funções que deseja acionar em eventos específicos. Uma vez feito, registre seu callback para torná-lo ativo.

Abaixo estão exemplos para cada categoria de entidades do jogo:

### Creature Callback

```lua
local callback = EventCallback("UniqueCallbackName")

function callback.creatureOnAreaCombat(creature, tile, isAggressive)
	-- comportamento customizado quando criatura entra em combate
	return RETURNVALUE_NOERROR
end

callback:register()
```

### Player Callback

```lua
local callback = EventCallback("UniqueCallbackName")

function callback.playerOnLook(player, inspectedThing, inspectedPosition, lookDistance)
	-- comportamento customizado quando jogador observa algo
end

callback:register()
```

### Party Callback

```lua
local callback = EventCallback("UniqueCallbackName")

function callback.partyOnJoin(party, player)
	-- comportamento customizado quando jogador entra em party
end

callback:register()
```

### Monster Callback

```lua
local callback = EventCallback("UniqueCallbackName")

function callback.monsterOnDropLoot(monster, corpse)
	logger.info("Monster {} has corpse {}", monster:getName(), corpse:getName())
end

callback:register()
```

## 🔄 Event Callbacks Booleanos

Alguns event callbacks retornam um valor booleano. O valor de retorno desempenha um papel crucial na determinação do fluxo do programa no lado C++.

Se o callback retorna `false`, a execução da função associada no lado C++ é interrompida imediatamente. Isso permite usar Lua scripting para introduzir condições customizadas para a execução de funções C++.

### Exemplo de Boolean Event Callback

```lua
local callback = EventCallback("UniqueCallbackName")

function callback.playerOnMoveItem(player, item, count, fromPos, toPos, fromCylinder, toCylinder)
	if item:getId() == ITEM_PARCEL then
		-- Comportamento customizado quando jogador move encomenda
		return false
	end
	return true
end

callback:register()
```

<Aside type="tip">
Neste exemplo, quando um jogador move um item, a função verifica se o item é uma encomenda (parcel) e aplica comportamento customizado, retornando `false` para impossibilitar o movimento, interrompendo a função associada no lado C++.
</Aside>

## 📊 Event Callbacks ReturnValue

Alguns event callbacks retornam um valor enum, neste caso, enum `ReturnValue`. Se o retorno for diferente de `RETURNVALUE_NOERROR`, interrompe a execução dos callbacks seguintes.

### Exemplo de ReturnValue Event Callback

```lua
local callback = EventCallback()

function callback.creatureOnAreaCombat(creature, tile, isAggressive)
	-- Se criatura não é agressiva, interrompe execução da função C++
	if not isAggressive then
		return RETURNVALUE_NOTPOSSIBLE
	end

	-- Comportamento customizado quando criatura agressiva entra em combate
	return RETURNVALUE_NOERROR
end

callback:register()
```

<Aside type="tip">
Neste exemplo, quando uma criatura não-agressiva entra em uma área de combate, a função `creatureOnAreaCombat` retorna `RETURNVALUE_NOTPOSSIBLE`, interrompendo a função associada no lado C++.
</Aside>

## 🔗 Múltiplos Callbacks para o Mesmo Evento

Você pode definir múltiplos callbacks para o mesmo tipo de evento. Isso permite encapsular diferentes comportamentos em callbacks separados, tornando seu código mais modular e fácil de gerenciar.

Também permite usar o mesmo callback em diferentes partes de seus scripts Lua. Todos os callbacks registrados para um evento específico são acionados quando esse evento ocorre.

### Exemplo 1: Primeiro Comportamento

```lua
local example1 = EventCallback("UniqueCallbackName1")

function example1.creatureOnAreaCombat(creature, tile, isAggressive)
	-- comportamento customizado 1 quando criatura entra em combate
end

example1:register()
```

### Exemplo 2: Segundo Comportamento

```lua
local example2 = EventCallback("UniqueCallbackName2")

function example2.creatureOnAreaCombat(creature, tile, isAggressive)
	-- comportamento customizado 2 quando criatura entra em combate
end

example2:register()
```

<Aside type="tip">
Quando o evento `creatureOnAreaCombat` ocorre, **ambos** os callbacks serão executados. Isso permite múltiplas camadas de lógica para o mesmo evento, cada uma isolada em seu próprio callback registrado.
</Aside>
