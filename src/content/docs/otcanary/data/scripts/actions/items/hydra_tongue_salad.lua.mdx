## 📄 Visão Geral do Código

**Resumo Executivo**

O script `hydra_tongue_salad.lua` implementa salada curativa temática com remoção multicondicional. Remove 10 tipos de condições ruinosas (poison, fire, energy, paralyze, drunk, drown, freezing, dazzled, cursed, bleeding) via loop simples. Usa cooldown compartilhado special-foods (10 min) com outras special foods. Efeito visual MAGIC_RED, emote "Chomp", mensagem descritiva. Sem validações especiais.

### hydraTongueSalad.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que cura condições.

**Parâmetros:**
- player: Creature player
- item: Salada sendo consumida
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. If hasExhaustion("special-foods-cooldown")
   ├─ "You need to wait before using it again."
   └─ return true

2. For _, conditionType in ipairs(conditionsToRemove)
   └─ player:removeCondition(conditionType)

3. sendTextMessage: "You feel better body condition."

4. player:say("Chomp.", TALKTYPE_MONSTER_SAY)

5. player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)

6. setExhaustion("special-foods-cooldown", 600s)

7. item:remove(1) + return true
```

**Implementação:**

```lua
function hydraTongueSalad.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if player:hasExhaustion("special-foods-cooldown") then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You need to wait before using it again.")
		return true
	end

	for _, conditionType in ipairs(conditionsToRemove) do
		player:removeCondition(conditionType)
	end

	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You feel better body condition.")
	player:say("Chomp.", TALKTYPE_MONSTER_SAY)
	player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)
	player:setExhaustion("special-foods-cooldown", 10 * 60)
	item:remove(1)
	return true
end
```

## Loop de Remoção

```lua
for _, conditionType in ipairs(conditionsToRemove) do
	player:removeCondition(conditionType)
end
```

Itera sobre 10 types e remove cada uma (mesmo se não ativa no player).

**removeCondition behavior**:
- Se condition ativa → remove
- Se condition inativa → ignora (seguro)
