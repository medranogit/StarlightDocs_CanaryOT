## 📄 Visão Geral do Código

**Resumo Executivo**

O script `northern_fishburger.lua` implementa fishburger temático com fishing skill +50 por 1 hora. Condition pré-compilada com SUBID JeanPierreFishing (nome da buff). FORCEUPDATE força aplicação imediata. Cooldown "special-foods-cooldown" (10 min) compartilhado com outras special foods. Emote "Smack.", mensagem "You felt fishing inspiration."

**Estrutura de Funcionalidades**

```
[Pré-compile fishingCondition]
    ├─ CONDITION_ATTRIBUTES type
    ├─ SUBID: JeanPierreFishing (nome buff)
    ├─ BUFF_SPELL: true (efeito positivo)
    ├─ TICKS: 3.600.000ms (1h)
    ├─ SKILL_FISHING: +50
    └─ FORCEUPDATE: true (refresh imediato)

[Create northernFishburger Action]
    ↓
[onUse function]
    ├─ If hasExhaustion("special-foods-cooldown")
    │   └─ "You need to wait before using it again."
    │   └─ return true
    ├─ addCondition(fishingCondition)
    ├─ sendTextMessage: "You felt fishing inspiration."
    ├─ player:say("Smack.", TALKTYPE_MONSTER_SAY)
    ├─ sendMagicEffect(CONST_ME_MAGIC_RED)
    ├─ setExhaustion("special-foods-cooldown", 10min)
    ├─ item:remove(1)
    └─ return true
    ↓
[Register on item ID 9088]
```

## Variáveis Globais

### fishingCondition (local)

```lua
local fishingCondition = Condition(CONDITION_ATTRIBUTES)
fishingCondition:setParameter(CONDITION_PARAM_SUBID, JeanPierreFishing)
fishingCondition:setParameter(CONDITION_PARAM_BUFF_SPELL, 1)
fishingCondition:setParameter(CONDITION_PARAM_TICKS, 60 * 60 * 1000)
fishingCondition:setParameter(CONDITION_PARAM_SKILL_FISHING, 50)
fishingCondition:setParameter(CONDITION_PARAM_FORCEUPDATE, true)
```

Condition pré-compilada para reutilização.

**Parâmetros:**
- SUBID: JeanPierreFishing (nome da buff)
- BUFF_SPELL: 1 (true) efeito positivo
- TICKS: 3.600.000ms (1 hora)
- SKILL_FISHING: 50 (boost significant)
- FORCEUPDATE: true (força recalc imediato)

## Funções

### northernFishburger.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que aplica buff fishing.

**Parâmetros:**
- player: Creature player
- item: Fishburger sendo consumido
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. If hasExhaustion("special-foods-cooldown")
   ├─ "You need to wait before using it again."
   └─ return true

2. addCondition(fishingCondition)
   └─ Fishing +50 por 1h

3. sendTextMessage: "You felt fishing inspiration."

4. player:say("Smack.", TALKTYPE_MONSTER_SAY)

5. player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)

6. setExhaustion("special-foods-cooldown", 600s)
   └─ Cooldown shared 10 min

7. item:remove(1) + return true
```

**Implementação:**

```lua
function northernFishburger.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if player:hasExhaustion("special-foods-cooldown") then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You need to wait before using it again.")
		return true
	end

	player:addCondition(fishingCondition)
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You felt fishing inspiration.")
	player:say("Smack.", TALKTYPE_MONSTER_SAY)
	player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)
	player:setExhaustion("special-foods-cooldown", 10 * 60)
	item:remove(1)
	return true
end
```
