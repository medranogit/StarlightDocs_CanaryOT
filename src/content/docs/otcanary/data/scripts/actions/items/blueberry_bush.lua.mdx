## 📄 Visão Geral do Código

**Resumo Executivo**

O script `blueberry_bush.lua` implementa colheita de arbusto temático. Ao usar arbusto (ID 3699), transforma em estado colhido (ID 3700), coloca decay timer, gera 3x mirtilos (item 3588) na posição e progride achievement Bluebarian. Sem cooldown ou restrições.

**Estrutura Fundamental**

```
[Create blueberryBush Action]
    ↓
[onUse function]
    ├─ item:transform(3700) [colhido]
    ├─ item:decay() [timer decay]
    ├─ Game.createItem(3588, 3, position) [3x mirtilo]
    ├─ addAchievementProgress("Bluebarian", 500)
    └─ return true
    ↓
[Register Action on item ID 3699]
```

## Funções

### blueberryBush.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback acionado ao usar arbusto.

**Parâmetros:**
- player: Creature player
- item: Arbusto sendo colhido
- fromPosition: Posição do arbusto
- target: Target (pode ser nil)
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```
1. item:transform(3700)
   └─ Transforma arbusto em estado colhido

2. item:decay()
   └─ Inicia decay timer (volta ao normal após tempo)

3. Game.createItem(3588, 3, fromPosition)
   ├─ Cria 3x mirtilos (item 3588)
   └─ Na posição original do arbusto

4. player:addAchievementProgress("Bluebarian", 500)
   └─ Progride achievement Bluebarian 500 pontos

5. return true
```

**Implementação:**

```lua
function blueberryBush.onUse(player, item, fromPosition, target, toPosition, isHotkey)
  item:transform(3700)
  item:decay()
  Game.createItem(3588, 3, fromPosition)
  player:addAchievementProgress("Bluebarian", 500)
  return true
end
```

Todos os passos em sequência simples.

## Achievement Integration

### Achievement: Bluebarian

**Chave**: "Bluebarian"  
**Progresso por uso**: 500 pontos  
**Tipo**: Tracking de colheita  
**Efeito**: Progride counter de berries colhidas

**Sistema**:
```lua
player:addAchievementProgress("Bluebarian", 500)
```

Cada colheita vale 500 pontos para achievement temático.

## Decay System

### item:decay()

Inicia timer de decay que restaura arbusto ao estado original (3699).

**Parâmetros**: Usa configuração padrão de decay do item (arquivo items.xml)

**Efeito**: Arbusto colhido volta ao normal automaticamente após tempo.

## Padrão de Harvesting

Este script segue padrão comum em MMOs:

1. **Transform**: Item muda visual (intacto → colhido)
2. **Decay**: Timer natural para regeneração
3. **Rewards**: Itens criados na posição
4. **Tracking**: Achievement progride com cada uso

Aplicável a qualquer colheita (mushrooms, herbs, etc).
