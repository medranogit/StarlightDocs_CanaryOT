## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa sistema de desbloqueamento de 9 tipos de outfits (Soil Guardian, Crystal Warlord, Makeshift Warrior, etc.) com padrão consistente: cada outfit tem 1 item para unlock + 2 items para addons. Valida premium, gênero do jogador, posse de outfit antes de adicionar addons. Suporta múltiplos tipos de feedback (orangeText, whiteText, effect).

### Estrutura de Funcionalidades

```
CONFIG TABLE (9 outfit types × ~2.5 items = 23 items):
  ├─ [Item 1] → Unlock: female/male + effect
  ├─ [Item 2] → Addon 1: female/male + addon + effect
  ├─ [Item 3] → Addon 2: female/male + addon + effect
  ├─ ... (9 tipos total)
  └─ Each outfit: female looktype + male looktype

HANDLER:
  └─ usableOutfitItems.onUse()
      ├─ isPremium()?
      ├─ outfitInfo = config[itemId]
      ├─ looktype = getSex() ? female : male
      ├─ hasOutfit(looktype)?
      │   ├─ NÃO → Unlock path
      │   │   ├─ if addon: erro (precisa outfit primeiro)
      │   │   ├─ addOutfit(female) + addOutfit(male)
      │   │   └─ efeito + feedback + remove
      │   │
      │   └─ SIM → Addon path
      │       ├─ hasOutfit(looktype, addon)?
      │       │   ├─ SIM → já tem addon (erro)
      │       │   ├─ NÃO → Continua
      │       ├─ addOutfitAddon(female, addon)
      │       ├─ addOutfitAddon(male, addon)
      │       ├─ hasOutfit(looktype, 3)? → achievement
      │       └─ efeito + feedback + remove
```

## Fluxo de Operação

### Operação Principal

```lua
function usableOutfitItems.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação: Premium obrigatório
	if not player:isPremium() then
		player:sendCancelMessage(RETURNVALUE_YOUNEEDPREMIUMACCOUNT)
		return true
	end

	-- Obter informação do outfit
	local outfitInfo = outfitConfig[item.itemid]
	
	-- Detectar looktype (female vs male)
	local looktype = player:getSex() == PLAYERSEX_FEMALE and outfitInfo.female or outfitInfo.male

	-- ============= PATH 1: UNLOCK OUTFIT =============
	if not player:hasOutfit(looktype) then
		-- Validação: Não pode adicionar addon sem outfit
		if outfitInfo.addon then
			player:sendCancelMessage("You need the outfit for this part.")
			return true
		end

		-- Unlock both genders
		player:addOutfit(outfitInfo.female)
		player:addOutfit(outfitInfo.male)
		
		-- Efeito
		player:getPosition():sendMagicEffect(outfitInfo.effect or CONST_ME_GIFT_WRAPS)
		
		-- Feedback (orangeText ou whiteText)
		if outfitInfo.orangeText then
			player:say(outfitInfo.orangeText, TALKTYPE_MONSTER_SAY)
		elseif outfitInfo.whiteText then
			player:sendTextMessage(MESSAGE_EVENT_ADVANCE, outfitInfo.whiteText)
		end

		item:remove(1)
		return true
	end

	-- ============= PATH 2: ADDON =============
	-- Validação: Já tem o addon?
	if player:hasOutfit(looktype, outfitInfo.addon) then
		player:sendCancelMessage("You already own this outfit part.")
		return true
	end

	-- Adicionar addon a ambos os gêneros
	player:addOutfitAddon(outfitInfo.female, outfitInfo.addon)
	player:addOutfitAddon(outfitInfo.male, outfitInfo.addon)
	
	-- Efeito
	player:getPosition():sendMagicEffect(outfitInfo.effect or CONST_ME_GIFT_WRAPS)
	
	-- Feedback
	if outfitInfo.orangeText then
		player:say(outfitInfo.orangeText, TALKTYPE_MONSTER_SAY)
	elseif outfitInfo.whiteText then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, outfitInfo.whiteText)
	end

	-- Achievement quando tem ambos os addons (addon 3 = completo)
	if player:hasOutfit(looktype, 3) then
		player:addAchievement(outfitInfo.achievement)
	end

	item:remove(1)
	return true
end

-- Registrar todos os IDs
for itemId, _ in pairs(outfitConfig) do
	usableOutfitItems:id(itemId)
end

usableOutfitItems:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Premium Mandatory**: isPremium() no início
- **Gender Detection**: getSex() para looktype selection
- **Outfit vs Addon**: hasOutfit sem addon = unlock, com addon = addon check
- **Double Unlock**: addOutfit(female) + addOutfit(male) sempre
- **Double Addon**: addOutfitAddon(female, addon) + addOutfitAddon(male, addon)
- **Feedback Types**: orangeText (audível) ou whiteText (mensagem)
- **Achievement Complete**: hasOutfit(looktype, 3) = ambos addons
- **Block Addon First**: Se não tem outfit, não pode ter addon
- **Cancel Message**: sendCancelMessage() para validações

### Responsabilidades do Handler

1. **Validar premium**: isPremium()
2. **Obter config**: outfitConfig[itemId]
3. **Detectar gênero**: getSex() → looktype
4. **Verificar outfit**: hasOutfit(looktype)
5. **Se não tem outfit**:
   - Validar não é addon
   - Adicionar ambas (female + male)
   - Efeito + feedback
   - Consumir
6. **Se tem outfit (addon path)**:
   - Verificar não tem addon
   - Adicionar addon (female + male)
   - Efeito + feedback
   - Achievement se completo (addon 3)
   - Consumir
