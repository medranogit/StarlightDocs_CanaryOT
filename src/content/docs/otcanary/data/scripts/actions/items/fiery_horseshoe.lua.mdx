## 📄 Visão Geral do Código

**Resumo Executivo**

O script `fiery_horseshoe.lua` implementa sistema de crafting de mount com acúmulo de 4 ferradura. Usa config table para permitir fácil extensão a múltiplos itens/mounts. Players que já tem o mount (184) são rejeitados. Rastreia progresso com kv "fiery-horseshoe". Ao atingir 4 ferradura, desbloqueia mount e achievement.

**Estrutura de Funcionalidades**

```
[Define config table]
    ├─ requiredItems: {36938} (1 tipo de ferradura)
    │   └─ key: "fiery-horseshoe"
    │   └─ count: 4 (necessário)
    └─ mountId: 184

[Create fieryHorseshoe Action]
    ↓
[onUse function]
    ├─ Get itemInfo = config.requiredItems[item:getId()]
    ├─ If not found? return true
    ├─ If already has mount? return true
    ├─ currentCount = kv:get(key) or 0 + 1
    ├─ kv:set(key, currentCount)
    ├─ sendMagicEffect(FIREATTACK)
    ├─ item:remove(1)
    ├─ Loop requiredItems
    │   ├─ For each: check if count < required
    │   └─ If any missing? return true
    ├─ player:addMount(mountId)
    ├─ player:addAchievement("Hot on the Trail")
    ├─ sendTextMessage: "Singeing Steed is now yours!"
    └─ return true
```

## Funções

### fieryHorseshoe.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que processa ferradura.

**Parâmetros:**
- player: Creature player
- item: Ferradura sendo usada
- fromPosition: Posição do uso
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. itemInfo = config.requiredItems[item:getId()]
   ├─ Não existe? return true
   └─ Existe? continuar

2. If player:hasMount(config.mountId)
   └─ return true (já tem mount)

3. currentCount = (kv:get(key) or 0) + 1
   └─ Incrementa contador

4. kv:set(key, currentCount)
   └─ Salva novo contador

5. sendMagicEffect(FIREATTACK)
   └─ Efeito visual fogo

6. item:remove(1)
   └─ Consome ferradura

7. For _, info in pairs(config.requiredItems)
   ├─ If (kv:get(key) or 0) < required
   │   └─ return true (ainda faltam)
   └─ If algum check falha
       └─ return true

8. player:addMount(mountId)
   ├─ addAchievement("Hot on the Trail")
   ├─ sendTextMessage: "Singeing Steed is now yours!"
   └─ return true
```

**Implementação:**

```lua
function fieryHorseshoe.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local itemInfo = config.requiredItems[item:getId()]
	if not itemInfo then
		return true
	end

	if player:hasMount(config.mountId) then
		return true
	end

	local currentCount = (player:kv():get(itemInfo.key) or 0) + 1
	player:kv():set(itemInfo.key, currentCount)
	player:getPosition():sendMagicEffect(CONST_ME_FIREATTACK)
	item:remove(1)

	for _, info in pairs(config.requiredItems) do
		if (player:kv():get(info.key) or 0) < info.count then
			return true
		end
	end

	player:addMount(config.mountId)
	player:addAchievement("Hot on the Trail")
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Singeing Steed is now yours!")
	return true
end
```

## Arquitetura Extensível

**Config-driven Approach**:

Atual: 1 ferradura (36938) → 1 mount (184)

**Pode estender para**:
```lua

	[36938] = { key = "fiery-horseshoe", count = 4 },
	[OTHER_ID] = { key = "other-key", count = 3 },
}
```

Permite múltiplas rotas de crafting mount.
