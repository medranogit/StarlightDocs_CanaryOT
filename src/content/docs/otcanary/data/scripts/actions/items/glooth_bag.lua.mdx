## 📄 Visão Geral do Código

**Resumo Executivo**

O script `glooth_bag.lua` implementa bolsa de loot ponderada com 10 items glooth possíveis. Usa sistema de ranges de chance (0-10000) para distribuição desigual - items com count menor (spear: 1875) são mais fáceis, control unit raro (1978). Quantidade pode ser fixa (1) ou array [min, max] para randomização. Efeito HITBYPOISON ao abrir.

**Estrutura de Funcionalidades**

```
[Define config com 10 items]
    ├─ Ranges: 0-10000
    ├─ Items: weapons (spear, club, axe, blade)
    ├─ Items: armor (amulet, backpack)
    ├─ Items: consumibles (sandwich, soup, steak)
    └─ Items: special (control unit - raro)

[Create gloothBag Action]
    ↓
[onUse function]
    ├─ chance = random(0, 10000)
    ├─ For i = 1, #config
    │   ├─ randomItem = config[i]
    │   ├─ If chance in range
    │   │   ├─ gift = itemId

    │   │   ├─ item:remove(1)
```

## Funções

### gloothBag.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que abre bolsa.

**Parâmetros:**
- player: Creature player
- item: Bolsa sendo aberta
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. chance = random(0, 10000)

2. For i = 1, #config
   ├─ randomItem = config[i]
   ├─ If chance >= chanceFrom AND chance <= chanceTo
   │   ├─ gift = randomItem.itemId
   │   ├─ count = randomItem.count or 1
   │   ├─ If type(count) == "table"
   │   │   └─ count = random(count[1], count[2])
   │   ├─ player:addItem(gift, count)
   │   ├─ item:getPosition():sendMagicEffect(HITBYPOISON)
   │   ├─ item:remove(1)
   │   └─ return true

3. return false (sem match - raro demais)
```

**Implementação:**

```lua
function gloothBag.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local chance = math.random(0, 10000)
	for i = 1, #config do
		local randomItem = config[i]
		if chance >= randomItem.chanceFrom and chance <= randomItem.chanceTo then
			if randomItem.itemId then
				local gift = randomItem.itemId
				local count = randomItem.count or 1
				if type(count) == "table" then
					count = math.random(count[1], count[2])
				end

				player:addItem(gift, count)
			end

			item:getPosition():sendMagicEffect(CONST_ME_HITBYPOISON)
			item:remove(1)
			return true
		end
	end
	return false
end
```

**Sistema 0-10000**:
