## 📄 Visão Geral do Código

**Resumo Executivo**

O script `decay_to.lua` é o maior handler de decorações do jogo, mapeando 500+ pares de transformações bidirecionais. Lâmpadas, estátuas, móveis alternam entre estados (on/off, cores, versões). Alguns itens emitem voice lines ("Au au!", "Grooaarr!"). Ao usar, transforma item em par mapeado, inicia decay timer para regeneração automática, permitindo decoradores criar ciclos e animações visuais.

**Estrutura de Funcionalidades**

```
[Define voices table: 2 entries]
    ├─ 23708 → "Au au!"
    └─ 23443 → "Grooaarr!"

[Define transformItems table: 500+ entries]
    ├─ Pares bidirecionais
    ├─ Exemplo: 2062 ↔ 2063 (sacred statue)
    ├─ Exemplo: 27667 → 27668 → 27669 → 27670 → 27667 (cycles)
    └─ Rotulados com comments

[Create decayTo Action]
    ↓
[onUse function]
    ├─ itemId = item:getId()
    ├─ If voices[itemId]
    │   ├─ Get spectators na área
    │   └─ For each: spectator:say(voice)
    ├─ newItemId = transformItems[itemId]
    ├─ If newItemId
    │   ├─ item:transform(newItemId)
    │   └─ item:decay()
    └─ return true

[Register via loop: for all transformItems keys]
```

### transformItems (local table - massivo)

```lua
local transformItems = {
	[2062] = 2063,
	[2063] = 2062, -- sacred statue
	[2064] = 2065,
	[2065] = 2064, -- sacred statue
	-- ... 500+ mais entries
}
```

Mapeamento de item ID para seu par transformado.

**Estrutura:**
- Índice: Item ID original
- Valor: Item ID after transformation

**Padrões:**
- Bidirecional: A → B, B → A (on/off)
- Cíclico: A → B → C → D → A (4 estados)
- Unidirecional: Alguns só vão em uma direção

**Categorias:**
- Lâmpadas (street lamps, wall lamps: 50+ pairs)
- Chamas (candles, torches, candlesticks: 30+ pairs)
- Móveis (tables, ovens: 20+ pairs)
- Estátuas (carvings, busts: 50+ pairs)
- Tema (Christmas, Kraken, Dragon, etc: 200+ pairs)

## Funções

### decayTo.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que transforma item com decay automático.

**Parâmetros:**
- player: Creature player
- item: Decoração sendo transformada
- fromPosition: Posição do uso
- target: Target (pode ser nil, não usado)
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo de Execução:**

```lua
1. itemId = item:getId()

2. If voices[itemId] then
   ├─ Get spectators no mapa
   └─ For each: spectator:say(voices[itemId], TALKTYPE_MONSTER_SAY)

3. newItemId = transformItems[itemId]

4. If newItemId then
   ├─ item:transform(newItemId)
   └─ item:decay()

5. return true
```

**Implementação:**

```lua
function decayTo.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local itemId = item:getId()
	if voices[itemId] then
		local spectators = Game.getSpectators(fromPosition, false, true, 3, 3)
		for _, spectator in ipairs(spectators) do
			player:say(voices[itemId], TALKTYPE_MONSTER_SAY, false, spectator, fromPosition)
		end
	end

	local newItemId = transformItems[itemId]
	if newItemId then
		item:transform(newItemId)
		item:decay()
	end
	return true
end
```

## Decay System

### item:decay()

Inicia timer de decay que automaticamente regenera item de volta para ID original.

**Duração**: Configurada em items.xml per-item (típico 10-30 minutos)

**Efeito**: Permite decoradores criar ciclos on/off automáticos ou cores alternadas.

### Exemplos de Padrões

#### Bidirecional (toggle)

```
2062 (off) ↔ 2063 (on) ↔ 2062 (off) ↔ ...
```

Alterna entre two states infinitamente.

#### Cíclico 4 states

```
27667 → 27668 → 27669 → 27670 → 27667 → ...
(light of change: empty → red → green → blue → empty)
```

Ciclo de 4 cores contínuo.
