## 📄 Visão Geral do Código

**Resumo Executivo**

O script `foods.lua` é extenso mapeamento de 60+ tipos de alimentos base do servidor. Cada alimento tem dois atributos: nível de saciedade (1-605) multiplicado por 12, e emote único (Gulp, Crunch, Munch, Yum, etc.). Ao usar, valida se player está "full" checando duração REGENERATION condition. Se não bloqueado, aplica saciedade via player:feed(), emite emote, sound effect e consome item.

**Estrutura de Funcionalidades**

```
[Define foods table com 60+ itens]
    ├─ [3606] = { 6, "Gulp." } (egg)
    ├─ [3250] = { 5, "Crunch." } (carrot)
    ├─ [3577] = { 15, "Munch." } (meat)
    ├─ [3600] = { 10, "Crunch." } (bread)
    ├─ [3583] = { 60, "Chomp." } (dragon ham)
    ├─ [48256] = { 605, "Yum." } (pastry dragon - maior)
    └─ ... mais 54 itens com ranges variados (1-605)

[Create food Action]
    ↓
[onUse function]
    ├─ itemFood = foods[item.itemid]
    ├─ Not found? return false
    ├─ condition = player:getCondition(REGENERATION)
    ├─ If condition and time >= 1200s
    │   └─ "You are full." (return)
    ├─ player:feed(itemFood[1] * 12)
    ├─ player:say(itemFood[2])
    ├─ player:updateSupplyTracker(item)

[Register all items via loop]
```

## Funções

### food.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que consome alimento.

**Parâmetros:**
- player: Creature player
- item: Alimento sendo consumido
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. itemFood = foods[item.itemid]
   ├─ Não existe? return false
   └─ Existe? continuar

2. condition = player:getCondition(CONDITION_REGENERATION, CONDITIONID_DEFAULT)

3. If condition and (ticks/1000 + saciedade*12) >= 1200
   ├─ "You are full."
   └─ return true

4. player:feed(itemFood[1] * 12)
   └─ Aplica saciedade com multiplicador

5. player:say(itemFood[2], TALKTYPE_MONSTER_SAY)

6. player:updateSupplyTracker(item)

7. player:getPosition():sendSingleSoundEffect(EAT)

8. item:remove(1) + return true
```

**Implementação:**

```lua
function food.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local itemFood = foods[item.itemid]
	if not itemFood then
		return false
	end

	local condition = player:getCondition(CONDITION_REGENERATION, CONDITIONID_DEFAULT)
	if condition and math.floor(condition:getTicks() / 1000 + (itemFood[1] * 12)) >= 1200 then
		player:sendTextMessage(MESSAGE_FAILURE, "You are full.")
		return true
	end

	player:feed(itemFood[1] * 12)
	player:say(itemFood[2], TALKTYPE_MONSTER_SAY)
	player:updateSupplyTracker(item)
	player:getPosition():sendSingleSoundEffect(SOUND_EFFECT_TYPE_ACTION_EAT, player:isInGhostMode() and nil or player)
	item:remove(1)
	return true
end
```

## Validação de "Full"

```lua
if condition and math.floor(condition:getTicks() / 1000 + (itemFood[1] * 12)) >= 1200 then
```

Bloqueia uso se:
- Player tem condition de REGENERATION E
- Duração restante + novo alimento >= 1200 segundos (20 min)

Exemplo:
- Player tem 600s de saciedade
- Tenta comer +100s item
- Total = 700s (< 1200) → OK
- Tenta comer +700s item
- Total = 1300s (>= 1200) → "You are full."
