## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa um item consumível que converte coins diretos em coins transferáveis na conta. O sistema lê a quantidade do item e adiciona ao balance de coins transferáveis. Inclui logging de auditoria para rastrear uso do item, efeito visual verde e mensagem customizada com total atualizado.

### Estrutura de Funcionalidades

```
storeCoin (Action)
  ├─ onUse(player, item, fromPosition, target, toPosition, isHotkey)
  │   ├─ Obter quantidade: item:getCount()
  │   ├─ Adicionar coins: addTransferableCoins(count)
  │   ├─ Mensagem com feedback: total atualizado
  │   ├─ Efeito visual: MAGIC_GREEN
  │   ├─ Remover item: item:remove()
  │   ├─ Logger warning com nome do jogador
  │   └─ return true
  └─ register() → ID ITEM_STORE_COIN
```

## Fluxo de Operação

### Operação Principal

```lua
function storeCoin.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Obter quantidade do item
	local count = item:getCount()
	
	-- Adicionar coins transferáveis
	player:addTransferableCoins(count)
	
	-- Mensagem com total atualizado
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
	  "You have added " .. count .. " tibia coins to your balance. Your total is now " .. 
	  player:getTransferableCoins() .. ".")
	
	-- Efeito visual
	player:getPosition():sendMagicEffect(CONST_ME_MAGIC_GREEN)
	
	-- Consumir item
	item:remove()

	-- Log de auditoria
	logger.warn("[StoreCoinScript - ITEM_STORE_COIN] The player {} used the item to store Tibia Coins.", 
	  player:getName())
	
	return true
end
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **getCount()**: Retorna quantidade de items empilhados
- **addTransferableCoins()**: Adiciona coins à conta (transferáveis entre chars)
- **getTransferableCoins()**: Obtém total atual para mensagem
- **item:remove()**: Remove item SEM parâmetro (remove tudo)
- **Logger Warn**: Auditoria de conversão para segurança
- **MAGIC_GREEN Effect**: Indica sucesso de operação
- **String Concatenation**: Mensagem dinâmica com valores
- **Always True**: Operação nunca falha

### Responsabilidades do Handler

1. **Obter quantidade**: item:getCount()
2. **Adicionar coins**: addTransferableCoins()
3. **Carregar novo total**: getTransferableCoins()
4. **Enviar feedback**: Mensagem customizada
5. **Efeito visual**: MAGIC_GREEN
6. **Consumir item**: item:remove()
7. **Auditar**: logger.warn() com nome do jogador
8. **Confirmar**: return true
