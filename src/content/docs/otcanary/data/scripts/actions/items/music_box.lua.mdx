## 📄 Visão Geral do Código

**Resumo Executivo**

O script `music_box.lua` implementa caixa de música para domação de 9 mobs diferentes. Cada mob tem config: mount ID, achievement temático, mensagem tame customizada, som do mob. Validações: target deve ser creature/monster, sem master (wild), mount não duplicado. Ao sucesso: add mount, achievements (global + temático), mensagem e som player, som mob, remove mob.

## Funções

### musicBox.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que doma mob.

**Parâmetros:**
- player: Creature player (domador)
- item: Caixa sendo usada
- fromPosition: Posição original
- target: Mob alvo
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. Validações
   ├─ if not target:isCreature() or not target:isMonster() or target:getMaster()
   │   └─ return false
   ├─ monsterConfig = config[target:getName():lower()]
   ├─ if not monsterConfig
   │   └─ return false
   ├─ if player:hasMount(mountId)
   │   └─ return false
   └─ continuar

2. Domação
   ├─ player:addMount(monsterConfig.mountId)
   ├─ player:addAchievement("Natural Born Cowboy")
   ├─ player:addAchievement(monsterConfig.achievement)
   ├─ player:say(monsterConfig.tameMessage, TALKTYPE_MONSTER_SAY)
   ├─ toPosition:sendMagicEffect(CONST_ME_SOUND_RED)
   ├─ target:say(monsterConfig.sound, TALKTYPE_MONSTER_SAY)
   ├─ target:remove()
   ├─ item:remove(1)
   └─ return true
```

**Implementação:**

```lua
function musicBox.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if not target:isCreature() or not target:isMonster() or target:getMaster() then
		return false
	end

	local monsterConfig = config[target:getName():lower()]
	if not monsterConfig then
		return false
	end

	if player:hasMount(monsterConfig.mountId) then
		return false
	end

	player:addMount(monsterConfig.mountId)
	player:addAchievement("Natural Born Cowboy")
	player:addAchievement(monsterConfig.achievement)
	player:say(monsterConfig.tameMessage, TALKTYPE_MONSTER_SAY)
	toPosition:sendMagicEffect(CONST_ME_SOUND_RED)

	target:say(monsterConfig.sound, TALKTYPE_MONSTER_SAY)
	target:remove()

	item:remove(1)
	return true
end
```

## Validações Sequenciais

### 1. Target é creature/monster wild

```lua
if not target:isCreature() or not target:isMonster() or target:getMaster() then
	return false
end
```

Target deve ser:
- Creature (yes)
- Monster (yes)
- Sem master (wild, não tamed)

### 2. Config encontrado

```lua
local monsterConfig = config[target:getName():lower()]
if not monsterConfig then
	return false
end
```

Nome do mob (case-insensitive) deve estar em config.

### 3. Mount não duplicado

```lua
if player:hasMount(monsterConfig.mountId) then
	return false
end
```

Player não pode ter mount duplicado.
