## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa sistema completo de remoção de ferrugem em equipamentos danificados. Possui 9 tipos de itens corrosivos (3 armaduras, 3 calças, 1 escudo, 2 capacetes) com múltiplos níveis de oxidação (heavily, rusted, slightly). Cada tipo tem tabela de probabilidades com 4-7 items possíveis de ser restaurados. Usa RNG baseado em range de 10000 para determinar resultado. Mensagens customizadas por categoria de item.

### Estrutura de Funcionalidades

```
CONFIG TABLE (9 tipos × 3-7 resultados):
  ├─ 8894-8896 → Armaduras (3 níveis)
  ├─ 8897-8899 → Calças (3 níveis)
  ├─ 8902 → Escudo (1 nível)
  └─ 8907-8908 → Capacetes (2 níveis)

HANDLER:
  └─ rustRemover.onUse()
      ├─ Validação: target em config?
      ├─ RNG: math.random(10000)
      ├─ Busca: match chance >= randomChance
      ├─ Resultado: item restaurado OR mensagem falha
      └─ Mensagens customizadas por tipo
```

## Fluxo de Operação

### Operação Principal

```lua
function rustRemover.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Carrega config para o target
	local targetItem = config[target.itemid]
	if not targetItem then
		return true  -- Item não é um tipo conhecido
	end

	-- Gera número aleatório de 1-10000
	local randomChance = math.random(10000)
	local index = false

	-- Busca primeira opção que passa no chance
	if targetItem[1].chance >= randomChance then
		while not index do
			local randomIndex = math.random(#targetItem)
			if targetItem[randomIndex].chance >= randomChance then
				index = randomIndex
			end
		end
	end

	-- Se nenhuma opção passou: falha
	if not index then
		local msg = nil
		if table.contains({ 8894, 8895, 8896 }, target.itemid) then
			msg = "The armor was already damaged so badly that it broke when you tried to clean it."
		elseif table.contains({ 8897, 8898, 8899 }, target.itemid) then
			msg = "The legs were already damaged so badly that they broke when you tried to clean them."
		elseif table.contains({ 8902 }, target.itemid) then
			msg = "The shield was already damaged so badly that it broke when you tried to clean it."
		elseif table.contains({ 8907, 8908 }, target.itemid) then
			msg = "The helmet was already damaged so badly that it broke when you tried to clean it."
		end
		-- Script continua... (mensagem enviada + item removido)
	end
end
```

### Árvore de Decisão

```
Jogador usa rust_remover perto de item oxidado
  │
  ├─ target.itemid em config?
  │   └─ NÃO → return true (item desconhecido)
  │
  ├─ SIM → Carrega config
  │
  ├─ Gera RNG: random(1-10000)
  │
  ├─ Busca match:
  │   ├─ Loop enquanto index == false
  │   ├─ randomIndex = random(1, #items)
  │   ├─ targetItem[randomIndex].chance >= randomChance?
  │   │   └─ SIM → index = randomIndex (encontrou)
  │   └─ Repetir até encontrar OR timeout
  │
  ├─ index encontrado?
  │   │
  │   ├─ SIM → Sucesso
  │   │   ├─ Item restaurado para ID possível
  │   │   └─ Remover ferrugem
  │   │
  │   └─ NÃO → Falha
  │       ├─ Mensagem por tipo (armor/legs/shield/helmet)
  │       └─ Item quebrado (removido)
  │
  └─ return true
```

### Sistema de Probabilidade

```
RNG Range: 1-10000 (10.000 possibilidades)
Chance: valor absoluto na table

Exemplo (8895 - Rusted Armor):
  ├─ Item 1 (scale): chance = 6437 → Pass se random <= 6437 (64.37%)
  ├─ Item 2 (chain): chance = 4606 → Pass se random <= 4606 (46.06%)
  ├─ Item 3 (brass): chance = 3029 → Pass se random <= 3029 (30.29%)
  ├─ Item 4 (plate): chance = 1559 → Pass se random <= 1559 (15.59%)
  ├─ Item 5 (knight): chance = 595 → Pass se random <= 595 (5.95%)
  ├─ Item 6 (paladin): chance = 283 → Pass se random <= 283 (2.83%)
  └─ Item 7 (crown): chance = 49 → Pass se random <= 49 (0.49%)

Se random > maior chance (10000): Failure (item breaks)
```

### Algoritmo de Seleção

```lua
-- Procura linear até encontrar match
if targetItem[1].chance >= randomChance then  -- Primeira verificação otimizada
	while not index do
		local randomIndex = math.random(#targetItem)
		if targetItem[randomIndex].chance >= randomChance then
			index = randomIndex  -- Encontrou, quebra loop
		end
	end
end
```

Este loop é eficiente porque maioria dos items tem alta chance, encontra rápido.

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Config Table Hierárquica**: item ID → array de possíveis resultados
- **Chance System**: Valores absolutos (0-10000) para probability hits
- **RNG Matching**: Encontra primeiro item que passa no threshold
- **Linear Search**: Loop `while not index` com random selection
- **Categoria Grouping**: table.contains() para agrupar tipos similares
- **Mensagens Customizadas**: Diferentes textos para armor/legs/shield/helmet
- **Fail Condition**: Nenhum item passou no chance (item queimou)
- **10000 Range**: Padrão de probabilidade em steps de 0.01%

### Responsabilidades do Handler

1. **Validar alvo**: Verificar se target está em config
2. **Gerar RNG**: random(10000) para base de comparação
3. **Buscar match**: Loop até encontrar item que passa chance
4. **Aplicar resultado**: Se encontrado, restaurar item específico
5. **Mensagem customizada**: Por tipo de item (armor/legs/shield/helmet)
6. **Remover ferrugem**: Transformar item oxidado em versão limpa
7. **Falha articulada**: Mensagem clara quando item quebra
