## 📄 Visão Geral do Código

**Resumo Executivo**

O script `dolls.lua` é extenso mapeamento de 16 bonecas temáticas cada com pool único de 1-10 frases. Ao usar, seleciona frase aleatória do pool, substitui placeholder |PLAYERNAME| por nome real do jogador, e emite via say monster. Algunas bonecas (5668, 9144, 12904, 14764, 21435, 22120) transformam em estado alternado (decay). Boneca 6566 tem lógica de efeitos especiais por frase.

**Estrutura de Funcionalidades**

```
[Define dollsTable com 16 bonecas]
    ├─ 5080: 1 frase (Hug me!)
    ├─ 5668: 10 frases comuns (com transform)
    ├─ 6566: 5 frases especiais (com efeitos)
    ├─ 6387: 1 frase natal (com placeholder)
    ├─ 6511: 6 frases papai noel (com transform)
    ├─ 8146: 1 frase épica
    ├─ 8149: 5 frases pirata
    ├─ 8153: 4 frases newsreader
    ├─ 8154: 3 frases glacial
    ├─ 9144: 4 frases viking (com transform)
    ├─ 12043: 3 frases imperador
    ├─ 12904: 4 frases troll (com transform)
    ├─ 14764: 2 frases poderoso (com transform)
    ├─ 18343: 3 frases bibliotecário
    ├─ 21435: 6 frases sombria (com transform)
    └─ 22120: 2+ frases ranger (com transform)
    ↓
[Create dolls Action]
    ↓
[onUse function]
    ├─ Get sounds por item ID
    ├─ Not found? return false

    ├─ sound:gsub("|PLAYERNAME|", player:getName())
    ├─ player:say(sound, TALKTYPE_MONSTER_SAY)
    └─ return true
```

## Funções

### dolls.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que emite frase aleatória.

**Parâmetros:**
- player: Creature player
- item: Boneca sendo usada
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. sounds = dollsTable[item.itemid]
   ├─ Não existe? return false
   └─ Existe? continuar

2. If fromPosition in container
   └─ fromPosition = player:getPosition()

3. chance = random(1, #sounds)

4. sound = sounds[chance]

5. Switch por item.itemid
   ├─ 5668: transform + MAGIC_RED + decay
   ├─ 6387: efeito SOUND_YELLOW
   ├─ 6566: 3 efeitos especiais (POFF, FIRE, EXPLOSION)
   ├─ 9144, 12904, 14764, 21435, 22120:
   │   └─ transform + decay
   └─ Others: say apenas

6. sound:gsub("|PLAYERNAME|", player:getName())
   └─ Substitui placeholder

7. player:say(sound, TALKTYPE_MONSTER_SAY)

8. return true
```

**Implementação:**

```lua
function dolls.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local sounds = dollsTable[item.itemid]
	if not sounds then
		return false
	end

	if fromPosition.x == CONTAINER_POSITION then
		fromPosition = player:getPosition()
	end

	local chance = math.random(#sounds)
	local sound = sounds[chance]
	
	-- Lógica de transformações e efeitos por ID
	if item.itemid == 5668 then
		fromPosition:sendMagicEffect(CONST_ME_MAGIC_RED)
		item:transform(item.itemid + 1)
		item:decay()
	elseif item.itemid == 6387 then
		fromPosition:sendMagicEffect(CONST_ME_SOUND_YELLOW)
	-- ... mais branches ...
	end

	sound = sound:gsub("|PLAYERNAME|", player:getName())
	player:say(sound, TALKTYPE_MONSTER_SAY, false, 0, fromPosition)
	return true
end
```

## Placeholder Substitution

```lua
sound = sound:gsub("|PLAYERNAME|", player:getName())
```

String.gsub substitui |PLAYERNAME| em qualquer frase que o contenha.

**Exemplos**:
- "Hail |PLAYERNAME|!" → "Hail PlayerName!"
- "Merry Christmas |PLAYERNAME|." → "Merry Christmas PlayerName."
