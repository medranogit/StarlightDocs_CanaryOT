## 📄 Visão Geral do Código

**Resumo Executivo**

O script `die.lua` implementa jogo de dados funcional que gera valor aleatório 1-6, emite efeito visual e frase pública comunicando resultado. Rastreia sequência de seis usando key-value "die-rolled-six". Ao atingir 3 seis consecutivos, desbloquia achievement "Number of the Beast". Qualquer outro resultado reseta contador.

**Estrutura de Funcionalidades**

```
[Create die Action]
    ↓
[onUse function]
    ├─ position = item:getPosition()
    ├─ value = random(1, 6)
    ├─ isInGhostMode = player:isInGhostMode()
    ├─ If not ghost
    │   ├─ sendMagicEffect(CRAPS)
    │   ├─ Get spectators
    │   └─ For each: player:say("rolled X")
    ├─ If value == 6
    │   ├─ Get rolledSixCount from kv
    │   ├─ Increment count
    │   ├─ Set in kv
    │   ├─ If count == 2 (terceiro seis)
    │   │   └─ addAchievement("Number of the Beast")
    │   └─ Else
    │       └─ kv:remove("die-rolled-six")
    ├─ item:transform(5791 + value)
    └─ return true
    ↓
[Register IDs 5792-5797 via loop]
```

## Funções

### die.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que executa rolagem de dado.

**Parâmetros:**
- player: Creature player
- item: Dado sendo rolado
- fromPosition: Posição do uso
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. position = item:getPosition()

2. value = random(1, 6)
   └─ Valor 1-6 equiprobável

3. isInGhostMode = player:isInGhostMode()

4. If not isInGhostMode
   ├─ sendMagicEffect(CONST_ME_CRAPS)
   ├─ spectators = Game.getSpectators(3x3)
   └─ For each spectator
       └─ say("NAME rolled a X.")

5. If value == 6 then
   ├─ Get counter (default 0)
   ├─ Increment counter
   ├─ If counter == 2 (meaning 3 sixes)
   │   └─ addAchievement("Number of the Beast")
   └─ Else
       └─ Remove "die-rolled-six" from kv

6. item:transform(5791 + value)
   └─ Muda visual (5792-5797 para 1-6)

7. return true
```

**Implementação:**

```lua
function die.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local position = item:getPosition()
	local value = math.random(1, 6)
	local isInGhostMode = player:isInGhostMode()

	if not isInGhostMode then
		position:sendMagicEffect(CONST_ME_CRAPS)

		local spectators = Game.getSpectators(position, false, true, 3, 3)
		for _, spectator in ipairs(spectators) do
			player:say(player:getName() .. " rolled a " .. value .. ".", TALKTYPE_MONSTER_SAY, isInGhostMode, spectator, position)
		end
	end

	if value == 6 then
		local rolledSixCount = player:kv():get("die-rolled-six") or 0
		player:kv():set("die-rolled-six", rolledSixCount + 1)

		if rolledSixCount == 2 then
			player:addAchievement("Number of the Beast")
		end
	else
		player:kv():remove("die-rolled-six")
	end

	item:transform(5791 + value)
	return true
end
```

## Achievement: Number of the Beast

**Desbloqueio**: 3 seis consecutivos (contador == 2)

**Nota Técnica**: Counter começa em 0, então:
- Primeiro 6: counter = 1
- Segundo 6: counter = 2  
- Terceiro 6: counter == 2 check, depois increment para 3

## Ghost Mode

Ao estar em ghost mode:
- Efeito visual não é emitido
- Mensagem não é transmitted (isInGhostMode=true)
- Contador de seis AINDA funciona (não condicionado)
