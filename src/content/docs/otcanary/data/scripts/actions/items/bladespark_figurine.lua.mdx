## 📄 Visão Geral do Código

**Resumo Executivo**

O script `bladespark_figurine.lua` implementa sistema de invocação de familiar temático para bruxos. Valida vocação (sorcerer), nível mínimo (200) com bypass premium, verifica familiar existente e adiciona se ausente. Inclui efeito de mensagem e consumo do item.

**Estrutura Fundamental**

```
[Create bladesparkFigurine Action]
    ↓
[onUse function]
    ├─ Validate vocation (sorcerer only)
    ├─ Validate level 200 or premium
    ├─ Check existing familiar
    ├─ Set familiar looktype if not set
    ├─ Add familiar if not exists
    ├─ Send appropriate message
    ├─ Remove item
    └─ return true
    ↓
[Register Action on item ID 35592]
```

## Variáveis Globais

### VOCATION.BASE_ID.SORCERER (global constant)

Constante que especifica ID base da vocação bruxo. Usado para validação de vocação.

## Funções

### bladesparkFigurine.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback acionado ao usar figurina.

**Parâmetros:**
- player: Creature player
- item: Figurina sendo usada
- fromPosition: Posição do uso
- target: Target (pode ser nil)
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```
1. Validate vocation
   ├─ Not sorcerer? → "Only sorcerers..." + return true
   └─ Is sorcerer → next

2. Validate level or premium
   ├─ Level < 200 AND not premium? → return true (silent)
   └─ Level >= 200 OR premium → next

3. Set familiar looktype if not set
   ├─ getFamiliarLooktype() == 0?
   │   └─ setFamiliarLooktype(1367)
   └─ Already set → next

4. Check and add familiar
   ├─ Not has familiar 1367?
   │   ├─ addFamiliar(1367)
   │   └─ "You have summoned a Bladespark."
   └─ Already has familiar?
       └─ "You already have a Bladespark."

5. Remove item + return true
```

**Bloco 1: Vocação**

```lua
if player:getVocation():getBaseId() ~= VOCATION.BASE_ID.SORCERER then
  player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Only sorcerers can use this item.")
  return true
end
```

Valida se player é bruxo (sorcerer).

**Bloco 2: Nível/Premium**

```lua
if player:getLevel() < 200 and not player:isPremium() then
  return true
end
```

Permite uso se nível >= 200 ou se é premium (bypass nível).

**Bloco 3: Set Familar Looktype**

```lua
if player:getFamiliarLooktype() == 0 then
  player:setFamiliarLooktype(1367)
end
```

Define looktype Bladespark se ainda não definido.

**Bloco 4: Add Familiar**

```lua
if not player:hasFamiliar(1367) then
  player:addFamiliar(1367)
  player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You have summoned a Bladespark.")
else
  player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You already have a Bladespark.")
end
```

Adiciona familiar se não existe, caso contrário informa já tem.

**Bloco 5: Cleanup**

```lua
item:remove(1)
return true
```

Remove figurina após uso.
