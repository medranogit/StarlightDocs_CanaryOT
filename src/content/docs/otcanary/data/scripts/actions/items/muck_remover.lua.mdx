## 📄 Visão Geral do Código

**Resumo Executivo**

O script `muck_remover.lua` implementa removedor de lama com loot aleatório ponderado. Alvo específico: lama ID 16102. Ranges de chance 1-9999 distribuem 9 items diferentes. Items variam: quantidade fixa (1) ou múltipla (5, 10). Container check: addItem (container full) fallback em inventory. Achievement "Goo Goo Dancer" +100 progress ao remover.

### muckRemover.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que remove lama.

**Parâmetros:**

- item: Removedor sendo usado
- fromPosition: Posição original
- target: Lama alvo
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. if target.itemid ~= 16102 (lama)
   └─ return false

2. chance = random(9999)

3. for i = 1, #config
   ├─ randomItem = config[i]
   ├─ if chance in range [from, to]
   │   ├─ if toPosition.x == CONTAINER_POSITION
   │   │   └─ player:addItem(itemId, count)
   │   └─ else
   │       └─ Game.createItem(itemId, count, toPosition)
   │   ├─ addAchievementProgress("Goo Goo Dancer", 100)
   │   ├─ target:getPosition():sendMagicEffect(GREEN_RINGS)
   │   ├─ target:remove(1)
   │   ├─ item:remove(1)
   │   └─ break
   └─ continue

4. return true
```

**Implementação:**

```lua
function muckRemover.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if target.itemid ~= 16102 then
		return false
	end

	local chance, randomItem = math.random(9999)
	for i = 1, #config do
		randomItem = config[i]
		if chance >= randomItem.from and chance <= randomItem.to then
			if toPosition.x == CONTAINER_POSITION then
				player:addItem(randomItem.itemId, randomItem.count or 1)
			else
				Game.createItem(randomItem.itemId, randomItem.count or 1, toPosition)
			end

			player:addAchievementProgress("Goo Goo Dancer", 100)
			target:getPosition():sendMagicEffect(CONST_ME_GREEN_RINGS)
			target:remove(1)
			item:remove(1)
			break
		end
	end
	return true
end
```

## Container Handling

**Container Placement** (toPosition.x == CONTAINER_POSITION):
```lua
player:addItem(itemId, count)
```
Adiciona ao inventory do player.

**Ground Placement**:
```lua
Game.createItem(itemId, count, toPosition)
```
Cria item no chão.
