## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa sistema de 5 scrolls para Wheel of Destiny progression. Cada scroll requer level 51+ e oferece 3-20 pontos conforme tipo (abridged a advanced). Usa wheelUnlockScroll() pré-compilada do servidor para unlock. Valida se jogador já decifraram o mesmo scroll (prevent duplicate). Sem cooldown, sem achievement, apenas progression points.

### Estrutura de Funcionalidades

```
PROMOTION SCROLLS (5 tipos):
  ├─ 43946 (Abridged) → 3 pontos
  ├─ 43947 (Basic) → 5 pontos
  ├─ 43948 (Revised) → 9 pontos
  ├─ 43949 (Extended) → 13 pontos
  └─ 43950 (Advanced) → 20 pontos

HANDLER:
  └─ scroll.onUse()
      ├─ getLevel() < 51?
      │   └─ SIM → Bloqueado (message)
      ├─ scrollData = promotionScrolls[item.getId()]
      ├─ wheelUnlockScroll(scrollData.name)?
      │   ├─ NÃO (já decifraram) → Message
      │   ├─ SIM → Continua
      ├─ Message: "gained X points"
      ├─ item:remove(1)
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local promotionScrolls = {
	[43946] = { name = "abridged", points = 3, itemName = "abridged promotion scroll" },
	[43947] = { name = "basic", points = 5, itemName = "basic promotion scroll" },
	[43948] = { name = "revised", points = 9, itemName = "revised promotion scroll" },
	[43949] = { name = "extended", points = 13, itemName = "extended promotion scroll" },
	[43950] = { name = "advanced", points = 20, itemName = "advanced promotion scroll" },
}

local scroll = Action()

function scroll.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação: Level 51+
	if player:getLevel() < 51 then
		player:sendTextMessage(MESSAGE_LOOK, "Only a hero of level 51 or above can decipher this scroll.")
		return true
	end

	-- Obter informação do scroll
	local scrollData = promotionScrolls[item:getId()]
	
	-- Validação: Já decifraram?
	if not player:wheelUnlockScroll(scrollData.name) then
		player:sendTextMessage(MESSAGE_LOOK, "You have already deciphered this scroll.")
		return true
	end

	-- Sucesso: ganhou pontos
	player:sendTextMessage(MESSAGE_LOOK, "You have gained " .. scrollData.points .. " promotion points for the Wheel of Destiny by deciphering the " .. scrollData.itemName .. ".")
	
	-- Consumir scroll
	item:remove(1)
	return true
end

-- Registrar todos os IDs
for id in pairs(promotionScrolls) do
	scroll:id(id)
end

scroll:register()
```

### Wheel Unlock Function

```
wheelUnlockScroll(scrollData.name) é pré-compilada no servidor:
  ├─ Retorna true se unlock bem-sucedido (primeira vez)
  ├─ Retorna false se já foi decifrante (lógica de prevenção)
  └─ Internamente: atualiza wheel progression + points

Nomes para wheelUnlockScroll:
  ├─ "abridged" (3 points)
  ├─ "basic" (5 points)
  ├─ "revised" (9 points)
  ├─ "extended" (13 points)
  └─ "advanced" (20 points)
```

### Progression Example

```
Player nivel 50: Tenta usar abridged scroll
  └─ getLevel() < 51? SIM
  └─ Message: "Only a hero of level 51..."
  └─ return true (sem consumir)

Player nivel 51 com 0 points: Usa abridged scroll
  ├─ getLevel() < 51? NÃO
  ├─ wheelUnlockScroll("abridged") = true (primeira vez)
  ├─ Message: "gained 3 points"
  ├─ Wheel progression: +3 points
  ├─ item:remove(1)
  └─ return true

Player nivel 51 tenta abridged novamente:
  ├─ getLevel() < 51? NÃO
  ├─ wheelUnlockScroll("abridged") = false (já decifrante)
  ├─ Message: "already deciphered"
  ├─ Item NÃO consumido
  └─ return true
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Level Gate**: getLevel() < 51 obrigatório
- **wheelUnlockScroll()**: Pré-compilada unlock function
- **Return Pattern**: false = já decifrante, true = sucesso
- **Points Scalation**: 3 até 20 conforme tipo
- **Duplicate Prevention**: wheelUnlockScroll retorna false se repetido
- **No Achievement**: Sem sistema de achievement
- **MESSAGE_LOOK**: Tipo de mensagem para scroll/look
- **String Concatenation**: Mensagem dinâmica com pontos

### Responsabilidades do Handler

1. **Validar level**: getLevel() < 51
2. **Rejeitar nível baixo**: Message + return true (sem consumir)
3. **Obter scroll data**: promotionScrolls[itemId]
4. **Unlock wheel**: wheelUnlockScroll(name)
5. **Verificar resultado**: false = já decifrante
6. **Rejeitar duplicado**: Message + return true (sem consumir)
7. **Success message**: "gained X points"
8. **Consumir**: item:remove(1)
9. **Confirmar**: return true

## Patterns e Implementação

### Padrão Level Gate

Validação de level:

```lua
if player:getLevel() < 51 then
	player:sendTextMessage(MESSAGE_LOOK, "Only a hero of level 51 or above...")
```

### Padrão wheelUnlockScroll

Unlock com prevenção de duplicado:

```lua
if not player:wheelUnlockScroll(scrollData.name) then
```
