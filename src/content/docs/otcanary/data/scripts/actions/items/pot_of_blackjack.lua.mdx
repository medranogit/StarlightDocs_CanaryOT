## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa um pote de blackjack que funciona como consumível multi-uso armazenando o número de goles remanescentes em KV storage. Cada ativação consola 5000 HP e decrementa o contador. Utiliza cooldown compartilhado "special-foods-cooldown" (10 min) com outras comidas especiais.

### Estrutura de Funcionalidades

```
potOfBlackjack (Action)
  ├─ onUse(player, item, fromPosition, target, toPosition, isHotkey)
  │   ├─ hasExhaustion("special-foods-cooldown") → validação cooldown
  │   ├─ kv(:get("pot-of-blackjack") → carrega goles
  │   │   └─ Se novo: random(2, 4) goles
  │   ├─ Decrementa remainingGulps
  │   ├─ Mensagem condicional por goles
  │   ├─ addHealth(5000)
  │   ├─ Emote + Effect + Cooldown
  │   └─ item:remove(1)
  └─ register() → ID 11586
```

## Fluxo de Operação

### Operação Principal

```lua
function potOfBlackjack.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Valida cooldown compartilhado
	if player:hasExhaustion("special-foods-cooldown") then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You need to wait before using it again.")
		return true
	end

	-- Carrega goles remanescentes (ou inicializa com 2-4)
	local remainingGulps = player:kv():get("pot-of-blackjack") or math.random(2, 4)

	-- Decrementa goles
	if remainingGulps > 0 then
		remainingGulps = remainingGulps - 1
		player:kv():set("pot-of-blackjack", remainingGulps)

		-- Mensagem condicional
		local message
		if remainingGulps > 0 then
			message = "You take a gulp from the large bowl, but there's still some blackjack in it."
		else
			message = "You take the last gulp from the large bowl. No leftovers!"
		end
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, message)
	end

	-- Aplicar healing e feedback
	player:addHealth(5000)
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You take a gulp from the large bowl.")
	player:say("Gulp.", TALKTYPE_MONSTER_SAY)
	player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)
	player:setExhaustion("special-foods-cooldown", 10 * 60)
	item:remove(1)
	return true
end
```

### Árvore de Decisão

```
Jogador ativa pot_of_blackjack (11586)
  │
  ├─ hasExhaustion("special-foods-cooldown")?
  │   ├─ SIM → Cancelled: "You need to wait..."
  │   │       return true (não remove item)
  │   │
  │   └─ NÃO → Continua...

  │   │       Salva novo valor em KV
  │   │       Envia mensagem condicional

  │

  ├─ Emote: "Gulp."
  ├─ Effect: MAGIC_RED
  ├─ Cooldown: setExhaustion(10 min)

```

### Sistema de Goles

```
Primeira ativação:
  └─ Random(2, 4) → N goles totais

Segunda ativação (cooldown expirado):
  ├─ Carregar N de KV
  ├─ Decrement → N-1
  ├─ Salvar N-1
  └─ Se N-1 > 0: mensagem "still some left"
     Se N-1 == 0: mensagem "last gulp"

Terceira/Nésima ativação:
  └─ Repetir processo até item remover-se
```

```
== 0 (último) | "You take the last gulp from the large bowl. No leftovers!"
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **KV Storage**: `player:kv():get(key)` e `player:kv():set(key, value)` para persistência local
- **Cooldown Compartilhado**: Múltiplos items usam "special-foods-cooldown" (10 min)
- **RNG Inicial**: `math.random(2, 4)` determina goles no primeiro uso
- **Decremento**: Cada uso reduz goles em 1
- **Mensagem Condicional**: Diferentes textos baseado em remainingGulps
- **Healing Fixo**: 5000 HP por gole sempre
- **Esgotamento Duplo**: Valida cooldown antes de consumir item
- **Return True Sem Consumir**: Se cooldown ativo, retorna true SEM remover item

### Responsabilidades do Handler

1. **Validar cooldown**: Verificar "special-foods-cooldown" antes de permitir
2. **Gerenciar estado**: Carregar goles de KV ou inicializar com random
3. **Decrementar uso**: Subtrair 1 de remainingGulps a cada ato
4. **Persistir estado**: Salvar novo valor de goles em KV
5. **Mensagens dinâmicas**: Adaptar texto conforme goles remanescentes
6. **Aplicar healing**: 5000 HP fixos por uso
7. **Ativar cooldown**: setExhaustion de 10 min
8. **Consumir item**: Remover 1 unidade do pote

```lua

player:kv():set("pot-of-blackjack", remainingGulps)
```
