## 📄 Visão Geral do Código

**Resumo Executivo**

O script `blueberry_cupcake.lua` implementa poção temática de mana sem efeitos visuais, apenas com emote de satisfação. Diferencia-se do blessed_steak por possuir exhaustion key própria (blueberry-cupcake-cooldown) em vez de compartilhada. Estrutura idêntica ao blessed_steak adaptada para temática de mirtilo.

**Estrutura de Funcionalidades**

```
[Create blueberryCupcake Action]
    ↓
[onUse function]
    ├─ Check exhaustion: blueberry-cupcake-cooldown
    │   ├─ SIM → "You need to wait..." + return true
    │   └─ NÃO → continuar
    ├─ addMana(getMaxMana())
    ├─ sendTextMessage: "Your mana has been refilled."
    ├─ player:say("Mmmm.", TALKTYPE_MONSTER_SAY)
    ├─ setExhaustion: 10 minutos
    ├─ Remove item
    └─ return true
    ↓
[Register Action on item ID 28484]
```

## Funções

### blueberryCupcake.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback acionado ao consumir cupcake.

**Parâmetros:**
- player: Creature player
- item: Cupcake sendo consumido
- fromPosition: Posição do uso
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se acionado por hotkey

**Fluxo de Execução:**

```lua
1. hasExhaustion("blueberry-cupcake-cooldown")?
   ├─ SIM → enviar mensagem de espera
   └─ NÃO → prosseguir
   
2. addMana(getMaxMana())
   └─ Restaura mana máxima
   
3. sendTextMessage: "Your mana has been refilled."
   
4. player:say("Mmmm.", TALKTYPE_MONSTER_SAY)
   
5. setExhaustion em 10 minutos (600s)
   
6. item:remove(1) + return true
```

**Implementação Completa:**

```lua
function blueberryCupcake.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if player:hasExhaustion("blueberry-cupcake-cooldown") then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You need to wait before using it again.")
		return true
	end

	player:addMana(player:getMaxMana())
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Your mana has been refilled.")
	player:say("Mmmm.", TALKTYPE_MONSTER_SAY)
	player:setExhaustion("blueberry-cupcake-cooldown", 10 * 60)
	item:remove(1)
	return true
end
```
