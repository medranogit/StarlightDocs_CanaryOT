## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa um sistema de reward bags que contém 3 tipos de bolsas temáticas: Soul items (21), Ethereal/Spiritthorn (15), e Sanguine (16). Ao usar uma bolsa, um item aleatório é selecionado de sua lista, adicionado ao jogador, e notificado via webhook + broadcast para outros jogadores. Cada bolsa contém items de alto nível decorados tematicamente.

### Estrutura de Funcionalidades

```
REWARD BAGS CONFIG:
  ├─ BAG_YOU_DESIRE (21 items)
  │   └─ soulcutter, soulshredder, soulbiter, ... (soul-themed)
  │
  ├─ PRIMAL_BAG (15 items)
  │   └─ spiritthorn armor, alicorn, arcanomancer, ... (ethereal/primal)
  │
  └─ BAG_YOU_COVET (16 items)
      └─ sanguine blade, sanguine cudgel, ... (sanguine-themed)

HANDLER:
  └─ randomItems.onUse()
      ├─ Math.random(1, #bag)
      ├─ player:addItem(rewardItem.id)
      ├─ Message ao jogador
      ├─ Webhook.sendMessage()
      ├─ Broadcast() a outros
      └─ item:remove(1)
```

## Fluxo de Operação

### Operação Principal

```lua
function randomItems.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Carrega bag configurada para esse item
	local rewardBag = rewardBags[item.itemid]
	if not rewardBag then
		return false  -- Item não é uma bag conhecida
	end

	-- Seleciona índice aleatório
	local randomIndex = math.random(1, #rewardBag)
	local rewardItem = rewardBag[randomIndex]
	
	-- Adiciona item ao jogador
	player:addItem(rewardItem.id, 1)
	
	-- Mensagem privada ao jogador
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You received a " .. rewardItem.name .. ".")

	-- Notificação via Webhook discord
	Webhook.sendMessage(":game_die: " .. player:getMarkdownLink() .. " received a **" .. 
	  rewardItem.name .. "** from a _" .. item:getName() .. "_.")
	
	-- Broadcast a todos EXCETO o jogador
	local text = player:getName() .. " received a " .. rewardItem.name .. " from a " .. item:getName() .. "."
	Broadcast(text, function(targetPlayer)
		return targetPlayer ~= player  -- Filtro: todos menos o jogador
	end)

	-- Consome a bag
	item:remove(1)
	return true
end

-- Register: percorre todos os IDs de bags
for itemId, info in pairs(rewardBags) do
	randomItems:id(tonumber(itemId))
end
randomItems:register()
```

### Árvore de Decisão

```
Jogador ativa reward bag (BAG_ID)
  │
  ├─ Bag configurada em rewardBags?
  │   └─ NÃO → return false (item inválido)
  │
  ├─ SIM → Seleciona aleatório:
  │   ├─ random(1, #bag) → indice aleatório
  │   └─ rewardBag[indice] → item selecionado
  │
  ├─ Adiciona item:
  │   └─ player:addItem(rewardItem.id, 1)
  │
  ├─ Notifica jogador:
  │   ├─ MSG privada: "You received a..."
  │   ├─ Webhook: Discord notification
  │   └─ Broadcast: Mensagem pública (menos o jogador)
  │
  ├─ Consome bag:
  │   └─ item:remove(1)
  │
  └─ return true (sucesso)
```

### Seleção Aleatória

```
Probabilidade para BAG_YOU_DESIRE (21 items):
  └─ Cada item: 1/21 (~4.76% chance)

Exemplo: Math.random(1, 21)
  ├─ Result 1 → rewardBag[1] = soulcutter
  ├─ Result 2 → rewardBag[2] = soulshredder
  ├─ Result 21 → rewardBag[21] = soulgarb
  └─ Todos equiprováveis
```

### Notificações Multiplos Canais

```
1° Canal: Mensagem Direta ao Jogador
   └─ MESSAGE_EVENT_ADVANCE: "You received a soulcutter."

2° Canal: Webhook Discord
   └─ ":game_die: [Player Name] received a **soulcutter** from a _bag_"

3° Canal: Broadcast In-Game
   └─ "Player Name received a soulcutter from a bag"
   └─ Enviado para todos EXCEPT o jogador
      (evita duplicação de mensagem)
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Master Table Config**: Múltiplas bags em única table structure
- **Random Selection**: `math.random(1, #rewardBag)` para equiprobabilidade
- **addItem() Pattern**: Adiciona items ao player inventory
- **Webhook Integration**: Notificação automática em Discord
- **Broadcast com Filter**: `Broadcast(text, filterFunction)` para filtrar destinatários
- **Função Anonymous**: `function(targetPlayer) return ... end` como filter
- **Dynamic Registration**: Loop `pairs()` para registrar todos os bags
- **tonumber()**: Converte ID para número (pode ser string em table)

### Responsabilidades do Handler

1. **Validar bag**: Verificar se item ID existe em rewardBags
2. **Selecionar aleatório**: math.random(1, #bag) para índice
3. **Buscar item**: rewardBag[randomIndex]
4. **Adicionar inventory**: player:addItem(id, 1)
5. **Notificar privado**: Mensagem para jogador
6. **Notificar webhook**: Enviar a Discord
7. **Broadcast público**: Mensagem a outros jogadores (com filtro)
8. **Consumir bag**: item:remove(1)
9. **Registrar todas**: Loop para registrar todos os bags

## Patterns e Implementação

### Padrão Config Table com Nomes

Este script armazena não apenas IDs, mas também nomes legíveis:

```lua
{ id = 34082, name = "soulcutter" },
```

Isso permite usar `rewardItem.name` em mensagens sem lookup separado.

### Padrão Dynamic Registration

Loop que registra todos os bags sem hardcoding:

```lua
for itemId, info in pairs(rewardBags) do
	randomItems:id(tonumber(itemId))
end
randomItems:register()
```

Adicionar nova bag à table registra automaticamente.
