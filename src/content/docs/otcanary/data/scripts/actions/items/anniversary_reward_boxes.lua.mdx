## 📄 Visão Geral do Código

**Resumo Executivo**

O script `anniversary_reward_boxes.lua` implementa sistema de recompensas em caixas para o evento de aniversário. Cada caixa possui configuração independente com 8-13 itens diferentes. Ao usar caixa, todos os itens são adicionados ao player com efeito mágico prismatic spark. Inclui: small reward box, standard reward box, balloon collection box, e big reward box premium.

**Estrutura Fundamental**

```
[Load config table]
    ↓
[4 box types defined]
    ├── Small reward box (8 items)
    ├── Reward box (13 items)
    ├── Box full of balloons (10 numbered balloons)
    └── Big reward box (13+ items)
    ↓
[Create rewardBox Action]
    ↓
[onUse function]
    ├─ Validate box exists in config
    ├─ Loop all items in reward array
    ├─ player:addItem() each reward
    ├─ sendMagicEffect() per item
    └─ Remove used box
    ↓
[Register Action on 4 box IDs]
```

## Funções

### rewardBox.onUse(player, item, fromPosition, itemEx, toPosition)

Callback principal acionado ao usar caixa.

**Parâmetros:**
- player: Creature player
- item: Caixa sendo usada
- fromPosition: Posição do uso
- itemEx: Alvo (pode ser nil)
- toPosition: Posição destino

**Fluxo:**

```
1. Lookup box em config[item:getId()]
   ├─ Não existe? → return false
   └─ Existe → box array

2. Loop cada reward em box array
   ├─ player:addItem(reward.id, reward.count)
   ├─ player:getPosition():sendMagicEffect(CONST_ME_PRISMATIC_SPARK)
   └─ Próximo item

3. item:remove() (delete caixa usada)

4. return true
```

**Bloco 1: Lookup**

```lua
local box = config[item:getId()]
if not box then
  return false
end
```

Valida caixa existe na configuração.

**Bloco 2: Distribute Rewards**

```lua
for _, reward in ipairs(box) do
  player:addItem(reward.id, reward.count)
  player:getPosition():sendMagicEffect(CONST_ME_PRISMATIC_SPARK)
end
```

Adiciona todos os itens com efeito mágico.

**Bloco 3: Cleanup**

```lua
item:remove()
return true
```

Remove caixa após distribuir rewards.

## Efeitos e Mensagens

| Elemento | Descrição |
|----------|-----------|
| CONST_ME_PRISMATIC_SPARK | Efeito mágico ao receber cada item (prisma) |
| Sem mensagem | Sem confirmação textual (apenas visual) |

## Fluxo de Operação

```
[Player usa caixa de recompensa]
    ↓
[Caixa existe em config?]
    ├─ NÃO → return false (silently)
    └─ SIM → próximo
    ↓
[Loop reward array]
    ├─ addItem(id, count) ×N
    ├─ sendMagicEffect() ×N
    └─ Próximo item
    ↓
[item:remove()]
    ↓
[Caixa desaparece, items adicionados ao inventário]
```

## Checkpoint de Aprendizagem

**Conceitos-chave:**
1. Configuração separada por box ID com arrays de rewards
2. Distribuição em massa de múltiplos itens (8-13 por caixa)
3. Efeito mágico visual para cada item adicionado
4. Sem validações (sem nível, sem quest, sem house)
5. Caixa é consumida após uso

**Responsabilidades:**
1. Manter config table com todos os box types
2. Validar caixa existe antes de distribuir
3. Iterar e adicionar todos os rewards
4. Emitir efeito mágico prismatic spark
5. Remover caixa após distribuição completa
