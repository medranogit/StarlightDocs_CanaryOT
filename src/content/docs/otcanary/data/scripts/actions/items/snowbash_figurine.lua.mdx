## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa figurinha que desbloqueia o familiar Snowbash, exclusivo para Cavaleiros. Implementa validações idênticas ao Sandscourge: vocação (KNIGHT), nível (200+) OU premium, e verificação de duplication. Usa setFamiliarLooktype() + addFamiliar() para ativar o familiar. Padrão class-exclusive replicado para diferente vocação.

### Estrutura de Funcionalidades

```
snowbashFigurine (Action)
  ├─ Validação 1: vocação == KNIGHT?
  │   └─ NÃO → reject
  │
  ├─ Validação 2: level 200+ OR premium?
  │   └─ NÃO → reject (silencioso)
  │
  ├─ Validação 3: looktype ainda não definido?
  │   └─ Sim → setFamiliarLooktype(1365)
  │
  ├─ Validação 4: não tem familiar 1365?
  │   ├─ SIM → addFamiliar(1365) + mensagem
  │   └─ NÃO → mensagem "already have"
  │
  ├─ Consumir: item:remove(1)
  └─ register() → ID 35589
```

## Fluxo de Operação

### Operação Principal

```lua
function snowbashFigurine.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação 1: Vocação obrigatória
	if player:getVocation():getBaseId() ~= VOCATION.BASE_ID.KNIGHT then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Only knights can use this item.")
		return true  -- Item NÃO removido
	end
	
	-- Validação 2: Level 200+ OU Premium
	if player:getLevel() < 200 and not player:isPremium() then
		return true  -- Rejeição silenciosa
	end
	
	-- Validação 3: Definir looktype se não está definido
	if player:getFamiliarLooktype() == 0 then
		player:setFamiliarLooktype(1365) -- Snowbash looktype
	end
	
	-- Validação 4: Adicionar familiar ou avisar se já tem
	if not player:hasFamiliar(1365) then
		player:addFamiliar(1365) -- Snowbash looktype
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You have summoned a Snowbash.")
	else
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You already have a Snowbash.")
	end
	
	-- Consumir item sempre
	item:remove(1)
	return true
end
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Class-Exclusive Knight**: Validação de `getVocation():getBaseId() == KNIGHT`
- **Level OR Premium**: Lógica `<200 AND NOT premium` para gate
- **Silent Rejection**: Return true sem mensagem para rejeições silenciosas
- **getFamiliarLooktype()**: Retorna 0 se nenhum looktype está definido
- **setFamiliarLooktype()**: Define visual antes de adicionar
- **hasFamiliar()**: Verifica duplication por ID específico
- **addFamiliar()**: Adiciona novo familiar com looktype pré-definido
- **Replicação Padrão**: Código idêntico ao Sandscourge, apenas vocação/looktype/mensagens diferentes

### Responsabilidades do Handler

1. **Validar vocação**: getVocation():getBaseId() == KNIGHT
2. **Rejeitar se inválido**: Mensagem clara "Only knights..."
3. **Validar nível/premium**: 200+ OU isPremium()
4. **Rejeitar se insuficiente**: Silenciosamente (sem mensagem)
5. **Definir looktype**: setFamiliarLooktype(1365)
6. **Verificar duplication**: hasFamiliar(1365)
7. **Adicionar ou avisar**: addFamiliar(1365) ou mensagem de duplicação
8. **Consumir**: item:remove(1)

