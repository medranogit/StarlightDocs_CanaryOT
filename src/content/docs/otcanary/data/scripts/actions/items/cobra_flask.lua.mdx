## 📄 Visão Geral do Código

**Resumo Executivo**

O script `cobra_flask.lua` implementa flask de cobra com dois handlers para dois estados (cheio/vazio). Estado cheio (31296) intoxica plantas com poção cobra (verde smoke), após uso transforma para vazio (31297) e ativa cooldown global 30 min. Estado vazio pode ser refill em 3 fontes específicas, voltando para estado cheio.

**Estrutura de Funcionalidades**

```
[Handler 1: Flask cheio (31296)]
    ├─ Check target em {31284, 31285, 31286, 31287}
    ├─ SIM → continuar
    └─ NÃO → return true
    ├─ sendMagicEffect(GREENSMOKE)
    ├─ sendTextMessage aviso
    ├─ item:transform(31297) [vazio]
    ├─ Game.setStorageValue(CobraFlask, now + 30min)
    └─ return true

[Handler 2: Flask vazio (31297)]
    ├─ Check target em {4188, 4189, 4190}
    ├─ SIM → item:transform(31296)
    ├─ NÃO → noop
    └─ return true
```

## Funções Globais

### Handler 1: cobraFlask.onUse para ID 31296

Callback que aplica cobra flask em plantas/objetos.

**Parâmetros:**
- player: Creature player
- item: Flask sendo usado
- fromPosition: Posição uso
- target: Alvo (deve ser plant ID específico)
- toPosition: Posição destino
- isHotkey: Boolean via hotkey

**Lógica:**

```lua
if table.contains({ 31284, 31285, 31286, 31287 }, target:getId()) then
	target:getPosition():sendMagicEffect(CONST_ME_GREENSMOKE)
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
		"You carefully pour just a tiny, little, finely dosed... and there goes the whole content of the bottle. Stand back!")
	item:transform(31297)
	Game.setStorageValue(Global.Storage.CobraFlask, os.time() + 30 * 60)
end
return true
```

**Efeito:**
1. Verifica se target é uma das 4 plantas cobras
2. Emite smoke verde na posição
3. Envia mensagem ao player
4. Transforma flask em vazio (31297)
5. Ativa cooldown global 30 minutos

### Handler 2: cobraFlask.onUse para ID 31297

Callback que reabastece flask vazio.

**Parâmetros:**
- player: Creature player
- item: Flask vazio
- fromPosition: Posição uso
- target: Fonte de água
- toPosition: Posição destino
- isHotkey: Boolean via hotkey

**Lógica:**

```lua
if table.contains({ 4188, 4189, 4190 }, target:getId()) then
	item:transform(31296)
end
return true
```

**Efeito:**
1. Verifica se target é uma das 3 fontes
2. Transforma flask em cheio (31296)
3. Sem mensagem ou efeito (simples refill)
