## 📄 Visão Geral do Código

**Resumo Executivo**

O script `ferumbras_mana_keg.lua` implementa keg temático com dois handlers para dois estados. Estado cheio (22769) permite extrair 10 pociones de mana ultimate, transformando em vazio (22770) iniciando decay. Estado vazio rejeita uso enquanto recarrega. Simples e direto sem validações complexas.

**Estrutura de Funcionalidades**

```
[Create ferumbrasAscendantManaKeg Action]
    ↓
[onUse function]
    ├─ If itemid == 22769 (cheio)
    │   ├─ player:addItem("ultimate mana potion", 10)
    │   ├─ item:transform(22770)
    │   ├─ item:decay()
    │   ├─ sendMagicEffect(CONST_ME_MAGIC_RED)
    │   ├─ sendTextMessage descritiva
    │   └─ return true
    └─ Elseif itemid == 22770 (vazio)
        ├─ sendTextMessage: "You are tired..."
        └─ return true
```

## Funções

### ferumbrasAscendantManaKeg.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que extrai pociones de mana.

**Parâmetros:**
- player: Creature player
- item: Keg sendo usado
- fromPosition: Posição do uso
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. If item.itemid == 22769 (cheio)
   ├─ addItem("ultimate mana potion", 10)
   │   └─ Cria 10 pociones no inventory
   ├─ item:transform(22770)
   │   └─ Vira vazio
   ├─ item:decay()
   │   └─ Inicia timer de recharge
   ├─ sendMagicEffect(CONST_ME_MAGIC_RED)
   │   └─ Efeito visual
   ├─ sendTextMessage(descritivo)
   │   └─ "Magical sparks... you fill ten empty vials..."
   └─ return true

2. Elseif item.itemid == 22770 (vazio)
   ├─ sendTextMessage: "You are tired of the last use..."
   └─ return true
```

**Implementação:**

```lua
function ferumbrasAscendantManaKeg.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if item.itemid == 22769 then
		player:addItem("ultimate mana potion", 10)
		item:transform(22770)
		item:decay()
		player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Magical sparks whirl around the keg as you open the spigot and you fill ten empty vials with mana fluid.")
		return true
	elseif item.itemid == 22770 then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You are tired of the last use of the mana keg, rest your arms for a moment.")
	end
	return true
end
```

## Item States

### Estado Cheio (ID 22769)

- Ativo e usável
- Gera 10 pociones de mana ultimate
- Emite efeito mágico vermelho
- Transforma para vazio após uso

### Estado Vazio (ID 22770)

- Recarregando
- Rejeita uso
- Entra em decay timer
- Volta para 22769 após decay
