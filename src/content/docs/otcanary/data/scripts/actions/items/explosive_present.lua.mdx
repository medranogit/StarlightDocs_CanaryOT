## 📄 Visão Geral do Código

**Resumo Executivo**

O script `explosive_present.lua` implementa presente temático de brincadeira com explosão. Ao usar, player emite grito "KABOOOOOOOOOOM!", efeito mágico de fogo em área e desaparece. Desbloquia achievement "Joke's on You". Sem validações ou cooldown - uso direto.

**Estrutura de Funcionalidades**

```
[Create explosivePresent Action]
    ↓
[onUse function]
    ├─ player:say("KABOOOOOOOOOOM!", TALKTYPE_MONSTER_SAY)
    ├─ player:getPosition():sendMagicEffect(CONST_ME_FIREAREA)
    ├─ player:addAchievement("Joke's on You")
    ├─ item:remove()
    └─ return true
    ↓
[Register on item ID 906]
```

## Funções

### explosivePresent.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que detona presente.

**Parâmetros:**
- player: Creature player
- item: Presente sendo detonado
- fromPosition: Posição do uso
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. player:say("KABOOOOOOOOOOM!", TALKTYPE_MONSTER_SAY)
   └─ Grito ouvido por espectadores

2. player:getPosition():sendMagicEffect(CONST_ME_FIREAREA)
   └─ Efeito visual fogo em área

3. player:addAchievement("Joke's on You")
   └─ Unlock achievement

4. item:remove()
   └─ Presente desaparece

5. return true
```

**Implementação:**

```lua
function explosivePresent.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	player:say("KABOOOOOOOOOOM!", TALKTYPE_MONSTER_SAY)
	player:getPosition():sendMagicEffect(CONST_ME_FIREAREA)
	player:addAchievement("Joke's on You")
	item:remove()
	return true
end
```
