## 📄 Visão Geral do Código

### Resumo Executivo

O script é trivialmente simples: 5 items mapeados para 5 efeitos visuais diferentes (GAZHARAGOTH, FERUMBRAS_1, MAD_MAGE, HORESTIS, DEVOVORGA). Ao usar, valida se alvo é player (target:isPlayer()) e envia o efeito na posição do alvo. Sem cooldown, sem message, sem achievement.

### Estrutura de Funcionalidades

```
CONFIG TABLE (5 vessels):
  ├─ 37572 → CONST_ME_GAZHARAGOTH (efeito visual)
  ├─ 37573 → CONST_ME_FERUMBRAS_1
  ├─ 37574 → CONST_ME_MAD_MAGE
  ├─ 37575 → CONST_ME_HORESTIS
  └─ 37576 → CONST_ME_DEVOVORGA

HANDLER:
  └─ vessels.onUse()
      ├─ vessel = config[item.itemid]
      ├─ target:isPlayer()? 
      │   ├─ NÃO → return true
      │   ├─ SIM → Continua
      ├─ toPosition:sendMagicEffect(vessel)
      ├─ item:remove(1)
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local config = {
	[37572] = CONST_ME_GAZHARAGOTH,
	[37573] = CONST_ME_FERUMBRAS_1,
	[37574] = CONST_ME_MAD_MAGE,
	[37575] = CONST_ME_HORESTIS,
	[37576] = CONST_ME_DEVOVORGA,
}

local vessels = Action()

function vessels.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Obter efeito
	local vessel = config[item.itemid]
	
	-- Validação: Alvo deve ser player
	if not vessel or not target:isPlayer() then
		return true
	end

	-- Enviar efeito na posição do alvo
	toPosition:sendMagicEffect(vessel)
	
	-- Consumir item
	item:remove(1)
	return true
end

-- Registrar todos os IDs
for index in pairs(config) do
	vessels:id(index)
end

vessels:register()
```

### Effect Validation

```
Usar vessel em NPC:
  ├─ target:isPlayer() = false
  ├─ return true (sem efeito)
  └─ Item consumido? SIM (antes do check)

Usar vessel em Player:
  ├─ target:isPlayer() = true
  ├─ toPosition:sendMagicEffect(vessel)
  ├─ item:remove(1)
  └─ Efeito visível
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Config Lookup**: Tabela itemId → effect constant
- **target:isPlayer()**: Validação se alvo é jogador
- **toPosition**: Posição do alvo para efeito
- **sendMagicEffect()**: Enviar efeito visual
- **No Feedback**: Sem mensagem ou emote
- **Simple Mapping**: 1:1 item-to-effect
- **Always Remove**: item:remove(1) mesmo se falhar
- **Return Structure**: if not valid return true

### Responsabilidades do Handler

1. **Obter efeito**: config[item.itemid]
2. **Validar**: if not vessel or not target:isPlayer()
3. **Rejeitar se inválido**: return true
4. **Enviar efeito**: toPosition:sendMagicEffect(vessel)
5. **Consumir**: item:remove(1)
