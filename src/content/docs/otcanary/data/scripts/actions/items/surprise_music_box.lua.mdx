## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa caixa de música com prêmios baseados em chance cumulativa de 1-100. Tabela contém 11 prêmios com diferentes raridades: itens raros no topo (1-5% chance), coins intermediários (10-90% chance). Usa soma cumulativa de chances para determinar o prêmio. Efeito POFF indica falha/sucesso.

### Estrutura de Funcionalidades

```
PRIZE TABLE (11 entradas):
  ├─ Chance 1-5: Itens raros (4 items)
  ├─ Chance 10-50: Crystal coins variáveis
  ├─ Chance 20-90: Gold coins (1 ou 80)
  └─ Chance 30-50: Platinum coins (15)

HANDLER:
  └─ surpriseBox.onUse()
      ├─ number = random(1, 100)
      ├─ cumulativeChance = 0
      ├─ Loop prizes:
      │   ├─ Soma chance ao cumulative
      │   ├─ number <= cumulative?
      │   │   ├─ SIM → encontrou prêmio
      │   │   ├─ addItem(id, amount)
      │   │   └─ break
      │   └─ Não → continua
      └─ Effect: POFF + remove
```

## Fluxo de Operação

### Operação Principal

```lua
local prize = {
	{ chance = 1, id = 3246, amount = 1 },
	{ chance = 2, id = 10227, amount = 1 },
	{ chance = 3, id = 11588, amount = 1 },
	{ chance = 4, id = 3549, amount = 1 },
	{ chance = 5, id = 3420, amount = 1 },
	{ chance = 10, id = ITEM_CRYSTAL_COIN, amount = 17 },
	{ chance = 20, id = ITEM_GOLD_COIN, amount = 1 },
	{ chance = 30, id = ITEM_CRYSTAL_COIN, amount = 1 },
	{ chance = 40, id = ITEM_GOLD_COIN, amount = 50 },
	{ chance = 50, id = ITEM_PLATINUM_COIN, amount = 15 },
	{ chance = 90, id = ITEM_GOLD_COIN, amount = 80 },
}

function surpriseBox.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- RNG de 1-100
	local number = math.random(1, 100)
	local cumulativeChance = 0

	-- Loop até encontrar prêmio
	for _, prizeEntry in ipairs(prize) do
		-- Somar chance ao total acumulado
		cumulativeChance = cumulativeChance + prizeEntry.chance
		
		-- Verificar se número está dentro do range
		if number <= cumulativeChance then
			-- Encontrou prêmio
			player:getPosition():sendMagicEffect(CONST_ME_POFF)
			player:addItem(prizeEntry.id, prizeEntry.amount)
			item:remove()
			break
		end
	end
	return true
end
```

### Chance Cumulativa

```
Prize 1: chance = 1
  └─ cumulative = 0 + 1 = 1
  └─ Hit se number = 1 (1% chance)

Prize 2: chance = 2
  └─ cumulative = 1 + 2 = 3
  └─ Hit se number = 2 ou 3 (2% chance)

Prize 3: chance = 3
  └─ cumulative = 3 + 3 = 6
  └─ Hit se number = 4, 5, ou 6 (3% chance)

...

Prize 11: chance = 90
  └─ cumulative = 10 + 90 = 100
  └─ Hit se number = 11-100 (90% chance)

Total cumulative = 1 + 2 + 3 + 4 + 5 + 10 + 20 + 30 + 40 + 50 + 90 = 255
```

**Problema:** Chances somam 255, não 100. Implementação gera número 1-100 e compara com cumulative progressivo. Último item (chance 90) nunca pode ser sorteado com este sistema, pois número máximo é 100 e cumulative chegaria a 255.

### Exemplo de Execução

```
Caso: number = 5
  ├─ Prize 1: cum = 1, 5 > 1? FIM
  ├─ Prize 2: cum = 3, 5 > 3? FIM
  ├─ Prize 3: cum = 6, 5 <= 6? SIM → ID 11588 (Sweet Mangonaise)
  └─ break

Caso: number = 27
  ├─ Prize 1-5: cum < 10, skip
  ├─ Prize 6: cum = 10, 27 > 10? FIM
  ├─ Prize 7: cum = 30, 27 <= 30? SIM → ID GOLD_COIN (1)
  └─ break
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Chance Cumulativa**: Somar chances até atingir threshold
- **math.random(1, 100)**: Gera número para comparação
- **Loop com Break**: Limpa quando encontra match
- **Soma Progressiva**: cumulativeChance += chance a cada iteração
- **Hit Condition**: `number <= cumulativeChance`
- **Rarity Distribution**: Items raros no início, coins comuns no final
- **Tabela Estruturada**: chance, id, amount por prêmio
- **Item Removal**: item:remove() após prêmio (não remove quantidade)

### Responsabilidades do Handler

1. **Gerar RNG**: random(1, 100)
2. **Inicializar cumulative**: = 0
3. **Loop prêmios**: ipairs(prize)
4. **Somar chance**: cumulativeChance += chance
5. **Comparar**: `number <= cumulativeChance`?
6. **Conceder prêmio**: addItem(id, amount)
7. **Efeito visual**: CONST_ME_POFF
8. **Consumir box**: item:remove()
9. **Break**: Sair do loop após acertar
