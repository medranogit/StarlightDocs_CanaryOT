## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa boneca voodoo com RNG de 5% chance de sucesso. Valida que alvo é player, gera número aleatório (1-100), e branqueia em sucesso (5% chance) ou falha (95%). No sucesso, concede achievement e efeito visual. Mensagens customizadas indicam sucesso ou falha. Return false se alvo não é player (obrigatório).

### Estrutura de Funcionalidades

```
HANDLER:
  └─ voodooDoll.onUse()
      ├─ target.itemid ~= 1? ou não isPlayer()?
      │   └─ NÃO → return false (target inválido)
      │
      ├─ SIM → Continua
      │
      ├─ math.random(100) <= 5? (5% chance)
      │   │
      │   ├─ SIM → Sucesso (5%)
      │   │   ├─ text = "hit the needle... success"
      │   │   ├─ addAchievement("Dark Voodoo Priest")
      │   │   ├─ Effect: DRAWBLOOD
      │   │   └─ say(text)
      │   │
      │   └─ NÃO → Falha (95%)
      │       └─ text = "hit the needle... nothing happens"
      │       └─ say(text)
      │
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local voodooDoll = Action()

function voodooDoll.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação: Alvo deve ser player (target.itemid verifica se é item creature)
	if target.itemid ~= 1 or not target:isPlayer() then
		return false
	end

	-- RNG: 5% chance de sucesso
	local text = ""
	if math.random(100) <= 5 then
		-- SUCESSO (5%)
		text = "You concentrate on your victim and hit the needle in the doll."
		player:addAchievement("Dark Voodoo Priest")
		toPosition:sendMagicEffect(CONST_ME_DRAWBLOOD, player)
	else
		-- FALHA (95%)
		text = "You concentrate on your victim, hit the needle in the doll.......but nothing happens."
	end

	-- Message (audível ao jogador que fez)
	player:say(text, TALKTYPE_MONSTER_SAY, false, player)
	return true
end

voodooDoll:id(3002)
voodooDoll:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Return False**: Indica target inválido (obrigatório alvo ser player)
- **RNG Condition**: `math.random(100) <= N` para percentual
- **5% Success**: Apenas rolls 1-5 (5 em 100)
- **95% Failure**: Rolls 6-100 (95 em 100)
- **Conditional Achievement**: Só se sucesso
- **Dynamic Message**: Texto muda conforme RNG
- **target.itemid**: Verifica se estrutura é player
- **DRAWBLOOD Effect**: Específico para efeito de sangue
- **say() com false, player**: Mensagem local audível

### Responsabilidades do Handler

1. **Validar target**: target.itemid ~= 1 ou não isPlayer()
2. **Rejeitar inválido**: return false
3. **Gerar RNG**: math.random(100)
4. **Comparar**: `<= 5` para sucesso
5. **Achievement**: addAchievement() se sucesso
6. **Effect**: DRAWBLOOD se sucesso
7. **Message**: text diferente por RNG
8. **Say**: Enviar mensagem audível
9. **Return**: true sempre (após validar)

## Patterns e Implementação

### Padrão RNG Conditional

Percentual baseado em random:

```lua
if math.random(100) <= 5 then
	-- 5% de chance
	text = "Sucesso!"
	player:addAchievement("Dark Voodoo Priest")
	toPosition:sendMagicEffect(CONST_ME_DRAWBLOOD, player)
else
	-- 95% de chance
	text = "Nada acontece."
end

player:say(text, TALKTYPE_MONSTER_SAY)
```

### Padrão Return False

Validação de target obrigatório:

```lua
if target.itemid ~= 1 or not target:isPlayer() then
	return false  -- Alvo inválido
end
```
