## 📄 Visão Geral do Código

**Resumo Executivo**

O script `filled_jalapeno_peppers.lua` implementa comida simples que aplica buff de velocidade (haste) por 1 hora. Usa cooldown compartilhado special-foods para sincronizar com outras special foods (10 minutos). Condition pré-compilada com velocidade 729 (boost significativo). Emote "Munch" e efeito mágico vermelho como feedback.

**Estrutura de Funcionalidades**

```
[Pré-compile speedCondition]
    ├─ CONDITION_HASTE type
    ├─ CONDITION_PARAM_TICKS: 3.600.000ms (1h)
    └─ CONDITION_PARAM_SPEED: 729

[Create filledJalapenoPeppers Action]
    ↓
[onUse function]
    ├─ Check exhaustion: special-foods-cooldown
    │   ├─ SIM → reject + return true
    │   └─ NÃO → continuar
    ├─ addCondition(speedCondition)
    ├─ sendTextMessage: "Your speed has been increased."
    ├─ player:say("Munch.", TALKTYPE_MONSTER_SAY)
    ├─ sendMagicEffect(CONST_ME_MAGIC_RED)
    ├─ setExhaustion("special-foods-cooldown", 10min)
    ├─ item:remove(1)
    └─ return true
    ↓
[Register on item ID 9085]
```

### speedCondition (local)

local speedCondition = Condition(CONDITION_HASTE)
speedCondition:setParameter(CONDITION_PARAM_TICKS, 60 * 60 * 1000)

**Parâmetros:**

## Funções

### filledJalapenoPeppers.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que aplica buff de velocidade.

**Parâmetros:**
- player: Creature player
- item: Pimenta sendo consumida
- fromPosition: Posição do uso
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. hasExhaustion("special-foods-cooldown")?
   ├─ SIM → "You need to wait..."
   └─ NÃO → continuar

2. addCondition(speedCondition)
   └─ Aplica buff 1 hora

3. sendTextMessage: "Your speed has been increased."

4. player:say("Munch.", TALKTYPE_MONSTER_SAY)

5. sendMagicEffect(CONST_ME_MAGIC_RED)

6. setExhaustion("special-foods-cooldown", 600s)
   └─ Cooldown 10 min compartilhado

7. item:remove(1) + return true
```

**Implementação:**

```lua
function filledJalapenoPeppers.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if player:hasExhaustion("special-foods-cooldown") then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You need to wait before using it again.")
		return true
	end

	player:addCondition(speedCondition)
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Your speed has been increased.")
	player:say("Munch.", TALKTYPE_MONSTER_SAY)
	player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)
	player:setExhaustion("special-foods-cooldown", 10 * 60)
	item:remove(1)
	return true
end
```
