## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa um item que se transforma em versão assada ao ser usado próximo a um campfire. É um exemplo minimalista de validação condicional baseada no target (item alvo). Quando o target é um campfire (ID 1998), o item transforma e envia efeito visual de fogo.

### Estrutura de Funcionalidades

```
roastedMeat (Action)
  ├─ onUse(player, item, fromPosition, target, toPosition, isHotkey)
  │   ├─ Validação: target.itemid == 1998? (campfire)
  │   ├─ SIM: transform(22187) + efeito HITBYFIRE
  │   └─ return true (sempre)
  └─ register() → ID 22186
```

## Fluxo de Operação

### Operação Principal

```lua
function roastedMeat.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Valida se target é um campfire
	if target.itemid == 1998 then -- campfire
		-- Transforma item em versão assada
		item:transform(22187)
		-- Efeito visual na posição do campfire
		toPosition:sendMagicEffect(CONST_ME_HITBYFIRE)
	end
	return true
end
```

### Árvore de Decisão

```
Jogador usa carne_crua (22186) perto de item
  │
  ├─ target.itemid == 1998 (campfire)?
  │   │
  │   ├─ SIM → Transformação Autorizada
  │   │   ├─ item:transform(22187)
  │   │   ├─ Efeito HITBYFIRE at toPosition
  │   │   └─ return true
  │   │
  │   └─ NÃO → Sem Transformação
  │       └─ return true (item não muda)
  │
  └─ Sempre retorna true (nunca falha)
```

### Target Validation

O script valida apenas o ID do item alvo:

```lua
if target.itemid == 1998 then
	-- Campfire detectado → permite transformação
	item:transform(22187)
	toPosition:sendMagicEffect(CONST_ME_HITBYFIRE)
end
```

Se o target não for campfire, a função retorna true sem fazer nada (item permanece inalterado).

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Target Validation**: Verificar `target.itemid` para validação condicional
- **Transform Condicional**: Apenas transforma se condição específica é atendida
- **toPosition vs fromPosition**: toPosition é a posição do target (onde o efeito aparece)
- **HITBYFIRE**: Efeito visual de fogo para ações relacionadas a fogueira
- **Return Always True**: Item sempre retorna sucesso (não falha mesmo sem campfire)
- **Minimal Logic**: Script com apenas uma validação simples
- **No Side Effects**: Nenhum achievement, cooldown ou healing

### Responsabilidades do Handler

1. **Validar alvo**: Verificar se target.itemid é campfire (1998)
2. **Transformar item**: Se validação passa, mudar 22186 → 22187
3. **Efeito visual**: Enviar HITBYFIRE à posição do target
4. **Sempre sucesso**: Retornar true independentemente
