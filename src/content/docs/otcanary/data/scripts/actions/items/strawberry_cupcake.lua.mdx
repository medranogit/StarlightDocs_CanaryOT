## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa consumível que restaura 100% da vida máxima com cooldown próprio "strawberry-cupcake-cooldown" (10 min). Diferencia-se de outras comidas por usar cooldown individual ao invés de compartilhado. Inclui validação de cooldown, efeito visual, emote e mensagem customizada.

## Fluxo de Operação

### Operação Principal

```lua
function strawberryCupcake.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação de cooldown próprio
	if player:hasExhaustion("strawberry-cupcake-cooldown") then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You need to wait before using it again.")
		return true  -- Item NÃO removido
	end

	-- Full heal
	player:addHealth(player:getMaxHealth())
	
	-- Feedback ao jogador
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Your health has been refilled.")
	player:say("Mmmm.", TALKTYPE_MONSTER_SAY)
	
	-- Ativar cooldown próprio
	player:setExhaustion("strawberry-cupcake-cooldown", 10 * 60)
	
	-- Consumir item
	item:remove(1)
	return true
end
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Cooldown Próprio**: "strawberry-cupcake-cooldown" é específico deste item
- **Full Heal Pattern**: `player:addHealth(player:getMaxHealth())`
- **hasExhaustion()**: Verifica se em cooldown
- **setExhaustion()**: Ativa cooldown de X segundos
- **Return True Sem Consumir**: Se cooldown bloqueia, não remove item
- **Emote Customizado**: "Mmmm." diferente de "Gulp."
- **No Visual Effect**: Apenas mensagem, sem efeito mágico
- **Always Returns True**: Operação não falha

### Responsabilidades do Handler

1. **Validar cooldown**: hasExhaustion("strawberry-cupcake-cooldown")
2. **Rejeitar se em cooldown**: Return true sem remover
3. **Restaurar vida**: addHealth(getMaxHealth())
4. **Enviar mensagem**: Feedback de restauração
5. **Emote**: "Mmmm." audível
6. **Ativar cooldown**: setExhaustion(10 min)
7. **Consumir item**: remove(1)
