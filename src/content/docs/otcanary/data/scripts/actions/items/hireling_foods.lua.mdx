## 📄 Visão Geral do Código

**Resumo Executivo**

O script `hireling_foods.lua` implementa sistema de pratos gourmet especializados com 6 conditions pré-compiladas (HASTE, FISHING, MAGIC_POINTS, MELEE, SHIELD, DISTANCE) cada com 1 hora duração e valor específico. 9 dishes mapeados (IDs 29408-29416) combinam conditions ou ações diretas (healing 30% HP, restore 30% mana). Cooldown compartilhado special-foods (10 min). Registração dinâmica via loop.

**Estrutura de Funcionalidades**

```
[Pré-compile 6 conditions com 1h duração]
    ├─ hasteCondition: HASTE, speed 80
    ├─ fishingCondition: FISHING skill +30
    ├─ magicPointsCondition: MAGIC_POINTS +3
    ├─ meleeCondition: MELEE skill +3
    ├─ shieldCondition: SHIELD skill +7
    └─ distanceCondition: DISTANCE skill +7

[Define gourmetDishes table com 9 pratos]
    ├─ 29408: shield condition
    ├─ 29409: distance condition
    ├─ 29410: magic points condition
    ├─ 29411: melee condition
    ├─ 29412: haste condition
    ├─ 29413: fishing condition
    ├─ 29414: healing 30% max HP
    ├─ 29415: mana restore 30% max mana
    └─ 29416: message only (no effect)

[Create hirelingFoods Action]
    ↓
[onUse function]
    ├─ dish = gourmetDishes[item.itemid]
    ├─ Not found? return true
    ├─ If special-foods-cooldown active
    │   └─ "You're still too full..." (return)
    ├─ If dish.condition
    │   └─ addCondition(dish.condition)
    ├─ Elseif dish.healing
    │   └─ addHealth(getMaxHealth() * 0.3)
    ├─ Elseif dish.manaRestore
    │   └─ addMana(getMaxMana() * 0.3)
    ├─ player:say(dish.message)
    ├─ setExhaustion("special-foods-cooldown", 10min)
    ├─ item:remove(1)
    └─ return true
    ↓
[Register all 9 items via loop]
```

## Funções

### hirelingFoods.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que aplica prato.

**Parâmetros:**
- player: Creature player (hireling eater)
- item: Prato sendo consumido
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. dish = gourmetDishes[item.itemid]
   ├─ Não existe? return true
   └─ Existe? continuar

2. If hasExhaustion("special-foods-cooldown")
   ├─ "You're still too full to eat any gourmet dishes..."
   └─ return true

3. If dish.condition
   └─ addCondition(dish.condition)

4. Elseif dish.healing
   └─ addHealth(getMaxHealth() * 0.3)

5. Elseif dish.manaRestore
   └─ addMana(getMaxMana() * 0.3)

6. player:say(dish.message, TALKTYPE_MONSTER_SAY)

7. setExhaustion("special-foods-cooldown", 600s)

8. item:remove(1) + return true
```

**Implementação:**

```lua
function hirelingFoods.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local dish = gourmetDishes[item.itemid]
	if not dish then
		return true
	end

	if player:hasExhaustion("special-foods-cooldown") then
		player:sendCancelMessage("You're still too full to eat any gourmet dishes for a while.")
		return true
	end

	if dish.condition then
		player:addCondition(dish.condition)
	elseif dish.healing then
		player:addHealth(player:getMaxHealth() * 0.3)
	elseif dish.manaRestore then
		player:addMana(player:getMaxMana() * 0.3)
	end

	player:say(dish.message, TALKTYPE_MONSTER_SAY)
	player:setExhaustion("special-foods-cooldown", 10 * 60)

	item:remove(1)
	return true
end
```

## Healing/Mana Calculations

**Healing**: `getMaxHealth() * 0.3` → 30% do HP máximo

**Mana Restore**: `getMaxMana() * 0.3` → 30% da mana máxima

Exemplos:
- 1000 max HP → heal 300 HP
- 500 max mana → restore 150 mana
