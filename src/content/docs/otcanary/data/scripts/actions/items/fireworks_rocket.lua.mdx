## 📄 Visão Geral do Código

**Resumo Executivo**

O script `fireworks_rocket.lua` implementa foguete de artifício com dois comportamentos distintos baseado em localização. Se usado no chão, emite efeito visual aleatório (amarelo ou azul). Se usado no inventory (bolsa), causa dano de 10 HP físico, emite dois efeitos (fogo + queimado), grita frase cômida e progride achievement "Rocket in Pocket". Todos os usos progridem "Fireworks in the Sky".

**Estrutura de Funcionalidades**

```
[Create fireworksRocket Action]
    ↓
[onUse function]
    ├─ If fromPosition not CONTAINER_POSITION
    │   └─ Ground placement
    │       ├─ efeito aleatório (YELLOW ou BLUE)
    │       └─ return true
    └─ Else container placement
        ├─ Dois efeitos (FIREAREA + HITBYFIRE)
        ├─ Frase: "Ouch! Rather place it on the ground..."
        ├─ Progress "Rocket in Pocket" +3
        ├─ Dano -10 HP (PHYSICAL)
        └─ return true
    ↓
[Ambos os casos]
    ├─ Progress "Fireworks in the Sky" +250
    ├─ item:remove()
    └─ return true
    ↓
[Register on item ID 6576]
```

## Funções

### fireworksRocket.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que detona foguete.

**Parâmetros:**
- player: Creature player
- item: Foguete sendo usado
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. If fromPosition.x != CONTAINER_POSITION (chão)
   ├─ efeito = random(YELLOW, BLUE)
   ├─ fromPosition:sendMagicEffect(efeito)
   └─ return true

2. Else (inventory/container)
   ├─ player:getPosition():sendMagicEffect(FIREAREA)
   ├─ player:getPosition():sendMagicEffect(HITBYFIRE)
   ├─ player:say("Ouch! Rather place it on the ground next time.")
   ├─ Progress "Rocket in Pocket" +3
   ├─ Dano addHealth(-10, PHYSICAL)
   └─ continue

3. Ambos os casos
   ├─ Progress "Fireworks in the Sky" +250
   ├─ item:remove()
   └─ return true
```

**Implementação:**

```lua
function fireworksRocket.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if fromPosition.x ~= CONTAINER_POSITION then
		fromPosition:sendMagicEffect(math.random(CONST_ME_FIREWORK_YELLOW, CONST_ME_FIREWORK_BLUE))
	else
		player:getPosition():sendMagicEffect(CONST_ME_FIREAREA)
		player:getPosition():sendMagicEffect(CONST_ME_HITBYFIRE)
		player:say("Ouch! Rather place it on the ground next time.", TALKTYPE_MONSTER_SAY)
		player:addAchievementProgress("Rocket in Pocket", 3)
		player:addHealth(-10, COMBAT_PHYSICALDAMAGE)
	end

	player:addAchievementProgress("Fireworks in the Sky", 250)
	item:remove()
	return true
end
```

## Checkpoint de Aprendizagem

**Conceitos-chave:**
1. Diferença localização chão vs container
2. Random entre dois efeitos
3. Múltiplos efeitos simultâneos
4. Achievement progress (não unlock único)
5. Dano físico como penalidade
6. Behavior condicional por posição

**Responsabilidades:**
1. Detectar localização (chão vs inventory)
2. Emitir efeito apropriado
3. Se inventory: dano + efeitos + frase
4. Progresso achievements em ambos os casos
5. Remover item
