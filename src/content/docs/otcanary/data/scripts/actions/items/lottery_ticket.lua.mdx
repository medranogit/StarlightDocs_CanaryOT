## 📄 Visão Geral do Código

**Resumo Executivo**

O script `lottery_ticket.lua` implementa bilhete de loteria com chance mínima 1/98 (1.02%), Sucesso transforma item para ID 5958 com efeito SOUND_YELLOW. Falha remove bilhete com efeito POFF. Simples e direto sem validações complexas.

**Estrutura de Funcionalidades**

```
[Create lotteryTicket Action]
    ↓
[onUse function]
    ├─ chance = random(98)
    ├─ If chance == 1 (1/98)
    │   ├─ sendMagicEffect(SOUND_YELLOW)
    │   ├─ item:transform(5958) [prêmio]
    │   └─ return true
    └─ Else (97/98)
        ├─ sendMagicEffect(POFF)
        ├─ item:remove(1)
        └─ return true
    ↓
[Register on item ID 5957]
```

## Funções

### lotteryTicket.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que testa sorte.

**Parâmetros:**
- player: Creature player
- item: Bilhete sendo usado
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. chance = random(98)

2. If chance == 1 (1/98 probability)
   ├─ player:getPosition():sendMagicEffect(SOUND_YELLOW)
   ├─ item:transform(5958) [vira prêmio]
   └─ return true

3. Else (97/98 probability)
   ├─ item:getPosition():sendMagicEffect(POFF)
   ├─ item:remove(1)
   └─ return true
```

**Implementação:**

```lua
function lotteryTicket.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if math.random(98) == 1 then
		player:getPosition():sendMagicEffect(CONST_ME_SOUND_YELLOW)
		item:transform(5958)
	else
		item:getPosition():sendMagicEffect(CONST_ME_POFF)
		item:remove(1)
	end
	return true
end
```
