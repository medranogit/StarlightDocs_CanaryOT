## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa um mealheiro com mecânica RNG onde cada uso gera moedas aleatórias: 1/6 chances (16.67%) de 1 moeda de ouro + achievement "Allowance Collector" +50, ou 5/6 chances (83.33%) de 1 moeda de platina. Ao conseguir ouro, o mealheiro transforma em versão quebrada (2996).

### Estrutura de Funcionalidades

```
piggyBank (Action)
  ├─ onUse(player, item, fromPosition, target, toPosition, isHotkey)
  │   ├─ math.random(6) == 1 → Resultado sucesso (1/6)
  │   │   ├─ Efeito: CONST_ME_POFF
  │   │   ├─ Transform: 2995 → 2996
  │   │   ├─ addItem(ITEM_GOLD_COIN, 1)
  │   │   └─ Achievement "Allowance Collector" +50
  │   └─ Falha (5/6)
  │       ├─ Efeito: CONST_ME_SOUND_YELLOW
  │       └─ addItem(ITEM_PLATINUM_COIN, 1)
  └─ register() → ID 2995
```

## Fluxo de Operação

### Operação Principal

```lua
function piggyBank.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Teste de 1 em 6 chances
	if math.random(6) == 1 then
		-- Raro sucesso (16.67%): ouro + achievement
		fromPosition:sendMagicEffect(CONST_ME_POFF)
		item:transform(2996)
		player:addItem(ITEM_GOLD_COIN, 1)
		player:addAchievementProgress("Allowance Collector", 50)
	else
		-- Comum (83.33%): platina
		fromPosition:sendMagicEffect(CONST_ME_SOUND_YELLOW)
		player:addItem(ITEM_PLATINUM_COIN, 1)
	end
	return true
end
```

### Árvore de Decisão

```
Jogador ativa piggy_bank (2995)
  │
  ├─ Teste: math.random(6) == 1?
  │   │
  │   ├─ SIM (1/6 = 16.67%) → Sucesso Raro
  │   │   ├─ Efeito: POFF
  │   │   ├─ Transform 2995 → 2996
  │   │   ├─ Gold Coin +1
  │   │   ├─ Achievement "Allowance Collector" +50
  │   │   └─ return true
  │   │
  │   └─ NÃO (5/6 = 83.33%) → Sucesso Comum
  │       ├─ Efeito: SOUND_YELLOW
  │       ├─ Platinum Coin +1
  │       └─ return true
  │
  └─ Sempre retorna true (Always success)
```

### Probabilidades

```
Resultado      | Probabilidade | Efeito        | Resultado
--- | --- | --- | ---
Ouro           | 1/6 (16.67%)  | POFF          | Gold Coin, Quebrado
Platina        | 5/6 (83.33%)  | SOUND_YELLOW  | Platinum Coin
```

### Contraste de Efeitos

Interestingly, o mealheiro usa **POFF effect para sucesso raro** (ouro), sugerindo falha paradoxal ("o mealheiro 'quebra'" ao dar ouro). Este design invertido melhora a experiência de jogo.

## Checkpoint de Aprendizagem

### Conceitos-chave

- **RNG Simples**: `math.random(6) == 1` gera 1/6 chance
- **Probabilidade**: 16.67% sucesso raro, 83.33% sucesso comum
- **Branching**: Padrão if/else para desfechos diferentes
- **Transform Condicional**: Apenas nunc ocorre em branch sucesso
- **Efectos Invertidos**: POFF (falha) para sucesso raro (design intencional)
- **Achievement Progress**: Apenas no desfecho raro
- **Sempre Retorna True**: Item sempre funciona (nunca falha)

### Responsabilidades do Handler

1. **Gerar RNG**: Usar `math.random(6)` para teste de 1/6
2. **Branch pelo resultado**: if/else para duas recompensas
3. **Aplicar efeito visual**: POFF ou SOUND_YELLOW conforme resultado
4. **Transformar no sucesso raro**: Quebrar mealheiro em versão 2996
5. **Conceder moedas**: Gold (rara) ou Platinum (comum)
6. **Registrar achievement**: Apenas para resultado raro
7. **Confirmar ação**: Sempre return true
