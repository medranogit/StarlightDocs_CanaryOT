## 📄 Visão Geral do Código

**Resumo Executivo**

O script `costume_bags.lua` implementa bags de fantasia com outfit aleatória de monstro. Cada bag (ID 653, 654, 655, 24949) tem pool de nomes de monstros. Ao usar, seleciona aleatoriamente um monstro, aplica outfit por 50 min, progride achievement em 100 pontos, emite efeito vermelho e consome bag.

**Estrutura de Funcionalidades**

```
[Define config com 4 bags]
    ├─ 653: 8 monstros (lower tiers)
    ├─ 654: 8 monstros (mid tiers)
    ├─ 655: 8 monstros (high tiers)
    └─ 24949: 4 monstros (old versions)
    ↓
[Create costumeBags Action]
    ↓
[onUse function]
    ├─ creatures = config[item.itemid]
    ├─ Not found? return true
    ├─ Pick random creature name
    ├─ setMonsterOutfit(name, 5 * 60 * 10 * 1000)
    │   └─ 5 * 10min = 50min total
    ├─ addAchievementProgress("Masquerader", 100)
    ├─ sendMagicEffect(CONST_ME_MAGIC_RED)
    ├─ item:remove()
    └─ return true
    ↓
[Register Action on 4 bag IDs via loop]
```

## Funções

### costumeBags.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que aplica outfit aleatória.

**Parâmetros:**
- player: Creature player
- item: Bag sendo usado
- fromPosition: Posição do uso
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. Get creatures list por item ID
   ├─ Não existe? return true
   └─ Existe? continuar

2. randomCreature = creatures[random(1, #creatures)]
   └─ Pick aleatório do pool

3. setMonsterOutfit(randomCreature, duration)
   └─ Transforma player em monstro

4. addAchievementProgress("Masquerader", 100)

5. sendMagicEffect(CONST_ME_MAGIC_RED)

6. item:remove() [consome bag completo]

7. return true
```

**Implementação:**

```lua
function costumeBags.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local creatures = config[item.itemid]
	if not creatures then
		return true
	end

	player:setMonsterOutfit(creatures[math.random(#creatures)], 5 * 60 * 10 * 1000)
	player:addAchievementProgress("Masquerader", 100)
	player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)
	item:remove()
	return true
end
```

## Duration: 50 Minutos

**Cálculo**: 5 * 60 * 10 * 1000 = 3.000.000 ms = 3.000 s = 50 min

Nota: Conversão em milissegundos direta com o game engine.
