## 📄 Visão Geral do Código

**Resumo Executivo**

O script `lemon_cupcake.lua` implementa cupcake temático com buff de distance skill. Condition pré-compilada com tipo ATTRIBUTES, skill DISTANCE +10, duração 1 hora, com FORCEUPDATE para aplicação imediata. Cooldown "lemon-cupcake-cooldown" (10 min) controla uso frequente. Emote "Mmmm.", mensagem "You feel more focused."

**Estrutura de Funcionalidades**

```
[Pré-compile distanceCondition]
    ├─ CONDITION_ATTRIBUTES type
    ├─ BUFF_SPELL true (efeito positivo)
    ├─ TICKS: 3.600.000ms (1h)
    ├─ SKILL_DISTANCE: +10
    └─ FORCEUPDATE: true (refresh imediato)

[Create lemonCupcake Action]
    ↓
[onUse function]
    ├─ If hasExhaustion("lemon-cupcake-cooldown")
    │   └─ "You need to wait before using it again."
    │   └─ return true
    ├─ addCondition(distanceCondition)
    ├─ sendTextMessage: "You feel more focused."
    ├─ player:say("Mmmm.", TALKTYPE_MONSTER_SAY)
    ├─ setExhaustion("lemon-cupcake-cooldown", 10min)
    ├─ item:remove(1)
    └─ return true
    ↓
[Register on item ID 28486]
```

## Funções

### lemonCupcake.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que aplica buff distance.

**Parâmetros:**
- player: Creature player
- item: Cupcake sendo consumido
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. If hasExhaustion("lemon-cupcake-cooldown")
   ├─ "You need to wait before using it again."
   └─ return true

2. addCondition(distanceCondition)
   └─ Distance +10 por 1h

3. sendTextMessage: "You feel more focused."

4. player:say("Mmmm.", TALKTYPE_MONSTER_SAY)

5. setExhaustion("lemon-cupcake-cooldown", 600s)

6. item:remove(1) + return true
```

**Implementação:**

```lua
function lemonCupcake.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if player:hasExhaustion("lemon-cupcake-cooldown") then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You need to wait before using it again.")
		return true
	end

	player:addCondition(distanceCondition)
	player:sendTextMessage(MESSAGE_FAILURE, "You feel more focused.")
	player:say("Mmmm.", TALKTYPE_MONSTER_SAY)
	player:setExhaustion("lemon-cupcake-cooldown", 10 * 60)
	item:remove(1)
	return true
end
```
