## 📄 Visão Geral do Código

**Resumo Executivo**

O script `ferumbras_amulet.lua` implementa amuleto temático com dois handlers para dois estados. Estado cheio (22767) permite restaurar 1000 HP ou 1000 mana com 50% chance cada, requer estar equipado no slot necklace. Após uso, transforma em vazio (22768) iniciando decay para regeneração. Estado vazio rejeita uso enquanto recarrega.

**Estrutura de Funcionalidades**

```
[Create ferumbrasAscendantAmulet Action]
    ↓
[onUse function]
    ├─ Get amulet from CONST_SLOT_NECKLACE
    ├─ If not equipped or not same item
    │   └─ "You need to equip the amulet..."
    │   └─ return true
    ├─ If itemid == 22767 (cheio)
    │   ├─ random(2) == 1?
    │   │   ├─ SIM (50%): addHealth(1000)
    │   │   │   └─ "...you was healed."
    │   │   └─ NÃO (50%): addMana(1000)
    │   │       └─ "...you was restored."
    │   ├─ item:transform(22768)
    │   ├─ item:decay()
    │   └─ sendMagicEffect(MAGIC_BLUE)
    └─ Else if itemid == 22768 (vazio)
        └─ "You are tired of the last use..."
        └─ return true
```

### ferumbrasAscendantAmulet.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que restaura vida/mana aleatoriamente.

**Parâmetros:**
- player: Creature player
- item: Amuleto sendo usado
- fromPosition: Posição do uso
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. amulet = player:getSlotItem(CONST_SLOT_NECKLACE)

2. If amulet != item
   ├─ sendTextMessage: "You need to equip the amulet..."
   └─ return true

3. If item.itemid == 22767 (cheio)
   ├─ random(2) == 1?
   │   ├─ SIM (50%): 
   │   │   ├─ addHealth(1000, true, true)
   │   │   └─ "...you was healed."
   │   └─ NÃO (50%):
   │       ├─ addMana(1000, true, true)
   │       └─ "...you was restored."
   ├─ item:transform(22768)
   ├─ item:decay()
   ├─ sendMagicEffect(MAGIC_BLUE)
   └─ return true

4. Elseif item.itemid == 22768 (vazio)
   ├─ "You are tired of the last use..."
   └─ return true
```

**Implementação:**

```lua
function ferumbrasAscendantAmulet.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local amulet = player:getSlotItem(CONST_SLOT_NECKLACE)
	if amulet ~= item then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You need to equip the amulet to try use it.")
		return true
	end

	if item.itemid == 22767 then
		if math.random(2) == 1 then
			player:addHealth(1000, true, true)
			player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Magical sparks whirl around the amulet as you use it and you was healed.")
		else
			player:addMana(1000, true, true)
			player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Magical sparks whirl around the amulet as you use it and you was restored.")
		end

		item:transform(22768)
		item:decay()
		player:getPosition():sendMagicEffect(CONST_ME_MAGIC_BLUE)
	elseif item.itemid == 22768 then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You are tired of the last use of the amulet, you must wait for the recharge.")
	end
	return true
end
```
