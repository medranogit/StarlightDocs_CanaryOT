## 📄 Visão Geral do Código

**Resumo Executivo**

O script `garlic_bread.lua` implementa pão de alho rejeitado. Ao usar, player emite frase indicando desgosto ("After taking a small bite you decide that you don't want to eat that.") e o item NÃO é consumido. Simples action que demonstra preferência do player.

**Estrutura de Funcionalidades**

```
[Create garlicBread Action]
    ↓
[onUse function]
    ├─ player:say("After taking a small bite you decide...")
    └─ return true (SEM consumir item)
    ↓
[Register on item ID 8194]
```

## Funções

### garlicBread.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que rejeita pão.

**Parâmetros:**
- player: Creature player
- item: Pão de alho
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. player:say("After taking a small bite you decide that you don't want to eat that.")

2. return true (não remove item)
```

**Implementação:**

```lua
function garlicBread.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	player:say("After taking a small bite you decide that you don't want to eat that.", TALKTYPE_MONSTER_SAY)
	return true
end
```
