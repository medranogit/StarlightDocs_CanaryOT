## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa sistema de presentes com 5 tipos diferentes (blue present, red present, 3 surprise bags). Cada tipo contém lista de items possíveis com RNG puro. Suporta items com quantidade fixa ou quantidade aleatória (definida em tabela aninhada). Seleção é totalmente aleatória entre os items da lista.

### Estrutura de Funcionalidades

```
SETTINGS TABLE (5 bags):
  ├─ 6570 → Blue Present (13 items)
  ├─ 6571 → Red Present (17 items)
  ├─ 8853 → Surprise Bag (11 items)
  ├─ 14751 → Surprise Bag (15 items)
  └─ 14759 → Surprise Bag (11 items)

HANDLER:
  └─ surpriseBag.onUse()
      ├─ present = settings[item.itemid]
      ├─ gift = random selection
      ├─ if type(gift) == "table":
      │   ├─ count = random(gift[2])
      │   └─ gift = gift[1]
      ├─ player:addItem(gift, count)
      ├─ Effect: GIFT_WRAPS
      └─ item:remove(1)
```

## Fluxo de Operação

### Operação Principal

```lua
local settings = {
	[6570] = { { 3598, 10 }, 6393, 6279, 6574, 6578, 6575, 6577, 6569, 6576, 6572, 2995, 14027, 14681 },
	[6571] = { 6574, 3079, 6393, 6576, 6578, 2995, 14027, 3036, 5944, 3386, 3420, 3039, 5080, 2993, 3392, 3057, 5791 },
	[8853] = { { 3031, 10 }, 123, 2995, 2397, 651, 3218, 6574, 6393, 7377, 3578, 8778 },
	[14751] = { { 9642, 15 }, { 3581, 15 }, 5917, 3273, 10302, 9019, 5928, 5926, 5927, 6095, 5918, 6097, 6098, 5461, 5090 },
	[14759] = { { 6569, 10 }, { 6541, 10 }, { 6542, 10 }, { 6543, 10 }, { 6544, 10 }, { 6545, 10 }, 6574, 4839, 6570, 6571, 3215 },
}

function surpriseBag.onUse(player, item, fromPosition)
	-- Carrega config da bag
	local present = settings[item.itemid]
	if not present then
		return true
	end

	-- Seleção aleatória entre items
	local gift = present[math.random(#present)]
	local count = 1

	-- Se item é tabela, extrai ID e quantidade aleatória
	if type(gift) == "table" then
		count = math.random(gift[2])  -- Quantidade 1 até gift[2]
		gift = gift[1]  -- ID do item
	end

	-- Adicionar item ao jogador
	player:addItem(gift, count)
	
	-- Efeito visual
	fromPosition:sendMagicEffect(CONST_ME_GIFT_WRAPS)
	
	-- Consumir bag
	item:remove(1)
	return true
end
```

### Árvore de Decisão

```
Jogador abre surprise_bag
  │
  ├─ present = settings[item.itemid]?
  │   └─ NÃO → return true (bag desconhecida)
  │
  ├─ SIM → Seleciona gift:
  │   └─ gift = present[random(1, #present)]
  │
  ├─ Processar gift:
  │   ├─ type(gift) == "table"?
  │   │   ├─ SIM → Quantidade variável
  │   │   │   ├─ count = random(1, gift[2])
  │   │   │   └─ gift = gift[1] (ID)
  │   │   │
  │   │   └─ NÃO → count = 1 (fixo)
  │
  ├─ Adicionar ao inventário:
  │   └─ addItem(gift, count)
  │
  ├─ Efeito:
  │   └─ GIFT_WRAPS
  │
  ├─ Consumir bag:
  │   └─ item:remove(1)
  │
  └─ return true
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Config Table Hierárquica**: Bag ID → array de items
- **RNG Puro**: `math.random(#present)` para seleção equiprobável
- **Type Checking**: `type(gift) == "table"` para diferenciar fixo/variável
- **Table Unpacking**: gift[1] = ID, gift[2] = max quantity
- **Random Range**: `math.random(max)` para quantidade 1 até max
- **addItem()**: Adiciona quantidade especificada
- **fromPosition**: Efeito na posição original da bag
- **Dynamic Item Lists**: Fácil adicionar/remover items por config

### Responsabilidades do Handler

1. **Carregar config**: settings[item.itemid]
2. **Validar bag**: Verificar se bag existe
3. **Seleção RNG**: math.random(#present) para equiprobável
4. **Type check**: Diferençar items fixos vs variáveis
5. **Extrair dados**: gift[1] = ID, gift[2] = max
6. **Quantidade**: Default 1 ou random até max
7. **Adicionar**: addItem(ID, count)
8. **Efeito visual**: GIFT_WRAPS
9. **Consumir**: remove(1)
