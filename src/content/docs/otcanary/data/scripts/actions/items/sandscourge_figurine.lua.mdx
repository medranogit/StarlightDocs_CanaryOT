## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa figurinha que desbloqueia o familiar Sandscourge, exclusivo para Paladinos. Inclui três validações sequenciais: vocação (PALADIN), nível (200+) OU premium, e verificação de duplication. Usa setFamiliarLooktype() + addFamiliar() para ativar o familiar.

### Estrutura de Funcionalidades

```
sandscourgeFigurine (Action)
  ├─ Validação 1: vocação == PALADIN?
  │   └─ NÃO → reject
  │
  ├─ Validação 2: level 200+ OR premium?
  │   └─ NÃO → reject (silencioso)
  │
  ├─ Validação 3: looktype ainda não definido?
  │   └─ Sim → setFamiliarLooktype(1366)
  │
  ├─ Validação 4: não tem familiar 1366?
  │   ├─ SIM → addFamiliar(1366) + mensagem
  │   └─ NÃO → mensagem "already have"
  │
  ├─ Consumir: item:remove(1)
  └─ register() → ID 35590
```

## Fluxo de Operação

### Operação Principal

```lua
function sandscourgeFigurine.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação 1: Vocação obrigatória
	if player:getVocation():getBaseId() ~= VOCATION.BASE_ID.PALADIN then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Only paladins can use this item.")
		return true  -- Item NÃO removido
	end
	
	-- Validação 2: Level 200+ OU Premium
	if player:getLevel() < 200 and not player:isPremium() then
		return true  -- Rejeição silenciosa se não passa
	end
	
	-- Validação 3: Definir looktype se não está definido
	if player:getFamiliarLooktype() == 0 then
		player:setFamiliarLooktype(1366) -- Sandscourge looktype
	end
	
	-- Validação 4: Adicionar familiar ou avisar se já tem
	if not player:hasFamiliar(1366) then
		player:addFamiliar(1366) -- Sandscourge looktype
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You have summoned a Sandscourge.")
	else
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You already have a Sandscourge.")
	end
	
	-- Consumir item sempre
	item:remove(1)
	return true
end
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Class-Exclusive**: Validação de `getVocation():getBaseId()` para restricão vocacional
- **Level OR Premium**: Lógica `<200 AND NOT premium` (equivalente a `>=200 OR premium`)
- **Silent Rejection**: Return true sem mensagem para rejeições secundárias
- **getFamiliarLooktype()**: Retorna 0 se nenhum looktype está definido
- **setFamiliarLooktype()**: Define o visual do familiar antes de adicionar
- **hasFamiliar()**: Verifica se jogador já tem este familiar específico
- **addFamiliar()**: Adiciona novo familiar (combina com setFamiliarLooktype)
- **Item Always Removed**: item:remove(1) ocorre em TODOS os paths (sucesso ou falha com silent)

### Responsabilidades do Handler

1. **Validar vocação**: getVocation():getBaseId() == PALADIN
2. **Rejeitar se inválido**: Retornar com mensagem clara
3. **Validar level/premium**: Level 200+ OU isPremium()
4. **Rejeitar se insuficiente**: Retornar silenciosamente
5. **Definir looktype**: setFamiliarLooktype(1366) se não está definido
6. **Verificar duplication**: hasFamiliar(1366) antes de adicionar
7. **Adicionar ou avisar**: addFamiliar() ou mensagem "already have"
8. **Consumir item**: item:remove(1) sempre

### Validação Level OU Premium

```
Interpretação atual:
  └─ if getLevel() < 200 AND NOT isPremium() then reject

Equivalência:
  └─ if getLevel() >= 200 OR isPremium() then allow

Matrixu de Verdade:
  Level 200+ | Premium | Resultado
  --- | --- | ---
  Sim | Sim | ✅ Allow
  Sim | Não | ✅ Allow
  Não | Sim | ✅ Allow
  Não | Não | ❌ Reject
```
