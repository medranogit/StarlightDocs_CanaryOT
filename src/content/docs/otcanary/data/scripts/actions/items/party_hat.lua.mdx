## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa um handler de ação para um item do tipo "party hat" que valida se o item está equipado na head slot do jogador e aplica um efeito visual junto com progresso de achievement. O sistema funciona apenas quando o item está equipado corretamente.

## Fluxo de Operação

### Operação Principal

```lua
function partyHat.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Obtém item equipado na cabeça
	local headSlotItem = player:getSlotItem(CONST_SLOT_HEAD)
	
	-- Valida se item existe E se UID match (item deve estar equipado)
	if not headSlotItem or item.uid ~= headSlotItem:getUniqueId() then
		return false
	end

	-- Se validação passa: aplica efeito + achievement
	player:getPosition():sendMagicEffect(CONST_ME_GIFT_WRAPS)
	player:addAchievementProgress("Party Animal", 200)
	return true
end
```

### Árvore de Decisão

```
Jogador ativa party_hat
  │
  ├─ headSlotItem existe? NÃO → return false (item não está equipado)
  │
  ├─ headSlotItem UID = item UID? NÃO → return false (item diferente)
  │
  └─ SIM (item validado como equipado)
      ├─ Efeito visual: GIFT_WRAPS (posição do jogador)
      ├─ Achievement "Party Animal" +200
      └─ return true (sucesso)
```

### Validação de Equipamento

O script implementa um mecanismo de validação de equip verificando:

1. **Existência do Item**: `not headSlotItem` → item não está equipado
2. **Correspondência de ID**: `item.uid ~= headSlotItem:getUniqueId()` → UID deve match exatamente

Esta validação dupla garante que apenas o party_hat equipado na cabeça possa ativar o efeito, prevenindo uso de cópias em inventário.
