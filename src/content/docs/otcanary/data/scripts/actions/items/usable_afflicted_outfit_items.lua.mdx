## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa sistema complexo de 3 caminhos distintos (paths) para o outfit Afflicted:
- **Path 1** (ID 12786): Addon máscara - requer outfit 430/431 já desbloqueado
- **Path 2** (ID 12787): Addon sino - requer outfit 430/431 já desbloqueado 
- **Path 3** (IDs 12551-12556): Unlock outfit completo - requer 6 items específicos

Todas as paths exigem premium, incluem validação de outfit e achievement "Beak Doctor" +2.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ usableOutfit.onUse()
      ├─ isPremium() check global (bloqueia se não premium)
      │
      ├─ if item.id == 12786:
      │   └─ PATH 1: Addon Máscara
      │       ├─ hasOutfit(430) ou hasOutfit(431)?
      │       ├─ addOutfitAddon(430, 2) + addOutfitAddon(431, 2)
      │       ├─ Achievement: +2 "Beak Doctor"
      │       └─ item:remove(1)
      │
      ├─ elseif item.id == 12787:
      │   └─ PATH 2: Addon Sino
      │       ├─ hasOutfit(430) ou hasOutfit(431)?
      │       ├─ addOutfitAddon(430, 1) + addOutfitAddon(431, 1)
      │       ├─ Achievement: +2 "Beak Doctor"
      │       └─ item:remove(1)
      │
      └─ else:
          └─ PATH 3: Unlock Outfit (12551-12556)
              ├─ Loop verificar 6 items (getItemCount < 1?)
              ├─ Remover 6 items
              ├─ Outfit 430/431: addOutfit()
              ├─ Outfit 430/431 Addon 1+2: addOutfitAddon()
              ├─ Achievement: +2 "Beak Doctor"
              └─ item:remove(1)
```

## Fluxo de Operação

### Operação Principal

```lua
local afflictedMaskId = 12786
local afflictedBellId = 12787
local afflictedOutfitIds = { 12551, 12552, 12553, 12554, 12555, 12556 }

function usableOutfit.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação global: Premium obrigatório
	if not player:isPremium() then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "This item requires a premium account.")
		return true
	end

	-- Outfit base (430 = female, 431 = male, sempre adiciona ambas)
	local outfit = player:getSex() == PLAYERSEX_FEMALE and 430 or 431

	-- ============= PATH 1: ADDON MÁSCARA =============
	if item:getID() == afflictedMaskId then
		-- Validação: Outfit já desbloqueado?
		if not player:hasOutfit(outfit) then
			player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
			  "You need to unlock the Afflicted outfit first.")
			return true
		end

		-- Aplicar addon tipo 2 (máscara)
		player:addOutfitAddon(430, 2)
		player:addOutfitAddon(431, 2)
		
		-- Achievement
		player:addAchievementProgress("Beak Doctor", 2)
		
		-- Feedback
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
		  "You have unlocked a new mask addon for the Afflicted outfit.")
		
		-- Consumir item
		item:remove(1)
		return true
	end

	-- ============= PATH 2: ADDON SINO =============
	if item:getID() == afflictedBellId then
		-- Validação: Outfit já desbloqueado?
		if not player:hasOutfit(outfit) then
			player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
			  "You need to unlock the Afflicted outfit first.")
			return true
		end

		-- Aplicar addon tipo 1 (sino)
		player:addOutfitAddon(430, 1)
		player:addOutfitAddon(431, 1)
		
		-- Achievement
		player:addAchievementProgress("Beak Doctor", 2)
		
		-- Feedback
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
		  "You have unlocked a new bell addon for the Afflicted outfit.")
		
		-- Consumir item
		item:remove(1)
		return true
	end

	-- ============= PATH 3: UNLOCK OUTFIT =============
	-- (Se não é mask ou bell, tenta unlock)
	
	-- Validação: Verificar se tem todos os 6 items
	for _, itemId in ipairs(afflictedOutfitIds) do
		if player:getItemCount(itemId) < 1 then
			player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
			  "You need all Afflicted outfit pieces to unlock it.")
			return true
		end
	end

	-- Remover os 6 items
	for _, itemId in ipairs(afflictedOutfitIds) do
		player:removeItem(itemId, 1)
	end

	-- Adicionar outfit (ambos os gêneros)
	if player:getSex() == PLAYERSEX_FEMALE then
		player:addOutfit(430)
	else
		player:addOutfit(431)
	end

	-- Adicionar ambos os addons (tipo 1 + 2)
	player:addOutfitAddon(430, 1)
	player:addOutfitAddon(430, 2)
	player:addOutfitAddon(431, 1)
	player:addOutfitAddon(431, 2)

	-- Achievement
	player:addAchievementProgress("Beak Doctor", 2)

	-- Feedback
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
	  "You have unlocked the Afflicted outfit and all its addons!")

	-- Item consumido (qualquer um dos 6)
	item:remove(1)
	return true
end
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Premium Mandatory**: isPremium() no início bloqueia tudo
- **Multi-Path Handler**: 3 branches distintas em 1 função
- **Outfit Addons**: addOutfitAddon() incrementa addon selecionado
- **Gender Detection**: getSex() determina outfit base (mas ambas aplicadas)
- **6-Item Cost**: Loop de validação + loop de remoção
- **hasOutfit()**: Verifica se outfit já está desbloqueado
- **Achievement Progress**: addAchievementProgress() para tracking
- **Outfit + Addons**: Unlock completo = outfit + addon 1 + addon 2

### Responsabilidades do Handler

**Fase Global:**
1. Validar premium: isPremium()
2. Detectar gênero: getSex()
3. Aplicar outfit base

**Path 1 (Máscara):**
4. Validar outfit existe: hasOutfit()
5. Adicionar addon tipo 2: addOutfitAddon(430, 2) + (431, 2)
6. Achievement: +2
7. Consumir item

**Path 2 (Sino):**
8. Validar outfit existe: hasOutfit()
9. Adicionar addon tipo 1: addOutfitAddon(430, 1) + (431, 1)
10. Achievement: +2
11. Consumir item

**Path 3 (Outfit):**
12. Validar 6 items: getItemCount() >= 1 para todos
13. Remover 6 items: removeItem(id, 1) em loop
14. Adicionar outfit: addOutfit(430 ou 431)
15. Adicionar addons: 1+2 em ambos os gêneros
16. Achievement: +2
17. Consumir item (qualquer um dos 6)

## Patterns e Implementação

### Padrão Multi-Path

Este script demonstra 3 caminhos em 1 handler:

```lua
-- PATH 1
if item:getID() == afflictedMaskId then
	-- Lógica máscara
	return true
end

-- PATH 2
if item:getID() == afflictedBellId then
	-- Lógica sino
	return true
end

-- PATH 3 (else implícito)
-- Lógica outfit unlock
return true
```

### Padrão 6-Item Cost

Validação + remoção:

```lua
-- Validação
for _, itemId in ipairs(afflictedOutfitIds) do
	if player:getItemCount(itemId) < 1 then
		return true  -- Falha silenciosa
	end
end

-- Remoção
for _, itemId in ipairs(afflictedOutfitIds) do
	player:removeItem(itemId, 1)
end
```

### Padrão Outfit Addon

Aplicação em ambos os gêneros:

```lua
player:addOutfitAddon(430, 2)  -- Feminino + tipo 2
player:addOutfitAddon(431, 2)  -- Masculino + tipo 2
```
