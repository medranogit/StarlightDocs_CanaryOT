## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa um handler para um item consumível (party trumpet) que produz um som, envia efeito visual, transforma o item em uma versão diferente e o decai automaticamente. É um exemplo simples de item one-use com transformação.

### Estrutura de Funcionalidades

```
partyTrumpet (Action)
  ├─ onUse(player, item, fromPosition, target, toPosition, isHotkey)
  │   ├─ say("TOOOOOOT!", TALKTYPE_MONSTER_SAY)
  │   ├─ sendMagicEffect(CONST_ME_SOUND_BLUE)
  │   ├─ transform(6573)
  │   ├─ decay()
  │   └─ return true
  └─ register() → ID 6572
```

## Fluxo de Operação

### Operação Principal

```lua
function partyTrumpet.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Jogador diz som de trombeta
	player:say("TOOOOOOT!", TALKTYPE_MONSTER_SAY)
	
	-- Efeito visual/som na posição original do item
	fromPosition:sendMagicEffect(CONST_ME_SOUND_BLUE)
	
	-- Transforma item em versão diferente
	item:transform(6573)
	
	-- Item começa decaimento automático
	item:decay()
	
	return true
end
```

### Árvore de Decisão

```
Jogador ativa party_trumpet (6572)
  │
  ├─ say("TOOOOOOT!", TALKTYPE_MONSTER_SAY)
  │   └─ Mensagem audível para jogadores próximos
  │
  ├─ sendMagicEffect(CONST_ME_SOUND_BLUE) na fromPosition
  │   └─ Efeito visual instantâneo
  │
  ├─ transform(6573)
  │   └─ Item muda para versão 6573
  │
  ├─ decay()
  │   └─ Inicia decaimento automático
  │
  └─ return true (sempre sucesso)
```

### Transformação e Decaimento

O item passa por dois estágios:

1. **Transformação**: `item:transform(6573)` muda ID do item (6572 → 6573)
2. **Decaimento**: `item:decay()` inicia processo de destruição automática

Esta sequência permite que el item permaneça visível por um tempo (no estado 6573) antes de desaparecer completamente, criando experience visual melhorada.

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Consumível One-Use**: Item que é consumido quando ativado
- **say()**: Função que faz player "falar" com tipo específico (TALKTYPE_MONSTER_SAY)
- **Magic Effects**: Efeitos visuais enviados a posições (fromPosition)
- **Transform**: Método para mudar ID do item mantendo posição/container
- **Decay**: Função que agenda destruição automática do item
- **fromPosition**: Posição original do item antes de ser usado
- **Return Always True**: Item consumível sempre retorna sucesso

### Responsabilidades do Handler

1. **Produzir som**: Executar fala "TOOOOOOT!" visível para outros jogadores
2. **Efeito visual**: Enviar efeito SOUND_BLUE à posição original
3. **Transformar item**: Mudar item de 6572 para 6573
4. **Iniciar decaimento**: Agendar destruição automática do item
5. **Confirmar ação**: Sempre retornar true (operação bem-sucedida)

## Patterns e Implementação

### Padrão de Item Consumível

Este script demonstra o padrão básico de consumível:

```lua
-- 1. Produzir feedback ao jogador
player:say("TOOOOOOT!", TALKTYPE_MONSTER_SAY)
fromPosition:sendMagicEffect(CONST_ME_SOUND_BLUE)

-- 2. Transformar item

-- 3. Agendar destruição
item:decay()

-- 4. Confirmar sucesso
return true
```

### Comparação: Party Trumpet vs Party Hat

| Aspecto | Party Trumpet | Party Hat |
