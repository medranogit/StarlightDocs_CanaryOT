## 📄 Visão Geral do Código

**Resumo Executivo**

O script `cup_of_molten_gold.lua` implementa ferramenta de decoração com 10% sucesso. Aplica ouro em fir cones (ID 3614 ou 19111) para criar versão dourada (item 12550). Com sucesso, item transformado ou adicionado. Com falha (90%), envia mensagem e consome material (cup ou target). Diferencia tratamento para materiais raros vs comuns.

**Estrutura de Funcionalidades**

```
[Create cupOfMoltenGold Action]
    ↓
[onUse function]
    ├─ targetId = target.itemid
    ├─ Not in {3614, 19111}?
    │   └─ return false
    ├─ random(100) <= 10?
    │   ├─ SIM (10% chance)
    │   │   ├─ transformedItemId = 12550
    │   │   ├─ If targetId == 19111
    │   │   │   └─ item:transform(12550)
    │   │   └─ Else
    │   │       └─ player:addItem(12550, 1)
    │   └─ NÃO (90% chance)
    │       ├─ sendTextMessage(failure)
    │       ├─ If targetId == 19111
    │       │   └─ target:remove(1)
    │       └─ item:remove(1)
    └─ return true
```

## Funções

### cupOfMoltenGold.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que tenta cobrir item com ouro.

**Parâmetros:**
- player: Creature player
- item: Cup de ouro sendo usado
- fromPosition: Posição do uso
- target: Item alvo para cobrir
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo de Execução:**

```lua
1. Get targetId = target.itemid

2. Check if targetId in {3614, 19111}
   ├─ NÃO → return false
   └─ SIM → continuar

3. if random(100) <= 10 then (10% sucesso)
   ├─ transformedItemId = 12550
   ├─ If targetId == 19111
   │   └─ item:transform(12550)
   │       [transforma target em dourado]
   └─ Else
       └─ player:addItem(12550, 1)
           [adiciona novo item ao inventory]
   
4. else (90% falha)
   ├─ sendTextMessage(failure message)
   ├─ If targetId == 19111
   │   └─ target:remove(1)
   │       [remove item raro]
   └─ item:remove(1)
       [remove cup]

5. return true
```

**Implementação:**

```lua
function cupOfMoltenGold.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local targetId = target.itemid
	if not table.contains({ 3614, 19111 }, targetId) then
		return false
	end

	if math.random(100) <= 10 then
		local transformedItemId = 12550
		if targetId == 19111 then
			item:transform(transformedItemId)
		else
			player:addItem(transformedItemId, 1)
		end
	else
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Drizzling all over a fir cone you picked from the tree, the molten gold only covers about half of it - not enough.")

		if targetId == 19111 then
			target:remove(1)
		end

		item:remove(1)
	end
	return true
end
```

## Target Handling

### Fir Cone 3614 (comum)

- Sucesso: player:addItem(12550, 1)
  - Não consome target (deixa no chão)
  - Cria novo item 12550 no inventory
  
- Falha: Apenas consome cup
  - Item target permanece (não consumido)

### Fir Cone 19111 (raro)

- Sucesso: item:transform(12550)
  - Transforma item no target
  
- Falha: target:remove(1)
  - Consome item raro (punição por falha)
  - Ainda consome cup

**Diferenciação**: Itens raros têm transição in-place; itens comuns geram novo item.
