## 📄 Visão Geral do Código

**Resumo Executivo**

O script `mossmasher_figurine.lua` implementa figurinha temática para druid com desbloquio de familiar Mossmasher. Validações: class druid (VOCATION.BASE_ID.DRUID), level 200+ OU premium account (premium ignora level). Primeiro uso seta looktype 1364, addFamiliar desbloqueia. Se já tem familiar, reject. Consumido ao usar.

**Estrutura de Funcionalidades**

```
[Create mossmasherFigurine Action]
    ↓
[onUse function]
    ├─ Validação 1: Vocação Druid?
    │   ├─ getNot druid? 
    │   │   └─ "Only druids can use this item."
    │   │   └─ return true
    │   └─ SIM Druid → continuar
    ├─ Validação 2: Level 200+ or Premium?
    │   ├─ level < 200 AND not premium?
```

### mossmasherFigurine.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback que desbloqueia familiar.

**Parâmetros:**
- player: Creature player
- item: Figurinha sendo usada
- fromPosition: Posição original
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo:**

```lua
1. if player:getVocation():getBaseId() ~= VOCATION.BASE_ID.DRUID
   ├─ "Only druids can use this item."
   └─ return true

2. if player:getLevel() < 200 and not player:isPremium()
   └─ return true (silencioso)

3. if player:getFamiliarLooktype() == 0
   └─ setFamiliarLooktype(1364)

4. if not player:hasFamiliar(1364)
   ├─ addFamiliar(1364)
   ├─ "You have summoned a Mossmasher."
   └─ return true

5. else
   ├─ "You already have a Mossmasher."
   └─ return true

6. item:remove(1)
```

**Implementação:**

```lua
function mossmasherFigurine.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	if player:getVocation():getBaseId() ~= VOCATION.BASE_ID.DRUID then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Only druids can use this item.")
		return true
	end
	if player:getLevel() < 200 and not player:isPremium() then
		return true
	end
	if player:getFamiliarLooktype() == 0 then
		player:setFamiliarLooktype(1364) -- Mossmasher looktype
	end
	if not player:hasFamiliar(1364) then
		player:addFamiliar(1364) -- Mossmasher looktype
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You have summoned a Mossmasher.")
	else
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You already have a Mossmasher.")
	end
	item:remove(1)
	return true
end
```
