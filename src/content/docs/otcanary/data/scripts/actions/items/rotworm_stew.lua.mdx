## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa consumível que restaura 100% da vida máxima do jogador. Utiliza cooldown compartilhado "special-foods-cooldown" (10 min) com outras comidas especiais. Inclui validação de cooldown antes de permitir uso, efeito visual, emote e mensagem customizada. Um poderoso item de healing com restrição temporal.

## Fluxo de Operação

### Operação Principal

```lua
function rotwormStew.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação de cooldown
	if player:hasExhaustion("special-foods-cooldown") then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You need to wait before using it again.")
		return true  -- Item NÃO removido
	end

	-- Full heal
	player:addHealth(player:getMaxHealth())
	
	-- Feedback ao jogador
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Your health has been refilled.")
	player:say("Gulp.", TALKTYPE_MONSTER_SAY)
	
	-- Efeito visual
	player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)
	
	-- Ativar cooldown compartilhado
	player:setExhaustion("special-foods-cooldown", 10 * 60)
	
	-- Consumir item
	item:remove(1)
	return true
end
```

```

  └─ player:getHealth() = X (qualquer valor)

  ├─ addHealth(getMaxHealth()) chamado
  ├─ Health aumenta por MaxHealth
  └─ Resultado: Health = min(current + MaxHealth, MaxHealth) = MaxHealth
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Full Heal Pattern**: `player:addHealth(player:getMaxHealth())` restaura 100% da vida
- **Cooldown Compartilhado**: Múltiplos items especiais usam "special-foods-cooldown"
- **Return True Sem Consumir**: Se cooldown bloqueia, return true MAS item não é removido
- **hasExhaustion()**: Verifica se jogador está em cooldown
- **setExhaustion()**: Ativa cooldown de X segundos
- **getMaxHealth()**: Obtém HP máximo do jogador (dinâmico por level)
- **Emote + Message**: Duplo feedback (visual + texto)
- **MAGIC_RED Effect**: Efeito visual para comidas/potências especiais

### Responsabilidades do Handler

1. **Validar cooldown**: hasExhaustion("special-foods-cooldown")
2. **Bloquear graciosamente**: Se em cooldown, return true sem remover item
3. **Restaurar vida**: addHealth(getMaxHealth()) para full heal
4. **Enviar mensagens**: Notificação de cura completa
5. **Produzir emote**: "Gulp." audível a outros
6. **Efeito visual**: MAGIC_RED na posição do jogador
7. **Ativar cooldown**: setExhaustion(10 min)
8. **Consumir item**: remove(1)

Este script demonstra comida especial com pool de cooldown:

