## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa comida que aplica condition de melee +10 durante 60 minutos. A condition é compilada localmente (meleeCondition) com CONDITION_ATTRIBUTES e SKILL_MELEE. Usa cooldown compartilhado "special-foods-cooldown" (10 min), efeito MAGIC_RED, emote "Yum." e mensagem "You feel stronger."

### Estrutura de Funcionalidades

```
LOCAL CONDITION:
  └─ meleeCondition (Condition object)
      ├─ CONDITION_ATTRIBUTES
      ├─ SUBID: JeanPierreMelee
      ├─ BUFF_SPELL: 1 (não-dispelável)
      ├─ TICKS: 60*60*1000 ms (1 hora)
      ├─ SKILL_MELEE: +10
      └─ FORCEUPDATE: true

HANDLER:
  └─ veggieCasserole.onUse()
      ├─ hasExhaustion("special-foods-cooldown")?
      │   └─ SIM → bloqueado
      ├─ addCondition(meleeCondition)
      ├─ Message: "You feel stronger."
      ├─ Emote: "Yum."
      ├─ Effect: MAGIC_RED
      ├─ setExhaustion(10 min)
      ├─ item:remove(1)
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
-- Condition compilada localmente
local meleeCondition = Condition(CONDITION_ATTRIBUTES)
meleeCondition:setParameter(CONDITION_PARAM_SUBID, JeanPierreMelee)
meleeCondition:setParameter(CONDITION_PARAM_BUFF_SPELL, 1)
meleeCondition:setParameter(CONDITION_PARAM_TICKS, 60 * 60 * 1000)
meleeCondition:setParameter(CONDITION_PARAM_SKILL_MELEE, 10)
meleeCondition:setParameter(CONDITION_PARAM_FORCEUPDATE, true)

local veggieCasserole = Action()

function veggieCasserole.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação: Cooldown compartilhado
	if player:hasExhaustion("special-foods-cooldown") then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You need to wait before using it again.")
		return true
	end

	-- Aplicar condition
	player:addCondition(meleeCondition)

	-- Feedback ao jogador
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You feel stronger.")
	player:say("Yum.", TALKTYPE_MONSTER_SAY)

	-- Efeito visual
	player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)

	-- Ativar cooldown
	player:setExhaustion("special-foods-cooldown", 10 * 60)

	-- Consumir item
	item:remove(1)
	return true
end

veggieCasserole:id(9084)
veggieCasserole:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Condition Compile**: Compilação local no início do script
- **CONDITION_ATTRIBUTES**: Para modificar skills/stats
- **SKILL_MELEE**: Adiciona ao fighting skill
- **BUFF_SPELL**: Valor 1 = buff permanente (não-dispel)
- **FORCEUPDATE**: true para UI atualizar sem delay
- **Shared Cooldown**: "special-foods-cooldown" afeta todas as comidas
- **hasExhaustion()**: Verifica se em cooldown antes de usar
- **return true se bloqueado**: Sem consumir item
- **Auto Expiration**: Condition expira após ticks

### Responsabilidades do Handler

1. **Validar cooldown**: hasExhaustion("special-foods-cooldown")
2. **Rejeitar se bloqueado**: return true (sem consumir)
3. **Aplicar buff**: addCondition(meleeCondition)
4. **Mensagem**: "You feel stronger."
5. **Emote**: "Yum." audível
6. **Efeito visual**: MAGIC_RED
7. **Ativar cooldown**: setExhaustion(10 min)
8. **Consumir item**: remove(1)
