## 📄 Visão Geral do Código

**Resumo Executivo**

O script `change_gold.lua` implementa sistema econômico de conversão de moedas com suporte a 3 níveis de denominação: ouro, platina e cristal. Cada nível pode converter "para cima" (mais valiosa, 100x volume) e alguns podem converter "para baixo" (menos valiosa, 1x = 100 anteriores). Validações de stack size garantem conversão correta.

**Estrutura de Funcionalidades**

```
[Define config table]
    ├─ ITEM_GOLD_COIN
    │   └─ changeTo: ITEM_PLATINUM_COIN
    ├─ ITEM_PLATINUM_COIN
    │   ├─ changeBack: ITEM_GOLD_COIN
    │   └─ changeTo: ITEM_CRYSTAL_COIN
    └─ ITEM_CRYSTAL_COIN
        └─ changeBack: ITEM_PLATINUM_COIN
    ↓
[Create changeGold Action]
    ↓
[onUse function]
    ├─ Get coin config por item ID
    ├─ IF changeTo AND stack = 100
    │   ├─ item:remove()
    │   ├─ player:addItem(changeTo, 1)
    │   └─ return true
    ├─ ELSEIF changeBack
    │   ├─ item:remove(1)
    │   ├─ player:addItem(changeBack, 100)
    │   └─ return true
    └─ ELSE return false
    ↓
[Register Action on 3 coin IDs]
    ├─ ITEM_GOLD_COIN
    ├─ ITEM_PLATINUM_COIN
    └─ ITEM_CRYSTAL_COIN
```

## Variáveis Globais

### config (local table)

```lua
local config = {
	[ITEM_GOLD_COIN] = { changeTo = ITEM_PLATINUM_COIN },
	[ITEM_PLATINUM_COIN] = { changeBack = ITEM_GOLD_COIN, changeTo = ITEM_CRYSTAL_COIN },
	[ITEM_CRYSTAL_COIN] = { changeBack = ITEM_PLATINUM_COIN },
}
```

Mapeamento de conversões de moedas.

**Estrutura:**

| Item | changeTo | changeBack | Descrição |
|------|----------|-----------|-----------|
| Gold Coin | Platinum | - | Upgrade para platina |
| Platinum Coin | Crystal | Gold | Upgrade/Downgrade |
| Crystal Coin | - | Platinum | Downgrade para platina |

**Regras:**
- Gold: só sobe para Platinum (1 → 100x menos)
- Platinum: sobe para Crystal ou desce para Gold
- Crystal: só desce para Platinum (100x mais)

## Funções

### changeGold.onUse(player, item, fromPosition, target, toPosition, isHotkey)

Callback acionado ao usar moeda para conversão.

**Parâmetros:**
- player: Creature player
- item: Moeda sendo convertida
- fromPosition: Posição do uso
- target: Target opcional
- toPosition: Posição destino
- isHotkey: Boolean se via hotkey

**Fluxo de Execução:**

```lua
1. Get coin config
   └─ coin = config[item:getId()]
   
2. IF changeTo AND item.type == 100
   ├─ item:remove() [remove full stack]
   ├─ player:addItem(coin.changeTo, 1) [add 1 de nova moeda]
   └─ return true
   
3. ELSEIF changeBack
   ├─ item:remove(1) [remove 1 unidade]
   ├─ player:addItem(coin.changeBack, 100) [add 100 de moeda menor]
   └─ return true
   
4. ELSE
   └─ return false
```

**Implementação:**

```lua
function changeGold.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	local coin = config[item:getId()]
	if coin.changeTo and item.type == 100 then
		item:remove()
		player:addItem(coin.changeTo, 1)
		return true
	elseif coin.changeBack then
		item:remove(1)
		player:addItem(coin.changeBack, 100)
		return true
	end
	return false
end
```

## Validações e Regras

### Validação: item.type == 100

```lua
if coin.changeTo and item.type == 100 then
```

Garante que upgrade (changeTo) só ocorre com stack completo (100 moedas).

**Razão**: Evita conversão parcial ou error.

**Efeito**: Player precisa de stack exato para converter para cima.

### Downgrade (changeBack)

```lua
elseif coin.changeBack then
	item:remove(1)
	player:addItem(coin.changeBack, 100)
```

Downgrade não precisa de validação stack - apenas remove 1 e adiciona 100.
