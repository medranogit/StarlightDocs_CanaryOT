## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper mínimo que abre a interface de stash pessoal. Registra 1 stash object que quando ativado dispara player:openStash(). Sem validações, sem lógica local, completamente transparente. Padrão idêntico ao market.lua.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ stash.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      ├─ player:openStash()
      │   └─ (abre UI de stash externa)
      └─ return true

REGISTRO:
  └─ 1 stash ID (28750)
```

	return true

### Conceitos-chave

- **Wrapper Pattern**: Handler mínimo que delega

- **No Logic**: Sem validação local
- **Always True**: return true sempre

1. **Abrir UI**: player:openStash()
2. **Confirmar**: return true
