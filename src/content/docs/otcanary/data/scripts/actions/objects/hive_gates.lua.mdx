## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa sistema de portais de colmeia que teleportam jogador com ajuste automático de posição. Diferencia entre gates verticais (Y-axis, IDs 13278-13283) e horizontais (X-axis, IDs 13290-13294). Valida se movimento é possível no eixo (position.y == toPosition.y bloqueia vertical). Ajusta coordenada dinâmicamente (pata na frente vs atrás).

### Estrutura de Funcionalidades

```
VERTICAL GATES (Y-axis):
  ├─ 13278, 13279, 13280, 13281, 13282, 13283
  ├─ position.y == toPosition.y? → return false (bloqueado)
  ├─ toPosition.y = position.y > toPosition.y ? 
  │                    (toPosition.y - 1) : (toPosition.y + 1)
  └─ Teleporte com ajuste Y

HORIZONTAL GATES (X-axis):
  ├─ 13290, 13291, 13292, 13293, 13294
  ├─ position.x == toPosition.x? → return false (bloqueado)
  ├─ toPosition.x = position.x > toPosition.x ?
  │                    (toPosition.x - 1) : (toPosition.x + 1)
  └─ Teleporte com ajuste X

HANDLER:
  └─ hiveGates.onUse()
      ├─ position = player:getPosition()
      ├─ if vertical gates:
      │   ├─ position.y == toPosition.y? → false
      │   ├─ Ajusta toPosition.y (±1)
      ├─ elseif horizontal gates:
      │   ├─ position.x == toPosition.x? → false
      │   ├─ Ajusta toPosition.x (±1)
      ├─ player:teleportTo(toPosition)
      ├─ Effect: TELEPORT
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local hiveGates = Action()

function hiveGates.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Obter posição do jogador
	local position = player:getPosition()
	
	-- ========== VERTICAL GATES (Y-axis) ==========
	if item:getId() == 13278 or item:getId() == 13279 or 
	   item:getId() == 13280 or item:getId() == 13281 or 
	   item:getId() == 13282 or item:getId() == 13283 then
		-- Validação: Portal na mesma linha Y?
		if position.y == toPosition.y then
			return false  -- Bloqueado
		end

		-- Ajustar Y dinamicamente
		-- Se jogador está acima (menor Y), ir mais acima (Y-1)
		-- Se jogador está abaixo (maior Y), ir mais abaixo (Y+1)
		toPosition.y = position.y > toPosition.y and toPosition.y - 1 or toPosition.y + 1
	
	-- ========== HORIZONTAL GATES (X-axis) ==========
	elseif item:getId() == 13290 or item:getId() == 13291 or 
	       item:getId() == 13292 or item:getId() == 13293 or 
	       item:getId() == 13294 then
		-- Validação: Portal na mesma linha X?
		if position.x == toPosition.x then
			return false  -- Bloqueado
		end

		-- Ajustar X dinamicamente
		-- Se jogador está à esquerda (menor X), ir mais à esquerda (X-1)
		-- Se jogador está à direita (maior X), ir mais à direita (X+1)
		toPosition.x = position.x > toPosition.x and toPosition.x - 1 or toPosition.x + 1
	end

	-- Executar teleporte
	player:teleportTo(toPosition)
	toPosition:sendMagicEffect(CONST_ME_TELEPORT)
	return true
end

hiveGates:id(13278, 13279, 13280, 13281, 13282, 13283, 13290, 13291, 13292, 13293, 13294)
hiveGates:register()
```


### Position Adjustment Examples

```
Vertical Gate (Y-axis):

Jogador em Y=100, Gate em Y=95:
  ├─ position.y (100) > toPosition.y (95)? SIM
  ├─ toPosition.y = 95 - 1 = 94
  ├─ Teleporta para Y=94 (ainda acima do gate)
  └─ Efeito garante movimento

Jogador em Y=100, Gate em Y=105:
  ├─ position.y (100) > toPosition.y (105)? NÃO
  ├─ toPosition.y = 105 + 1 = 106
  ├─ Teleporta para Y=106 (abaixo do gate)
  └─ Efeito garante movimento

Horizontal Gate (X-axis):

Jogador em X=50, Gate em X=60:
  ├─ position.x (50) > toPosition.x (60)? 
  │   (jogador à esquerda do gate)
  ├─ SIM (não é) → NÃO (não é)
  ├─ toPosition.x = 60 + 1 = 61
  └─ Teleporta para X=61 (à direita do gate)
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Axis-based Gating**: Vertical validate Y, Horizontal validate X
- **Ternário Operator**: `condition and valueA or valueB`
- **Position Adjustment**: ±1 em eixo específico
- **Blocking Logic**: return false se movimento impossível
- **getPosition()**: Obtém coordinates do jogador
- **teleportTo()**: Teleporta com nova position
- **Multiple IDs**: 11 gates (6 vertical + 5 horizontal)
- **Automatic Direction**: Detecta em qual lado da porta está

### Responsabilidades do Handler

1. **Obter posição**: player:getPosition()
2. **Detectar tipo**: if vertical/horizontal gates
3. **Validar eixo**: position.axis == toPosition.axis? → false
4. **Ajustar posição**: ±1 no eixo apropriado
5. **Teleportar**: player:teleportTo(toPosition)
6. **Efeito**: TELEPORT
7. **Confirmar**: return true
