## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa sistema de estátuas de treinamento offline com lookup table: cada ID vinculado a 1 skill (sword, axe, club, distance, maglevel). Validações: premium account obrigatório (reject se não), PZ lock check (block se sim). Se passar: setOfflineTrainingSkill(skill) + player:remove() (logout). Cada estátua treina 1 skill diferente.

### Estrutura de Funcionalidades

```
LOOKUP TABLE:
  └─ setting[ID] = SKILL
      ├─ 16198 → SKILL_SWORD
      ├─ 16199 → SKILL_AXE
      ├─ 16200 → SKILL_CLUB
      ├─ 16201 → SKILL_DISTANCE
      └─ 16202 → SKILL_MAGLEVEL

HANDLER:
  └─ skillTrainer.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      ├─ skill = setting[item:getId()]
      ├─ isPremium()? → false: sendCancelMessage + return true
      ├─ isPzLocked()? → true: return false (bloqueia)
      ├─ setOfflineTrainingSkill(skill)
      ├─ player:remove(false) → logout
      └─ return true

REGISTRO:
  └─ 5 estátuas (16198-16202)
      └─ for-in loop dinâmico
```

## Fluxo de Operação

### Operação Principal

```lua
local setting = {
	[16198] = SKILL_SWORD,
	[16199] = SKILL_AXE,
	[16200] = SKILL_CLUB,
	[16201] = SKILL_DISTANCE,
	[16202] = SKILL_MAGLEVEL,
}

local skillTrainer = Action()

function skillTrainer.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Obter skill da lookup table
	local skill = setting[item:getId()]
	
	-- VALIDAÇÃO 1: Premium account obrigatório
	if not player:isPremium() then
		player:sendCancelMessage(RETURNVALUE_YOUNEEDPREMIUMACCOUNT)
		return true  -- Retorna true sem consumir item
	end

	-- VALIDAÇÃO 2: PZ lock (não pode estar preso)
	if player:isPzLocked() then
		return false  -- Retorna false (bloqueia)
	end

	-- OPERAÇÕES: Assignar skill e logout
	player:setOfflineTrainingSkill(skill)
	player:remove(false)  -- false = logout (não mata)
	return true
end

-- REGISTRO dinâmico
for index, value in pairs(setting) do
	skillTrainer:id(index)
end

skillTrainer:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Lookup Table**: ID -> Skill mapping
- **isPremium()**: Validação de conta premium
- **isPzLocked()**: Validação de prisão de proteção
- **setOfflineTrainingSkill()**: Assinala skill para treinamento
- **player:remove()**: Logout automático (false = não mata)
- **sendCancelMessage()**: Mensagem de erro padrão
- **for-in pairs()**: Iteração dinâmica de tabela
- **Dual Validation**: Premium obrigatório, PZ lock bloqueia

### Responsabilidades do Handler

1. **Obter skill**: setting[item:getId()]
2. **Validar premium**: isPremium() obrigatório
3. **Validar PZ**: isPzLocked() bloqueia
4. **Assignar skill**: setOfflineTrainingSkill(skill)
5. **Logout**: player:remove(false)
6. **Confirmar**: return true
