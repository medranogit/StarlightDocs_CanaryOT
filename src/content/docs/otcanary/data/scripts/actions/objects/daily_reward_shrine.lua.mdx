## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper mínimo que apenas delega para DailyReward.loadDailyReward(). Registra 6 shrine objects que quando ativados disparam o sistema de recompensas diárias com parâmetro 0. Sem validações, sem lógica local, completamente transparente ao sistema externo.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ dailyRewardShrine.onUse(player, item, fromPosition, itemEx, toPosition)
      ├─ DailyReward.loadDailyReward(player, 0)
      │   └─ (lógica externa em DailyReward module)
      └─ return true

REGISTRO:
  └─ 6 shrine IDs (25720, 25721, 25722, 25723, 25802, 25803)
```

## Fluxo de Operação

### Operação Principal

```lua
local dailyRewardShrine = Action()

function dailyRewardShrine.onUse(player, item, fromPosition, itemEx, toPosition)
	-- Delegar para módulo externo
	DailyReward.loadDailyReward(player, 0)
	return true
end

-- Registrar 6 shrine IDs
dailyRewardShrine:id(25720, 25721, 25722, 25723, 25802, 25803)
dailyRewardShrine:register()
```

### Execução

```
Jogador clica em shrine (25720-25723, 25802-25803)
  │
  └─ onUse() dispara
      ├─ DailyReward.loadDailyReward(player, 0)
      │   └─ Processa recompensa diária (lógica externa)
      └─ return true
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Wrapper Pattern**: Handler mínimo que delega
- **External Module**: DailyReward é módulo separado
- **Parameter Pass**: player + 0 passados ao módulo
- **Multiple IDs**: 6 shrines, 1 handler
- **No Local Logic**: Tudo delegado externamente
- **Always True**: return true (sem validação)

### Responsabilidades do Handler

1. **Delegar**: DailyReward.loadDailyReward(player, 0)
2. **Confirmar**: return true
