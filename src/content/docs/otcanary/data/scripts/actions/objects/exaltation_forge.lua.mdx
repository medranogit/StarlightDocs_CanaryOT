## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper mínimo que abre a interface de forja de exaltação. Registra 8 forge objects diferentes que quando ativados disparam player:openForge(). Sem validações, sem lógica local, completamente transparente.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ forge.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      ├─ player:openForge()
      │   └─ (abre UI de forja externa)
      └─ return true

REGISTRO:
  └─ 8 forge IDs (37122, 37128, 37129, 37131, 37132, 37133, 37153, 37157)
```

## Fluxo de Operação

### Operação Principal

```lua
local forge = Action()

function forge.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Abrir interface de forja
	player:openForge()
	return true
end

-- Registrar 8 forge IDs
forge:id(37122, 37128, 37129, 37131, 37132, 37133, 37153, 37157)
forge:register()
```

### Execução

```
Jogador ativa forge object
  │
  └─ onUse() dispara
      ├─ player:openForge()
      │   └─ Abre UI de forja
      └─ return true
```
