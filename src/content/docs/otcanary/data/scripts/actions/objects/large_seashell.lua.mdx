## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa concha interativa com RNG tri-branch: 16% chance de dano (200 HP fisico), 48% chance de pérola (item + achievement), 36% chance de nada. Cooldown daily compartilhado (20 horas). Após uso, transforma item para ID 198 e inicia decay automático. Diferentes mensagens por resultado.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ largeSeashell.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      ├─ hasExhaustion("delay-large-seashell")?
      │   └─ SIM → Message + return true
      ├─ chance = random(1-100)
      ├─ if chance <= 16 (16%):
      │   ├─ Dano: 200 HP physical
      │   ├─ Message: "Ouch! Squeezed fingers"
      │   └─ Achievement: nenhuma
      ├─ elseif chance > 16 && <= 64 (48%):
      │   ├─ Criar pérola (281 ou 282)
      │   ├─ Message: "Found beautiful pearl"
      │   └─ Achievement: "Shell Seeker" +100
      ├─ else (36%):
      │   └─ Message: "Nothing inside"
      ├─ Cooldown: 20h
      ├─ say(message)
      ├─ item:transform(198)
      ├─ item:decay()
      ├─ Effect: BUBBLES
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local largeSeashell = Action()

function largeSeashell.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação: Cooldown daily (20h)
	if player:hasExhaustion("delay-large-seashell") then
		player:say("You have already opened a shell today.", TALKTYPE_MONSTER_SAY, false, player, item:getPosition())
		return true
	end

	-- RNG: 1-100
	local chance = math.random(100)
	local message = "Nothing is inside."

	-- ========== BRANCH 1: DAMAGE (16%) ==========
	if chance <= 16 then
		doTargetCombatHealth(0, player, COMBAT_PHYSICALDAMAGE, -200, -200, CONST_ME_NONE)
		message = "Ouch! You squeezed your fingers."
	
	-- ========== BRANCH 2: PEARL (48%) ==========
	elseif chance > 16 and chance <= 64 then
		Game.createItem(math.random(281, 282), 1, player:getPosition())
		message = "You found a beautiful pearl."
		player:addAchievementProgress("Shell Seeker", 100)
	
	-- ========== BRANCH 3: NOTHING (36%) ==========
	-- else: message já é "Nothing is inside."
	end

	-- Efeitos finais
	player:setExhaustion("delay-large-seashell", 20 * 60 * 60)
	player:say(message, TALKTYPE_MONSTER_SAY, false, player, item:getPosition())
	item:transform(198)
	item:decay()
	item:getPosition():sendMagicEffect(CONST_ME_BUBBLES)
	return true
end

largeSeashell:id(197)
largeSeashell:register()
```

### RNG Probability

```
math.random(100) retorna 1-100 equiprobável

Branch 1 (Damage):
  └─ if chance <= 16
  └─ Probabilidade: 16/100 = 16.0%

Branch 2 (Pearl):
  └─ elseif chance > 16 && <= 64
  └─ Probabilidade: (64-16)/100 = 48/100 = 48.0%

Branch 3 (Nothing):
  └─ else (implícito)
  └─ Probabilidade: (100-64)/100 = 36/100 = 36.0%

Total: 16 + 48 + 36 = 100% ✓
```

Três outcomes com ranges:

```lua
local chance = math.random(100)
local message = "Nothing is inside."

if chance <= 16 then
	-- Branch 1 (16%)
elseif chance > 16 and chance <= 64 then
	-- Branch 2 (48%)
else
	-- Branch 3 (36%)
end
```
