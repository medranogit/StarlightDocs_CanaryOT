## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper mínimo que abre a interface de mercado. Registra 1 market object que quando ativado dispara player:openMarket(). Sem validações, sem lógica local, completamente transparente.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ market.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      ├─ player:openMarket()
      │   └─ (abre UI de mercado externa)
      └─ return true

REGISTRO:
  └─ 1 market ID (12903)
```

## Fluxo de Operação

### Operação Principal

```lua
local market = Action()

function market.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Abrir interface de mercado
	player:openMarket()
	return true
end

-- Registrar market ID
market:id(12903)
market:register()
```
