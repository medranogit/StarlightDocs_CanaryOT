## 📄 Visão Geral do Código

### Resumo Executivo

O script é handler trivial que transforma bathtub preenchida em vazia (drenagem). Valida que nenhuma criatura está na tile antes de permitir transform. Usa BATHTUB_FILLED e BATHTUB_EMPTY como constantes globais. Sem consumo de item, sem mensagem, apenas transform direto.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ bathtubDrain.onUse(player, item, fromPosition, itemEx, toPosition)
      ├─ tile = Tile(fromPosition)
      ├─ tile:getTopCreature()? (validação)
      │   └─ SIM → return false (bloqueado)
      ├─ NÃO → Continua
      ├─ item:transform(BATHTUB_EMPTY)
      │   └─ BATHTUB_FILLED → BATHTUB_EMPTY
      └─ (implicit return true)

REGISTRO:
  └─ ID: BATHTUB_FILLED
```

## Fluxo de Operação

### Operação Principal

```lua
local bathtubDrain = Action()

function bathtubDrain.onUse(player, item, fromPosition, itemEx, toPosition)
	-- Obter tile
	local tile = Tile(fromPosition)
	
	-- Validação: Criatura no topo?
	if tile:getTopCreature() then
		return false
	end

	-- Transform (sem remover, apenas muda ID)
	item:transform(BATHTUB_EMPTY)
end

-- Registrar
bathtubDrain:id(BATHTUB_FILLED)
bathtubDrain:register()
```

### Execução Simples

```
Jogador clica em bathtub preenchida

  │
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Tile Creation**: Tile(fromPosition) constrói objeto
- **getTopCreature()**: Verifica criatura no topo
- **Return False**: Bloqueia ação se criatura presente
- **item:transform()**: Muda versão sem remover
- **BATHTUB Constants**: Global IDs utilizados
- **No Explicit Return**: return true implícito ao fim
- **Simple Validation**: Apenas 1 check

### Responsabilidades do Handler

1. **Criar tile**: Tile(fromPosition)
2. **Validar criatura**: getTopCreature()
3. **Return false**: Se criatura presente
4. **Transform**: item:transform(BATHTUB_EMPTY)
