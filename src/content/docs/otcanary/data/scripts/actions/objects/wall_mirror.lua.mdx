## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa 8 espelhos de parede que exibem mensagens de vaidade aleatórias. Contém array de 11 mensagens pré-escritas (vaidade, beleza, aparência). Ao ativar: verifica cooldown 20h (delay-wall-mirror), se ativo exibe mensagem bloqueadora "Don't be so vain", se inativo seleciona mensagem aleatória via math.random(1, conta de mensagens), exibe via say() e assinala cooldown 20h. Padrão similar ao large_seashell mas sem RNG branches, apenas seleção de mensagem.

## Fluxo de Operação

### Operação Principal

```lua
local setting = {
	"You could win a beauty contest today!",
	"You rarely looked better.",
	"Well, you can't look good every day.",
	"You should think about a makeover.",
	"Is that the indication of a potbelly looming under your clothes?",
	"You look irresistible.",
	"You look tired.",
	"You look awesome!",
	"You nearly don't recognize yourself.",
	"You look fabulous.",
	"Surprise, surprise, you don't see yourself.",
}

local wallMirror = Action()

function wallMirror.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- VALIDAÇÃO: Cooldown 20h
	if player:hasExhaustion("delay-wall-mirror") then
		player:say("Don't be so vain about your appearance.", TALKTYPE_MONSTER_SAY)
		return true
	end

	-- RNG: Seleção de mensagem (1 de 11)
	player:say(setting[math.random(1, #setting)], TALKTYPE_MONSTER_SAY)
	
	-- ASSINALAR: Cooldown 20h
	player:setExhaustion("delay-wall-mirror", 20 * 60 * 60)
	return true
end

wallMirror:id(2603, 2604, 2630, 2631, 2633, 2634, 2636, 2637)
wallMirror:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Array with Messages**: setting[1-11] (11 options)
- **math.random(1, count)**: RNG simples com range
- **meta-length Operator**: #setting retorna tamanho
- **hasExhaustion()**: Validação de cooldown
- **setExhaustion()**: Assinala cooldown (20h neste caso)
- **say() Output**: Mensagem visível com TALKTYPE_MONSTER_SAY
- **Multiple IDs**: 8 espelhos diferentes
- **Blocked Message**: Mensagem fixa quando em cooldown

### Responsabilidades do Handler

1. **Validar cooldown**: hasExhaustion("delay-wall-mirror")
2. **Gerar RNG**: math.random(1, #setting)
3. **Obter mensagem**: setting[randomIdx]
4. **Exibir**: say(message, TALKTYPE_MONSTER_SAY)
5. **Assinalar**: setExhaustion(20h)
6. **Confirmar**: return true
