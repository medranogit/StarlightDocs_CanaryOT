## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper mínimo que delega toda a lógica para função externa onUseSpoon(). Registra 1 spoon tool que quando ativado simplesmente chama função externa passando todos os parâmetros direto. Sem lógica local, sem validações, completamente transparente.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ spoon.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      └─ return onUseSpoon(player, item, fromPosition, target, toPosition, isHotkey)
          └─ Função externa (não definida neste arquivo)

REGISTRO:
  └─ 1 spoon ID (3468)
```

## Fluxo de Operação

### Operação Principal

```lua
local spoon = Action()

function spoon.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	return onUseSpoon(player, item, fromPosition, target, toPosition, isHotkey)
end

spoon:id(3468)
spoon:register()
```

### Execução

```
Jogador usa spoon (3468)
  │
  └─ onUse() dispara
      └─ return onUseSpoon(...)
          └─ Lógica externa
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Wrapper Pattern**: Handler proxy que delega
- **Parameter Pass-through**: Todos os parâmetros repassados
- **External Function**: onUseSpoon() (definida fora)
- **Single ID**: 1 spoon, 1 handler
- **No Local Logic**: Execução completamente delegada

### Responsabilidades do Handler

1. **Delegar**: Passar para onUseSpoon()
2. **Retornar resultado**: Return direto da função externa
