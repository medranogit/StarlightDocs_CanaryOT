## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa relógio que exibe hora formatada do servidor. Ao usar watch: chama getFormattedWorldTime() que retorna string com hora/minuto atual, monta mensagem "The time is [hora]." e envia via sendTextMessage(). Registrado com 7 IDs diferentes (variantes de relógio). Sem lógica, sem validações, apenas display.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ watch.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      ├─ getFormattedWorldTime()
      │   └─ Retorna string com hora (exemplo: "10:30")
      ├─ Concatena: "The time is " .. hora .. "."
      ├─ sendTextMessage(MESSAGE_EVENT_ADVANCE, message)
      │   └─ Envia mensagem ao jogador
      └─ return true

REGISTRO:
  └─ 7 watch IDs (variantes de relógio)
```

## Fluxo de Operação

### Operação Principal

```lua
local watch = Action()

function watch.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Obter hora formatada do servidor
	local formattedTime = getFormattedWorldTime()
	
	-- Montar mensagem
	local message = "The time is " .. formattedTime .. "."
	
	-- Enviar ao jogador
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, message)
	return true
end

watch:id(2445, 2446, 2447, 2448, 2906, 2771, 6091)
watch:register()
```

### Execução

```
Jogador usa watch (2445-6091)
  │
  ├─ getFormattedWorldTime()
  │   └─ Retorna hora (exemplo: "10:30")
  │
  ├─ "The time is 10:30."
  │
  ├─ sendTextMessage(EVENT_ADVANCE, message)
  │   └─ Exibe no chat
  │
  └─ return true
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **getFormattedWorldTime()**: Função que retorna hora do servidor como string
- **String Concatenation**: .. operador para juntar strings
- **sendTextMessage()**: Outra forma de enviar texto (vs player:say)
- **MESSAGE_EVENT_ADVANCE**: Tipo de mensagem (evento/achievement)
- **Multi-ID Display**: 7 variantes de relógio
- **No Logic**: Apenas display time
- **No Validation**: Nenhuma validação implícita

### Responsabilidades do Handler

1. **Obter hora**: getFormattedWorldTime()
2. **Montar mensagem**: Concatenação de string
3. **Enviar**: sendTextMessage()
4. **Confirmar**: return true
