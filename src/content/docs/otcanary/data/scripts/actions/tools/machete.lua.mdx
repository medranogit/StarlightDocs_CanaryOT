## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper mínimo que delega toda a lógica para função externa onUseMachete(). Registra 1 machete tool que quando ativado simplesmente chama função externa passando todos os parâmetros direto. Sem lógica local, sem validações, completamente transparente.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ machete.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      └─ return onUseMachete(player, item, fromPosition, target, toPosition, isHotkey)
          └─ Função externa (não definida neste arquivo)

REGISTRO:
  └─ 1 machete ID (3308)
```

## Fluxo de Operação

### Operação Principal

```lua
local machete = Action()

function machete.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	return onUseMachete(player, item, fromPosition, target, toPosition, isHotkey)
end

machete:id(3308)
machete:register()
```

```
Jogador usa machete (3308)
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Wrapper Pattern**: Handler proxy que delega
- **Parameter Pass-through**: Todos os parâmetros repassados
- **External Function**: onUseMachete() (definida fora)
- **Single ID**: 1 machete, 1 handler
- **No Local Logic**: Execução completamente delegada

### Responsabilidades do Handler

1. **Delegar**: Passar para onUseMachete()
2. **Retornar resultado**: Return direto da função externa
