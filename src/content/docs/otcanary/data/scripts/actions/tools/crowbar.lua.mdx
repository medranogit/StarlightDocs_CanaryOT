## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper mínimo que delega toda a lógica para função externa onUseCrowbar(). Registra 1 crowbar tool que quando ativado simplesmente chama função externa passando todos os parâmetros diretos. Sem lógica local, sem validações, completamente transparente.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ crowbar.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      └─ return onUseCrowbar(player, item, fromPosition, target, toPosition, isHotkey)
          └─ Função externa (não definida neste arquivo)

REGISTRO:
  └─ 1 crowbar ID (3304)
```

function crowbar.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	return onUseCrowbar(player, item, fromPosition, target, toPosition, isHotkey)

crowbar:id(3304)
crowbar:register()

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Wrapper Pattern**: Handler proxy que delega
- **Parameter Pass-through**: Todos os parâmetros repassados
- **External Function**: onUseCrowbar() (definida fora)
- **Single ID**: 1 crowbar, 1 handler
- **No Local Logic**: Execução completamente delegada

### Responsabilidades do Handler

1. **Delegar**: Passar para onUseCrowbar()
2. **Retornar resultado**: Return direto da função externa
