## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa anel mágico com condição de curse em RNG 5%. Ao usar: valida se é anel (CONST_SLOT_RING). Se sim: 5% chance de aplicar cursed condition (-800 a -1200 HP damage, 4 segundos interval, delayed), enviar mensagem, transformar item (9392 -> 9395), decay e achievement "Cursed!". Caso oposto (95%): remover poison, transformar item (9392 -> 9394) e decay. Ambas branches disparam effect (red ou green).

### Estrutura de Funcionalidades

```
CONDITION SETUP:
  └─ cursed (CONDITION_CURSED)
      ├─ DELAYED: true
      ├─ MINVALUE: -800 HP
      ├─ MAXVALUE: -1200 HP
      ├─ STARTVALUE: -1
      ├─ TICKINTERVAL: 4000ms (4s)
      └─ FORCEUPDATE: true

HANDLER:
  └─ clawOfTheNoxiousSpawn.onUse()
      ├─ isRingSlot(player, item)?
      │   ├─ SIM → Continua
      │   └─ NÃO → return false
      ├─ RNG: random(100) <= 5?
      │   ├─ SIM (5%):
      │   │   ├─ player:addCondition(cursed)
      │   │   ├─ Message: "Cursed by The Noxious Spawn!"
      │   │   ├─ transform(9395)
      │   │   ├─ decay()
      │   │   ├─ Effect: MAGIC_RED
      │   │   └─ Achievement: "Cursed!"
      │   │
      │   └─ NÃO (95%):
      │       ├─ removeCondition(POISON)
      │       ├─ transform(9394)
      │       ├─ decay()
      │       └─ Effect: MAGIC_GREEN
      └─ return true

REGISTRO:
  └─ 1 anel ID (9392)
```

## Fluxo de Operação

### Operação Principal

```lua
local cursed = Condition(CONDITION_CURSED)
cursed:setParameter(CONDITION_PARAM_DELAYED, true)
cursed:setParameter(CONDITION_PARAM_MINVALUE, -800)
cursed:setParameter(CONDITION_PARAM_MAXVALUE, -1200)
cursed:setParameter(CONDITION_PARAM_STARTVALUE, -1)
cursed:setParameter(CONDITION_PARAM_TICKINTERVAL, 4000)
cursed:setParameter(CONDITION_PARAM_FORCEUPDATE, true)

local clawOfTheNoxiousSpawn = Action()

function clawOfTheNoxiousSpawn.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação: Anel equipado
	if item == player:getSlotItem(CONST_SLOT_RING) then
		-- RNG: 5% chance
		if math.random(100) <= 5 then
			-- BRANCH 1: CURSE (5%)
			player:addCondition(cursed)
			player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You are cursed by The Noxious Spawn!")
			item:transform(9395)  -- Muda para versão amaldiçoada
			item:decay()          -- Schedule remoção
			player:getPosition():sendMagicEffect(CONST_ME_MAGIC_RED)
			player:addAchievement("Cursed!")
		else
			-- BRANCH 2: CLEANSE (95%)
			player:removeCondition(CONDITION_POISON)
			item:transform(9394)  -- Muda para versão limpa
			item:decay()          -- Schedule remoção
			player:getPosition():sendMagicEffect(CONST_ME_MAGIC_GREEN)
		end
		return true
	end
	return false
end

clawOfTheNoxiousSpawn:id(9392)
clawOfTheNoxiousSpawn:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Condition System**: CONDITION_CURSED com parâmetros
- **Delayed Damage**: Aplicado ao longo do tempo (tick interval)
- **MINVALUE/MAXVALUE**: Range de dano por tick (800-1200)
- **TICKINTERVAL**: 4000ms = 4 segundos entre aplicações
- **FORCEUPDATE**: Força aplicação mesmo com duplicatas
- **Slot Validation**: CONST_SLOT_RING para validar ring slot
- **RNG Branches**: 5% curse vs 95% cleanse
- **Item Transform**: Muda ID (9392 -> 9395 ou 9394)
- **item:decay()**: Schedule automático de remoção
- **Effect Mágico**: MAGIC_RED (curse) vs MAGIC_GREEN (cleanse)
- **Achievement**: addAchievement() apenas na branch curse

### Responsabilidades do Handler

1. **Setup condition**: cursed com 6 parâmetros
2. **Validar slot**: Ring slot obrigatório
3. **RNG 5%**: Determina curse vs cleanse
4. **Branch 1 (5%)**: Curse + message + transform + decay + red effect + achievement
5. **Branch 2 (95%)**: Cleanse poison + transform + decay + green effect
6. **Confirmar**: return true/false
