## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa colheita com detecção de crop. Ao usar foice (3293): valida target (item target deve ser crop 5463). Se sim: transform crop (5463 -> 5462, estado colhido/murchado), decay automático, cria item colhido (5466) na posição alvo e retorna true. Se target não é crop 5463: retorna nil (silenciosamente). Padrão simples de harvest com estado de planta.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ sickle.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      ├─ target.itemid == 5463?
      │   ├─ SIM:
      │   │   ├─ target:transform(5462) → Marca como colhido
      │   │   ├─ target:decay() → Remove após tempo
      │   │   ├─ Game.createItem(5466, 1, toPosition)
      │   │   │   └─ Cria item colhido na posição
      │   │   └─ return true
      │   │
      │   └─ NÃO:
      │       └─ return nil (silencioso)
```

## Fluxo de Operação

### Operação Principal

```lua
local sickle = Action()

function sickle.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação: Target é crop?
	if target.itemid == 5463 then
		-- BRANCH: Crop detectado
		target:transform(5462)      -- Transforma para estado colhido
		target:decay()              -- Schedule remoção
		Game.createItem(5466, 1, toPosition)  -- Cria item colhido
		return true
	end
	-- Se não é crop: return nil (falha silenciosa)
end

sickle:id(3293)
sickle:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Item Detection**: target.itemid para verificar tipo
- **Transform State**: Muda ID para representar estado
- **Decay Schedule**: item:decay() para remoção automática
- **Item Creation**: Game.createItem() no local alvo
- **Silent Failure**: return nil sem mensagem
- **Single ID**: 1 sickle, 1 handler
- **Crop Pattern**: Vivo (5463) -> Colhido (5462)

### Responsabilidades do Handler

1. **Validar target**: É crop (5463)?
2. **Transform state**: 5463 -> 5462
3. **Schedule removal**: target:decay()
4. **Create output**: Game.createItem(5466)
5. **Confirmar**: return true/nil
