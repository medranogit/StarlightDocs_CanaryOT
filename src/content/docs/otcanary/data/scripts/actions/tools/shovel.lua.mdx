## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper que delega toda a lógica para função externa onUseShovel(). Registra 2 shovel tool IDs (3457 e 5710) que quando ativados chamam a mesma função externa. Diferença importante: passa parâmetro adicional itemEx (não é toPosition, é item target externo). Sem lógica local, completamente transparente.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ shovel.onUse(player, item, itemEx, fromPosition, target, toPosition, isHotkey)
      └─ return onUseShovel(player, item, itemEx, fromPosition, target, toPosition, isHotkey)
          └─ Função externa (não definida neste arquivo)

REGISTRO:
  └─ 2 shovel IDs
      ├─ 3457 (Shovel primário)
      └─ 5710 (Shovel secundário/variante)
```

## Fluxo de Operação

### Operação Principal

```lua
local shovel = Action()

function shovel.onUse(player, item, itemEx, fromPosition, target, toPosition, isHotkey)
	return onUseShovel(player, item, itemEx, fromPosition, target, toPosition, isHotkey)
end

shovel:id(3457, 5710)
shovel:register()
```

### Execução

```
Jogador usa shovel (3457 ou 5710)
  │
  ├─ ID 3457 (Shovel) → onUse() dispara
  │                    └─ return onUseShovel(...)
  │
  └─ ID 5710 (Variant) → onUse() dispara
                         └─ return onUseShovel(...)
                         (mesma lógica)
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Wrapper Pattern**: Handler proxy que delega
- **Parameter Pass-through**: Todos os parâmetros repassados
- **External Function**: onUseShovel() (definida fora)
- **Multiple IDs**: 2 IDs, 1 handler
- **Special Parameter**: itemEx (item target externo)
- **No Local Logic**: Execução completamente delegada

### Responsabilidades do Handler

1. **Delegar**: Passar para onUseShovel()
2. **Retornar resultado**: Return direto da função externa
3. **Suportar múltiplos IDs**: Ambas variantes usam mesma lógica
