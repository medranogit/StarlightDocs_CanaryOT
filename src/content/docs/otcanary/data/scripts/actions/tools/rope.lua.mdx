## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper que delega toda a lógica para função externa onUseRope(). Registra 2 rope tool IDs (3003 e 646) que quando ativados chamam a mesma função externa passando parâmetros direto. Sem lógica local, sem validações, completamente transparente. Única diferença comparado aos outros wrappers: dois IDs registrados.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ rope.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      └─ return onUseRope(player, item, fromPosition, target, toPosition, isHotkey)
          └─ Função externa (não definida neste arquivo)

REGISTRO:
  └─ 2 rope IDs
      ├─ 3003 (Rope ou normal)
      └─ 646 (Climbing Rope ou variante)
```

## Fluxo de Operação

### Operação Principal

```lua
local rope = Action()

function rope.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	return onUseRope(player, item, fromPosition, target, toPosition, isHotkey)
end

rope:id(3003, 646)
rope:register()
```

### Execução

```
Jogador usa rope (3003 ou 646)
  │
  ├─ ID 3003 (Rope) → onUse() dispara
  │                  └─ return onUseRope(...)
  │
  └─ ID 646 (Climbing Rope) → onUse() dispara
                              └─ return onUseRope(...)
                              (mesma lógica)
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Wrapper Pattern**: Handler proxy que delega
- **Parameter Pass-through**: Todos os parâmetros repassados
- **External Function**: onUseRope() (definida fora)
- **Multiple IDs**: 2 IDs, 1 handler
- **No Local Logic**: Execução completamente delegada
- **ID Array**: rope:id(3003, 646) registra ambas variantes

### Responsabilidades do Handler

1. **Delegar**: Passar para onUseRope()
2. **Retornar resultado**: Return direto da função externa
3. **Suportar múltiplos IDs**: Ambas variantes usam mesma lógica
