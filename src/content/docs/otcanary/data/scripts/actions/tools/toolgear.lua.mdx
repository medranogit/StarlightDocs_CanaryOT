## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa multi-tool universal (toolgear) com RNG dual-branch. 95% chance: cascata OR de 8 funções (rope -> shovel -> pick -> machete -> crowbar -> spoon -> scythe -> kitchen_knife), retorna se qualquer uma suceder. 5% chance: jams tool (item state = ItemID+1, decay schedule, achievement "Bad Timing" +10, message). 3 IDs (9594, 9596, 9598) representando 3 estados (normal, jammed level 1 e 2). Padrão complexo com cascata lógica e state machine.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ toolGear.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      ├─ random(100) > 5?
      │   │
      │   ├─ SIM (95%):
      │   │   └─ Cascata OR:
      │   │       ├─ onUseRope() → true? return
      │   │       ├─ onUseShovel() → true? return
      │   │       ├─ onUsePick() → true? return
      │   │       ├─ onUseMachete() → true? return
      │   │       ├─ onUseCrowbar() → true? return
      │   │       ├─ onUseSpoon() → true? return
      │   │       ├─ onUseScythe() → true? return
      │   │       └─ onUseKitchenKnife() → true? return
      │   │
      │   └─ NÃO (5%):
      │       ├─ Message: "Tool is jammed for a minute"
      │       ├─ Achievement: "Bad Timing" +10
      │       ├─ transform(itemid + 1) → Next jam state
      │       └─ decay() → Remove após tempo
      │
      └─ return true

REGISTRY:
  └─ 3 toolgear IDs
      ├─ 9594 (Normal)
      ├─ 9596 (Jammed 1)
      └─ 9598 (Jammed 2 ou final) [nota: pode ser 9597]
```

## Fluxo de Operação

### Operação Principal

```lua
local toolGear = Action()

function toolGear.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- RNG: 95% vs 5%
	if math.random(100) > 5 then
		-- ========== SUCCESS BRANCH (95%) ==========
		-- Cascata OR: tenta cada função até suceder
		return onUseRope(player, item, fromPosition, target, toPosition, isHotkey)
			or onUseShovel(player, item, fromPosition, target, toPosition, isHotkey)
			or onUsePick(player, item, fromPosition, target, toPosition, isHotkey)
			or onUseMachete(player, item, fromPosition, target, toPosition, isHotkey)
			or onUseCrowbar(player, item, fromPosition, target, toPosition, isHotkey)
			or onUseSpoon(player, item, fromPosition, target, toPosition, isHotkey)
			or onUseScythe(player, item, fromPosition, target, toPosition, isHotkey)
			or onUseKitchenKnife(player, item, fromPosition, target, toPosition, isHotkey)
	else
		-- ========== JAM BRANCH (5%) ==========
		player:say("Oh no! Your tool is jammed and can't be used for a minute.", TALKTYPE_MONSTER_SAY)
		player:addAchievementProgress("Bad Timing", 10)
		item:transform(item.itemid + 1)
		item:decay()
	end
	return true
end

toolGear:id(9594, 9596, 9598)
toolGear:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **RNG Dual-Branch**: random(100) > 5 → 95% vs 5%
- **Cascata OR**: 8 funções em cascata, primeira true vence
- **State Machine**: ItemID+1 para estados travados (9594 -> 9596 -> 9598)
- **Transform Increment**: item.itemid + 1 para trocar estado
- **Achievement Progress**: addAchievementProgress() com valor
- **Silent Decay**: item:decay() schedula remoção
- **Message Feedback**: say() com TALKTYPE_MONSTER_SAY
- **Multi-ID Variants**: 3 IDs para 3 estados diferentes
- **Always Return True**: Mesmo em jam, return true (consumido)
- **External Delegation**: Chama 8 funções externas

### Responsabilidades do Handler

1. **RNG**: random(100) para 95/5 split
2. **Success Branch (95%)**:
   - Cascata OR: tenta 8 funções
   - Return primeiro resultado truthy
3. **Jam Branch (5%)**:
   - Message ao jogador
   - Achievement +10
   - Transform state (itemid+1)
   - Decay item
4. **Always Return True**: Consumido sempre
