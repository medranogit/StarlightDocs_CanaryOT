## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper mínimo que delega toda a lógica para função externa onUseScythe(). Registra 1 scythe tool que quando ativado simplesmente chama função externa passando todos os parâmetros direto. Sem lógica local, sem validações, completamente transparente.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ scythe.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      └─ return onUseScythe(player, item, fromPosition, target, toPosition, isHotkey)
          └─ Função externa (não definida neste arquivo)

REGISTRO:
  └─ 1 scythe ID (3453)
```

## Fluxo de Operação

### Operação Principal

```lua
local scythe = Action()

function scythe.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	return onUseScythe(player, item, fromPosition, target, toPosition, isHotkey)
end

scythe:id(3453)
scythe:register()
```

### Execução

```
Jogador usa scythe (3453)
  │
  └─ onUse() dispara
      └─ return onUseScythe(...)
          └─ Lógica externa (harvest tool)
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Wrapper Pattern**: Handler proxy que delega
- **Parameter Pass-through**: Todos os parâmetros repassados
- **External Function**: onUseScythe() (definida fora)
- **Single ID**: 1 scythe, 1 handler
- **No Local Logic**: Execução completamente delegada
- **Harvest Tool**: Scythe é ferramenta de colheita

### Responsabilidades do Handler

1. **Delegar**: Passar para onUseScythe()
2. **Retornar resultado**: Return direto da função externa
