## 📄 Visão Geral do Código

### Resumo Executivo

O script é um wrapper mínimo que delega toda a lógica para função externa onUsePick(). Registra 1 pick tool que quando ativado simplesmente chama função externa passando todos os parâmetros direto. Sem lógica local, sem validações, completamente transparente.

### Estrutura de Funcionalidades

```
HANDLER:
  └─ pick.onUse(player, item, fromPosition, target, toPosition, isHotkey)
      └─ return onUsePick(player, item, fromPosition, target, toPosition, isHotkey)
          └─ Função externa (não definida neste arquivo)

REGISTRO:
  └─ 1 pick ID (3456)
```

## Fluxo de Operação

### Operação Principal

```lua
local pick = Action()

function pick.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	return onUsePick(player, item, fromPosition, target, toPosition, isHotkey)
end

pick:id(3456)
pick:register()
```

### Execução

```
Jogador usa pick (3456)
  │
  └─ onUse() dispara
      └─ return onUsePick(...)
          └─ Lógica externa (mining tool)
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Wrapper Pattern**: Handler proxy que delega
- **Parameter Pass-through**: Todos os parâmetros repassados
- **External Function**: onUsePick() (definida fora)
- **Single ID**: 1 pick, 1 handler
- **No Local Logic**: Execução completamente delegada
- **Mining Tool**: Pick é ferramenta de mineração

### Responsabilidades do Handler

1. **Delegar**: Passar para onUsePick()
2. **Retornar resultado**: Return direto da função externa
