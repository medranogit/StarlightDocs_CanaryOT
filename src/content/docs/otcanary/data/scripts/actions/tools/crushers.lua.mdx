## 📄 Visão Geral do Código

### Resumo Executivo

O script implementa sistema dual de esmagadores para gemas com lookup table de 15 gemas diferentes. Config: maxGemBreak=10 (máx por operação), 3 tiers (small/medium/great), cada tier com 5 IDs e correspondentes fragmentos + range. getGemData() busca ID da gema na config e retorna tipo de fragmento + range. amberCrusher (46628): ilimitado, quebra até 10 gemas (breakAmount logic), cria fragmentos random (range[1]-range[2]). crusher (46627): com charges (getAttribute), decrementa charge após cada uso, remove item quando charges=0. Ambos com validações: target existe, is item, não é si mesmo, tem count > 0, é gema conhecida.

### Estrutura de Funcionalidades

```
CONFIG:
  └─ maxGemBreak: 10
  └─ fragmentGems:
      ├─ small: 5 IDs, fragment 46625, range 1-4
      ├─ medium: 5 IDs, fragment 46625, range 2-8
      └─ great: 5 IDs, fragment 46626, range 1-4

FUNÇÃO LOCAL:
  └─ getGemData(gemId)
      ├─ Itera fragmentGems
      ├─ Se gemId está no table
      │   └─ return fragment, range
      └─ Senão: return nil

HANDLER 1 - AMBER CRUSHER (46628):
  └─ Ilimitado
      ├─ Validações: target, item, não-self, count > 0
      ├─ getGemData() → fragment e range
      ├─ breakAmount = min(count, 10) ou 1
      ├─ for 1 to breakAmount:
      │   └─ player:addItem(fragment, random(range))
      └─ Remove breakAmount gemas

HANDLER 2 - CRUSHER (46627):
  └─ Com Charges
      ├─ Validações: target, item, não-self, count > 0
      ├─ getGemData() → fragment e range
      ├─ crusherCharges = getAttribute(CHARGES)
      ├─ if crusherCharges <= 0: return false
      ├─ Remove 1 gema
      ├─ Cria 1 fragmento
      ├─ crusherCharges - 1
      ├─ if > 0: setAttribute + updateContainer
      └─ else: remove() + message "consumed"

REGISTRO:
  └─ 2 crushers (46627, 46628)
```

## Funções Locais

### getGemData(gemId)

Busca dados da gema na config:

```lua
local function getGemData(gemId)
	for _, gemData in pairs(config.fragmentGems) do
		if table.contains(gemData.ids, gemId) then
			return gemData.fragment, gemData.range
		end
	end
	return nil
end
```

**Parâmetro:**
- gemId: ID da gema a buscar

**Retorna:**
- fragment: ID do fragmento correspondente
- range: Table with min and max quantity values

**Exemplo:**
```lua
local fragment, range = getGemData(44602)
-- fragment = 46625, range = {1, 4}
```

## Fluxo de Operação

### Operação Principal

```lua
local config = {
	maxGemBreak = 10,
	fragmentGems = {
		small = { ids = { 44602, 44605, 44608, 44611, 49371 }, fragment = 46625, range = { 1, 4 } },
		medium = { ids = { 44603, 44606, 44609, 44612, 49372 }, fragment = 46625, range = { 2, 8 } },
		great = { ids = { 44604, 44607, 44610, 44613, 49373 }, fragment = 46626, range = { 1, 4 } },
	},
}

local function getGemData(gemId)
	for _, gemData in pairs(config.fragmentGems) do
		if table.contains(gemData.ids, gemId) then
			return gemData.fragment, gemData.range
		end
	end
	return nil
end

-- ========== AMBER CRUSHER (Ilimitado) ==========
local amberCrusher = Action()

function amberCrusher.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação: Target
	if not target or not target:isItem() or target:getId() == item:getId() or 
	   player:getItemCount(target:getId()) <= 0 then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You can only use the crusher on a valid gem in your inventory.")
		return true
	end

	-- Lookup: Dados da gema
	local fragmentType, fragmentRange = getGemData(target:getId())
	if not fragmentType then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "This item can't be broken into fragments.")
		return true
	end

	-- Break amount logic: min(count, 10) ou 1
	local breakAmount = (target:getCount() >= config.maxGemBreak) and config.maxGemBreak or 1
	target:remove(breakAmount)

	-- Criar fragmentos
	for _ = 1, breakAmount do
		player:addItem(fragmentType, math.random(fragmentRange[1], fragmentRange[2]))
	end

	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You have broken the gem into fragments.")
	return true
end

amberCrusher:id(46628)
amberCrusher:register()

-- ========== CRUSHER (Com Charges) ==========
local crusher = Action()

function crusher.onUse(player, item, fromPosition, target, toPosition, isHotkey)
	-- Validação: Target
	if not target or not target:isItem() or target:getId() == item:getId() or 
	   player:getItemCount(target:getId()) <= 0 then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You can only use the crusher on a valid gem in your inventory.")
		return true
	end

	-- Lookup: Dados da gema
	local fragmentType, fragmentRange = getGemData(target:getId())
	if not fragmentType then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "This item can't be broken into fragments.")
		return true
	end

	-- Charge check
	local crusherCharges = item:getAttribute(ITEM_ATTRIBUTE_CHARGES)
	if not crusherCharges or crusherCharges <= 0 then
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Your crusher has no more charges.")
		return true
	end

	-- quebrar 1 gema
	target:remove(1)
	player:addItem(fragmentType, math.random(fragmentRange[1], fragmentRange[2]))
	player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You have broken the gem into fragments.")

	-- Decrement charges
	crusherCharges = crusherCharges - 1
	if crusherCharges > 0 then
		local container = item:getParent()
		item:setAttribute(ITEM_ATTRIBUTE_CHARGES, crusherCharges)
		if container:isContainer() then
			player:sendUpdateContainer(container)
		end
	else
		item:remove()
		player:sendTextMessage(MESSAGE_EVENT_ADVANCE, "Your crusher has been consumed.")
	end
	return true
end

crusher:id(46627)
crusher:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Config Table**: Centralizar dados (gemas, ranges)
- **Local Function**: getGemData() para lookup
- **pairs() vs ipairs()**: pairs para dicts, ipairs para arrays
- **table.contains()**: Validar existência em array
- **Target Validation**: 4 checks (exists, isItem, not-self, count)
- **Fragment Lookup**: getGemData() retorna 2 valores
- **Break Amount Logic**: Ternário para min(count, 10) vs 1
- **Charge System**: getAttribute(ITEM_ATTRIBUTE_CHARGES)
- **Charge Decrement**: Decrementa até 0 então remove()
- **Container Update**: sendUpdateContainer() para visual
- **Dual Implementation**: Ilimitado vs Charges (mesmo core)
- **Gem Tiers**: 3 tipos (small/medium/great) com ranges diferentes

### Responsabilidades do Handler

**Amber Crusher (Ilimitado):**
1. Validar target (4 checks)
2. Lookup: getGemData()
3. Calcular breakAmount: min(count, 10) ou 1
4. Remover N gemas
5. Criar N fragmentos (cada 1 random range)

**Crusher (Charges):**
1. Validar target (4 checks)
2. Lookup: getGemData()
3. Validar charges > 0
4. Remover 1 gema
5. Criar 1 fragmento
6. Decrement charges
7. Se = 0: remove() crusher; se > 0: update visual
