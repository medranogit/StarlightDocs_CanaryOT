## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener que regenera stamina offline. Valida se stamina system está ativado, obtém offlineTime (max 21 dias), deduz 10 minutos (penalty), valida mínimo 3 minutos. Calcula normal stamina regen (180s por ponto), compara com max normal (2340). Se overflow: regen restante em happy hour (360s por ponto, double rate). Aplicar stamina final respeitando máximos (2340 normal, 2520 happy hour). Padrão de duas-tier stamina regen.

## Fluxo de Operação

### Operação Principal

```lua
local regenerateStamina = CreatureEvent("RegenerateStamina")

function regenerateStamina.onLogin(player)
	-- Validação
	if not configManager.getBoolean(configKeys.STAMINA_SYSTEM) then
		return true
	end

	-- Cálculo de tempo offline
	local lastLogout = player:getLastLogout()
	local offlineTime = lastLogout ~= 0 and 
		math.min(os.time() - lastLogout, 86400 * 21) or 0

	-- Deduzir penalty (10 minutos)
	offlineTime = offlineTime - 600

	-- Validação: mínimo 3 minutos
	if offlineTime < 180 then
		return true
	end

	-- Stamina atual
	local staminaMinutes = player:getStamina()
	
	-- Espaço disponível até max normal
	local maxNormalStaminaRegen = 2340 - math.min(2340, staminaMinutes)
	
	-- Regen em rate normal (1 min per 180s)
	local regainStaminaMinutes = offlineTime / 180

	-- Overflow para happy hour?
	if regainStaminaMinutes > maxNormalStaminaRegen then
		-- Stamina consumida em normal regen
		local normalCost = maxNormalStaminaRegen * 180
		
		-- Tempo restante em happy hour (1 min per 360s)
		local happyHourStaminaRegen = (offlineTime - normalCost) / 360
		
		-- Aplicar ambos os regens
		staminaMinutes = math.min(2520, 
			math.max(2340, staminaMinutes) + happyHourStaminaRegen)
	else
		-- Apenas normal regen
		staminaMinutes = staminaMinutes + regainStaminaMinutes
	end

	player:setStamina(staminaMinutes)
	return true
end

regenerateStamina:register()
```

### Stamina Calculation Example

```lua
-- EXEMPLO 1: Sem overflow
-- offlineTime = 3600s (1 hora), after penalty = 3000s
-- staminaMinutes = 1000
-- maxNormalRegen = 2340 - 1000 = 1340
-- regain = 3000 / 180 = 16.67 min
-- 16.67 < 1340? SIM → apenas normal
-- staminaMinutes = 1000 + 16.67 = 1016.67

-- EXEMPLO 2: Com overflow para happy hour
-- offlineTime = 86400s (24 horas), after penalty = 85800s
-- staminaMinutes = 2300
-- maxNormalRegen = 2340 - 2300 = 40
-- regain = 85800 / 180 = 476.67 min
-- 476.67 > 40? SIM → overflow!
-- normalCost = 40 * 180 = 7200s
-- happyHourTime = 85800 - 7200 = 78600s
-- happyHourGain = 78600 / 360 = 218.33 min
-- staminaMinutes = max(2340, 2300) + 218.33 = 2558.33
-- staminaMinutes = min(2520, 2558.33) = 2520 (capped)
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **CreatureEvent onLogin**: Callback disparado ao fazer login
- **STAMINA_SYSTEM**: Global config flag
- **Offline Time**: math.min com cap de 21 dias
- **Offline Penalty**: 10 minutos deduzidos
- **Normal Regen Rate**: 180s por 1 min stamina
- **Happy Hour Rate**: 360s por 1 min (2x slower = mais eficiente)
- **Normal Max**: 2340 minutos
- **Happy Hour Max**: 2520 minutos (overflow buffer)
- **Overflow Logic**: Regen normal → happy hour
- **Cost Calculation**: normalRegen * 180s = tempo consumido
- **Remaining Time**: offlineTime - normalCost = happy hour time

### Responsabilidades do Handler

1. **Validate**: System enabled?
2. **Get**: lastLogout + offlineTime
3. **Deduct**: 10 min penalty
4. **Check**: Mínimo 3 minutos?
5. **Calculate**: maxNormalRegen
6. **Calculate**: regainStaminaMinutes (normal rate)
7. **Check**: Overflow?
   - SIM: Apply normal + happy hour
   - NÃO: Apply normal only
8. **Apply**: setStamina()
9. **Return**: true
