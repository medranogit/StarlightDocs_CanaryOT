## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de level-up trivial que restaura HP/Mana e salva. Valida se skill é SKILL_LEVEL e newLevel > oldLevel. Se sim: adiciona HP ao máximo (addHealth + getMaxHealth), adiciona Mana ao máximo, aplica getFinalLowLevelBonus(), persiste player.save(). Padrão simples de reward ao avançar.

### Estrutura de Funcionalidades

```
EVENT: "UpdatePlayerOnAdvancedLevel"
  └─ onAdvance(player, skill, oldLevel, newLevel)
      ├─ Validação: skill == SKILL_LEVEL?
      │   ├─ NÃO → return true
      │   └─ SIM → Continua
      │
      ├─ Validação: newLevel > oldLevel?
      │   ├─ NÃO → return true (downgrade ou igual)
      │   └─ SIM → Continua (real level-up)
      │
      ├─ player:addHealth(player:getMaxHealth())
      │   └─ Restaura HP ao máximo
      │
      ├─ player:addMana(player:getMaxMana())
      │   └─ Restaura Mana ao máximo
      │
      ├─ player:getFinalLowLevelBonus()
      │   └─ Aplica bônus low-level (se aplicável)
      │
      ├─ player:save()
      │   └─ Persiste player no DB
      │
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local updatePlayerOnAdvancedLevel = CreatureEvent("UpdatePlayerOnAdvancedLevel")

function updatePlayerOnAdvancedLevel.onAdvance(player, skill, oldLevel, newLevel)
	-- Validação: é skill_level?
	if skill ~= SKILL_LEVEL or newLevel <= oldLevel then
		return true
	end

	-- Restaurar HP
	player:addHealth(player:getMaxHealth())
	
	-- Restaurar Mana
	player:addMana(player:getMaxMana())
	
	-- Aplicar low-level bonus
	player:getFinalLowLevelBonus()
	
	-- Persist
	player:save()
	return true
end

updatePlayerOnAdvancedLevel:register()
```

### Árvore de Decisão

```
Player faz level-up
  │
  ├─ Advance event disparado
  │   └─ onAdvance(player, skill, oldLevel, newLevel)
  │
  ├─ skill == SKILL_LEVEL && newLevel > oldLevel?
  │   ├─ NÃO → return true (skip)
  │   │   (não é level-up válido)
  │   │
  │   └─ SIM → Processar
  │       │
  │       ├─ addHealth(getMaxHealth())
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **CreatureEvent onAdvance**: Callback disparado ao avançar skill
- **SKILL_LEVEL**: ID da skill de level (distinta de outras skills)
- **Health Restoration**: addHealth + getMaxHealth para restore completo
- **Mana Restoration**: addMana + getMaxMana para restore completo
- **Low-Level Bonus**: Bônus aplicado em baixo-level (regeneration/stats)
- **Player Persistence**: save() para DB
- **Validation**: skill check + level check duplo

### Responsabilidades do Handler

1. **Validate**: skill == SKILL_LEVEL?
2. **Validate**: newLevel > oldLevel?
3. **Restore**: HP ao máximo
4. **Restore**: Mana ao máximo
5. **Apply**: Low-level bonus
6. **Persist**: player:save()
7. **Return**: true
