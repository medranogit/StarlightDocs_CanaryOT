## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener que distribui items iniciais. Possui config table com 6 vocações (NONE, SORCERER, DRUID, PALADIN, KNIGHT, MONK), cada uma com items diretos e container items (dentro de backpack). Obtém targetVocation da config, valida primeiro login (lastLoginSaved == 0). Se sim: adiciona items diretos (equipment), cria backpack (2854), adiciona items dentro do backpack. Padrão simples de equip distribuition por vocation.

local sendFirstItems = CreatureEvent("SendFirstItems")

function sendFirstItems.onLogin(player)
	-- Obter config para vocation
	local targetVocation = config[player:getVocation():getId()]
	
	-- Validação: config exist && first login?
	if not targetVocation or player:getLastLoginSaved() ~= 0 then
		return true
	end

	-- Adicionar items diretos
	if targetVocation.items then
		for i = 1, #targetVocation.items do
			player:addItem(
				targetVocation.items[i][1],    -- itemId
				targetVocation.items[i][2]     -- count
			)
		end
	end

	-- Criar backpack
	local backpack = player:addItem(2854)
	if not backpack then
		return true
	end

	-- Adicionar items dentro do backpack
	if targetVocation.container then
		for i = 1, #targetVocation.container do
			backpack:addItem(
				targetVocation.container[i][1],   -- itemId
				targetVocation.container[i][2]    -- count
			)
		end
	end
	return true
end

sendFirstItems:register()

## Checkpoint de Aprendizagem

### Conceitos-chave

- **CreatureEvent onLogin**: Callback disparado ao fazer login
- **First Login Detection**: lastLoginSaved == 0
- **Vocation Lookup**: config[vocationId] from global table
- **Equipment Distribution**: addItem direto para player
- **Container Items**: addItem dentro de backpack
- **Backpack**: Item ID 2854, 8 slots
- **Item Count**: `{itemId, count}` tuple pattern
- **Conditional Items**: Vocations específicas com equipamento apropriado

### Responsabilidades do Handler

1. **Lookup**: targetVocation da config
2. **Validate**: Vocation exists && first login?
3. **Equipment**: Adicionar items diretos
4. **Container**: Criar backpack
5. **Check**: Backpack criado com sucesso?
6. **Fill**: Adicionar items dentro do backpack
7. **Return**: true (sucesso)
