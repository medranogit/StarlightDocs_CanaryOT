## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de login que aplica bênção automática. Carrega módulo `blessing.lua` do core via dofile. CreatureEvent "AdventurerBlessingLogin" dispara onLogin que delega para `Blessings.doAdventurerBlessing(player)`. Padrão simples de wrapper que integra módulo externo.

### Estrutura de Funcionalidades

```
MODULO CARREGADO: blessing.lua
  └─ Blessings (sistema externo)

EVENT: "AdventurerBlessingLogin"
  └─ onLogin(player)
      └─ return Blessings.doAdventurerBlessing(player)
          └─ Aplica bênção
```

## Fluxo de Operação

### Operação Principal

```lua
-- Carregar módulo external
dofile(CORE_DIRECTORY .. "/libs/systems/blessing.lua")

-- Registrar listener
local adventurerBlessingLogin = CreatureEvent("AdventurerBlessingLogin")

function adventurerBlessingLogin.onLogin(player)
	-- Delegar para módulo externo
	return Blessings.doAdventurerBlessing(player)
end

adventurerBlessingLogin:register()
```

### Árvore de Decisão

```
Player faz login
  │
  ├─ dofile(blessing.lua)
  │   └─ Carrega módulo (primeira vez)
  │
  ├─ CreatureEvent("AdventurerBlessingLogin")
  │   └─ Registra listener
  │
  ├─ onLogin(player) dispara
  │   │
  │   └─ Blessings.doAdventurerBlessing(player)
  │       └─ Delega para módulo externo
  │           ├─ Valida requisitos
  │           ├─ Aplica bênção se qualificado
  │           └─ return true/false
  │
  └─ Listener retorna resultado
```

### Conceitos-chave

- **dofile()**: Carregar arquivo Lua em memória
- **CORE_DIRECTORY**: Constante para core libs
- **Module Loading**: System integration via external modules
- **External Delegation**: Chamar função de módulo carregado
- **Return Passthrough**: Retornar diretamente do módulo

### Padrão Module Loading

Carregar módulo externo:

```lua

```

### Padrão External Delegation

Delegar para externa com passthrough:

```lua
function adventurerBlessingLogin.onLogin(player)
	return Blessings.doAdventurerBlessing(player)
end
```

### Padrão One-liner Events

Listeners muito simples que apenas delegam:

```lua
local listener = CreatureEvent("EventName")

function listener.onCallback(param)
	return ExternalSystem.doAction(param)
end

listener:register()
```
