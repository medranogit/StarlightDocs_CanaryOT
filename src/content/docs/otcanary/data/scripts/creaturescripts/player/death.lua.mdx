## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener complexo de morte de player que coordena múltiplos sistemas. Valida deathListEnabled (global flag), obtém lista de killers, extrai info do killer/mostDamage via funções locais (validando master players), tira screenshots (PVP/PVE conditional), serializa participants, salva morte no DB via saveDeathRecord, envia webhook de anúncio, coordena guild war com checagem de limite de frags. Padrão enterprise com banco de dados, webhooks e sistemas integrados.

## Funções Locais

### getKillerInfo(killer)

Extrai nome do killer com validação de master:

```lua
local function getKillerInfo(killer)
	local byPlayer = 0
	local killerName

	if killer then
		if killer:isPlayer() then
			byPlayer = 1
		else
			-- Se é summon, obtem master player
			local master = killer:getMaster()
			if master and master ~= killer and master:isPlayer() then
				killer = master
				byPlayer = 1
			end
		end

		-- Nome: monster type ou player name
		killerName = killer:isMonster() and 
			killer:getType():getNameDescription() or 
			killer:getName()
	else
		killerName = "field item"
	end

	return killerName, byPlayer
end
```

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| killer | Creature | Assassino (player/monster/summon) |

| Retorno 1 | Tipo | Descrição |
|-----------|------|-----------|
| killerName | string | Nome do killer ou "field item" |

| Retorno 2 | Tipo | Descrição |
|-----------|------|-----------|
| byPlayer | número | 1 se player, 0 se monster |

### serializeParticipants(participants)

Converte array de participants em string formatada:

```lua
local function serializeParticipants(participants)
	if not participants or #participants == 0 then
		return ""
	end

	local result = {}
	for _, participant in ipairs(participants) do
		local entry = string.format("Name: %s\nType: %s", 
			participant.name, participant.type)
		result[#result + 1] = entry
	end
	return table.concat(result, "\n\n")
end
```

| Parâmetro | Tipo | Descrição |
|-----------|------|-----------|
| participants | table | Array de `{name, type}` |

| Retorno | Tipo | Descrição |
|---------|------|-----------|
| result | string | Participants formatados (ou "") |

### saveDeathRecord(playerGuid, player, killerName, byPlayer, ...)

```lua
local function saveDeathRecord(playerGuid, player, killerName, byPlayer, 
	mostDamageName, byPlayerMostDamage, unjustified, 
	mostDamageUnjustified, participants)
	
	local participantsString = serializeParticipants(participants)
	local query = string.format(
		"INSERT INTO `player_deaths` (...) VALUES (%d, %d, %d, %s, %d, %s, %d, %d, %d, %s)",
		playerGuid, os.time(), player:getLevel(),
		db.escapeString(killerName), byPlayer,
		db.escapeString(mostDamageName), byPlayerMostDamage,
		unjustified and 1 or 0, mostDamageUnjustified and 1 or 0,
		db.escapeString(participantsString)
	)
	db.query(query)
end
```

| playerGuid | número | ID único do player |
| player | Player | Player object |
| killerName | string | Nome do killer |
| byPlayer | número | 1 se player, 0 se monster |
| ... | múltiplos | Dados adicionais |

### getDeathRecords(playerGuid)

Conta total de mortes no DB:

```lua
local function getDeathRecords(playerGuid)
	local resultId = db.storeQuery(
		"SELECT `player_id` FROM `player_deaths` WHERE `player_id` = " .. playerGuid)
	local deathRecords = 0
	while resultId do
		resultId = Result.next(resultId)
		deathRecords = deathRecords + 1
	end

	if resultId then
		Result.free(resultId)
	end

	return deathRecords
end
```

| Retorno | Tipo | Descrição |
|---------|------|-----------|
| deathRecords | número | Total de mortes |

### handleGuildWar(player, killer, mostDamageKiller, killerName, mostDamageName)

Orquestra sistema de guild wars:

```lua
local function handleGuildWar(player, killer, mostDamageKiller, 
	killerName, mostDamageName)
	
	-- Validação de guilds
	if not player or not killer or not killer:isPlayer() or 
		not player:getGuild() or not killer:getGuild() then
		return
	end

	-- Same guild = skip
	if player:getGuild():getId() == killer:getGuild():getId() then
		return
	end

	-- Check if war exists
	if getDeathRecords(player:getGuid()) > 0 then
		local warId = checkForGuildWar(player:getGuild():getId(), 
			killer:getGuild():getId())
		
		if warId then
			recordGuildWarKill(killer, player, ...)
			checkAndUpdateGuildWarScore(warId, ...)
		end
	end
end
```

### checkForGuildWar(targetGuildId, killerGuildId)

Query de guerra ativa entre guilds:

```lua
local function checkForGuildWar(targetGuildId, killerGuildId)
	local resultId = db.storeQuery(string.format(
		"SELECT `id` FROM `guild_wars` WHERE `status` = 1 " ..
		"AND ((`guild1` = %d AND `guild2` = %d) " ..
		"OR (`guild1` = %d AND `guild2` = %d))",
		killerGuildId, targetGuildId, targetGuildId, killerGuildId))

	local warId = false
	if resultId then
		warId = Result.getNumber(resultId, "id")
		Result.free(resultId)
	end

	return warId
end
```

| Retorno | Tipo | Descrição |
|---------|------|-----------|
| warId | número/false | ID da guerra ou false |

### checkAndUpdateGuildWarScore(warId, targetGuildId, killerGuildId, ...)

```lua
local function checkAndUpdateGuildWarScore(warId, targetGuildId, 
	killerGuildId, playerName, killerName, mostDamageName)
	
	-- Query complexa: conta kills de cada guild
	local resultId = db.storeQuery(string.format(
		"SELECT `guild_wars`.`id`, `guild_wars`.`frags_limit`, " ..
		"(SELECT COUNT(*) FROM `guildwar_kills` WHERE ... guild1) AS guild1_kills, " ..
		"(SELECT COUNT(*) FROM `guildwar_kills` WHERE ... guild2) AS guild2_kills " ..
		"FROM `guild_wars` WHERE ...",
		killerGuildId, targetGuildId, warId))

	if resultId then
		-- Score update + broadcast
		updateGuildWarScore(...)
		endGuildWarIfLimitReached(...)
	end
end
```

### endGuildWarIfLimitReached(guild1Kills, guild2Kills, fragsLimit, warId, ...)

Finaliza guerra se limite de frags atingido:

```lua
local function endGuildWarIfLimitReached(guild1Kills, guild2Kills, 
	fragsLimit, warId, killerGuild, targetGuild)
	
	if guild1Kills >= fragsLimit or guild2Kills >= fragsLimit then
		db.query(string.format(
			"UPDATE `guild_wars` SET `status` = 4, `ended` = %d WHERE `id` = %d",
			os.time(), warId))
		
		Game.broadcastMessage(
			string.format("%s has just won the war against %s.",
				killerGuild:getName(),
				targetGuild:getName()))
	end
end
```

## Fluxo de Operação

### onDeath - Event Handler

```lua
local playerDeath = CreatureEvent("PlayerDeath")

function playerDeath.onDeath(player, corpse, killer, mostDamageKiller, 
	unjustified, mostDamageUnjustified)
	
	-- Validação global
	if not deathListEnabled then
		return
	end

	-- 1. Obter lista de killers
	local killers = player:getKillers(false)
	local participants = {}
	for _, entry in ipairs(killers) do
		local name = entry:isMonster() and 
			entry:getType():getNameDescription() or 
			entry:getName()
		local type = entry:isPlayer() and "player" or "monster"
		participants[#participants + 1] = { name = name, type = type }
	end

	-- 2. Extrair info killer/mostDamage
	local killerName, byPlayer = getKillerInfo(killer)
	local mostDamageName, byPlayerMostDamage = getMostDamageInfo(mostDamageKiller)

	-- 3. Screenshots
	player:takeScreenshot(byPlayer and SCREENSHOT_TYPE_DEATHPVP or SCREENSHOT_TYPE_DEATHPVE)
	if mostDamageKiller and mostDamageKiller:isPlayer() then
		mostDamageKiller:takeScreenshot(SCREENSHOT_TYPE_PLAYERKILL)
	end

	-- 4. Salvar morte no DB
	local playerGuid = player:getGuid()
	saveDeathRecord(playerGuid, player, killerName, byPlayer, 
		mostDamageName, byPlayerMostDamage, unjustified, 
		mostDamageUnjustified, participants)

	-- 5. Webhook announce
	Webhook.sendMessage(
		":skull_crossbones: " .. player:getMarkdownLink() .. 
		" has died. Killed at level _" .. player:getLevel() .. 
		"_ by **" .. killerName .. "**.",
		announcementChannels["player-kills"])

	-- 6. Guild war coordination
	handleGuildWar(player, killer, mostDamageKiller, killerName, mostDamageName)
end

playerDeath:register()
```

### Master Validation Pattern

```lua
-- Quando killer é summon (cão, elemental, etc)
if killer:isPlayer() then
	byPlayer = 1
else
	local master = killer:getMaster()
	-- Valida: master existe && é diferente de killer && é player
	if master and master ~= killer and master:isPlayer() then
		killer = master  -- Override para player
		byPlayer = 1
	end
end
```
