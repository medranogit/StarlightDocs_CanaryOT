## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de logout que gerencia limpeza de dados globais e estado de bosses. Ao sair: obtém playerId, limpa NextUseStaminaTime[playerId] (global stamina timer), obtem boss fight stats via `inBossFight()`, se tem boss: lookup monster, obtem damage map, accumula damageOut, salva stamina atual. Se em exercise training: para event com stopEvent(), limpa global OnExerciseTraining, seta training(false). Padrão de multi-cleanup com persistência de estado.

### Estrutura de Funcionalidades

```
EVENT: "PlayerLogout"
  └─ onLogout(player)
      ├─ playerId = player:getId()
      │   └─ Obtem ID único
      │
      ├─ CLEANUP 1: NextUseStaminaTime
      │   ├─ if _G.NextUseStaminaTime[playerId]:
      │   │   └─ _G.NextUseStaminaTime[playerId] = nil
      │
      ├─ CLEANUP 2: Boss Fight Stats
      │   ├─ stats = player:inBossFight()
      │   ├─ if stats:
      │   │   ├─ boss = Monster(stats.bossId)
      │   │   ├─ if boss:
      │   │   │   ├─ dmgOut = boss:getDamageMap()[playerId]
      │   │   │   ├─ if dmgOut:
      │   │   │   │   └─ stats.damageOut += dmgOut.total
      │   │   │   └─ stats.stamina = player:getStamina()
      │
      ├─ CLEANUP 3: Exercise Training
      │   ├─ if _G.OnExerciseTraining[playerId]:
      │   │   ├─ stopEvent(event)
      │   │   ├─ _G.OnExerciseTraining[playerId] = nil
      │   │   └─ player:setTraining(false)
      │
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local playerLogout = CreatureEvent("PlayerLogout")

function playerLogout.onLogout(player)
	local playerId = player:getId()

	-- CLEANUP 1: NextUseStaminaTime
	if _G.NextUseStaminaTime[playerId] then
		_G.NextUseStaminaTime[playerId] = nil
	end

	-- CLEANUP 2: Boss Fight Stats
	local stats = player:inBossFight()
	if stats then
		local boss = Monster(stats.bossId)
		if boss then
			-- Acumular damage (em caso de reconexão)
			local dmgOut = boss:getDamageMap()[playerId]
			if dmgOut then
				stats.damageOut = (stats.damageOut or 0) + dmgOut.total
			end
			-- Salvar stamina
			stats.stamina = player:getStamina()
		end
	end

	-- CLEANUP 3: Exercise Training
	if _G.OnExerciseTraining[playerId] then
		stopEvent(_G.OnExerciseTraining[playerId].event)
		_G.OnExerciseTraining[playerId] = nil
		player:setTraining(false)
	end
	return true
end

playerLogout:register()
```

### Damage Accumulation Detail

```lua
-- Quando player reconecta em boss fight:
-- 1. Dano anterior está em stats.damageOut
-- 2. Novo dano durante logout está em getDamageMap()
-- 3. Combina os dois:

dmgOut = boss:getDamageMap()[playerId]  -- Dano atual
if dmgOut then
	stats.damageOut = (stats.damageOut or 0) + dmgOut.total
	-- (stats.damageOut or 0) = default 0 se não existe
	-- + dmgOut.total = adiciona novo dano
end
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **CreatureEvent onLogout**: Callback disparado ao fazer logout
- **player:getId()**: Obtem ID único do player
- **Global Tables**: _G.NextUseStaminaTime, _G.OnExerciseTraining
- **inBossFight()**: Obtem stats do boss fight (ou nil)
- **Monster(bossId)**: Lookup de monster por ID
- **getDamageMap()**: Obtem mapa de dano por playerId
- **stopEvent()**: Para event previamente schedulado
- **setTraining()**: Flag de training status
- **Damage Accumulation**: (x or 0) + new para não sobrescrever
- **Conditional Cleanup**: Apenas limpa se existe

### Responsabilidades do Handler

1. **Obter**: playerId para lookup
2. **Cleanup stamina**: _G.NextUseStaminaTime
3. **Cleanup boss**: Acumula damage + salva stamina
4. **Cleanup training**: stopEvent + flags
5. **Confirmar**: return true
