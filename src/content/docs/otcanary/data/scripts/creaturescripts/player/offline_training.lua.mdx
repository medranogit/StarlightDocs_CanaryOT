## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener que processa tempo offline para treinamento. Obtém lastLogout, calcula offlineTime (máx 21 dias), valida offlineTrainingSkill. Se nenhum skill selecionado: adiciona tempo ao pool geral (return). Se skill selecionado: limpa selection, valida mínimo 10 minutos, calcula trainingTime (máx 12 horas), compensa remainder. Calcula tries por skill (weapon baseAttackSpeed vs magic manaGainTicks), aplica rate config, adiciona shield training automático (25% do trainamento). Padrão de offline skill training com cálculos complexos.

## Fluxo de Operação

### Operação Principal

```lua
local offlineTraining = CreatureEvent("OfflineTraining")

function offlineTraining.onLogin(player)
	-- Cálculos básicos
	local lastLogout = player:getLastLogout()
	local offlineTime = lastLogout ~= 0 and 
		math.min(os.time() - lastLogout, 86400 * 21) or 0
	local offlineTrainingSkill = player:getOfflineTrainingSkill()
	
	-- Caso 1: Sem skill selecionado
	if offlineTrainingSkill == SKILL_NONE then
		player:addOfflineTrainingTime(offlineTime * 1000)
		return true
	end

	-- Caso 2: Skill selecionado - limpar
	player:setOfflineTrainingSkill(SKILL_NONE)

	-- Validação: mínimo 10 minutos
	if offlineTime < 600 then
		player:sendTextMessage(MESSAGE_OFFLINE_TRAINING, 
			"You must be logged out for more than 10 minutes to start offline training.")
		return true
	end

	-- Calcular time de treinamento (máx 12h)
	local trainingTime = math.max(0, 
		math.min(offlineTime, 
			math.min(43200, player:getOfflineTrainingTime() / 1000)))
	player:removeOfflineTrainingTime(trainingTime * 1000)

	-- Guardar remainder para próxima sessão
	local remainder = offlineTime - trainingTime
	if remainder > 0 then
		player:addOfflineTrainingTime(remainder * 1000)
	end

	-- Validação: mínimo 60 segundos de train
	if trainingTime < 60 then
		return true
	end

	-- Gerar mensagem formatada
	local text = "During your absence you trained for"
	local hours = math.floor(trainingTime / 3600)
	if hours > 1 then
		text = string.format("%s %d hours", text, hours)
	elseif hours == 1 then
		text = string.format("%s 1 hour", text)
	end

	local minutes = math.floor((trainingTime % 3600) / 60)
	if minutes ~= 0 then
		if hours ~= 0 then
			text = string.format("%s and", text)
		end
		if minutes > 1 then
			text = string.format("%s %d minutes", text, minutes)
		else
			text = string.format("%s 1 minute", text)
		end
	end

	text = string.format("%s.", text)
	player:sendTextMessage(MESSAGE_OFFLINE_TRAINING, text)

	-- Calcular tries por skill
	local vocation = player:getVocation()
	local promotion = vocation:getPromotion()
	local topVocation = not promotion and vocation or promotion

	local tries = nil
	if table.contains({ SKILL_CLUB, SKILL_SWORD, SKILL_AXE, SKILL_DISTANCE }, 
		offlineTrainingSkill) then
		-- Weapon skills: baseado em attack speed
		local modifier = topVocation:getBaseAttackSpeed() / 1000
		tries = (trainingTime / modifier) / 
			(offlineTrainingSkill == SKILL_DISTANCE and 4 or 2)
	elseif offlineTrainingSkill == SKILL_MAGLEVEL then
		-- Magic: baseado em mana gain
		local gainTicks = topVocation:getManaGainTicks() / 1000
		if gainTicks == 0 then
			gainTicks = 1
		end
		tries = trainingTime * (vocation:getManaGainAmount() / gainTicks)
	end

	-- Aplicar tries
	local updateSkills = false
	if tries then
		updateSkills = player:addOfflineTrainingTries(offlineTrainingSkill, 
			tries * configManager.getFloat(configKeys.RATE_OFFLINE_TRAINING_SPEED))
	end

	-- Shield training automático (25%)
	if updateSkills then
		player:addOfflineTrainingTries(SKILL_SHIELD, trainingTime / 4)
	end
	return true
end

offlineTraining:register()
```

### Weapon vs Magic Calculation Example

```lua
-- WEAPON EXAMPLE (Sword skill, Knight promoted):
-- baseAttackSpeed = 2000ms → modifier = 2
-- trainingTime = 3600s (1 hora)
-- tries = (3600 / 2) / 2 = 900 tries

-- DISTANCE EXAMPLE (Distance, Paladin promoted):
-- baseAttackSpeed = 1500ms → modifier = 1.5
-- trainingTime = 3600s
-- tries = (3600 / 1.5) / 4 = 600 tries (menos porque é ranged)

-- MAGIC EXAMPLE (Magic, Sorcerer promoted):
-- manaGainTicks = 6000ms → gainTicks = 6
-- manaGainAmount = 50
-- trainingTime = 3600s
-- tries = 3600 * (50 / 6) = 30000 tries
```

### Conceitos-chave

- **CreatureEvent onLogin**: Callback disparado ao fazer login
- **Offline Time Calculation**: math.min com cap de 21 dias

- **Skill Selection**: getOfflineTrainingSkill() + set SKILL_NONE
- **Training Time**: Máximo 12 horas por sessão
- **Weapon Tries**: baseAttackSpeed / 1000 com divisor (2 ou 4)
- **Magic Tries**: manaGainTicks + manaGainAmount calculation
- **Promoted Vocation**: Uses promotion se existe para stats
- **Shield Training**: Automático com 25% do tempo
- **Rate Config**: RATE_OFFLINE_TRAINING_SPEED application
- **Message Formatting**: Hours/minutes com pluralization
- **Remainder Logic**: Overflow volta ao pool

### Responsabilidades do Handler

1. **Get**: lastLogout + offlineTime (max 21 dias)
2. **Validate**: offlineTrainingSkill selection
3. **Pool Case**: Sem skill → add time ao pool
4. **Skill Case**: 
   - Clear selection
   - Validate mínimo 10 minutos
   - Calculate training time (max 12h)
   - Compensate remainder
5. **Message**: Formatado com hours/minutes
6. **Tries**: Calcular por skill (weapon vs magic)
7. **Apply**: addOfflineTrainingTries com rate
8. **Shield**: Automático training
9. **Return**: true (sucesso)
