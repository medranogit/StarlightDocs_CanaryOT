## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de morte de monster que delega para sistema externo. Ao monster morrer: validar se é monster (getMonster()), se não retorna true (silencioso). Se sim: delega para ForgeMonster:onDeath() passando todos os parâmetros e retorna seu resultado. Padrão simples de wrapper que apenas valida e delega.

### Estrutura de Funcionalidades

```
EVENT: "ForgeSystemMonster"
  └─ onDeath(creature, corpse, killer, mostDamageKiller, unjustified, mostDamageUnjustified)
      ├─ targetMonster = creature:getMonster()
      │   └─ Valida se é monster
      │
      ├─ Validação: targetMonster exists?
      │   ├─ NÃO → return true
      │   └─ SIM → Continua
      │
      └─ return ForgeMonster:onDeath(
          creature, corpse, killer, 
          mostDamageKiller, unjustified, 
          mostDamageUnjustified
      )
```

## Fluxo de Operação

### Operação Principal

```lua
local forgeKill = CreatureEvent("ForgeSystemMonster")

function forgeKill.onDeath(creature, corpse, killer, mostDamageKiller, unjustified, mostDamageUnjustified)
	-- Validação: É monster?
	local targetMonster = creature:getMonster()
	if not targetMonster then
		return true
	end

	-- Delegar para sistema externo
	return ForgeMonster:onDeath(creature, corpse, killer, mostDamageKiller, unjustified, mostDamageUnjustified)
end

forgeKill:register()
```

### Execução

```
Monster morre
  │

  │   └─ SIM → Continua
  │
  └─ return ForgeMonster:onDeath(...)
      └─ Delega para sistema externo
          └─ Retorna seu resultado
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **CreatureEvent onDeath**: Callback disparado ao morrer
- **getMonster()**: Valida se creature é monster
- **Validation Check**: Retorna true se não é monster
- **External Delegation**: Passa para ForgeMonster:onDeath()
- **Parameter Forwarding**: Todos os parâmetros repassados
- **Return Delegation**: Return direto da função externa

### Responsabilidades do Handler

1. **Validar**: É monster (getMonster)?
2. **Return true**: Se não é monster (silencioso)
3. **Delegar**: ForgeMonster:onDeath()
4. **Return resultado**: Da função externa

## Patterns e Implementação

### Padrão Monster Validation

Validar se é monster:

```lua
local targetMonster = creature:getMonster()
if not targetMonster then
	return true
end
```

### Padrão Delegation com Passthrough

Delegar com todos os parâmetros:

```lua
return ForgeMonster:onDeath(creature, corpse, killer, mostDamageKiller, unjustified, mostDamageUnjustified)
```
