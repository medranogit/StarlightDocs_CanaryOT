## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de morte de boss com sistema de zona. Ao boss morrer: obtem nome do boss, constrói zone key ("boss." + toKey(name)), lookup zone e BossLever config via name. Se BossLever.timeoutEvent existe: cancela. Se timeAfterKill > 0: envia mensagem avizando tempo, assinala novo event que refresha zona e remove players após timeout (milliseconds). Chama onDeathForDamagingPlayers com callback de screenshot. Padrão complexo com zona management e event scheduling.

## Fluxo de Operação

### Operação Principal

```lua
local onBossDeath = CreatureEvent("BossLeverOnDeath")

function onBossDeath.onDeath(creature)
	-- Validação: creature exists?
	if not creature then
		return true
	end

	-- Construir zone key
	local name = creature:getName()
	local key = "boss." .. toKey(name)
	local zone = Zone(key)

	-- Validação: zone exists?
	if not zone then
		return true
	end

	-- Lookup: BossLever config
	local bossLever = BossLever[name:lower()]
	
	-- Validação: bossLever exists?
	if not bossLever then
		return true
	end

	-- ========== CANCELAR TIMEOUT ANTERIOR ==========
	if bossLever.timeoutEvent then
		stopEvent(bossLever.timeoutEvent)
		bossLever.timeoutEvent = nil
	end

	-- ========== NOVO TIMEOUT (Se configurado) ==========
	if bossLever.timeAfterKill > 0 then
		-- Enviar mensagem avizando
		zone:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
			"The " .. name .. " has been defeated. You have " .. 
			bossLever.timeAfterKill .. " seconds to leave the room.")
		
		-- Schedulr evento de refresh/remoção
		bossLever.timeoutEvent = addEvent(
			function(zn)
				zn:refresh()
				zn:removePlayers()
			end,
			bossLever.timeAfterKill * 1000,  -- Convertendo segundos para ms
			zone
		)
	end

	-- ========== SCREENSHOT PARA DAMAGERS ==========
	onDeathForDamagingPlayers(creature, function(creature, player)
		player:takeScreenshot(SCREENSHOT_TYPE_BOSSDEFEATED)
	end)
	
	return true
end

onBossDeath:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **Zone System**: Zonas com metadata e operações
- **toKey()**: Converte nome para chave (normalizado)
- **BossLever Table**: Config external de bosses
- **addEvent()**: Scheduler de eventos com delay
- **stopEvent()**: Cancelar evento ativo
- **Closure**: Função anônima com acesso externo
- **ms Conversion**: * 1000 para converter segundos
- **sendTextMessage()**: Mensagem na zona
- **onDeathForDamagingPlayers()**: Iterate players que deram dano
- **takeScreenshot()**: Tirar screenshot (achievement)

### Responsabilidades do Handler

1. **Validar**: creature + zone + bossLever exists?
2. **Cancelar**: stopEvent(anterior timeoutEvent)
3. **Enviar**: Mensagem de derrota
4. **Schedule**: addEvent com refresh + removePlayers
5. **Screenshot**: onDeathForDamagingPlayers callback
6. **Confirmar**: return true

## Patterns e Implementação

### Padrão Zone Key Construction

Construir chave de zona:

```lua
local key = "boss." .. toKey(name)
local zone = Zone(key)
```

### Padrão Event Cancellation

Cancelar evento anterior:

```lua
if bossLever.timeoutEvent then
	stopEvent(bossLever.timeoutEvent)
	bossLever.timeoutEvent = nil
end
```

### Padrão Event Scheduling com Closure

Schedulr evento com argumento:

```lua
bossLever.timeoutEvent = addEvent(
	function(zn)
		zn:refresh()
		zn:removePlayers()
	end,
	bossLever.timeAfterKill * 1000,  -- ms
	zone
)
```

### Padrão Damaging Players Callback

Iterar players com dano:

```lua
onDeathForDamagingPlayers(creature, function(creature, player)
	player:takeScreenshot(SCREENSHOT_TYPE_BOSSDEFEATED)
end)
```
