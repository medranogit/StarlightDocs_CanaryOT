## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de morte para White Deer que cria novos monsters por chance. Possui config table com chance (30% Enraged, 100% Desperate), nome do monster e mensagem. Ao morrer: valida se é monster sem master, gera random 1-100, itera config até encontrar chance válida, cria monster na posição, envia magic effect TELEPORT, boss diz mensagem correspondente. Padrão de transformation com probabilidade cumulativa.

### Estrutura de Funcionalidades

```
EVENT: "WhiteDeerDeath"
  └─ onDeath(creature, corpse, killer, mostDamageKiller, lastHitUnjustified, mostDamageUnjustified)
      ├─ config = [
      │   { chance = 30, monster = "Enraged White Deer", message = "..." },
      │   { chance = 100, monster = "Desperate White Deer", message = "..." }
      │ ]
      │
      ├─ Validação: targetMonster:getMaster()?
      │   ├─ SIM → return true (tem master, pula)
      │   └─ NÃO → Continua (wild monster)
      │
      ├─ chance = math.random(100)  -- 1-100
      │   └─ Gera número aleatório
      │
      ├─ for i = 1, #config:
      │   ├─ if chance <= config[i].chance:
      │   │   ├─ spawnMonster = Game.createMonster(config[i].monster, position, true, true)
      │   │   ├─ spawnMonster:getPosition():sendMagicEffect(CONST_ME_TELEPORT)
      │   │   ├─ targetMonster:say(config[i].message)
      │   │   └─ break (para aqui)
      │
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local config = {
	{ chance = 30, monster = "Enraged White Deer", message = "The white deer summons all his strength and turns to fight!" },
	{ chance = 100, monster = "Desperate White Deer", message = "The white deer desperately tries to escape!" },
}

local whiteDeerDeath = CreatureEvent("WhiteDeerDeath")

function whiteDeerDeath.onDeath(creature, corpse, killer, mostDamageKiller, lastHitUnjustified, mostDamageUnjustified)
	local targetMonster = creature:getMonster()
	if not targetMonster or targetMonster:getMaster() then
		return true
	end

	local chance = math.random(100)
	for i = 1, #config do
		if chance <= config[i].chance then
			local spawnMonster = Game.createMonster(config[i].monster, targetMonster:getPosition(), true, true)
			if spawnMonster then
				spawnMonster:getPosition():sendMagicEffect(CONST_ME_TELEPORT)
				targetMonster:say(config[i].message, TALKTYPE_MONSTER_SAY)
			end
			break
		end
	end
	return true
end

whiteDeerDeath:register()
```

### Árvore de Decisão

```
White Deer morre
  │
  ├─ targetMonster = creature:getMonster()
  │   └─ Obtem monster data
  │
  ├─ targetMonster exists && not:getMaster()?
  │   ├─ NÃO (nulo ou tem master) → return true (pula)
  │   └─ SIM (wild monster) → Continua
  │
  ├─ chance = math.random(100)
  │   └─ Número aleatório 1-100
  │
  ├─ for i = 1 to #config:
  │   │
  │   ├─ chance <= config[i].chance?
  │   │   │
  │   │   ├─ SIM:
  │   │   │   │
  │   │   │   ├─ spawnMonster = Game.createMonster(...)
  │   │   │   │   └─ Cria novo monster
  │   │   │   │
  │   │   │   ├─ if spawnMonster:
  │   │   │   │   │
  │   │   │   │   ├─ sendMagicEffect(TELEPORT)
  │   │   │   │   │   └─ Efeito visual
  │   │   │   │   │
  │   │   │   │   └─ targetMonster:say(message)
  │   │   │   │       └─ Boss fala
  │   │   │   │

```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **CreatureEvent onDeath**: Callback disparado ao morrer
- **creature:getMonster()**: Obtem monster data
- **getMaster()**: Valida se tem dono (summon)
- **math.random(100)**: Número aleatório 1-100
- **Cumulative Probability**: Chance cumulativa (não exclusiva)
- **Game.createMonster()**: Cria novo monster no mundo
- **getPosition()**: Obtem position do monster
- **sendMagicEffect()**: Envia efeito mágico
- **creature:say()**: Boss fala mensagem

### Responsabilidades do Handler

1. **Validar**: É wild monster (sem master)?
2. **Gerar**: Número aleatório 1-100
3. **Iterar**: Config table até match
4. **Criar**: Game.createMonster()
5. **Efeito**: Teleport magic effect
6. **Falar**: Boss diz mensagem
7. **Confirmar**: return true
