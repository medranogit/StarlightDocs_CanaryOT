## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de morte para White Deer Scouts. Ao morrer: valida se é wild monster (sem master), gera random 1-100, se &lt;= 10 (10% chance): loop 2 vezes para criar "Elf Scout" na mesma posição, cada um recebe magic effect TELEPORT, scout diz mensagem sobre elves. Padrão simples de spawn condicional em loop.

### Estrutura de Funcionalidades

```
EVENT: "WhiteDeerScoutsDeath"
  └─ onDeath(creature, corpse, killer, mostDamageKiller, lastHitUnjustified, mostDamageUnjustified)
      ├─ Validação: targetMonster:getMaster()?
      │   ├─ SIM → return true (tem master, pula)
      │   └─ NÃO → Continua (wild monster)
      │
      ├─ chance = math.random(100)  -- 1-100
      │   └─ Gera número aleatório
      │
      ├─ if chance <= 10:  -- 10% de chance
      │   │
      │   ├─ for i = 1, 2:  -- Cria 2 scouts
      │   │   ├─ spawnMonster = Game.createMonster("Elf Scout", position, true, true)
      │   │   ├─ if spawnMonster:
      │   │   │   └─ spawnMonster:getPosition():sendMagicEffect(CONST_ME_TELEPORT)
      │   │   │
      │   │   └─ targetMonster:say("The elves came too late to save the deer...")
      │
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local whiteDeerScoutsDeath = CreatureEvent("WhiteDeerScoutsDeath")

function whiteDeerScoutsDeath.onDeath(creature, corpse, killer, mostDamageKiller, lastHitUnjustified, mostDamageUnjustified)
	local targetMonster = creature:getMonster()
	if not targetMonster or targetMonster:getMaster() then
		return true
	end

	local chance = math.random(100)
	if chance <= 10 then
		for i = 1, 2 do
			local spawnMonster = Game.createMonster("Elf Scout", targetMonster:getPosition(), true, true)
			if spawnMonster then
				spawnMonster:getPosition():sendMagicEffect(CONST_ME_TELEPORT)
			end
		end
		targetMonster:say("The elves came too late to save the deer, however they might avenge it.", TALKTYPE_MONSTER_SAY)
	end
	return true
end

whiteDeerScoutsDeath:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **CreatureEvent onDeath**: Callback disparado ao morrer
- **creature:getMonster()**: Obtem monster data
- **getMaster()**: Valida se tem dono (summon)
- **math.random(100)**: Número aleatório 1-100
- **Chance Threshold**: `if chance <= 10` (menor ou igual)
- **Loop for i = 1, 2**: Criar múltiplos monsters
- **Game.createMonster()**: Cria novo monster no mundo
- **getPosition()**: Obtem position
- **sendMagicEffect()**: Efeito visual

### Responsabilidades do Handler

1. **Validar**: É wild monster (sem master)?
2. **Gerar**: Número aleatório 1-100
3. **Testar**: 10% de chance?
4. **Loop**: 2 vezes para criar scouts
5. **Criar**: Game.createMonster("Elf Scout")
6. **Efeito**: Teleport magic effect
7. **Falar**: Scout diz mensagem
8. **Confirmar**: return true

## Patterns e Implementação

### Padrão Chance Threshold

Teste de probabilidade simples:

```lua
local chance = math.random(100)
if chance <= 10 then
	-- 10% de probabilidade
end
```

### Padrão Monster Validation

Validar se é wild monster:

```lua
local targetMonster = creature:getMonster()
if not targetMonster or targetMonster:getMaster() then
	return true

end
```
