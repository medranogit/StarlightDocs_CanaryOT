## 📄 Visão Geral do Código

### Resumo Executivo

O script registra dois listeners de morte para gerenciar spawn system. Ambos validam se creature é monster. `monsterDeath`: obtem spawn object via storage (MonsterStorage.Spawn.monster_spawn_object), executa callback "onDeath", deleta monster da lista. `monsterDeathBoss`: obtem spawn object, remove spawn inteiro e todos os monsters. Padrão de lifecycle management com callbacks.

### Estrutura de Funcionalidades

```
EVENT 1: "monsterDeath"
  └─ onDeath(creature, corpse, killer, mostDamage, unjustified, mostDamageUnjustified)
      ├─ Validação: creature:isMonster()?
      │   ├─ SIM → Continua
      │   └─ NÃO → return true (silencioso)
      │
      ├─ self = creature:getStorageValue(MonsterStorage.Spawn.monster_spawn_object)
      │   └─ Obtem spawn object
      │
      ├─ self:executeFunctionMonster("onDeath", creature)
      │   └─ Executa callback externo
      │
      ├─ self:deleteMonster(creature)
      │   └─ Remove monster da lista
      │
      └─ return true

EVENT 2: "monsterDeathBoss"
  └─ onDeath(creature, corpse, killer, mostDamage, unjustified, mostDamageUnjustified)
      ├─ Validação: creature:isMonster()?
      │   ├─ SIM → Continua
      │   └─ NÃO → return true (silencioso)
      │
      ├─ self = creature:getStorageValue(MonsterStorage.Spawn.monster_spawn_object)
      │   └─ Obtem spawn object
      │
      ├─ self:removeSpawn()
      │   └─ Remove spawn inteiro
      │
      ├─ self:removeMonsters()
      │   └─ Remove todos os monsters
      │
      └─ return true
```

## Fluxo de Operação

### monsterDeath - Regular Monster Death

```lua
local monsterDeath = CreatureEvent("monsterDeath")

function monsterDeath.onDeath(creature, corpse, killer, mostDamage, unjustified, mostDamageUnjustified)
	if creature and creature:isMonster() then
		local self = creature:getStorageValue(MonsterStorage.Spawn.monster_spawn_object)
		self:executeFunctionMonster("onDeath", creature)
		self:deleteMonster(creature)
		return true
	end
	return true
end

monsterDeath:register()
```

### monsterDeathBoss - Boss Death (Cleanup)

```lua
local monsterDeathBoss = CreatureEvent("monsterDeathBoss")

function monsterDeathBoss.onDeath(creature, corpse, killer, mostDamage, unjustified, mostDamageUnjustified)
	if creature and creature:isMonster() then
		local self = creature:getStorageValue(MonsterStorage.Spawn.monster_spawn_object)
		self:removeSpawn()
		self:removeMonsters()
		return true
	end
	return true
end

monsterDeathBoss:register()
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **CreatureEvent onDeath**: Callback disparado ao morrer
- **creature:isMonster()**: Valida se é monster
- **getStorageValue()**: Obtem spawn object (storage)
- **executeFunctionMonster()**: Executa callback na classe spawn
- **deleteMonster()**: Remove monster (mas não o spawn)
- **removeSpawn()**: Remove spawn inteiro
- **removeMonsters()**: Remove todos os monsters do spawn
- **Storage-based Delegation**: Usa storage para obter objeto externo

### Responsabilidades do Handler

**monsterDeath:**
1. **Validar**: creature:isMonster()?
2. **Obter**: spawn object via storage
3. **Callback**: executeFunctionMonster("onDeath")
4. **Deletar**: Apenas este monster
5. **Confirmar**: return true

**monsterDeathBoss:**
1. **Validar**: creature:isMonster()?
2. **Obter**: spawn object via storage
3. **Cleanup**: removeSpawn() + removeMonsters()
4. **Confirmar**: return true

## Patterns e Implementação

### Padrão Storage-based Object Retrieval

Obter objeto armazenado em storage:

```lua
local self = creature:getStorageValue(MonsterStorage.Spawn.monster_spawn_object)
```

### Padrão External Function Execution

Executar função na classe spawn:

```lua
self:executeFunctionMonster("onDeath", creature)
```

### Padrão Regular Monster Cleanup

Deletar apenas este monster:

```lua
self:deleteMonster(creature)
```

### Padrão Boss Cleanup

Deletar spawn inteiro:

```lua
self:removeSpawn()
self:removeMonsters()
```

### Comparação: Regular vs Boss

| Operação | monsterDeath | monsterDeathBoss |
|----------|--------------|------------------|
| Obter spawn | getStorageValue | getStorageValue |
| Callback | executeFunctionMonster | (nenhum) |
| Cleanup | deleteMonster (único) | removeSpawn + removeMonsters |
| Escopo | Monster individual | Spawn inteiro |
