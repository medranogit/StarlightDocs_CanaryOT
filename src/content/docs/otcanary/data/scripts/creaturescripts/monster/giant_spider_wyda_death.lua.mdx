## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de morte para o boss Giant Spider Wyda. Ao morrer: faz o spider dizer mensagem de ilusão ("It seems this was just an illusion."), valida se killer é player, se sim adiciona achievement "Someone's Bored". Padrão simples de death message com achievement grant.

### Estrutura de Funcionalidades

```
EVENT: "GiantSpiderWyda"
  └─ onDeath(creature, corpse, killer, mostDamageKiller, lastHitUnjustified, mostDamageUnjustified)
      ├─ creature:say("It seems this was just an illusion.", TALKTYPE_MONSTER_SAY)
      │   └─ Boss diz mensagem
      │
      ├─ Validação: mostDamageKiller:isPlayer()?
      │   ├─ SIM → mostDamageKiller:addAchievement("Someone's Bored")
      │   └─ NÃO → Pula achievement
      │
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local creatureevent = CreatureEvent("GiantSpiderWyda")

function creatureevent.onDeath(creature, corpse, killer, mostDamageKiller, lastHitUnjustified, mostDamageUnjustified)
	-- Boss diz mensagem de ilusão
	creature:say("It seems this was just an illusion.", TALKTYPE_MONSTER_SAY)

	-- Conceder achievement ao killer
	if mostDamageKiller:isPlayer() then
		mostDamageKiller:addAchievement("Someone's Bored")
	end
	return true
end

creatureevent:register()
```
