## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de morte de familiar. Ao familiar morrer: obtem master (jogador dono), lookup vocation em FAMILIAR_ID, valida se o familiar morto está na lista da vocation (table.contains por nome). Se sim: registra morte via player:kv():set("familiar-summon-time", os.time()), faz loop em FAMILIAR_TIMER table e cancela todos os timers ativos (stopEvent + setStorageValue -1). Padrão de familiar death com cleanup de timers.

## Fluxo de Operação

### Operação Principal

```lua
local familiarOnDeath = CreatureEvent("FamiliarDeath")

function familiarOnDeath.onDeath(creature, corpse, lasthitkiller, mostdamagekiller, lasthitunjustified, mostdamageunjustified)
	-- Obter master (jogador dono)
	local player = creature:getMaster()
	if not player then
		return false
	end

	-- Lookup: Vocation familiar data
	local vocation = FAMILIAR_ID[player:getVocation():getBaseId()]

	-- Validação: É familiar registrado desta vocation?
	if table.contains(vocation, creature:getName()) then
		-- Registrar morte (timestamp)
		player:kv():set("familiar-summon-time", os.time())
		
		-- Cleanup: Cancelar todos os timers
		for sendMessage = 1, #FAMILIAR_TIMER do
			-- Obter ID do timer ativo
			local timerEventId = player:getStorageValue(FAMILIAR_TIMER[sendMessage].storage)
			
			-- Cancelar timer
			stopEvent(timerEventId)
			
			-- Marcar como inativo
			player:setStorageValue(FAMILIAR_TIMER[sendMessage].storage, -1)
		end
	end
	return true
end

familiarOnDeath:register()
```

### Timer Cleanup Loop

```lua
-- Loop sobre todos os timers configurados
for sendMessage = 1, #FAMILIAR_TIMER do
	-- FAMILIAR_TIMER[sendMessage] = { storage = numero }
	local storage = FAMILIAR_TIMER[sendMessage].storage
	
	-- Obter ID do timer ativo do player
	local timerEventId = player:getStorageValue(storage)
	
	-- Cancelar timer
	stopEvent(timerEventId)
	
	-- Marcar como inativo (-1)
	player:setStorageValue(storage, -1)
end
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **getMaster()**: Obtem jogador dono de creature
- **table.contains()**: Validar existência em table
- **player:kv()**: Key-value storage persistente
- **kv():set()**: Registrar timestamp
- **os.time()**: Timestamp Unix atual
- **stopEvent()**: Cancelar event ativo
- **getStorageValue()**: Obter ID de timer
- **setStorageValue()**: Marcar como inativo (-1)
- **Loop de timers**: Cleanup automático de múltiplos timers

### Responsabilidades do Handler

1. **Obter dono**: creature:getMaster()
2. **Validar**: player exists?
3. **Lookup**: vocation = FAMILIAR_ID[baseId]
4. **Verificar**: table.contains(vocation, name)
5. **Registrar**: kv():set("familiar-summon-time", os.time())
6. **Cleanup**: Loop stopEvent + setStorageValue -1
7. **Confirmar**: return true
