## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de login que restaura familiar. Registra event listener "FamiliarAdvance" para este player. Lookup vocation em FAMILIAR_ID. Se não premium E tem familiar: remove familiar. Se level < 200: remove familiar. Se premium E level 200+: calcula familiarTimeLeft (math.max(0, summonTime - agora)), se timeLeft > 0 obtem familiarName, seta looktype e adiciona familiar, depois cria familiar com createFamiliar(name, timeLeft). Padrão complexo com cooldown calculation.

## Fluxo de Operação

### Operação Principal

```lua
local familiarOnLogin = CreatureEvent("FamiliarLogin")

function familiarOnLogin.onLogin(player)
	-- Validação: Player exists?
	if not player then
		return false
	end

	-- Registrar outro listener
	player:registerEvent("FamiliarAdvance")
	
	-- Lookup: Vocation familiar data
	local vocation = FAMILIAR_ID[player:getVocation():getBaseId()]

	-- Variáveis de cooldown
	local familiarName
	local familiarSummonTime = player:kv():get("familiar-summon-time") or 0
	local familiarTimeLeft = math.max(0, familiarSummonTime - os.time())

	if vocation then
		-- Validação 1: Não premium && tem familiar?
		if (not player:isPremium() and player:hasFamiliar(vocation.id)) or player:getLevel() < 200 then
			player:removeFamiliar(vocation.id)
		-- Validação 2: Premium && level 200+?
		elseif player:isPremium() and player:getLevel() >= 200 then
			-- Se tem cooldown ativo: obter nome
			if familiarTimeLeft > 0 then
				familiarName = vocation.name
			end
			
			-- Seta looktype se não possui
			if player:getFamiliarLooktype() == 0 then
				player:setFamiliarLooktype(vocation.id)
			end
			
			-- Adiciona familiar se não possui
			if not player:hasFamiliar(vocation.id) then
				player:addFamiliar(vocation.id)
			end
		end
	end

	-- Recriar familiar se houver cooldown
	if not familiarName then
		return true
	end
	player:createFamiliar(familiarName, familiarTimeLeft)
	return true
end

familiarOnLogin:register()
```

### Cooldown Calculation Example

```lua
-- Exemplo: Familiar morreu há 30 minutos
familiarSummonTime = 1650000000  -- Timestamp de morte
os.time() = 1650001800            -- Agora (30 min depois)

familiarTimeLeft = max(0, 1650000000 - 1650001800)
                 = max(0, -1800)
                 = 0               -- Cooldown expirou

-- Exemplo 2: Familiar morreu há 10 minutos (cooldown = 1 hora)
familiarSummonTime = 1650003600   -- Timestamp de morte
os.time() = 1650004200             -- Agora (10 min depois)

familiarTimeLeft = max(0, 1650003600 - 1650004200)
                 = 0  (ou ainda ativo se summonTime é futuro)

-- Nota: O cooldown é baseado na diferença, não em duração fixa
```

## Checkpoint de Aprendizagem

### Conceitos-chave

- **CreatureEvent onLogin**: Callback disparado ao fazer login
- **registerEvent()**: Registrar listener adicional para player
- **kv():get()**: Obter valor persistente (ou default)
- **os.time()**: Timestamp Unix atual
- **math.max()**: Garantir valor mínimo (não negativo)
- **Premium Gating**: Requisito premium para familiar
- **Level Requirement**: Level 200+ necessário
- **Familiar Restoration**: createFamiliar() com cooldown persistence
- **Looktype Setup**: Visual do familiar

### Responsabilidades do Handler

1. **Validar**: player exists?
2. **Registrar**: registerEvent("FamiliarAdvance")
3. **Lookup**: vocation = FAMILIAR_ID[baseId]
4. **Calcular cooldown**: max(0, summonTime - agora)
5. **Remover inválido**: Sem premium ou level < 200
6. **Restaurar valido**: Premium + level 200+
7. **Recriar**: createFamiliar(name, timeLeft)
8. **Confirmar**: return true
