## 📄 Visão Geral do Código

### Resumo Executivo

O script registra listener de level-up que adiciona familiar ao jogador. Ao fazer advance (level-up): valida se vocation existe em FAMILIAR_ID table (lookup por vocation base ID). Se não premium e newLevel < 200: retorna true silenciosamente. Se vocation existe e premium/level 200+: seta familiarLooktype (visual), verifica e adiciona familiar se não possui. Padrão de familiar system com premium gating.

### Estrutura de Funcionalidades

```
EVENT: "FamiliarAdvance"
  └─ onAdvance(player, skill, oldLevel, newLevel)
      ├─ Lookup: vocation = FAMILIAR_ID[player:getVocation():getBaseId()]
      │
      ├─ Validação: newLevel < 200 && não premium?
      │   └─ SIM → return true (silencioso, sem ação)
      │
      ├─ if vocation:
      │   ├─ getFamiliarLooktype() == 0?
      │   │   └─ SIM → setFamiliarLooktype(vocation.id)
      │   │
      │   ├─ hasFamiliar(vocation.id)?
      │   │   └─ NÃO → addFamiliar(vocation.id)
      │
      └─ return true
```

## Fluxo de Operação

### Operação Principal

```lua
local familiarOnAdvance = CreatureEvent("FamiliarAdvance")

function familiarOnAdvance.onAdvance(player, skill, oldLevel, newLevel)
	-- Lookup: Obter familiar data da vocation
	local vocation = FAMILIAR_ID[player:getVocation():getBaseId()]
	
	-- Validação: Premium + level check
	if newLevel < 200 and not player:isPremium() then
		return true  -- Silencioso, sem ação
	end

	-- Se vocation existe
	if vocation then
		-- Seta looktype se não possui
		if player:getFamiliarLooktype() == 0 then
			player:setFamiliarLooktype(vocation.id)
		end
		
		-- Adiciona familiar se não possui
		if not player:hasFamiliar(vocation.id) then
			player:addFamiliar(vocation.id)
		end
	end
	return true
end

familiarOnAdvance:register()
```

### Conceitos-chave

- **CreatureEvent**: Sistema de listeners para eventos de creature
- **onAdvance**: Callback disparado ao fazer level-up
- **getBaseId()**: Obtem ID base de vocation (sem classe secundária)
- **Premium Gating**: Requisito premium para algumas features
- **Familiar Looktype**: Visual do familiar (ID numérico)
- **Familiar Possession**: Validar e adicionar familiar
- **FAMILIAR_ID Lookup**: Tabela global de mapeamento

### Responsabilidades do Handler

1. **Obter vocation**: FAMILIAR_ID[baseVocationId]
2. **Validar requisitos**: Premium + level 200+
3. **Seta looktype**: Se não possui
4. **Adicionar familiar**: Se não possui
5. **Confirmar**: return true
