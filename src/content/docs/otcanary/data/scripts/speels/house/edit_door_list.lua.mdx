## 🔧 Estrutura de Funcionalidades

### Variável Global: spell

```lua
local spell = Spell("instant")
```

**Propósito:** Instância do spell de edição de porta.

**Tipo:** Instant (sem cast time)

---

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	local currentPos = creature:getPosition()
	local forwardPos = creature:getPosition()
	forwardPos:getNextPosition(creature:getDirection())

	local tile = Tile(currentPos)
	local house = tile and tile:getHouse()
	local doorId = house and house:getDoorIdByPosition(forwardPos)

	if not doorId then
		tile = Tile(currentPos)
		house = tile and tile:getHouse()
		doorId = house and house:getDoorIdByPosition(currentPos)
	end

	if not doorId or not house:canEditAccessList(doorId, creature) then
		creature:sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
		creature:getPosition():sendMagicEffect(CONST_ME_POFF)
		return false
	end

	creature:setEditHouse(house, doorId)
	creature:sendHouseWindow(house, doorId)
	return true
end
```

**Propósito:** Procura porta adjacente/atual e abre editor de acesso.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Caster (house owner/co-owner) |
| `variant` | Variant | Direção ou target |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Janela editora aberta |
| `false` | Erro (sem porta ou sem permissão) |

**Lógica Detalhada:**

1. **Busca de Posição:**
   - `currentPos` = posição atual do creature
   - `forwardPos` = posição frontal (getNextPosition)

2. **Busca de Porta (Frontal):**
   - Tile na posição frontal
   - getHouse() para ambos
   - getDoorIdByPosition(forwardPos)

3. **Fallback Busca Atual:**
   - Se não encontrou na frontal
   - Busca novamente na posição atual
   - Dupla verificação!

4. **Validação:**
   - Verifica se doorId existe
   - canEditAccessList(doorId, creature)
   - Ambas condições obrigatórias

5. **Sucesso:**
   - setEditHouse(house, doorId)
   - sendHouseWindow(house, doorId)
   - Abre interface nativa

6. **Erro:**
   - sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
   - sendMagicEffect(CONST_ME_POFF)
   - Feedback visual/sonoro
