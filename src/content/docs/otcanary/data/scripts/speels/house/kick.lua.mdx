**Tipo:** Instant (sem cast time)

---

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(player, variant)
	local targetPlayer = Player(variant:getString()) or player
	local guest = targetPlayer:getTile():getHouse()
	local owner = player:getTile():getHouse()

	-- Owner kick yourself from house
	if targetPlayer == player then
		player:getPosition():sendMagicEffect(CONST_ME_POFF)
		player:teleportTo(owner:getExitPosition())
		player:getPosition():sendMagicEffect(CONST_ME_TELEPORT)
		return true
	end

	if not owner:canEditAccessList(GUEST_LIST, player) then
		player:sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
		player:getPosition():sendMagicEffect(CONST_ME_POFF)
		return false
	end

	if not owner or not guest or not guest:kickPlayer(player, targetPlayer) then
		player:sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
		player:getPosition():sendMagicEffect(CONST_ME_POFF)
		return false
	end
	return true
end
```

**Propósito:** Remove player da house ou executa self-kick.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Caster (house owner/co-owner) |
| `variant` | Variant | String com player name |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Kick executado (sucesso) |
| `false` | Erro (sem permissão ou house não existe) |

**Lógica Detalhada:**

1. **Obtenção de Target:**
   - `targetPlayer = Player(variant:getString()) or player`
   - Busca player pelo nome
   - Se não encontrado, usa self (fallback)

2. **Obtenção de Houses:**
   - `guest = targetPlayer:getTile():getHouse()`
   - `owner = player:getTile():getHouse()`
   - Ambas as houses (target e caster)

3. **Self-Kick (targetPlayer == player):**
   - Efeito CONST_ME_POFF (antes)
   - `teleportTo(owner:getExitPosition())`
   - Efeito CONST_ME_TELEPORT (depois)
   - Return true (sucesso)

4. **Validação Permissões (outro player):**
   - `canEditAccessList(GUEST_LIST, player)`
   - Se falhar: erro + efeito + return false

5. **Execução Kick:**
   - `guest:kickPlayer(player, targetPlayer)`
   - Remove player da house
   - Validação houses existem

6. **Erro Final:**
   - sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
   - sendMagicEffect(CONST_ME_POFF)

## 🤖 Documentação das Funções

### spell.onCastSpell(player, variant)

**Descrição:** Remove player da house ou executa self-kick com teleportação.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Caster (house owner/co-owner) |
| `variant` | Variant | String contendo player name |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Kick executado com sucesso |
| `false` | Erro (sem permissão ou house não existe) |

**Requisitos:**
- Estar dentro de uma casa
- Para kick de outro: ser owner ou co-owner
- Para self-kick: ser qualquer um na house
- Target player existir (ou fallback para self)

**Lógica de Execução:**

| Cenário | Ação | Efeito |
|---|---|---|
| targetPlayer == player | Teleporta para exit position | POFF + TELEPORT |
| Sem permissão canEditAccessList | Mensagem erro + efeito | POFF |
| Kick bem-sucedido | Remove player da house | Sucesso |
| Kick falha | Mensagem erro + efeito | POFF |
