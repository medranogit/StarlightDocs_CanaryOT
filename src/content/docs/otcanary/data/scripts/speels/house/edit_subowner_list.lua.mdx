### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(player, variant)
	local house = player:getTile():getHouse()
	if not house then
		return false
	end

	if house:canEditAccessList(SUBOWNER_LIST, player) then
		player:setEditHouse(house, SUBOWNER_LIST)
		player:sendHouseWindow(house, SUBOWNER_LIST)
	else
		player:sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
		player:getPosition():sendMagicEffect(CONST_ME_POFF)
	end
	return true
end
```

**Propósito:** Abre editor de co-owners da casa.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Caster (house owner) |
| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Always (sucesso ou erro informado) |
| `false` | Não está em casa |

**Lógica Detalhada:**

1. **Busca de Casa:**
   - getTile() do player
   - getHouse() do tile
   - Se não existe: return false

2. **Validação Permissões:**
   - canEditAccessList(SUBOWNER_LIST, player)
   - Constante SUBOWNER_LIST para tipo
   - Normalmente apenas owner pode editar

3. **Sucesso:**
   - setEditHouse(house, SUBOWNER_LIST)
   - sendHouseWindow(house, SUBOWNER_LIST)
   - Abre interface nativa

4. **Erro:**
   - sendCancelMessage(RETURNVALUE_NOTPOSSIBLE)
   - sendMagicEffect(CONST_ME_POFF)
   - Retorna true (spell executado)
