### Função Global: onTargetCreature

```lua
function onTargetCreature(creature, target)
	local min = 0
	local max = 1000

	if target:isPlayer() then
		return true
	end
	if target:getMaster() then
		return true
	end

	doTargetCombatHealth(0, target, COMBAT_HEALING, min, max, CONST_ME_NONE)
	return true
end
```

**Propósito:** Filtra monsters e cura apenas wild monsters (não players/pets).

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Caster (GM) |
| `target` | Creature | Alvo da área |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Callback executado |
| `false` | Callback falho |

**Lógica de Filtro:**
```
1. Check: target:isPlayer() → IGNORA players
2. Check: target:getMaster() → IGNORA summons/pets
3. Else: doTargetCombatHealth() → cura monster wild
```
