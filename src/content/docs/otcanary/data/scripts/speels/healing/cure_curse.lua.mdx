### Propósito Principal

O spell `cure_curse` oferece dispel de curse/cursed:

- **Tipo:** Dispel Combat
- **Spell ID:** 147
- **Dispel:** CONDITION_CURSED
- **Mana:** 40 (moderado-alto)
- **Level:** 80 (high)
- **Cooldown:** 6s (longo!)
- **Classe:** Paladin exclusive

### Arquitetura

```

├─ setParameter(COMBAT_PARAM_EFFECT, CONST_ME_MAGIC_BLUE)
├─ setParameter(COMBAT_PARAM_DISPEL, CONDITION_CURSED)
└─ setParameter(COMBAT_PARAM_AGGRESSIVE, false)

local spell = Spell("instant")
├─ onCastSpell(creature, variant)
│  └─ return combat:execute(creature, variant)
└─ Configuração spell
   ├─ group: healing
   ├─ mana: 40
   ├─ level: 80
   ├─ premium: true
   └─ vocation: paladin exclusive
```
