### Propósito Principal

O spell `cure_electrification` oferece dispel de energy/electrification:

- **Tipo:** Dispel Combat
- **Spell ID:** 146
- **Dispel:** CONDITION_ENERGY
- **Mana:** 30 (moderado)
- **Level:** 22 (early-mid)
- **Cooldown:** 6s (longo!)
- **Classe:** Druid exclusive

```
├─ setParameter(COMBAT_PARAM_EFFECT, CONST_ME_MAGIC_BLUE)

local spell = Spell("instant")
├─ onCastSpell(creature, variant)
│  └─ return combat:execute(creature, variant)
└─ Configuração spell
   ├─ group: healing
   ├─ mana: 30
   ├─ level: 22
   ├─ premium: true
   └─ vocation: druid exclusive
```
