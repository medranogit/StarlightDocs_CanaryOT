**Descrição:** Calcula healing cure avançado baseado em level + magic level.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `_player` | Player | Caster (não utilizado) |

| `magicLevel` | Integer | Magic level do player |

**Retorno:**

| Valor | Descrição |
|---|---|
| `min` | Healing mínimo: level * 0.2 + magicLevel * 7.22 + 44 |
| `max` | Healing máximo: level * 0.2 + magicLevel * 12.79 + 79 |

**Exemplo de Cálculo:**
```lua
-- Paladin lvl 35, magic lvl 0
-- min = 35 * 0.2 + 0 * 7.22 + 44 = 7 + 0 + 44 = 51
-- max = 35 * 0.2 + 0 * 12.79 + 79 = 7 + 0 + 79 = 86

-- Paladin lvl 50, magic lvl 20
-- min = 50 * 0.2 + 20 * 7.22 + 44 = 10 + 144.4 + 44 = 198.4
-- max = 50 * 0.2 + 20 * 12.79 + 79 = 10 + 255.8 + 79 = 344.8
```
