## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O spell `cure_burning` oferece dispel de burning/fire:

- **Tipo:** Dispel Combat
- **Spell ID:** 145
- **Dispel:** CONDITION_FIRE
- **Mana:** 30 (moderado)
- **Level:** 30 (mid)
- **Cooldown:** 6s (longo!)
- **Classe:** Druid exclusive

### Arquitetura

```
local combat = Combat()
├─ setParameter(COMBAT_PARAM_EFFECT, CONST_ME_MAGIC_BLUE)
├─ setParameter(COMBAT_PARAM_DISPEL, CONDITION_FIRE)
└─ setParameter(COMBAT_PARAM_AGGRESSIVE, false)

local spell = Spell("instant")
├─ onCastSpell(creature, variant)
│  └─ return combat:execute(creature, variant)
└─ Configuração spell
   ├─ group: healing
   ├─ mana: 30
   ├─ level: 30
   ├─ premium: true
   └─ vocation: druid exclusive
```
