## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O spell `intense_recovery` oferece recuperação intensa contínua via condition regeneration:

- **Tipo:** Healing Combat (Self + Condition)
- **Spell ID:** 160
- **Healing:** 40 HP a cada 3 segundos por 60 segundos (2400 total!)
- **Mana:** 165 (alto!)
- **Level:** 100 (mid-high!)
- **Efeito Visual:** CONST_ME_MAGIC_GREEN
- **Cooldown:** 60s (longo!)
- **Vocações:** 4 (knight/paladin exclusive!)

### Arquitetura

```
local cooldown = 60000 -- milis

local combat = Combat()
├─ setParameter(COMBAT_PARAM_EFFECT, CONST_ME_MAGIC_GREEN)
├─ setParameter(COMBAT_PARAM_AGGRESSIVE, false)
└─ addCondition(condition)

local condition = Condition(CONDITION_REGENERATION)
├─ setParameter(CONDITION_PARAM_TICKS, cooldown)
├─ setParameter(CONDITION_PARAM_HEALTHGAIN, 40)
├─ setParameter(CONDITION_PARAM_HEALTHTICKS, 3000)
└─ setParameter(CONDITION_PARAM_BUFF_SPELL, true)

local spell = Spell("instant")
├─ onCastSpell(creature, variant)
│  └─ return combat:execute(creature, variant)
└─ Configuração spell
   ├─ group: healing
   ├─ mana: 165
   ├─ isSelfTarget: true
   └─ vocation: 4 classes
```

- `spell:cooldown()` (cooldown do spell)

### Padrão 1: Condition Regeneration Contínua

