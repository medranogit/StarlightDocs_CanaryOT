### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, magicLevel)
	local min = (level / 5) + (magicLevel * 6.8) + 42
	local max = (level / 5) + (magicLevel * 12.9) + 90
	return min, max
end
```

**Propósito:** Calcula valores mid-high de healing baseado em level + magic level.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Caster |
| `level` | Integer | Level do player |
| `magicLevel` | Integer | Magic level do player |

**Retorno:**

| Valor | Descrição |
|---|---|
| `min` | Healing mínimo mid-high |
| `max` | Healing máximo mid-high |

**Fórmula de Cura:**
```
min = level / 5 + magicLevel * 6.8 + 42
max = level / 5 + magicLevel * 12.9 + 90
Range = [min, max]
```

**Exemplo de Cálculo:**
```lua
-- Druid lvl 30, magic lvl 20
-- min = 30 / 5 + 20 * 6.8 + 42 = 6 + 136 + 42 = 184
-- max = 30 / 5 + 20 * 12.9 + 90 = 6 + 258 + 90 = 354

-- Druid lvl 60, magic lvl 40
-- min = 60 / 5 + 40 * 6.8 + 42 = 12 + 272 + 42 = 326
-- max = 60 / 5 + 40 * 12.9 + 90 = 12 + 516 + 90 = 618
```
