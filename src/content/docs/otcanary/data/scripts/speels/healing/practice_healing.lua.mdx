### Propósito Principal

O spell `practice_healing` oferece cura training universal entry-level com healing fixo baixo para treinar:

- **Tipo:** Healing Combat (Self - Training)
- **Spell ID:** 166
- **Healing:** 5-9 (fixo training!)
- **Mana:** 5 (ultra acessível!)
- **Level:** 1 (entry-level!)
- **Formula:** COMBAT_FORMULA_DAMAGE (-5, 0, -9, 0)
- **Cooldown:** 1s (rápido!)
- **Vocações:** Nenhuma (universal training!)

### Arquitetura

```
local combat = Combat()
├─ setParameter(COMBAT_PARAM_TYPE, COMBAT_HEALING)
├─ setParameter(COMBAT_PARAM_EFFECT, CONST_ME_MAGIC_BLUE)
├─ setParameter(COMBAT_PARAM_DISPEL, CONDITION_PARALYZE)
├─ setParameter(COMBAT_PARAM_AGGRESSIVE, false)
├─ setFormula(COMBAT_FORMULA_DAMAGE, -5, 0, -9, 0)
└─ setCallback(CALLBACK_PARAM_LEVELMAGICVALUE, "onGetFormulaValues")

local spell = Spell("instant")
├─ onCastSpell(creature, variant)
│  └─ return combat:execute(creature, variant)
└─ Configuração spell
   ├─ group: healing
   ├─ mana: 5
   ├─ isSelfTarget: true
   ├─ vocation: none
   └─ needLearn: false
```
