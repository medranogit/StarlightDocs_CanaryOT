### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level * 0 + maglevel * 0.1614) + 8
	local max = (level * 0 + maglevel * 0.2468) + 15
	return min, max
end
```

**Propósito:** Calcula valores de cura mágica baseado apenas em magic level.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|

| `level` | Integer | Level do player (não usado!) |
| `maglevel` | Integer | Magic level do player |

**Retorno:**

| Valor | Descrição |
|---|---|
| `min` | Healing mínimo |
| `max` | Healing máximo |

**Fórmula de Cura:**
