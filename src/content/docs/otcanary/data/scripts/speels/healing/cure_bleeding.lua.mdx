## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O spell `cure_bleeding` oferece dispel de bleeding universal:

- **Tipo:** Dispel Combat
- **Spell ID:** 144
- **Dispel:** CONDITION_BLEEDING
- **Mana:** 30 (moderado)
- **Level:** 45 (mid-high)
- **Cooldown:** 6s (longo!)
- **Classe:** Universal 4-class (druid + knight families)

### Arquitetura

```
local combat = Combat()
├─ setParameter(COMBAT_PARAM_EFFECT, CONST_ME_MAGIC_BLUE)
├─ setParameter(COMBAT_PARAM_DISPEL, CONDITION_BLEEDING)
└─ setParameter(COMBAT_PARAM_AGGRESSIVE, false)

local spell = Spell("instant")
├─ onCastSpell(creature, variant)
│  └─ return combat:execute(creature, variant)
└─ Configuração spell
   ├─ group: healing
   ├─ mana: 30
   ├─ level: 45
   ├─ premium: true
   └─ vocation: universal 4-class
```
