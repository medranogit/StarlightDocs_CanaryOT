## 📄 Visão Geral do Código - Resumo Executivo

O spell `swift_foot.lua` implementa haste super-agressiva premium para Paladins (level 55+) com sincronização inteligente de familiares e lógica WOD bifurcada oferecendo trade-off entre penalties (sem Wheel) vs damage buff (com Wheel). É versão mais extrema de haste, com fórmula (1.8, 72) super agressiva combinada com estratégia de compensação via Wheel. O spell calcula sincronização proporcional de familiares com factor 0.8, executa combat com haste, valida sucesso, consulta Wheel, aplica ou penalties (3 conditions se GRADE_NONE) ou damage buff +50 (se GRADE_REGULAR). A implementação demonstra padrão avançado de sincronização com bifurcação WOD simétrica (dois caminhos equilibrados).

## 🎯 Padrões Identificados

### 1. **Padrão de Sincronização com Factor Alto (0.8)**
```lua
local deltaSpeed = math.max(creature:getBaseSpeed() - summon:getBaseSpeed(), 0)
local FamiliarSpeed = ((summon:getBaseSpeed() + deltaSpeed) * 0.8) - 72
```
Factor 0.8 (80%) vs 0.7 (70%) em Strong Haste - familiares ganham mais velocidade.

### 2. **Padrão de WOD Bifurcado Simétrico**
```lua
if grade == WHEEL_GRADE_NONE then
    -- Aplica 3 penalties
elseif grade == WHEEL_GRADE_REGULAR then
    -- Aplica damage buff +50
end
```
Dois caminhos equilibrados: sem Wheel = penalties, com Wheel = buff positivo.

### 3. **Padrão de Três Penalties Simultâneos**
```lua
local exhaust = Condition(CONDITION_EXHAUST_COMBAT)
local disable = Condition(CONDITION_PACIFIED)
local exhaustAttackGroup = Condition(CONDITION_SPELLGROUPCOOLDOWN)
```
Exhaust (cooldown), pacify (sem ataque), + group cooldown attack.

### 4. **Padrão de Combat Executado antes de Condições Adicionais**
```lua
if combat:execute(creature, var) then
    -- Adiciona condições extras
    return true
end
return false
```
Combat com haste primeiro, depois bifurcação WOD.

### 5. **Padrão de Haste Agressiva com Offset Alto**
```lua
condition:setFormula(1.8, 72, 1.8, 72)
```
Offset 72 (vs 56 padrão, 40 em Strong Haste) - mais agressivo.

## 🤖 Documentação das Funções

### `spell.onCastSpell(creature, var)`

**Descrição:** Função principal de execução do spell. Sincroniza familiares, executa haste, aplica trade-off WOD bifurcado.

**Parâmetros:**
- `creature` (Creature/Player): Paladin que executa o spell.
- `var` (Variant): Dados variáveis (self target).

**Fluxo de Execução:**

1. **Sincronização de Familiares**:
   - Obtém `summons = creature:getSummons()`
   - Valida existência, tipo tabela, quantidade > 0
   - Para cada summon:
     - Valida se é familiar via `summon_t:familiar()`
     - Calcula `deltaSpeed = math.max(creature speed - summon speed, 0)`
     - Calcula `FamiliarSpeed = ((summon speed + deltaSpeed) * 0.8) - 72`
     - Cria Condition CONDITION_HASTE com ticks 10000
     - Seta parâmetro SPEED com FamiliarSpeed calculado
     - Aplica ao summon

2. **Execução de Combat**:
   - `combat:execute(creature, var)`
   - Aplica CONDITION_HASTE com formula (1.8, 72)
   - Efeito visual CONST_ME_MAGIC_GREEN

3. **Validação de Sucesso**:
   - Se combat falhou: `return false`

4. **Consulta de Wheel**:
   - `grade = creature:upgradeSpellsWOD("Swift Foot")`

5. **Bifurcação WOD - Caminho GRADE_NONE**:
   - Se `grade == WHEEL_GRADE_NONE`:
     - Cria e aplica CONDITION_EXHAUST_COMBAT (ticks 10000)
     - Cria e aplica CONDITION_PACIFIED (ticks 10000)
     - Cria e aplica CONDITION_SPELLGROUPCOOLDOWN subid 1 (ticks 10000)
     - Retorna `true`

6. **Bifurcação WOD - Caminho GRADE_REGULAR**:
   - Senão se `grade == WHEEL_GRADE_REGULAR`:
     - Cria Condition CONDITION_ATTRIBUTES
     - Seta ticks 10000
     - Adiciona buff damage dealt +50 (CONDITION_PARAM_BUFF_DAMAGEDEALT)
     - Aplica ao creature
     - Retorna `true`

**Valores de Retorno:**
- `true`: Haste aplicada com trade-off WOD, mana de 400 consumida
- `false`: Combat falhou, mana não consumida

**Lógica Detalhada:**

O spell implementa haste super-agressiva (1.8x) com sistema de balanceamento via Wheel. A fórmula (1.8, 72) é a mais extrema em todo o sistema, oferecendo velocidade massiva.

A sincronização com factor 0.8 (80%) permite familiares ganhar 80% da diferença de velocidade, deixando-os muito rápidos. Offset 72 é correspondente.

A lógica WOD oferece trade-off interessante:
- Sem Wheel: velocidade max (1.8x) mas com penalties (exhaust + pacify + cooldown)
- Com Wheel: velocidade max (1.8x) + damage buff +50, sem penalties

Isso incentiva investimento em Wheel: players com Wheel ganham pure offense, sem-Wheel ganham pure defense/mobility.

A duração de 10 segundos combina com cooldown de 10 segundos - permite manter ativo com timing perfeito.

A mana de 400 é investimento extremo para level 55, tornando spell de uso estratégico.

**Sound Effect:**
- `SOUND_EFFECT_TYPE_SPELL_SWIFT_FOOT`: Som característico

## 📌 Resumo

**Swift Foot** é um spell de suporte premium para Paladins (level 55+) que aplica haste super-agressiva (1.8x, -72) ao caster, sincroniza proporcional de familiares (factor 0.8), e oferece trade-off WOD bifurcado: sem Wheel aplica 3 penalties (exhaust, pacify, attack cooldown), com Wheel aplica damage buff +50. O spell requer 400 de mana e cooldown de 10 segundos (2s grupo). A duração é 10 segundos em todas as conditions. É ferramenta ofensiva extrema para Paladins, oferecendo velocidade máxima com balanceamento via Wheel investing.

A implementação segue padrão avançado de sincronização multi-target com bifurcação WOD simétrica, diferenciando-se por: (1) factor sincronização alto (0.8), (2) haste agressiva (1.8x), (3) offset alto (72), (4) WOD bifurcado com penalties vs buff, (5) mana extremamente alta (400).
