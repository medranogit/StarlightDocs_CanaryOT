## 📄 Visão Geral do Código - Resumo Executivo

O spell `haste.lua` implementa buff de haste premium para todas as vocações (level 14+) que aumenta velocidade de movimento do caster em 1.3x com suporte opcional de sincronização de familiares. É versão universal (todas vocações) de Charge, parametrizada com duração mais curta (30s vs Charge 5s) e fatores de sincronização diferentes. O spell obtém summons se existem, filtra familiares, calcula velocidade proporcional com fator 0.3 (vs Charge 0.9), aplica condition separada com duração 33s para familiares, executa combat para caster. A implementação demonstra padrão de sincronização familiar com parâmetros vocação-específicos.

## 🤖 Documentação das Funções

### `spell.onCastSpell(creature, variant)`

**Descrição:** Função principal de execução do spell. Aplica buff de haste ao caster e dinamicamente ajusta familiares se existem.

**Parâmetros:**
- `creature` (Creature/Player): Qualquer player (todas vocações) que conjura o spell.
- `variant` (Variant): Dados variáveis (não utilizados - self target).

**Fluxo de Execução:**

1. **Obtenção de Summons**:
   - Chama `creature:getSummons()`
   - Valida tipo table e existência de elementos
   - Se vazio, pula loop de familiares

2. **Iteração sobre Summons** (se existem):
   - Loop `for i = 1, #summons`
   - Obtém `summon_t = summon:getType()`

3. **Filtro de Familiares**:
   - Verifica `summon_t:familiar()`
   - Ignora summons que não são familiares

4. **Cálculo de Velocidade Individual**:
   - Calcula `deltaSpeed = math.max(creature:getBaseSpeed() - summon:getBaseSpeed(), 0)`
   - Diferença positiva em pixels/sec

5. **Ajuste Proporcional com Fator 0.3**:
   - Calcula `FamiliarSpeed = ((summon:getBaseSpeed() + deltaSpeed) * 0.3) - 24`
   - Aplica 30% do ajuste (vs 90% em Charge)
   - Subtrai penalidade de 24 pixels/sec

6. **Aplicação de Haste na Familiar**:
   - Cria `FamiliarHaste = Condition(CONDITION_HASTE)` separada
   - Define duração para 33.000 ms (3s extra vs caster)
   - Aplica velocidade customizada via setParameter
   - Adiciona à familiar

7. **Aplicação de Haste no Caster**:
   - Executa `combat:execute(creature, variant)`
   - Combat aplica condition base (1.3x formula) ao caster
   - Duração 30.000 ms
   - Efeito visual CONST_ME_MAGIC_GREEN

8. **Retorno**:
   - Retorna `true` (cast bem-sucedido)

**Valores de Retorno:**
- `true`: Spell executado, mana de 60 consumida

**Lógica Detalhada:**

O spell implementa haste universal com sincronização familiar sofisticada. O fator 0.3 é mais conservador que Charge 0.9 - indica que Haste é spell base para todas vocações, enquanto Charge é exclusive de Knights com bonus de sincronização alta.

O multiplicador 1.3x (30% aumento) vs Charge 1.9x (90% aumento) reflete diferença de design - Haste é mais acessível universalmente, Charge é premium high-level.

A duração de 30s para caster e 33s para familiar oferece 3s buffer - familiar não fica para trás quando haste expira no caster.

A mana de 60 é baixa para level 14, tornando acessível cedo no jogo para premium players. Premium-only flag força subscription.

## 📌 Resumo

**Haste** é um spell de suporte premium para TODAS as vocações (level 14+) que aplica buff de haste aumentando velocidade de movimento do caster em 1.3x com sincronização opcional de familiares por 30 segundos (33 para familiares). O spell requer 60 de mana e cooldown de 2 segundos. A implementação itera summons dinamicamente, filtra familiares, e aplica velocidade proporcional com fator 0.3 (conservador) e penalidade -24. É versão universal de Charge, acessível a todas vocações. Crítico para mobilidade em exploração prolongada, permitindo deslocamento rápido mantendo formação familiar sincronizada para familiares que existem.

A implementação segue padrão de sincronização familiar com parâmetros reduzidos, diferenciando-se por: (1) acesso universal, (2) fator de sincronização 0.3 (vs Charge 0.9), (3) duração 30s caster/33s familiar, (4) multiplicador 1.3x (vs Charge 1.9x), (5) premium-only access.
