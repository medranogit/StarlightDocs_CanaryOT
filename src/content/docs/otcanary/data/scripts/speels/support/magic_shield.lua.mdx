## 📄 Visão Geral do Código - Resumo Executivo

O spell `magic_shield.lua` implementa manashield escalável para Druids e Sorcerers (level 14+) que calcula valor de shield dinamicamente baseado em fórmula de level e magic level com bônus opcional do Wheel de Destiny. É um dos poucos spells que calcula valor de condition manualmente dentro do cast ao invés de usar valor fixo. O spell obtém player, consulta Wheel de Destiny, calcula shield via fórmula (300 + 7.6*level + 7*magic), aplica bônus 1.25x se Wheel ativo, capa ao maxMana, cria condition, aplica, e executa combat visual. A implementação demonstra padrão avançado de cálculo dinâmico com integração WOD.

## 🎯 Padrões Identificados

### 1. **Padrão de Cálculo Dinâmico em Cast**
```lua
local shield = 300 + 7.6 * player:getLevel() + 7 * player:getMagicLevel()
```
Calcula shield dinamicamente no momento de cast, não valor fixo.

### 2. **Padrão de Bônus WOD Condicional**
```lua
local grade = player:upgradeSpellsWOD("Magic Shield")
if grade >= WHEEL_GRADE_REGULAR then
    shield = shield * 1.25
end
```
Consulta Wheel e aplica 25% bônus se grade suficiente.

### 3. **Padrão de Cap ao MaxMana**
```lua
condition:setParameter(CONDITION_PARAM_MANASHIELD, math.min(player:getMaxMana(), shield))
```
Shield não pode exceder maxMana do player.

### 4. **Padrão de Condition Manual Pré-Cast**
```lua
local condition = Condition(CONDITION_MANASHIELD)
condition:setParameter(CONDITION_PARAM_TICKS, 180000)
...
creature:addCondition(condition)
return combat:execute(creature, var)
```
Condition é criada e aplicada antes de combat, não integrada no combat.

### 5. **Padrão de Cooldown Discrepante**
```lua
spell:cooldown(14 * 1000)
spell:groupCooldown(2 * 1000)
```
Cooldown individual longo (14s) vs grupo curto (2s).

## 🤖 Documentação das Funções

### `spell.onCastSpell(creature, var)`

**Descrição:** Função principal de execução do spell. Calcula e aplica manashield com fórmula dinâmica e bônus WOD.

**Parâmetros:**
- `creature` (Creature/Player): Druid ou Sorcerer que executa o spell.
- `var` (Variant): Dados variáveis (não utilizados - self target).

**Fluxo de Execução:**

1. **Criação de Condition**:
   - Cria `condition = Condition(CONDITION_MANASHIELD)`
   - Seta duração: `CONDITION_PARAM_TICKS = 180000` (3 minutos)

2. **Obtenção de Conversão Player**:
   - `player = creature:getPlayer()`
   - Permite acesso a getLevel() e getMagicLevel()

3. **Consulta de Wheel de Destiny**:
   - `grade = player:upgradeSpellsWOD("Magic Shield")`
   - Obtém nível de upgrade (0 = nenhum, 1+ = gradual)

4. **Cálculo de Shield com Fórmula**:
   - `shield = 300 + 7.6 * player:getLevel() + 7 * player:getMagicLevel()`
   - Base 300, +7.6 por level, +7 por magic level
   - Linear scaling com atributos

5. **Aplicação de Bônus WOD**:
   - Se `grade >= WHEEL_GRADE_REGULAR`:
     - `shield = shield * 1.25` (25% bônus)
   - Se grade < regular: sem bônus

6. **Cap ao MaxMana**:
   - `math.min(player:getMaxMana(), shield)`
   - Shield nunca excede mana máxima

7. **Setagem do Shield na Condition**:
   - `condition:setParameter(CONDITION_PARAM_MANASHIELD, ...)`
   - Aplica valor calculado à condition

8. **Aplicação de Condition**:
   - `creature:addCondition(condition)`
   - Condition é adicionada ao creature

9. **Execução de Combat**:
   - `combat:execute(creature, var)`
   - Aplica apenas efeito visual (CONST_ME_MAGIC_BLUE)

10. **Retorno**:
    - Retorna `true` (cast bem-sucedido, mana consumida)

**Valores de Retorno:**
- `true`: Shield aplicado, mana de 50 consumida

**Lógica Detalhada:**

O spell implementa manashield escalável com fórmula que cresce com progressão do player. A base de 300 oferece proteção inicial, e os multiplicadores (7.6, 7) permitem crescimento significativo conforme player avança.

O bônus WOD de 25% é incentivo para investir em Wheel - players investindo Wheel ganham shield 25% maior. Sem Wheel: baseline. Com Wheel: +25%.

A cap ao maxMana é crítica - previne que shield exceda total de mana do player (mana nunca pode ser negativa).

A duração de 180 segundos (3 minutos) é padrão para buffs defensivos. Cooldown individual de 14s força planejamento - player não pode manter shield constantemente mesmo se solo. Cooldown de grupo de 2s significa que em grupo de players com magic shield, cada um espera 14s, depois próximo pode recast após 2s (para sincronização).

A aplicação manual de condition antes de combat é incomum - oferece mais controle. Combat é usado apenas para efeito visual, não para condition application.

**Sound Effect:**
- `SOUND_EFFECT_TYPE_SPELL_MAGIC_SHIELD`: Som característico

**Mensagens ao Jogador:**
- Nenhuma mensagem verbal

## 📌 Resumo

**Magic Shield** é um spell de suporte gratuito para Druids e Sorcerers (level 14+) que cria manashield com valor calculado dinamicamente via fórmula (300 + 7.6*level + 7*magic) capped ao maxMana e modificado por Wheel de Destiny (1.25x se WHEEL_GRADE_REGULAR+). O spell requer 50 de mana e cooldown individual de 14 segundos (2s em grupo). A duração é 3 minutos. A implementação calcula shield manualmente no momento de cast, consulta Wheel dinamicamente, aplica condition separada antes de combat visual. É ferramenta defensiva essencial para mages, permitindo absorver dano antes que mana verdadeira seja subtraída. O scaling com level + magic level garante que shield cresce com progressão do player.

A implementação segue padrão de cálculo dinâmico com integração WOD, diferenciando-se por: (1) fórmula de shield calculada em cast, (2) escalagem com level+magic, (3) bônus WOD condicional (1.25x), (4) cap ao maxMana, (5) condition manual pré-cast, (6) cooldown individual longo (14s).
