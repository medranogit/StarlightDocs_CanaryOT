## 📄 Visão Geral do Código - Resumo Executivo

O spell `find_person.lua` implementa localizador de players para todos (level 8+) que encontra player específico por nome e fornece inteligência de localização (direção, distância, nível). É variante player-specific de Find Fiend com lógica similar de trigonometria para direção. O spell recebe nome como parâmetro, obtém Player object via lookup, valida se player tem access maior (previne localização de admins), calcula diferença de posição, determina direção via cálculo de ângulo, classifica distância e nível, e fornece relatório de localização. A implementação demonstra padrão parametrizado com validação de access para segurança administrativa.

## 🎯 Padrões Identificados

### 1. **Padrão de Lookup de Player por Nome**
```lua
local target = Player(variant:getString())
if not target or target:getGroup():getAccess() and not creature:getGroup():getAccess() then
    creature:sendCancelMessage(RETURNVALUE_PLAYERWITHTHISNAMEISNOTONLINE)
    return false
end
```
Obtém Player via string, valida existência E validação de access.

### 2. **Padrão de Validação de Access (Segurança Administrativa)**
```lua
if target:getGroup():getAccess() and not creature:getGroup():getAccess() then
    -- target tem access E caster NÃO tem
    -- Bloqueia localização
end
```
Previne que players normais localizem admins/moderators.

### 3. **Padrão de Cálculo de Direção Idêntico a Find Fiend**
```lua
local maxPositionDifference, direction = math.max(math.abs(positionDifference.x), math.abs(positionDifference.y))
if maxPositionDifference >= 5 then
    local positionTangent = positionDifference.x ~= 0 and positionDifference.y / positionDifference.x or 10
```
Algoritmo trigonométrico reusado de Find Fiend, com thresholds para 8 direções.

### 4. **Padrão de Classificação de Distância Idêntico**
```lua
local distance = maxPositionDifference < 5 and DISTANCE_BESIDE or maxPositionDifference < 101 and DISTANCE_CLOSE or maxPositionDifference < 275 and DISTANCE_FAR or DISTANCE_VERYFAR
```
Mesmos thresholds: 5 (beside), 101 (close), 275 (far).

### 5. **Padrão de Construção de Mensagem Simplificada**
```lua
creature:sendTextMessage(MESSAGE_LOOK, target:getName() .. " " .. message .. ".")
```
Diferente de Find Fiend, aqui é simpler: apenas "PlayerName [direction message].".

## 🤖 Documentação das Funções

### `spell.onCastSpell(creature, variant)`

**Descrição:** Função principal de execução do spell. Localiza player específico por nome e fornece direção, distância e nível relativo.

**Parâmetros:**
- `creature` (Creature/Player): Player que executa o spell.
- `variant` (Variant): Contém nome do player alvo como string via `getString()`.

**Fluxo de Execução:**

1. **Lookup de Player**:
   - Chama `target = Player(variant:getString())`
   - Convertendo string para Player object
   - Se não encontrado: `target` é null

2. **Validações de Existência e Access**:
   - Verifica `if not target` (player não existe)
   - Verifica acesso: `target:getGroup():getAccess() and not creature:getGroup():getAccess()`
     - Se target tem access (admin/support) E caster NÃO tem access:
       - Bloqueia localização (segurança)
   - Se alguma condição falha:
     - Envia `RETURNVALUE_PLAYERWITHTHISNAMEISNOTONLINE` (engine traduz para mensagem)
     - Aplica efeito visual erro `CONST_ME_POFF`
     - Retorna `false`

3. **Cálculo de Diferença de Posição**:
   - `targetPosition = target:getPosition()`
   - `creaturePosition = creature:getPosition()`
   - `positionDifference = {x: diff_x, y: diff_y, z: diff_z}`

4. **Cálculo de Distância Máxima**:
   - `maxPositionDifference = max(|diff_x|, |diff_y|)`

5. **Cálculo de Direção (se >= 5)**:
   - Idêntico a Find Fiend:
     - Calcula tangente: `positionTangent = diff_y / diff_x`
     - Usa 3 thresholds:
       - `|tan| < 0.4142`: EAST/WEST
       - `|tan| < 2.4142`: NE/SE/NW/SW
       - Senão: NORTH/SOUTH

6. **Classificação de Nível Vertical**:
   - Se `z > 0`: LEVEL_HIGHER
   - Se `z < 0`: LEVEL_LOWER
   - Senão: LEVEL_SAME

7. **Classificação de Distância**:
   - `< 5`: DISTANCE_BESIDE
   - `< 101`: DISTANCE_CLOSE
   - `< 275`: DISTANCE_FAR
   - Senão: DISTANCE_VERYFAR

8. **Obtenção de Mensagem**:
   - Obtém `messages[distance][level]` se existe
   - Se não: usa `messages[distance]` (genérica)
   - Se não beside: concatena `directions[direction]`

9. **Construção de Mensagem Final**:
   - `message = target:getName() .. " " .. message .. "."`
   - Exemplo: `"PlayerName is to the north."`

10. **Envio de Mensagem**:
    - `creature:sendTextMessage(MESSAGE_LOOK, message)`
    - Efeito visual: `creaturePosition:sendMagicEffect(CONST_ME_MAGIC_BLUE)`

11. **Retorno**:
    - Retorna `true` (localização bem-sucedida)

**Valores de Retorno:**
- `true`: Player encontrado, informação enviada, mana de 20 consumida
- `false`: Player não existe ou access check failed

**Lógica Detalhada:**

O spell implementa localizador player-específico simples mas poderoso. A validação de access é crítica - previne que players normais localizem staff members que optaram por invisibilidade administrativa. A lógica é:
- Admins (access > 0) não podem ser localizados por players normais
- Mas admins PODEM localizar players (access override)

A trigonometria é idêntica a Find Fiend, reusando mesmos cálculos e thresholds. O algoritmo oferece boa resolução angular (8 direções) sem custoso arcsine/arccosine.

A mana minimal (20) e level baixíssimo (8) tornam acessível logo no início do jogo. Original Tibia permite Find Person desde level 8, indicando que é ferramenta básica de mobilidade social.

O hasPlayerNameParam true indica que cliente fornecerá autocomplete/interface para seleção de player. O spell não requer invocação de nome exato - client pode fornecer verificação de typo.

**Sound Effect:**
- `SOUND_EFFECT_TYPE_SPELL_FIND_PERSON`: Som característico

**Mensagens ao Jogador:**
- Sucesso: `"PlayerName [direction and distance description]."`
  - Exemplos:
    - "Player is standing next to you."
    - "Player is to the north."
    - "Player is far to the south-west."
- Falha (não existe ou access denied): RETURNVALUE_PLAYERWITHTHISNAMEISNOTONLINE (traduzido pelo engine)

## 📌 Resumo

**Find Person** é um spell informativo gratuito para todos (level 8+) que localiza player específico por nome e fornece relatório de localização incluindo direção (8 pontos cardeais), distância relativa (beside/close/far/veryfar), e nível vertical (above/same/below). O spell requer apenas 20 de mana e cooldown de 2 segundos. A implementação inclui validação de access para segurança - admins/staff não podem ser localizados por players normais, prevenindo stalking. O parâmetro requer nome de player via hasPlayerNameParam, permitindo autocomplete do client. É ferramenta social fundamental, permitindo players encontrar amigos, guildmates, ou rivais em mundos grandes. O cálculo trigonométrico oferece 8 direções via thresholds de tangente.

A implementação segue padrão informativo parametrizado com validação de access, diferenciando-se por: (1) lookup de player por nome, (2) validação de access para segurança, (3) trigonometria para 8-direções, (4) classificação dinâmica de distância, (5) mensagem simplificada comparada a Find Fiend, (6) acesso extremamente cedo (level 8).
