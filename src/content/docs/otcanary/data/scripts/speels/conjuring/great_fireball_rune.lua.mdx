## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O spell `great_fireball_rune` oferece conjuração em batch de runa grande bola:

- **Tipo:** Conjuring (invocação)
- **Item:** Runa Grande Bola de Fogo (3191)
- **Quantidade:** 4 runes per cast
- **Mana:** 530 (moderado-caro)
- **Soul:** 3 (moderado)
- **Level:** 30 (high)
- **Upgrade:** Versão melhorada de fireball_rune (batch menor mas mais dano)

### Arquitetura

```
local spell = Spell("instant")
├─ onCastSpell(creature, variant)
│  ├─ creature:conjureItem(baseID, runeID, quantity)
│  └─ return success
└─ Configuração spell
   ├─ group: support
   ├─ mana: 530
   ├─ soul: 3
   └─ vocation: sorcerer exclusive
```

### Função Global: spell.onCastSpell

```lua

	return creature:conjureItem(3147, 3191, 4)
end
```

**Parâmetros:**
