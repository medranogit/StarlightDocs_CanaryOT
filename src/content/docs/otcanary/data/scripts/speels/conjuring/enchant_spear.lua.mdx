```lua

	return creature:conjureItem(3277, 7367, 1, CONST_ME_MAGIC_GREEN)
end
```

**Parâmetros:**

| Spear Item ID | 7367 | ID específico lança encantada |
| Quantidade | 1 | 1 lança por cast |
| Efeito Visual | CONST_ME_MAGIC_GREEN | Efeito verde na conjuração |
