- **Item:** Runa Tempestade Trovejante (3202)
- **Quantidade:** 4 runes per cast
- **Mana:** 430 (moderado)
- **Soul:** 3 (moderado)

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(3147, 3202, 4)
end
```

**Propósito:** Conjura batch de 4 runes tempestade trovejante.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Runes conjuradas com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| Base Item ID | 3147 | ID base da runa |
| Rune Item ID | 3202 | ID específico runa tempestade trovejante |
| Quantidade | 4 | 4 runes por cast |
