### Propósito Principal

O spell `wild_growth_rune` oferece conjuração em batch de runa crescimento selvagem:

- **Tipo:** Conjuring (invocação)
- **Item:** Runa Crescimento Selvagem (3156)
- **Quantidade:** 2 runes per cast
- **Mana:** 600 (moderado-alto)
- **Soul:** 5 (moderado)
- **Level:** 27 (mid)
- **Premium:** Sim (account required!)
- **Elemento:** Grav Vita (gravidade + vida)

### Arquitetura

```
local spell = Spell("instant")
├─ onCastSpell(creature, variant)

│  └─ return success
└─ Configuração spell
   ├─ group: support
   ├─ mana: 600
   ├─ soul: 5
   ├─ premium: true
   └─ vocation: druid exclusive
```

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(3147, 3156, 2)
end
```

**Propósito:** Conjura batch de 2 runes crescimento selvagem.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Runes conjuradas com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| Base Item ID | 3147 | ID base da runa |
| Rune Item ID | 3156 | ID específico runa crescimento selvagem |
| Quantidade | 2 | 2 runes por cast |
