- **Tipo:** Conjuring (invocação)
- **Item:** Runa Púa de Gelo (3158)
- **Quantidade:** 5 runes per cast (BATCH!)
- **Mana:** 460 (moderado)
- **Soul:** 3 (moderado)
- **Level:** 28 (mid)
- **Premium:** Sim (account required!)
- **Elemento:** Frigo (gelo/frio - NOVO!)

```
local spell = Spell("instant")

   ├─ soul: 3
   ├─ premium: true
```

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(3147, 3158, 5)
end
```

**Propósito:** Conjura batch de 5 runes púa de gelo.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Runes conjuradas com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| Base Item ID | 3147 | ID base da runa |
| Rune Item ID | 3158 | ID específico runa púa de gelo |
| Quantidade | 5 | 5 runes por cast |
