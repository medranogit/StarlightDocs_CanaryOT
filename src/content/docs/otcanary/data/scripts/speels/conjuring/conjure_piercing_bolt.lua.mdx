### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(0, 7363, 5, CONST_ME_MAGIC_BLUE)
end
```

**Propósito:** Conjura batch de 5 projéteis perfurantes.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Projéteis conjurados com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| Base Item ID | 0 | Sem base específica |
| Bolt Item ID | 7363 | ID específico projétil perfurante |
| Quantidade | 5 | 5 projéteis por cast |
| Efeito Visual | CONST_ME_MAGIC_BLUE | Efeito azul na conjuração |
