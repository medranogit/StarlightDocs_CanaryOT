### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(3147, 3203, 1)
end
```

**Propósito:** Conjura runa morta.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|

| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Runa conjurada com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| Base Item ID | 3147 | ID base da runa |
| Rune Item ID | 3203 | ID específico runa morta |
| Quantidade | 1 | 1 runa por cast |
