## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O spell `ultimate_healing_rune` oferece conjuração single de runa de cura suprema:

- **Tipo:** Conjuring (invocação)
- **Item:** Runa Cura Suprema (3160)
- **Quantidade:** 1 rune per cast (single!)
- **Mana:** 400 (moderado)
- **Soul:** 3 (moderado)
- **Level:** 24 (mid)
- **Tipo Runa:** Healing Ultimate (upgrade!)

### Arquitetura

```
local spell = Spell("instant")
├─ onCastSpell(creature, variant)
│  ├─ creature:conjureItem(baseID, runeID, quantity)
│  └─ return success
└─ Configuração spell
   ├─ group: support
   ├─ mana: 400
   ├─ soul: 3
   └─ vocation: druid exclusive
```


**Tipo:** Instant (sem cast time)

---

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(3147, 3160, 1)
end
```

**Propósito:** Conjura single de 1 runa cura suprema.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Rune conjurada com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| Base Item ID | 3147 | ID base da runa |
| Rune Item ID | 3160 | ID específico runa cura suprema |
| Quantidade | 1 | 1 rune per cast |
