## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O spell `conjure_poisoned_arrow` oferece conjuração em batch de flechas envenenadas:

- **Tipo:** Conjuring (invocação)
- **Item:** Flecha Envenenada (3448)
- **Quantidade:** 7 flechas per cast (BATCH!)
- **Mana:** 130 (moderado)
- **Soul:** 2 (moderado)
- **Level:** 16 (mid)

### Arquitetura

```
local spell = Spell("instant")
├─ onCastSpell(creature, variant)
│  ├─ creature:conjureItem(baseID, itemID, quantity, effect)
│  └─ return success
└─ Configuração spell
   ├─ group: support
   ├─ mana: 130
   ├─ soul: 2
   ├─ self target: true
   └─ vocation: paladin exclusive
```

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(0, 3448, 7, CONST_ME_MAGIC_BLUE)
end
```

**Propósito:** Conjura batch de 7 flechas envenenadas.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Flechas conjuradas com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| Base Item ID | 0 | Sem base específica |
| Arrow Item ID | 3448 | ID específico flecha envenenada |
| Quantidade | 7 | 7 flechas por cast |
| Efeito Visual | CONST_ME_MAGIC_BLUE | Efeito azul na conjuração |
