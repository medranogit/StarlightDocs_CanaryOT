### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(0, 3449, 8, CONST_ME_MAGIC_BLUE)
end
```

**Propósito:** Conjura batch de 8 flechas explosivas.

**Parâmetros:**

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Flechas conjuradas com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|

| Arrow Item ID | 3449 | ID específico flecha explosiva |
| Quantidade | 8 | 8 flechas por cast |
| Efeito Visual | CONST_ME_MAGIC_BLUE | Efeito azul na conjuração |
