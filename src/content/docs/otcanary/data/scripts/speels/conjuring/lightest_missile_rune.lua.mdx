- **Tipo:** Conjuring (invocação)
- **Item:** Runa Míssil Mínimo (21352)
- **Quantidade:** 10 runes per cast (BATCH ULTRA!)
- **Mana:** 6 (barato!)

### Função Global: spell.onCastSpell

```lua

	return creature:conjureItem(3147, 21352, 10)
end
```
