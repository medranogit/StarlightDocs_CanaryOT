### Propósito Principal

O spell `soulfire_rune` oferece conjuração em batch de runa chama da alma:

- **Tipo:** Conjuring (invocação)
- **Item:** Runa Chama da Alma (3195)
- **Quantidade:** 3 runes per cast
- **Mana:** 420 (moderado)
- **Soul:** 3 (moderado)
- **Level:** 27 (mid)
- **Premium:** Sim (account required!)
- **Elemento:** Res Flam (resistência + fogo - novo!)

### Arquitetura

```
local spell = Spell("instant")
├─ onCastSpell(creature, variant)
│  ├─ creature:conjureItem(baseID, runeID, quantity)
│  └─ return success
└─ Configuração spell
   ├─ group: support
   ├─ mana: 420
   ├─ soul: 3
   ├─ premium: true
   └─ vocation: druid/sorcerer multi-class
```

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(3147, 3195, 3)
end
```

**Propósito:** Conjura batch de 3 runes chama da alma.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Conjurador |
| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Runes conjuradas com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| Base Item ID | 3147 | ID base da runa |
| Rune Item ID | 3195 | ID específico runa chama alma |
| Quantidade | 3 | 3 runes por cast |
