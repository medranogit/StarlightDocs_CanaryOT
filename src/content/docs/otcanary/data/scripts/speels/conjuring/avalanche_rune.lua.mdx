- **Tipo:** Conjuring (invocação)

- **Quantidade:** 4 runes per cast
- **Mana:** 530 (caro)

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(3147, 3161, 4)
end
```

**Propósito:** Conjura 4 runes de avalanche.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Druid |
| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Runes conjuradas com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| Base Item ID | 3147 | ID base da runa |
| Rune Item ID | 3161 | ID específico runa avalanche |
| Quantidade | 4 | 4 runes por cast |
