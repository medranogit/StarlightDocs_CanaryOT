### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, variant)
	return creature:conjureItem(3147, 3192, 2)
end
```

**Propósito:** Conjura batch de 2 runes bomba de fogo.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|

| `variant` | Variant | Não utilizado |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Runes conjuradas com sucesso |
| `false` | Falha conjuração |

**Lógica de Conjuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| Base Item ID | 3147 | ID base da runa |
| Rune Item ID | 3192 | ID específico runa bomba fogo |
| Quantidade | 2 | 2 runes por cast |
