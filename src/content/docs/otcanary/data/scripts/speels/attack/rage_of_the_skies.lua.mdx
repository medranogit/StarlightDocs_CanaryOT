### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 7)
	local max = (level / 5) + (maglevel * 14)
	return -min, -max
end
```

**Propósito:** Calcula dano energia AOE EXTREMAMENTE escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 7)
max = (level / 5) + (maglevel * 14)
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 7 (MÁXIMO!)
- Maglevel max: 14 (MÁXIMO!)
- Sem bônus fixo (linear!)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 55 | 10 | 81 | 151 |
| 55 | 20 | 151 | 291 |
| 55 | 30 | 221 | 431 |
| 55 | 50 | 361 | 711 |
