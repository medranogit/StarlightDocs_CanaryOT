## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_EXPLOSIONAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_EXPLOSION)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, 1)
```

**Propósito:** Combat de dano físico distance com armor ignore.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_PHYSICALDAMAGE | Dano físico |
| `COMBAT_PARAM_EFFECT` | CONST_ME_EXPLOSIONAREA | Efeito explosão área |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_EXPLOSION | Projétil explosão |
| `COMBAT_PARAM_BLOCKARMOR` | 1 | Ignora armadura! |

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.403) + 8
	local max = (level / 5) + (maglevel * 2.203) + 13
	return -min, -max
end
```

**Propósito:** Calcula dano físico escalável MUITO alto.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 1.403) + 8
max = (level / 5) + (maglevel * 2.203) + 13
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 1.403 (MUITO ALTO!)
- Maglevel max: 2.203 (MUITO ALTO!)
- Bônus: 8/13 (significativo)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 16 | 5 | 18 | 27 |
| 30 | 10 | 28 | 41 |
| 50 | 20 | 50 | 74 |
| 80 | 35 | 92 | 139 |

### Registração do Callback
