### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 2.8) + 16
	local max = (level / 5) + (maglevel * 4.4) + 28
	return -min, -max
end
```

**Propósito:** Calcula dano energia EXTREMAMENTE escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 2.8) + 16
max = (level / 5) + (maglevel * 4.4) + 28
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 2.8 (EXTREMAMENTE ALTO!)
- Maglevel max: 4.4 (EXTREMAMENTE ALTO!)
- Bônus: 16/28 (significativo!)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 80 | 20 | 88 | 132 |
| 80 | 30 | 116 | 176 |
| 80 | 40 | 144 | 220 |
| 80 | 60 | 200 | 308 |
