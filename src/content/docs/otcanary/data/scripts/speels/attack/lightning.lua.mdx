### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 2.2) + 12
	local max = (level / 5) + (maglevel * 3.4) + 21
	return -min, -max
end
```

**Propósito:** Calcula dano energia EXTREMAMENTE escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 2.2) + 12
max = (level / 5) + (maglevel * 3.4) + 21
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 2.2 (MÁXIMO!)
- Maglevel max: 3.4 (MÁXIMO!)
- Bônus: 12/21 (significativo)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 55 | 20 | 67 | 100 |
| 55 | 30 | 78 | 123 |
| 55 | 50 | 133 | 202 |
| 100 | 50 | 183 | 252 |
