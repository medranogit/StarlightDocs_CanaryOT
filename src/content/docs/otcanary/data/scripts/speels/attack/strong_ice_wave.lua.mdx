### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 4.5) + 20
	local max = (level / 5) + (maglevel * 7.6) + 48
	return -min, -max
end
```

**Propósito:** Calcula dano gelo AOE ABSURDAMENTE escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 4.5) + 20
max = (level / 5) + (maglevel * 7.6) + 48
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 4.5 (SUPREMO!)
- Maglevel max: 7.6 (SUPREMO!)
- Bônus: 20/48 (alto!)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 40 | 10 | 73 | 132 |
| 40 | 15 | 95 | 182 |
| 40 | 20 | 118 | 208 |
| 40 | 40 | 208 | 360 |
