## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ETHEREALSPEAR)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, 1)
```

**Propósito:** Combat de dano físico com armor bypass.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_PHYSICALDAMAGE | Dano físico |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HITAREA | Efeito impacto |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ETHEREALSPEAR | Projétil lança |
| `COMBAT_PARAM_BLOCKARMOR` | 1 | Ignora armadura! |

---

### Função Global: onGetFormulaValues (SKILL-BASED!)

```lua
function onGetFormulaValues(player, skill, attack, factor)
	local level = player:getLevel()

	local min = (level / 5) + (skill + 25) / 3
	local max = (level / 5) + skill + 25

	return -min, -max
end
```

**Propósito:** Calcula dano físico escalável por SKILL.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `skill` | number | Skill value (não magic level!) |
| `attack` | number | Attack power (não usado) |
| `factor` | number | Factor (não usado) |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
level = player:getLevel()
min = (level / 5) + (skill + 25) / 3
max = (level / 5) + skill + 25
```

**Pesos:**
- Level: 0.2 por ponto
- Skill min: (skill+25)/3 = escalabilidade skill
- Skill max: (skill+25) = escalabilidade skill forte
- Sem bônus fixo

**Exemplos:**

| Level | Skill | Min | Max |
|---|---|---|---|
| 23 | 30 | 22 | 59 |
| 50 | 60 | 22 | 110 |
| 80 | 100 | 32 | 150 |
| 100 | 120 | 40 | 170 |
