## 🔧 Estrutura de Funcionalidades

### Função Local: formulaFunction

```lua
local function formulaFunction(player, level, maglevel)
	local min = (level / 5) + (maglevel * 4)
	local max = (level / 5) + (maglevel * 7)
	return -min, -max
end
```

**Propósito:** Função base compartilhada para ambas formulas.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Sorcerer |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 4)
max = (level / 5) + (maglevel * 7)
```

---

### Função Global: onGetFormulaValues (Normal)

```lua
function onGetFormulaValues(player, level, maglevel)
	return formulaFunction(player, level, maglevel)
end
```

**Propósito:** Callback para BEAM8 normal.

---

### Função Global: onGetFormulaValuesWOD (WOD)

```lua
function onGetFormulaValuesWOD(player, level, maglevel)
	return formulaFunction(player, level, maglevel)
end
```

**Propósito:** Callback para BEAM10 WOD ampliado.

**Nota:** Usa MESMA fórmula que normal, mas area é maior (BEAM10)!

### Função Local: createCombat (Factory)

```lua
local function createCombat(area, combatFunc)
	local initCombat = Combat()
	initCombat:setCallback(CALLBACK_PARAM_LEVELMAGICVALUE, combatFunc)
	initCombat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
	initCombat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYAREA)
	initCombat:setArea(createCombatArea(area))
	return initCombat
end
```

**Propósito:** Factory parametrizada para criar combats.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `area` | Area | BEAM8 ou BEAM10 |
| `combatFunc` | string | "onGetFormulaValues" ou "onGetFormulaValuesWOD" |

**Retorno:** Combat customizado.

**Uso:**
```lua
local combat = createCombat(AREA_BEAM8, "onGetFormulaValues")
local combatWOD = createCombat(AREA_BEAM10, "onGetFormulaValuesWOD")
```

### Função Global: spell.onCastSpell (COMPLEXA!)

```lua
function spell.onCastSpell(creature, var)
	local player = creature:getPlayer()
	if not creature or not player then
		return false
	end
	return player:instantSkillWOD("Beam Mastery") and 
	       combatWOD:execute(creature, var) or 
	       combat:execute(creature, var)
end
```

**Propósito:** Handler complexo com WOD skill selection.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Sorcerer |
| `var` | Variant | Direction |

**Lógica:**
1. Valida creature/player
2. Checa instantSkillWOD("Beam Mastery")
3. TRUE: executa combatWOD (BEAM10!)
4. FALSE: executa combat (BEAM8)

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Beam lançado |
| `false` | Validação falhou |
