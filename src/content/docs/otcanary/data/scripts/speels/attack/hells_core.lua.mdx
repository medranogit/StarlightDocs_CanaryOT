local combat = Combat()

combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_FIREAREA)
combat:setArea(createCombatArea(AREA_CIRCLE5X5))

**Propósito:** Combat de dano fogo AOE self-target.

**Parâmetros:**

| `Area` | CIRCLE5X5 | AOE grande! |

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 10)
	local max = (level / 5) + (maglevel * 14)
	return -min, -max
end
```

**Propósito:** Calcula dano fogo magic-level EXTREMO.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 10)
max = (level / 5) + (maglevel * 14)
```

**Pesos (EXTREMAMENTE ALTOS!):**
- Level: 0.2 por ponto
- Maglevel min: 10 (EXTREMO!)
- Maglevel max: 14 (EXTREMO!)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 60 | 20 | 212 | 292 |
| 60 | 30 | 312 | 432 |
| 80 | 40 | 416 | 576 |
| 100 | 50 | 520 | 720 |
