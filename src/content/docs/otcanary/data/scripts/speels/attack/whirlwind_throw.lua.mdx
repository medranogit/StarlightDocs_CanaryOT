<Aside type="tip">
**Ataque Giratório - Mid-Level Skill-Based FÍSICA**

Este spell implementa um sistema de weapon-based physical attack:

1. **Skill-Based Formula:**
   - min = (level/5) + (skill+attack)/3
   - max = (level/5) + skill + attack
   - Multiplier: 1.28 (física!)
   - Escalabilidade SKILL (não magic!)

2. **Mid-Level Knight:**
   - Level 28 (MID!)
   - 40 mana (BARATO!)
   - Premium only
   - Cooldown 6s

3. **Weapon-Based Attack:**
   - needWeapon: true
   - needTarget: true
   - useCharges: true
   - blockArmor: true

4. **Tipo Físico:**
   - COMBAT_PHYSICALDAMAGE
   - Distance effect WEAPONTYPE
   - Range 5 (LONGO!)
   - Physical hit area

**Fórmula Visual:**
```
Knight lvl 28, skill 50, attack 20:
  min = 5.6 + (50+20)/3 = 5.6 + 23.33 = 28.93 × 1.28 = 37.03
  max = 5.6 + 50 + 20 = 75.6 × 1.28 = 96.77

Knight lvl 28, skill 80, attack 40:
  min = 5.6 + (80+40)/3 = 5.6 + 40 = 45.6 × 1.28 = 58.37
  max = 5.6 + 80 + 40 = 125.6 × 1.28 = 160.77

Knight lvl 28, skill 100, attack 60:
  min = 5.6 + (100+60)/3 = 5.6 + 53.33 = 58.93 × 1.28 = 75.43
  max = 5.6 + 100 + 60 = 165.6 × 1.28 = 211.97
```

**Diferencial:** Knight mid-level skill-based weapon physical power!

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, skill, attack, factor)
	local level = player:getLevel()
	local min = (level / 5) + (skill + attack) / 3
	local max = (level / 5) + skill + attack
	return -min * 1.28, -max * 1.28 -- TODO : Use New Real Formula instead of an %
end
```

**Propósito:** Calcula dano físico skill-based com multiplicador.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Knight |
| `skill` | number | Weapon skill |
| `attack` | number | Weapon attack |
| `factor` | number | Não utilizado |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min * 1.28` | number | Dano mínimo × 1.28 |
| `-max * 1.28` | number | Dano máximo × 1.28 |

**Fórmula:**
```
level = player:getLevel()
min = (level / 5) + (skill + attack) / 3
max = (level / 5) + skill + attack
return -min * 1.28, -max * 1.28
```

**Pesos:**
- Level: 0.2 por ponto
- Skill: 0.33 até 1.0 escala
- Attack: 0.33 até 1.0 escala
- Multiplicador: 1.28 (física!)

**Exemplos:**

| Level | Skill | Attack | Min | Max |
|---|---|---|---|---|
| 28 | 50 | 20 | 37 | 97 |
| 28 | 80 | 40 | 58 | 161 |
| 28 | 100 | 60 | 75 | 212 |
| 28 | 120 | 80 | 92 | 262 |
