## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_FIREDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_FIREATTACK)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_FIRE)
```

**Propósito:** Combat de dano fogo.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_FIREDAMAGE | Dano fogo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_FIREATTACK | Efeito fogo ataque |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_FIRE | Projétil fogo |

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.403) + 8
	local max = (level / 5) + (maglevel * 2.203) + 13
	return -min, -max
end
```

**Propósito:** Calcula dano fogo escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 1.403) + 8
max = (level / 5) + (maglevel * 2.203) + 13
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 1.403 (MUITO ALTO!)
- Maglevel max: 2.203 (MUITO ALTO!)
- Bônus: 8/13 (significativo)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 14 | 5 | 17 | 26 |
| 30 | 10 | 28 | 43 |
| 50 | 15 | 40 | 60 |
| 80 | 25 | 65 | 97 |

---

### Registração do Callback

```lua

```

**Descrição:** Conjura golpe fogo em target.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Sorcerer ou Druid |
| `var` | Variant | Target ou direction |

**Retorno:**

| Valor | Descrição |
|---|---|
| `true` | Flame strike ativado |
| `false` | Target falhou |

**Requisitos:**
- Level 14+
- 20 mana
- Target ou direction
- Premium account
- Cooldown 2s

**Efeito:**
- Efeito fogo ataque
- Projétil fogo
- Dano magic-level escalável
- Range 3 tiles
- Bloqueia walls

**Exemplo:**

```lua

//   ✓ Level 30 >= 14
//   ✓ Mana 20 disponível
//   ✓ Target ou direction
//   ✓ Premium account

// Dano: -28 a -41

// Cooldown 2s
```
