### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGY)
```

**Propósito:** Combat de dano energia.

**Parâmetros:**

|---|---|---|

| `COMBAT_PARAM_EFFECT` | CONST_ME_ENERGYAREA | Efeito área energia |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ENERGY | Projétil energia |

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.403) + 8
	local max = (level / 5) + (maglevel * 2.203) + 13
	return -min, -max
end
```

**Propósito:** Calcula dano energia escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 1.403) + 8
max = (level / 5) + (maglevel * 2.203) + 13
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 1.403 (MUITO ALTO!)
- Maglevel max: 2.203 (MUITO ALTO!)
- Bônus: 8/13 (significativo)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 12 | 5 | 17 | 26 |
| 30 | 10 | 28 | 43 |
| 50 | 15 | 40 | 60 |
| 80 | 25 | 65 | 97 |
