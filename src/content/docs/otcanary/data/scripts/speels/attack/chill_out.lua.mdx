## 💡 Tip

<Aside type="tip">
**Ondas de Gelo - Direcionado Free-Play**

Este spell implementa um **sistema de AOE direcionado com ondas**:

1. **Áreas Wave Direcionadas:**
   - AREA_WAVE4 (linha onda)
   - AREADIAGONAL_WAVE4 (diagonais)
   - Cobertura direcionada progressive

2. **Magic-Level Escalável:**
   - Usa CALLBACK_PARAM_LEVELMAGICVALUE
   - min = (level/5) + (maglevel × 0.3) + 2
   - max = (level/5) + (maglevel × 0.6) + 4
   - Escalabilidade baixa (iniciante)

3. **Level 1 Instant:**
   - Acesso IMEDIATO novo druid
   - 8 mana (spam possível)
   - Sem premium
   - Direcionado (não target)

4. **Direção, Não Target:**
   - needDirection: true (clique direção)
   - Sem needTarget
   - AOE projetado direção

**Fórmula Visual:**
```
Druid lvl 1, mlvl 0:
  min = 0.2 + 0 + 2 = 2.2
  max = 0.2 + 0 + 4 = 4.2

Druid lvl 50, mlvl 20:
  min = 10 + 6 + 2 = 18
  max = 10 + 12 + 4 = 26
```

**Diferencial:** Wave AOE direccionado level 1!
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O spell `chill_out` oferece AOE gelo direcionado:

- **Dano:** COMBAT_ICEDAMAGE magic-level based
- **Fórmula:** (level/5) + (maglevel*0.3/0.6) + bônus
- **Mana:** 8 (barato)
- **Level:** 1 (imediato!)
- **Área:** Wave4 + diagonal (direcionada)

### Arquitetura

Combat com áreas wave:

```
local combat = Combat()
├─ Type: ICEDAMAGE
├─ Effect: ICEAREA
├─ Area: WAVE4
├─ Area: AREADIAGONAL_WAVE4
└─ Callback: onGetFormulaValues (LEVELMAGIC)

onGetFormulaValues(player, level, maglevel)
└─ min/max escalável

spell.onCastSpell()
└─ combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ICEDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ICEAREA)
combat:setArea(createCombatArea(AREA_WAVE4, AREADIAGONAL_WAVE4))
```

**Propósito:** Combat de AOE gelo direcionado.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ICEDAMAGE | Dano gelo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ICEAREA | Efeito gelo |
| `Area 1` | AREA_WAVE4 | Onda linha |
| `Area 2` | AREADIAGONAL_WAVE4 | Onda diagonal |

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 0.3) + 2
	local max = (level / 5) + (maglevel * 0.6) + 4
	return -min, -max
end
```

**Propósito:** Calcula dano gelo AOE.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 0.3) + 2
max = (level / 5) + (maglevel * 0.6) + 4
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 0.3 (baixo)
- Maglevel max: 0.6 (baixo)
- Bônus: 2/4 (moderado)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 1 | 0 | 2 | 4 |
| 30 | 10 | 12 | 18 |
| 60 | 25 | 21 | 39 |
| 100 | 50 | 32 | 64 |

---

### Registração do Callback

```lua
combat:setCallback(CALLBACK_PARAM_LEVELMAGICVALUE, "onGetFormulaValues")
```
