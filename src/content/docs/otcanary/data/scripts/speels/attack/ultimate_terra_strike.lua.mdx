### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 4.5) + 35
	local max = (level / 5) + (maglevel * 7.3) + 55
	return -min, -max
end
```

**Propósito:** Calcula dano terra SUPREMAMENTE escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 4.5) + 35
max = (level / 5) + (maglevel * 7.3) + 55
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 4.5 (SUPREMO!)
- Maglevel max: 7.3 (SUPREMO!)
- Bônus: 35/55 (ALTOS!)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 90 | 20 | 143 | 219 |
| 90 | 30 | 187.5 | 272 |
| 90 | 40 | 233 | 365 |
| 90 | 60 | 323 | 511 |
