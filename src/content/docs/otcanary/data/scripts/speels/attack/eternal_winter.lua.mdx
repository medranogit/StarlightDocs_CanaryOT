## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ICEDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ICETORNADO)
combat:setArea(createCombatArea(AREA_CIRCLE5X5))
```

**Propósito:** Combat de AOE gelo.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ICEDAMAGE | Dano gelo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ICETORNADO | Efeito tornado gelo |
| `Area` | AREA_CIRCLE5X5 | 5x5 círculo (25 tiles!) |

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 6)
	local max = (level / 5) + (maglevel * 12)
	return -min, -max
end
```

**Propósito:** Calcula dano gelo AOE potente.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 6)
max = (level / 5) + (maglevel * 12)
```

**Pesos:**
- Level: 0.2 por ponto (baixo)
- Maglevel min: 6 (EXTREMAMENTE ALTO!)
- Maglevel max: 12 (EXTREMAMENTE ALTO!)
- Sem bônus fixo

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 60 | 20 | 132 | 252 |
| 80 | 25 | 166 | 312 |
| 100 | 30 | 206 | 372 |
| 120 | 40 | 260 | 500 |

---

### Registração do Callback
