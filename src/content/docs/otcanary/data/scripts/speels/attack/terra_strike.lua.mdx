### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.403) + 8
	local max = (level / 5) + (maglevel * 2.203) + 13
	return -min, -max
end
```

**Propósito:** Calcula dano terra entry-level escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 1.403) + 8
max = (level / 5) + (maglevel * 2.203) + 13
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 1.403 (BAIXO!)
- Maglevel max: 2.203 (BAIXO!)
- Bônus: 8/13 (pequeno)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 13 | 5 | 17.6 | 26.6 |
| 13 | 10 | 24.6 | 37.6 |
| 13 | 20 | 38.7 | 59.7 |
| 13 | 30 | 52.7 | 81.7 |

### Registração do Callback
