## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_GROUNDSHAKER)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, 1)
```

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, skill, attack, factor)
	local level = player:getLevel()
	local min = (level / 5) + (skill + attack) * 0.5
	local max = (level / 5) + (skill + attack) * 1.1
	return -min * 1.28, -max * 1.28
end
```

**Propósito:** Calcula dano físico skill-based escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Knight |
| `skill` | number | Weapon skill |
| `attack` | number | Attack power |
| `factor` | number | Factor (unused) |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min * 1.28` | number | Dano mínimo × 1.28 |
| `-max * 1.28` | number | Dano máximo × 1.28 |

**Fórmula:**
```
level = player:getLevel()

min = (level / 5) + (skill + attack) * 0.5
max = (level / 5) + (skill + attack) * 1.1

final_min = min * 1.28
final_max = max * 1.28
```

**Pesos:**
- Level: 0.2 por ponto
- Skill+Attack min coef: 0.5
- Skill+Attack max coef: 1.1
- Multiplicador final: 1.28 (28% boost!)

**Exemplos:**

| Level | Skill | Attack | Min | Max |
|---|---|---|---|
| 33 | 80 | 40 | 85 | 177 |
| 40 | 100 | 50 | 104 | 224 |
| 50 | 120 | 60 | 138 | 290 |
