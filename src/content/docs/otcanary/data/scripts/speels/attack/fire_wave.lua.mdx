O spell `fire_wave` oferece dano fogo AOE direcionado:

- **Dano:** COMBAT_FIREDAMAGE magic-level based
- **Fórmula:** (level/5) + (maglevel*1.25/2) (MUITO ALTA!)
- **Mana:** 25 (baato)
- **Level:** 18 (early)

```

└─ combat:execute()
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_FIREDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITBYFIRE)

local area = createCombatArea(AREA_WAVE4, AREADIAGONAL_WAVE4)
combat:setArea(area)
```

**Propósito:** Combat de AOE fogo direcionado.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_FIREDAMAGE | Dano fogo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HITBYFIRE | Efeito fogo impacto |
| `Area 1` | AREA_WAVE4 | Onda linha |
| `Area 2` | AREADIAGONAL_WAVE4 | Onda diagonal |

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.25) + 4
	local max = (level / 5) + (maglevel * 2) + 12
	return -min, -max
end
```

**Propósito:** Calcula dano fogo AOE.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 1.25) + 4
max = (level / 5) + (maglevel * 2) + 12
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 1.25 (MUITO ALTO!)
- Maglevel max: 2 (MUITO ALTO!)
- Bônus: 4/12 (moderado)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 18 | 5 | 13 | 25 |
| 40 | 10 | 30 | 50 |
| 60 | 20 | 50 | 92 |
| 100 | 40 | 90 | 172 |
