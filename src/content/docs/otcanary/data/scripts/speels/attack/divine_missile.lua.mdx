### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 1.79) + 11
	local max = (level / 5) + (maglevel * 3) + 18
	return -min, -max
end
```

**Propósito:** Calcula dano sagrado escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 1.79) + 11
max = (level / 5) + (maglevel * 3) + 18
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 1.79 (MUITO ALTO!)
- Maglevel max: 3 (MUITO ALTO!)
- Bônus: 11/18 (significativo)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 40 | 10 | 36 | 56 |
| 60 | 15 | 46 | 78 |
| 80 | 20 | 62 | 94 |
| 120 | 30 | 95 | 138 |
