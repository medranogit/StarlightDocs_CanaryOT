### Função Global: onGetFormulaValues (Skill-Based Complexo!)

```lua
function onGetFormulaValues(player, skill, attack, factor)
	local skillTotal = skill * attack
	local levelTotal = player:getLevel() / 5
	return -(((skillTotal * 0.17) + 17) + levelTotal) * 1.28, -(((skillTotal * 0.20) + 40) + levelTotal) * 1.28
end
```

**Propósito:** Calcula dano weapon skill-based COMPLEXO.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Knight |
| `skill` | number | Weapon skill |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|

**Fórmula:**

min = (((skillTotal * 0.17) + 17) + levelTotal) * 1.28

**Pesos Complexos:**

### Função Global: getChainValue (WOD CALLBACKS!)

```lua
function getChainValue(creature)
	local grade = creature:revelationStageWOD("Executioner's Throw")
	if grade == 0 then
		return false
	end

	local bounces = 0
	if grade >= 3 then
		bounces = 4
	elseif grade >= 2 then
		bounces = 3
	elseif grade >= 1 then
		bounces = 2
	end

	return bounces + 1, 3, false
end
```

**Propósito:** Calcula chain bounces baseado WOD grade.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Knight |

**Retorno:**

| Valor | Semântica |
|---|---|
| false | Grade 0 (não pode usar) |
| bounces+1, 3, false | Targets, chain range, ??? |

**Chain Logic:**

| Grade | Bounces | Total Targets | Behavior |
|---|---|---|---|
| 0 | 0 | Reject! | Não pode usar |
| 1 | 2 | 3 (primário + 2 bounce) | Baseline |
| 2 | 3 | 4 (primário + 3 bounce) | Mid upgrade |
| 3+ | 4 | 5 (primário + 4 bounce) | MÁXIMO! |

### Função Global: spell.onCastSpell (MUITO COMPLEXA!)

```lua
function spell.onCastSpell(creature, var)
	if not creature or not creature:isPlayer() then
		return false
	end

	local grade = creature:revelationStageWOD("Executioner's Throw")
	if grade == 0 then
		creature:sendCancelMessage("You need to learn this spell first")
		creature:getPosition():sendMagicEffect(CONST_ME_POFF)
		return false
	end
	return combat:execute(creature, var)
end
```

**Propósito:** Handler complexo com WOD grade validation.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Knight |
| `var` | Variant | Target |

**Lógica:**
1. Valida creature é player
2. Check revelationStageWOD("Executioner's Throw")
3. Se grade 0: send cancel message + POFF effect
4. Senão: execute combat

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Lançamento ativado |
| `false` | Validação falhou |
