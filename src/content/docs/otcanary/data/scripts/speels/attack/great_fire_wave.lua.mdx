## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O spell `great_fire_wave` oferece dano fogo AOE em wave grande direcionada:

- **Dano:** COMBAT_FIREDAMAGE magic-level based
- **Fórmula:** (level/5) + (maglevel × 2.8/4.4) + bônus (ALTA!)
- **Mana:** 120 (moderado)
- **Level:** 38 (early)
- **Área:** WAVE7 + diagonal (grande!)

### Arquitetura

```
local combat = Combat()
├─ Type: FIREDAMAGE
├─ Effect: HITBYFIRE
├─ Area: WAVE7 + AREADIAGONAL_WAVE7
└─ Callback: onGetFormulaValues (LEVELMAGIC)

onGetFormulaValues(player, level, maglevel)
└─ min/max magic-level escalável com bônus

spell.onCastSpell(creature, var)
└─ combat:execute()
```

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 2.8) + 16
	local max = (level / 5) + (maglevel * 4.4) + 28
	return -min, -max
end
```

**Propósito:** Calcula dano fogo AOE magic-level escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 2.8) + 16
max = (level / 5) + (maglevel * 4.4) + 28
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 2.8 (alto!)
- Maglevel max: 4.4 (muito alto!)
- Bônus: +16/+28 (significativo!)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 38 | 10 | 51 | 79 |
| 50 | 15 | 68 | 104 |
| 70 | 25 | 100 | 152 |
| 100 | 40 | 180 | 252 |
