## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_FIREDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_FIREATTACK)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_FIRE)
```

**Propósito:** Combat de dano fogo.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_FIREDAMAGE | Dano fogo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_FIREATTACK | Efeito fogo |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_FIRE | Projétil fogo |

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 0.4) + 3
	local max = (level / 5) + (maglevel * 0.7) + 5
	return -min, -max
end
```

**Propósito:** Calcula dano fogo iniciante.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 0.4) + 3
max = (level / 5) + (maglevel * 0.7) + 5
```

**Pesos:**
- Level: 0.2 por ponto (baixo)
- Maglevel min: 0.4 (muito baixo)
- Maglevel max: 0.7 (muito baixo)
- Bônus: 3/5 (moderado)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 8 | 1 | 5 | 7 |
| 30 | 10 | 14 | 20 |
| 60 | 25 | 28 | 42 |
| 100 | 50 | 48 | 71 |

---

### Registração do Callback

```lua
combat:setCallback(CALLBACK_PARAM_LEVELMAGICVALUE, "onGetFormulaValues")
```
