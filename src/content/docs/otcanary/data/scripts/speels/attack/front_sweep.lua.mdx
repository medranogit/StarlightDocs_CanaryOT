### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITAREA)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, 1)
combat:setParameter(COMBAT_PARAM_USECHARGES, 1)
```

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, skill, attack, factor)
	local skillTotal = skill * attack
	local levelTotal = player:getLevel() / 5
	return -(((skillTotal * 0.04) + 31) + levelTotal) * 1.1, 
	       -(((skillTotal * 0.08) + 45) + levelTotal) * 1.1
end
```

**Propósito:** Calcula dano físico skill-based escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Knight |
| `skill` | number | Weapon skill |
| `attack` | number | Attack power |
| `factor` | number | Factor (unused) |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min * 1.1` | number | Dano mínimo × 1.1 |
| `-max * 1.1` | number | Dano máximo × 1.1 |

**Fórmula:**
```
skillTotal = skill × attack
levelTotal = level / 5

min = ((skillTotal × 0.04 + 31) + levelTotal) × 1.1
max = ((skillTotal × 0.08 + 45) + levelTotal) × 1.1
```

**Pesos:**
- skillTotal: 0.04-0.08 (baixo coef)
- Bônus: +31/+45
- Level: 0.2 por ponto
- Multiplicador final: 1.1 (boost!)

**Exemplos:**

| Level | Skill | Attack | Min | Max |
|---|---|---|---|
| 70 | 80 | 40 | 385 | 291 |
| 70 | 100 | 50 | 220 | 440 |
| 80 | 120 | 60 | 427 | 737 |
