1. **Skill-Based Damage:**
   - Usa CALLBACK_PARAM_SKILLVALUE
   - Depende de skill + attack weapon
   - skillTotal = skill × attack
   - Multiplicador final × 1.28

2. **Fórmula Complexa:**
   - min = (skillTotal × 0.17 + 13 + levelTotal) × 1.28
   - max = (skillTotal × 0.20 + 34 + levelTotal) × 1.28

   - Level 110 (máximo)

4. **Melee Physical:**
   - Alcance 1 (melee close)

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_WEAPONTYPE)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, 1)
combat:setParameter(COMBAT_PARAM_USECHARGES, 1)
```

**Propósito:** Combat de dano físico.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_PHYSICALDAMAGE | Dano físico |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HITAREA | Efeito hit área |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_WEAPONTYPE | Projétil weapon |
| `COMBAT_PARAM_BLOCKARMOR` | 1 | Bloqueia armor |
| `COMBAT_PARAM_USECHARGES` | 1 | Usa charges arma |

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, skill, attack, factor)
	local skillTotal = skill * attack
	local levelTotal = player:getLevel() / 5
	return -(((skillTotal * 0.17) + 13) + levelTotal) * 1.28, -(((skillTotal * 0.20) + 34) + levelTotal) * 1.28
end
```

**Propósito:** Calcula dano físico skill-based.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `skill` | number | Weapon skill |
| `attack` | number | Attack weapon |
| `factor` | number | Factor (unused) |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
skillTotal = skill × attack
levelTotal = level / 5

min = (skillTotal × 0.17 + 13 + levelTotal) × 1.28
max = (skillTotal × 0.20 + 34 + levelTotal) × 1.28
```

**Variáveis Locais:**

| Nome | Tipo | Descrição |
|---|---|---|
| `skillTotal` | number | skill × attack |
| `levelTotal` | number | level / 5 |

**Exemplos:**

| Level | Skill | Attack | Min | Max |
|---|---|---|---|---|
| 110 | 100 | 15 | 347 | 422 |
| 120 | 120 | 20 | 635 | 774 |
| 150 | 150 | 25 | 996 | 1209 |
