### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 3.5)
	local max = (level / 5) + (maglevel * 7)
	return -min, -max
end
```

**Propósito:** Calcula dano terra AOE ALTAMENTE escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 3.5)
max = (level / 5) + (maglevel * 7.0)
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 3.5 (ALTO!)
- Maglevel max: 7.0 (ALTO!)
- Bônus: 0 (direto no coef!)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 38 | 10 | 42.6 | 77.6 |
| 38 | 15 | 60.1 | 112.6 |
| 38 | 20 | 77.6 | 147.6 |
| 38 | 30 | 112.6 | 217.6 |
