### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 4)
	local max = (level / 5) + (maglevel * 6)
	return -min, -max
end
```

**Propósito:** Calcula dano sagrado AOE potente.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 4)
max = (level / 5) + (maglevel * 6)
```

**Pesos:**
- Level: 0.2 por ponto (baixo)
- Maglevel min: 4 (MUITO ALTO!)
- Maglevel max: 6 (MUITO ALTO!)
- Sem bônus fixo

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 50 | 10 | 50 | 70 |
| 80 | 20 | 96 | 136 |
| 120 | 30 | 160 | 200 |
| 150 | 40 | 210 | 270 |
