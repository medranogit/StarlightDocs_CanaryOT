## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_TARGETCASTERORTOPMOST, 1)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_DRAWBLOOD)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_WEAPONTYPE)
combat:setParameter(COMBATPARAM_USECHARGES, 1)
```

**Propósito:** Combat de dano físico melee com condition.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_PHYSICALDAMAGE | Dano físico |
| `TARGETCASTERORTOPMOST` | 1 | Target caster ou topmost |
| `COMBAT_PARAM_EFFECT` | CONST_ME_DRAWBLOOD | Efeito sangue |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_WEAPONTYPE | Weapon distance |
| `COMBATPARAM_USECHARGES` | 1 | Consome charges |

---

### Variável Global: condition

```lua
local condition = Condition(CONDITION_BLEEDING)
condition:setParameter(CONDITION_PARAM_DELAYED, 10)
condition:addDamage(15, 2000, -50)
combat:addCondition(condition)
```

**Propósito:** Condition de sangramento com damage periódico.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `Type` | CONDITION_BLEEDING | Sangramento! |
| `DELAYED` | 10 | Delay inicial 10ms! |
| `Damage` | 15 | Dano fixo |
| `Duration` | 2000ms | 2 segundos |
| `Period` | -50 | Oscilação negativa |

**Detalhes:**
- Dano fixo 15 (não aleatório)
- `2000`: duração 2 segundos
- `-50`: período oscilante (efeito variável!)
- `10`: delay INICIAL antes de começar sangrar (UNIQUE!)

---

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, var)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler simples executa combat.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Knight ou Monk |
| `var` | Variant | Target |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Ferida infligida |
| `false` | Target falhou |
