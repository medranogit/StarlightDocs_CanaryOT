## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ETHEREALSPEAR)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, 1)
```

**Propósito:** Combat de dano físico skill-based ranged.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|

| `COMBAT_PARAM_EFFECT` | CONST_ME_HITAREA | Efeito hit área |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_ETHEREALSPEAR | Projétil lança etérea |
| `COMBAT_PARAM_BLOCKARMOR` | 1 | Ignora armadura! |

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, skill, attack, factor)
	local levelTotal = player:getLevel() / 5
	return -(((2 * skill + attack / 2500) * 2.30) + levelTotal + 7), 
	       -(((2 * skill + attack / 1875) * 3.30) + levelTotal + 13)
end
```

**Propósito:** Calcula dano físico skill-based UNIQUE.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Paladim |
| `skill` | number | Melee skill |
| `attack` | number | Weapon attack |
| `factor` | number | Fator (não usado) |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
levelTotal = level / 5

min = -( ((2*skill + attack/2500) * 2.30) + levelTotal + 7 )
max = -( ((2*skill + attack/1875) * 3.30) + levelTotal + 13 )
```

**Componentes:**
- **Skill Component:** 2 * skill (linear)
- **Attack Component:** attack / ratio (2500 ou 1875)
- **Coef:** 2.30 (min) ou 3.30 (max)
- **Level:** level / 5 (pequeno)
- **Bonus:** 7 (min) ou 13 (max)

**Exemplos:**

| Level | Skill | Attack | Min | Max |
|---|---|---|---|---|
| 90 | 100 | 100 | 255 | 361 |
| 90 | 150 | 150 | 370 | 526 |
| 90 | 200 | 200 | 488 | 695 |
