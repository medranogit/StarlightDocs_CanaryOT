Este spell implementa um sistema de AOE onda gelo direcionado com escalabilidade magic-level variável:

   - Usa CALLBACK_PARAM_LEVELMAGICVALUE

   - max = (level/5) + (maglevel × 2) + 12
   - Coef varia MUITO (0.81 min, 2 max!)

3. **Early-Game Druid:**
   - Level 18 (cedo!)
   - 25 mana (baato)
   - Não-premium
   - Cooldown 4s

4. **Tipo Gelo:**
   - COMBAT_ICEDAMAGE
   - Efeito ICEAREA
   - Direcionado (não target)
   - Wave áreas

```
Druid lvl 18, mlvl 5:
  min = 3.6 + 4.05 + 4 = 11.65
```

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O spell `ice_wave` oferece dano gelo AOE direcionado:

- **Dano:** COMBAT_ICEDAMAGE magic-level based
- **Fórmula:** (level/5) + (maglevel × 0.81/2) (VARIÁVEL!)
- **Mana:** 25 (baato)
- **Level:** 18 (early)
- **Áreas:** Wave4 + diagonal

```
local combat = Combat()

```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ICEDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ICEAREA)
combat:setArea(createCombatArea(AREA_WAVE4, AREADIAGONAL_WAVE4))
```

**Propósito:** Combat de AOE gelo direcionado.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_ICEDAMAGE | Dano gelo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_ICEAREA | Efeito gelo área |
| `Area 1` | AREA_WAVE4 | Onda linha |
| `Area 2` | AREADIAGONAL_WAVE4 | Onda diagonal |

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 0.81) + 4
	local max = (level / 5) + (maglevel * 2) + 12
	return -min, -max
end
```

**Propósito:** Calcula dano gelo AOE.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 0.81) + 4
max = (level / 5) + (maglevel * 2) + 12
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 0.81 (variável!)
- Maglevel max: 2 (MUITO ALTO!)
- Bônus: 4/12 (moderado)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 18 | 5 | 11 | 25 |
| 40 | 10 | 24 | 50 |
| 60 | 20 | 44 | 92 |
| 100 | 40 | 84 | 172 |

---

### Registração do Callback

