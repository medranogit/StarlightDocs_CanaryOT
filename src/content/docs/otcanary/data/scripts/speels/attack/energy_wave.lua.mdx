### Propósito Principal

O spell `energy_wave` oferece dano energia AOE com WOD:

- **Dano:** COMBAT_ENERGYDAMAGE magic-level based
- **Fórmula:** (level/5) + (maglevel*4.5/9) (EXTREMA!)
- **Mana:** 170 (custoso)
- **Level:** 38 (mid-late)
- **Áreas:** Wave quadrado normal vs Wave 7 WOD

### Arquitetura (Complexa!)

```
Dual Combat System:

1. combat (normal)
├─ Type: ENERGYDAMAGE
├─ Area: SQUAREWAVE5 + AREADIAGONAL_SQUAREWAVE5
└─ Callback: onGetFormulaValues

2. combatWOD (upgraded)
├─ Type: ENERGYDAMAGE
├─ Area: WAVE7 + AREADIAGONAL_WAVE7
└─ Callback: onGetFormulaValuesWOD

3. formulaFunction (shared)
└─ Cálculo unificado

spell.onCastSpell()
├─ getWheelSpellAdditionalArea("Energy Wave") check
└─ Execute combatWOD OU combat
```

## 🔧 Estrutura de Funcionalidades

### Função Local: formulaFunction (Helper)

```lua
local function formulaFunction(player, level, maglevel)
	local min = (level / 5) + (maglevel * 4.5)
	local max = (level / 5) + (maglevel * 9)
	return -min, -max
end
```

**Propósito:** Fórmula compartilhada normal + WOD.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

---

### Função Global: onGetFormulaValues (Normal)

```lua
function onGetFormulaValues(player, level, maglevel)
	return formulaFunction(player, level, maglevel)
end
```

**Propósito:** Callback normal combat.

---

### Função Global: onGetFormulaValuesWOD (Upgrade)

```lua
function onGetFormulaValuesWOD(player, level, maglevel)
	return formulaFunction(player, level, maglevel)
end
```

**Propósito:** Callback WOD combat (mesma fórmula, área maior).

### Função Local: createCombat (Factory)

```lua
local function createCombat(area, areaDiagonal, combatFunc)
	local initCombat = Combat()
	initCombat:setCallback(CALLBACK_PARAM_LEVELMAGICVALUE, combatFunc)
	initCombat:setParameter(COMBAT_PARAM_TYPE, COMBAT_ENERGYDAMAGE)
	initCombat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_ENERGYAREA)
	initCombat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_ENERGY)
	initCombat:setArea(createCombatArea(area, areaDiagonal))
	return initCombat
end
```

**Propósito:** Factory para criar combats (reutilização DRY).

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `area` | Constant | Área principal |
| `areaDiagonal` | Constant | Área diagonal |
| `combatFunc` | string | Função callback |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| Combat | Combat | Instância configurada |

### Variáveis Globais: combat, combatWOD

```lua
local combat = createCombat(AREA_SQUAREWAVE5, AREADIAGONAL_SQUAREWAVE5, "onGetFormulaValues")
```

**Propósito:**

**Diferenças:**

|---|---|---|---|

| `combatWOD` | WAVE7 | AREADIAGONAL_WAVE7 | Maior! |

### Função Global: spell.onCastSpell (SMART!)

```lua
function spell.onCastSpell(creature, var)
	local player = creature:getPlayer()
	if creature and player then
		if player:getWheelSpellAdditionalArea("Energy Wave") then
			return combatWOD:execute(creature, var)
		end
	end
	return combat:execute(creature, var)
end
```

**Propósito:** Smart dispatch WOD vs normal.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Sorcerer |
| `var` | Variant | Direction |

**Lógica:**
1. Valida creature + player
2. Check getWheelSpellAdditionalArea("Energy Wave")
3. Se WOD area: execute combatWOD (WAVE7)
4. Senão: execute combat (SQUAREWAVE5)

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Wave ativada |
| `false` | Validação falhou |
