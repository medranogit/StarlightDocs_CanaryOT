<Aside type="tip">
**Envenenamento - Fixed Poison DoT**

Este spell implementa um **sistema de condition poison com dano fixo atrasado**:

1. **Condition Poison Simples:**
   - CONDITION_POISON (tipo)
   - 25 dano fixo (não escalável!)
   - 3000ms interval (3 segundos)
   - DELAYED: 1 (começa com delay)

2. **Cooldown Muito Longo:**
   - 40s cooldown (TÁTICO!)
   - Reflete potência condition
   - Spell poderoso = espera longa

3. **Mid-Game Druid:**
   - Level 50 (mid-game)
   - 30 mana (baato)
   - Non-premium (gratuito!)
   - Single target (não AOE)

4. **Tipo Earth:**
   - COMBAT_EARTHDAMAGE
   - Efeito SMALLPLANTS
   - Range 3 (ranged)
   - Agressivo True

**Situação Condition:**
```
- CONDITION_POISON aplicada
- DELAYED: 1 (wait antes começo)
- addDamage(25, 3000, -45)
  └─ 25 dano @ 3000ms interval
  └─ -45 = ticks (45 ticks = 3s×45 ticks)
- Fixed dano (sem escalabilidade!)
```

**Diferencial:** Fixed poison DoT tactical com 40s CD!
</Aside>

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_EARTHDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_SMALLPLANTS)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_EARTH)
```

**Propósito:** Combat de dano terra.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_EARTHDAMAGE | Dano terra |
| `COMBAT_PARAM_EFFECT` | CONST_ME_SMALLPLANTS | Efeito plantas |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_EARTH | Projétil terra |

---

### Variável Global: condition

```lua
local condition = Condition(CONDITION_POISON)
condition:setParameter(CONDITION_PARAM_DELAYED, 1)
condition:addDamage(25, 3000, -45)
combat:addCondition(condition)
```

**Propósito:** Condition poison com DoT fixo.

**Configuração:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `Type` | CONDITION_POISON | Tipo condition |
| `DELAYED` | 1 | Começa com delay |
| `addDamage` | 25, 3000, -45 | 25 dano @ 3s, 45 ticks |

**DOT Estrutura:**
- Dano: 25 (fixo)
- Interval: 3000ms (3 segundos)
- Ticks: 45 (-45)
- Total duração: ~45 × 3s = 135 segundos (~2min15s!)
- Total damage: 25 × múltiplo ticks

---

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, var)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler simples.

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Envenom ativado |
| `false` | Target falhou |
