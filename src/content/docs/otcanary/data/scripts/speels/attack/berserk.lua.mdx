<Aside type="tip">
**Fúria Berserk - Ataques Combo**

Este spell implementa um **sistema de dano físico combo skill+attack**:

1. **Skill+Attack Combo:**
   - Usa CALLBACK_PARAM_SKILLVALUE
   - Formula: (skill + attack) × 0.5-1.5
   - Multiplicador extra × 1.1

2. **Fórmula Combo:**
   - min = (level/5) + (skill + attack) × 0.5 × 1.1
   - max = (level/5) + (skill + attack) × 1.5 × 1.1
   - Altamente dependente weapon combo

3. **Mid-Game Premium:**
   - Level 35 (mid)
   - 115 mana (moderado)
   - Premium only
   - Cooldown 4s

4. **Melee Combo:**
   - Alcance 0 (muito close)
   - Area square 1x1
   - Requer weapon
   - BlockArmor
   - Usa charges

**Fórmula Visual:**
```
Knight lvl 35, skill 50, attack 10:
  min = 7 + (50 + 10) × 0.5 × 1.1 = 40
  max = 7 + (50 + 10) × 1.5 × 1.1 = 106

Knight lvl 60, skill 100, attack 20:
  min = 12 + (100 + 20) × 0.5 × 1.1 = 78
  max = 12 + (100 + 20) × 1.5 × 1.1 = 210
```

**Diferencial:** Combo skill+attack doubling!

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITAREA)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, 1)
combat:setParameter(COMBAT_PARAM_USECHARGES, 1)
combat:setArea(createCombatArea(AREA_SQUARE1X1))
```

**Propósito:** Combat de dano combo.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_PHYSICALDAMAGE | Dano físico |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HITAREA | Efeito hit |
| `COMBAT_PARAM_BLOCKARMOR` | 1 | Bloqueia armor |
| `COMBAT_PARAM_USECHARGES` | 1 | Usa charges |
| `Area` | AREA_SQUARE1X1 | 1x1 square melee |

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, skill, attack, factor)
	local level = player:getLevel()

	local min = (level / 5) + (skill + attack) * 0.5
	local max = (level / 5) + (skill + attack) * 1.5

	return -min * 1.1, -max * 1.1
end
```

**Propósito:** Calcula dano combo skill+attack.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Knight |
| `skill` | number | Weapon skill |
| `attack` | number | Weapon attack |
| `factor` | number | Factor (unused) |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
level = player:getLevel()

min = (level / 5) + (skill + attack) × 0.5
max = (level / 5) + (skill + attack) × 1.5

return -min × 1.1, -max × 1.1
```

**Variáveis Locais:**

| Nome | Tipo | Descrição |
|---|---|---|
| `level` | number | Player level |
| `min` | number | Dano mínimo (pré-mult) |
| `max` | number | Dano máximo (pré-mult) |

**Exemplos:**

| Level | Skill | Attack | Min | Max |
|---|---|---|---|---|
| 35 | 50 | 10 | 40 | 106 |
| 60 | 100 | 20 | 78 | 210 |
| 100 | 150 | 40 | 156 | 418 |
