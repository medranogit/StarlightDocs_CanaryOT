O spell `curse` oferece maldição com DOT persistente:

- **Dano:** COMBAT_DEATHDAMAGE condition-based
- **Condition:** CONDITION_CURSED com 17 ticks
- **DOT:** Escalonado custom (1-10 dano por tick)

Combat com condition customizada:

```
local combat = Combat()
├─ Type: DEATHDAMAGE
├─ Effect: SMALLCLOUDS

   └─ 17 ticks de dano

    condition:setParameter(DELAYED, 1)

    condition:addDamage(1, 3000, -40)
```

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_DEATHDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_SMALLCLOUDS)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_DEATH)
```

**Propósito:** Combat de maldição morte.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_DEATHDAMAGE | Dano morte |
| `COMBAT_PARAM_EFFECT` | CONST_ME_SMALLCLOUDS | Efeito nuvens |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_DEATH | Projétil morte |
