## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_FIREDAMAGE)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_FIRE)
```

**Propósito:** Combat de dano fogo ranged.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_FIREDAMAGE | Dano fogo |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_FIRE | Projétil fogo |

---

### Variável Global: condition

```lua
local condition = Condition(CONDITION_FIRE)
condition:setParameter(CONDITION_PARAM_DELAYED, 1)
condition:addDamage(25, 3000, -45)
combat:addCondition(condition)
```

**Propósito:** Condition de queimadura com damage periódico.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `Type` | CONDITION_FIRE | Queimadura! |
| `DELAYED` | 1 | Inicio com delay |
| `Damage` | 25 | Dano fixo |
| `Duration` | 3000ms | 3 segundos |
| `Period` | -45 | Oscilação negativa |

**Detalhes:**
- Dano fixo 25 (não aleatório)
- `3000`: duração 3 segundos
- `-45`: período oscilante (efeito variável!)

---

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, var)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler simples executa combat.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Sorcerer |
| `var` | Variant | Target |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Ignição lançada |
| `false` | Target falhou |
