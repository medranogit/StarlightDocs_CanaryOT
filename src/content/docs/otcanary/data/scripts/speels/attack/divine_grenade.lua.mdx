### Função Global: onGetFormulaValues (com WOD)

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 4)
	local max = (level / 5) + (maglevel * 6)

	local grade = player:upgradeSpellsWOD("Divine Grenade")

	local multiplier = 1.0
	if grade ~= WHEEL_GRADE_NONE then
		local multiplierByGrade = { 1.3, 1.6, 2.0 }
		multiplier = multiplierByGrade[grade]
	end

	min = min * multiplier
	max = max * multiplier

	return -min, -max
end
```

**Propósito:** Calcula dano com WOD multiplier.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Paladin |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula Base:**
```
min = (level / 5) + (maglevel * 4)
max = (level / 5) + (maglevel * 6)
```

**WOD Multipliers:**

### Função Global: explodeGrenade (CALLBACK)

```lua
local explodeGrenade = function(position, playerId)
	local tile = Tile(position)
	if not tile then
		return
	end

	local player = Player(playerId)
	if not player then
		return
	end

	local var = {}
	var.instantName = "Divine Grenade"
	var.runeName = ""
	var.type = 2 -- VARIANT_POSITION
	var.pos = position
	combatGrenade:execute(player, var)
end
```

**Propósito:** Explosão atrasada 3s após cast.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `position` | Position | Explosão tile |
| `playerId` | number | Player ID caster |

**Lógica:**
- Valida tile existe
- Valida player existe
- Cria variant position
- Executa combatGrenade
- Aplica dano em area 2x2

### Função Global: onTargetCreature (CALLBACK)

```lua
function onTargetCreature(creature, target)
	if not (creature and target and creature:isPlayer()) then
		return false
	end

	local position = creature:getPosition():getWithinRange(target:getPosition(), 4)
	addEvent(explodeGrenade, 3000, position, creature:getId())
	addEvent(removeGrenadeEffect, 3000, position)
	return true
end
```

**Propósito:** Trigger explosão após hit target.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Paladin |
| `target` | Creature | Target criatura |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Callback ok, granada "arremessada" |
| `false` | Validação falhou |

**Lógica:**
- Valida creature é player
- Calcula position within range 4
- Agenda explodeGrenade 3s após
- Agenda removeGrenadeEffect 3s (visual cleanup)

### Função Global: spell.onCastSpell (MUITO COMPLEXA!)

```lua
function spell.onCastSpell(creature, var)
	if not creature or not creature:isPlayer() then
		return false
	end

	local grade = creature:revelationStageWOD("Divine Grenade")

	if grade == 0 then
		creature:sendCancelMessage("You cannot cast this spell")
		creature:getPosition():sendMagicEffect(CONST_ME_POFF)
		return false
	end

	local cooldownByGrade = { 26, 20, 14 }
	local cooldown = cooldownByGrade[grade]

	var.instantName = "Divine Grenade Cast"
	if combatCast:execute(creature, var) then
		local target = Creature(var:getNumber())
		local position = creature:getPosition():getWithinRange(target:getPosition(), 4)
		position:sendMagicEffect(CONST_ME_DIVINE_GRENADE)
		local condition = Condition(CONDITION_SPELLCOOLDOWN, CONDITIONID_DEFAULT, 258)
		condition:setTicks((cooldown * 1000) / configManager.getFloat(configKeys.RATE_SPELL_COOLDOWN))
		creature:addCondition(condition)
		return true
	end
	return false
end
```

**Propósito:** Master handler com validações WOD.

**Fluxo:**

| Step | Ação | Resultado |
|---|---|---|
| 1 | Player check | Se não player: return false |
| 2 | WOD stage check | revelationStageWOD("Divine Grenade") |
| 3 | Grade 0 reject | Se grade 0: send cancel + POFF |
| 4 | Select cooldown | cooldownByGrade[grade] (26/20/14s) |
| 5 | combatCast execute | Triggers onTargetCreature |
| 6 | Get target | Creature(var:getNumber()) |
| 7 | Send visual | CONST_ME_DIVINE_GRENADE magic effect |
| 8 | Add cooldown cond | CONDITION_SPELLCOOLDOWN ID 258 |
| 9 | Return true | Cast success |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Granada lançada com sucesso |
| `false` | Validação falhou |
