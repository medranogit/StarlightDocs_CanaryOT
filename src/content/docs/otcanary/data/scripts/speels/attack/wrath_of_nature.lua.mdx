### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, maglevel)
	local min = (level / 5) + (maglevel * 5)
	local max = (level / 5) + (maglevel * 10)
	return -min, -max
end
```

**Propósito:** Calcula dano terra AOE LINEAR SUPREMAMENTE escalável.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level |
| `maglevel` | number | Magic level |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
min = (level / 5) + (maglevel * 5.0)
max = (level / 5) + (maglevel * 10.0)
```

**Pesos:**
- Level: 0.2 por ponto
- Maglevel min: 5.0 (LINEAR SUPREMO!)
- Maglevel max: 10.0 (LINEAR SUPREMO!)
- Bônus: 0 (direto no coef!)

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 55 | 20 | 111 | 211 |
| 55 | 30 | 161 | 311 |
| 55 | 40 | 211 | 411 |
| 55 | 50 | 261 | 511 |
