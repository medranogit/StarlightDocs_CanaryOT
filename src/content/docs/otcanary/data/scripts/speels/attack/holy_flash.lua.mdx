## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_HOLYDAMAGE)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_SMALLHOLY)
```

**Propósito:** Combat de dano sagrado ranged.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_HOLYDAMAGE | Dano sagrado |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_SMALLHOLY | Projétil sagrado |

---

### Variável Global: condition

```lua
local condition = Condition(CONDITION_DAZZLED)
condition:setParameter(CONDITION_PARAM_DELAYED, 1)
condition:addDamage(math.random(7, 11), 3000, -20)
combat:addCondition(condition)
```

**Propósito:** Condition de paralisia com damage periódico.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `Type` | CONDITION_DAZZLED | Paralisia! |
| `DELAYED` | 1 | Inicio com delay |
| `Damage min-max` | 7-11 | Dano aleatório |
| `Duration` | 3000ms | 3 segundos |
| `Period` | -20 | Oscilação negativa |

**Detalhes:**
- `math.random(7, 11)`: damage aleatório
- `3000`: duração 3 segundos
- `-20`: período oscilante (efeito variável!)

---

### Função Global: spell.onCastSpell

```lua
function spell.onCastSpell(creature, var)
	return combat:execute(creature, var)
end
```

**Propósito:** Handler simples executa combat.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Paladin |
| `var` | Variant | Target |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Flash lançado |
| `false` | Target falhou |
