## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_FIREDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITBYFIRE)
combat:setArea(createCombatArea(AREA_WAVE4, AREADIAGONAL_WAVE4))
```

**Propósito:** Combat de AOE fogo direcionado.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_FIREDAMAGE | Dano fogo |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HITBYFIRE | Efeito fogo |
| `Area 1` | AREA_WAVE4 | Onda linha |
| `Area 2` | AREADIAGONAL_WAVE4 | Onda diagonal |

---

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, level, magicLevel)
	return -11, -14
end
```

**Propósito:** Retorna fixed damage prática.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Conjurador |
| `level` | number | Level (ignorado) |
| `magicLevel` | number | Magic level (ignorado) |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-11` | number | Dano mínimo (fixed) |
| `-14` | number | Dano máximo (fixed) |

**Fórmula:**
```
min = -11 (hardcoded!)
max = -14 (hardcoded!)
```

**Características:**
- Completamente fixed
- Não escalável
- Reduzido prática
- Igual para todos players

**Exemplos:**

| Level | MLvl | Min | Max |
|---|---|---|---|
| 1 | 1 | -11 | -14 |
| 100 | 50 | -11 | -14 |
| Sempre | Sempre | -11 | -14 |

---

### Registração do Callback

```lua

```
