## 💡 Tip

<Aside type="tip">
**Golpe Brutal - Physical Starter Knight**

Este spell implementa um **sistema de dano físico muito escalável para iniciantes**:

1. **Skill-Based Muito Baixo:**
   - Usa CALLBACK_PARAM_SKILLVALUE
   - skillTotal = skill × attack
   - Multiplicadores PEQUENOS (0.02-0.04)

2. **Fórmula Escalável Iniciante:**
   - min = (skillTotal × 0.02 + 4 + levelTotal) × 1.28
   - max = (skillTotal × 0.04 + 9 + levelTotal) × 1.28
   - Baixa escala = training friendly

3. **Iniciante Premium:**
   - Level 16 (cedo)
   - 30 mana (barato)
   - Sem premium
   - Cooldown 6s

4. **Melee Physical:**
   - Alcance 1 (melee)
   - Requer weapon
   - BlockArmor
   - Usa charges

**Fórmula Visual:**
```
Knight lvl 16, skill 20, attack 5:
  skillTotal = 20 × 5 = 100
  levelTotal = 16 / 5 = 3.2
  min = (100×0.02 + 4 + 3.2) × 1.28 = 11.3
  max = (100×0.04 + 9 + 3.2) × 1.28 = 20.2

Knight lvl 50, skill 75, attack 15:
  skillTotal = 75 × 15 = 1125
  levelTotal = 50 / 5 = 10
  min = (1125×0.02 + 4 + 10) × 1.28 = 49.7
  max = (1125×0.04 + 9 + 10) × 1.28 = 73.2
```

**Diferencial:** Muito skill-low para training puro!
</Aside>

## 🔧 Estrutura de Funcionalidades

### Variável Global: combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_PARAM_TYPE, COMBAT_PHYSICALDAMAGE)
combat:setParameter(COMBAT_PARAM_EFFECT, CONST_ME_HITAREA)
combat:setParameter(COMBAT_PARAM_DISTANCEEFFECT, CONST_ANI_WEAPONTYPE)
combat:setParameter(COMBAT_PARAM_BLOCKARMOR, 1)
combat:setParameter(COMBAT_PARAM_USECHARGES, 1)
```

**Propósito:** Combat de dano iniciante.

**Parâmetros:**

| Parâmetro | Valor | Significado |
|---|---|---|
| `COMBAT_PARAM_TYPE` | COMBAT_PHYSICALDAMAGE | Dano físico |
| `COMBAT_PARAM_EFFECT` | CONST_ME_HITAREA | Efeito hit |
| `COMBAT_PARAM_DISTANCEEFFECT` | CONST_ANI_WEAPONTYPE | Projétil weapon |
| `COMBAT_PARAM_BLOCKARMOR` | 1 | Bloqueia armor |
| `COMBAT_PARAM_USECHARGES` | 1 | Usa charges |

### Função Global: onGetFormulaValues

```lua
function onGetFormulaValues(player, skill, attack, factor)
	local skillTotal = skill * attack
	local levelTotal = player:getLevel() / 5
	return -(((skillTotal * 0.02) + 4) + levelTotal) * 1.28, -(((skillTotal * 0.04) + 9) + levelTotal) * 1.28
end
```

**Propósito:** Calcula dano brutal iniciante.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Knight |
| `skill` | number | Weapon skill |
| `attack` | number | Weapon attack |
| `factor` | number | Factor (unused) |

**Retorno:**

| Valor | Tipo | Descrição |
|---|---|---|
| `-min` | number | Dano mínimo |
| `-max` | number | Dano máximo |

**Fórmula:**
```
skillTotal = skill × attack
levelTotal = level / 5

min = (skillTotal × 0.02 + 4 + levelTotal) × 1.28
max = (skillTotal × 0.04 + 9 + levelTotal) × 1.28
```

**Variáveis Locais:**

| Nome | Tipo | Descrição |
|---|---|---|
| `skillTotal` | number | skill × attack |
| `levelTotal` | number | level / 5 |

**Exemplos:**

| Level | Skill | Attack | Min | Max |
|---|---|---|---|---|
| 16 | 20 | 5 | 11 | 20 |
| 30 | 50 | 10 | 34 | 51 |
| 60 | 100 | 15 | 76 | 113 |
| 100 | 150 | 25 | 171 | 256 |
