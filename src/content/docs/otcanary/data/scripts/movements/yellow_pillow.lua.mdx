### Callback onStepIn

```lua
function yellowPillow.onStepIn(creature, item, position, fromPosition)
	local player = creature:getPlayer()
	if not player or player:isInGhostMode() then
		return true
	end

	player:say("Faaart!", TALKTYPE_MONSTER_SAY)
	item:getPosition():sendMagicEffect(CONST_ME_POFF)
	return true
end
```

**Propósito:** Ao pisar, emite som divertido e efeito visual.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que pisou |
| `item` | Item | A almofada (não usado) |
| `position` | Position | Posição da almofada |
| `fromPosition` | Position | Posição anterior (não usado) |

**Fluxo Lógico:**

1. **Converte para Jogador:** `creature:getPlayer()`
2. **Validação Dupla:**
   - Se não é jogador: retorna true (sem ação)
   - Se em ghost mode: retorna true (sem ação)
3. **Som:** `player:say("Faaart!", TALKTYPE_MONSTER_SAY)`
   - Tipo MONSTER_SAY indica som de criatura
   - Audível para todos na área
4. **Efeito Visual:** `item:getPosition():sendMagicEffect(CONST_ME_POFF)`
   - POOF effect (explosão visual cômica)
5. **Retorna:** true (movimento permitido)

## 🤖 Documentação das Funções

### yellowPillow.onStepIn(creature, item, position, fromPosition)

Ao pisar, emite som "Faaart!" e efeito visual poof.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que pisou |
| `item` | Item | A almofada |
| `position` | Position | Posição |
| `fromPosition` | Position | De onde veio |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Sempre (movimento permitido) |

**Validações:**

- **Se não é jogador:** Sem ação
- **Se ghost mode:** Sem ação
- **Senão:** Som + efeito

**Exemplo:**

```lua
-- Jogador normal pisa em almofada (2397)
yellowPillow.onStepIn(player, pillow, pos, fromPos)
// say("Faaart!", MONSTER_SAY)
// sendMagicEffect(POOF)
// Resultado: Som e efeito visual, diversão

-- Jogador ghost pisa
yellowPillow.onStepIn(ghostPlayer, pillow, pos, fromPos)
// isInGhostMode() = true
// Retorna true imediatamente
// Resultado: Sem som, sem efeito (phantasma silencioso)
```
