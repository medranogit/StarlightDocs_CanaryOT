## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `cake.lua` implementa um mecanismo simples de transformação de objeto:

- **Validação de Item:** Verifica se o item a adicionar é exatamente ID 2918
- **Remoção:** Remove o item do inventário do jogador
- **Transformação:** Converte o bolo de ID 6278 para ID 6279
- **Efeito Visual:** Emite magia vermelha na posição do bolo

### Arquitetura

Callback único de additem com validação:

```
Jogador adiciona item a bolo
  └─ onAddItem(item, bolo, posição)
     ├─ if moveitem.itemid == 2918
     │  ├─ remove moveitem
     │  ├─ transform tileitem → 6279
     │  ├─ sendMagicEffect(MAGIC_RED)
     │  └─ return true (sucesso)
     └─ else
        └─ return true (ignora, sem erro)
```

### Fluxo Lógico Resumido

| Condição | Ação | Resultado |
|---|---|---|
| **Item = 2918** | Transforma, remove, efeito | Bolo transformado ✅ |
| **Item ≠ 2918** | Sem ação | Item não afeta ❌ |

### Callback onAddItem

```lua
function cake.onAddItem(moveitem, tileitem, position)
	if moveitem.itemid ~= 2918 then
		return true
	end

	moveitem:remove()
	tileitem:transform(6279)
	position:sendMagicEffect(CONST_ME_MAGIC_RED)
	return true
end
```

**Propósito:** Executado quando jogador adiciona um item sobre o bolo. Se for o item correto, transforma.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `moveitem` | Item | Item sendo adicionado (do inventário do jogador) |
| `tileitem` | Item | Item na tile (o bolo base) |
| `position` | Position | Posição do bolo |

**Fluxo Lógico:**

1. **Validação de Item:** Verifica se `moveitem.itemid == 2918`
   - Se não: Retorna true (ignora, sem erro)
   - Se sim: Continua
2. **Remove Item:** Executa `moveitem:remove()` (o ingrediente sai do jogo)
3. **Transforma Bolo:** `tileitem:transform(6279)` (bolo vira nova versão)
4. **Efeito Visual:** `position:sendMagicEffect(CONST_ME_MAGIC_RED)` (magia vermelha)
5. **Retorna:** true (operação bem-sucedida)

## 🤖 Documentação das Funções

### cake.onAddItem(moveitem, tileitem, position)

Callback executado quando jogador adiciona um item sobre o bolo. Transforma o bolo se for o ingrediente correto.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `moveitem` | Item | Item sendo adicionado (do jogador) |
| `tileitem` | Item | Item na tile (bolo base que será transformado) |
| `position` | Position | Posição onde está o bolo |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Sempre retorna true (sucesso ou item ignored) |

**Validações:**

- **Se itemid ≠ 2918:** Retorna true (item ignorado, sem ação)
- **Se itemid = 2918:** Executa transformação completa

**Execução:**

| Passo | Operação | Descrição |
|---|---|---|
| 1 | `moveitem:remove()` | Remove ingrediente do jogo |
| 2 | `tileitem:transform(6279)` | Transforma bolo em versão nova |
| 3 | `position:sendMagicEffect()` | Emite efeito visual de magia vermelha |
| 4 | `return true` | Confirma sucesso |

**Exemplo:**

```lua
-- Jogador tem "ingrediente especial" (ID 2918)
-- Coloca sobre "bolo vazio" (ID 6278) na tile

cake.onAddItem(ingredient, emptyBolo, position)

-- Validação: ingrediente.itemid = 2918?
-- Sim! Continua...

-- Ações:
-- 1. ingredient:remove() → ingrediente desaparece
-- 2. emptyBolo:transform(6279) → bolo vira boloRecheado
-- 3. position:sendMagicEffect(MAGIC_RED) → magia vermelha no ar
-- 4. return true → bem-sucedido

-- Resultado: Bolo transformado, efeito visual
```
