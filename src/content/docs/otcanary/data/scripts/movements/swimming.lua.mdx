<Aside type="tip">
**Natação com Limpeza de Debuffs**

Este script implementa um **sistema de piscina mágica curativa**:

**Ao Entrar em Água:**
1. Remove 10 tipos de debuffs:
   - Poison, Fire, Energy, Paralyze, Drunk
   - Drown, Freezing, Dazzled, Cursed, Bleeding
2. Aplica outfit único (lookType 267)
3. Outfit é permanente (ticks -1)

**Diferencial:** Água não apenas muda aparência - cura todos os efeitos ruins!

**Fluxo:**
```
Jogador pisa em água
├─ Remove poison
├─ Remove fire
├─ Remove paralyze
├─ ... (10 condições)
└─ Aplica outfit natação

Jogador sai de água
└─ Remove outfit
   (Debuffs já foram removidos, não voltam)
```

**Casos de Uso:**
- Piscinas curativas em town
- Áreas de reset antes de boss
- Mecânica de safe zone com theme

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `swimming.lua` implementa um sistema integrado de natação com benefícios:

- **Remoção de Debuffs:** 10 tipos de conditions removidas
- **Outfit Especial:** Aparência de nadador (lookType 267)
- **Permanência:** Outfit dura até sair da água
- **Cobertura:** Múltiplas tiles de água via `swimmingTiles`

### Arquitetura

Condition pré-criada + loop de remoção + dois callbacks:

```
local condition = Condition(OUTFIT)
├─ lookType = 267 (aparência)
└─ ticks = -1 (permanente)

local conditions = { 10 condition types }

onStepIn:
  ├─ Remove todas 10 conditions
  ├─ Aplica outfit
  └─ Retorna true

onStepOut:
  ├─ Remove outfit
  └─ Retorna true
```

### Fluxo Lógico Resumido

| Evento | Ação | Resultado |
|---|---|---|
| **onStepIn** | Remove debuffs + aplica outfit | Jogador nadador, curado |
| **onStepOut** | Remove outfit | Volta visual normal |

### Callback onStepIn

```lua
function swimming.onStepIn(creature, item, position, fromPosition)
	local player = creature:getPlayer()
	if not player then
		return false
	end

	for i = 1, #conditions do
		player:removeCondition(conditions[i])
	end

	player:addCondition(condition)
	return true
end
```

**Propósito:** Ao entrar em água, cura debuffs e aplica outfit.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que entrou |
| `item` | Item | A água (tile) |
| `position` | Position | Posição da água |
| `fromPosition` | Position | Posição anterior |

**Fluxo Lógico:**

1. **Validação:** Se não é jogador, retorna false
2. **Loop de Remoção:** Itera por 10 conditions
   - Chama `player:removeCondition(conditions[i])` para cada
   - Nenhum erro se não possui (removeCondition é seguro)
3. **Aplica Outfit:** `player:addCondition(condition)` (lookType 267)
4. **Retorna:** true
