## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `trap.lua` implementa um sistema versátil de armadilhas:

- **Configuração Dinâmica:** Tabela suporta múltiplos tipos
- **Transformação Condicional:** Pode transformar ao disparar
- **Dano Variável:** Range min-max por armadilha
- **Tipo de Dano:** Suporta PHYSICAL, EARTH, etc
- **Proteção:** Ignora jogadores em PvP/PvE conforme config
- **Casos Especiais:** Handler especial para "Starving Wolf"

### Arquitetura

Tabela + 3 callbacks em MoveEvents separadas:

```
local traps = {
	[itemId] = { transformTo, damage[], ignorePlayer, type }
}

onStepIn:
  ├─ Validação: PZ, item count, ignorePlayer
  ├─ Transform (se config)
  ├─ Caso especial: Starving Wolf
  └─ Dano (se não especial)

onStepOut:
  └─ Restaura (transform -1)

onRemoveItem:
  ├─ Valida distância
  └─ Restaura + efeito
```

### Fluxo Lógico Resumido

| Evento | Ação | Resultado |
|---|---|---|
| **onStepIn** | Validação + dano | Criatura sofre dano |
| **onStepOut** | Restaura | Armadilha volta visual |
| **onRemoveItem** | Remove remotamente | Restaura + efeito |

## 🔧 Estrutura de Funcionalidades

### Tabela de Armadilhas

```lua
local traps = {
	[2145] = { transformTo = 2146, damage = { -50, -100 } },
	[2148] = { damage = { -50, -100 } },
	[3482] = { transformTo = 3481, damage = { -15, -30 }, ignorePlayer = (Game.getWorldType() == WORLD_TYPE_NO_PVP) },
	[3944] = { transformTo = 3945, damage = { -15, -30 }, type = COMBAT_EARTHDAMAGE },
	[12368] = { ignorePlayer = true },
}
```

**Propósito:** Configuração centralizada de todas as armadilhas.

| Item ID | transformTo | damage | type | ignorePlayer |
|---|---|---|---|---|
| 2145 | 2146 | -50 a -100 | DEFAULT | false |
| 2148 | - | -50 a -100 | DEFAULT | false |
| 3482 | 3481 | -15 a -30 | DEFAULT | PvE-only |
| 3944 | 3945 | -15 a -30 | EARTH | false |
| 12368 | - | - | - | true |

**Nota:** 12368 é caso especial (Starving Wolf feed trap).

### Callback onStepIn

```lua
function trap.onStepIn(creature, item, position, fromPosition)
	local trap = traps[item.itemid]
	if not trap then
		return true
	end

	local tile = Tile(position)
	if not tile then
		return true
	end

	if tile:hasFlag(TILESTATE_PROTECTIONZONE) then
		return true
	end

	if tile:getItemCountById(3482) > 1 then
		return true
	end

	if trap.ignorePlayer and creature:isPlayer() then
		return true
	end

	if trap.transformTo then
		item:transform(trap.transformTo)
	end

	if item.itemid == 12368 and creature:getName() == "Starving Wolf" then
		position:sendMagicEffect(CONST_ME_STUN)
		creature:remove()
		Game.createItem(12369, 1, position)
	else
		doTargetCombatHealth(0, creature, trap.type or COMBAT_PHYSICALDAMAGE, trap.damage[1], trap.damage[2], CONST_ME_NONE)
	end

	return true
end
```

**Propósito:** Ao pisar, dispara armadilha com dano e transformação.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que pisou |
| `item` | Item | A armadilha |
| `position` | Position | Posição |
| `fromPosition` | Position | De onde veio |

**Fluxo Lógico:**

1. **Lookup:** Busca `traps[item.itemid]`
   - Se não encontrado: retorna true (não é armadilha)
2. **Valida Tile:** Se não consegue pegar tile, retorna true
3. **Validação PZ:** Se em protection zone, retorna true (não dispara)
4. **Validação de Item Count:** Se há mais de 1 item ID 3482 na tile, retorna (preventivo)
5. **Validação ignorePlayer:** Se `ignorePlayer=true` e é jogador, retorna true
6. **Transformação:** Se config tem `transformTo`, executa
7. **Caso Especial (Starving Wolf):**
   - Se item 12368 e criatura se chama "Starving Wolf"
   - Efeito STUN
   - Remove a criatura
   - Cria item 12369 (comida)
8. **Dano Normal:**
   - Se não especial: aplica dano variável
   - Tipo: `trap.type or COMBAT_PHYSICALDAMAGE`

### Callback onStepOut

```lua
function trap.onStepOut(creature, item, position, fromPosition)
	if Tile(position):hasFlag(TILESTATE_PROTECTIONZONE) then
		return true
	end

	item:transform(item.itemid - 1)
	return true
end
```

**Propósito:** Ao sair, volta armadilha ao estado anterior.

**Fluxo:**

1. **Validação PZ:** Se em zone segura, não restaura
2. **Restaura:** `item:transform(item.itemid - 1)`
   - Volta ao visual anterior (ex: 2146 → 2145)
3. **Retorna:** true

**Padrão:** Assume que ID anterior é -1 (2146 → 2145).

### Registração do onStepIn/Out

```lua
trap:type("stepin")
for itemId, info in pairs(traps) do
	trap:id(itemId)
end
trap:register()

trap = MoveEvent()
trap:type("stepout")
trap:id(2146, 3945)
trap:register()
```

**onStepOut:** Apenas para IDs transformados (2146, 3945).

### Callback onRemoveItem

```lua
function trap.onRemoveItem(item, position)
	local itemPosition = item:getPosition()
	if itemPosition:getDistance(position) > 0 then
		item:transform(item.itemid - 1)
		itemPosition:sendMagicEffect(CONST_ME_POFF)
	end
	return true
end
```

**Propósito:** Se armadilha is removed remotamente, restaura + efeito.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `item` | Item | A armadilha |
| `position` | Position | Posição do remover |

**Fluxo:**

1. **Get Item Position:** Posição atual do item
2. **Valida Distância:** Se remover não é exato (distance > 0)
   - Transforma para ID anterior
   - Efeito POFF (poof)
3. **Retorna:** true

## 🤖 Documentação das Funções

### trap.onStepIn(creature, item, position, fromPosition)

Ao pisar, dispara armadilha com dano/transformação.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que pisou |
| `item` | Item | A armadilha |
| `position` | Position | Posição |
| `fromPosition` | Position | De onde veio |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Sempre |

**Validações:**

- **Config:** Se item não em traps, ignora
- **PZ:** Em protection zone, não dispara
- **ignorePlayer:** Se true e jogador, ignora
- **Especial:** "Starving Wolf" tem handler próprio

**Exemplo:**

```lua
-- Jogador pisa em armadilha 2145 (dano -50 a -100)
trap.onStepIn(player, item2145, pos, fromPos)
-- transformTo = 2146 → executa
-- Não é PZ → continua
-- damage aplicado: random entre -50 e -100
// Resultado: Armadilha disparada, visual muda

// Criatura "Starving Wolf" pisa em 12368
trap.onStepIn(wolf, item12368, pos, fromPos)
// ignorePlayer = true, mas é criatura → continua
// itemid == 12368 && name == "Starving Wolf"? Sim
// Efeito STUN, remove lobo, cria item 12369
```
