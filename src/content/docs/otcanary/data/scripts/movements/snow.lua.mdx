**Neve com Transformação Progressiva**

Este script implementa um **sistema ambiental de cascata visual**:

1. **Entrada:** Jogador entra em neve

   - Normal? Continua
2. **Transformação:** Neve muda ao sair

```
Neve 799 → Neve 6594 (especial, piegada)

```

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `snow.lua` implementa um sistema dinâmico de neve que transforma progressivamente:

- **Transformação de Neve:** +15 ao ID normal, +814 ao ID 799 (especial)
- **Validação de Ghost:** Ghost mode não marca neve
- **Achievement:** Adiciona progresso a "Snowbunny"
- **Decay:** Neve desaparece naturalmente
- **Cobertura:** 15 tiles de neve diferentes

### Arquitetura

Callback único de stepout com lógicas de transformação:

```
Jogador sai da neve
  └─ onStepOut(creature, item, position, fromPosition)
     ├─ if not player: return true
     ├─ if ghost mode: return true
     ├─ if itemid == 799
     │  └─ transform(6594)
     ├─ else
     │  └─ transform(itemid + 15)
     ├─ achievement +10000
     ├─ decay()
     └─ return true
```

### Fluxo Lógico Resumido

| ItemID | Ghost? | Transformação | Decay | Achievement |
|---|---|---|---|---|
| **799** | Não | → 6594 | Sim | +10k ✅ |
| **799** | Sim | (nenhum) | Não | ❌ |
| **6580-6593** | Não | → +15 | Sim | +10k ✅ |
| **6580-6593** | Sim | (nenhum) | Não | ❌ |

### Callback onStepOut

```lua
function snow.onStepOut(creature, item, position, fromPosition)
	local player = creature:getPlayer()
	if not player then
		return true
	end

	if player:isInGhostMode() then
		return true
	end

	if item.itemid == 799 then
		item:transform(6594)
	else
		item:transform(item.itemid + 15)
	end

	player:addAchievementProgress("Snowbunny", 10000)
	item:decay()
	return true
end
```

**Propósito:** Executado quando jogador sai da neve. Transforma neve e aplica efeitos.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que saiu (pode não ser jogador) |
| `item` | Item | A neve |
| `position` | Position | Posição da neve |
| `fromPosition` | Position | Posição anterior |

**Fluxo Lógico:**

1. **Validação de Jogador:** Se não é jogador, retorna true
2. **Validação de Ghost:** Se em ghost mode, retorna true (sem efeito)
3. **Lógica de Transformação:**
   - Se `itemid == 799`: Transforma para 6594 (especial)
   - Senão: Transforma para `itemid + 15` (progressão)
4. **Achievement:** Adiciona 10.000 pontos a "Snowbunny"
5. **Decay:** Inicia decaimento da neve
6. **Retorna:** true

## 🤖 Documentação das Funções

### snow.onStepOut(creature, item, position, fromPosition)

Callback executado quando jogador sai da neve. Transforma e marca pisadas com achievement.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que saiu |
| `item` | Item | A neve |
| `position` | Position | Posição da neve |
| `fromPosition` | Position | Posição anterior |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Sempre (validação ou processamento completo) |

**Validações:**

1. **Se não é jogador:** Retorna true (sem ação)
2. **Se ghost mode:** Retorna true (sem ação)
3. **Senão:** Transforma, achievement, decay

**Exemplo:**

```lua
-- Jogador normal sai de neve 799
snow.onStepOut(player, neve799, pos, fromPos)
-- isGhostMode() = false
-- itemid == 799? Sim → transform(6594)
-- achievement "Snowbunny" +10000
-- decay()
-- Resultado: Neve transformada visualmente, contador avança

-- Jogador ghost sai de neve 6580
snow.onStepOut(ghostPlayer, neve6580, pos, fromPos)
-- isGhostMode() = true
-- Retorna true imediatamente
-- Resultado: Sem transformação, sem achievement
```
