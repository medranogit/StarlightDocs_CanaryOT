## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `claw_of_the_noxious_spawn.lua` implementa um anel mágico com efeito de penalidade ao equipar:

- **Validação de Zona:** Não causa dano em zonas de proteção (PZ)
- **Dano Randômico:** Inflige 150-200 de damage físico
- **Mensagem de Roleplaying:** Escolhe aleatoriamente entre duas mensagens
- **Efeito Visual:** Emite o efeito de sangue na posição do jogador

### Arquitetura

Simples callback de equip com validação:

```
Jogador equipa anel
  └─ onEquip(player, item, ring, isCheck)
     ├─ if not isCheck (validação real, não preview)
     │  ├─ if not PZ (não está em zone segura)
     │  │  ├─ doTargetCombatHealth() → -150 a -200
     │  │  ├─ sendTextMessage() → msg random
     │  │  ├─ sendMagicEffect() → DRAWBLOOD
     │  │  └─ return true
     │  └─ se em PZ → sem dano
     └─ return true (sempre permite equipagar)
```

### Fluxo Lógico Resumido

| Evento | Entrada | Saída |
|---|---|---|
| **onEquip (fora PZ)** | isCheck = false | Dano (-150 a -200) + Efeito + Mensagem |
| **onEquip (em PZ)** | isCheck = false | Sem dano |
| **onEquip (preview)** | isCheck = true | Sem ação |

### Callback onEquip

```lua
function clawOfTheNoxiousSpawn.onEquip(player, item, slot, isCheck)
	if not isCheck then
		if not Tile(player:getPosition()):hasFlag(TILESTATE_PROTECTIONZONE) then
			doTargetCombatHealth(0, player, COMBAT_PHYSICALDAMAGE, -150, -200, CONST_ME_DRAWBLOOD)
			player:sendTextMessage(MESSAGE_EVENT_ADVANCE, (math.random(2) == 1 and "It tightens around your wrist as you take it on." or "Ouch! The serpent claw stabbed you."))
			return true
		end
	end
	return true
end
```

**Propósito:** Executado quando jogador equipa o anel. Aplica dano se fora de PZ.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Jogador que equipou |
| `item` | Item | O anel sendo equipado |
| `slot` | number | Slot do anel (ring = 8) |
| `isCheck` | boolean | true = preview, false = ação real |

**Fluxo Lógico:**

1. **Verifica isCheck:** Se true (preview), retorna true sem ação
2. **Verifica PZ:** Se jogador está em zona proteção
   - Sim: Retorna true (sem dano)
   - Não: Continua
3. **Aplica Dano:** `doTargetCombatHealth(0, player, COMBAT_PHYSICALDAMAGE, -150, -200, CONST_ME_DRAWBLOOD)`
   - `0` = ID de atacante (sem ataque específico)
   - `COMBAT_PHYSICALDAMAGE` = Tipo de dano
   - `-150` a `-200` = Range de dano
   - `CONST_ME_DRAWBLOOD` = Efeito visual
4. **Envia Mensagem:** Texto aleatório
   - 50% de chance: "It tightens around your wrist as you take it on."
   - 50% de chance: "Ouch! The serpent claw stabbed you."
5. **Retorna true:** Sempre permite equipar (mesmo com dano)

## 🤖 Documentação das Funções

### clawOfTheNoxiousSpawn.onEquip(player, item, slot, isCheck)

Callback executado quando jogador equipa o anel. Inflige dano se fora de zona de proteção.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `player` | Player | Jogador que está equipando |
| `item` | Item | O anel (Claw of the Noxious Spawn) |
| `slot` | number | Slot do anel (ring) |
| `isCheck` | boolean | true = verificação (preview), false = equipada real |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Permite equipar (sempre) |

**Execução:**

1. **Se isCheck = true (preview):** Retorna true sem fazer nada
2. **Se em PZ:** Retorna true sem dano
3. **Se fora de PZ:**
   - Aplica -150 a -200 de damage físico
   - Envia mensagem aleatória (50/50)
   - Efeito visual de sangue
   - Retorna true

**Exemplo:**

```lua
-- Jogador level 100 equipa o anel em town (PZ)
clawOfTheNoxiousSpawn.onEquip(player, anel, 8, false)
-- isCheck = false → ação real
-- Tile possui PZ flag → sem dano
-- Retorna true → anel equipado

-- Jogador level 100 equipa o anel em dungeon (sem PZ)
clawOfTheNoxiousSpawn.onEquip(player, anel, 8, false)
-- isCheck = false → ação real
-- Tile não possui PZ flag → continua
-- Dano: -175 (random entre -150 e -200)
-- Mensagem: "It tightens around your wrist as you take it on."
-- Efeito: CONST_ME_DRAWBLOOD
-- Retorna true → anel equipado (com dano)

-- Preview (mouse over)
clawOfTheNoxiousSpawn.onEquip(player, anel, 8, true)
-- isCheck = true (preview)
-- Retorna true imediatamente (sem verificações)
```
