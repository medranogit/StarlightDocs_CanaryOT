## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `decay_to.lua` implementa um sistema de transformação com decay automático:

- **Transformação:** Incrementa ID do item (+1)
- **Decay:** Inicia decaimento imediato do item
- **Cobertura:** 3 items monitorados (293, 475, 1066)
- **Validação:** Apenas jogadores acionam o evento

### Arquitetura

Callback único de stepin com transformação:

```
Jogador pisa no item
  └─ onStepIn(creature, item, position, fromPosition)
     ├─ if player exists
     │  ├─ transform(itemid + 1)
     │  ├─ decay()
     │  └─ return true
     └─ else return false
```

### Fluxo Lógico Resumido

| Evento | Ação | Resultado |
|---|---|---|
| **onStepIn** | Transforma + decay | Item incrementa e desaparece |

### Callback onStepIn

```lua
function decay.onStepIn(creature, item, position, fromPosition)
	local player = creature:getPlayer()
	if not player then
		return false
	end

	item:transform(item.itemid + 1)
	item:decay()
	return true
end
```

**Propósito:** Executado quando criatura pisa no item. Transforma item e inicia decay.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que pisou (pode não ser jogador) |
| `item` | Item | O item sendo pisado |
| `position` | Position | Posição do item |
| `fromPosition` | Position | Posição anterior da criatura |

**Fluxo Lógico:**

1. **Validação:** Converte creature para player
2. **Rejeita NPC/Monstro:** Se não é jogador, retorna false
3. **Transforma Item:** `item.itemid + 1` (ex: 293 → 294)
4. **Ativa Decay:** `item:decay()` (inicia desaparecimento)
5. **Retorna:** true (movimento permitido)

## 🤖 Documentação das Funções

### decay.onStepIn(creature, item, position, fromPosition)

Callback executado quando criatura pisa no item. Transforma item e inicia decay.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que pisou |
| `item` | Item | O item |
| `position` | Position | Posição atual |
| `fromPosition` | Position | Posição anterior |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Movimento permitido, transformação executada |
| `false` | NPC/Monstro, sem transformação |

**Exemplo:**

```lua
-- Jogador pisa em item 293
decay.onStepIn(player, item293, pos, fromPos)
-- Transformação: 293 → 294
-- Decay ativado
-- Retorna true → movimento permitido

-- NPC pisa em item 293
decay.onStepIn(npc, item293, pos, fromPos)
-- Retorna false → sem transformação
```
