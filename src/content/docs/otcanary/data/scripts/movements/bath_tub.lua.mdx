## 💡 Tip

<Aside type="tip">
**Banheira Mágica com Transformação**

Este script implementa um **mecanismo de área de efeito com estado**:

**Ao Entrar (onStepIn):**
1. Jogador entra na banheira
2. Condition de outfit é aplicada (lockado)
3. Aparência muda para outfit visual (ID 26087)
4. Efeito de splash de água
5. Banheira se torna "não-movível" (transform)

**Ao Sair (onStepOut):**
1. Jogador sai da banheira
2. Condition de outfit é removida
3. Aparência volta ao normal
4. Banheira volta ao estado original (transform)

**Diferencial:**
- Banheira **trocaestado** ao ocupar (FILLED → FILLED_NOTMOVABLE)
- Previne movimento óbvio (não desliza com jogador dentro)
- Condition com ticks `-1` = permanente (até remover)

**Cenários:**
- Transformação visual sem affetar stats
- Zone comportamental (área mágica)
- Feedback imediato (outfit + efeito)
</Aside>

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `bath_tub.lua` implementa um sistema de transformação de outfit combinado com mudança de estado de tile:

- **Transformação de Outfit:** Altera aparência visual do jogador
- **Mudança de Estado:** Banheira muda de ID quando ocupada
- **Efeito Visual:** Emite splash de água
- **Remoção de Efeito:** Restaura tudo ao sair

### Arquitetura

Dois MoveEvents paralelos com estado compartilhado:

```
Jogador entra na banheira
  └─ onStepIn
     ├─ if player exists
     │  ├─ Cria Condition OUTFIT
     │  ├─ addCondition(condition)
     │  ├─ transform(NOTMOVABLE)
     │  ├─ sendMagicEffect(SPLASH)
     │  └─ return true
     └─ return true

Jogador sai da banheira
  └─ onStepOut
     ├─ if player exists
     │  ├─ removeCondition(OUTFIT)
     │  ├─ transform(FILLED)
     │  └─ return true
     └─ return true
```

### Fluxo Lógico Resumido

| Evento | Ação | Resultado |
|---|---|---|
| **onStepIn** | Aplica condition + transforma tile | Jogador com novo outfit, banheira locked |
| **onStepOut** | Remove condition + volta tile | Jogador com outfit original, banheira livre |

## 🔧 Estrutura de Funcionalidades

### Seção 1: Entrada na Banheira (onStepIn)

#### Instanciação

```lua
local bathtubEnter = MoveEvent()
```

**Propósito:** Cria nova instância de MoveEvent para entrada.

---

#### Callback onStepIn

```lua
function bathtubEnter.onStepIn(creature, item, position, fromPosition)
	local player = creature:getPlayer()
	if not player then
		return true
	end

	local condition = Condition(CONDITION_OUTFIT)
	condition:setOutfit({ lookTypeEx = 26087 })
	condition:setTicks(-1)

	position:sendMagicEffect(CONST_ME_WATERSPLASH)
	item:transform(BATHTUB_FILLED_NOTMOVABLE)
	player:addCondition(condition)
	return true
end
```

**Propósito:** Executado quando jogador entra na banheira. Aplica outfit e muda estado.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que entrou (pode não ser jogador) |
| `item` | Item | A banheira |
| `position` | Position | Posição da banheira |
| `fromPosition` | Position | Posição anterior (não usado) |

**Fluxo Lógico:**

1. **Valida se é Jogador:** Se não, retorna true (ignorado)
2. **Cria Condition de Outfit:**
   - Tipo: `CONDITION_OUTFIT` (transformação visual)
   - Data: `{ lookTypeEx = 26087 }` (ID do novo visual)
   - Duração: `-1` (permanente até remover)
3. **Envia Efeito Visual:** `CONST_ME_WATERSPLASH` na posição
4. **Transforma Banheira:** Muda de `FILLED` para `FILLED_NOTMOVABLE`
   - Impede movimento (locked visual)
5. **Aplica Condition:** Jogador agora tem novo outfit
6. **Retorna:** true (sempre sucesso)

---

#### Registração do onStepIn

```lua
bathtubEnter:type("stepin")
bathtubEnter:id(BATHTUB_FILLED)
bathtubEnter:register()
```

| Método | Valor | Significado |
|---|---|---|
| `:type("stepin")` | stepin | Dispara ao entrar na tile |
| `:id(BATHTUB_FILLED)` | BATHTUB_FILLED | ID da banheira vazia/ocupável |
| `:register()` | - | Registra o evento |

**Fluxo Lógico:**

   - Permite movimento novamente
3. **Remove Condition:** Retira condition de outfit

## 🎯 Padrões Identificados

### Padrão 1: Validação de Jogador

```lua
local player = creature:getPlayer()
if not player then
	return true
end
```

**Benefício:** Apenas jogadores recebem efeitos, NPCs/monstros são ignorados.

### Padrão 2: Condition com Ticks Permanentes

```lua
local condition = Condition(CONDITION_OUTFIT)
condition:setTicks(-1)  -- Permanente
```

**Benefício:** Condition dura até explicit removal, não expira sozinha.

### Padrão 3: Transformação Bidirecional

```lua
-- Entrada
item:transform(BATHTUB_FILLED_NOTMOVABLE)

-- Saída
item:transform(BATHTUB_FILLED)
```

**Benefício:** Estado é sincronizado com presença de jogador.

### Padrão 4: Operações Reverse no Exit

```lua
-- onStepIn
condition:setOutfit(...)
player:addCondition(condition)
item:transform(...NOTMOVABLE)

-- onStepOut
player:removeCondition(CONDITION_OUTFIT)
item:transform(...FILLED)
```

**Benefício:** Cada ação de entrada tem reverso na saída.

## 🤖 Documentação das Funções

### bathtubEnter.onStepIn(creature, item, position, fromPosition)

Callback executado quando jogador entra na banheira. Aplica transformation de outfit e altera estado da banheira.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que entrou |
| `item` | Item | A banheira (se for FILLED) |
| `position` | Position | Posição da banheira |
| `fromPosition` | Position | Posição anterior |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Sempre retorna true (sucesso ou ignorado) |

**Execução:**

1. **Validação:** Se não é jogador, retorna true
2. **Cria Condition:** CONDITION_OUTFIT com lookTypeEx=26087
3. **Define Duração:** `-1` (permanente)
4. **Efeito Visual:** WATERSPLASH na position
5. **Transforma Banheira:** BATHTUB_FILLED → BATHTUB_FILLED_NOTMOVABLE
6. **Aplica Condition:** Jogador recebe novo outfit

**Exemplo:**

```lua
-- Jogador entra na banheira
bathtubEnter.onStepIn(jogador, banheira, pos, fromPos)

-- Ações:
-- 1. condition = Condition(OUTFIT)
-- 2. condition:setOutfit({ lookTypeEx = 26087 })
-- 3. condition:setTicks(-1)
-- 4. position:sendMagicEffect(WATERSPLASH)
-- 5. banheira:transform(NOTMOVABLE)
-- 6. jogador:addCondition(condition)

-- Resultado: Jogador com novo visual, banheira locked
```
