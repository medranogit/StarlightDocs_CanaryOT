## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `dough.lua` implementa um sistema de culinária com mapeamento direto:

- **Tabela de Transformação:** 2 pares item → resultado
- **Validação de Item:** Verifica se item está na tabela
- **Transformação:** Converte crú em cozido
- **Efeito Visual:** Emite magia vermelha (calor)
- **Cobertura:** 4 fornos diferentes

### Arquitetura

Tabela + callback de validação e transformação:

```
local pastries = {
	[3604] = 3600,
	[6276] = 6277,
}

Jogador adiciona item em forno
  └─ onAddItem(item, forno, posição)
     ├─ if pastries[moveitem.itemid]
     │  ├─ transform(pastryId)
     │  ├─ sendMagicEffect(HITBYFIRE)
     │  └─ return true
     └─ else return true (ignora)
```

### Fluxo Lógico Resumido

| Item | Forno | Ação | Resultado |
|---|---|---|---|
| **3604** | 2535-2541 | Transforma | 3600 ✅ |
| **6276** | 2535-2541 | Transforma | 6277 ✅ |
| **Outro** | 2535-2541 | Sem ação | Ignora ❌ |

### Callback onAddItem

```lua
function dough.onAddItem(moveitem, tileitem, position)
	local pastryId = pastries[moveitem.itemid]
	if not pastryId then
		return true
	end

	moveitem:transform(pastryId)
	position:sendMagicEffect(CONST_ME_HITBYFIRE)
	return true
end
```

**Propósito:** Executado ao adicionar item em forno. Transforma se for item válido.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `moveitem` | Item | Item sendo adicionado (do inventário) |
| `tileitem` | Item | A tile/forno (não usado) |
| `position` | Position | Posição do forno |

**Fluxo Lógico:**

1. **Lookup:** Busca `moveitem.itemid` em tabela `pastries`
   - Se não encontrado: `pastryId = nil`, retorna true (ignora)
   - Se encontrado: `pastryId = valor`, continua
2. **Transforma Item:** `moveitem:transform(pastryId)` (crú → cozido)
3. **Efeito Visual:** `position:sendMagicEffect(CONST_ME_HITBYFIRE)` (fogo)
4. **Retorna:** true (sempre, sucesso ou ignorado)

## 🤖 Documentação das Funções

### dough.onAddItem(moveitem, tileitem, position)

Callback executado ao adicionar item em forno. Transforma item se for matéria culinária válida.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `moveitem` | Item | Item sendo adicionado |
| `tileitem` | Item | A tile/forno |
| `position` | Position | Posição do forno |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Sempre (item transformado ou ignorado) |

**Validações:**

1. **Se item em tabela:** Transforma
2. **Se item não em tabela:** Ignora

**Exemplo:**

```lua
-- Jogador adiciona biscoito crú (3604) em forno (2535)
dough.onAddItem(cookieRaw, forno2535, pos)
-- pastryId = pastries[3604] = 3600
-- moveitem:transform(3600)
-- position:sendMagicEffect(HITBYFIRE)
-- Retorna true → biscoito assado

-- Jogador adiciona pão (999) em forno
dough.onAddItem(bread, forno, pos)
-- pastryId = pastries[999] = nil
-- Retorna true → sem ação (item ignorado)
```
