**Sistema Complexo de Afogamento com Proteção**

Este script implementa um **mecanismo de água com múltiplas camadas**:

**Camada 1: Afogamento Base**
- Dano: -20 HP a cada 2 segundos
- Ticks: -1 (permanente até remover)
- Aplicado ao entrar em água

**Camada 2: Proteção Equipada**
- 3 capacetes especiais (5460, 11585, 13995)
- Detecta ao entrar
- Sem dano se equipado
- Bonus: haste se exaustão ativa

**Camada 3: Chance de Bolhas**
- 10% de chance ao entrar (1 em 10)
- Efeito visual de bolhas
- Apenas sem capacete

**Fluxo de Entrada (onStepIn):**
```
Jogador entra em água
├─ Tem capacete especial?
│  ├─ Sim: Tem exaustão "coconut-shrimp-bake"?
│  │  ├─ Sim: Aplica haste
│  │  └─ Não: sem efeito
│  └─ Não: Continua
├─ Random 10%?
│  └─ Sim: Efeito de bolhas
└─ Aplica condition de afogamento
```

**Diferencial:** Não é simples "toma dano" - tem proteção equipável!

## 📄 Visão Geral do Código (Resumo Executivo)

### Propósito Principal

O script `drowning.lua` implementa um sistema de afogamento com proteção e mecânicas de bonus:

- **Dano Base:** -20 HP a cada 2 segundos
- **Proteção:** 3 capacetes especiais eliminam dano
- **Bonus Haste:** Se exaustão ativa + capacete + água
- **Chance Visual:** 10% bolhas ao entrar (sem capacete)
- **Remoção:** Ao sair, remove conditions

### Arquitetura

Múltiplas conditions pré-criadas + dois callbacks:

```
Condition DROWN (pré-criada)
├─ -20 dano periódico
├─ -1 ticks (permanente)
└─ 2000ms intervalo

Condition HASTE (pré-criada)
├─ -1 ticks
└─ formula(1.0, 300, 1.0, 300)

onStepIn:
  ├─ Validação de capacete
  ├─ Validação de exaustão
  ├─ Chance 10% bolhas
  └─ Aplica condition

onStepOut:
  ├─ Remove DROWN
  └─ Remove HASTE
```

### Fluxo Lógico Resumido

| Cenário | Ação | Resultado |
|---|---|---|
| **Sem capacete** | Aplica dano | Afoga (-20 a cada 2s) |
| **Com capacete** | Sem dano | Protegido ✅ |
| **Capacete + Exaustão** | Aplica haste | Velocidade ⚡ |
| **Na água** | Sai | Remove dano |

## 🔧 Estrutura de Funcionalidades

### Seção 1: Criação de Conditions Globais

```lua
local condition = Condition(CONDITION_DROWN)
condition:setParameter(CONDITION_PARAM_PERIODICDAMAGE, -20)
condition:setParameter(CONDITION_PARAM_TICKS, -1)
condition:setParameter(CONDITION_PARAM_TICKINTERVAL, 2000)

local conditionHaste = Condition(CONDITION_HASTE)
conditionHaste:setTicks(-1)
conditionHaste:setFormula(1.0, 300, 1.0, 300)
```

**Propósito:** Pré-cria conditions reutilizáveis.

**Condition Drown:**
- Tipo: `CONDITION_DROWN` (afogamento)
- Dano Periódico: `-20` HP
- Duração: `-1` (permanente)
- Intervalo: `2000ms` (a cada 2 segundos)

**Condition Haste:**
- Tipo: `CONDITION_HASTE` (velocidade)
- Duração: `-1` (permanente)
- Fórmula: `(1.0, 300, 1.0, 300)` (velocidade base)

### Seção 2: Entrada em Água (onStepIn)

#### Instanciação

local drowning = MoveEvent()
drowning:type("stepin")

---

#### Callback onStepIn

```lua
function drowning.onStepIn(creature, item, position, fromPosition)
	local player = creature:getPlayer()
	if not player then
		return false
	end

	local headItem = player:getSlotItem(CONST_SLOT_HEAD)
	if headItem and table.contains({ 5460, 11585, 13995 }, headItem:getId()) then
		if player:hasExhaustion("coconut-shrimp-bake") then
			player:addCondition(conditionHaste)
		end

		return true
	elseif math.random(1, 10) == 1 then
		position:sendMagicEffect(CONST_ME_BUBBLES)
	end

	player:addCondition(condition)
	return true
end
```

**Propósito:** Executado ao entrar em água. Aplica dano ou proteção conforme equipamento.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que entrou |
| `item` | Item | A água (tile) |
| `position` | Position | Posição da água |
| `fromPosition` | Position | Posição anterior |

**Fluxo Lógico:**

1. **Validação de Jogador:** Se não é, retorna false
2. **Busca Item na Cabeça:** `getSlotItem(CONST_SLOT_HEAD)`
3. **Validação de Capacete Especial:**
   - Se item na cabeça e ID em `{5460, 11585, 13995}`
     - Valida exaustão "coconut-shrimp-bake"
     - Se ativa: Aplica haste (velocidade aquática)
     - Retorna true (protegido)
4. **Chance de Bolhas (sem capacete):**
   - Random 1 em 10 (10%)
   - Se verdade: Efeito BUBBLES
5. **Aplica Afogamento:** Condition de dano periódico
6. **Retorna:** true

**Capacetes Especiais:**
- 5460, 11585, 13995 protegem de afogamento

## 🎯 Padrões Identificados

### Padrão 1: Condition Pré-Criada

```lua
local condition = Condition(CONDITION_DROWN)
condition:setParameter(...)
condition:setParameter(...)
-- ...reutilizado depois
player:addCondition(condition)
```

**Benefício:** Condition criada uma vez, aplicada múltiplas vezes (performance).

### Padrão 2: Validação em Cascata

```lua
if headItem and table.contains({...}, headItem:getId()) then
	-- Protegido
elseif math.random(...) == 1 then
	-- Efeito visual
end
-- Afogamento padrão
```

**Benefício:** Múltiplas camadas de validação + fallback padrão.

### Padrão 3: Exaustão como Gateway

```lua
if headItem and ... then
	if player:hasExhaustion("coconut-shrimp-bake") then
		player:addCondition(conditionHaste)
	end
	return true
end
```

**Benefício:** Bônus especial (haste) requer equipamento + exaustão específica.

### Padrão 4: Remoção Simétrica

```lua
function drawning.onStepIn
	player:addCondition(condition)
	player:addCondition(conditionHaste)

function drowning.onStepOut
	player:removeCondition(CONDITION_DROWN)
	player:removeCondition(CONDITION_HASTE)
```

**Benefício:** onStepOut é reverso de onStepIn.

## 🤖 Documentação das Funções

### drowning.onStepIn(creature, item, position, fromPosition)

Callback executado ao entrar em água. Aplica afogamento ou proteção conforme equipamento.

**Parâmetros:**

| Nome | Tipo | Descrição |
|---|---|---|
| `creature` | Creature | Criatura que entrou |
| `item` | Item | A água |
| `position` | Position | Posição da água |
| `fromPosition` | Position | Posição anterior |

**Retorno:**

| Valor | Significado |
|---|---|
| `true` | Movimento permitido |
| `false` | Se não é jogador |

**Validações:**

1. **Jogador?** Se não, retorna false
2. **Capacete especial?** Se sim:
   - Validação de exaustão
   - Aplica haste se ativa
   - Retorna true (protegido)
3. **Random 10%?** Se sim:
   - Efeito de bolhas
4. **Padrão:** Aplica afogamento

**Exemplo:**

```lua
-- Jogador sem capacete entra em água
drowning.onStepIn(player, water, pos, fromPos)
-- headItem = nil
-- Random 10% = verdade
-- position:sendMagicEffect(BUBBLES)
-- player:addCondition(condition) → -20 dano a cada 2s
-- Resultado: Afogando com efeito de bolhas

-- Jogador com capacete 5460 entra em água
drowning.onStepIn(player, water, pos, fromPos)
-- headItem:getId() = 5460 (em lista)
-- hasExhaustion("coconut-shrimp-bake")? Sim
-- player:addCondition(conditionHaste)
-- return true
-- Resultado: Protegido + velocidade aquática

-- Mesmo jogador sai
drowning.onStepOut(player, water, pos, fromPos)
-- removeCondition(DROWN)
-- removeCondition(HASTE)
-- return true
-- Resultado: Sem dano, velocidade volta
```
