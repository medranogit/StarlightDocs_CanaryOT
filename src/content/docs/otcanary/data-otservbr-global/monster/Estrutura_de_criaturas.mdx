# Estrutura de Monstros - Guia Completo

## 📋 Visão Geral

Este documento explica a estrutura padrão utilizada para documentar cada monstro no Canary Server. Todos os monstros seguem este template português de 11 seções, permitindo compreensão consistente de suas propriedades, combate e loot.

---

## 1️⃣ Seção: Informações Básicas

**Propriedades fundamentais do monstro:**

| Propriedade | Descrição |
|---|---|
| **Experiência** | XP oferecido ao derrotar a criatura |
| **Vida Total** | HP máximo (mana cost em alguns casos especiais) |
| **Raça** | Classificação biológica (Blood, Undead, Venom, Elemental, etc.) |
| **Velocidade** | Quão rápido o monstro se move (valor numérico 0-999) |

### Exemplo:
```
XP: 1.430 | HP: 3.600 | Raça: Undead | Velocidade: 110
```

---

## 2️⃣ Seção: Aparência

**Características visuais do monstro:**

| Propriedade | Descrição |
|---|---|
| **Look Type** | ID do modelo visual principal |
| **Look Type Extended** | ID estendido (para modelos especiais/piñatas) |
| **Head/Body/Legs/Feet** | IDs de aparência customizada |
| **Corpse ID** | ID do cadáver deixado ao morrer |
| **Addons** | Acessórios/customizações (0 = nenhum) |

### Exemplo:
```
Look Type: 78 | Corpse ID: 6.019
ou
Look Type Extended: 25.062 | Corpse ID: 0 (para piñatas)
```

---

## 3️⃣ Seção: Stats (Defesa & Mitigação)

**Propriedades defensivas fundamentais:**

| Propriedade | Descrição |
|---|---|
| **Armadura** | Defesa física do monstro (formato Defense/Armor em pares, ex: 25/25) |
| **Mitigação** | Multiplicador de redução de dano (0.00 = nenhuma, 1.60 = máxima conhecida) |
| **Cura** | Se o monstro se regenera (Sim/Não + valores) |

### Interpretação de Mitigação:
- **0.00-0.99**: Defesa fraca (vulnerável)
- **1.00-1.19**: Defesa normal (padrão)
- **1.20-1.40**: Defesa forte (tanque)
- **1.50+**: Defesa excelente (fortress)

---

## 4️⃣ Seção: Combate

**Sistema de ataque e defesa em combate:**

### Subsseção A: Ataques

| Campo | Descrição |
|---|---|
| **Tipo** | Melee, Combat (ranged), Speed, Outfit, Condition, etc. |
| **Intervalo** | Tempo em ms entre ataques (2000 = 2 segundos) |
| **Chance** | Percentual de chance de executar (100% = sempre) |
| **Dano** | Range de dano (ex: -50 a -150) |
| **Especiais** | Efeitos adicionais (Poison, Fire, Drunk, Skill Reducer, etc.) |

### Subsseção B: Defesas

| Campo | Descrição |
|---|---|
| **Type** | Speed Boost, Healing, Outfit Transform, Combat Resistance |
| **Chance** | Frequência da defesa ativar (%) |
| **Efeito** | O que acontece (aumenta velocidade, cura HP, transforma outfit) |

### Subsseção C: Summons (Se aplicável)

| Campo | Descrição |
|---|---|
| **Creature** | Nome da criatura summonada |
| **Chance** | Frequência de summon (%) |
| **Intervalo** | Tempo entre tentativas de summon |
| **Máximo** | Número máximo de cópias simultâneas |

---

## 5️⃣ Seção: Bestiary

**Classificação e categorização do monstro:**

| Propriedade | Descrição |
|---|---|
| **Classe** | Tipo geral (Blood, Undead, Humanoid, Memory, Event, etc.) |
| **Tipo** | Subtipo específico (Boss, Minion, Raid, Decoration, etc.) |
| **Localização** | Zona onde aparece (Venore, Kazordoon, Event, Memory, etc.) |
| **⭐ Avaliação** | Raridade/Dificuldade (1-5 stars, Elite, NEMESIS, Event Boss, etc.) |

---

## 6️⃣ Seção: Características

**Flags comportamentais do monstro:**

| Flag | Significado |
|---|---|
| **Summonable** | Pode ser summonado por spell |
| **Convincível** | Pode ser convencido (servant) |
| **Pushable** | Pode ser empurrado (knocked back) |
| **Pode caminhar em [Elemento]** | Imunidade de terreno (Energia, Fogo, Veneno) |
| **Reward Boss** | Status de boss de recompensa |
| **Estatística de Ataque** | % de acerto base (90% padrão) |
| **Distância Alvo** | Range de detecção (1 = melee, 4+ = ranged) |
| **Corre quando** | HP threshold para fuga |

---

## 7️⃣ Seção: Imunidades

**Resistências a status/condições:**

| Status | Efeito |
|---|---|
| **Paralyze** | Imune a paralização |
| **Outfit Change** | Imune a transformação de outfit |
| **Invisibility** | Imune a invisibilidade |
| **Bleed** | Imune a sangramento |

⚠️ **Padrão de Memory Creatures**: Paralyze (✓), Invisibility (✓), Outfit (✗), Bleed (✗)

---

## 8️⃣ Seção: Resistências

**Matrix de resistência a 10 tipos de dano:**

| Tipo | Descrição |
|---|---|
| **Físico** | Espadas, machados, impactos |
| **Energia** | Magia de energia/eletricidade |
| **Terra** | Magia de terra/plant effects |
| **Fogo** | Chamas diretas |
| **Drain de Vida** | Absorção de HP |
| **Drain de Mana** | Absorção de mana |
| **Afogamento** | Dano por água |
| **Gelo** | Magia de gelo |
| **Sagrado** | Magia holy/divine |
| **Morte** | Magia de morte/necromancy |

### Valores:
- **0%**: Sem resistência (vulnerável)
- **50-99%**: Resistência parcial
- **100%**: Imune

## 9️⃣ Seção: Loot

**Tabela de drops com percentuais de chance:**

| Item | Chance | QTY |
|---|---|---|
| Gold Coin | 70% | até 75 |
| Rare Item | 5.5% | 1-2 |
| Decoration | 10% | 1 |

### Interpretação de Chance:
- **100%**: DROP GARANTIDO
- **50%+**: DROP COMUM
- **10-50%**: DROP MODERADO
- **1-10%**: DROP RARO
- **\<1%**: DROP ULTRA-RARO

## 🔟 Seção: Nota Contextual

**Resumo narrativo caracterizando o monstro:**

Parágrafo único em português PT-BR que descreve:
- Categoria do monstro (reward boss, minion, raid creature, etc.)
- Especialização de combate (fire specialist, poison master, etc.)
- Caraceterísticas defensivas notáveis
- Qualidades únicas de loot
- Contexto de evento (se aplicável)

### Exemplo:
```
"Memory of a Hydra é criatura de memória avançada (1800 XP, 3550 HP) com 
múltiplos ataques elementais (ice line + ranged, terra line, melee). Speed 
reducer MASSIVO (-700, MAIOR redutor) à longa distância. Mitigação EXCELENTE 
(1.50) com healing MASSIVO (260-407 HP, MAIOR healing). Loot mínimo (5 itens). 
Imunidades standard."
```

## 🎯 Checklista de Documentação

Ao documentar um novo monstro, verificar:

- [ ] **Seção 1**: XP, HP, Raça, Velocidade preenchidos
- [ ] **Seção 2**: Look Type + Corpse ID confirmados
- [ ] **Seção 3**: Armadura, Mitigação, Cura calculados
- [ ] **Seção 4**: Todos ataques listados com dano/chance
- [ ] **Seção 5**: Bestiary classification apropriada
- [ ] **Seção 6**: Todas flags comportamentais mapeadas
- [ ] **Seção 7**: Imunidades de status verificadas
- [ ] **Seção 8**: Matrix de 10 resistências completa
- [ ] **Seção 9**: Loot table com chances reais
- [ ] **Seção 10**: Nota contextual em português PT-BR

## 🎓 Conclusão

Este guia fornece a base estrutural para compreender e documentar qualquer monstro no Canary Server. Cada criatura, independentemente de raridade ou complexidade, segue este template de 11 seções, garantindo documentação consistente e navegável.

Para perguntas específicas sobre uma criatura, sempre consulte primeiro:
1. Seu arquivo `.lua` original (data-otservbr-global/monster/*)
2. O arquivo MDX correspondente da categoria
3. Este guia de estrutura para interpretação
