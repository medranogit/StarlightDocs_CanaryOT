## 📄 Visão Geral

Soul War é a **quest final/épica** do Canary com mecânicas avançadas:

1. **6 Fases**: Cada Goshnar mini-boss tem mechanic único
2. **Item Progression**: 25+ itens especiais (sorrow, mortal essence, etc)
3. **Taint System**: 5 níveis de "taint" progressiva (~4.5% a 24.6% XP boost)
4. **Raids Progressivas**: 3 floors de Claustrophobic Inferno
5. **Weapons Épicas**: 18 soul weapons como reward final

### Taint Experience Boost

```lua
taintExperienceBoostMap = {
  [1] = { boost = 4.5 },    -- 1 taint = +4.5%
  [2] = { boost = 9.2 },    -- 2 taint = +9.2%
  [3] = { boost = 14.1 },   -- 3 taint = +14.1%
  [4] = { boost = 19.2 },   -- 4 taint = +19.2%
  [5] = { boost = 24.6 },   -- 5 taint = +24.6%
}
```

Cada taint adiciona multiplicador de experience crescente (não-linear).

### Goshnar Cruelty Mechanics

```lua
timeToIncreaseCrueltyDefense = 15,        -- Defense aumenta a cada 15 seg
useGreedMawCooldown = 30,                 -- 30 seg cooldown pra usar item
goshnarsCrueltyDefenseChange = 2,         -- +/- 2 defense por 15 seg
goshnarsCrueltyWaveInterval = 7,          -- Waves a cada 7 seg

timeToReturnImmuneMegalomania = 70,       -- After 70 seg, imune novamente
```

Cruelty é **boss progressivo** que:
- Aumenta defense a cada 15 seg (se não usar mortal essence)
- Pode ser reduzido com `someMortalEssenceId`
- Spawna waves de creatures

## 💾 Storage (KV System)
