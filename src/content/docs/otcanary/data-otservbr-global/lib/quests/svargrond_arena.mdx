## 🛠️ Informações do Arquivo

O arquivo **svargrond_arena.lua** implementa a **Barbarian Arena de Svargrond** com sistema de:
- 10 pits de combate (1v1 arenas)
- 3 dificuldades progressivas
- 30 creatures/bosses para lutar
- 3 trophies para rewards

## 📄 Visão Geral

Svargrond Arena é um **sistema de pits/arenas** onde:
1. 10 salas de combate (pits) independentes
2. Cada pit pode ser usado por 1 jogador simultâneamente
3. 3 dificuldades ascending (30 creatures total)
4. Trophies como rewards para vencedores
5. Preço para participar (1000, 5000, 10000 gold)

## 🕐 Timing

```lua
kickTime = 600  -- 10 minutos
```

Se jogador não terminar arena em 10 minutos:
1. Qualquer criatura viva é removida
2. Jogador é kickado do pit
3. Teleportado para `kickPosition`

## 🎯 Fluxo de Operação

```
Player paga X gold (1000/5000/10000)
  ↓
Pit escolhido (1-10)
  ↓
Creature #1 summoned no pit
  ↓
Player vs Creature (arena fechada)
  ↓
Creature morre?
  ├─ NÃO: Player morre → Kickado
  └─ SIM: Próxima criatura (#2-10)
  ↓
Todo creature vencido? (10/10)
  ├─ NÃO: Continue
  └─ SIM: Victory!
      ├─ Trophy dado
      ├─ Achievement desbloqueado
      └─ Teleportado para rewardPosition
```
