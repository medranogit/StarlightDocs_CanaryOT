## 🛠️ Informações do Arquivo

O arquivo **quest.lua** é um **arquivo loader (bootstrap)** que centraliza o carregamento de todos os 10 arquivos de quest da pasta `lib/quests/`.

<Card title="Caminho Original">
`data-otservbr-global/lib/quests/quest.lua`
</Card>

<Aside type="tip">
**Tipo**: Bootstrap/Loader  
**Padrão**: Central dofile() hub  
**Total de Arquivos Carregados**: 10  
**Propósito**: Inicializar todo o subsystem de quests
</Aside>

## 📄 Visão Geral

Este é um arquivo **mínimo** contendo apenas 10 linhas de `dofile()`:

```lua
dofile(DATA_DIRECTORY .. "/lib/quests/bigfoot_burden.lua")
dofile(DATA_DIRECTORY .. "/lib/quests/demon_oak.lua")
dofile(DATA_DIRECTORY .. "/lib/quests/grimvale.lua")
dofile(DATA_DIRECTORY .. "/lib/quests/killing_in_the_name_of.lua")
dofile(DATA_DIRECTORY .. "/lib/quests/svargrond_arena.lua")
dofile(DATA_DIRECTORY .. "/lib/quests/the_cursed_crystal.lua")
dofile(DATA_DIRECTORY .. "/lib/quests/the_queen_of_the_banshees.lua")
dofile(DATA_DIRECTORY .. "/lib/quests/soul_war.lua")
dofile(DATA_DIRECTORY .. "/lib/quests/their_masters_voice.lua")
dofile(DATA_DIRECTORY .. "/lib/quests/the_primal_ordeal.lua")
```

## 🔄 Fluxo de Carregamento

```
[Server Bootstrap]
  ↓
[quest.lua carregado]
  ↓
dofile(bigfoot_burden.lua) → warzoneConfig global criado
  ↓
dofile(demon_oak.lua) → DEMON_OAK_* constantes criadas
  ↓
dofile(grimvale.lua) → grimvaleSpectators() função criada
  ↓
dofile(killing_in_the_name_of.lua) → tasks config criado
  ↓
dofile(svargrond_arena.lua) → SvargrondArena/PITS/ARENA criados
  ↓
dofile(the_cursed_crystal.lua) → TCC_* constantes criadas
  ↓
dofile(the_queen_of_the_banshees.lua) → Seal tables criadas
  ↓
dofile(soul_war.lua) → SoulWarQuest config criado
  ↓
dofile(their_masters_voice.lua) → Wave system funcs criadas
  ↓
dofile(the_primal_ordeal.lua) → RegisterPrimalPackBeast func criada
  ↓
[Todos globals/funcs disponíveis para scripts]
```

## 💡 Padrão: Centralized Bootstrap

**Vantagem**: 
- Single entry point para quest system
- Fácil adicionar/remover quests (edit uma linha)
- Order of loading é explícito
- Evita circular dependencies

**Alternativa não-usada**:
```lua
-- Menos ideal:
local questDir = DATA_DIRECTORY .. "/lib/quests/"
for file in io.files(questDir) do
  dofile(questDir .. file)
end
```
A alternativa seria dinâmica mas perderia controle de ordem.

## 🔍 Ordem de Carregamento (Importante!)

A **ordem importa** pois alguns arquivos podem depender de outros:

1. **bigfoot_burden.lua** → Define warzoneConfig (usado por events)
2. **demon_oak.lua** → Posições isoladas (sem dependências)
3. **grimvale.lua** → Event system independente
4. **killing_in_the_name_of.lua** → Task system independente
5. **svargrond_arena.lua** → Arena config independente
6. **the_cursed_crystal.lua** → Posições isoladas
7. **the_queen_of_the_banshees.lua** → Config da quest
8. **soul_war.lua** → **DEPENDE** de KV system (talvez carregado antes?)
9. **their_masters_voice.lua** → Wave spawner independente
10. **the_primal_ordeal.lua** → Registro de custom monster

## ⚠️ Notas Técnicas

### DATA_DIRECTORY

```lua
DATA_DIRECTORY .. "/lib/quests/..."
```

- Constante global que aponta para `data-otservbr-global/`
- Path absoluto reconstruído dinamicamente
- Independente do diretório raiz do servidor

### Sem Verificação de Erro

Arquivo usa `dofile()` simples (sem try/catch):
```lua
dofile(...)  -- Se falhar, server falha todo
```

Melhor prática seria:
```lua
if not dofile(...) then
  print("[ERROR] Failed to load quest: " .. filename)
end
```

## 🎯 Padrão de Extensão

Para **adicionar nova quest**:

```lua
-- Adicionar antes do último dofile:
dofile(DATA_DIRECTORY .. "/lib/quests/my_new_quest.lua")

-- Último item fica com a_primal_ordeal.lua
```

Para **remover quest**:

```lua
-- Comentar/deletar linha:
-- dofile(DATA_DIRECTORY .. "/lib/quests/their_masters_voice.lua")
```
