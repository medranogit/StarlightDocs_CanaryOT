## 🛠️ Informações do Arquivo

O arquivo **demon_oak.lua** é um **arquivo de constantes de posição** que define os 4 pontos-chave para a quest Demon Oak.

<Card title="Caminho Original">
`data-otservbr-global/lib/quests/demon_oak.lua`
</Card>

<Aside type="note">
**Tipo**: Constantes de Posição  
**Total de Posições**: 4
**Padrão**: Global Position Constants
**Arquivo Mínimo**: ~5 linhas código
**Propósito**: Referência para callbacks/scripts da quest
</Aside>

## 📄 Visão Geral

Este é um dos **arquivos mais simples do projeto** - contém apenas 4 constantes `Position`:

```lua
DEMON_OAK_POSITION = Position(32716, 32351, 7)
DEMON_OAK_KICK_POSITION = Position(32716, 32340, 7)
DEMON_OAK_ENTER_POSITION = Position(32716, 32347, 7)
DEMON_OAK_REWARDROOM_POSITION = Position(32714, 32398, 8)
```

## 🗺️ Posições Definidas

### DEMON_OAK_POSITION

```
Position: (32716, 32351, 7)
```

- **Uso**: Posição principal do Demon Oak (onde boss spawna ou está localizado)
- **Z-level**: 7 (floor inferior)
- **Propósito**: Centro da sala da quest

### DEMON_OAK_KICK_POSITION

```
Position: (32716, 32340, 7)
```

- **Uso**: Posição onde o jogador é kickado/teleportado fora
- **Offset**: 11 tiles ACIMA de DEMON_OAK_POSITION (Y: 32351 → 32340)
- **Z-level**: 7 (mesmo floor)
- **Propósito**: Exit de fail/derrota

### DEMON_OAK_ENTER_POSITION

```
Position: (32716, 32347, 7)
```

- **Uso**: Posição de entrada/teleport para dentro da sala
- **Offset**: 4 tiles ACIMA de DEMON_OAK_POSITION (Y: 32351 → 32347)
- **Z-level**: 7 (mesmo floor)
- **Propósito**: Spawn position ao entrar na quest

### DEMON_OAK_REWARDROOM_POSITION

```
Position: (32714, 32398, 8)
```

- **Uso**: Posição da sala de recompensa (após sucesso)
- **Offset**: 47 tiles ABAIXO (Y: 32351 → 32398) + 1 floor UP (Z: 7 → 8)
- **Z-level**: 8 (floor superior)
- **Propósito**: Teleport para reward room após vencer

## 🎯 Mapa de Posições

```
Floor 7 (Main Battle):
  Y=32340 ← KICK_POSITION (exit fail)
  Y=32347 ← ENTER_POSITION (entry point)
  Y=32351 ← DEMON_OAK_POSITION (boss location)
  X=32716 (todas as mesmas)

Floor 8 (Reward):
  (32714, 32398, 8) ← REWARDROOM_POSITION
```

## 💡 Padrões de Uso

### Em scripts de quest

```lua
-- Teleportar jogador para sala de boss
player:teleportTo(DEMON_OAK_ENTER_POSITION)

-- Se falhar ou morre
player:teleportTo(DEMON_OAK_KICK_POSITION)

-- Se completar quest
player:teleportTo(DEMON_OAK_REWARDROOM_POSITION)
```

### Em eventos de morte

```lua
if creature:getName() == "Demon Oak" then
  local pos = Tile(DEMON_OAK_POSITION)
  pos:sendMagicEffect(CONST_ME_MAGIC_ENERGYAREA)
end
```

## ⚠️ Notas de Implementação

- **Sem movimento**: Todas coordenadas em X fixas (32716)
- **Sem movement check**: Este arquivo apenas define, não valida
- **Integração**: Usado por outros scripts via `dofile()`
- **Recompensa**: Position separada em floor diferente (anti-cheese)
