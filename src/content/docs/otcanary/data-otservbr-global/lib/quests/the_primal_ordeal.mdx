## 🔧 Função: RegisterPrimalPackBeast

### Assinatura

```lua
function RegisterPrimalPackBeast(template)
  local name = template.name or template.description:gsub("an ", ""):gsub("a ", ""):titleCase()
  local primal = Game.createMonsterType(name .. " (Primal)")
  local primalMonster = table.copy(template)
  
  -- Modificações
  primalMonster.experience = 0
  primalMonster.loot = {}
  primalMonster.name = "Primal Pack Beast"
  primalMonster.description = "a primal pack beast"
  primalMonster.maxHealth = primalMonster.maxHealth * 0.7
  primalMonster.health = primalMonster.maxHealth
  primalMonster.raceId = nil
  primalMonster.Bestiary = nil
  primalMonster.corpse = 0
  
  primal:register(primalMonster)
end
```

### Parâmetros

**template**: Tabela de definição de monster original

```lua
{
  name = "creature name",
  description = "a creature description",
  maxHealth = 100,
  -- ... (resto das propriedades)
}
```

## 🔄 Processamento Passo-a-Passo

### 1. Derivar Nome

```lua
local name = template.name or 
  template.description:gsub("an ", ""):gsub("a ", ""):titleCase()
```

**Lógica**:
- Se `.name` existe: use direto
- Senão, use `.description`
- Remove artigos "an " e "a "
- Aplica `.titleCase()` (capitalize first letter)

**Exemplos**:
- `"a troll"` → `"Troll"`
- `"an orc wizard"` → `"Orc Wizard"`
- `"Giant Spider"` → `"Giant Spider"` (já capitalizado)

### 2. Criar Tipo Customizado

```lua
local primal = Game.createMonsterType(name .. " (Primal)")
```

- **Nome registrado**: `"Original Name (Primal)"`
- **Exemplo**: `"Troll (Primal)"`, `"Giant Spider (Primal)"`

### 3. Clonar Template

```lua
local primalMonster = table.copy(template)
```

Deep-copy da tabela completa (inclui stats, abilities, loot, etc).

### 4. Modificações ao Clone

#### Experience = 0

```lua
primalMonster.experience = 0
```

- **Efeito**: Matar Primal Beast NÃO dá XP
- **Propósito**: Mobs de quest (não farm)

#### Loot = {}

```lua
primalMonster.loot = {}
```

- **Efeito**: Nenhum drop ao matar
- **Propósito**: Sem gold/items

#### Nome Genérico

```lua
primalMonster.name = "Primal Pack Beast"
primalMonster.description = "a primal pack beast"
```

- **Efeito**: Todos Primal Beasts têm mesmo nome
- **Propósito**: Grupos de creatures indistinguíveis

#### Health -30%

```lua
primalMonster.maxHealth = primalMonster.maxHealth * 0.7
primalMonster.health = primalMonster.maxHealth
```

- **Modificação**: 30% HP redução
- **Exemplo**: 100 HP → 70 HP
- **Propósito**: Mais fáceis que originais

#### Sem Race/Bestiary

```lua
primalMonster.raceId = nil
primalMonster.Bestiary = nil
```

- **Efeito**: Não contam para Bestiary
- **Propósito**: Não polui progression

#### Sem Corpse

```lua
primalMonster.corpse = 0
```

- **Efeito**: Sem corpo lootável
- **Propósito**: Limpa arena automaticamente

### 5. Registrar Novo Tipo

```lua
primal:register(primalMonster)
```

Registra o monster customizado no servidor.

## 🎯 Características da Primal Beast

| Propriedade | Modificação | Propósito |
|-------------|-------------|----------|
| `experience` | = 0 | Sem farm |
| `loot` | = {} | Sem drop |
| `name` | = "Primal Pack Beast" | Genérico |
| `maxHealth` | × 0.7 | -30% HP |
| `raceId` | = nil | Sem Bestiary |
| `Bestiary` | = nil | Sem tracking |
| `corpse` | = 0 | Sem body |

## ⚠️ Observações

1. **Aplicável a qualquer creature**: Função genérica (não specific monster)
2. **Clonagem profunda**: Todas propriedades copiadas, não shared
3. **Health é auto-reset**: `health` é sinc com `maxHealth`
4. **Sem damage scaling**: Damages inherit do template (não reduzem)
