## 🛠️ Informações do Arquivo

O arquivo **killing_in_the_name_of.lua** implementa um **sistema de tarefas de morte massivo** com múltiplos NPCs oferecendo diferentes tipos de missões de assassinato com recompensas escaladas (exp, moeda, achievements, items).

<Card title="Caminho Original">
`data-otservbr-global/lib/quests/killing_in_the_name_of.lua`
</Card>

<Aside type="caution">
**Tipo**: Task System Config  
**Arquivo Size**: 1052 linhas  
**NPCs**: 50+ (DanielSteelsoul, Gabel, Malor, Budrik, Lugri, etc)  
**Ranks**: 6 níveis (Join, Huntsman, Ranger, Big Game Hunter, Trophy Hunter, Elite Hunter)  
**Padrão**: Global Config Table (tasks by NPC by mission)
</Aside>

## 📄 Visão Geral

Sistema de **tarefas de morte** onde:
1. Cada NPC oferece 1+ missões de assassinato
2. Cada missão requer X kills de criaturas específicas
3. Recompensas podem ser: EXP, Moeda, Achievements, Items, Storage
4. Rank sobe progressivamente pela conclusão de tarefas

## 🔧 Estrutura Técnica

### Constantes Globais

```lua
RANK_NONE = 0
RANK_JOIN = 1
RANK_HUNTSMAN = 2           -- 100 kills
RANK_RANGER = 3             -- 300 kills
RANK_BIGGAMEHUNTER = 4      -- 600 kills
RANK_TROPHYHUNTER = 5       -- 1000 kills
RANK_ELITEHUNTER = 6        -- 2000+ kills

REWARD_MONEY = 1
REWARD_EXP = 2
REWARD_ACHIEVEMENT = 3
REWARD_STORAGE = 4
REWARD_POINT = 5
REWARD_ITEM = 6

QUESTSTORAGE_BASE = 1500    -- Quest storage offset
JOIN_STOR = 100157          -- Join quest storage
KILLSSTORAGE_BASE = 65000   -- Kills counter storage
REPEATSTORAGE_BASE = 48950  -- Repeat quest storage
POINTSSTORAGE = 2500        -- Fame points storage
```

### Padrão de Task

```lua
[1] = {
  killsRequired = 100,
  raceName = "Trolls",
  level = { 6, 19 },          -- Min/Max level required
  storage = { 12701, 1 },     -- [storage_key, requirement_value]
  norepeatable = false,       -- true = quest não pode ser repetida
  premium = true,             -- Requer Premium
  creatures = {
    "troll",
    "troll champion",
  },
  rewards = {
    { type = "exp", value = { 200 } },
    { type = "money", value = { 200 } },
    { type = "achievement", value = { "Troll Slayer" } },
  },
}
```

## 💡 Tipos de Recompensas

### REWARD_MONEY (type: "money")

```lua
{ type = "money", value = { 5000 } }  -- Adiciona 5000 gold
```

### REWARD_EXP (type: "exp")

```lua
{ type = "exp", value = { 10000 } }  -- Adiciona 10000 experience
```

### REWARD_ACHIEVEMENT (type: "achievement")

```lua
{ type = "achievement", value = { "Troll Slayer" } }
```

### REWARD_STORAGE (type: "storage")

```lua
{ type = "storage", value = { 17524, 1 } }  -- storage_key, value
```

### REWARD_POINT (type: "point")

```lua
{ type = "point", value = { 100 } }  -- Fame points (POINTSSTORAGE)
```

### REWARD_ITEM (type: "item")

```lua
{ type = "item", value = { itemId, count } }  -- item reward
```

## 📊 Fluxo de Task

```
Player aceita task de NPC
  ↓
[Start Task] Storage = começado
  ↓
Player mata creature X kills vezes
  ↓
Kill counter storage incrementa
  ↓
[Complete] Counter ≥ killsRequired?
  ├─ NÃO: Continue matando
  └─ SIM: Task completada
      ↓
      Recompensas distribuídas:
      - EXP adicionada
      - Moeda adicionada
      - Achievements desbloqueadas
      - Storage marcado como feito

```
