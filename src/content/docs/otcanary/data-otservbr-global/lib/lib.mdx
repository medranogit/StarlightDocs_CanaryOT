## 🛠️ Informações do Arquivo

O arquivo **lib.lua** é o **arquivo loader/bootstrap principal** que centraliza o carregamento de todos os 5 subsistemas da pasta `lib/`.

<Card title="Caminho Original">
`data-otservbr-global/lib/lib.lua`
</Card>

<Aside type="tip">
**Tipo**: Master Bootstrap/Loader  
**Padrão**: Central dofile() hub  
**Total de Subsistemas**: 5  
**Propósito**: Entry point para todo sistema de biblioteca  
**Carregamento**: Sequencial (order importa)
</Aside>

## 📄 Visão Geral

Arquivo **mínimo no código** (~15 linhas) mas **máximo em importância** - carrega todos os 5 subsistemas principais:

```lua
-- Core API functions implemented in Lua
dofile(DATA_DIRECTORY .. "/lib/core/load.lua")

-- Others library
dofile(DATA_DIRECTORY .. "/lib/others/load.lua")

-- Quests library
dofile(DATA_DIRECTORY .. "/lib/quests/quest.lua")

-- Tables library
dofile(DATA_DIRECTORY .. "/lib/tables/load.lua")

-- Functions library
dofile(DATA_DIRECTORY .. "/lib/functions/load.lua")
```

## 🎯 Order of Loading (Importante!)

Ordem **é crítica** pois alguns subsistemas dependem de outros:

### ✅ Ordem Correta

```
1. core/load.lua primeiro
   └─ Define quest catalog base
   
2. others/load.lua (depends on players, quests)
   └─ Define Dawnport na área starter
   
3. quests/quest.lua (depends on core)
   └─ Carrega todos os quests específicos
   
4. tables/load.lua (independent)
   └─ Define constantes de cidades/items
   
5. functions/load.lua (depends on all)
   └─ Extend Player API
```

**Mudança de ordem pode causar**:
- Globals não definidos (nil error)
- Functions não encontradas
- Quest incompleteness

## ⚠️ Ordem de Execução (Crítica)

**NÃO MUDE** a ordem sem entender dependências:

```
✅ SEGURO:
1. core → others → quests → tables → functions

❌ PERIGOSO:
1. quests → core  (quests precisa de core)
1. functions → others  (functions precisa de tudo)
```

## 📌 Notas de Implementação

1. **Sem lógica**: Arquivo é **apenas loader**, sem processamento
2. **Sem erros**: Usa `dofile()` simples (sem try-catch)
3. **Global scope**: Todos os subsistemas carregados no global scope
4. **Sequential**: Ordem é determinística (não paralelo)
5. **Complete**: Após esse arquivo, **todo** o sistema está pronto
