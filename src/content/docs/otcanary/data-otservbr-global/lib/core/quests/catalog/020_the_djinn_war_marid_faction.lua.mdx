## 📄 Visão Geral do Código

### Resumo Executivo

"The Djinn War - Marid Faction" é um **sistema de alinhamento benevolente** na war djinn:

```
Lado: Marid (azul, amigável)
Mentor: King Gabel
↓
4 Missões:
  1. Dwarven Kitchen: Trazer cookbook
  2. Spyreport: Infiltrar Efreet, código PIEDPIPER
  3. Rata'Mari & Cheese: Trade quest lateral
  4. Sleeping Lamp: Trocar lâmpadas (vs Efreet)
↓
Resultado: Acesso a traders Marid (Haroun, Nah'bob)
```

## 7. Comparação: Marid vs Efreet Lamp Swap

```
EFREET (Evil):
  Steal Gabel's (Marid king) lamp
  Replace with neutral lamp
  = Sabotage

vs

MARID (Good):
  Steal Malor's (Efreet king) lamp  
  Replace with neutral lamp
  = Defensive protection

Same mechanic, opposite alignment!
```
