## 🛠️ Informações do Arquivo

Este arquivo define a **estrutura de dados** da quest "Outfit and Addon Quests", um **catálogo de quests de moda** onde players obtêm diferentes outfits e addons completando tarefas diversas.

</Aside>

## 📄 Visão Geral do Código

### Resumo Executivo

"Outfit and Addon Quests" é um **sistema modular de quest de cosmética**:

```
Objetivo: Coletar diferentes outfits e addons
↓
Tipos:
  1. Assassin Outfit (2 missions)
  2. Citizen Outfit (2 addons)
  3. Barbarian Outfit (17 states!)
  4. Beggar Outfit (8 states)
  5. Druid Outfit (10 states)
  6. Hunter Outfit (5 states)
  7. Knight Outfit (6 states)
  8. Mage/Summoner (2 separate missions)
  ... e mais
```

## 12. Tipo de Quest: Fashion-Cosmetic Catalog

- ✅ 11+ diferentes outfits
