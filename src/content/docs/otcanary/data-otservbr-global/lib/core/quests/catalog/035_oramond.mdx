## 🛠️ Informações do Arquivo

A quest **Oramond** é uma quest inusualmente breve com apenas **1 missão** que desvia do padrão tradicional. Em vez de usar um array de `states`, utiliza uma `description` em string simples, representando um padrão minimalista de implementação.

## 🔧 Estrutura do Código

### Variáveis Locais

| Nome | Tipo | Descrição |
|------|------|-----------|
| `quest` | table | Tabela principal minimalista |
| `name` | string | Nome da quest: "Oramond" |
| `missions` | table | Array com 1 única missão |
| `startStorageId` | string | ID de armazenamento |
| `startStorageValue` | number | 1 (início) |

### Estrutura de Dados - Padrão String

```lua
-- Padrão minimalista com description em string
[1] = {
  name = "To Take Roots",
  storageId = Storage.Quest.U10_50.OramondQuest,
  missionId = 10365,
  startValue = 0,
  endValue = 3000,  -- Valor alto (não é número de estados!)
  description = "Instrução em string plano, sem array de states"
}
```

**DIFERENÇA CRÍTICA**: Não há array `states` - apenas uma string única em `description`.

## 🎮 Inovação: String Description Pattern

Este padrão representa uma terceira abordagem ao rastreamento de progresso:

| Padrão | Uso | Exemplo |
|--------|-----|---------|
| **States Array** | Narrativa com múltiplos passos | Quest 033: 5-12 states |
| **Função Dinâmica** | Contador em tempo real | Quest 034: `function(player) ... end` |
| **String Description** | Instruções simples e lineares | Quest 035: descrição fixa |

### Vantagens do Padrão String

- Implementação minimal e clara
- Ideal para quests de coleta simples
- Sem overhead de múltiplos states
- Descrição única durante toda progressão

## 💾 Mapeamento de Storage

```lua
Storage.Quest.U10_50.OramondQuest = {

```

## 🌍 Significado do EndValue=3000

O `endValue = 3000` não representa número de states (não há states). Provavelmente:
- Marca especial de conclusão
- Valor de milestone ou recompensa
- Controle de limite de progresso

## 🎭 Narrativa de Caridade

A quest trata de satisfazer a fome de Oramond por raízes suculentas, representando um ato de caridade comunitária. É uma das quests mais diretas e simples do jogo.
