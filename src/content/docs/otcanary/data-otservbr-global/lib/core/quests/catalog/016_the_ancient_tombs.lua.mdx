## 📄 Visão Geral do Código

### Resumo Executivo

"The Ancient Tombs" é uma **quest de dungeon crawl**:

```
Estrutura: Série de 7 Tombs/Treasures antigos
Cada tomb tem:
  - Puzzle elements (levers, plaques)
  - Boss fight (guardian)
  - Helmet reward (Ornament, Holder, Horn, Piece)
  
Bosses:
  1. Omruc (2 states)
  2. Thalas (2 states, 8 levers)
  3. Diphtrah (3 states, 11 levers + plaques)
  4. Mahrdis (2 states)
  5. Vashresamun (3 states, musical puzzle)
  6. Morguthis (2 states, blue fireworks)
  7. Rahemos (2 states, levers)
```
