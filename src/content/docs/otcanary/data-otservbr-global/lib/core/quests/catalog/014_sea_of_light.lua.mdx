## 📄 Visão Geral do Código

### Resumo Executivo

"Sea of Light" é uma **quest de engenharia mágica**:

```
Contexto: Spectulus (astrônoma) quer reconstruir invenção antiga
↓
Problema: Blueprints históricos perdidos
↓
3 Missões:
  1. The Plans: Encontrar inventor secreto (beggar)
  2. The Collector: Obter cristal raro das Lost Mines
  3. The Mirror Crystal: Sacrificar + derrotar boss
↓
Resultado: Dispositivo é recriado (mas cai e quebra)
```

## 7. Elemento Narrativo: Sacrifice & Consequence

A quest tem tema de **sacrifice**:

1. **Beggar sacrifica planos** para player
2. **Player sacrifica cristal raro** no well
3. **Collector sacrifica** à defeat
4. **Finale**: Dispositivo falha mesmo assim!

Mensagem: Nem todo esforço leva a sucesso perfeito.
