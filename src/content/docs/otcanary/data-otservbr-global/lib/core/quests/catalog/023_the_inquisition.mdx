## 📄 Visão Geral do Código

**The Inquisition** é uma quest de investigação demoníaca onde o jogador trabalha para eliminar hereges, vampiros e demônios sob orientação do Demon Hunter Henricus.

### Resumo Executivo

- **Nome da Quest**: The Inquisition
- **Mentor**: Henricus (Demon Hunter)
- **Mecânica Principal**: Investigação com contadores, Boss fights, Coleta de essências
- **Reward Sistema**: Demon Hunter Outfit + Addons
- **Storage Namespace**: Storage.Quest.U8_2.TheInquisitionQuest.*
- **Missões**: 7
