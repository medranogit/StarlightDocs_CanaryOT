**Convenção**:
- Métodos implementados diretamente na tabela `Player`

## 💡 Funções Detalhadas

### 1. getCookiesDelivered()

**Propósito**: Contar quantos cookies foram entregues na Quest 033 (What a Foolish Quest).

**Assinatura**:
```lua
function Player.getCookiesDelivered(self) -> number
```

**Implementação**:
```lua
local storage, amount = {
  Storage.Quest.U8_1.WhatAFoolishQuest.CookieDelivery.SimonTheBeggar,
  Storage.Quest.U8_1.WhatAFoolishQuest.CookieDelivery.Markwin,
  Storage.Quest.U8_1.WhatAFoolishQuest.CookieDelivery.Ariella,
  -- ... (7 mais) ...
  Storage.Quest.U8_1.WhatAFoolishQuest.CookieDelivery.Hjaern,
}, 0

for i = 1, #storage do
  if self:getStorageValue(storage[i]) == 1 then
    amount = amount + 1
  end
end

return amount
```

**Lógica**:
1. Define array de 10 storage keys (NPCs para entrega)
2. Inicializa contador em 0
3. Itera sobre cada key
4. Se storage == 1, incrementa contador
5. Retorna total contado

**NPCs Rastreados** (10 total):
- Simon the Beggar
- King Markwin
- Ariella
- Hairycles
- Djinn
- Avar Tar
- Orc King
- Lorbas
- Wyda
- Hjaern

**Uso**:
```lua
local cookies = player:getCookiesDelivered()
print("Cookies delivered: " .. cookies .. "/10")
```

### 2. checkGnomeRank()

**Propósito**: Verificar rank de Gnomes (Bigfoot's Burden - Quest 005) e desbloquear achievements progressivos.

**Assinatura**:
```lua
function Player.checkGnomeRank(self) -> boolean
```

**Lógica de Rank**:

| Pontos | Range | QuestProgress | Achievements Desbloqueados |
|--------|-------|---------------|---------------------------|
| 0-29 | < 30 | - | Nenhum |
| 30-119 | 30-119 | → 26 | Gnome Little Helper |
| 120-479 | 120-479 | → 27 | + Gnome Friend |
| 480-1439 | 480-1439 | → 28 | + Gnomelike |
| 1440+ | ≥ 1440 | → 30 | + Honorary Gnome |

**Implementação**:

```lua
function Player.checkGnomeRank(self)
  local points = self:getStorageValue(Storage.Quest.U9_60.BigfootsBurden.Rank)
  local questProgress = self:getStorageValue(Storage.Quest.U9_60.BigfootsBurden.QuestLine)
  
  if points >= 30 and points < 120 then
    if questProgress <= 25 then
      self:setStorageValue(Storage.Quest.U9_60.BigfootsBurden.QuestLine, 26)
      self:getPosition():sendMagicEffect(CONST_ME_MAGIC_BLUE)
      self:addAchievement("Gnome Little Helper")
    end
  -- ... (mais elseif para outros ranges) ...
```

**Mechanics Especiais**:
1. Fetch pontos de `Rank` storage
2. Fetch progresso de `QuestLine` storage
3. Se pontos estão em novo range E questProgress não foi atualizado:
   - Update QuestLine para novo nível
   - Enviar efeito mágico (CONST_ME_MAGIC_BLUE)
   - Unlock achievements cumulativos
4. Retorna true

**Effects**:
- `CONST_ME_MAGIC_BLUE`: Efeito visual azul mágico
- `self:addAchievement()`: Unlock achievement

**Achievements Progressivos**:
Acumulam - ao atingir tier 4, obtém todas 4 achievements.

**Uso**:
```lua
player:checkGnomeRank()  -- Verifica automaticamente ao completar tarefas
```

### 3. addFamePoint()

**Propósito**: Adicionar 1 ponto de fama (Spike Task - Quest 003).

**Assinatura**:
```lua
function Player.addFamePoint(self) -> void
```

**Implementação**:
```lua
function Player.addFamePoint(self)
  local points = self:getStorageValue(Storage.Quest.U10_20.SpikeTaskQuest.Constants.Spike_Fame_Points)
  local current = math.max(0, points)
  self:setStorageValue(Storage.Quest.U10_20.SpikeTaskQuest.Constants.Spike_Fame_Points, current + 1)
  self:sendTextMessage(MESSAGE_EVENT_ADVANCE, "You have received a fame point.")
end
```

**Lógica**:
1. Fetch pontos atuais (ou 0 se nil)
2. Usar `math.max(0, points)` para garantir não-negativo
3. Incrementar por 1
4. Set novo valor no storage
5. Enviar mensagem de sucesso

**Message Type**: `MESSAGE_EVENT_ADVANCE` (amarelo, sistema)

**Uso**:
```lua
player:addFamePoint()  -- +1 fama
```

### 4. getFamePoints()

**Propósito**: Retornar total de pontos de fama atual.

**Assinatura**:
```lua
function Player.getFamePoints(self) -> number
```

**Implementação**:
```lua
function Player.getFamePoints(self)
  local points = self:getStorageValue(Storage.Quest.U10_20.SpikeTaskQuest.Constants.Spike_Fame_Points)
  return math.max(0, points)
end
```

**Lógica**:
1. Fetch valor storage
2. Retornar máximo entre 0 e value (nunca negativo)

**Uso**:
```lua
local fame = player:getFamePoints()
if fame >= 100 then
  -- Unlock reward
end
```

### 5. removeFamePoints(amount)

**Propósito**: Remover X pontos de fama.

**Assinatura**:
```lua
function Player.removeFamePoints(self, amount: number) -> void
```

**Implementação**:
```lua
function Player.removeFamePoints(self, amount)
  local points = self:getStorageValue(Storage.Quest.U10_20.SpikeTaskQuest.Constants.Spike_Fame_Points)
  local current = math.max(0, points)
  self:setStorageValue(Storage.Quest.U10_20.SpikeTaskQuest.Constants.Spike_Fame_Points, current - amount)
end
```

**Lógica**:
1. Fetch pontos atuais (mínimo 0)
2. Subtrair amount
3. Set novo valor (pode ficar negativo!)

**⚠️ Aviso**: Diferente de `addFamePoint()`, este método não garante não-negatividade no armazenamento. Poderia resultar em valores negativos se amount > current.

**Sugestão de Fix**:
```lua
self:setStorageValue(..., math.max(0, current - amount))
```

**Uso**:
```lua
player:removeFamePoints(10)  -- -10 fama
```

```lua

  player:removeFamePoints(50)
  -- Grant reward
end
```

## ⚠️ Problemas Identificados

1. **removeFamePoints() pode causar storage negativo**: Deveria usar `math.max(0, current - amount)`
2. **Sem validação de param**: `removeFamePoints(amount)` não valida se amount >= 0
