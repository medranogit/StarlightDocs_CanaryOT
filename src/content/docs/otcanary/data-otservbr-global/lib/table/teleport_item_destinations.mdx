## 🛠️ Informações do Arquivo

O arquivo **teleport_item_destinations.lua** define uma **tabela global de mapeamento** que associa item IDs de teleporte a suas posições de destino e efeitos visuais.

<Card title="Caminho Original">
`data-otservbr-global/lib/tables/teleport_item_destinations.lua`
</Card>

<Aside type="note">
**Tipo**: Item Configuration Table  
**Total de Teleports**: 4 items  
**Padrão**: Item ID → `{destination Position, effect}`  
**Propósito**: Central teleport destination registry
</Aside>

## 📄 Visão Geral

Arquivo que define **4 teleport items**:

```lua
ItemTeleports = {
  [5629] = { destination = Position(33145, 32863, 7), effect = CONST_ME_MAGIC_GREEN },

  [50241] = { destination = Position(32066, 32192, 7), effect = CONST_ME_MAGIC_BLUE },
}
```

## 🎯 Padrão de Uso

### Em Script de Item

```lua
-- Quando jogador usa item teleport:
local teleport = ItemTeleports[item:getId()]
if teleport then
  player:teleportTo(teleport.destination)
  teleport.destination:sendMagicEffect(teleport.effect)
end
```

### Verificar se é Teleport

```lua
if ItemTeleports[itemId] then
  -- É um teleport válido
end
```

## 🔗 Efeitos Utilizados

| Efeito | Descrição |
|--------|-----------|
| `CONST_ME_MAGIC_GREEN` | Efeito verde (teleport normal) |
| `CONST_ME_MAGIC_BLUE` | Efeito azul (teleport Rookgaard) |

## ⚠️ Notas Técnicas

1. **Item IDs baixos**: 5629-5630 são items padrões tibia
2. **Item IDs altos**: 50240-50241 parecem customizados (custom server items)
3. **Sem validação**: Arquivo apenas define, não valida
4. **Efeito opcional**: Campo `effect` poderia ser omitido
5. **Position fixo**: Destinos são hardcoded (não dinâmico)
