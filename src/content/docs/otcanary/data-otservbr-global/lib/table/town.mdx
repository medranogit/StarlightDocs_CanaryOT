## 🛠️ Informações do Arquivo

O arquivo **town.lua** define a **lista global de cidades (TOWNS_LIST)** com IDs únicos para todas as regiões do mundo do servidor Canary.

<Card title="Caminho Original">
`data-otservbr-global/lib/tables/town.lua`
</Card>

<Aside type="tip">
**Tipo**: Configuration Constants  
**Total de Cidades**: 26 cidades + 1 vale especial = 27 total  
**Range de IDs**: 1-26 + 33 (BLUE_VALLEY)  
**Padrão**: Named Constants (TOWNS_LIST)  
**Propósito**: Central city registry para NPCs, spawns, etc
</Aside>

## 📄 Visão Geral

Arquivo que define **27 cidades constantes** numeradas:

```lua
TOWNS_LIST = {
  DAWNPORT_TUTORIAL = 1,      -- Tutorial inicial
  DAWNPORT = 2,               -- Starter city
  ROOKGAARD = 3,              -- Free-to-play starter
  -- ... (23 mais cidades) ...
  BLUE_VALLEY = 33,           -- Vale especial
}
```

## 🎯 Padrão de Uso

### Verificar Cidade do Player

```lua
local playerTown = player:getTown()
if playerTown and playerTown:getId() == TOWNS_LIST.DAWNPORT then
  -- Player está em Dawnport
end
```

### Usar Constante em Script

```lua
-- Em lib/core/quests/catalog/051_the_way_of_the_monk.lua:
if player:getTown():getId() == TOWNS_LIST.BLUE_VALLEY then
  -- Shrine em Blue Valley
end
```

### Iterar Todas Cidades

```lua
for townName, townId in pairs(TOWNS_LIST) do
  print(townName .. " = " .. townId)
end
```

## ⚠️ Notas Técnicas

1. **ID 33 para Blue Valley**: Não sequencial! IDs 27-32 parecem não existir
2. **Sem estrutura adicional**: Apenas keys-values simples
3. **Referenciado globalmente**: Usado por NPCs, spawns, quests, teleports
4. **Imutável em runtime**: Não deve ser modificado
5. **Sem validação**: Arquivo apenas define, não valida
