## 🛠️ Informações do Arquivo

O arquivo **dawnport.lua** implementa o sistema de **área inicial (Dawnport)** com funcionalidades de troca de vocação, limites de progressão de skills, e remoção de contraband items.

</Aside>

## 📄 Visão Geral

Dawnport é a área inicial onde:
1. Players escolhem/trocam vocação (com conversão de skills)
2. Skill growth é **limitado** (cap em magic level/skills)
3. Items de contrabando do mainland são removidos

## 🔧 Configuração

### Skill Limits por Vocação

```lua
Dawnport = {
  skillsLimit = {
    [VOCATION.ID.NONE] = {},  -- Sem vocação: sem limites
    [VOCATION.ID.SORCERER] = {
      [SKILL_MAGLEVEL] = 20,  -- Max magic level 20
    },
    [VOCATION.ID.DRUID] = {
      [SKILL_MAGLEVEL] = 20,  -- Max magic level 20
    },
    [VOCATION.ID.PALADIN] = {
      [SKILL_MAGLEVEL] = 9,   -- Max magic level 9
    },
    [VOCATION.ID.KNIGHT] = {
      [SKILL_MAGLEVEL] = 4,   -- Max magic level 4
    },
  },
}
```

**Padrão**: Casters (Sorcerer/Druid) podem atingir magic 20, Paladins 9, Knights 4.

## 💡 Funções

### 1. Player.changeVocation(newVocationId)

**Propósito**: Trocar vocação com conversão automática de skills e stats.

#### Lógica de Conversão

```lua
function Player.changeVocation(self, newVocationId)
  -- 1. Validação
  if self:getVocation():getId() == newVocationId then
    return false  -- Já tem essa vocação
  end

  -- 2. Salvar magic level atual
  local magic = {
    level = self:getBaseMagicLevel(),
    manaSpent = self:getManaSpent()
  }
  -- Somar mana spent de todos os níveis
  for level = 1, magic.level do
    magic.manaSpent = magic.manaSpent + 
      self:getVocation():getRequiredManaSpent(level)
  end

  -- 3. Salvar todos os 6 skills
  local skills = {
    { id = SKILL_FIST },
    { id = SKILL_CLUB },
    { id = SKILL_SWORD },
    { id = SKILL_AXE },
    { id = SKILL_DISTANCE },
    { id = SKILL_SHIELD },
  }
  for i = 1, #skills do
    skills[i].level = self:getSkillLevel(skills[i].id)
    skills[i].tries = self:getSkillTries(skills[i].id)
    -- Somar tries de todos os níveis
    for level = 11, skills[i].level do
      skills[i].tries = skills[i].tries + 
        self:getVocation():getRequiredSkillTries(skills[i].id, level)
    end
  end

  -- 4. Mudar vocação
  self:setVocation(newVocationId)

  -- 5. Converter magic level
  local newMagicLevel = 0
  if magic.manaSpent > 0 then
    local reqManaSpent = self:getVocation():getRequiredManaSpent(newMagicLevel + 1)
    while magic.manaSpent >= reqManaSpent do
      magic.manaSpent = magic.manaSpent - reqManaSpent
      newMagicLevel = newMagicLevel + 1
      reqManaSpent = self:getVocation():getRequiredManaSpent(newMagicLevel + 1)
    end
  end
  
  -- Fazer set se alcançou novo level
  if newMagicLevel > 0 then
    self:setMagicLevel(newMagicLevel, magic.manaSpent)
  elseif magic.manaSpent > 0 then
    self:addManaSpent(magic.manaSpent, true)
  end

  -- 6. Converter todos os 6 skills
  for i = 1, #skills do
    local newSkillLevel = 10  -- Sempre começa em 10
    if skills[i].tries > 0 then
      local reqSkillTries = self:getVocation():getRequiredSkillTries(
        skills[i].id, (newSkillLevel + 1)
      )
      while skills[i].tries >= reqSkillTries do
        skills[i].tries = skills[i].tries - reqSkillTries
        newSkillLevel = newSkillLevel + 1
        reqSkillTries = self:getVocation():getRequiredSkillTries(
          skills[i].id, (newSkillLevel + 1)
        )
      end
    end
    
    if newSkillLevel > 10 then
      self:setSkillLevel(skills[i].id, newSkillLevel, skills[i].tries)
    elseif skills[i].tries > 0 then
      self:addSkillTries(skills[i].id, skills[i].tries, true)
    end
  end

  -- 7. Recalcular HP, Mana, Capacity (se level > 8)
  if self:getLevel() > 8 then
    local stats = { health = 150, mana = 55, capacity = 40000 }
    if self:getVocation():getId() == VOCATION.ID.NONE then
      -- Sem vocação
      local level = self:getLevel() - 1
      stats.health = stats.health + 
        (level * self:getVocation():getHealthGain())
      stats.mana = stats.mana + 
        (level * self:getVocation():getManaGain())
      stats.capacity = stats.capacity + 
        (level * self:getVocation():getCapacityGain())
    else
      -- Com vocação (Levels 8+)
      local baseLevel = 7
      local baseVocation = Vocation(VOCATION.ID.NONE)
      local level = self:getLevel() - 8
      stats.health = stats.health + 
        (baseLevel * baseVocation:getHealthGain()) + 
        (level * self:getVocation():getHealthGain())
      stats.mana = stats.mana + 
        (baseLevel * baseVocation:getManaGain()) + 
        (level * self:getVocation():getManaGain())
      stats.capacity = stats.capacity + 
        (baseLevel * baseVocation:getCapacityGain()) + 
        (level * self:getVocation():getCapacityGain())
    end
    self:setMaxHealth(stats.health)
    self:addHealth(stats.health)
    self:setMaxMana(stats.mana)
    self:addMana(stats.mana)
    self:setCapacity(stats.capacity)
  end

  return true
end
```

**Fluxo**:
1. Valida se é vocação diferente
2. Salva magic level + mana spent total
3. Salva 6 skills + tries total
4. Muda pra nova vocação
5. Recalcula magic level na nova vocação (proporcional)
6. Recalcula 6 skills na nova vocação (proporcional)
7. Re-calcula stats (HP, Mana, Capacity)

**Exemplo**:
```lua
-- Sorcerer level 20 magic → trocar pra Paladin
-- Resultado: paladin com magic level ~5-6 (proporcional)
-- Todos skills também convertidos proporcionalmente
```

### 2. isSkillGrowthLimited(player, skillId)

**Propósito**: Verificar se player em Dawnport atingiu limite de skill.

```lua
function isSkillGrowthLimited(player, skillId)
  local town = player:getTown()
  
  -- Check que reside em Dawnport
  if town and town:getId() == TOWNS_LIST.DAWNPORT then
    local vocationId = player:getVocation():getId()
    local skillsLimit = Dawnport.skillsLimit[vocationId]
    
    -- Check se há limit pra esse skillId
    if skillsLimit and skillsLimit[skillId] then
      -- Pegar nível atual
      local skillLevel
      if skillId == SKILL_MAGLEVEL then
        skillLevel = player:getBaseMagicLevel()
      else
        skillLevel = player:getSkillLevel(skillId)
      end
      
      -- Verificar limit
      if skillLevel >= skillsLimit[skillId] then
        return true  -- LIMITADO
      end
    end
  end
  
  return false  -- NÃO LIMITADO
end
```

**Uso**:
```lua
-- Em onAdvance ou onGainSkillTries:
if isSkillGrowthLimited(player, SKILL_MAGLEVEL) then
  player:sendTextMessage(MESSAGE_STATUS, 
    "Magic level capped at 20 in Dawnport")
  return false  -- Não permite avanço
end
```

### 3. removeMainlandSmugglingItems(player)

**Propósito**: Remover items contrabandeados quando player deixa Dawnport.

```lua
function removeMainlandSmugglingItems(player)
  local smugglingItemIds = {
    3355,    -- Leather helmet
    3562,    -- Coat
    3559,    -- Leather legs
    3552,    -- Leather boots
    21348,   -- The scorcher (staff)
    21350,   -- The chiller (staff)
    21400,   -- Spellbook of the novice
    3350,    -- Bow
    3267,    -- Dagger
    3412,    -- Wooden shield
    35562,   -- Quiver
    21470,   -- Simple arrow
    266,     -- Health potion
    268,     -- Mana potion
    7876,    -- Small health potion
    21352,   -- Lightest missile rune
    21351,   -- Light stone shower rune
    50166,   -- Light Jo Staff
  }
  
  for i = 1, #smugglingItemIds do
    local amount = player:getItemCount(smugglingItemIds[i])
    if amount > 0 then
      player:removeItem(smugglingItemIds[i], amount)
    end
  end
end
```

**18 Items Removidos**:
- Armadura (4): helmet, coat, legs, boots
- Weapons (4): 2 staffs, bow, dagger
- Off-hand (2): shield, quiver
- Ammunition (2): arrows, runes
- Potions (3): health, mana, small health
- Spellbook (1)
- Equipment (1): Jo Staff

**Uso**:
```lua
-- Ao sair de Dawnport:
removeMainlandSmugglingItems(player)
```

**Nota**: Apenas magic level é limitado. Outros skills (fist, club, etc) podem crescer freely.

## 🎯 Padrão de Conversão de Skill

**Mecânica**: Proporcional baseado em "tries" (custo acumulado)

```
Skill Level 10: 0 tries
Skill Level 11: 10 tries (vocação específico)
Skill Level 12: 20 tries + 30 tries vocação = 50 tries total
...

Se trocar vocação:
  Old vocação: 100 tries = level 15
  New vocação: 100 tries = level 12 (se requer mais tries)
```

## ⚠️ Notas Técnicas

1. **Base stats L1**: health=150, mana=55, capacity=40000
2. **Level 8 threshold**: Recalcula stats completamente
3. **Conversão linear**: Proporcional baseado em tries acumulado
4. **Magic level sempre começa em 0**: Quando muda vocação
