## 🛠️ Informações do Arquivo

O arquivo **soulpit.lua** implementa a **quest Soul Pit** - um sistema de coleta de soul cores com battles progressivas, abilities de boss e fusão de items.

**Waves**: 4 progressivas  
**Boss Abilities**: 3 únicas  
**Soul Cores**: 10 variações  
**Padrão**: Global Config Table + Functions
</Aside>

## 📄 Visão Geral

Soul Pit é uma **quest de coleta e combate** onde:
1. Players entram em arena (5 posições simultâneas)
2. 4 waves progressivas de monstros spawn
3. Bosses têm abilities especiais (critical, enrage, spells)
4. Soul cores dropam (progressão)
5. Fusão de soul cores para melhorar raridade

### Ability 2: enrageSoulPit

```lua
enrageSoulPit = {
  bounds = {
    [{ 0.8, 0.6 }] = 0.9,   -- 80-60% health: -10% damage
    [{ 0.6, 0.4 }] = 0.75,  -- 60-40% health: -25% damage
    [{ 0.4, 0.2 }] = 0.6,   -- 40-20% health: -40% damage
    [{ 0.0, 0.2 }] = 0.4,   -- 20-0% health: -60% damage
  },
  apply = function(monster)
    monster:registerEvent("enrageSoulPit")
  end,
}
```

**Efeito**: Boss fica **mais forte** conforme fica com pouca vida:
- 20% HP → 60% damage reduction (muito difícil!)
- Mechanic "enrage": fica furioso quando perto de morrer

### Ability 3: opressorSoulPit

```lua
opressorSoulPit = {
  spells = {
    { name = "soulpit opressor", 
      interval = 2000, chance = 25, 
      minDamage = 0, maxDamage = 0 },
    { name = "soulpit powerless", 
      interval = 2000, chance = 30, 
      minDamage = 0, maxDamage = 0 },
    { name = "soulpit intensehex", 
      interval = 2000, chance = 15, 
      minDamage = 0, maxDamage = 0 },
  },
  apply = function(monster)
    for _, spell in pairs(SoulPit.bossAbilities.opressorSoulPit.spells) do
      monster:addAttackSpell(readSpell(spell, monster:getType()))
    end
    return true
  end,
}
```

**Efeito**: Boss lança 3 spells custom progressivamente:
1. "Opressor" (25% chance, 2 seg interval)
2. "Powerless" (30% chance) - provavelmente weakness
3. "Intense Hex" (15% chance) - provavelmente curse/debuff

## 🔄 Utility Functions

### getMonsterVariationNameBySoulCore(searchName)

```lua
function getMonsterVariationNameBySoulCore(searchName)
  for mTypeName, soulCoreName in pairs(
    SoulPit.SoulCoresConfiguration.monsterVariationsSoulCore
  ) do
    if soulCoreName == searchName then
      return mTypeName  -- Retorna creature name
    end
  end
  return nil
end
```

**Uso**: Reverse lookup - dado soul core name, retorna creature original.

### getSoulCoreMonster(name)

```lua
function getSoulCoreMonster(name)
  return name:match("^(.-) soul core")
end
```

**Uso**: Extract creature type from core item name.
- Input: `"horse soul core (brown)"`
- Output: `"horse"`

### onFuseSoulCores(player, item, target)

```lua
function onFuseSoulCores(player, item, target)
  -- 1. Validar quantity >= 2
  local itemCount = item:getCount(item:getId())
  if item:getId() == target:getId() and itemCount <= 1 then
    return false
  end

  -- 2. Extract monster types
  local itemSoulCore = SoulPit.getSoulCoreMonster(item:getName())
  local targetSoulCore = SoulPit.getSoulCoreMonster(target:getName())
  if not itemSoulCore or not targetSoulCore then
    return false
  end

  -- 3. Combinar cores → random resultado
  local randomSoulCore = 
    SoulPit.soulCores[math.random(#SoulPit.soulCores)]
  
  -- 4. Dar item ao player
  player:addItem(randomSoulCore:getId(), 1)
  player:getPosition():sendMagicEffect(CONST_ME_MAGIC_BLUE)
  player:sendTextMessage(MESSAGE_EVENT_ADVANCE, 
    string.format("You have received a %s soul core.", 
      randomSoulCore:getName()))

  -- 5. Remover usados
  item:remove(1)
  target:remove(1)
  
  return true
end
```

**Mechanic**: Fusão de soul cores:
1. Precisa 2+ cores (pode ser do mesmo tipo)
2. Random resultado (pode upgrade raro)
3. Efeito visual + mensagem

**Exemplo**:
```
Funde: horse brown + horse taupe
Result: Random core (qualquer tipo)
```
