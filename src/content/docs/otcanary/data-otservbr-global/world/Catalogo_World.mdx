## 📄 Arquivos de Base

<Card title="Configurações Principais do World (4 arquivos)" icon="cog">

Localizados na raiz: `data-otservbr-global/world/`

### 1️⃣ otservbr-house.xml

| Propriedade | Valor |
|---|---|
| **Localização** | `world/otservbr-house.xml` |
| **Tipo** | XML - Configuração |
| **Função** | Definir casas jogáveis (aluguel, bandeiras, portas) |
| **Conteúdo** | ~100+ casas em várias cidades |
| **Escopo** | Gerenciamento imobiliário do servidor |
| **Modificação** | Adicionar/remover casas, ajustar aluguéis |

**Estrutura:**
```xml
<house id="ID" name="Nome" town="TOWN_ID" entry="x,y,z" rent="GOLD">
    <door id="1" x="..." y="..." z="..." />
</house>
```

---

### 2️⃣ otservbr-monster.xml

| Propriedade | Valor |
|---|---|
| **Localização** | `world/otservbr-monster.xml` |
| **Tipo** | XML - Configuração |
| **Função** | Definir spawns padrão de monstros |
| **Conteúdo** | 50+spawnpoints com diversos tipos |
| **Escopo** | Distribuição de monstros no mundo |
| **Modificação** | Adicionar spawns, balancear dificuldade |

**Estrutura:**
```xml
<spawn type="monster" x="32000" y="31000" z="7">
    <monstertype name="Dragon" />
</spawn>
```

---

### 3️⃣ otservbr-npc.xml

| Propriedade | Valor |
|---|---|
| **Localização** | `world/otservbr-npc.xml` |
| **Tipo** | XML - Configuração |
| **Função** | Definir posições e tipos de NPCs |
| **Conteúdo** | 100+ NPCs (vendedores, quest givers, etc) |
| **Escopo** | Distribuição de NPCs no mundo |
| **Modificação** | Adicionar NPCs, mudar scripts |

**Estrutura:**
```xml
<npc id="ID" name="Nome" script="script_name.lua">
    <position x="32000" y="31000" z="7" />
</npc>
```

---

### 4️⃣ otservbr-zones.xml

| Propriedade | Valor |
|---|---|
| **Localização** | `world/otservbr-zones.xml` |
| **Tipo** | XML - Configuração |
| **Função** | Definir zonas (áreas com propriedades) |
| **Conteúdo** | 20+ zonas (Thais, Carlin, etc) |
| **Escopo** | Controlar regras regionais |
| **Modificação** | Adicionar zonas, ajustar PvP |

**Estrutura:**
```xml
<zone name="Thais" type="normal">
    <rect x1="32000" y1="31000" x2="32100" y2="31100" z="7" />
</zone>
```

## 🎨 Customizações do Servidor

<Card title="Arquivo e Variantes Customizados (5 arquivos)" icon="palette">

Localizados em: `data-otservbr-global/world/custom/`

Estes arquivos contêm **customizações e extensões** do servidor além dos configs base.

| # | Arquivo | Tipo | Função |
|---|---------|------|--------|
| 1 | `otservbr-custom-house.xml` | XML | Casas customizadas adicionais |
| 2 | `otservbr-custom-monster.xml` | XML | Spawns customizados adicionais |
| 3 | `otservbr-custom-npc.xml` | XML | NPCs customizados adicionais |
| 4 | `otservbr-custom-zones.xml` | XML | Zonas customizadas adicionais |
| 5 | `otservbr-custom.otbm` | OTBM | Mapa/áreas customizadas |

**Padrão**: Mantém separação entre **base** e **custom** para fácil porting.

---

### Custom XML Files (4)

Cada arquivo custom espelha a estrutura de seu equivalente base:

```xml
<!-- otservbr-custom-house.xml -->
<house id="NEXT_ID" name="Custom House" town="3" entry="..." rent="..." />

<!-- otservbr-custom-monster.xml -->
<spawn type="monster" x="..." y="..." z="...">
    <monstertype name="Custom Monster" />
</spawn>

<!-- otservbr-custom-npc.xml -->
<npc id="NEXT_ID" name="Custom NPC" script="custom_npc.lua">
    <position x="..." y="..." z="..." />
</npc>

<!-- otservbr-custom-zones.xml -->
<zone name="Custom Zone" type="pvp">
    <rect x1="..." y1="..." x2="..." y2="..." z="7" />
</zone>
```

---

### Custom OTBM File

| Propriedade | Valor |
|---|---|
| **Nome** | `otservbr-custom.otbm` |
| **Tipo** | Mapa Binário (OTBM) |
| **Função** | Extensão de mapa para customizações |
| **Uso** | Áreas customizadas, ilhas, dungeons |
| **Integração** | Carregado junto com base world |

</Card>
