# 🌍 Arquitetura - World

Guia completo sobre a arquitetura e estrutura técnica dos arquivos de **World** do servidor OTServ Canary. Entenda como o mundo é organizado, configurado e expandido com eventos anuais, quests imersivas e mudanças dinâmicas.

---

## 🎯 Sobre essa Pasta de World

<Card title="O que é?" icon="information">
A pasta `data-otservbr-global/world/` contém todos os arquivos que definem **configurações do mundo do servidor**, incluindo:
- **Mapas OTBM** - Arquivos binários que contêm o layout físico do mundo
- **Configurações XML** - Casas, NPCs, Monstros e Zonas
- **Eventos Anuais** - World changes sazonais (Winterlight Solstice, etc.)
- **Quests Imersivas** - Áreas de quest específicas com mapas e NPCs
- **World Changes Dinâmicos** - Eventos que alteram o mundo em datas específicas (Full Moon, Fury Gates, etc.)

O world é o **coração do servidor** - define onde os jogadores podem estar, como o mapa parece, quais eventos ocorrem e como o mundo muda ao longo do tempo.
</Card>

<Card title="Casos de Uso" icon="target">
Você utilizará essa pasta quando precisar:

- **Adicionar novo mapa/área**: Criar islandas, cavernas, boss arenas
- **Modificar casas**: Adicionar/remover casas jogáveis, ajustar preços
- **Configurar NPCs**: Definir posições, diálogos, função (vendedor, quest giver, etc.)
- **Ajustar monstros**: Adicionar novos monstros ao mundo, modificar spawns
- **Criar zonas de PvP**: Definir áreas onde PvP é permitido/bloqueado
- **Implementar eventos sazonais**: Winterlight, Orcsoberfest, etc.
- **Adicionar world changes**: Full Moon, Nightmare Isle, eventos periódicos
- **Criar novas quests**: Soul War, Ferumbras, The Percht Queen, etc.
- **World expansion**: Adicionar continentes, cidades, dungeons
</Card>

## 🔍 Estrutura Geral

<Card title="Camadas do World System" icon="layers">

O world é construído em **camadas hierárquicas**:

### Camada 1: Mapa Base (OTBM)

```
OTBM (Tibia Map Binary File)
├── Layout físico dos tiles
├── Estruturas (paredes, pisos, objetos)
├── Spawn points
└── Waypoints/Portals
```

**Responsabilidade**: Definir onde o players podem andar e o que veem visualmente.

### Camada 2: Configuração Estática (XML)

```
XML Configuration Files
├── Houses (otservbr-house.xml)       - Casas jogáveis
├── Monsters (otservbr-monster.xml)   - Spawns de monstros
├── NPCs (otservbr-npc.xml)           - Posições/tipos de NPCs
└── Zones (otservbr-zones.xml)        - Definições de zonas
```

**Responsabilidade**: Definir o que existe no mundo (NPCs, monstros, casas).

### Camada 3: Eventos Sazonais (Annual Events)

```
Annual Events
├── Winterlight Solstice (Dezembro)
└── [Outras celebrações sazonais]
```

**Responsabilidade**: Adicionar conteúdo temporário durante períodos específicos.

### Camada 4: Quests Imersivas (Quest Areas)

```
Quest Areas (Integrated into World)
├── Cults of Tibia
├── Ferumbras Ascendant
├── Soul War
└── The Dream Courts
```

**Responsabilidade**: Fornecer mapas e ambientes para quests complexas.

### Camada 5: Mudanças Dinâmicas (World Changes)

```
World Changes (Dynamic Events)
├── Full Moon (Boss Arena Muda)
├── Fury Gates (Novos NPC/Itens)
├── Nightmare Isle (Área Especial)
└── Oriental Trader (Trader Especial)
```

**Responsabilidade**: Alterar o mundo em datas/períodos específicos.

## 📄 Arquivos de Base do World

<Card title="Configurações XML Principais" icon="document">

### 1. otservbr-house.xml

```xml
<!-- Define casas jogáveis no mundo -->
<house id="1" name="House Name" town="3" entry="32000,31000,7">
    <door id="1" x="32001" y="31000" z="7" />
</house>
```

**Conteúdo:**
- ID único de cada casa
- Nome visível para jogadores
- Cidade associada (town ID)
- Ponto de entrada (entry)
- Posições de portas

**Uso**: Gerenciar propriedades imobiliárias, aluguéis, decorações pessoais.

### 2. otservbr-monster.xml

```xml
<!-- Define spawns de monstros no mundo -->
<spawn type="monster" x="32000" y="31000" z="7">
    <monstertype name="Demon" />
    <monstertype name="Dragon Lord" />
</spawn>
```

**Conteúdo:**
- Posição de spawn
- Tipo(s) de monstros
- Quantidade/frequência (implicado pelo tipo)

**Uso**: Definir áreas de encontro, dificuldade regional, balanceamento de monstros.

### 3. otservbr-npc.xml

```xml
<!-- Define posições e tipos de NPCs -->
<npc id="1" name="NPC Name" script="script_name.lua">
    <position x="32000" y="31000" z="7" />
</npc>
```

**Conteúdo:**
- ID único do NPC
- Nome visível
- Script Lua associado
- Posição no mundo

**Uso**: Fornecer NPCs para vendas, quests, informações.

### 4. otservbr-zones.xml

```xml
<!-- Define zonas (áreas com propriedades comuns) -->
<zone name="Thais" type="normal">
    <rect x1="32000" y1="31000" x2="32100" y2="31100" z="7" />
</zone>
```

**Conteúdo:**
- Nome/tipo de zona
- Retângulo de área (coordenadas)
- Propriedades (PvP, agressão permitida, etc.)

**Uso**: Controlar regras regionais, restrições de PvP, ações de comando.

</Card>

## 💻 Formato XML

<Tabs>
<TabItem label="Estrutura Básica">

### Elementos Principais

```xml
<!-- Raiz do documento -->
<config>
    <!-- Definições individuais -->
    <house id="1" name="House Name" .../>
    <spawn type="monster" x="32000" y="31000" z="7" .../>
    <npc id="1" name="NPC Name" .../>
    <zone name="Thais" type="normal" .../>
</config>
```

### Atributos Comuns

```xml
<!-- Posição no mundo -->
<element x="32000" y="31000" z="7" />

<!-- Identificação -->
<element id="1" name="Name" type="Type" />

<!-- Referência a script/tipo -->
<element script="script_name.lua" monstertype="Dragon" />

<!-- Dados numéricos -->
<element rent="1000" townid="3" level="10" />
```

</TabItem>

<config>
    <house id="1"

           town="3"

           rent="5000"
           level="0">
        <door id="1" x="32001" y="31000" z="7" />
        <door id="2" x="32001" y="31001" z="7" />

<TabItem label="Validação">

### Verificações Importantes

```xml
<!-- ✅ Válido -->
<house id="1" name="House" town="3" entry="32000,31000,7" />

<!-- ❌ Inválido - ID duplicado -->
<house id="1" name="House1" ... />
<house id="1" name="House2" ... />  <!-- Erro: ID já existe -->

<!-- ❌ Inválido - Posição fora do mundo -->
<house id="3" entry="60000,60000,10" ... />  <!-- Fora dos limites -->

<!-- ❌ Inválido - Town ID não existe -->
<house id="4" town="999" ... />  <!-- Town 999 não existe -->
```

## 🗺️ Formato OTBM

<Card title="Arquivos de Mapa Binários" icon="map">

### O que é OTBM?

**OTBM** (Otland Tibia Binary Map) é um **formato binário** que armazena o mapa do Tibia.

```
.otbm (Binary)
├── Tile Data (Pixels do mapa)
│   └── Terreno, estruturas, objetos
├── Spawn Markers
│   └── Posições onde NPCs/monstros spawnnam
├── Waypoints
│   └── Pontos de referência ou teletransportes
└── Metadados
    └── Versão, tamanho, propriedades
```

### Criação e Edição

**Ferramentas:**
- **Tibia Map Editor** - Editor padrão para .otbm
- **Remere's Map Editor** - Editor visual moderno
- **OTLand Tools** - Ferramentas de exportação/conversão

**Fluxo Comum:**
```
1. Abrir arquivo .otbm em editor
2. Desenhar/modificar tiles
3. Adicionar spawns (se necessário)
4. Verificar erros
5. Salvar e testar no servidor
```

### Estrutura para Mapas de Quest/Event

```
Quest Map (ex: Soul War - Ebb and Flow)
├── Base Map (ebb-flow.otbm)
│   └── Mapa padrão da área
├── Variant A (ebb-flow-inundate.otbm)
│   └── Mapa com água (fase enchented)
└── Variant B (ebb-flow-empty.otbm)
    └── Mapa seco (fase dreno)
```

**Uso**: Permitir que o mundo mude dinamicamente durante eventos.

## 🎉 Eventos Anuais

<Card title="Annual Events System" icon="calendar">

### Estrutura

```
annual_events/
└── winterlight_solstice/
    ├── island.otbm              (Mapa da ilha)
    ├── island-monster.xml       (Monstros)
    ├── island-npc.xml           (NPCs)
    └── README.md
```

### Winterlight Solstice (Dezembro)

**O que é:**
- Evento anual de inverno
- Permite desafiar **The Percht Queen**
- Adiciona island temporária ao mundo

**Datas:**
- Dezembro (período específico)

**Mapa:**
- Local: Orcsoberfest Island (posição compartilhada)
- Coordenadas: 33768,31051,7
- Contém arena para boss fight

**NPCs/Monstros:**
- The Percht Queen (boss)
- Monstros temáticos de inverno

### Como Eventos Anuais Funcionam

```
1. Evento é configurado com datas no servidor
2. Em data específica, worldchange é ativado
3. Arquivo .otbm especial é carregado
4. Mapas alternativos substituem seções do mundo
5. NPCs/monstros especiais spawnam
6. Após período, volta ao normal
```

**Integração:**
- Eventos anuais usam o **mesmo sistema world_changes**
- Diferem apenas em periodicidade e temática

### Como World Changes Funcionam

```
Timeline:
1. Servidor inicia (carrega otbm padrão)
2. Script monitora data/hora
3. Em data específica, mundo é recarregado
4. Novo .otbm é carregado (substitui seção)
5. Novos NPCs/monstros spawnam
6. Após período, volta ao .otbm padrão

Exemplo (Full Moon):
├── Dias 1-11: Mapa normal (middle.otbm)
├── Dias 12-14: Boss arena (final.otbm)
└── Dias 15-30: Volta ao normal
```

## 🔧 Troubleshooting

<Card title="Problemas Comuns" icon="bug">

### Problema: Casa não aparece no mundo

**Causa**: ID duplicado ou posição fora do mapa  
**Solução:**
```xml
<!-- Verificar ID único -->
<house id="1" ... />  <!-- ✅ Único -->

<!-- Verificar posição válida -->
entry="32000,31000,7"  <!-- ✅ Dentro do mundo -->

<!-- Verificar town existe -->
town="3"  <!-- ✅ Town existe -->
```

---

### Problema: NPC não spawna

**Causa**: Script ausente ou posição inválida  
**Solução:**
```xml
<!-- Verificar script existe -->
script="trader.lua"  <!-- Arquivo deve estar em scripts/npcs/ -->

<!-- Verificar posição -->
<position x="32000" y="31000" z="7" />  <!-- Deve ser walkable -->
```

---

### Problema: Monstros não spawnam

**Causa**: Tipo inválido ou posição bloqueada  
**Solução:**
```xml
<!-- Verificar tipo existe -->
<monstertype name="Dragon" />  <!-- Deve estar em monsters/ -->

<!-- Verificar posição -->
<spawn type="monster" x="32000" y="31000" z="7">
    <!-- Coordenadas devem estar em área válida do mapa -->
</spawn>
```

---

### Problema: World Change não carrega

**Causa**: Arquivo OTBM não encontrado ou script desabilita  
**Solução:**
```lua
-- Verificar arquivo existe:
-- world_changes/evento/mapa.otbm

-- Verificar datas no script:
if os.date("%d") >= 12 and os.date("%d") <= 14 then
    -- Carregar Full Moon map
end
```

---

### Problema: Mapa corrompido

**Causa**: Arquivo OTBM danificado  
**Solução:**
```bash
# 1. Restaurar backup
cp world/mundo-original.otbm world/mundo.otbm

# 2. Validar com editor Remere's
# 3. Recriar em seção menor se necessário
```

</Card>
