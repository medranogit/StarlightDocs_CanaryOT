## 📄 Visão Geral Resumida

Implementa comando administrativo simples `/forceperiod` que permite ao god forçar globalmente um período específico (dia/noite) ou restaurar comportamento automático. Modifica variável global `forcePeriod` utilizada por sistema de sons e outros sistemas dependentes de período.

## 🔧 Estrutura de Funcionalidades

### Variáveis Globais

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `forcePeriod` | boolean\|string | Armazena período forçado: false (auto), "day" (forçado dia), "night" (forçado noite) |

### Funções Globais

**`forcePeriodCommand.onSay(player, words, param)`**
- **Parâmetros**: 
  - `player`: Jogador que executou comando
  - `words`: String do comando (`/forceperiod`)
  - `param`: Parametro fornecido (day|night|auto)
- **Retorno**: `true` (sempre)
- **Acesso**: god
- **Lógica Detalhada**:
  1. Converte param para minúsculas e remove espaços
  2. Se param vazio: envia mensagem de uso
  3. Se param == "day" ou "night": 
     - Atribui `forcePeriod = param`
     - Envia mensagem de confirmação
  4. Se param == "auto":
     - Atribui `forcePeriod = false`
     - Restaura comportamento automático
  5. Caso contrário: envia mensagem de erro

### Pseudocódigo Detalhado

```lua
function onSay(player, words, param)
  logCommand(player, words, param)
  param = param:lower():trimSpace()
  
  if param == "" então
    envia "Usage: /forceperiod day|night|auto"
    retorna true
  end
  
  if param == "day" ou param == "night" então
    forcePeriod = param
    envia "Forcing period: " .. param
    retorna true
  end
  
  if param == "auto" então
    forcePeriod = false
    envia "Automatic period restored."
    retorna true
  end
  
  envia "Usage: /forceperiod day|night|auto"
  retorna true
end
```

## 📊 Dados Técnicos

### Parâmetros Aceitos

| Parâmetro | Efeito | Mensagem |
|-----------|--------|----------|
| `day` | Força período diurno | "Forcing period: day" |
| `night` | Força período noturno | "Forcing period: night" |
| `auto` | Restaura automático | "Automatic period restored." |
| (vazio) | Erro | "Usage: /forceperiod day\|night\|auto" |
| (outro) | Erro | "Usage: /forceperiod day\|night\|auto" |

### Configurações

| Propriedade | Valor | Descrição |
|-----------|-------|-----------|
| **Separador** | " " | Espaço separa comando do parâmetro |
| **Tipo Grupo** | "god" | Apenas gods podem usar |

### Tipos de Mensagem

- `MESSAGE_EVENT_ADVANCE`: Usado para mensagens de sucesso (colorido/destacado)
- `MESSAGE_FAILURE`: Implícito em `sendCancelMessage()` para erros
