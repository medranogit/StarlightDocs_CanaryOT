## 📄 Visão Geral Resumida

Move event que detecta entrada do jogador em sala de treinamento e distribuição inteligente para postos disponíveis em grid configurável. Procura recursivamente por primeiro tile desocupado em matriz de treinamento (7 colunas × 54 linhas) com espaçamento de 12 tiles XY. Spawna 2 máquinas de treinamento na posição inicial do jogador.

## 🔧 Estrutura de Funcionalidades

### Variáveis Globais

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `config` | table | Configuração da sala de treinamento |

### Configuração

```lua
config = {
  firstRoomPosition = { x = 1018, y = 1112, z = 7 },  -- Primeira sala
  distancePositionX = 12,  -- Espaçamento X entre salas
  distancePositionY = 12,  -- Espaçamento Y entre salas
  columns = 7,             -- Colunas de salas
  lines = 54               -- Linhas de salas
}
```

### Funções Locais

**`isBusyable(position)`**
- **Parâmetros**: `position` (table com x, y, z)
- **Retorno**: `boolean` (true se tile está livre e acessível)
- **Validações**:
  1. Obtém criatura topo do tile
  2. Se mais criatura ou pet: retorna false (ocupado)
  3. Se sem tile: retorna false
  4. Se ground bloqueador (BLOCKSOLID): retorna false
  5. Itera itemz: se item não-móvel com BLOCKSOLID: retorna false
  6. Retorna true (tile livre)

**`calculatingRoom(uid, position, column, line)`**
- **Parâmetros**:
  - `uid`: ID do jogador
  - `position`: Posição primeiro tile
  - `column`: Coluna atual (0 inicial)
  - `line`: Linha atual (0 inicial)
- **Retorno**: Void
- **Lógica Recursiva**:
  1. Obtém jogador via Player(uid)
  2. Se column >= columns: reseta para 0, incrementa line
  3. Se line esgotado: retorna mensagem de erro
  4. Calcula posição do tile: `pos = primeira_posição + (coluna × espaço_x, linha × espaço_y, z)`
  5. Se tile livre: teleporta jogador, envia efeito TELEPORT
  6. Se ocupado: chamada recursiva para próxima coluna
  
### Move Event

**Evento: `trainerEntrance.onStepIn`**
- **Disparador**: Jogador pisa na posição especificada
- **Ação**:
  1. Verifica se criatura é jogador, caso negativo retorna true
  2. Calcula primeiro tile livre via `calculatingRoom()`
  3. Spawna 2 × "Training Machine" na posição do jogador
  4. Retorna true
