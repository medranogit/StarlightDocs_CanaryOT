## 📄 Visão Geral Resumida

Move event que detecta pisada em items de saída (baseados em action IDs) da sala de treinamento e teleporta jogador de volta ao templo de sua cidade de origem. Utiliza system de towns integrado para obter posição correta de templo.

## 🔧 Estrutura de Funcionalidades

### Funções Locais

**`teleportToTemple(creature)`**
- **Parâmetros**: `creature` (Criatura a teleportar)
- **Retorno**: `true`
- **Lógica**:
  1. Valida se criatura é jogador, caso negativo retorna true
  2. Obtém town do jogador via `creature:getTown()`
  3. Obtém posição do templo da town via `town:getTemplePosition()`
  4. Teleporta jogador via `creature:teleportTo(posição)`
  5. Envia efeito visual TELEPORT na nova posição
  
### Move Event

**Evento: `trainerExit.onStepIn`**
- **Disparador**: Jogador pisa em item com action ID 40015 ou 4255
- **Ação**:
  1. Chama `teleportToTemple(creature)`
  2. Retorna true (evento processado)

### Pseudocódigo Detalhado

```lua
function teleportToTemple(creature)
  if não creature:isPlayer() então
    retorna true
  end
  
  posição_templo = creature:getTown():getTemplePosition()
  creature:teleportTo(posição_templo)
  creature:getPosition():sendMagicEffect(CONST_ME_TELEPORT)
end

function trainerExit.onStepIn(creature, item, position, fromPosition)
  teleportToTemple(creature)
  retorna true
end
```
