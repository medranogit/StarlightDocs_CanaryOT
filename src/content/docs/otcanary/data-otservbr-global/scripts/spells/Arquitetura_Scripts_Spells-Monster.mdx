# 🏗️ Arquitetura - Monster Spells

Guia completo sobre a arquitetura e estrutura técnica dos scripts de **Monster Spells** do servidor OTServ Canary. Entenda como os feitiços de monstros são implementados, organizados e como criar novos.

---

## 🎯 Sobre essa Pasta de Scripts

<Card title="O que é?" icon="information">
A pasta `data-otservbr-global/scripts/spells/monster/` contém todos os scripts **Lua** responsáveis pelos feitiços e habilidades mágicas de **monstros e chefes**. Cada spell define o comportamento, efeitos visuais, dano, condições e áreas de ataque quando o monstro usa suas habilidades contra jogadores.
</Card>

<Card title="Casos de Uso" icon="information">
Você utilizará essa pasta quando precisar:

- **Criar nova magia de monstro**: Definir spell words, tipo de dano, efeitos visuais
- **Modificar dano/efeito**: Ajustar parâmetros de combat, fórmulas de dano, ticks de condições
- **Implementar condições**: Paralisia, veneno, queimadura, redução de skill
- **Definir áreas de ataque**: Criar padrões de wave, cone, blast para ataques em área
- **Adicionar efeitos especiais**: Distância, visualização de partículas, sons
- **Balancear boss fights**: Ajustar timing, potência e frequência de ataques especiais
- **Debug de spell**: Investigar por que monstro não está usando spell corretamente
</Card>

<Card title="Estrutura da Pasta" icon="information">
Os scripts de mongo spells são organizados por **boss/criatura**:

- Arquivos nomeados descritivamente: `abyssador_paralyze.lua`, `dragon_fire_wave.lua`, etc.
- Cada arquivo contém uma função `spell.onCastSpell(creature, var)` que executa o combat
- Configurações via `spell:parameter()` (name, words, aggressive, needTarget, etc.)
- Combat system integrado com condições, áreas e efeitos visuais

Estrutura típica:
1. Definir `Combat()` e seus parâmetros
2. Adicionar condições (se aplicável)
3. Definir área de ataque (se não é single target)
4. Criar instância `Spell()` e registrar
</Card>

## 🧩 Componentes Principais

<Tabs>
<TabItem label="Combat System">

### Sistema de Combat

Todo spell de monstro começa com um objeto `Combat()` que define o tipo de dano e parâmetros de ataque.

```lua
-- Estrutura básica
local combat = Combat()
combat:setParameter(COMBAT_PHYSICALDAMAGE, -50, 0)
combat:setParameter(COMBAT_MAGICDAMAGE, true)
combat:setParameter(COMBAT_LIFEDRAIN, true)

-- Tipos de Combat disponíveis:
-- COMBAT_PHYSICALDAMAGE    - Dano físico direto
-- COMBAT_MAGICDAMAGE       - Dano mágico geral
-- COMBAT_FIREDAMAGE        - Dano de fogo
-- COMBAT_ICEDAMAGE         - Dano de gelo
-- COMBAT_ENERGYDAMAGE      - Dano energético
-- COMBAT_DEATHDAMAGE       - Dano de morte
-- COMBAT_EARTHDAMAGE       - Dano de terra
-- COMBAT_LIFEDRAIN         - Drenar vida
-- COMBAT_MANADRAIN         - Drenar maná
-- COMBAT_DROWNDAMAGE       - Dano de afogamento
```

**Exemplo Completo:**
```lua
local combat = Combat()
combat:setParameter(COMBAT_PHYSICALDAMAGE, -100, -150)  -- -100 a -150 de dano
combat:setParameter(COMBAT_LIFEDRAIN, true)
combat:setArea(createCuboidArea(Vector3(0, 0, 0), Vector3(3, 3, 0)))

function onCastSpell(creature, var)
    return combat:execute(creature, var)
end
```

</TabItem>

<TabItem label="Spell Object">

### Objeto Spell

O objeto `Spell` registra e configura metadados do feitiço.

```lua
local spell = Spell("instant")  -- ou "rune"

-- Configurações básicas
spell:words("###100")           -- Comando de ativação
spell:name("Paralyze")          -- Nome do spell
spell:description("Paralisa alvo")

-- Parâmetros comportamentais
spell:needTarget(true)          -- Requer alvo?
spell:isAggressive(true)        -- É ataque?
spell:blockWalls(true)          -- Bloqueado por paredes?
spell:range(4)                  -- Alcance em tiles

-- Configurar combat associado
function spell.onCastSpell(creature, var)
    return combat:execute(creature, var)
end

-- Registrar
spell:register()
```

**Atributos Principais:**
| Atributo | Tipo | Descrição |
|----------|------|-----------|
| `words` | string | Comando do spell (###XXX) |
| `name` | string | Nome descritivo |
| `needTarget` | boolean | Requer seleção de alvo |
| `isAggressive` | boolean | É ataque agressivo |
| `blockWalls` | boolean | Bloqueado por walls |
| `range` | number | Alcance em tiles |
| `cooldown` | number | Cooldown em ms |

</TabItem>

### Sistema de Áreas

Define onde e como o spell afeta múltiplos tiles.

```lua
-- Área quadrada
local area = createCuboidArea(Vector3(0, 0, 0), Vector3(3, 3, 0))

-- Área circular
local area = createCircleArea(Vector3(0, 0, 0), 3)

-- Validações
if not combat:setArea(area) then
    print("Erro ao definir área")
end
```

**Tipos de Áreas Comuns:**

```lua

```

## ⚡ Sistema de Combat

<Card title="Fórmulas de Dano" icon="zap">

### Cálculo de Dano

O dano é calculado por uma fórmula configurável:

```lua
local combat = Combat()

-- Formato: combat:setParameter(tipo, minDano, maxDano)
combat:setParameter(COMBAT_PHYSICALDAMAGE, -50, -100)
-- Resultado: Dano aleatório entre -50 e -100

-- Modificadores
combat:setParameter(COMBAT_MAGICDAMAGE, true)      -- Usa magic shield
combat:setParameter(COMBAT_LIFEDRAIN, true)       -- Drena vida
combat:setParameter(COMBAT_MANADRAIN, true)       -- Drena maná
```

### Ajustes por Skill/Level

```lua
function damage(level, magicLevel)
    local min = math.max(-30, -(level / 5 + magicLevel * 1.1))
    local max = math.max(-50, -(level / 3 + magicLevel * 1.4))
    return min, max
end

combat:setParameter(COMBAT_FIREDAMAGE, damage(creature:getLevel(), creature:getMagicLevel()))
```

## 🌀 Condições de Efeito

<Card title="Sistema de Condições" icon="shapes">

### Tipos de Condições

As condições aplicam efeitos persistentes ao alvo.

```lua
local combat = Combat()
combat:setParameter(COMBAT_PHYSICALDAMAGE, -50, -80)

-- Aplicar paralisia
local condition = Condition(CONDITION_PARALYZE)
condition:setParameter(CONDITION_PARAM_TICKS, 20000)  -- 20 segundos
condition:setFormula(-0.70, 0, -0.85, 0)              -- Reduz velocidade em 70-85%
combat:addCondition(condition)

function onCastSpell(creature, var)
    return combat:execute(creature, var)
end
```

### Condições Disponíveis

```lua
CONDITION_PARALYZE          -- Paralisia (reduz velocidade)
CONDITION_POISON            -- Veneno (dano contínuo)
CONDITION_FIRE              -- Fogo (queimadura)
CONDITION_ENERGY            -- Energia (choque)
CONDITION_CURSE             -- Maldição (debilidade)
CONDITION_DROWN             -- Afogamento
CONDITION_FREEZING          -- Congelamento
CONDITION_DAZZLED           -- Atordoamento
CONDITION_DRUNK             -- Embriaguez
CONDITION_EXHAUSTED         -- Exaustão
CONDITION_FEARED            -- Medo
```

**Parâmetros de Condição:**
```lua
condition:setParameter(CONDITION_PARAM_TICKS, 20000)           -- Duração em ms
condition:setParameter(CONDITION_PARAM_HEALTHTICKS, 1000)      -- Ticks de dano
condition:setParameter(CONDITION_PARAM_HEALTHVALUE, -50)       -- Valor do dano
condition:setFormula(minMul, minBase, maxMul, maxBase)         -- Redução de atributos
```

## 🛠️ Como Criar um Novo Spell

<Card title="Guia Passo a Passo" icon="wrench">

### Passo 1: Criar o Arquivo

```bash
# Arquivo: {nome_boss}_{tipo_efeito}.lua
# Exemplo: mymonster_fireball.lua
```

### Passo 2: Definir Combat

```lua
local combat = Combat()
combat:setParameter(COMBAT_FIREDAMAGE, -50, -100)  -- Tipo e dano
```

### Passo 3: Adicionar Condições (opcional)

```lua
local condition = Condition(CONDITION_FIRE)
condition:setParameter(CONDITION_PARAM_TICKS, 10000)  -- 10 segundos
condition:setParameter(CONDITION_PARAM_HEALTHTICKS, 2000)  -- Tick de dano a cada 2s
condition:setParameter(CONDITION_PARAM_HEALTHVALUE, -20)  -- -20 de dano por tick
combat:addCondition(condition)
```

### Passo 4: Definir Área (opcional)

```lua
local area = createCuboidArea(Vector3(0, 0, 0), Vector3(3, 3, 0))
combat:setArea(area)
```

### Passo 5: Criar Objeto Spell

```lua
local spell = Spell("instant")
spell:words("###500")  -- Substitua por número único
spell:name("Fire Ball")
spell:description("Lança uma bola de fogo em área")
spell:needTarget(false)  -- true = requer alvo
spell:isAggressive(true)  -- true = dano/ataque
spell:blockWalls(true)  -- true = bloqueado por paredes
```

### Passo 6: Implementar Função onCastSpell

```lua
function spell.onCastSpell(creature, var)
    return combat:execute(creature, var)
end
```

### Passo 7: Registrar

```lua
spell:register()
```

### Arquivo Completo Exemplo

```lua
-- mymonster_fireball.lua

local combat = Combat()
```

## 🔧 Guia de Troubleshooting

<Card title="Problemas Comuns" icon="bug">

### Problema: Spell não executa

**Causa:** Função `onCastSpell` ausente ou mal nomeada  
**Solução:**
```lua
function spell.onCastSpell(creature, var)
    return combat:execute(creature, var)
end
```

### Problema: Dano muito fraco/forte

**Causa:** Parâmetros de dano incorretos  
**Solução:** Ajustar valores
```lua
-- Fraco: -10, -20
combat:setParameter(COMBAT_PHYSICALDAMAGE, -50, -100)  -- Mais forte
```

### Problema: Spell não atinge múltiplos alvos

**Causa:** Área não definida corretamente  
**Solução:** Verificar `createCuboidArea` ou `createCircleArea`
```lua
local area = createCircleArea(Vector3(0, 0, 0), 4)  -- Raio 4
combat:setArea(area)
```

### Problema: Condição não aplica

**Causa:** Condição não adicionada ao combat  
**Solução:**
```lua
combat:addCondition(condition)  -- Garantir que está adicionado
```

### Problema: Spell bloqueia ao colidir com paredes

**Isto é esperado!** Configurar com:
```lua
spell:blockWalls(false)  -- Para atravessar paredes
```

<Aside type="tip">

**Spell Words Format:**
- `###XXX`: Formato padrão (ex: ###86, ###100, ###500)
- `##XXX`: Formato alternativo (2 dígitos)
- `#XXXXXX`: Formato estendido (6 dígitos)

**Combat Types:**
- PHYSICALDAMAGE, MAGICDAMAGE
- FIREDAMAGE, ICEDAMAGE, ENERGYDAMAGE, DEATHDAMAGE
- EARTHDAMAGE, LIFEDRAIN, MANADRAIN

**Condition Formulas:**
- `setFormula(minMul, minBase, maxMul, maxBase)`
- Exemplo: `(-0.70, 0, -0.85, 0)` = reduz 70-85%

**Criação de Áreas:**
- `createCuboidArea(min, max)` - Retângulo
- `createCircleArea(center, radius)` - Círculo
