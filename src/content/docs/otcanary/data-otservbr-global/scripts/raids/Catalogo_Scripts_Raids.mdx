# 🏰 Catálogo de Scripts - Raids

Documentação técnica completa de todos os raids do servidor, incluindo boss raids, invasões onduladas e eventos periódicos.

## 🎯 Sobre essa Pasta de Scripts

<Card title="O que é?" icon="information">
A pasta `data-otservbr-global/scripts/raids/` contém scripts **Lua** que implementam **eventos periódicos de invasão/spawning**. Cada raid script define uma zona, probabilidade de ocorrência, quantidade mínima de players, e sequência de spawns de monstros/bosses. Raids são eventos globais que afetam todo o servidor em horários aleatórios.
</Card>

<Card title="Como Usar o Catálogo" icon="star">
Este catálogo lista **todos os scripts raid** com:
- **Arquivo**: Nome exato do arquivo Lua
- **Localização**: Zona do servidor onde ocorre
- **Tipo**: Boss Único, Wave, Invasão, etc
- **Spawns**: Monstros spawneados
- **Configuração**: Chance, min players, gaps
- **Duração**: Timing total do evento
- **Probabilidade**: Frequência de ocorrência

Use **Ctrl+F** para buscar por raid.
</Card>

## 👑 Raid 1: Arachir the Ancient One

### **arachir_the_ancient_one.lua**

**Localização**: Drefia  
**Tipo**: Boss Único  
**Zona Spawn**: Position(32963, 32399, 12) → Position(32965, 32401, 12)  
**Tamanho Zone**: 2×2 tiles (muito pequena)

### Boss

```
Nome: Arachir the Ancient One
Quantidade: 1
Posição: (32964, 32400, 12) - Centro da zone
```

### Configuração

```lua
{
    zone = Zone("drefia.arachir"),
    allowedDays = { 7 dias/semana },
    minActivePlayers = 3,
    initialChance = 0.02,        -- 2% inicial
    targetChancePerDay = 0.02,   -- +2% por dia
    maxChancePerCheck = 0.8,     -- Máximo 80%
}
```

**Cálculo de Frequência**:
- Dia 1: 2% chance
- Dia 2: 4% chance
- Dia 3: 6% chance
- ...
- Dia 40+: 80% máximo
- **MinGap**: Sem limite configurado

### Timeline

```
t=0s: Raid executa (se passou chance check)
      Arachir spawn em (32964, 32400, 12)
      Raid ativo por 24h automático
      
t=24h: Raid encerra, reset para próxima possibilidade
```

### Spawn Details

```lua
{
    name = "Arachir the Ancient One",
    amount = 1,
    position = Position(32964, 32400, 12)
}
```

### Players Afetados

Qualquer player em Drefia quando raid ocorrer.

### Dificuldade

⭐⭐⭐ (3 stars) - Boss desafiador, exige 3+ players

## 🐭 Raid 5: Rats

### **rats.lua**

**Localização**: Thais  
**Tipo**: Invasão Multi-Monster  
**Zona**: Position(32331, 32182, 7) → Position(32426, 32261, 7)  
**Tamanho Zone**: 95×79 tiles (grande)

### Broadcast

```
"Rat Plague in Thais!"
```

### Waves

#### Wave 1: Initial Infestation (Delay: 10m)
```
Rat: 10
Cave Rat: 10
———
Total: 20 creatures
```

#### Wave 2: Escalation (Delay: 10m)
```
Rat: 20
Cave Rat: 20
———
Total: 40 creatures
```

### Configuração

```lua
{
    zone = Zone("thais.rats"),
    allowedDays = { 7 dias/semana },
    minActivePlayers = 0,           -- ⚠️ Qualquer um pode trigger!
    targetChancePerDay = 30,        -- 30% chance (muito alta!)
    maxChancePerCheck = 50,         -- Máximo 50% (moderado)
    minGapBetween = "36h",          -- Minigap LONGO (36h)
}
```

### Frequência (Muito Diferente!)

```
Diferente de outros raids que usam initialChance:
- Usa targetChancePerDay = 30 (30% base!)
- maxChancePerCheck = 50 (50% máximo)
- minGapBetween = 36h (força 36h de espera)

Resultado: Comum (30-50%), mas rara garantida (36h mínimo)
```

### Duração Total

```
Broadcast: 5s
Wave 1: 10m
Wave 2: 10m
———
Total: 20m5s (evento longo!)
```

### Spawns Totais

```
Wave 1: 10 Rats + 10 Cave Rats = 20
Wave 2: 20 Rats + 20 Cave Rats = 40
————————————————————————————
Total: 60 creatures
```

### Players Afetados

**Qualquer player em Thais** - minActivePlayers = 0 significa sem requisito!

### Dificuldade

⭐⭐ (2 stars) - Muitos números, mas fracos

### Diferenças Notáveis

```
Comparado com outros raids:

| Aspecto | Rats | Bosses |
|---------|------|--------|
| Min Players | 0 | 2-3 |
| Chance Base | 30% | 2-3% |
| Gap Min | 36h | None |
| Duration | 20m | 0s |
| Total Spawns | 60 | 1 |
| Difficulty | Fácil | Difícil |
```

**Rats** é o raid mais acessível e frequente!

<Aside type="note">
**Padrões em 21 Raids**:

1. Todos usam **Zone** com addArea (alguns dual zones)
2. Boss raids: Instantâneos (0 duração), 24h auto-advance
3. Wave raids: Progressivos (5m - 61m)
4. Long-running: Até 21 horas de duração!
5. Minigap previne spam (12h - 48h)
6. Broadcasts notificam players
7. Configuração **allowedDays**: Maioria 7/7 (alguns 5-6 dias)
8. Chance cresce diariamente até cap
9. Min players variam (0-3):
   - 0: Pode rodar offline (Wild Horses Thais, Rats escalada)
   - 2: Mais acessível (Draptor, Mawhawk, Tyrn, Yeti)
   - 3: Mais desafiador (Maioria dos bosses)
10. Random positions raro (apenas Midnight Panther, Welter, Tyrn)
11. maxChecksPerDay limita frequência (Wild Horses)
12. Large zones (85×192 para Furyosa!) para zonas abertas

**Scalability Pattern**:

- Boss único: Copy template 2×2 zone
- Boss + waves: Add for loop antes do boss
- Long waves: Aumentar loops (7-20 iterations)
- Invasão: Multiple creatures + escalação
- Offline raids: minActivePlayers = 0

**Performance Insights**:

- Boss raids (11): Zero load (0 duration)
- Short waves (3): ~5m load durante evento
- Long waves (3): Intermitente durante 21h/61m
- Minigap: Previne spam, mantém rareidade
- maxChecksPerDay: Extra throttle (Wild Horses)

</Aside>
