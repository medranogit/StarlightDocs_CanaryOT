# 🏰 Arquitetura - Raids Scripts

Guia completo sobre a arquitetura e estrutura técnica dos scripts **Raids** do servidor OTServ Canary. Entenda como implementar eventos periódicos que spawnam bosses e monstros em zonas específicas.

---

## 🎯 Sobre essa Pasta de Scripts

<Card title="O que é?" icon="information">
A pasta `data-otservbr-global/scripts/raids/` contém scripts **Lua** que implementam **eventos periódicos de invasão/spawning** - 21 raids no total que ocorrem em horários aleatórios, com spawns de monstros e bosses em zonas específicas. Cada raid script define a zona, probabilidade de ocorrência, quantidade mínima de players, e sequência de spawns. Raids são eventos globais que afetam toda a comunidade, com duração variando de instantâneo (bosses) até 21 horas (invasões prolongadas).
</Card>

<Card title="Casos de Uso" icon="target">
Você utilizará essa pasta quando precisar:

- **Boss Raids**: Eventos periódicos com spawn de bosses únicos
- **Wave-Based Events**: Spawns em ondas (wave 1, wave 2, etc)
- **Zone-Based Invasions**: Invasão de monstros em áreas específicas
- **Server-Wide Events**: Eventos que afetam todo servidor
- **Probabilistic Encounters**: Chance variável de ocorrência
- **Time-Gated Content**: Minigap entre raids + day scheduling
- **Broadcast Messages**: Avisos globais ao iniciar raid
- **Difficulty Scaling**: Min players + spawn amounts
- **Random Positions**: Bosses aparecem em múltiplos pontos
- **Duration Management**: Auto-advance em timers predefinidos
</Card>

<Card title="Estrutura da Pasta" icon="list">
A pasta `scripts/raids/` é organizada por **tipo/localização de raid**:

```
raids/
├── bosses/
│   ├── arachir_the_ancient_one.lua  (Boss único)

└── thais/
    └── rats.lua                     (Invasão progressiva)
```

**Padrão de Organização**: 21 raids totais, organizados por tipo/localização.

**Total**: 21 raids documentadas, cobrindo 14+ zonas do servidor (25 scripts com variações diferentes)

</Card>

## 🔍 Estrutura Geral

<Card title="Entendendo Raids Scripts" icon="document">

Um **Raid Script** é um script que:
- **Define uma invasão/evento periódico** com horários e probabilidades
- **Especifica uma zona** (area com coordenadas X/Y/Z)
- **Configura condições de spawn** (min players, dias, chance)
- **Sequencia spawns** de monstros/bosses em fases
- **Afeta todo o servidor** (evento global)

### Ciclo de Vida de um Raid

```lua
-- 1. Criar Zone
local zone = Zone("raid.name")
zone:addArea(Position(x1, y1, z), Position(x2, y2, z))

-- 2. Criar Raid com config
local raid = Raid("raid.id", {
    zone = zone,
    allowedDays = {"Monday", "Tuesday", ...},
    minActivePlayers = 3,
    initialChance = 0.02,
    -- ... mais config
})

-- 3. Adicionar fases de spawn
raid
    :addSpawnMonsters({...})
    :autoAdvance("delay")
    :addBroadcast("Mensagem")
    :autoAdvance("delay")

-- 4. Registrar
raid:register()
```

### Padrão Básico

```lua
-- 1. Zone definição
local zone = Zone("locacao.raid_name")
zone:addArea(Position(x1, y1, z), Position(x2, y2, z))

-- 2. Raid object
local raid = Raid("locacao.raid_name", {
    zone = zone,
    allowedDays = { "Monday", "Tuesday", "Wednesday", ... },
    minActivePlayers = 2,
    initialChance = 0.02,
    targetChancePerDay = 0.02,
    maxChancePerCheck = 0.8,
})

-- 3. Spawns e fases
raid
    :addSpawnMonsters({
        { name = "Boss Name", amount = 1, position = Position(x,y,z) }
    })
    :autoAdvance("24h")

-- 4. Registrar
raid:register()
```

### Componentes Principais

```lua
-- Config Table
{
    zone = Zone("..."),                    -- Área onde raid ocorre
    allowedDays = {"Monday", ...},         -- Dias da semana permitidos
    minActivePlayers = 3,                  -- Mínimo players online
    initialChance = 0.02,                  -- Chance inicial (2%)
    targetChancePerDay = 0.02,             -- Chance por dia
    maxChancePerCheck = 0.8,               -- Chance máxima (80%)
    minGapBetween = "12h",                 -- Tempo mínimo entre raids
}

-- Métodos
:addSpawnMonsters({...})                   -- Spawn de wave
:addBroadcast("Text")                      -- Mensagem global
:autoAdvance("delay")                      -- Avança após delay
:register()                                -- Registra raid
```

## 🎪 Componentes de Raid

<Card title="Elementos que Compõem um Raid" icon="layers">

### Componente 1: Zone (Área de Ação)

```lua
-- Define retângulo onde raid ocorre
local zone = Zone("drefia.arachir")
zone:addArea(
    Position(32963, 32399, 12),  -- Canto superior esquerdo
    Position(32965, 32401, 12)   -- Canto inferior direito
)

-- Cálculo: Área = (65-63) × (401-399) = 2 × 2 = 4 tiles
```

**Propósito**: Delimitar onde monstros podem spawnar.

**Flexibility**:
- Pequena: 2×2 tiles (bosses únicos)
- Média: 50×50 tiles (invasões)
- Grande: 100×100 tiles (eventos massivos)

### Componente 2: Raid Configuration

```lua
{
    zone = zone,                           -- Obrigatório
    allowedDays = {...},                   -- Obrigatório
    minActivePlayers = 3,                  -- Obrigatório
    
    -- Probabilidade (opcional)
    initialChance = 0.02,                  -- 2% inicial
    targetChancePerDay = 0.02,             -- +2% por dia
    maxChancePerCheck = 0.8,               -- Máximo 80%
    
    -- Timing (opcional)
    minGapBetween = "12h",                 -- 12h entre raids
}
```

**initialChance**: Chance base quando server inicia  
**targetChancePerDay**: Aumenta a cada dia sem raid  
**maxChancePerCheck**: Teto máximo de probabilidade  
**minGapBetween**: Força espera mínima entre ocorrências

### Componente 3: Spawn Wave

```lua
raid:addSpawnMonsters({
    {
        name = "Monster Name",
        amount = 5,
        position = Position(x, y, z)  -- Opcional
    },
    {
        name = "Boss Name",
        amount = 1
        -- Sem position = spread na zone
    }
})
```

**Options**:
- `name`: Exato do monstro no servidor
- `amount`: Quantidade a spawnar
- `position`: (Opcional) Posição fixa ou aleatória na zone

### Componente 4: Delay e Avanço

```lua
raid
    :addSpawnMonsters({...})      -- Spawn wave 1
    :autoAdvance("30s")            -- Espera 30s
    
    :addBroadcast("Invasão!")      -- Mensagem
    :autoAdvance("5s")             -- Espera 5s
    
    :addSpawnMonsters({...})       -- Spawn wave 2
    :autoAdvance("2m")             -- Espera 2 minutos
```

**Delays Comuns**:
- Instantâneo: "0s" ou omitir
- Curto: "5s", "10s", "30s"
- Médio: "2m", "5m", "10m"
- Longo: "1h", "24h"

### Componente 5: Broadcast

```lua
raid:addBroadcast("Rat Plague in Thais!")
    :autoAdvance("5s")
```

**Propósito**: Avisar jogadores sobre evento global

**Timing**: Geralmente no início do raid

</Card>

## 🏰 Tipos de Raids

<Card title="Padrões e Classificações de Raids" icon="zap">

### Tipo 1: Boss Único (Simple)

```lua
-- Spawna 1 boss em posição fixa
local raid = Raid("drefia.boss", {
    zone = zone,
    allowedDays = { "Monday", "Tuesday", ... },
    minActivePlayers = 3,
    initialChance = 0.02,
    targetChancePerDay = 0.02,
    maxChancePerCheck = 0.8,
})

raid:addSpawnMonsters({
    { name = "Arachir the Ancient One", amount = 1, position = Position(...) }
})
:autoAdvance("24h")

raid:register()
```

**Características**:
- 1 boss apenas
- Posição fixa ou opcional
- Duration: 24h (automático)
- Minigap: Sem limite

### Tipo 2: Boss Random Position

```lua
-- Spawna 1 boss em um de múltiplos pontos aleatórios
local possiblePositions = {
    Position(32847, 32697, 7),
    Position(32871, 32717, 7),
    Position(32856, 32738, 7),
}

raid:addSpawnMonsters({
    {
        name = "Midnight Panther",
        amount = 1,
        position = possiblePositions[math.random(1, #possiblePositions)],
    },
})
:autoAdvance("24h")
```

**Características**:
- 1 boss com random spawn
- 3 posições possíveis
- Mais desafiante (players não sabem onde)

### Tipo 3: Wave-Based (Progressivo)

```lua
-- Múltiplas waves com delay entre elas
raid:addBroadcast("Dragons invaded!"):autoAdvance("5s")

for i = 1, 3 do
    raid:addSpawnMonsters({
        { name = "Dragon", amount = 50 }
    }):autoAdvance("2m")
end

for i = 1, 8 do
    raid:addSpawnMonsters({
        { name = "Draptor", amount = 1 }
    }):autoAdvance("10s")
end
```

**Características**:
- Broadcast inicial
- Múltiplas waves (3+)
- Escalação de dificuldade
- Timing progressivo

### Tipo 4: Multi-Monster Event (Invasão)

```lua
-- Múltiplos tipos de monstro em sequência
raid:addBroadcast("Rat Plague in Thais!"):autoAdvance("5s")

raid:addSpawnMonsters({
    { name = "Rat", amount = 10 },
    { name = "Cave Rat", amount = 10 },
}):autoAdvance("10m")

raid:addSpawnMonsters({
    { name = "Rat", amount = 20 },
    { name = "Cave Rat", amount = 20 },
}):autoAdvance("10m")
```

**Características**:
- Múltiplos tipos simultâneos
- Escalação de quantidade
- Longo duration (20m total)
- Alto minGapBetween (36h)

</Card>

## 📊 Configuração de Probabilidade

<Card title="Sistema de Chance de Raid" icon="target">

### Probabilidade Inicial vs Diária

```lua
initialChance = 0.02      -- 2% quando server inicia
targetChancePerDay = 0.02 -- +2% por dia sem raid
maxChancePerCheck = 0.8   -- Máximo 80%

-- Progresso:
-- Dia 0: 2%
-- Dia 1: 4%
-- Dia 2: 6%
-- ...
-- Dia 39+: 80% (pico)
```

**Fórmula Simulada**:
```
Hoje: initialChance = 0.02 (2%)
Amanhã (se não acontecer): 0.02 + 0.02 = 0.04 (4%)
Dia 3: 0.06 (6%)
...
Limite: 0.80 (80%)
```

### Minigap Between

```lua
minGapBetween = "12h"    -- Mínimo 12h entre raids

-- Exemplos:
minGapBetween = "12h"    -- 12 horas (bosses)
minGapBetween = "24h"    -- 24 horas (padrão)
minGapBetween = "36h"    -- 36 horas (invasões big)
```

**Propósito**: Preventar spam de raids  
**Efeito**: Force espera mínima depois de última ocorrência

### Min Active Players

```lua
minActivePlayers = 0      -- Qualquer um pode trigger
minActivePlayers = 2      -- Mínimo 2 players
minActivePlayers = 3      -- Mínimo 3 players
minActivePlayers = 5      -- Mínimo 5 players
```

**Lógica**:
```
IF isTimeToRaid() THEN
    IF getActivePlayers() >= minActivePlayers THEN
        :spawn()
    ELSE
        :skip() -- Espera mais players
    END
END
```

### Exemplo Real: Rats (Testes Alta)

```lua
targetChancePerDay = 30    -- 30% de chance
maxChancePerCheck = 50     -- Máximo 50%
minGapBetween = "36h"      -- 36 horas mínimo
minActivePlayers = 0       -- Qualquer um
```

**Efeito**: Invasão comum (alta chance), frequente (36h min), sempre permite (0 players)

</Card>

## 💥 Wave-Based Raids

<Card title="Implementando Raids com Múltiplas Fases" icon="zap">

### Anatomy of Wave Raid

```lua
-- Array de waves
for i = 1, 3 do              -- 3 waves
    raid
        :addSpawnMonsters({
            {
                name = "Dragon",
                amount = 50,
            },
        })
        :autoAdvance("2m")     -- 2m entre waves
end

-- Resultado:
-- t=0s: Broadcast
-- t=5s: Wave 1 (50 Dragons)
-- t=125s: Wave 2 (50 Dragons)
-- t=245s: Wave 3 (50 Dragons)
-- t=365s: Final bosses
```

### Wave Control

```lua
-- 3 waves iguais
for i = 1, 3 do
    raid
        :addSpawnMonsters({...})
        :autoAdvance("2m")
end

-- Waves customizadas
raid:addSpawnMonsters({...}):autoAdvance("1m")
raid:addSpawnMonsters({...}):autoAdvance("3m")
raid:addSpawnMonsters({...}):autoAdvance("5m")

-- Conditional spawns
if dayOfWeek() == "Monday" then
    raid:addSpawnMonsters({...})
end
```

### Escalation Pattern

```lua
-- Começa pequeno, cresce
raid:addSpawnMonsters({
    { name = "Weak", amount = 5 }
}):autoAdvance("1m")

raid:addSpawnMonsters({
    { name = "Medium", amount = 10 }
}):autoAdvance("1m")

raid:addSpawnMonsters({
    { name = "Strong", amount = 20 }
}):autoAdvance("1m")

raid:addSpawnMonsters({
    { name = "Boss", amount = 1 }
}):autoAdvance("30m")
```

## 🛠️ Criando um Raid Script

<Card title="Guia Passo a Passo" icon="wrench">

### Passo 1: Determinar Tipo

Escolha qual padrão melhor se encaixa:
- **Boss Único**: 1 monstro/boss em posição fixa
- **Boss Random**: 1 boss com múltiplas posições possíveis
- **Invasão**: Múltiplos tipos de monstro em sequence
- **Wave Event**: Progressão de waves com escalação

### Passo 2: Definir Zone

```lua
-- Identificar localização no mapa
local zone = Zone("area.raid_name")
zone:addArea(
    Position(x1, y1, z1),  -- Canto 1
    Position(x2, y2, z2)   -- Canto 2
)
```

### Passo 3: Configurar Raid

```lua
local raid = Raid("area.raid_name", {
    zone = zone,
    allowedDays = { "Monday", "Tuesday", ... },
    minActivePlayers = 3,
    initialChance = 0.02,
    targetChancePerDay = 0.02,
    maxChancePerCheck = 0.8,
    -- minGapBetween = "12h",  -- Opcional
})
```

### Passo 4: Adicionar Spawns

```lua
raid
    :addBroadcast("Mensaje opcional")
    :autoAdvance("5s")
    
    :addSpawnMonsters({
        { name = "Monster", amount = 5 },
        { name = "Boss", amount = 1 },
    })
    :autoAdvance("2m")
```

### Passo 5: Registrar

```lua
raid:register()
```

### Exemplo Completo

```lua
-- scripts/raids/custom/my_raid.lua

local zone = Zone("area.my_raid")
zone:addArea(Position(1000, 1000, 7), Position(1100, 1100, 7))

local raid = Raid("area.my_raid", {
```

## 🔧 Guia de Troubleshooting

<Card title="Problemas Comuns" icon="bug">

### Problema: Raid não spawna

**Causa**: Zone não registra, position errada, ou minactiveplayers  
**Solução**:
```lua
-- ✅ Correto - Zone e coordenadas válidas
local zone = Zone("drefia.arachir")
zone:addArea(Position(32963, 32399, 12), Position(32965, 32401, 12))

local raid = Raid("drefia.arachir", {
    zone = zone,
    minActivePlayers = 0,  -- Começa com 0 para teste
    -- ... resto
})

-- ❌ Errado - Zone vazia
local zone = Zone("drefia.arachir")
-- Sem addArea = zone vazia!
```

### Problema: Spawns não aparecem quando esperado

**Causa**: autoAdvance com delay errado  
**Solução**:
```lua
-- ✅ Correto - Delays apropriados
raid
    :addBroadcast("Event!")
    :autoAdvance("5s")      -- Avança após 5s
    
    :addSpawnMonsters({...})
    :autoAdvance("2m")      -- Próximo wave em 2m

-- ❌ Errado - Omitiu autoAdvance
raid
    :addSpawnMonsters({...})
    -- Sem autoAdvance - não avança!
    :addSpawnMonsters({...})
```

### Problema: Raid acontece com muita frequência

**Causa**: minGapBetween está curto ou targetChancePerDay alta  
**Solução**:
```lua
-- ✅ Controlar frequência
minGapBetween = "24h",       -- Aumentar gap
targetChancePerDay = 0.01,   -- Reduzir chance
maxChancePerCheck = 0.5,     -- Reduzir máximo

-- ❌ Comum
minGapBetween = "1h",        -- Muito curto
targetChancePerDay = 0.5,    -- Muito alto
```

### Problema: Posição específica não funciona

**Causa**: Position errada ou fora da zone

```lua
-- ✅ Correto - Position dentro da zone

    }
```

```lua
-- 1. Zone
local zone = Zone("area.name")

local raid = Raid("area.name", {

    allowedDays = {...},

    initialChance = 0.02,
    targetChancePerDay = 0.02,
    maxChancePerCheck = 0.8,
})

-- 3. Spawns
raid:addSpawnMonsters({...}):autoAdvance("delay")

-- 4. Register
raid:register()
```

**Tipos de Raid**:
- Boss Único (1 monstro)
- Boss Random (1 em positions aleatórias)
- Wave-Based (múltiplas phases)
- Invasão (multi-type sequences)

**Configuração**:
- `allowedDays`: Always all 7 days
- `minActivePlayers`: 0-5 típico
- `initialChance`: 0.01-0.05 (1-5%)
- `maxChancePerCheck`: 0.5-0.9 (50-90%)
- `minGapBetween`: "12h" a "36h"

**Boas Práticas**:
- ✅ Zone sempre definida
- ✅ autoAdvance entre spawns
- ✅ minActivePlayers apropriado
- ✅ Broadcast para feedback
- ✅ Register ao final
