## 📄 Visão Geral Resumida

Global event que distribui tokens (items) a jogadores online a cada 60 segundos. Calcula quantidade de tokens por minuto baseado em configuração por-hora, acumula resto em storage com precisão 10-milhões, e distribui quando atinge threshold. Sistema permite customizar ID do item token e usa mesmos filtros de IP/grupo.

## 🔧 Estrutura de Funcionalidades

### Configuração

```lua
config = {
  enabled = false,              -- Desabilitado por padrão
  storage = Storage.VipSystem.OnlineTokensGain,  -- Storage acúmulo
  checkDuplicateIps = false,    -- Validar IPs duplicados
  tokenItemId = 14112,          -- Bar of Gold
  interval = 60 * 1000,         -- 60 segundos
  tokensPerHour = {
    free = 5,                   -- 5 tokens/hora free
    vip = 10,                   -- 10 tokens/hora VIP
  },
  awardOn = 5,                  -- Distribuir quando acumular 5
}
```

### Cálculos

**`runsPerHour`**
- Cálculo: `3600 / (interval / 1000)`
- Com 60s: 60 execuções/hora

**`tokensPerRun(tokensPerHour)`**
- **Parâmetro**: tokensPerHour (5 ou 10)
- **Retorno**: tokens por execução
- **Fórmula**: `tokensPerHour / runsPerHour`
- Exemplo: 10 tokens/hora ÷ 60 = 0.1667 tokens/minuto

### Variáveis Globais

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `onlineTokensEvent` | GlobalEvent | Instância do evento |
| `runsPerHour` | number | 60 (com interval padrão) |

### GlobalEvent Hook

**`onlineTokensEvent.onThink(interval)`**
- **Parâmetro**: `interval` (60000ms)
- **Retorno**: `true`
- **Intervalo Execução**: 60 segundos
- **Lógica Detalhada**:
  1. Obtém jogadores online via `Game.getPlayers()`
  2. Se nenhum: retorna true
  3. Inicializa tabela `checkIp`
  4. Para cada jogador:
     a. Check: Se grupo > SENIORTUTOR → skip
     b. Obtém IP do jogador
     c. Check: Se IP é 0 ou já processado → skip
     d. Marca IP como processado
     e. Lê resto em storage: `remainder / 10000000`
     f. Calcula tokens: `tokensPerRun() + remainder`
     g. Escreve storage: `tokens * 10000000`
     h. Se tokens >= awardOn:
        - Calcula floor: `tokensMath = math.floor(tokens)`
        - Tenta adicionar item: `player:addItem(tokenItemId, tokensMath)`
        - Se sucesso:
          * Envia mensagem de parabéns
          * Reseta stor com resto: `(tokens - tokensMath) * 10000000`

### Pseudocódigo Detalhado

```lua
function onThink(interval)
  players = Game.getPlayers()
  if #players == 0 então retorna true end
  
  checkIp = {}
  for _, player in pairs(players) do
    -- Filtrar admin
    if player:getGroup():getId() > GROUP_TYPE_SENIORTUTOR então
      goto continue
    end
    
    -- Filtrar IP
    ip = player:getIp()
    if ip ~= 0 e (não checkDuplicateIps ou não checkIp[ip]) então
      checkIp[ip] = true
      
      -- Acúmulo
      remainder = math.max(0, player:getStorageValue(storage)) / 10000000
      tokens = tokensPerRun(player:isVip() ? 10 : 5) + remainder
      player:setStorageValue(storage, tokens * 10000000)
      
      -- Distribuição
      if tokens >= awardOn então
        tokensMath = math.floor(tokens)
        item = player:addItem(tokenItemId, tokensMath)
        
        if item então
          player:sendTextMessage(...)
          player:setStorageValue(storage, (tokens - tokensMath) * 10000000)
        end
      end
    end
    
    ::continue::
  end
  retorna true
end
```

### Item Padrão

| Campo | Valor | Descrição |
|-------|-------|-----------|
| **ID** | 14112 | Bar of Gold |
| **Tipo** | Item | Físico no inventário |
| **Customizável** | Sim | Via config.tokenItemId |

### Filtros Aplicados

| Filtro | Critério | Resultado |
|--------|----------|-----------|
| Grupo Admin | > SENIORTUTOR | Skip |
| IP Zero | = 0 | Skip |
| IP Duplicado | Em checkDuplicateIps | Skip opcional |

### Armazenamento com Precisão

| Operação | Fórmula | Propósito |
|----------|---------|-----------|
| Leitura | value / 10000000 | Evitar ponto flutuante |
| Escrita | value * 10000000 | Manter precisão 4 casas |
| Resto | (tokens - floor) * 10000000 | Próxima distribuição |
