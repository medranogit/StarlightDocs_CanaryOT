## 📄 Visão Geral Resumida

Global event extremamente simples que executa a cada 5 segundos e envia efeito visual de relâmpago (THUNDER) em 8 posições diferentes dentro de Dawnport. Sistema apenas itera array de posições e chama `sendMagicEffect()` em cada uma.

## 🔧 Estrutura de Funcionalidades

### Configuração de Posições

```lua
positions = {
  { x = 32054, y = 31889, z = 5 },
  { x = 32056, y = 31889, z = 5 },
  { x = 32063, y = 31880, z = 5 },
  { x = 32063, y = 31882, z = 5 },
  { x = 32073, y = 31889, z = 5 },
  { x = 32075, y = 31889, z = 5 },
  { x = 32063, y = 31899, z = 5 },
  { x = 32063, y = 31901, z = 5 },
}
```

**Padrão**: Todas posições em Z=5 (mesmo nível), X-Y formam cluster em Dawnport

### GlobalEvent Hook

**`dawnportMagicEffect.onThink(interval)`**
- **Parâmetro**: `interval` (5000ms)
- **Retorno**: `true`
- **Intervalo**: 5 segundos
- **Lógica**:
  1. Loop i = 1 até tamanho array
  2. Obtém posição do array
  3. Cria Position object
  4. Envia efeito THUNDER
  5. Retorna true

### Pseudocódigo

```lua
function onThink(interval)
  for i = 1, #positions do
    Position(positions[i]):sendMagicEffect(CONST_ME_THUNDER)
  end
  retorna true
end
```
