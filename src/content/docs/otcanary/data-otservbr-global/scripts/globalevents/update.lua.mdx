:::

## 📄 Visão Geral Resumida

Global event que executa uma única vez na inicialização do servidor e verifica flag `updated` em arquivo de controle externo. Se ativada, reseta posições X, Y, Z de todos os jogadores para 0 (teleportando ao templo), atualiza arquivo de controle resetando flag para false, e registra warning em log.

## 🔧 Estrutura de Funcionalidades

### Configuração Interna

| Propriedade | Valor | Descrição |
|-----------|-------|-----------|
| **Arquivo Controle** | `CORE_DIRECTORY/update.lua` | Localização da flag |
| **Flag** | `updated = true` | Indica execução de update |
| **Reset Post-Update** | `updated = false` | Estado após processamento |

### Variáveis Globais

| Variável | Tipo | Escopo | Descrição |
|----------|------|--------|-----------|
| `fileToUpdate` | string | Local | Caminho do arquivo controle |
| `updated` | boolean | Lido de arquivo | Flag de update ativo |

### GlobalEvent Hook

**`update.onStartup()`**
- **Parâmetro**: Nenhum
- **Retorno**: `true`
- **Disparo**: Uma única vez na inicialização
- **Lógica Detalhada**:
  1. Carrega arquivo de controle: `dofile(fileToUpdate)`
  2. Se flag `updated` desativada: retorna (nada a fazer)
  3. Se flag `updated` ativada:
     a. Executa SQL: `UPDATE players SET posx=0, posy=0, posz=0`
        - Reseta TODOS jogadores para posição (0,0,0)
        - Servidor teleporta automaticamente ao templo
     b. Abre arquivo para leitura
     c. Lê primeira linha
     d. Valida se contém "updated = true"
     e. Se encontrado:
        - Cria string de reset: "updated = false"
        - Abre arquivo para escrita (sobrescreve)
        - Escreve novo conteúdo
        - Fecha arquivo
        - Log warning com mensagem
     f. Log warning: "All players sent to temple"

### Pseudocódigo Detalhado

```lua
fileToUpdate = CORE_DIRECTORY .. "/update.lua"
dofile(fileToUpdate)  -- Carrega e executa arquivo

if updated então
  -- Reset posições no banco
  db.query("UPDATE `players` SET `posx`=0, `posy`=0, `posz`=0;")
  
  -- Lê arquivo para validar
  readFile = io.open(fileToUpdate, "r")
  if readFile então
    io.input(readFile)
    str = io.read()
    io.close(readFile)
    
    -- Procura por flag
    ae = string.match(str, "updated = true")
    if ae então
      -- Reseta arquivo
      updateFile = io.open(fileToUpdate, "w")
      io.output(updateFile)
      io.write("updated = false")
      io.close(updateFile)
      
      logger.warn("All players sent to temple...")
    end
  end
end
```
