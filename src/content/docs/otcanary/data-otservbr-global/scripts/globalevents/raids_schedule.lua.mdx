## 📄 Visão Geral Resumida

Global event que executa a cada 60 segundos (1 minuto) e verifica agenda de raids configurada. Suporta raids recorrentes por dia da semana (Tuesday-Sunday) e raid especial em data fixa (Halloween 31/10). Para cada raid no horário atualizado, verifica se já foi executada e dispara via `Game.startRaid()` se ainda não rodou, marcando com flag `alreadyExecuted` para evitar múltiplos dispares.

## 🔧 Estrutura de Funcionalidades

### Tabela de Agendamento

```lua
raidSchedule = {
  ["Tuesday"] = {
    ["16:00"] = { raidName = "Midnight Panther" },
  },
  ["Wednesday"] = {
    ["12:00"] = { raidName = "Draptor" },
  },
  ["Thursday"] = {
    ["19:00"] = { raidName = "Undead Cavebear" },
  },
  ["Friday"] = {
    ["06:00"] = { raidName = "Titanica" },
  },
  ["Saturday"] = {
    ["20:00"] = { raidName = "Draptor" },
  },
  ["Sunday"] = {
    ["15:00"] = { raidName = "Midnight Panther" },
    ["13:00"] = { raidName = "Orc Backpack" },
  },
  ["31/10"] = {
    ["16:00"] = { raidName = "Halloween Hare" },
  },
}
```

**Estrutura**
- **Chave Primária**: Dia semana string ("Tuesday") ou data especial ("31/10")
- **Chave Secundária**: Horário em formato "HH:MM"
- **Valor**: Table com `raidName` (string) e `alreadyExecuted` flag (added dinamicamente)

### Variáveis Globais

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `raidSchedule` | table | Mapeamento dia/hora → raid |
| `currentDayOfWeek` | string | Dia semana atual ("Tuesday", etc) |
| `currentDate` | string | Data atual em formato "31/10" |
| `raidsToSpawn` | table | Raids a verificar (pode ter até 2: dia semana + data especial) |

### Funções Globais

**`spawnRaidsEvent.onThink(interval, lastExecution, thinkInterval)`**
- **Parâmetros**:
  - `interval`: Intervalo em millisegundos (60000)
  - `lastExecution`: Timestamp última execução
  - `thinkInterval`: Intervalo pensamento
- **Retorno**: `true` (sempre)
- **Execução**: A cada 60 segundos
- **Lógica Detalhada**:
  1. Obtém dia da semana atual: `os.date("%A")`
  2. Obtém data atual em formato: `getRealDate()` 
  3. Inicializa array `raidsToSpawn` vazio
  4. Se `raidSchedule[currentDayOfWeek]` existe:
     - Adiciona à raidsToSpawn
  5. Se `raidSchedule[currentDate]` existe:
     - Adiciona à raidsToSpawn  
     - (Permite raid de data especial + dia semana simultaneamente)
  6. Se raidsToSpawn não vazio:
     - Para cada entrada em raidsToSpawn:
       a. Obtém horário atual: `getRealTime()` (retorna string "HH:MM")
       b. Obtém raid configurada para horário: `raidsToSpawn[i][getRealTime()]`
       c. Se raid existe e `alreadyExecuted` não setado:
          - Dispara raid: `Game.startRaid(raidName)`
          - Marca flag: `alreadyExecuted = true`
          - Evita re-disparo no mesmo horário
  7. Retorna true

### Pseudocódigo Detalhado

```lua
function onThink(interval, lastExecution, thinkInterval)
  currentDayOfWeek = os.date("%A")        -- "Tuesday", "Wednesday", etc
  currentDate = getRealDate()             -- "31/10", "25/12", etc
  raidsToSpawn = {}
  
  -- Verifica raids do dia da semana
  if raidSchedule[currentDayOfWeek] então
    raidsToSpawn[#raidsToSpawn + 1] = raidSchedule[currentDayOfWeek]
  end
  
  -- Verifica raids de data especial
  if raidSchedule[currentDate] então
    raidsToSpawn[#raidsToSpawn + 1] = raidSchedule[currentDate]
  end
  
  -- Processa raids programadas
  if #raidsToSpawn > 0 então
    for i = 1, #raidsToSpawn do
      currentRaidSchedule = raidsToSpawn[i][getRealTime()]  -- "16:00", "12:00", etc
      
      if currentRaidSchedule e não currentRaidSchedule.alreadyExecuted então
        Game.startRaid(currentRaidSchedule.raidName)
        currentRaidSchedule.alreadyExecuted = true
      end
    end
  end
  
  retorna true
end
```

**Total**: 7 dias × 1-2 raids/dia = ~8 spawns semanais

### Configuração de Verificação

| Propriedade | Valor | Descrição |
|-----------|-------|-----------|
| **Intervalo** | 60000 ms | 60 segundos entre verificações |
| **Frequência Máxima** | 1/minuto | Uma verificação por minuto |
| **Re-disparo** | Bloqueado | Flag `alreadyExecuted` previne duplicação |

### Funções Tempo

| Função | Retorno | Exemplo |
|--------|---------|---------|
| `os.date("%A")` | string | "Monday", "Tuesday", ... "Sunday" |

| `getRealTime()` | string | "16:00", "12:00", "19:30" |

### Fluxo de Integração

```
Server ativa globalevento a cada 60s
    ↓
Verifica dia semana (os.date)
    ↓
Verifica data especial (getRealDate)
    ↓
Coleta raids agendados em ambos
    ↓
Obtém horário atual (getRealTime)
    ↓
Procura raid para horário
    ↓
Se existe e não foi disparada:
    ├── Game.startRaid()
    └── Marca alreadyExecuted = true
    ↓
Próxima verificação em 60s
```
