## 📄 Visão Geral Resumida

Global event de inicialização que executa uma única vez ao ligar o servidor e carrega completo sistema de atributos/interações do mapa. Inclui carregamento de todas ações (baús, alavancas, portas), unicos nomeados, sinais/livros, items criados e atualização de chaves de quest. Também reseta storages globais de Ferumbras Ascension.

## 🔧 Estrutura de Funcionalidades

### Funções Locais

**`loadMapActionsAndUniques()`**
- **Parâmetro**: Nenhum
- **Retorno**: Void
- **Propósito**: Registra todas ações e eventos únicos do mapa
- **Carregamentos** (19 pares de ação+unique):
  1. ChestAction/ChestUnique - Baús
  2. CorpseAction/CorpseUnique - Corpos
  3. KeyDoorAction - Portas com chave (não tem unique)
  4. LevelDoorAction - Portas com nível (não tem unique)
  5. QuestDoorAction/QuestDoorUnique - Portas de quest
  6. ItemAction/ItemUnique - Items genéricos
  7. ItemUnmovableAction - Items fixos
  8. LeverAction/LeverUnique - Alavancas
  9. TeleportAction/TeleportUnique - Teletranportadores
  10. TeleportItemAction/TeleportItemUnique - Items teletransportadores
  11. TileAction/TileUnique - Ações de tile
  12. TilePickAction - Coleta de items
- **Funções Auxiliares**:
  - `CreateMapItem(CreateItemOnMap)` - Cria items no mapa
  - `updateKeysStorage(QuestKeysUpdate)` - Atualiza tracker de chaves

**`loadMapAttributes()`**
- **Parâmetro**: Nenhum
- **Retorno**: Void
- **Propósito**: Carrega todos atributos visuais e interativos
- **Chamadas**:
  1. Log debug: "Loading map attributes"
  2. `loadLuaMapSign(SignTable)` - Carrega sinais
  3. `loadLuaMapBookDocument(BookDocumentTable)` - Carrega livros
  4. `loadMapActionsAndUniques()` - Carrega ações/unicos
  5. Log debug: "Loaded all actions and uniques in the map"

**`resetGlobalStorages()`**
- **Parâmetro**: Nenhum
- **Retorno**: Void
- **Propósito**: Reseta storages globais de quests
- **Lógica**:
  1. Itera array `startupGlobalStorages`
  2. Para cada storage ID: `Game.setStorageValue(storageId, 0)`
  3. Limpa state de quests globais

**`resetFerumbrasAscendantQuestHabitats()`**
- **Parâmetro**: Nenhum
- **Retorno**: Void
- **Propósito**: Reseta habitats de Ferumbras Ascension quest
- **Lógica**:
  1. Itera array `Storage.Quest.U10_90.FerumbrasAscension.Habitats`
  2. Para cada habitat ID: `Game.setStorageValue(habitatId, 0)`
  3. Reseta state de todos habitats

### GlobalEvent Hook

**`mapAttributesLoader.onStartup()`**
- **Parâmetro**: Nenhum
- **Retorno**: Void
- **Disparo**: Executado UMA VEZ ao inicializar servidor
- **Sequência de Execução**:
  1. `loadMapAttributes()` - Carrega ações, unicos, sinais
  2. `resetGlobalStorages()` - Reseta storages globais
  3. `resetFerumbrasAscendantQuestHabitats()` - Reseta Ferumbras
