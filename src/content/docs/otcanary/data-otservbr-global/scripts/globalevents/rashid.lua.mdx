## 📄 Visão Geral Resumida

Gerencia NPC Rashid (famoso mercador viajante) que se aparece em cidades diferentes a cada dia da semana. Na inicialização do servidor cria Rashid no local do dia atual e, a cada meia-noite (00:01), teleporta para próxima cidade. Sistema envia notificações via webhook Discord após 1 minuto de espera.

### Funções Locais

**`rashidwebhook(message)`**
- **Parâmetros**: `message` (string de mensagem)
- **Retorno**: Void
- **Propósito**: Enviar notificação assíncrona via webhook Discord
- **Lógica**:
  1. Formata mensagem com emoji turbante: `:man_wearing_turban:`
  2. Envia para canal announcements via `Webhook.sendMessage()`
  3. Executada com 60s de delay via `addEvent()`

### GlobalEvent Hooks

**GlobalEvent: `rashid` (onStartup)**
- **Disparador**: Execução única na inicialização do servidor
- **Lógica**:
  1. Obtém dia semana atual: `os.date("*t").wday` (1=Sunday, 7=Saturday)
  2. Busca configuração em `positionByDay[today]`
  3. Se encontrada:
     a. Cria NPC "Rashid" na posição do dia
     b. Define posição master via `setMasterPos()`
     c. Envia efeito TELEPORT
     d. Log info com cidade
     e. Agenda webhook message com 60s de delay
  4. Se não encontrada: log warning

**GlobalEvent: `rashidSpawnOnTime` (onTime 00:01)**
- **Disparador**: Diariamente às 00:01
- **Lógica**:
  1. Obtém dia semana (para próxima localização)
  2. Obtém instância NPC "rashid"
  3. Se NPC existe:
     a. Envia efeito TELEPORT na posição antiga
     b. Teleporta para nova posição do dia
     c. Atualiza posição master
     d. Envia efeito TELEPORT na nova posição
     e. Log info "Rashid is traveling to `{city}s` location"
     f. Agenda webhook com 60s delay

### Pseudocódigo Detalhado

```lua
local today = os.date("*t").wday  -- 1-7 (Sun-Sat)
local config = positionByDay[today]

if config then
  rashid = Game.createNpc("Rashid", config.position)
  rashid:setMasterPos(config.position)
  rashid:getPosition():sendMagicEffect(CONST_ME_TELEPORT)
  
  message = "Rashid arrived at " .. config.city .. " today."
  addEvent(rashidwebhook, 60000, message)
end
```
