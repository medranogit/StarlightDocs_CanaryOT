# 🏗️ Arquitetura - Movements

Guia completo sobre a arquitetura e estrutura técnica dos scripts de **Movements** do servidor OTServ Canary. Entenda como os eventos de movimento são implementados, organizados e como criar novos.

---

## 🎯 Sobre essa Pasta de Scripts

<Card title="O que é?" icon="information">
A pasta `data-otservbr-global/scripts/movements/` contém todos os scripts **Lua** responsáveis pela lógica de **MoveEvents** no servidor OTServer Canary. Esses scripts controlam o que acontece quando um jogador se move para uma posição específica (pisar em um tile, entrar em uma área, usar um teleporte, etc). Cada movimento pode ter interações simples (teleporte direto) até mecânicas complexas (validações, efeitos, transformações).
</Card>

<Card title="Casos de Uso" icon="target">
Você utilizará essa pasta quando precisar:

- **Criar novos teleportes**: Implementar sistemas de transporte entre áreas
- **Estabelecer áreas restritas**: Validar level, premium, itens antes de permitir entrada
- **Gerar efeitos ao pisar**: Reproduzir sons, efeitos visuais, poderes ao entrar em tiles
- **Implementar puzzles de movimento**: Sequências de passos, dança, padrões
- **Controlar acesso a dungeons**: Verificar quest requirements antes de permitir entrada
- **Criar armadilhas**: Teleportes surpresa, dano ao pisar, transformações
- **Debug de problemas**: Investigar por que jogadores não conseguem passar em uma área
- **Balanceamento**: Ajustar requerimentos, destinos, efeitos de movimento
</Card>

<Card title="Estrutura da Pasta" icon="list">
A pasta `scripts/movements/` é organizada por **região/área** (ex: `oramond/`, `krailos/`, etc). Dentro de cada pasta, você encontrará scripts nomeados descritivamente:

- `*_teleport.lua` - Sistemas de teleportação diretos
- `*_entrance.lua` - Entrada bidirecional para áreas
- `*_movements.lua` - Múltiplos movimentos de uma área
- `*_puzzle.lua` - Puzzles baseados em movimento
- Outros tipos conforme necessário

**Tipo de MoveEvent**: `stepin` (quando jogador entra na posição)
</Card>

## 🧩 Componentes Principais

<Tabs>
<TabItem label="MoveEvent Object">

### Objeto MoveEvent

O objeto `MoveEvent` define o que acontece quando um jogador se move para uma posição.

```lua
local movement = MoveEvent()
movement:type("stepin")     -- Tipo de evento
movement:aid(4253)          -- Action ID ou
movement:uid(9056)          -- Unique ID

function movement.onStepIn(creature, item, position, fromPosition)
    -- Lógica aqui
    return true
end

movement:register()
```

**Tipos de MoveEvent:**

| Tipo | Descrição | Trigger |
|------|-----------|---------|
| `stepin` | Jogador entra na posição | Pisar no tile |
| `stepout` | Jogador sai da posição | Sair do tile |
| `equip` | Item é equipado | Equipar item |
| `deequip` | Item é desequipado | Remover equipamento |

<br />

**Identificadores:**
```lua
-- Por ActionID (AID)
movement:aid(4253)  -- Qualquer item com AID 4253

-- Por UniqueID (UID)
movement:uid(9056)  -- Item específico com UID 9056

-- Por ItemID
movement:itemid(1949)  -- Qualquer item de tipo 1949
```

</TabItem>

<TabItem label="Position">

### Objeto de Posição

Representa uma localização no mundo com coordenadas X, Y, Z.

```lua
local pos = Position(33539, 32014, 6)
-- ou
local targetPos = creature:getPosition()

-- Acessar coordenadas
print(pos.x, pos.y, pos.z)

-- Operações
local newPos = pos:moveRel(1, 0, 0)  -- Mover 1 tile leste
```

**Sistema de Coordenadas:**
- **X**: Eixo horizontal (Leste/Oeste)
- **Y**: Eixo vertical (Norte/Sul)
- **Z**: Altura/Nível (vários flares do mapa)

</TabItem>

### Objeto Creature

Representa o jogador ou criatura que está se movendo.

```lua
function movement.onStepIn(creature, item, position, fromPosition)
    -- Verificações de entidade
    if creature:isPlayer() then
        -- É um jogador
        local player = creature
        print(player:getName())
    end
end
```

**Propriedades Principais:**
```lua
creature:getName()           -- Nome do jogador
creature:getLevel()          -- Level do jogador

creature:getStorageValue(key) -- Ler storage
```

<TabItem label="Condiciones e Validações">

### Sistema de Validações

MoveEvents frequentemente precisam validar se jogador pode entrar.

```lua
function movement.onStepIn(creature, item, position, fromPosition)
    if not creature:isPlayer() then
        return true  -- Apenas jogadores
    end
    
    local player = creature
    
    -- Validar level
    if player:getLevel() < 100 then
        player:sendTextMessage(MESSAGE_ERROR, "Você precisa de level 100")
        player:teleportTo(fromPosition)
        return false
    end
    
    -- Validar premium
    if player:getPremiumDays() <= 0 then
        player:sendTextMessage(MESSAGE_ERROR, "Apenas premium!")
        player:teleportTo(fromPosition)
        return false
    end
    
    -- Verificar item
    if not player:hasItem(12345) then
        player:sendTextMessage(MESSAGE_ERROR, "Você precisa de um item específico")
        player:teleportTo(fromPosition)
        return false
    end
    
    -- Verificar quest
    if player:getStorageValue("quest_id") ~= 2 then
        player:sendTextMessage(MESSAGE_ERROR, "Complete a quest antes")
        player:teleportTo(fromPosition)
        return false
    end
    
    return true  -- Permitir entrada
end
```

### 2. Teleporte Bidirecional

```lua
local movement = MoveEvent()
movement:type("stepin")
movement:uid(9056)

function movement.onStepIn(creature, item, position, fromPosition)
    local targetPos
    
    -- Determinar para onde teleportar baseado na posição atual
    if position.x == 33338 then
        targetPos = Position(33574, 32224, 7)  -- De Candia para Feyrist
    else
        targetPos = Position(33338, 32125, 7)  -- De Feyrist para Candia
    end
    
    creature:teleportTo(targetPos)
    position:sendMagicEffect(CONST_ME_TELEPORT)
    targetPos:sendMagicEffect(CONST_ME_TELEPORT)
    return true
end

movement:register()
```

### 3. Bloqueador com Validação

```lua
local movement = MoveEvent()
movement:type("stepin")

    end
```

### 4. Múltiplos Destinos

```lua
local teleports = {
    [36489] = {x=33559, y=31970, z=12},
    [42626] = {x=33539, y=32014, z=6},
    [42627] = {x=33491, y=31985, z=7},
    [42630] = {x=33636, y=31891, z=6},
}

local movement = MoveEvent()
movement:type("stepin")

function movement.onStepIn(creature, item, position, fromPosition)
    local dest = teleports[item:getActionId()]
    if dest then
        creature:teleportTo(Position(dest.x, dest.y, dest.z))
        position:sendMagicEffect(CONST_ME_GREEN_RINGS)
        creature:say("Slrrp!")
        return true
    end
    return false
end

-- Registrar para várias AIDs
for aid, _ in pairs(teleports) do
    local mvmt = MoveEvent()
    mvmt:type("stepin")
    mvmt:aid(aid)
    mvmt.onStepIn = movement.onStepIn
    mvmt:register()
end
```

## 📍 Coordenadas e Posições

<Card title="Sistema de Coordenadas" icon="compass">

### Mapa 3D

O Tibia usa um sistema 3D com múltiplos "flares" (níveis):

```
Z=0-5:   Mundo superior/cidades
Z=6-7:   Primeiro nível subterrâneo
Z=8-9:   Segundo nível subterrâneo
Z=10+:   Níveis mais profundos
```

### Calculando Distâncias

```lua
function getDistance(pos1, pos2)
    local dx = math.abs(pos1.x - pos2.x)
    local dy = math.abs(pos1.y - pos2.y)
    local dz = math.abs(pos1.z - pos2.z)
    return math.max(dx, dy) + (dz > 0 and dz * 10 or 0)
end

-- Exemplo
local pos1 = Position(100, 100, 7)
local pos2 = Position(110, 105, 7)
local dist = getDistance(pos1, pos2)  -- ~10
```

### Áreas Retangulares

```lua
function isInArea(pos, topLeft, bottomRight)
    return pos.x >= topLeft.x and pos.x <= bottomRight.x and
           pos.y >= topLeft.y and pos.y <= bottomRight.y and
           pos.z == topLeft.z
end

-- Verificar se jogador está em dungeon específica
local dungeonTopLeft = Position(32100, 32100, 8)
local dungeonBottomRight = Position(32200, 32200, 8)

if isInArea(creature:getPosition(), dungeonTopLeft, dungeonBottomRight) then
    -- Jogador está no dungeon
end
```

## 🛠️ Como Criar um Novo Movement

<Card title="Guia Passo a Passo" icon="wrench">

### Passo 1: Criar o Arquivo

```bash
# Arquivo: {region}_{tipo}.lua ou {funcionalidade}.lua
# Exemplo: myregion_teleport.lua ou custom_puzzle.lua
```

### Passo 2: Criar Instância MoveEvent

```lua
local movement = MoveEvent()
movement:type("stepin")  -- ou "stepout", "equip", "deequip"
```

### Passo 3: Identificar o Trigger

```lua
-- Por ActionID (para items com AID)
movement:aid(4253)

-- Ou por UniqueID (para items específicos)
movement:uid(9056)

-- Ou por ItemID (para tipos de items)
movement:itemid(1949)
```

### Passo 4: Implementar a Função

```lua
function movement.onStepIn(creature, item, position, fromPosition)
    -- Lógica aqui
    return true  -- true = permitir, false = bloquear
end
```

### Passo 5: Adicionar Lógica

```lua
-- Exemplo completo: Teleporte com validação
function movement.onStepIn(creature, item, position, fromPosition)
    if not creature:isPlayer() then
        return true
    end
    
    local player = creature
    
    -- Validação
    if player:getLevel() < 100 then
        player:sendTextMessage(MESSAGE_ERROR, "Level 100 required")
        player:teleportTo(fromPosition)
        position:sendMagicEffect(CONST_ME_MAGIC_BLUE)
        return false
    end
    
    -- Executar
    player:teleportTo(Position(33636, 31891, 6))
    position:sendMagicEffect(CONST_ME_TELEPORT)
    player:say("Slrrp!")
    
    return true
end
```

### Passo 6: Registrar

```lua
movement:register()
```

## 🔧 Guia de Troubleshooting

<Card title="Problemas Comuns" icon="bug">

### Problema: Movement não é acionado

**Causa:** Item não tem ActionID/UniqueID configurado corretamente  
**Solução:** Verificar que AID/UID no script corresponde ao XML/database

```lua
-- Verificar qual AID está sendo usado
movement:aid(4253)  -- Garantir que valor é o correto
```

### Problema: Jogador fica preso/bug

**Causa:** Teleporte falhou ou script não retorna valor correto  
**Solução:**
```lua
function movement.onStepIn(creature, item, position, fromPosition)
    if not creature:isPlayer() then
        return true  -- Deixar não-jogadores passar
    end
    
    -- Sempre retornar valor booleano
    return true  -- ou false para bloquear
end
```

### Problema: Validação não funciona

**Causa:** Lógica condicional incorreta  
**Solução:** Verificar player:getLevel() e outras propriedades

```lua
-- ❌ Errado - creature pode não ser player
if creature:getLevel() < 100 then
    -- ...
end

-- ✅ Correto
if creature:isPlayer() then
    local player = creature
    if player:getLevel() < 100 then
        -- ...
    end
end
```

### Problema: Múltiplos teleportes quebram

**Causa:** Usando mesma variável para múltiplos registros  
**Solução:** Usar função factory ou tabela diferente por registro

```lua
-- ✅ Correto - cada AID tem seu próprio closure
local function createTeleport(aid)
    local movement = MoveEvent()
    movement:type("stepin")
    movement:aid(aid)
    
    function movement.onStepIn(creature, item, position, fromPosition)
        -- 'aid' é diferente para cada chamada
        local dest = teleportMap[aid]
        if dest then
            creature:teleportTo(Position(dest.x, dest.y, dest.z))
            return true
        end
        return false
    end
    
    movement:register()
end
```

### Problema: Efeito não aparece

**Causa:** Position/MagicEffect inválido  
**Solução:**
```lua
-- Verificar que position é válida
if position then
    position:sendMagicEffect(CONST_ME_TELEPORT)
end

-- Ou usar creature
creature:getPosition():sendMagicEffect(CONST_ME_TELEPORT)
```

### Problema: Jogador volta para posição anterior

**Causa:** Função retorna `false` ou teleportação falha  
**Solução:** Garantir return `true` e posição válida

```lua
function movement.onStepIn(creature, item, position, fromPosition)
    if not validarAcesso(creature) then
        creature:teleportTo(fromPosition)  -- Voltar
        return false
    end
    
    creature:teleportTo(targetPos)
    return true  -- Permitir movimento
end
```

**Estrutura Básica:**
```lua
local movement = MoveEvent()
movement:type("stepin")
movement:aid(123)  -- ou uid(456) ou itemid(789)

function movement.onStepIn(creature, item, position, fromPosition)
    -- Lógica aqui
    return true
end

movement:register()
```

**MoveEvent Types:**
- `stepin`: Quando entra na posição
- `stepout`: Quando sai da posição
- `equip`: Quando equipa item
- `deequip`: Quando remove item

**Identificadores:**
- `aid(XXX)`: ActionID (item com AID específico)
- `uid(XXX)`: UniqueID (item único específico)
- `itemid(XXX)`: ItemID (tipo de item)

**Função Principal:**
```lua
function movement.onStepIn(creature, item, position, fromPosition)
    -- creature: Jogador/criatura
    -- item: Item que acionou
    -- position: Posição atual
    -- fromPosition: Posição anterior
    return true/false
end
```

**Propriedades Principais:**
- `creature:isPlayer()`: É jogador?
- `creature:getLevel()`: Level atual
- `creature:getPremiumDays()`: Dias premium
- `creature:hasItem(id)`: Tem item?
- `creature:getStorageValue(key)`: Ler storage
- `creature:getVocation()`: Vocação

**Teleportação:**
```lua
creature:teleportTo(Position(x, y, z))
creature:teleportTo(fromPosition)  -- Voltar
```

**Efeitos:**

```lua
position:sendMagicEffect(CONST_ME_TELEPORT)
```
