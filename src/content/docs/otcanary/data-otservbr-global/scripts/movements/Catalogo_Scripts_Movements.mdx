## 📝 Guia de Campos

| Campo | Descrição |
|-------|-----------|
| **Caminho** | Localização do arquivo no repositório |
| **Tipo** | Classificação (Movement - MoveEvent stepin) |
| **AIDs/UIDs** | Action IDs ou Unique IDs dos items/tiles |
| **Função** | Descrição breve da funcionalidade |
| **Destinos** | Coordenadas X, Y, Z de origem e destino |
| **Efeito** | Efeitos visuais (CONST_ME_*) aplicados |
| **Som** | Som reproduzido ao usar o movimento |
