## 📄 Visão Geral do Código Resumo Executivo

O arquivo `monk_npcs_step_in.lua` implementa um sistema de proteção de portão para Blue Valley que restringe acesso ao local sagrado para monges. Registra MoveEvent em 10 posições de portão (2 linhas de 5 posições cada) que valida vocação ao entrar. Se o jogador não for monge (baseId ≠ VOCATION.BASE_ID.MONK), é teleportado imediatamente para uma posição segura de retorno. Se for monge, o script checa a direção do movimento (entrada de cima via linha Y=31458, ou entrada de baixo via linha Y=31459) e dispara mensagens de boas-vindas de NPCs registrados ("Saih The Guardian" or "Chesa The Guardian"). O sistema é elegante ao centralizar a lógica de restrição em um único MoveEvent multi-posição.

### Funções Locais

#### `shouldSayMessage(pos, fromPos)`

```lua
local function shouldSayMessage(pos, fromPos)
	if pos.y == 31458 then
		return fromPos.y < pos.y -- From above
	elseif pos.y == 31459 then
		return fromPos.y > pos.y -- From below
	end
	return false
end
```

**Propósito**: Determinar se monge entrou pela primeira vez (direção correta).

**Lógica**:
- Se posição é 31458 (entrada de cima): retorna `true` se `fromPos.y < 31458`
- Se posição é 31459 (entrada de baixo): retorna `true` se `fromPos.y > 31459`
- Senão: retorna `false`

**Efeito**: Garante que mensagens só trigguem em primeira entrada, não em saída passiva.

### Funções Globais

#### `monkGate.onStepIn()`

```lua
function monkGate.onStepIn(creature, item, position, fromPosition)
```

**Propósito**: Validar acesso de monges e bloquear não-monges.

**Parâmetros**:
- `creature` (Creature): Criatura entrando
- `item` (Item): Item na posição (não utilizado)
- `position` (Position): Posição do portão
- `fromPosition` (Position): Posição anterior da criatura

**Retorno**: `boolean` - `true` sempre

**Lógica**:

1. **Conversão para Player**:
   - Converte creature para player
   - Se not player: retorna `true` (permite passage)

2. **Validação de Vocação**:
   - Obtém baseId da vocação
   - Compara com VOCATION.BASE_ID.MONK
   - Se não for monge:
     - Teleporta para `targetPosition`
     - Usa forceMove = true

3. **Se Monge + Entrada Válida**:
   - Checa `shouldSayMessage(position, fromPosition)`
   - Se true:
     - Itera `npcMessages`
     - Para cada NPC listado:
       - Obtém NPC por name
       - Se NPC existe: faz say da mensagem com TALKTYPE_MONSTER_SAY

4. **Return**:
   - Sempre retorna `true`

### Registro do MoveEvent

```lua
for _, pos in ipairs(gatePositions) do
	monkGate:position(pos)
end
monkGate:register()
```
