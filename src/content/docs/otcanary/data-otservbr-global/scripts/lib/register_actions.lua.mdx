## 📄 Visão Geral Resumida

Arquivo de biblioteca monolítico (1177 linhas) que registra ações genéricas aplicáveis a muitos items do servidor. Contém arrays de IDs de items destruíveis (43 tipos de buracos, 2 trituradores), configurações de quests específicas (8 cristais Secret Library, 80+ items cortáveis), funções locais para transformação/remoção de items, e implementação de evento `onDestroyItem` que processa cortes, queimadas, quests condicionales.

### Funções Locais

**`revertItem(position, itemId, transformId)`**
- **Parâmetro**: posição, ID item original, ID transformação
- **Ação**: Obtém item no tile e faz transformação
- **Lógica**: Tile → getItemById → transform(new_id)

**`removeRemains(toPosition)`**
- **Parâmetro**: posição
- **Ação**: Remove resíduos Item 3133
- **Uso**: Limpeza pós-evento

**`revertCask(position)`**
- **Parâmetro**: posição
- **Ação**: Transforma cask 3134 → 4848
- **Efeito**: Envia CONST_ME_MAGIC_GREEN

**`addFerumbrasAscendantReward(player, target, toPosition)`**
- **Parâmetro**: jogador, item alvo, posição
- **Ação**: Verifica se é recompensa Ferumbras (22172, AID 53803)
- **Lógica**:
  1. Valida item ID e action ID
  2. Se jogador não tem recompensa (storage < 1)
  3. Adiciona item 22170 ao jogador
  4. Marca como recebido

### Evento Principal

**`onDestroyItem(player, item, fromPosition, target, toPosition, isHotkey)`**
- **Parâmetro**: jogador, ferramenta, pos origem, item alvo, pos destino, hotkey flag
- **Retorno**: boolean (processado sim/não)
- **Validações**:
  1. Target deve ser item
  2. Target não pode ter UNIQUE_ID ou ACTION_ID
  3. toPosition não pode ser CONTAINER_POSITION
  4. Damage da ferramenta deve exceder limiar (10)
  5. Chance roll baseada em ataque da ferramenta (1-80)
- **Lógica Detalhada**:
  1. Calcula destroy ID via `cutItems` ou ItemType
  2. Se ID = 0 e não é removível (25798/25800): retorna false
  3. Calcula watt da ferramenta
  4. Roll de chance: `random <= watt`
  5. Se sucesso:
     - **Spider Cult**: Se egg 233 → incrementa storage e spawna Giant Spider
     - **Container items**: Move items internos para posição final
     - **Fluid**: Se tem fluid → cria vaso com fluid

### Pseudocódigo Parcial

```lua
function onDestroyItem(player, item, fromPosition, target, toPosition, isHotkey)
  -- Validações
  if não target ou não target:isItem() então
    retorna false
  end
  
  if target:hasAttribute(UNIQUE_ID ou ACTION_ID) então
    retorna false
  end
  
  -- Calcula destroy ID
  destroyId = cutItems[target.itemid] or ItemType(target.itemid):getDestroyId()
  
  -- Chance de sucesso
  watt = ItemType(item.itemid):getAttack()
  if math.random(1, 80) <= (watt ou 10) então
    -- Aplica efeitos (Spider Cult, items container, fluids)
  end
  
  retorna true
end
```
