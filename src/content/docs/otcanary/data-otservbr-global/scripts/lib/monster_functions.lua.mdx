## 📄 Visão Geral Resumida

Arquivo de biblioteca que estende classe Monster com método `handleCobraOnSpawn()`. Método verifica se Flask global de Cobra está em cooldown via storage timestamp, e se assim, reduz HP máximo para 75% e aplica efeito visual verde ao aparecer.

## 🔧 Estrutura de Funcionalidades

### Funções Globais

**`Monster:handleCobraOnSpawn()`**
- **Contexto**: Método de instância de Monster
- **Parâmetro**: Implícito `self` (instância de monster)
- **Retorno**: Void
- **Chamada**: Na criação/spawn de Cobra
- **Lógica Detalhada**:
  1. Obtém storage global `Global.Storage.CobraFlask`
  2. Compara com tempo atual via `os.time()`
  3. Se storage >= os.time() (Flask ainda em cooldown):
     a. Reduz saúde para 75% do máximo
        - `self:setHealth(self:getMaxHealth() * 0.75)`
     b. Envia efeito verde ao spawn
        - `self:getPosition():sendMagicEffect(CONST_ME_GREEN_RINGS)`
  4. Caso contrário (cooldown expirou):
     a. Invalida storage com -1
        - `Game.setStorageValue(Global.Storage.CobraFlask, -1)`

### Pseudocódigo Detalhado

```lua
function Monster:handleCobraOnSpawn()
  cobraFlaskTime = Game.getStorageValue(Global.Storage.CobraFlask)
  
  if cobraFlaskTime >= os.time() então
    -- Flask em cooldown: cobra enfraquecida
    self:setHealth(self:getMaxHealth() * 0.75)
    self:getPosition():sendMagicEffect(CONST_ME_GREEN_RINGS)
  else
    -- Flask expirou: limpa storage
    Game.setStorageValue(Global.Storage.CobraFlask, -1)
  end
end
```

## 📊 Dados Técnicos

### Condições de Spawn

| Condição | Ação | Efeito |
|----------|------|--------|
| Flask em cooldown | Reduz HP 75% | Cobra enfraquecida |
| Flask expirado | Invalida storage | Cobra normal |
| Novo spawn | Verifica sempre | Aplicado a cada spawn |

### Sistema de Storage

| Storage | Tipo | Descrição |
|---------|------|-----------|
| `Global.Storage.CobraFlask` | Timestamp | Unix time de expiração |
| Valor -1 | Flag | Storage inválido/expirado |
| Valor > 0 | Timestamp | Contém tempo de cooldown |

### Efeitos Visuais

| Efeito | Constante | Condição |
|--------|-----------|----------|
| GREEN_RINGS | CONST_ME_GREEN_RINGS | Flask ativo |

### APIs Utilizadas

- Monster: `setHealth()`, `getMaxHealth()`, `getPosition()`
- Position: `sendMagicEffect()`
- Game: `getStorageValue()`, `setStorageValue()`
- Lua: `os.time()`

### Integração

Método deve ser chamado em NPC ou script de Cobra quando spawna:
```lua
local cobra = Game.createMonster("Cobra", position)
if cobra then
  cobra:handleCobraOnSpawn()
end
```
