## ⚙️ Arquivo de Funções

<Card title="Integration Functions" icon="cog">

### others/functions.lua

**Localização**: `data-otservbr-global/startup/others/functions.lua`

| Propriedade | Valor |
|---|---|
| **Tipo** | Módulo de Funções Globais |
| **Linhas** | ~200 |
| **Responsabilidade** | Implementar e registrar 6 funções globais |
| **Chamado Por** | others/load.lua |
| **Depende De** | Todas as 16 tabelas de Phase 1 |

**Funções Implementadas**:

1. **CreateMapItem(itemId, position, count)**
   - Cria items no mapa dinamicamente
   - Uso: Spawnar rewards, items especiais

2. **loadLuaMapAction(table)**
   - Registra todos action IDs de uma tabela
   - Uso: Disponibilizar ItemAction, ChestAction, etc para scripts

3. **loadLuaMapUnique(table)**
   - Registra todos unique IDs de uma tabela
   - Uso: Registrar IDs únicos de itens/criaturas

4. **loadLuaMapSign(table)**
   - Carrega textos de signs/murais
   - Uso: Display de mensagens no mapa

5. **loadLuaMapBookDocument(table)**
   - Carrega conteúdo de livros/documentos
   - Entrada: BookDocumentTable
   - Uso: Disponibilizar textos de livros para players

6. **updateKeysStorage(player)**
   - Migra storage keys de players antigos para novos
   - Usa: QuestKeysUpdate table
   - Crítico: Garante compatibilidade de dados

**Documentação**: Ver [functions.lua.mdx](./functions.lua.mdx)

</Card>

## 🎯 Guia de Uso

<Card title="Como Usar Este Catálogo" icon="bulb">

### Para Entender o Sistema
1. Leia [Arquitetura_Startup.mdx](./Arquitetura_Startup.mdx)
2. Estude o fluxo em "Relações Entre Arquivos"
3. Analise os 3 arquivos de orquestração

### Para Trabalhar com Tabelas Específicas
1. Encontre a tabela neste catálogo
2. Clique no link para arquivo .mdx detalhado
3. Entenda a estrutura e padrão
4. Veja exemplos práticos

### Para Adicionar Nova Funcionalidade
1. Leia Arquitetura (Estendendo o Sistema)
2. Escolha a categoria apropriada
3. Siga o padrão do arquivo mais similar
4. Atualize tables/load.lua se necessário
5. Considere storage_keys_update.lua se usar quests

### Para Debug
1. Verifique qual arquivo está falhando
2. Consulte seção de Troubleshooting em Arquitetura
3. Valide sintaxe e paths
4. Garanta ordem correta de carregamento

</Card>
