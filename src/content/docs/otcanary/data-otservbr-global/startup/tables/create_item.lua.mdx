## 📋 Resumo Executivo

<Card title="O que este arquivo faz?" icon="info">

Tabela que define **items a serem criados automaticamente**:

**Propósito**:
- Evitar editar XML do mapa
- Criar items dinamicamente via Lua
- Útil para items reutilizáveis em múltiplos locais

**Estrutura**:
```lua
[itemId] = {
    itemPos = {
        {x = xxxxx, y = xxxxx, z = x},
        {x = xxxxx, y = xxxxx, z = x},
        -- mais posições
    }
}
```

**Exemplo**: Criar 6 picaretas em locais diferentes para The Explorer Society quest.

## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### CreateItemOnMap

**Propósito**: Definir items a criar automaticamente

**Estrutura**:
```lua
CreateItemOnMap = {
    [itemId] = {
        itemPos = {
            {x = xxxxx, y = xxxxx, z = x},
            {x = xxxxx, y = xxxxx, z = x},
            -- múltiplas posições
        }
    }
}
```

**Campos**:
- `itemId`: ID do item a criar
- `itemPos`: Array de posições `{x, y, z}`

**Características**:
- Cria **um único item** em cada posição
- Sem action/unique ID (item simples)
- Sem verificação de duplicatas (sempre cria)
- Sem container (items no chão)

</Card>

## 🔑 Padrões de Uso

<Card title="Boas Práticas" icon="star">

### Ao Adicionar Novo Item

1. **Conhecer o item**:
   - Item ID deve existir
   - Deve ser um item válido

2. **Determinar posições**:
   - Validar coordenadas X, Y, Z
   - Verificar que tile existe no mapa
   - Não usar PZ (Protected Zones)

3. **Documentar**:
   - Adicionar comentário com quest/purpose
   - Linkar script relevante

4. **Testar**:
   - Startup completa sem erro
   - Item aparece na posição certa
   - Pode ser usado/pego por player

### Evitar

- ❌ Item IDs inválidos
- ❌ Posições fora do mapa
- ❌ Duplicar posições (mesmo item 2x)
- ❌ Items em PZ

</Card>

## 🎛️ Integração com Funções

<Card title="Como os Scripts Usam" icon="link">

**Em `functions.lua`**:
```lua
function CreateMapItem(tablename)
    for index, value in pairs(tablename) do
        for i = 1, #value.itemPos do
            local tile = Tile(value.itemPos[i])
            if tile then
                if tile:getItemCountById(index) == 0 then
                    Game.createItem(index, 1, value.itemPos[i])
                end
            end
        end
    end
    logger.debug("Created all items in the map")
end
```

**Lógica**:
1. Para cada itemId
2. Para cada posição
3. Verifica se item já existe (evita duplas)
4. Se não existe, cria

**Chamada no startup**:
```lua
CreateMapItem(CreateItemOnMap)
```

</Card>

## ⚠️ Diferenças Importantes

<Card title="CreateItemOnMap vs ChestAction" icon="alert">

| Aspecto | CreateItemOnMap | ChestAction |
|---------|---|---|
| **Propósito** | Items simples | Items com action/reward |
| **Complexidade** | Mínima | Alta |
| **Tem Action ID** | Não | Sim |
| **Tem Reward** | Não | Sim |
| **Tem Storage** | Não | Sim |
| **Duplicado Se Existe** | Não (skip) | Sim (overwrite) |
| **Uso** | Items básicos | Chests, baús |

</Card>
