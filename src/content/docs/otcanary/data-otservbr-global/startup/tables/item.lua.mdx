## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### ItemAction

**Propósito**: Definir items interativos com action IDs

**Estrutura**:
```lua
ItemAction = {
    [actionId] = {
        itemId = ITEM_ID ou false,
        itemPos = {
            {x = xxxxx, y = xxxxx, z = xx},
            -- múltiplas posições possíveis
        }
    }
}
```

**Campos**:
- `actionId`: ID único do action (100-2300+)
- `itemId`: Tipo visual do item (ou false)
- `itemPos`: Array de posições no mapa

**Range de IDs**:
- Começa em 100
- Vai até 2300+
- Centenas de entradas
- Multiple quests

</Card>

## 🎛️ Integração com Sistema

<Card title="Como Funciona" icon="link">

**Em `item.lua`**:
```lua
ItemAction = {
    [2000] = {
        itemId = 5463,
        itemPos = { {x = 32741, y = 31710, z = 7} }
    }
}
```

**Em action script** (`actions/quests/questname.lua`):
```lua
local questItemAction = Action()
questItemAction:id(2000)

function questItemAction.onUse(player, item, fromPos, target, toPos)
    local storageKey = Storage.Quest.QuestName.QuestItem
    
    -- Verifica se já fez
    if player:getStorageValue(storageKey) > 0 then
        player:sendCancelMessage("Already used!")
        return true
    end
    
    -- Executa quest logic
    player:setStorageValue(storageKey, 1)
    player:sendTextMessage(MESSAGE_STATUS, "Quest item activated!")
    
    return true
end

questItemAction:register()
```

**Fluxo**:
1. Item na posição `{x, y, z}`
2. Player pisa/usa (action 2000)
3. Script executa
4. Progride quest

</Card>
