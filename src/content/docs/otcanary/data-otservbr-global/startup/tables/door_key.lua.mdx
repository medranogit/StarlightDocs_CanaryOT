## 📋 Resumo Executivo

<Card title="O que este arquivo faz?" icon="info">

Configuração de **portas com sistema de chaves**:

**Mecanismo**:
- Player tem chave item específica
- Tenta usar/pisar na porta
- Script verifica storage key
- Se possui chave, abre; senão, nega acesso

**Estrutura**:
```lua
[storageKeyId] = {
    itemId = false,
    itemPos = { {x, y, z}, ... }
}
```

**Exemplo**: Portas da Draconia quest com 8 chaves diferentes (3001-3008)

</Card>

```
    KeyDoorAction     Player Storage

         │                │
         ├─ storageKeyId  ├─ tem Storage.Quest.Key.ID3001?
         ├─ itemId        ├─ player:getStorageValue(...)
         ├─ itemPos       └─ Se sim → abre
         └─ Script checa
```

**Fluxo**:
1. Player pisa/usa porta
2. Script lê Storage.Quest.Key.ID3001
3. Se > 0 (player tem chave), porta abre
4. Senão, nega acesso

## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### KeyDoorAction

**Propósito**: Definir portas com sistema de chave

**Estrutura**:
```lua
KeyDoorAction = {
    [storageKeyId] = {
        itemId = false,  -- Sempre false para portas
        itemPos = {
            {x = xxxxx, y = xxxxx, z = xx},
            -- múltiplas posições possíveis
        }
    }
}
```

**Campos**:
- `storageKeyId`: Storage key que controla acesso
- `itemId`: Sempre `false` (porta sem item visible)
- `itemPos`: Posições da porta no mapa

**Padrão Storage Keys**:
- `Storage.Quest.Key.ID3001` a `Storage.Quest.Key.ID3008`
- Nomeados por quest (Draconia, etc)

</Card>

## 🔑 Padrões de Uso

<Card title="Boas Práticas" icon="star">

### Sistema de Storage Keys

```lua
-- Storage Keys são definidos em constantes
Storage.Quest.Key = {
    ID3001 = numero_unico,
    ID3002 = numero_unico,
    -- ... até ID3012, ID3033, etc
}

-- Usados em portas
[Storage.Quest.Key.ID3001] = {
    itemId = false,
    itemPos = { {x, y, z} }
}

-- Verificados em scripts
if player:getStorageValue(Storage.Quest.Key.ID3001) > 0 then
    -- player tem chave, abre porta
end
```

### Ao Adicionar Nova Porta de Chave

1. **Criar storage key** em constants
   - `Storage.Quest.Key.IDXXXX`

2. **Adicionar entrada**:
   ```lua
   [Storage.Quest.Key.IDXXXX] = {
       itemId = false,
       itemPos = { {x, y, z} }
   }
   ```

3. **Documentar quest**:
   - Adicionar comentário
   - Referenciar quest/key item

4. **Testar**:
   - Player pisa na porta
   - Sem chave = blocked
   - Com chave = open

</Card>

```lua

    local player = creature:getPlayer()
    if not player then return true end
    
    -- Pega door action ID
    local doorActionId = item:getAttribute(ITEM_ATTRIBUTE_ACTIONID)
    
    -- Verifica storage key
    if player:getStorageValue(doorActionId) > 0 then
        -- Abre porta
        door:open(player)
    else
        -- Nega acesso

    end
```

## 📚 Estrutura de Quests com Chaves

<Card title="Exemplo: Draconia Quest" icon="book">

**Draconia usa 8 portas com chaves diferentes**:

```
7 chaves (3001-3008) para abrir 8 portas
│
├─ Key 4182 → Door ID3001 → z=7
├─ Key 4183 → Door ID3002 → z=7
├─ Key 4184 → Door ID3003 → z=7
├─ Key 4185 → Door ID3004 → z=6
├─ Key 4186 → Door ID3005 → z=6
├─ Key 4187 → Door ID3006 → z=6
├─ Key 4188 → Door ID3007 → z=4
└─ Key 4189 → Door ID3008 → z=1
```

**Progressão**:
1. Player obtém chave após resolver puzzle
2. Encontra porta correspondente
3. Storage key traceia se destrancou
4. Próxima chave desbloqueia próxima porta
