## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### TeleportAction

**Propósito**: Definir teleportes mágicos no mapa

**Estrutura**:
```lua
TeleportAction = {
    [actionId] = {
        itemId = VISUAL_ID ou false,
        itemPos = {
            {x = xxxxx, y = xxxxx, z = xx},
            -- múltiplas posições possíveis
        }
    }
}
```

**Campos**:
- `actionId`: ID único (variável, não sequencial)
- `itemId`: Visual do teleporte (spell effect ou false)
- `itemPos`: Posições do glifo

**Range de IDs**:
- 4253: Um teleporte
- 4905-4906: Dupla de teleportes
- 5517-5518: Outro par
- 14562+: Teleportes avançados

</Card>

## 🎛️ Integração com Sistema

<Card title="Como Funciona" icon="link">

**Em `teleport.lua`**:
```lua
TeleportAction = {
    [4905] = {
        itemId = false,
        itemPos = { {x = 32352, y = 31654, z = 6} }
    }
}
```

**Em action script** ou movimento:
```lua
-- Quando player pisa (onStepIn)
function onStepIn(creature, item, position, ...)
    if not creature:isPlayer() then
        return true
    end
    
    local player = creature:getPlayer()
    local actionId = item:getAttribute(ITEM_ATTRIBUTE_ACTIONID)
    
    -- Define destino
    local destination = getTeleportDestination(actionId)
    if not destination then return false end
    
    -- Teleporta
    position:sendMagicEffect(CONST_ME_TELEPORT)
    player:teleportTo(destination)
    destination:sendMagicEffect(CONST_ME_TELEPORT)
    
    return true
end

function getTeleportDestination(actionId)
    local destinations = {
        [4905] = Position(32500, 31700, 6),  -- Portal B
        [4906] = Position(32352, 31654, 6),  -- Portal A
        -- ... mais destinos
    }
    return destinations[actionId]
end
```
