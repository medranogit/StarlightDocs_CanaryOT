Arquivo de tabela responsável por **items teleportadores** - objetos que transportam o player para outra localização quando usados.

## 📋 Resumo Executivo

<Card title="O que este arquivo faz?" icon="info">

**Escopo**: Items teleportadores

**Diferença**:
- `teleport_item.lua`: Items (mochila, podem ir com player)
- `teleport.lua`: Féromonas mágicas (área do mapa)

**Estrutura**:
```lua
[actionId] = {
    itemId = false,
    itemPos = { {x, y, z} }
}
```

**Range**: 15001-20000 action IDs
**Uso**: Shrines, portais de quest, teleportes rápidos

</Card>

## 🏗️ Estrutura de Funcionalidades

<Card title="Arquitetura de Teleportes Item" icon="layers">

```
┌─────────────────────────────┐
│  TELEPORTS VIA ITEM         │
└────────────┬────────────────┘
             │
    ┌────────┴────────┐
    │                 │
    ▼                 ▼
Item Position      Destination
(Pickup area)      (where to go)
    │                 │
Player usa item      ├─ Calculate destination
(action 15001+)      ├─ Teleport player
                     └─ Remove from original
```

**Fluxo**:
1. Item em localização X (shrine)
2. Player pega item
3. Player usa (teleport)
4. Transportado para Y (outra shrine)
5. Se pegar novamente, usa

</Card>

## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### TeleportItemAction

**Propósito**: Definir items teleportadores

**Estrutura**:
```lua
TeleportItemAction = {
    [actionId] = {
        itemId = false,  -- Geralmente false
        itemPos = {
            {x = xxxxx, y = xxxxx, z = xx},
            -- múltiplas posições possíveis
        }
    }
}
```

**Campos**:
- `actionId`: ID único (15001-20000)
- `itemId`: false (item invisível/teleporte)
- `itemPos`: Posições de origem

**Range de IDs**:
- 15001-20000 (5,000 de range)
- Dezenas de teleportes
- Shrine-based teleports

</Card>

## 🎛️ Integração com Sistema

<Card title="Como Funciona" icon="link">

**Em `teleport_item.lua`**:
```lua
TeleportItemAction = {
    [15001] = {
        itemId = false,
        itemPos = { {x = 32369, y = 32240, z = 7} }
    }
}
```

**Em action script** (`actions/other/teleport_item.lua`):
```lua
local teleportItemAction = Action()
teleportItemAction:id(15001)

function teleportItemAction.onUse(player, item, fromPos, target, toPos)
    -- Define destino baseado no item/action
    local destination = getTeleportDestination(item:getAttribute(ITEM_ATTRIBUTE_ACTIONID))
    
    if not destination then
        return false
    end
    
    -- Effect de saída
    fromPos:sendMagicEffect(CONST_ME_TELEPORT)
    
    -- Teleporta player
    player:teleportTo(destination)
    
    -- Effect de chegada
    destination:sendMagicEffect(CONST_ME_TELEPORT)
    
    return true
end

function getTeleportDestination(actionId)
    -- Busca configuração de destino
    local destinations = {
        [15001] = Position(32400, 32300, 7),  -- Shrine entrance
        [15002] = Position(32500, 32300, 7),  -- Another shrine
        -- ... mais destinos
    }
    return destinations[actionId]
end

teleportItemAction:register()
```
