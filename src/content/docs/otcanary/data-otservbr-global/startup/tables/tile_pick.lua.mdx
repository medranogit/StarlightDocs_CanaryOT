## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### TilePickAction

**Estado**: Template com action ID 101

```lua
TilePickAction = {
    [101] = {  -- Action ID 101 (fixo e exclusivo)
        itemId = false,
        itemPos = {
            {x = xxxxx, y = xxxxx, z = xx},
            -- múltiplas posições
        }
    }
}
```

**Campos**:
- `101`: Action ID fixo (reservado)
- `itemId`: false (itens invisíveis)
- `itemPos`: Posições colhíveis

**Característica Única**: 
- Todos os pickables usam action ID 101
- Multiple positions para mesma quest

</Card>

## 🔑 Padrão de Uso

<Card title="Boas Práticas" icon="star">

### Ao Adicionar Item Colhível

1. **Usar Action ID 101** (fixo):
   ```lua
   [101] = {
       itemId = false,
       itemPos = { {x, y, z} }
   }
   ```

2. **Adicionar múltiplas posições**:
   ```lua
   itemPos = {
       {x = ..., y = ..., z = ...},
       {x = ..., y = ..., z = ...},
       -- múltiplas
   }
   ```

3. **Documentar quest**:
   - Registrar quest name
   - Total de itens
   - Area onde colhidos

4. **Script de coleta**:
   - Action 101 em action script
   - Incrementar storage para quest
   - Dar feedback ao player

</Card>

## 🎛️ Integração com Sistema

<Card title="Como Funciona" icon="link">

**Em `tile_pick.lua`**:
```lua
TilePickAction = {
    [101] = {
        itemId = false,
        itemPos = {
            {x = 32456, y = 31654, z = 6},
            {x = 32457, y = 31654, z = 6},
            -- ... 14 mais
        }
    }
}
```

**Em action script** (`actions/other/tile_pick.lua`):
```lua
local tilePickAction = Action()
tilePickAction:id(101)

function tilePickAction.onUse(player, item, fromPos, target, toPos)
    local storageKey = Storage.Quest.TheExplorerSociety.Collected
    
    -- Verifica se já colheu este
    if hasCalled[player:getId()] and hasCalled[player:getId()][toPos.x .. ',' .. toPos.y] then
        player:sendCancelMessage("You have already picked this.")
        return true
    end
    
    -- Incrementa contador
    local count = player:getStorageValue(storageKey) or 0
    count = count + 1
    player:setStorageValue(storageKey, count)
    
    -- Feedback
    player:sendTextMessage(MESSAGE_STATUS, "You picked item (" .. count .. "/16)")
    
    -- Check se completou
    if count == 16 then
        player:sendTextMessage(MESSAGE_STATUS, "You completed The Explorer Society!")
    end
    
    return true
end

tilePickAction:register()
```

## 💡 Característica Única

<Card title="Por Que Action ID 101?" icon="lightbulb">

**Centralização**:
- Todos os pickables usam 101
- Script único para todas coletas
- Escalável para múltiplas quests

**Prós**:
- ✅ Código simples e centralizado
- ✅ Fácil de manter
- ✅ Performance otimizada

**Implementação**:
- Script onUse(action 101)
- Verifica posição `{x, y, z}`
- Mapeia para quest específica
- Incrementa contador apropriado

</Card>
