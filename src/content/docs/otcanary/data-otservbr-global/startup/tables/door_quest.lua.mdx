# 📖 door_quest.lua

Arquivo de tabela responsável pela configuração de **portas específicas de quests** - portas que abrem apenas para players que completaram certas condições de quest.

## 📋 Resumo Executivo

<Card title="O que este arquivo faz?" icon="info">

Configuração de **portas associadas a quests**:

**Propósito**:
- Portas que só abrem se player completou quest milestone
- Rastrear progresso via storage keys
- Progressão natural dentro de quests

**Estrutura**:
```lua
[Storage.Quest.QUESTNAME.MILESTONENAME] = {
    itemId = DOOR_ITEM_ID ou false,
    itemPos = { {x, y, z}, ... }
}
```

**Exemplos**: The Queen of Banshees, Sam's Old Backpack, To Outfox a Fox, etc

</Card>

QuestDoorAction   Player Storage
(Definições)      (Verificação)
    │                 │
    ├─ Storage Key    ├─ hasStorage?
    ├─ Item ID        ├─ getStorageValue
    ├─ Positions      └─ Se completou → abre
    └─ Quest-specific

**Fluxo**:
1. Player passa por quest
2. Completa milestone (armazena storage key)
3. Encontra porta com mesmo storage key
4. Porta abre (reconhece que completou)

## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### QuestDoorAction

**Propósito**: Definir portas específicas de quests

**Estrutura**:
```lua
QuestDoorAction = {
    [Storage.Quest.QUESTNAME.MILESTONE] = {
        itemId = DOOR_ITEM_ID ou false,
        itemPos = {
            {x = xxxxx, y = xxxxx, z = xx},
            -- múltiplas posições possíveis
        }
    }
}
```

**Campos**:
- `Storage.Quest.QUESTNAME.MILESTONE`: Storage key da quest
- `itemId`: Tipo visual da porta (ou false)
- `itemPos`: Posições no mapa

**Padrão Naming**:
- `Storage.Quest.U7_2.TheQueenOfTheBanshees.BansheeDoor`
- `Storage.Quest.U7_5.SamsOldBackpack.SamsOldBackpackDoor`
- Hierarquia clara: Quest → Milestone

</Card>

## 🔑 Padrões de Uso

<Card title="Boas Práticas" icon="star">

### Estrutura de Storage Keys

```lua
-- Em constants/storage.lua
Storage.Quest = {
    U7_2 = {
        TheQueenOfTheBanshees = {
            BansheeDoor = numero_unico,
            FirstSealDoor = numero_unico,
            SecondSealDoor = numero_unico,
            -- ... mais milestones
        }
    },
    U7_5 = {
        SamsOldBackpack = {
            SamsOldBackpackDoor = numero_unico
        }
    }
}

-- Em door_quest.lua
[Storage.Quest.U7_2.TheQueenOfTheBanshees.BansheeDoor] = {...}
```

### Ao Adicionar Nova Porta Quest

1. **Criar storage key**:
   - Em `constants/storage.lua`
   - Nomear hierarquicamente

2. **Adicionar porta**:
   ```lua
   [Storage.Quest.QUESTNAME.MILESTONE] = {
       itemId = DOOR_ITEM,
       itemPos = { {x, y, z} }
   }
   ```

3. **Documentar**:
   - Quest name em comentário
   - Script que usa a porta

4. **Testar**:
   - Sem storage key = blocked
   - Com storage key = open

</Card>

## 🎛️ Integração com Sistema

<Card title="Como Funciona" icon="link">

**Em `door_quest.lua`**:
```lua
QuestDoorAction = {
    [Storage.Quest.U7_2.TheQueenOfTheBanshees.BansheeDoor] = {...}
}
```

**Em quest script** (quando completa milestone):
```lua
-- Player completou The Queen of Banshees
player:setStorageValue(Storage.Quest.U7_2.TheQueenOfTheBanshees.BansheeDoor, 1)
-- Regrista a conclusão do milestone
```

**Em movimento script** (porta):
```lua
function mvEvent.onStepIn(creature, item, position, ...)
    local player = creature:getPlayer()
    if not player then return true end
    
    -- Pega action ID (que é storage key)
    local actionId = item:getAttribute(ITEM_ATTRIBUTE_ACTIONID)
    
    -- Verifica storage
    if player:getStorageValue(actionId) > 0 then
        door:open(player)
    else
        player:sendCancelMessage("Access denied")
    end
end
```
