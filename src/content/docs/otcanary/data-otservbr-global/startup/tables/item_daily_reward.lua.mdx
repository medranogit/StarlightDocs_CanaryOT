## 🎛️ Potencial de Integração

<Card title="Como Funcionaria" icon="link">

**Em `item_daily_reward.lua` (futuro)**:
```lua
DailyRewardAction = {
    [7001] = {
        itemId = 2160,
        itemPos = { {x = 32369, y = 32240, z = 7} }
    }
}
```

**Em item script**:
```lua
function itemEvent.onUse(player, item, fromPos, target, toPos)
    -- Verifica se já pegou hoje
    local lastTaken = player:getStorageValue(Storage.DailyReward.Item7001)
    local now = os.time()
    
    if lastTaken and (now - lastTaken) < 86400 then
        -- Menos de 24 horas
        player:sendCancelMessage("You already took this today")
        return true
    end
    
    -- Marca que pegou hoje
    player:setStorageValue(Storage.DailyReward.Item7001, now)
    
    -- Dá recompensa
    player:addItem(2160, 1)
    player:sendTextMessage(MESSAGE_STATUS, "You received a blessing!")
    
    return true
end
```

**Respawn**:
- Item remove da posição quando pegado
- Script scheduler respawn após 24h
- Automático no servidor

</Card>
