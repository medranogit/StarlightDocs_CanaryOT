## 📋 Resumo Executivo

<Card title="O que este arquivo faz?" icon="info">

Arquivo de configuração para **corpses especiais** que aparecem em determinados locais:

**Tipos de Corpses**:
- Corpses de quests (Threatened Dreams, Cursed Crystal, etc)
- Corpses de story/lore
- Corpses que rastreiam progresso de quest
- Corpses com items especiais

**Estrutura Básica**:
```lua
[actionId] = {
    itemId = CORPSE_ITEM_ID,
    itemPos = { {x, y, z}, ... }
}
```

**Faixa Reservada**: 20000-25000 (CorpseAction/CorpseUnique)

</Card>

## 📊 Variáveis Globais

<Card title="Tabelas Principais" icon="database">

### CorpseAction

**Propósito**: Define corpses com action IDs

**Estrutura**:
```lua
CorpseAction = {
    [actionId] = {
        itemId = CORPSE_ITEM_ID,
        itemPos = {
            {x = xxxxx, y = xxxxx, z = xx},
            {x = xxxxx, y = xxxxx, z = xx}
        }
    }
}
```

**Campos**:
- `actionId`: ID único (faixa 20000-25000)
- `itemId`: Item ID do corpse (ex: 4285)
- `itemPos`: Array de posições `{x, y, z}`

### CorpseUnique

**Propósito**: Define corpses com unique IDs

**Estrutura**: Idêntica a CorpseAction, porém com unique IDs em vez de action IDs.

**Exemplo Retirado do Código**:
```lua
CorpseUnique = {
    -- The Ice Island Quest - Skeleton
    [3112] = {
        itemId = 4024,
        itemPos = { x = 32258, y = 31098, z = 10 }
    },
    -- Tinder Box Quest - Chyllfroest
    [3263] = {
        itemId = 4285,
        itemPos = { x = 32085, y = 31025, z = 1 }
    }
}
```

</Card>

## 🔑 Padrões de Uso

<Card title="Boas Práticas" icon="star">

### Ao Adicionar Novo Corpse

1. **Identificar tipo**:
   - Action corpse? → CorpseAction
   - Unique corpse? → CorpseUnique

2. **Escolher ID** dentro do range
   - Action: 20000-25000
   - Unique: 20000-22000

3. **Determinar item**:
   - Item ID do corpse (4285 padrão)
   - Pode variar por tipo de criatura

4. **Registrar posição(ões)**:
   - Single: `{ x = ..., y = ..., z = ... }`
   - Múltiplas: Array de posições

5. **Documentar na quest**:
   - Adicionar comentário mencionando quest
   - Linkar script relevante

### Convenções

```lua
-- ✅ BOM: Bem documentado
-- The cursed crystal quest
[40001] = {
    itemId = 4285,
    itemPos = { {x = 31974, y = 32907, z = 8} }
    -- Corpse do líder dos esqueletos
}

-- ❌ RUIM: Sem documentação
[40001] = {
    itemId = 4285,
    itemPos = { {x = 31974, y = 32907, z = 8} }
}
```

## 🎛️ Integração com Sistema

<Card title="Como os Scripts Usam" icon="link">

**Em `functions.lua`**:
```lua
-- Função que carrega corpses
function loadLuaMapUnique(tablename)
    for index, value in pairs(tablename) do
        local tile = Tile(value.itemPos)
        if tile then
            local item = tile:getItemById(value.itemId)
            if item then
                item:setAttribute(ITEM_ATTRIBUTE_UNIQUEID, index)
            end
        end
    end
end
```

**Chamada no startup**:
```lua
loadLuaMapUnique(CorpseUnique)
```

**Resultado**:
- Corpse aparece no mapa
- Tem unique ID registrado
- Script pode referenciá-lo por ID
