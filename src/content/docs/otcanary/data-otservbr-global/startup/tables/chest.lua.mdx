# 📦 chest.lua

Arquivo de tabelas responsável pela configuração de todos os baús do servidor, incluindo baús normais, customizados e com rewards especiais. Suporta tanto configuração simples quanto integração com sistema KV.

## 📋 Resumo Executivo

<Card title="O que este arquivo faz?" icon="info">

Arquivo principal de configuração de **baús interativos** no servidor com duas abordagens:

**1. Configuração Simples**:
```lua
[actionId] = {
    itemId = ITEM_ID,
    itemPos = { {x, y, z}, ... },
    container = CONTAINER_ID,
    reward = {{ITEM, COUNT}, ...},
    storage = STORAGE_KEY
}
```

**2. Integração com KV System**:
```lua
[actionId] = {
    useKV = true,
    itemId = ITEM_ID,
    itemPos = { {x, y, z}, ... },
    reward = {{ITEM, COUNT}, ...},
    questName = "name"
}
```

**Faixas Reservadas**:
- **5000-6000**: Reward keys
- **6001-12472**: Quest rewards scripts
- **12473-15000**: Outros scripts com varied rewards

</Card>

4. Cada baú registra action/unique ID no mapa
5. Script de ação ativa reward system

## 📊 Variáveis Globais

<Card title="Tabelas Principais" icon="database">

### ChestAction Table

**Propósito**: Define todos os baús com action IDs

**Estrutura**:
```lua
ChestAction = {
    [actionId] = {
        -- Para uso do mapa
        itemId = ITEM_ID ou false,
        itemPos = {
            {x = xxxxx, y = xxxxx, z = x},
            {x = xxxxx, y = xxxxx, z = x}
        },
        
        -- Para uso do script
        container = CONTAINER_ID,  -- Opcionalmente
        keyAction = KEY_ACTION_ID, -- Se usar chave
        reward = {{ITEM_ID, COUNT}, ...},
        storage = STORAGE_KEY
    }
}
```

**Campos Explicados**:

| Campo | Tipo | Descrição |
|-------|------|-----------|
| **itemId** | number/false | ID do item baú (false = piso vazio) |
| **itemPos** | array | Posições onde o baú aparece no mapa |
| **container** | number | ID do container para reward guardado |
| **keyAction** | number | Action ID da chave (se necessário) |
| **reward** | array | Array de `{ITEM_ID, COUNT}` |
| **storage** | number | Storage key para tracker progresso |
| **useKV** | boolean | Ativar sistema KV (alternativa) |
| **questName** | string | Nome da quest (se usar KV) |

### ChestUnique Table

**Propósito**: Define baús com unique IDs (opcional)

**Estrutura**: Similar a `ChestAction`, com foco em unique IDs em vez de action IDs.

</Card>

## 📝 Padrões de Uso

<Card title="Boas Práticas" icon="star">

### Ao Adicionar Novo Baú

1. **Escolher Action ID** dentro do range apropriado (5000-15000)
2. **Definir item e posição**:
   - `itemId = CHEST_ITEM_ID` ou `false`
   - `itemPos = {{x, y, z}, ...}`
3. **Configurar reward**:
   - Array simples `{{ITEM, COUNT}, ...}`
4. **Registrar storage**:
   - `storage = UNIQUE_KEY`
5. **Testar in-game**:
   - Verificar baú aparece
   - Verificar reward é dado
   - Verificar storage atualiza

### Evitar

- ❌ Reutilizar action IDs
- ❌ Posições fora do mapa
- ❌ Storage keys duplicadas
- ❌ Rewards inválidos (itemIds que não existem)

</Card>

<Card title="Como os Scripts Usam Esta Tabela" icon="link">

**Em `functions.lua`**:
```lua
-- Função carrega ChestAction
function CreateChestOnMap(tablename)
    for index, value in pairs(tablename) do
        -- Para cada action ID
        -- Cria item na posição
        -- Registra action ID no mapa
    end
end
```

**Chamada no startup**:
```lua
CreateChestOnMap(ChestAction)
```

**Em script de ação** (`quest_reward_common.lua`):
```lua
-- Ao usar baú
local chestConfig = ChestAction[actionId]
if chestConfig then
    -- Dar reward do config
    for _, reward in ipairs(chestConfig.reward) do
        player:addItem(reward[1], reward[2])
    end
    -- Atualizar storage
    player:setStorageValue(chestConfig.storage, 1)
end
```
