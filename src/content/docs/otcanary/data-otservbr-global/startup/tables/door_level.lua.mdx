## 📋 Resumo Executivo

<Card title="O que este arquivo faz?" icon="info">

Configuração de **portas com requisito de level**:

**Sistema de Numeração Única**:
```
Padrão: 1[level]
1020  = Level 20
1050  = Level 50
1100  = Level 100
1250  = Level 250
```

**Estrutura**:
```lua
[1020] = {
    itemId = false,
    itemPos = { {x, y, z}, ... }
}
```

**Verificação**: Player level >= [level extraído do action ID]

             │

1010 = 10, 1020 = 20, ..., 1250 = 250

**Parsing do Level**:
```lua
-- Script extrai level do action ID
local actionId = 1050  -- Level 50
local requiredLevel = tonumber(tostring(actionId):sub(2))
-- requiredLevel = 50
```

## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### LevelDoorAction

**Propósito**: Definir portas com requisito de level

**Estrutura**:
```lua
LevelDoorAction = {
    [levelActionId] = {
        itemId = false,  -- Sempre false
        itemPos = {
            {x = xxxxx, y = xxxxx, z = xx},
            -- múltiplas posições possíveis
        }
    }
}
```

**Campos**:
- `levelActionId`: Action ID em formato 1[level]
- `itemId`: Sempre `false` (porta)
- `itemPos`: Array de posições

**Format Action ID**:
- Sempre começa com `1`
- Seguido por 2-3 dígitos do level
- Ex: 1010, 1025, 1030, 1040, 1100, 1250

</Card>

## 🔑 Padrões de Uso

<Card title="Boas Práticas" icon="star">

### Sistema de Numeração

```lua
-- ✅ CORRETO: 1[level]
[1010] = {...}  -- Level 10
[1050] = {...}  -- Level 50
[1100] = {...}  -- Level 100
[1250] = {...}  -- Level 250

-- ❌ ERRADO: Formato incorreto
[2050] = {...}  -- Não funciona (não começa com 1)
[1500] = {...}  -- Ambíguo (15 ou 150?)
```

### Ao Adicionar Nova Porta Level

1. **Decidir level**:
   - Level 10-250 típico
   - Match com suas áreas

2. **Format action ID**:
   - 1[level]
   - 1010 = 10, 1100 = 100, etc

3. **Adicionar entradas**:
   ```lua
   [1045] = {
       itemId = false,
       itemPos = { {x, y, z} }
   }
   ```

4. **Testar**:
   - Player abaixo level = blocked
   - Player acima level = open

</Card>

## 🎛️ Integração com Sistema

<Card title="Como Funciona" icon="link">

**Em `door_level.lua`**:
```lua
LevelDoorAction = {
    [1020] = {itemId = false, itemPos = {...}}
}
```

**Em movimento script**:
```lua
function mvEvent.onStepIn(creature, item, position, ...)
    local player = creature:getPlayer()
    if not player then return true end
    
    -- Pega action ID
    local actionId = item:getAttribute(ITEM_ATTRIBUTE_ACTIONID)
    
    -- Extrai level necessário
    -- actionId = 1020 → requiredLevel = 20
    local requiredLevel = tonumber(tostring(actionId):sub(2))
    
    -- Verifica level
    if player:getLevel() >= requiredLevel then
        door:open(player)
    else
        player:sendCancelMessage("You need level " .. requiredLevel)
    end
end
```

**Lógica**:
1. Player pisa na porta
2. Script lê action ID (ex: 1020)
3. Extrai level (20)
4. Verifica `getLevel()`
5. Se >= 20, abre; senão, bloqueia

</Card>
