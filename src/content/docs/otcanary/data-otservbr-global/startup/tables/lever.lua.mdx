## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### LeverAction

**Propósito**: Definir alavancas e botões acionáveis

**Estrutura**:
```lua
LeverAction = {
    [actionId] = {
        itemId = false,  -- Geralmente false
        itemPos = {
            {x = xxxxx, y = xxxxx, z = xx},
            -- múltiplas posições possíveis
        }
    }
}
```

**Campos**:
- `actionId`: ID único (4001-7799+)
- `itemId`: false (botão/alavanca invisível)
- `itemPos`: Posições no mapa

**Range de IDs**:
- Começa em 4001
- Vai até 7799+
- Centenas de alavancas
- Organized by area

</Card>

## 🎛️ Integração com Sistema

<Card title="Como Funciona" icon="link">

**Em `lever.lua`**:
```lua
LeverAction = {
    [4001] = {
        itemId = false,
        itemPos = { {x = 32352, y = 31654, z = 6} }
    }
}
```

**Em action script** (`actions/other/lever.lua`):
```lua
local leverAction = Action()
leverAction:id(4001)

function leverAction.onUse(player, item, fromPos, target, toPos)
    -- Verifica cooldown
    if item:getAttribute(ITEM_ATTRIBUTE_ACTIONID) ~= 4001 then
        return false
    end
    
    -- Executa efeito
    fromPos:sendMagicEffect(CONST_ME_CRACKGROUND)
    
    -- Abre porta ou ativa mecanismo
    local doorPos = Position(32352, 31660, 6)
    local door = Tile(doorPos):getGround()
    if door then
        door:transform(1211)  -- Abre
    end
    
    return true
end

leverAction:register()
```

**Fluxo**:
1. Alavanca na posição `{x, y, z}`
2. Player usa (action 4001)
3. Verifica se é correta
4. Ativa mecanismo
5. Efeito visual

</Card>
