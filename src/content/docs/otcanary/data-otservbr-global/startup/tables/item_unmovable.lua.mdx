Arquivo de tabela responsável por **items imóveis** - objetos que não podem ser movidos pelos players.

## 📋 Resumo Executivo

<Card title="O que este arquivo faz?" icon="info">

**Estado**: Template estruturado

```lua
ItemUnmovableAction = {}
```

**Propósito**:
- Items que players não podem pegar/mover
- Decoração interativa
- Environmental objects
- Action ID reservado: 100

**Estrutura**:
```lua
[100] = {
    itemId = false,
    itemPos = { {x, y, z} }
}
```

**Diferença**: Ao contrário de chest.lua, esses items não podem ser levados

</Card>

## 🏗️ Estrutura de Funcionalidades

<Card title="Arquitetura de Items Imóveis" icon="layers">

```
┌──────────────────────────┐
│   ITEMS IMÓVEIS (ACTION) │
└────────────┬─────────────┘
             │
         ┌───┴────┐
         │        │
         ▼        ▼
    Config      Interaction
    (Dados)     (Script)
         │        │
    Action ID    ├─ onUse() script
    Item Type    ├─ Não remove item
    Positions    └─ Effect only
```

**Comportamento**:
- Player tenta pegar → Block
- Player tenta usar → Execute action
- Item permanece no mapa

</Card>

## 🔑 Padrões de Uso

<Card title="Casos de Uso" icon="star">

### Quando Usar Items Imóveis

1. **Decoração Interativa**:
   - Estatue que fala
   - Logo que dá info
   - Environmental storytelling

2. **Environmental Puzzles**:
   - Plataforma que não se move
   - Button que ativa algo
   - Interactive art

3. **Game Mechanics**:
   - Trigger para quest
   - Weather effect trigger
   - Map feature

### Ao Adicionar Item Imóvel

1. **Usar Action ID 100** (reservado):
   ```lua
   [100] = {
       itemId = false,
       itemPos = { {x, y, z} }
   }
   ```

2. **Criar action script**:
   - Em `data/scripts/actions/`
   - Registrar action ID 100
   - Implementar onUse()

3. **Posição no mapa**:
   - Colocar item no mapa
   - Atribuir action ID 100
   - Teste interação

4. **Documentar**:
   - Propósito do item
   - Script asociado
   - Comportamento esperado

## 🎛️ Integração com Sistema

<Card title="Como Funcionaria" icon="link">

**Em `item_unmovable.lua`** (futuro):
```lua
ItemUnmovableAction = {
    [100] = {
        itemId = false,
        itemPos = { {x = 32352, y = 31654, z = 6} }
    }
}
```

**Em action script** (`actions/other/unmovable.lua`):
```lua
local unmovableAction = Action()
unmovableAction:id(100)

function unmovableAction.onUse(player, item, fromPos, target, toPos)
    -- Player tenta interagir com item imóvel
    
    -- Effect customizado
    position:sendMagicEffect(CONST_ME_BLOCKINGAREA)
    
    -- Mensagem
    player:sendTextMessage(MESSAGE_INFO_DESCR, 
        "This object is immovable and serves a special purpose.")
    
    return true
end

unmovableAction:register()
```

**Verificação**:
- Item não pode ser pego
- Script apenas usa onUse
- Permanece no mapa

</Card>
