## 🏗️ Estrutura de Funcionalidades

<Card title="Arquitetura de Documentos" icon="layers">

```
┌──────────────────────────────┐
│  SISTEMA DE LIVROS/DOCUMENTOS │
└────────────┬─────────────────┘
             │
    ┌────────┴────────┐
    │                 │
    ▼                 ▼
BookDocumentTable   Content Loading
(Tabela array)      (quando necessário)
    │                 │
    ├─ containerId    ├─ Player abre livro
    ├─ itemId         ├─ Sistema busca
    ├─ position       ├─ Encontra em tabela
    └─ text           └─ Exibe conteúdo


Para cada livro:
containerId = Container Item ID
    ↓
itemId = Qual item no container
    ↓
position = Qual posição naquele item
    ↓
text = Conteúdo completo do livro
```

**Fluxo**:
1. Player abre container (ex: bookcase)
2. Vê item "Red Tome"
3. Sistema procura BookDocumentTable
4. Encontra match (containerId+itemId+position)
5. Exibe texto armazenado

</Card>

## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### BookDocumentTable

**Propósito**: Armazenar conteúdo de documentos

**Estrutura**:
```lua
BookDocumentTable = {
    {
        containerId = CONTAINER_ITEM_ID,
        itemId = ITEM_ID_DO_LIVRO,
        position = POSICAO_NO_CONTAINER,
        text = "Conteúdo completo do livro\nCom múltiplas linhas\nE parágrafos..."
    },
    {
        containerId = ...,
        itemId = ...,
        position = ...,
        text = "..."
    }
    -- 100+ entradas
}
```

**Campos**:
- `containerId`: ID do container (baúe, estante, etc)
- `itemId`: ID do item livro
- `position`: Índice no container
- `text`: Conteúdo completo (pode ter \n para quebras)

</Card>

## 🔑 Padrões de Uso

<Card title="Boas Práticas" icon="star">

### Ao Adicionar Novo Livro

1. **Definir container**:
   - Onde livro será encontrado
   - Container ID do baúe/estante

2. **Selecionar item**:
   - Item ID do livro (tipo)
   - Deve existir em items.xml

3. **Posição no container**:
   - Índice sequencial
   - Ordem dentro do container

4. **Escrever conteúdo**:
   ```lua

          "\n" ..
          "Parágrafo 1...\n" ..
          "\n" ..
          "Parágrafo 2...""
   ```

5. **Adicionar à tabela**:
   ```lua
   {
       containerId = 1234,
       itemId = 5678,
       position = 7,
       text = "..."
   }
   ```

## 🎛️ Integração com Sistema

<Card title="Como Funciona" icon="link">

**Em `writeable.lua`**:
```lua
BookDocumentTable = {
    {
        containerId = 1234,
        itemId = 3966,
        position = 2,
        text = "MONSTERS AND FOES OF DAWNPORT I\n..."
    }
}
```

**Em item script** (quando player abre livro):
```lua
function itemEvent.onUse(player, item, fromPos, target, toPos)
    local itemId = item:getId()
    local containerId = item:getParent():getId()
    local position = item:getPosition()
    
    -- Busca em BookDocumentTable
    for _, book in ipairs(BookDocumentTable) do
        if book.itemId == itemId and 
           book.containerId == containerId then
            -- Encontrou! Exibe texto
            player:showTextWindow(
                item:getName(),
                book.text
            )
            return true
        end
    end
    
    return false
end
```

**Fluxo**:
1. Player abre container
2. Vê livro "Monsters and Foes"
3. Player clica no livro
4. OnUse executa
5. Sistema busca em BookDocumentTable
6. Encontra match
7. Exibe janela com texto completo

</Card>

## 💡 Por Que Tabela Separada

<Card title="Vantagens da Abordagem" icon="lightbulb">

### Comparado a Hardcode em Scripts

**Sem BookDocumentTable**:
```lua
-- No script - difícil de manter
function onUse(player, item)
    if item:getId() == 3966 then
        player:showTextWindow("Monsters I", 
            "MONSTERS AND FOES OF DAWNPORT I\n" ..
            "Muito texto longo aqui..." ..
            "Difícil de manter tudo em um script"
        )
    end
end
```

**Com BookDocumentTable**:
```lua
-- Em tabela separada - organizado
{
    containerId = 1234,
    itemId = 3966,
    position = 2,
    text = "MONSTERS AND FOES OF DAWNPORT I\n..."
}

-- Script genérico que funciona com todos
function onUse(player, item)
    -- Busca em BookDocumentTable
    -- Funciona para qualquer livro
end
```

**Vantagens**:
- ✅ Tabela centralizada
- ✅ Script genérico reutilizável
- ✅ Fácil adicionar novos livros
- ✅ Melhor organização

</Card>
