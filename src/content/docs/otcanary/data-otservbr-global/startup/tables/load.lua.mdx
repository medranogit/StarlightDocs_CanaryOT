# 📄 load.lua (Tabelas)

Arquivo carregador principal responsável por orquestrar o carregamento de todas as 15+ tabelas de configuração do servidor. Localizado em `startup/tables/`, este arquivo é o entry point para o subsistema de tabelas.

---

## 🛠️ Informações do Arquivo

<Card title="Detalhes Técnicos" icon="document">

| Propriedade | Valor |
|---|---|
| **Caminho** | `data-otservbr-global/startup/tables/load.lua` |
| **Tipo** | Arquivo Loader de Tabelas |
| **Escopo** | Startup (carregado por `startup.lua`) |
| **Dependências** | 15+ arquivos de tabela |
| **Linhas de Código** | ~16 linhas (15 dofile calls) |
| **Função Principal** | Orquestrar carregamento de tabelas |
| **Carregado por** | `startup.lua` (primeira etapa) |

</Card>

<Aside type="tip">
**Caminho Original**: `data-otservbr-global/startup/tables/load.lua`

Este é o **sub-loader** de tabelas. É chamado **PRIMEIRO** pelo `startup.lua` antes do loader de funções, garantindo que todas as tabelas estejam prontas para uso.
</Aside>

---

## 📋 Resumo Executivo

<Card title="O que este arquivo faz?" icon="info">

Arquivo simples mas crítico que **ordena e carrega 15+ arquivos de tabelas**:

```lua
dofile(DATA_DIRECTORY .. "/startup/tables/chest.lua")
dofile(DATA_DIRECTORY .. "/startup/tables/corpse.lua")
dofile(DATA_DIRECTORY .. "/startup/tables/create_item.lua")
-- ... e mais 12 arquivos
```

**Responsabilidade**:
- Carregar tabelas **em ordem específica**
- Garantir disponibilidade para funções
- Manter organização central

**Timing**:
- Carregado PRIMEIRO (tabelas antes de funções)
- Executa rapidamente
- Bloqueia startup até completar

</Card>

## 🏗️ Estrutura de Carregamento

<Card title="Ordem Hierárquica de Carregamento" icon="layers">

```
┌──────────────────────────────────────────────────┐
│         STARTUP MAIN (startup.lua)               │
└────────────┬─────────────────────────────────────┘
             │
             ├─ Line 1: dofile(...tables/load.lua)
             │          ↓
             │  ┌────────────────────────────────┐
             │  │  tables/load.lua (ESTE ARQUIVO)│
             │  │  ┌──────────────────────────────┤
             │  │  │ 1. chest.lua                │
             │  │  │ 2. corpse.lua               │
             │  │  │ 3. create_item.lua          │
             │  │  │ 4. door_key.lua             │
             │  │  │ 5. door_level.lua           │
             │  │  │ 6. door_quest.lua           │
             │  │  │ 7. item.lua                 │
             │  │  │ 8. item_daily_reward.lua    │
             │  │  │ 9. item_unmovable.lua       │
             │  │  │ 10. lever.lua               │
             │  │  │ 11. teleport.lua            │
             │  │  │ 12. teleport_item.lua       │
             │  │  │ 13. tile.lua                │
             │  │  │ 14. tile_pick.lua           │
             │  │  │ 15. writeable.lua           │
             │  │  │ 16. storage_keys_update.lua │
             │  │  └──────────────────────────────┤
             │  └────────────────────────────────┘
             │
             ├─ Line 2: dofile(...others/load.lua)
             │
             └─ Rest of startup
```

**Fluxo Temporal**:
1. Sistema booteia
2. APIs internas carregadas
3. `startup.lua` executado
4. **Este arquivo (`tables/load.lua`)** executado
5. Todas 15+ tabelas carregadas **globalmente**
6. **ENTÃO** `others/load.lua` carregado
7. Resto do startup continua

</Card>

## 🔍 Análise de Ordem

<Card title="Por que esta ordem?" icon="magnifying-glass">

### Ordem Crítica para Dependências

```
1. Chest → Base item system
2. Corpse → Corpse specifics  
3. CreateItem → Basic creation
4-6. Doors → Door system variants
7. Item → Main items
8-9. Item variants → Specialized items
10. Lever → Interaction system
11-12. Teleport → Movement system
13-14. Tile → Ground system
15. Writeable → Content system
16. Storage Keys → Migration system (deve ser ÚLTIMO)
```

### Storage Keys Update - Deve Ser Último

**Importante**: `storage_keys_update.lua` usa funções que **dependem de outras tabelas estarem carregadas**. Deve ser **SEMPRE o último**.

```lua
-- ❌ ERRADO
dofile(...storage_keys_update.lua)  -- Arquivo não existe ainda!
dofile(...chest.lua)

-- ✅ CORRETO
dofile(...chest.lua)
-- ... outros arquivos ...
dofile(...storage_keys_update.lua)  -- Último!
```

### Lógica Geral

1. **Items base** (1-9): Definem estruturas
2. **Systems** (10-15): Definem comportamentos especiais
3. **Migrations** (16): Processa dados históricos

</Card>

## 🎓 Extensibilidade

<Card title="Como Expandir" icon="plus">

### Adicionar Nova Tabela

**1. Criar arquivo**:
```lua
-- data-otservbr-global/startup/tables/my_table.lua

MyNewTable = {
    [1] = {
        -- dados
    }
}
```

**2. Adicionar ao load.lua** (ANTES de storage_keys_update.lua):
```lua
dofile(DATA_DIRECTORY .. "/startup/tables/my_table.lua")
```

**3. Testar startup**:
```
lua startup.lua
```

### Remover Tabela

1. Verificar se é usado em scripts
2. Remover linha do load.lua
3. Testar startup

### Reordenar (COM CUIDADO)

Apenas se absolutamente necessário:
1. Verificar dependências
2. **MANTER storage_keys_update.lua por último**
3. Testar completamente
