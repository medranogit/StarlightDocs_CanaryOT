## 📊 Variáveis Globais

<Card title="Tabela Principal" icon="database">

### TileAction

**Propósito**: Definir tiles com action IDs

**Estrutura**:
```lua
TileAction = {
    [actionId] = {
        itemId = false,
        itemPos = {
            {x = xxxxx, y = xxxxx, z = xx},
            -- múltiplas posições possíveis
        }
    }
}
```

**Campos**:
- `actionId`: ID único (variável)
- `itemId`: false (visually transparent)
- `itemPos`: Array de posições no mapa

**Range de IDs**:
- 12124: Uma série de transformação
- 20001+: Tiles quest-específicas
- 25001-25009+: Dawnport vocacao tiles

</Card>

## 🎛️ Integração com Sistema

<Card title="Como Funciona" icon="link">

**Em `tile.lua`**:
```lua
TileAction = {
    [25001] = {
        itemId = false,
        itemPos = { {x = 32420, y = 31666, z = 7} }
    }
}
```

**Em movimento script** (`movements/...`):
```lua
function mvEvent.onStepIn(creature, item, position, ...)
    if not creature:isPlayer() then return true end
    
    local player = creature:getPlayer()
    local actionId = item:getAttribute(ITEM_ATTRIBUTE_ACTIONID)
    
    -- Vocação tiles (Dawnport)
    if actionId >= 25001 and actionId <= 25004 then
        local vocations = {
            [25001] = VOCATION_KNIGHT,
            [25002] = VOCATION_PALADIN,
            [25003] = VOCATION_DRUID,
            [25004] = VOCATION_SORCERER
        }
        
        local voc = vocations[actionId]
        if voc then
            player:setVocation(voc)
            player:sendTextMessage(MESSAGE_STATUS, "You became a " .. voc:getName())
        end
    end
    
    return true
end
```

**Fluxo**:
1. Player pisa na tile
2. Script lê action ID
3. Executa lógica específica
4. Aplica transformação/efeito

</Card>
