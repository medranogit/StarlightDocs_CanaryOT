# Estrutura de NPCs - Guia Completo

## 📋 Visão Geral

Este documento explica a estrutura padrão utilizada para documentar cada NPC no Canary Server. Todos os NPCs seguem este template português de 10 seções, permitindo compreensão consistente de suas propriedades, função, localização e diálogos.

---

## 1️⃣ Seção: Informações Básicas

**Propriedades fundamentais do NPC:**

| Propriedade | Descrição |
|---|---|
| **Nome Interno** | internalNpcName (identificador único) |
| **Nome Exibido** | npcConfig.name (nome visível aos players) |
| **Descrição** | npcConfig.description (normalmente igual ao nome) |
| **Saúde** | npcConfig.health (sempre 100 nos NPCs) |
| **Localização** | Zona/Cidade onde o NPC fica (ex: Tibia City, Kazordoon) |

### Exemplo:
```
Nome: Cerebrir | Saúde: 100 | Localização: ???
Nome: A Beautiful Girl | Saúde: 100 | Localização: ???
```

---

## 2️⃣ Seção: Aparência

**Características visuais do NPC:**

| Propriedade | Descrição |
|---|---|
| **Look Type** | npcConfig.outfit.lookType - ID do modelo visual principal |
| **Look Head** | npcConfig.outfit.lookHead - ID customização de cabeça |
| **Look Body** | npcConfig.outfit.lookBody - ID customização de corpo |
| **Look Legs** | npcConfig.outfit.lookLegs - ID customização de pernas |
| **Look Feet** | npcConfig.outfit.lookFeet - ID customização de pés |
| **Look Addons** | npcConfig.outfit.lookAddons - Acessórios (0 = nenhum, 1-3 = addons) |

### Exemplo:
```
Look Type: 140 | Head: 60 | Body: 22 | Legs: 24 | Feet: 32 | Addons: 1
ou
Look Type: 1067 | (sem customização adicional)
```

---

## 3️⃣ Seção: Comportamento

**Flags e configurações de movimento:**

| Propriedade | Descrição |
|---|---|
| **walkInterval** | Intervalo de caminhada em ms (0 = imóvel, 2000+ = mobile) |
| **walkRadius** | Raio de movimento permitido (1 = pouco movimento, 2-4 = moderado) |
| **floorchange** | Se pode mudar de andar (true/false) |

### Interpretação:
- **walkInterval 0, walkRadius 0**: NPC completamente imóvel
- **walkInterval 2000, walkRadius 2-4**: NPC passeia na área
- **walkInterval 0, walkRadius 2+**: NPC fica em um ponto específico com pequeno raio

### Exemplo:
```
Walk Interval: 0 ms | Walk Radius: 2 | Floor Change: false (imóvel)
ou
Walk Interval: 2000 ms | Walk Radius: 4 | Floor Change: false (passeia)
```

---

## 4️⃣ Seção: Vozes & Diálogos

**Sistema de fala automática do NPC:**

| Campo | Descrição |
|---|---|
| **Intervalo** | Tempo em ms entre falas automáticas |
| **Chance** | Percentual de chance de falar (50% = às vezes fala) |
| **Textos** | Lista de frases disponíveis |

### Exemplo:
```
Intervalo: 15000 ms | Chance: 50%
Frases:
  - "Hello traveler!"
  - "How can I help you?"
  - "Looking for something?"
```

---

## 5️⃣ Seção: Keywords & Respostas

**Mapeamento de palavras-chave e respostas do NPC:**

| Keyword | Resposta | Módulo |
|---|---|---|
| job | "I am..." | StdModule.say |
| name | "My name is..." | StdModule.say |
| quest | "I have a quest for you..." | StdModule.say/Trade |
| trade | Abre trade window | StdModule.trade |
| buy/sell | Abre shop | StdModule.shop |

### Tipos de Módulos:
- **StdModule.say**: Fala texto simples
- **StdModule.trade**: Abre janela de trade
- **StdModule.shop**: Abre loja de compra/venda
- **FocusModule**: Foca no player quando fala
- **TravelModule**: NPC é um travel agent

## 9️⃣ Seção: Localização & Movimentação

**Posição geográfica no mapa:**

| Campo | Descrição |
|---|---|
| **Cidade** | Cidade principal (Tibia City, Kazordoon, etc) |
| **Local** | Descrição do local (Tavern, Magic Shop, Bank, etc) |
| **Coordenadas** | X, Y, Z do mapa (se documentado) |
| **Área de Patrulha** | Se caminha, qual área (townhall, street, etc) |

### Exemplo:
```
Cidade: Tibia City | Local: Tavern | Patrulha: Tavern area
ou
Cidade: Kazordoon | Local: Magic Shop | Patrulha: N/A (imóvel)
```

## 🔟 Seção: Nota Contextual

**Resumo narrativo caracterizando o NPC:**

Parágrafo único em português PT-BR que descreve:
- Função principal do NPC (merchant, questgiver, etc)
- Quests ou serviços oferecidos
- Localização e contexto de mundo
- Significância narrativa (se aplicável)
- Interações especiais (trades únicos, diálogos especiais)

### Exemplo:
```
"Cerebrir é um NPC imóvel (Look Type 1067) sem funções específicas visíveis. 
Localização desconhecida. Contém apenas FocusModule, sugerindo função narrativa 
ou futura expansão de conteúdo. Saúde padrão (100 HP)."
```

## 🎯 Checklista de Documentação

Ao documentar um novo NPC, verificar:

- [ ] **Seção 1**: Nome interno, nome exibido, localização
- [ ] **Seção 2**: Look Type + customizações (head/body/legs/feet) confirmadas
- [ ] **Seção 3**: Walk interval, radius, floor change documentados
- [ ] **Seção 4**: Vozes automáticas (se existentes) listadas
- [ ] **Seção 5**: Todos keywords e respostas mapeados
- [ ] **Seção 6**: Função principal identificada
- [ ] **Seção 7**: Trades/serviços tabulados (se existentes)
- [ ] **Seção 8**: Quests oferecidas listadas (se existentes)
- [ ] **Seção 9**: Localização e coordenadas documentadas
- [ ] **Seção 10**: Nota contextual em português PT-BR
