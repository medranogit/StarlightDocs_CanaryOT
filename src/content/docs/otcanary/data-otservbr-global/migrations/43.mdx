## Visão Geral

**Versão**: 43  
**Objetivo**: Add payment and duration system to guild wars

## Alteração

```sql
ALTER TABLE `guild_wars`
ADD `frags_limit` smallint(4) UNSIGNED NOT NULL DEFAULT '0',
ADD `payment` bigint(13) UNSIGNED NOT NULL DEFAULT '0',
ADD `duration_days` tinyint(3) UNSIGNED NOT NULL DEFAULT '0'
```

**Novas Colunas**:
- `frags_limit` - Limite de kills para war
- `payment` - Custo da war
- `duration_days` - Duração em dias

**Propósito**: Controlar custos e duração de guild wars
