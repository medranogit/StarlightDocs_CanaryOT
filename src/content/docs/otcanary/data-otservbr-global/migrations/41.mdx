## Alteração

```sql

MODIFY `xpboost_stamina` smallint(5) UNSIGNED DEFAULT NULL,

```

**Tabela**: `players`  
**Colunas Modificadas**:
- `xpboost_stamina` → smallint(5) UNSIGNED
- `xpboost_value` → tinyint(4) UNSIGNED

**Propósito**: Suportar apenas valores positivos no boost de XP
