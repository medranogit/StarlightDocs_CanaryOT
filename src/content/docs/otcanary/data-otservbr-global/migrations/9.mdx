## Visão Geral

**Versão**: 9  
**Objetivo**: Add mount customization and familiar support

## Alterações para players

```sql
ALTER TABLE `players` 
ADD `lookmountbody` tinyint(3) unsigned NOT NULL DEFAULT '0'
ADD `lookmountfeet` tinyint(3) unsigned NOT NULL DEFAULT '0'
ADD `lookmounthead` tinyint(3) unsigned NOT NULL DEFAULT '0'
ADD `lookmountlegs` tinyint(3) unsigned NOT NULL DEFAULT '0'
ADD `lookfamiliarstype` int(11) unsigned NOT NULL DEFAULT '0'
```

**Novas Colunas**:
- `lookmountbody` - Corpo da montaria
- `lookmountfeet` - Pés da montaria
- `lookmounthead` - Cabeça da montaria
- `lookmountlegs` - Pernas da montaria
- `lookfamiliarstype` - Tipo de familiar

**Propósito**: Customizar aparência de montarias e suportar familiares
