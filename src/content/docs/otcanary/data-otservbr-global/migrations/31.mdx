## Visão Geral

**Versão**: 31  
**Objetivo**: Add session management and improve password storage

## Tabela Criada

```sql
CREATE TABLE `account_sessions` (
  `id` VARCHAR(191) NOT NULL PRIMARY KEY,
  `account_id` INTEGER UNSIGNED NOT NULL,
  `expires` BIGINT UNSIGNED NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8;
```

## Alteração

```sql
ALTER TABLE `accounts` 
MODIFY `password` TEXT NOT NULL;
```

**Colunas sessions**:
- `id` - Session ID único
- `account_id` - Account associada
- `expires` - Timestamp de expiração

**Propósito**: Gerenciamento seguro de sessões e criptografia de password (bcrypt)
