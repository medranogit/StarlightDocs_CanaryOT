## Visão Geral

**Versão**: 19  
**Objetivo**: Add tournament coins support to gamestore

## Alterações

```sql
ALTER TABLE `accounts` 
ADD `tournament_coins` int(11) NOT NULL DEFAULT 0 AFTER `coins`

ALTER TABLE `store_history` 
ADD `coin_type` tinyint(1) NOT NULL DEFAULT 0 AFTER `description`

ALTER TABLE `store_history` 
DROP COLUMN `coins`  -- Not in use anywhere
```

**Novas Colunas**:
- `accounts.tournament_coins` - Tournament coins balance
- `store_history.coin_type` - Tipo de moeda usada (0=normal, 1=tournament)

**Removido**:
- `store_history.coins` (não utilizado)

**Propósito**: Suportar tournament coins como currency alternativa
