## Visão Geral

**Versão**: 26  
**Objetivo**: Create towns management system

## Tabela Criada

```sql
CREATE TABLE `towns` (
  `id` int NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `name` varchar(255) NOT NULL UNIQUE,
  `posx` int NOT NULL DEFAULT '0',
  `posy` int NOT NULL DEFAULT '0',
  `posz` int NOT NULL DEFAULT '0'
);
```

**Colunas**:
- `name` - Nome da cidade (UNIQUE)
- `posx`, `posy`, `posz` - Coordenadas X, Y, Z

**Propósito**: Centralizar definição de cidades e suas posições
