## Visão Geral

**Versão**: 6  
**Objetivo**: Create stash system for supply items

## Tabela Criada

```sql
CREATE TABLE `player_stash` (
  `player_id` INT(16) NOT NULL,
  `item_id` INT(16) NOT NULL,
  `item_count` INT(32) NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8;
```

**Colunas**:
- `player_id` - ID do jogador
- `item_id` - ID do item armazenado
- `item_count` - Quantidade armazenada

**Propósito**: Armazenar items no stash supply system
