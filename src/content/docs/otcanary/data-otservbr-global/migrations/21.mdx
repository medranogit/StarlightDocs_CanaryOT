## Visão Geral

**Versão**: 21  
**Objetivo**: Add forge and tier system support

## Alterações

```sql
ALTER TABLE `market_offers` 
ADD `tier` tinyint UNSIGNED NOT NULL DEFAULT '0';

ALTER TABLE `market_history` 
ADD `tier` tinyint UNSIGNED NOT NULL DEFAULT '0';

ALTER TABLE `players` 
ADD `forge_dusts` bigint(21) NOT NULL DEFAULT '0',
ADD `forge_dust_level` bigint(21) UNSIGNED NOT NULL DEFAULT '100';
```

**Novas Colunas**:
- `market_offers.tier` - Tier do item
- `market_history.tier` - Tier histórico
- `players.forge_dusts` - Forge dust acumulado
- `players.forge_dust_level` - Nível de dust do forge

**Propósito**: Suportar sistema de forge com tiers
