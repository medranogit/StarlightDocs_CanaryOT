## Visão Geral

**Versão**: 38  
**Objetivo**: Create key-value storage system

## Tabela Criada

```sql
CREATE TABLE `kv_store` (
  `key_name` varchar(191) NOT NULL PRIMARY KEY,
  `timestamp` bigint NOT NULL,
  `value` longblob NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8;
```

**Colunas**:
- `key_name` - Chave única
- `timestamp` - Última modificação
- `value` - Valor BLOB (pode ser serializado)

**Propósito**: Armazenamento genérico de chave-valor para configurações dinâmicas
