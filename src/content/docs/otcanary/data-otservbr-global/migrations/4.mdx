## Visão Geral

**Versão**: 4  
**Objetivo**: Create boosted creature tracking system

## Tabela Criada

```sql
CREATE TABLE `boosted_creature` (
  `boostname` TEXT,
  `date` varchar(250) NOT NULL DEFAULT '' PRIMARY KEY,
  `raceid` varchar(250) NOT NULL DEFAULT '',
  PRIMARY KEY (`date`)
);
```

**Colunas**:
- `boostname` - Nome da criatura boosted
- `date` - Data do boost (PK)
- `raceid` - ID da raça

**Propósito**: Registrar criatura do dia boosted
