## Tabela Criada

```sql
CREATE TABLE `player_hirelings` (
  `id` INT NOT NULL PRIMARY KEY AUTO_INCREMENT,
  `player_id` INT NOT NULL,
  `name` varchar(255),
  `active` tinyint unsigned DEFAULT '0',
  `sex` tinyint unsigned DEFAULT '0',
  `posx` int DEFAULT '0',
  `posy` int DEFAULT '0',
  `posz` int DEFAULT '0',
  `lookbody` int DEFAULT '0',
  `lookfeet` int DEFAULT '0',
  `lookhead` int DEFAULT '0',
  `looklegs` int DEFAULT '0',
  `looktype` int DEFAULT '136',
  FOREIGN KEY(`player_id`) REFERENCES `players`(`id`)
    ON DELETE CASCADE
);
```

**Colunas**:
- Position (posx, posy, posz)
- Appearance (lookbody, lookfeet, lookhead, looklegs, looktype)
- Meta (active, sex, name)

**Propósito**: NPC staff contratáveis pelos jogadores
