## Visão Geral

**Versão**: 23  
**Objetivo**: Create forge history tracking system

## Tabela Criada

```sql
CREATE TABLE `forge_history` (
  `id` int NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `player_id` int NOT NULL,
  `action_type` int NOT NULL DEFAULT '0',
  `description` text NOT NULL,
  `is_success` tinyint NOT NULL DEFAULT '0',
  `bonus` tinyint NOT NULL DEFAULT '0',
  `done_at` bigint NOT NULL,
  `done_at_date` datetime DEFAULT NOW(),
  `cost` bigint UNSIGNED NOT NULL DEFAULT '0',
  `gained` bigint UNSIGNED NOT NULL DEFAULT '0',
  FOREIGN KEY (`player_id`) REFERENCES `players` (`id`) 
    ON DELETE CASCADE
);
```

**Colunas**:
- `action_type` - Tipo de ação forge
- `is_success` - Sucesso da operação
- `bonus` - Bonus obtido
- `cost` / `gained` - Recursos

**Propósito**: Registrar histórico de forge operations
