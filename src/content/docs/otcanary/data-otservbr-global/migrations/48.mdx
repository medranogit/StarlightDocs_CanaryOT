## Visão Geral

**Versão**: 48  
**Objetivo**: Rework house auction system

## Remoções

```sql
ALTER TABLE `houses`
DROP `bid`, `bid_end`, `last_bid`, `highest_bidder`
```

## Adições

```sql
ALTER TABLE `houses`
ADD `bidder` int NOT NULL DEFAULT '0',
ADD `bidder_name` varchar(255) NOT NULL DEFAULT '',
ADD `highest_bid` int NOT NULL DEFAULT '0',
ADD `internal_bid` int NOT NULL DEFAULT '0',
ADD `bid_end_date` int NOT NULL DEFAULT '0',
ADD `state` smallint UNSIGNED NOT NULL DEFAULT '0',
ADD `transfer_status` tinyint DEFAULT '0'

ALTER TABLE `accounts`
ADD `house_bid_id` int NOT NULL DEFAULT '0'
```

**Novas Colunas**:
- `bidder`, `bidder_name` - Informações de quem está licitando
- `highest_bid`, `internal_bid` - Controle de lances
- `state`, `transfer_status` - Estados da house
- `accounts.house_bid_id` - Referência da bid

**Propósito**: Sistema de leilão mais robusto
