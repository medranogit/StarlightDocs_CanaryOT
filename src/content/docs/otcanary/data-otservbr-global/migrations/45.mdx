## Visão Geral

**Versão**: 45  
**Objetivo**: Add VIP groups management system

## Tabelas Criadas

**account_vipgroups**:
```sql
CREATE TABLE `account_vipgroups` (
  `id` int UNSIGNED NOT NULL AUTO_INCREMENT,
  `account_id` int UNSIGNED NOT NULL,
  `name` varchar(128) NOT NULL,
  `customizable` BOOLEAN NOT NULL DEFAULT '1',
  PRIMARY KEY (`id`, `account_id`)
);
```

**account_vipgrouplist**:
```sql
CREATE TABLE `account_vipgrouplist` (
  `account_id` int UNSIGNED NOT NULL,
  `player_id` int NOT NULL,
  `vipgroup_id` int UNSIGNED NOT NULL,
  UNIQUE (`account_id`, `player_id`, `vipgroup_id`),
  FOREIGN KEY (`player_id`) REFERENCES `players` (`id`)
    ON DELETE CASCADE
);
```

## Grupos Padrão

- **Friends** (ID 1) - Não customizável
- **Enemies** (ID 2) - Não customizável
- **Trading Partners** (ID 3) - Não customizável

## Trigger

Ao criar accounts, insere 3 grupos padrão automaticamente

**Propósito**: Organizar VIP list em grupos
